# RENAMED.md

This is the public sample of Checkable AI's knowledge base. Some of its files and folders use an older working name, Offerings Atlas, or Atlas. That name is retired, and the sample is described now as the Public sample slice of the Checkable AI knowledge base.

You will still see the older name in:

- the `okf/atlas/` folder, which holds the sample's pages
- the `web/atlas-sample.json` file and the `app/` folder, the reference code for the sample viewer
- tags such as `process:offerings-atlas-ingest` in the header of each page
- names that start with `atlas.` inside data files

These names are kept so the files stay the same and any link to them keeps working. They all mean the sample knowledge base.

If you are an AI agent or a script, read `okf/atlas/` as the sample's page tree and leave these names as they are. Do not rename them in the pages or the data.

Some product names in the sample contain the word Atlas, such as MITRE ATLAS and MongoDB Atlas. Those belong to other organisations.
