## Answer

Not covered. Only outbound A2A client connections via an installed integration; no inbound A2A, mutual authentication or card signature checks documented.

Last checked 16 November 2026.

Research detail: Agentic virtual agents act as A2A clients that delegate tasks to external agents through the External A2A Server integration, which fetches the Agent Card from a public URL and authenticates with Basic Auth or OAuth credentials. Only mapped fields are shared and the virtual agent stays the customer-facing owner.
