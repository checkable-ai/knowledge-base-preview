## Answer

Not covered. No sandbox or egress policy; deletion of an agent or Copilot agent disablement is not an immediate emergency stop.

Last checked 16 November 2026.

Research detail: Administrators can enable or disable available Copilot AI agents, with audit logs recording each change, and the announcement dates from July 2026. Copilot operates within the permissions of the user and has safeguards that block out-of-scope or harmful requests. An agentic virtual agent can be deleted from its management page, and flows in Architect decide where it runs.

## Products

Copilot AI agent enable and disable, agentic virtual agent management, Architect flows

## Gaps

No sandbox, filesystem, process or network egress policy is documented for agent-executed actions, which run through data actions. Deletion is the only documented stop for an agentic virtual agent, and the page does not say what happens to live conversations. The Copilot toggle is announced for a future release in the source.
