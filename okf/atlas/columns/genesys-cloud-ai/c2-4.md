## Answer

Not covered. Start and end context variables and interaction data retention exist, but session memory access, resumption and turn limits are not documented.

Research detail: Each interaction session receives start context variables from the calling flow, with string values maskable from the agent, and returns up to 50 end context variables. Session data is retained under the organisation's maximum interaction data retention setting.

## Products

## Gaps
