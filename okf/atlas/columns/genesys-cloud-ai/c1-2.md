<!-- chunk: answer -->
## Answer

Covered. Copilot is bound to user permissions. Virtual agents are limited to the tools selected in their profile and the credentials behind them, with no per-tool read or write scoping.

Source statement: "Genesys Cloud Copilot and its AI Agents operate strictly within the permissions of the user." (https://help.genesys.cloud/faqs/how-does-genesys-cloud-copilot-ensure-trust-and-control/)

Research detail: Each agent can only call the data actions, knowledge and A2A connections selected in its profile, with a limit of 20 data actions per guide and per-session execution limits. Genesys Cloud data actions run under OAuth clients whose roles are scoped to divisions. Copilot agents act within the user's role permissions.

<!-- chunk: products -->
## Products

Agent Tools tab, data actions, OAuth client roles and divisions, Copilot permissions

<!-- chunk: gaps -->
## Gaps

No per-tool read or write scoping inside an agent beyond selecting the tool. Third-party data actions rely on whatever the external credential allows.

<!-- chunk: options -->
## Options

Create separate data action integrations with least-privilege credentials per agent and restrict OAuth client roles to the needed divisions.
