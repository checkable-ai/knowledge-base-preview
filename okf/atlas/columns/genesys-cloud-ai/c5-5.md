## Answer

Not covered. Genesys does not document a readable view that shows, for each agent, which downstream systems it can reach and what it can do there. Nearby features fall short. The tool Summary tab for an agentic virtual agent shows one tool's parameters at a time, not the agent's reach across systems. The object dependency view on the integration Connections tab traces integrations, data actions, Architect flows and credentials, but it is organised by integration, not by agent, and does not show what actions the credentials allow.

Last checked 16 November 2026.

Research detail: Each agent profile lists its Tools, Knowledge and A2A connections, and A2A tiles show the external agent card with its skills. This gives a per-agent list of reachable systems.
