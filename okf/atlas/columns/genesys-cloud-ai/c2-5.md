## Answer

Covered. Vendor-managed runtime inside AI Studio agentic virtual agents. Customers configure only the tools themselves (data actions, knowledge, A2A). The runtime itself cannot be customised.

Source statement: "View the sequence of tool calls made during an interaction" (https://help.genesys.cloud/409104)

Last checked 16 November 2026.

Research detail: Genesys runs the harness that executes data actions, knowledge searches, A2A calls and built-in tools, and records each tool call with latency, status and inputs and outputs. Tool contracts are typed as DataAction, KnowledgeBase, KnowledgeSetting or ExternalA2AServer.

## Products

Agentic virtual agent runtime, tool call logs

## Gaps
