## Answer

Covered. Virtual Agent must be enabled in the organisation. The user needs AI Studio permissions for agentic virtual agents.

Source statement: "Define strict validation rules that the agent must pass before the tool is actioned." (https://help.genesys.cloud/articles/set-up-tools-for-an-agentic-virtual-agent/)

Last checked 16 November 2026.

Research detail: Tools are limited to selected data actions with typed input variables, allowed-value lists, unsupported schema features rejected and output fields masked. Data action invocations count toward per-session execution limits. Guardrail custom rules can block requests such as accepting payments.

<!-- chunk: products -->
## Products

Agent Tools configuration, data action limits, custom guardrail rules

<!-- chunk: gaps -->
## Gaps

No egress control, dangerous-action filtering at execution time or injection screening of tool responses.

<!-- chunk: options -->
## Options

Constrain inputs with List types and pre-instructions and enforce authorisation in the backend that the data action calls.
