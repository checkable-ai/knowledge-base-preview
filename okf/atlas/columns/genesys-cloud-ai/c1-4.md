## Answer

Covered. Requires AI Studio permissions such as Agentic Virtual Agent Add/Edit and Delete. Some Copilot agents cannot be disabled.

Source statement: "You can view all existing agents and duplicate, delete, or rename an agent on the Agentic Virtual Agents view." (https://help.genesys.cloud/articles/manage-an-agentic-virtual-agent/)

Last checked 16 November 2026.

Research detail: Creating, editing, deleting and versioning agents and guides is gated by AI Studio permissions such as Agentic > Virtual Agent Add/Edit and AI Studio > Guide Delete. Agents can be duplicated and deleted, and Copilot administrators can enable or disable individual Copilot AI agents.

## Products

AI Studio permissions, View and manage agentic virtual agents, Copilot configuration

## Gaps

## Options
