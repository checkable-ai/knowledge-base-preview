## Answer

Not covered. No documented short-lived credentials, rotation, expiry or revocation for data action or A2A credentials. Mask value from agent keeps selected tool output from the model but does not manage credential lifecycle, and secure data actions are unavailable in AI Guides.

Research detail: Tools are data actions whose integration credentials Genesys encrypts, restricts to the services that use them and keeps out of the public API. Tool outputs can be masked from the agent so tokens and internal IDs do not enter model context. External A2A servers take Basic Auth or OAuth client credentials or password grant credentials configured on the integration.

<!-- chunk: products -->
## Products

Data actions integrations, Mask value from agent, External A2A Server integration

<!-- chunk: gaps -->
## Gaps

Credential rotation, expiry and revocation are not described for data action or A2A credentials. Secure data actions are unavailable in AI Guides.

<!-- chunk: options -->
## Options

Use OAuth client credentials with short token durations and rotate integration secrets through the platform API. Test that masked outputs never appear in transcripts.
