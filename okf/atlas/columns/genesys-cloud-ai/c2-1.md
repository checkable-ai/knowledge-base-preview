## Answer

Not covered. No documented ordering, hand-off, cancellation or recovery control across the steps of an agent's task. The nearest feature, configurable error handling for Agentic Virtual Agents (retries, fallback paths, recovery prompts), covers tool execution failures only.

Last checked 16 November 2026.

Research detail: Architect Virtual Agent flows call agents and take Success or Failure paths with exit reasons. Agents have built-in end_conversation and escalate_to_human_agent tools, mapped error cases per tool status code, and can delegate tasks to external A2A agents.

## Products
