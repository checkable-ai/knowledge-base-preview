## Answer

Not covered. No documented approval gate for virtual agent tool calls, binding of approval to the exact action, handling of refusals or replay protection. Nearby feature: Genesys Cloud Copilot approval of system configuration changes, which covers configuration only.

Research detail: Genesys Cloud Copilot always requires the user to review and approve system configuration changes before they are applied. Agentic virtual agents have no built-in approval step before a tool call, although pre-instructions can tell the agent to confirm details with the customer first.

## Gaps

## Options
