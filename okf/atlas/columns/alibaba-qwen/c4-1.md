## Answer

Not covered. Agent applications have an app ID and version records, but no identity tied to an owner and to where the agent runs. API keys are the only workload credential. Application features are also a restricted preview.

Research detail: Model Studio agent and workflow applications have an app ID within a workspace, and version management records each published version with its version ID, publication time and publisher. These application features are a preview open only to some Singapore accounts. No workload identity for agents beyond API keys is described.
