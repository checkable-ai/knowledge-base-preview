## Answer

Not covered. No gateway that filters what data each agent or user can retrieve, and no DLP over prompts or retrieved content. RAM custom policies (sfm:CreateIndex, UpdateIndex, DeleteIndex, SubmitIndexJob) and temporary API keys only limit who can manage knowledge bases. They do not filter retrieval or prevent data loss.

Research detail: RAM custom policies can grant only the knowledge base actions a user needs, and temporary keys keep the parent key's knowledge base restrictions. No DLP over prompts or retrieved content is described.
