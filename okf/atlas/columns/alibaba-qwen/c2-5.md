## Answer

Covered. Responses API only. MCP servers must use SSE, with at most 10 MCP servers per request. Built-in tools such as Code Interpreter and web search run server-side. The tool loop is run by the platform, and the only setting is which tools are enabled.

Source statement: "The Model Context Protocol (MCP) enables large language models to use external tools and data." (https://www.alibabacloud.com/help/en/model-studio/mcp.md)

Research detail: The Responses API runs built-in tools server-side, including Code Interpreter, web search and up to 10 MCP servers over SSE. The tool loop is platform-run and is not configurable beyond tool selection.
