## Answer

Covered. Controls are per workspace, not per user or agent; routing limited to Beijing and Singapore; no prompt injection screening.

Source statement: "The routing strategy determines which model in the candidate set executes each request." (https://www.alibabacloud.com/help/en/model-studio/model-routing.md)

Research detail: Each sub-workspace sets which models can be called and per-model request and token limits, and API keys inherit them. Intelligent Model Routing picks a model from a candidate set by an effect-first or cost-first strategy. All calls pass inline content moderation that cannot be fully turned off.
