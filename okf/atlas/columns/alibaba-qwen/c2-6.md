## Answer

Covered, with conditions. Agent application long-term memory is a preview feature. The Application Development tab is limited to users who created Model Studio applications in the Singapore region before 21 April 2025. Memory storage is free. Memory content is merged into the prompt during Q&A.

Source statement: "Data storage for long-term memory is free of charge." (https://www.alibabacloud.com/help/en/model-studio/single-agent-application.md)

Last checked 19 October 2026.

Research detail: Agent applications support long-term memory, and RAM custom policies can grant create, update and delete actions on memory. Memory content is merged into the prompt during a session. The application features are a preview with restricted access.
