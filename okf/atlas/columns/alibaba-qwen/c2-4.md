## Answer

Not covered. Conversations API stores history until deleted, but no per-user read access control is described, deleting a conversation does not delete its items, and ZDR does not apply.

Research detail: The Conversations API stores conversation items so the Responses API can inject history across devices, and conversations can be retrieved, updated and deleted. Stateful features are kept until the user deletes them. Access is by API key, and per-user access control is not described.
