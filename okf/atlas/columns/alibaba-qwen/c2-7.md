## Answer

Not covered. Code interpreter sandbox isolation, network access and resource limits are undocumented, and there is no stop control for a running agent. Key deletion or disabling cuts access but does not stop a running agent.

Research detail: The code interpreter tool has the model write and run Python in a sandbox. On QwenCloud, deleting an API key makes all requests with it fail immediately, a disabled key rejects requests and re-enabling is immediate, and a reset Token Plan key invalidates the old one at once. In Model Studio, removing a RAM user from a workspace invalidates their key.

<!-- chunk: products -->
## Products

Code interpreter sandbox, QwenCloud API key delete, disable and reset, Model Studio workspace key invalidation

<!-- chunk: gaps -->
## Gaps

The sandbox's isolation, network access, timeouts and resource limits are not documented on either site. The Model Studio permission page does not state timing. There is no stop control for a running agent or call.
