## Answer

Not covered. Temporary API keys (1 to 1,800 seconds) are minted by the customer backend. There is no broker for third-party tool credentials, MCP credentials are static per request, and nothing keeps secrets from the model.

Research detail: A backend can mint temporary API keys that inherit the parent key's permissions and expire after 1 to 1,800 seconds, so permanent keys are not exposed in browsers or apps. API keys can carry an IP allow list and become invalid when the user is removed from the workspace. Credentials for MCP servers and custom plugins are passed as static headers.

## Gaps

## Options
