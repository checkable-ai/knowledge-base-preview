## Answer

Covered. Creation limits are set by Studio app admins (selected groups, up to 10, or admins only). Editing, transferring and deleting agents is per the research notes; plan requirements vary by page.

Source statement: "You can determine who can or can't create agents within your organisation." (https://support.atlassian.com/studio/docs/manage-who-can-create-in-studio/)

Research detail: Studio app admins limit agent creation to all users, up to 10 groups or no users. Only the creator or an org admin can edit an agent, ownership can be transferred, org admins can delete any agent, and agent access is granted and revoked from the agent profile.

<!-- chunk: products -->
## Products

Studio agent creation settings, Rovo Agents tab, agent profile

<!-- chunk: gaps -->
## Gaps

No documented approval step before an agent goes live. Plan requirements differ across pages, and the Agents tab page lists Guard Premium.

<!-- chunk: options -->
## Options

Restrict creation to a builder group and pair it with an external review step.
