## Answer

Not covered. Atlassian documents audit log events for Rovo MCP tool use (tool name, action, user), but does not document write-once or integrity-validated storage for these entries, nor an export of them to such storage. Audit log streaming to a SIEM is a nearby feature but does not itself meet the tamper-evidence outcome. Agent-level actions beyond MCP tool calls are not documented as a complete record, and API-token use may be attributed to a service account instead of the end user.

Research detail: The audit log records Rovo chats started, agents created, updated or deleted, bookmarks and connector changes, with Rovo logs on all plans. Each MCP tool call is logged with tool name, action and user, and Agent's account changes appear under the agent's name. Retention is 180 days, or 365 with Guard.

## Gaps

Prompts, responses and reasoning are not described as logged. No tamper-proof claim. API token MCP calls log the token owner, and later user authorisations of the MCP app are not logged.

## Options

Stream logs to an immutable store and capture conversation content through live review where needed.
