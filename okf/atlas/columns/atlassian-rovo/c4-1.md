## Answer

Not covered. Agent's account option gives each agent an Atlassian account, but no documented binding of that identity to where the agent runs or to a release or version. User's account agents act as the invoking user.

Research detail: A Rovo agent built with the Agent's account option gets its own Atlassian account, and changes it makes are credited to the agent in audit logs. Org admins see each agent in the Rovo Agents tab with its creator or owner, and ownership can be transferred. Agents built with the User's account option have no separate acting identity.

## Products

Rovo Studio agent accounts, Rovo Agents tab in Atlassian Administration

## Gaps

No documented link from the identity to a runtime or a release or version. User's account agents act as the invoking user. The Agents tab page lists Guard Premium as the plan, which may limit who gets the inventory.
