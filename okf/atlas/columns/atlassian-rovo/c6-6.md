## Answer

Covered. Agents in Rovo Studio. Creator is owner by default, ownership can be transferred, and owners can add editors and managers.

Source statement: "An agent is attributed to the person who created it (the owner) by default." (https://support.atlassian.com/rovo/docs/rovo-agent-permissions-and-governance/)

Research detail: Each agent has a creator or owner shown in the admin inventory. Ownership can be transferred, a manager can take over an agent whose owner is gone, and an author display name can show a team.
