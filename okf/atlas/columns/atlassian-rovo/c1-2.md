## Answer

Covered. Agent's account agents; admin access management in Atlassian Administration.

Source statement: "To revoke an agent's access to an app, select the **More actions** () menu for the app, then **Remove access**." (https://support.atlassian.com/organization-administration/docs/manage-agents-in-your-organization/)

Research detail: Agent's account agents get app access and group membership set by org admins, default access for future agents, and space and page grants from space admins and users. Builders choose each agent's tools, admins choose which tools from external MCP servers are usable, and automations can run an agent read-only.

<!-- chunk: products -->
## Products

Rovo Agents tab, default access, agent tools, external MCP server tool selection

<!-- chunk: gaps -->
## Gaps

User's account agents inherit the full user scope. Bulk Jira actions are capped at 20 items but finer per-action limits are not described.

<!-- chunk: options -->
## Options

Set restrictive default access, build single-purpose agents with few tools, and use read-only mode in automations.
