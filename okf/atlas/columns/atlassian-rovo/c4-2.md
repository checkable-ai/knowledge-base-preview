## Answer

Not covered. OAuth 2.1 is the MCP default, but no documented token expiry, rotation or exclusion of secrets from model context. API token clients run as the token owner.

Research detail: Third-party tools are connected through an OAuth flow to the third-party product, after which the agent acts without re-authentication, and users revoke access from Connected apps. For the Rovo MCP server, OAuth 2.1 is the default and admins can switch off API token authentication.

## Gaps

No documentation on token storage, rotation, expiry or whether secrets are kept out of model context. API token clients run under the token owner's account.
