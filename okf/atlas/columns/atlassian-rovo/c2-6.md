## Answer

Covered. Per user and site; admins cannot view memories.

Source statement: "You can view, edit, or delete them at any time." (https://support.atlassian.com/rovo/docs/what-is-rovo-memory-management/)

Research detail: Rovo memory keeps an implicit summary from Teamwork Graph activity and explicit instructions saved from chat, scoped to the user and site. Users can view, edit, delete and switch memory off, and org admins cannot view memories.

<!-- chunk: products -->
## Products

Rovo memory

<!-- chunk: gaps -->
## Gaps

No documented admin control to disable memory or set retention. Implicit details cannot be deleted directly.

## Options

Ask Atlassian for an org-level memory control and test deletion.
