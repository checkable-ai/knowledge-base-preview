## Answer

Not covered. Admin selection of allowed tools on MCP servers is only a tool allowlist. No input format enforcement, rate limits, or blocking of dangerous actions is documented.

Research detail: Admins select which tools from external MCP servers Rovo can use and can turn off default third-party actions per site. The Rovo MCP server enforces a domain allowlist for OAuth clients and org IP allowlists, and Rovo Dev has allowedMcpServers and disabledMcpServers settings.

<!-- chunk: products -->
## Products

External MCP server tool selection, Rovo MCP server settings, Rovo Dev MCP settings

<!-- chunk: gaps -->
## Gaps

No injection screening or dangerous action filtering. Atlassian states guardrails in instructions are suggestions the agent may not follow. No per-agent rate limits.

<!-- chunk: options -->
## Options

Limit tools per agent, block unneeded domains and add an external MCP gateway for screening.
