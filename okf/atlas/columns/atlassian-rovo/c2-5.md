## Answer

Covered. Rovo Dev CLI and Rovo agents tools.

Source statement: "In interactive mode, when Rovo Dev is about to use a tool for the first time, it will ask for permission." (https://support.atlassian.com/rovo/docs/use-tools-in-rovo-dev-cli/)

Research detail: Rovo agents run tools and skills, each a single action such as creating Jira work items or Confluence pages, with Forge tool modules for custom tools. Rovo Dev CLI is a coding harness with file, bash or PowerShell, git and MCP tools.
