## Answer

Covered. Live conversation review must be enabled per agent by an org admin or Studio admin. Review happens after the fact.

Source statement: "Access to view transcripts is restricted to agent creators and managers to ensure data privacy." (https://support.atlassian.com/rovo/docs/review-live-conversations-with-your-rovo-agent/)

Research detail: Agent creators and managers can review full transcripts of user conversations with message feedback when live review is enabled, and users see a privacy notice. Automations can run agents read-only so output is produced without changes.

<!-- chunk: products -->
## Products

Live conversation review, Use agent read-only mode

<!-- chunk: gaps -->
## Gaps

Review is after the fact. Org admins only see transcripts if they also hold an agent role.

<!-- chunk: options -->
## Options

Enable live review for high-impact agents and route automation output to a human step.
