## Answer

Covered. Rovo Dev CLI only; settings in local config file; YOLO mode skips confirmations.

Source statement: "Control which tools can be used, and whether you are prompted before they are used." (https://support.atlassian.com/rovo/docs/manage-rovo-dev-cli-settings)

Research detail: Rovo Dev CLI sets allow, ask or deny per tool in config.yml, with regex rules for bash commands, each part of compound commands checked separately, and file access limited to the workspace unless paths are allowed. Rovo agents themselves run in Atlassian cloud with no local host.

## Gaps

Settings are in a user-editable local file and YOLO mode skips confirmations for the session. The bash sandbox setting is marked macOS only and internal users.
