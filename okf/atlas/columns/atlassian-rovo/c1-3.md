## Answer

Not covered. Chat confirmation and Rovo Dev CLI prompts exist, but approval is not tied to an authorised approver or exact parameters, automations have no approval step, and always/YOLO options remove prompts.

Research detail: In chat an agent asks for confirmation before running consequential tools that may change data across systems. Rovo Dev CLI asks before tool use with once, session or always options and lets the user give a deny reason.

<!-- chunk: products -->
## Products

Rovo agent tool confirmation, Rovo Dev CLI approvals

## Gaps

Autonomous agents in automations have no approval step. No documentation that approval is bound to exact parameters or handles replay. Always and YOLO choices remove prompts.
