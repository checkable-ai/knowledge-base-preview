## Answer

Not covered. No central tool allow list, schema enforcement, tool quotas or egress control. Autonomy policies and MCP annotations fall short.

Research detail: Tools are attached per agent in North by adding MCP servers under the agent's Tools section, and autonomy policies limit agents to authorised actions. MCP tool annotations such as destructiveHint let North warn users before destructive actions. Schema enforcement, tool call quotas, injection screening of tool output and egress control are not documented.

## Products

North agent Tools configuration, autonomy policies, MCP tool annotations

## Gaps

No documented central tool allow list, tool rate limits, dangerous action filtering beyond annotations, or egress control. North admin documentation is not public (the Cohere customer hub needs a login), so launch posts, product pages and the public North MCP SDK repository were used.
