## Answer

Not covered. North Libraries documents access control, permission carry-over and automatic resync, but no data cleaning, deduplication or data-quality enforcement for the stores agents read. The vendor does not state that it covers only part of the outcome.

Research detail: The Cohere API Datasets feature validates uploaded data against its type before use, deletes datasets 30 days after creation, allows manual deletion and caps storage at 10GB per organisation. North Libraries hold shared knowledge for the organisation, but their governance, sanitisation and access control are not documented.

Cohere Datasets API, North Libraries

## Gaps

No documented sanitisation beyond format validation and no governance of North Libraries. North admin documentation is not public (the Cohere customer hub needs a login), so launch posts, product pages and the public North MCP SDK repository were used.
