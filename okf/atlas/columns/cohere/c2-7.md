## Answer

Not covered. No documented sandbox for files, processes or network, and no per-agent emergency stop. Model Vault pause stops the model for all callers.

Research detail: Model Vault lets an admin pause a model, which shuts down its replicas and halts all ongoing traffic. Private deployments run in the customer's VPC or on-premises and can be fully network-isolated. The North 2 post describes autonomy policies so agents take only authorised actions, and North Admin guardrails per agent.

<!-- chunk: products -->
## Products

Model Vault pause, private deployment, North autonomy policies and North Admin

<!-- chunk: gaps -->
## Gaps

Cohere documents no code execution sandbox, filesystem or process policy, or per-agent stop for North agents. Pausing a vault stops the model for every caller, not one agent.

<!-- chunk: options -->
## Options

In a private deployment, apply network policy around North and its tool servers, and test whether disabling an agent in North Admin stops a running task.
