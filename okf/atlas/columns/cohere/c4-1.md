## Answer

Not covered. No stable agent identity bound to owner, runtime and release. North passes the user's IdP token and the API uses team keys.

Research detail: Checked the North 2 post, North product pages, the North MCP SDK and the API docs. North authenticates calls to MCP tool servers with the initiating user's identity provider ID token, not an agent identity, and the API authenticates with team API keys. North Admin reports usage per agent, but no stable agent or workload identity bound to an owner, runtime and release is documented.
