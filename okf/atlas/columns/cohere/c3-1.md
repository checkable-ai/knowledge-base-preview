## Answer

Covered. North Admin. Prompt injection screening and per-agent model routing are not documented.

Source statement: "Monitor and control token spend and limiting by defining consumption tiers." (https://cohere.com/blog/introducing-north-2)

Research detail: North Admin tracks token spend per user and agent, sets consumption tiers by request and token rate for users and groups, sets org-wide caps and alerts, and controls which models are used by whom. North is model agnostic. The post names prompt injection as a risk but does not describe an injection screen.
