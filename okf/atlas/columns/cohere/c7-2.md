## Answer

Not covered. No security events, SIEM export, detections or response ownership documented for North. The MCP SDK telemetry covers only customer tool servers.

Research detail: The North MCP Python SDK adds OpenTelemetry helpers for tool servers, with log and trace correlation and sensitive data left out of spans by default. The North page says North connects to existing monitoring systems through APIs. No security event schema, SIEM export, detections or response ownership is documented for North itself.

## Products

North MCP Python SDK telemetry, North monitoring integration

<!-- chunk: gaps -->
## Gaps

SDK telemetry covers the customer's own MCP servers, not North. No security events with actor and session correlation. Cohere receives no log data from private deployments. North admin documentation is not public (the Cohere customer hub needs a login), so launch posts, product pages and the public North MCP SDK repository were used.

## Options
