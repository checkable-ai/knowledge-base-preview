## Answer

Not covered. Run state is stored in Dataverse tables, but no retention period or session resumption is documented.

Research detail: Agent state per lead is stored in Dataverse tables such as Sales Agent Run, Lead Agent Result and Sales Agent Handover, governed by security roles. The agent processes read data in memory and discards it after analysis.
