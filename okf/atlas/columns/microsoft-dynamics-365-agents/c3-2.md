## Answer

Not covered. Allowed MCP clients and role-filtered tools help, but there are no per-tool limits, input schema checks or injection screening at the MCP server.

Research detail: The ERP MCP server only accepts agent clients listed in Allowed MCP clients, filters tools by the user's role and excludes security, user setup and feature management forms. Sales agents need named connectors allowed in Power Platform data policies.
