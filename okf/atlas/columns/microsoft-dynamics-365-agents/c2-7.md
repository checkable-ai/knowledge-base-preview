## Answer

Not covered. No sandbox for files, processes or network. Stopping the Sales Qualification Agent is not immediate for in-flight leads, and Allowed MCP clients only limits connections.

Research detail: Dynamics 365 agents run in Microsoft-operated services, so there is no customer sandbox to configure. Administrators can stop the Sales Qualification Agent, but leads already in its pipeline continue until handed over or escalated. Case update rules can be deactivated or put in shadow mode. For the ERP MCP server, the Allowed MCP clients list controls which agent platforms can connect, and every request runs under the user's or agent's own finance and operations security roles.

## Products

Sales Qualification Agent stop control, Case Management Agent rules and shadow mode, ERP MCP Allowed MCP clients

## Gaps

Stopping the Sales Qualification Agent is not immediate for in-flight work. No code execution sandbox, process policy or egress control is exposed. The agent cannot be deleted without Microsoft support.

<!-- chunk: options -->
## Options

Disable the agent's Dataverse application user and remove its client from Allowed MCP clients to cut access at once. Test how long in-flight work continues after stopping an agent in a sandbox environment.
