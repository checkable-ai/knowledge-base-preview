## Answer

Not covered. Guided setup and start/stop exist, but retirement of a configured Sales Qualification Agent needs a Microsoft support request and no permission change-approval process is documented.

Research detail: Admins provision the Sales Qualification Agent through a guided prerequisite list that creates the app registration, Dataverse app user, role and shared mailbox. Creating a sales agent auto-provisions its Copilot Studio skill agents and their app registrations. Agents can be stopped, but a configured Sales Qualification Agent can only be deleted by Microsoft support.
