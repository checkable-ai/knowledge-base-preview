## Answer

Covered. Dynamics 365 ERP MCP server with chat or delegated agents configured to run on behalf of the user. Autonomous agents use their own identity instead.

Source statement: "For chat or delegated agents, set the agent configuration to run on behalf of the user who is chatting with the agent." (https://learn.microsoft.com/en-us/dynamics365/fin-ops-core/dev-itpro/copilot/mcp/mcp-security)

Research detail: The ERP MCP server runs every request as the authenticated user, so chat or delegated agents act on behalf of the user and their roles and record-level security apply. The Scheduling Operations Agent applies the combined permissions of the dispatcher and its application user. The Sales Qualification Agent acts as its own app user and reads external knowledge sources with the administrator's identity, though sellers only see output their roles allow.

<!-- chunk: products -->
## Products

Dynamics 365 ERP MCP server, Scheduling Operations Agent, Sales Qualification Agent

<!-- chunk: gaps -->
## Gaps

Autonomous Sales and Service agents do not carry the initiating user identity. Knowledge source access uses the configuring administrator's identity.

<!-- chunk: options -->
## Options

Prefer delegated agents through the ERP MCP server for user-bound actions and review which identity each knowledge source uses.
