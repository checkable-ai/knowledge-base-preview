## Answer

Not covered. No public Dynamics 365 agent documentation describes write-once or integrity-validated storage for agent action records, nor a documented export of that record to such storage. Dataverse auditing records changes but logs can be deleted and retrieve operations are excluded. Purview audit events for agent activity exist but are not documented as tamper-evident for this product.

Research detail: Dataverse auditing records who created, changed or deleted records with old and new values, including agent application users, and agent runs are kept in the Sales Agent Runs table. Governance policy evaluations are logged. Audit logs can be deleted by users with the right privilege, and auditing excludes retrieve operations.

## Products

Dataverse auditing, Sales Agent Runs table, governance logs

## Gaps

Not tamper-proof. Model reasoning is not logged in Dataverse audit. Auditing must be turned on per table.

## Options
