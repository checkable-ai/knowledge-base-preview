## Answer

Covered. Dataverse security roles on the agent user and ERP security roles. Scope is per role and table, not per action instance.

Source statement: "The system rejects any explicit calls to actions or objects to which the user role doesn't have access." (https://learn.microsoft.com/en-us/dynamics365/fin-ops-core/dev-itpro/copilot/copilot-mcp)

Research detail: Agent actions are limited by Dataverse security roles on the agent user, such as the customisable AISalesperson role and roles assigned to the Scheduling Operations Agent Team, including field security profiles. Case Management Agent only updates fields listed in admin rules. ERP MCP tools return only menu items, entities and actions the role allows, and the server never elevates privilege.

<!-- chunk: products -->
## Products

Dataverse security roles, Case Management Agent rules, Dynamics 365 ERP MCP server

<!-- chunk: gaps -->
## Gaps

Scopes are set per role and table, not per action instance.

<!-- chunk: options -->
## Options

Create least-privilege custom roles for each agent user and review them after updates.
