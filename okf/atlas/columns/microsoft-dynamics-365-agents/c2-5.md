## Answer

Not covered. The tool-calling harness belongs to Copilot Studio or the chosen agent client. The ERP MCP server is a tool provider, not the program that runs tools for the agent.

Research detail: Prebuilt Dynamics agents are sets of Copilot Studio skill agents run by Copilot Studio and coordinated by Dynamics backend services. The ERP MCP server adds data, form and action tools that an agent client calls.
