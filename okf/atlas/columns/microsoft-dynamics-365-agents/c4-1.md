## Answer

Not covered. Agents get their own identities (Dataverse application users, ERP MCP autonomous agent identity), but no documented link to an accountable owner, run location or specific release.

Research detail: The Sales Qualification Agent runs as a Dataverse application user tied to a Microsoft Entra app registration, with its own ID and the AISalesperson role. The Scheduling Operations Agent runs as an application user in the Scheduling Operations Agent Team, and autonomous ERP MCP agents authenticate with their own identity. Copilot Studio also creates an app registration for each skill-based agent. The Dynamics pages do not link these identities to an owner or release.

<!-- chunk: products -->
## Products

Dataverse application users, Entra app registrations, Copilot Studio skill agents

## Gaps

No owner or release linkage documented for the Dynamics agent user. Whether Copilot Studio Entra Agent IDs and sponsors apply to the auto-provisioned skill agents is not stated.

## Options
