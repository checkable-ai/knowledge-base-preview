## Answer

Not covered. No generated view of which downstream systems each agent can reach and what it can do there. The ERP MCP server returns only the objects a security role allows, and provisioned skill agents are listed, but neither is a readable reach-and-permissions map.

Last checked 12 November 2026. This platform is checked on demand, so this answer has not been rechecked since.

Research detail: Microsoft lists the skill agents and app registrations each sales agent provisions and the connectors it needs in data policies. ERP MCP returns only the actions and entities the agent's role can reach.
