## Answer

Not covered. No load or latency dashboards for the systems agents run on. Per-agent exception rates and the OpenTelemetry Distro are nearby but leave infrastructure monitoring to the customer's backend.

Research detail: The admin center shows exceptions and exception rates per agent and tool, and the OpenTelemetry Distro collects traces, metrics and logs including HTTP and database instrumentation for export to Azure Monitor or any OTLP backend.
