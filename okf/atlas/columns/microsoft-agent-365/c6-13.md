## Answer

Not covered. No Agent 365 specific IRAP, SOC 2, ISO 27001 or ISO 42001 scope is published. Assurance is inherited from underlying services and Agent 365 is not named in the IRAP scope.

Research detail: Microsoft states Agent 365 is not yet a Core Online Service under the Product Terms and operates on Microsoft services that hold SOC reports, ISO certifications, FedRAMP, HIPAA and PCI DSS. Microsoft's IRAP page lists Azure, Dynamics 365, Microsoft Managed Desktop, Office 365 and Windows 365 as in scope at PROTECTED, with reports on the Service Trust Portal. Agent 365 is not named in that scope.

## Gaps
