## Answer

Covered. Single Agent Map is preview and depends on observability data from SDK-integrated agents. Defender inventory shows tools and MCP servers per agent.

Source statement: "The Single Agent Map (preview) gives admins a connected view of one agent, the users who interact with it, and the tools it invokes." (https://learn.microsoft.com/en-us/microsoft-365/admin/manage/agent-map?view=o365-worldwide)

Research detail: Agent Map shows agents grouped by platform, and Single Agent Map shows the users and tools an agent calls. The Data and tools tab lists capabilities, knowledge sources and tools, the Permissions tab lists granted permissions, and Defender shows tools, MCP servers and attack-surface relationships.

## Products

Agent Map, registry agent details, Defender AI Agents page

## Gaps

Single Agent Map is preview and depends on telemetry. Data and tools metadata is missing for some agent types.

## Options

Check that every agent sends telemetry and review the Permissions tab during access reviews.
