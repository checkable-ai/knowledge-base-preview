## Answer

Covered. Tool-level granular control is rolling out and supports only specific MCP server types registered on Agent 365. Conditional Access covers only Entra-protected resources.

Source statement: "Tool-level granular control lets you allow or block individual tools within a supported MCP server registered on Agent 365 instead of blocking the entire server." (https://learn.microsoft.com/en-us/microsoft-agent-365/admin/manage-plugins-skills-mcp-servers)

Research detail: Agents get inheritable permissions from the blueprint plus direct assignments, and declared permissions need admin consent. Access packages assign groups, OAuth permissions and Entra roles with expiry, Conditional Access gates token issuance, and admins can allow or block individual MCP tools enforced at runtime by the tooling gateway.

<!-- chunk: products -->
## Products

Entra Agent ID, entitlement management, Conditional Access, Agent 365 tooling gateway, SharePoint restricted access control

<!-- chunk: gaps -->
## Gaps

Conditional Access only covers Entra-protected resources, so agents using API keys bypass it. Tool-level control is still rolling out and does not yet cover BYO MCP servers.

<!-- chunk: options -->
## Options

Assign least-privilege permissions per agent identity through access packages and disable write tools by default in the Tools registry.
