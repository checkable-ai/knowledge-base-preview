## Answer

Not covered. The objection is right. The page confirms Defender blocks matching threat detections before tools run, and custom rules can be scoped to agents. That is threat-specific blocking, not a gateway enforcing allowed tools, input formats, limits and internet access together. Nothing on the page documents input-format validation, usage limits or internet egress control. Coverage also depends on Work IQ MCP integration, and Copilot Studio and Foundry are in preview. My earlier covered verdict overstated what the vendor documents.

Research detail: The Agent 365 Tooling Gateway routes MCP calls, enforces server-level and tool-level block or allow at runtime, and requires admin approval and Entra consent for registered servers. Defender real-time protection evaluates tool invocations through Work IQ MCP before they run and blocks detections such as secret exfiltration. Copilot Studio agent traffic can be forwarded to Global Secure Access for web content and threat filtering.

## Products

Agent 365 Tooling Gateway, Tools registry, Defender real-time protection, Secure Web and AI Gateway

<!-- chunk: gaps -->
## Gaps

No documented per-agent quota or rate limits. Real-time protection only covers tools integrated with Work IQ MCP, Copilot Studio and Foundry. Tool-level control and BYO MCP are preview or rolling out.

<!-- chunk: options -->
## Options

Route all MCP servers through the tooling gateway or a connected APIM gateway, set Defender custom rules to block, and add rate limits in APIM.
