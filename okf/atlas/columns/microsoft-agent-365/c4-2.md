## Answer

Not covered. Credentials sit on the shared blueprint, not per agent. Rotation and expiry are standard Entra app settings, not agent-specific. Nothing documents keeping secrets from the model. Managed identity federation (Azure only) is the nearby feature but falls short.

Research detail: Credentials sit on the agent identity blueprint, not the agent identity, and can be federated identity credentials, certificates or client secrets. Agents on Azure can federate the blueprint to a managed identity so no secret is stored. The Agent 365 tooling gateway acquires tokens for MCP servers from scopes in the tooling manifest.

<!-- chunk: products -->
## Products

Entra agent identity blueprints, Agent 365 tooling gateway, ID Protection for agents

<!-- chunk: gaps -->
## Gaps

Blueprint credentials are shared by every agent identity from that blueprint. Rotation and expiry for secrets are standard Entra app settings, not agent-specific. BYO MCP servers can use API keys and client secrets supplied at registration.

<!-- chunk: options -->
## Options

Use managed identity federation, one blueprint per credential boundary, and the suspicious credential usage detection in ID Protection.
