## Answer

Not covered. No hardening or scanning of containers, agent software or hosts. Defender runtime protection detects attacks but does not harden hosts.

Research detail: Defender for Endpoint inspects local agent prompts and tool calls in audit or block mode, protected by tamper protection. For cloud agents, real-time protection audits by default and custom rules block detected actions before they run.

<!-- chunk: products -->
## Products

Defender for Endpoint AI agent runtime protection, Defender real-time protection

<!-- chunk: gaps -->
## Gaps

No assurance of inference or tool containers or host hardening. Coverage is limited to listed agents and platforms, and network inspection does not support certificate pinning or HTTP/3.

<!-- chunk: options -->
## Options

Start in audit mode, then move to block for high-confidence detections.
