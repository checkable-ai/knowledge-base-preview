## Answer

Not covered. No model version, endpoint, region or limit controls. Telemetry records model and token counts only.

Research detail: Agent 365 does not run models. It records inference spans, model and token counts through the Microsoft OpenTelemetry Distro, but model version, endpoint and limits are set in the agent platform.
