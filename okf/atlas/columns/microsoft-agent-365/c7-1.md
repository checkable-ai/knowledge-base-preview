## Answer

Not covered. Purview Audit records agent interactions and admin actions in the unified audit log with configurable retention, but Microsoft does not document that log as write-once or integrity-validated, nor a documented export of the agent action record to immutable storage. Retention settings are not tamper-evidence.

Research detail: Purview Audit records prompts and responses for agent-to-human, human-to-agent, agent-to-tools and agent-to-agent interactions in the unified audit log, and is enabled automatically for agent instances. Entra sign-in logs record the credential source, acting identity and token subject. Agent soft-delete and restore events are audited.
