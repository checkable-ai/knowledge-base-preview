## Answer

Covered. AI Administrators cannot configure Conditional Access or access package policies, which need a higher role.

Source statement: "When a user requests activation so they can create instances of an agent, the request requires AI admin approval before the requester can create instances." (https://learn.microsoft.com/en-us/microsoft-agent-365/admin/agent-actions)

Research detail: Agents are created from IT-approved blueprints, and activation requests need AI admin approval with a default or custom security template. Access packages expire unless a sponsor requests extension, lifecycle workflows handle sponsor changes, and admins can block, soft delete, restore or permanently delete agents.

<!-- chunk: products -->
## Products

Microsoft 365 admin center agent activation, Entra ID Governance access packages and lifecycle workflows, Agent 365 CLI

<!-- chunk: gaps -->
## Gaps

AI Administrators cannot configure Conditional Access or access package policies, so a higher role is needed. Owner reassignment only applies to Agent Builder and Copilot Studio agents.

<!-- chunk: options -->
## Options

Use access packages with end dates for all agent access and require activation through the request workflow.
