## Answer

Not covered. Agent 365 does not define the host, code interpreter or network sandbox; agent code runs on the customer's chosen platform.

Research detail: Agent 365 works with agent code hosted on any cloud and does not provide the host, interpreter or network sandbox. The CLI can deploy agent code to Azure and admins can start or stop Foundry agent infrastructure from the admin center.
