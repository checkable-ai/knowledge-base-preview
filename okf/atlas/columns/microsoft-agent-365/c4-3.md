## Answer

Covered. OBO mode uses delegated permissions. Conditional Access in OBO targets the user, not the agent identity. Agentic-User mode needs the Frontier preview programme.

Source statement: "It uses delegated permissions; the user is the token subject and the agent identity is the actor." (https://learn.microsoft.com/en-us/microsoft-agent-365/developer/identity)

Research detail: Agent 365 supports an on-behalf-of execution mode in which the signed-in user is the token subject and the agent identity is the actor, using delegated permissions. Conditional Access evaluates the OBO token exchange, and sign-in and audit logs separate the subject from the acting agent.
