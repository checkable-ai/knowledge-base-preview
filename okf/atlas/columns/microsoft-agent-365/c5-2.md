## Answer

Covered. ID Protection for agents needs an Agent 365 licence. Detections are security anomalies on autonomous agent activity, with no task-quality validation.

Source statement: "Once an agent exhibits suspicious behavior, ID Protection flags the activity as risky." (https://learn.microsoft.com/en-us/entra/id-protection/concept-risky-agents)

Research detail: ID Protection flags anomalous agent behaviour such as sign-in spikes and unfamiliar resource access, with a learning mode for new agents. Defender detects jailbreak, indirect prompt injection and LLM reconnaissance from Agent 365 telemetry, and Insider Risk Management scores risky AI usage.
