## Answer

Covered. Activation requests are reviewed in the Microsoft 365 admin center by an AI admin, with approve or reject, optional audience scoping and policy templates. Requires Agent 365 and appropriate admin roles. Some template policies (such as Defender real-time protection) are in preview.

Source statement: "When a user requests activation so they can create instances of an agent, the request requires AI admin approval before the requester can create instances." (https://learn.microsoft.com/en-us/microsoft-agent-365/admin/agent-actions)

Research detail: Agent activation requests go to AI admins, who review description, owner, data and tools before approving and applying a template. Requested agents can be published to the store or rejected. MCP server registrations and plugin access requests also go through approve or reject.
