## Answer

Not covered. No SBOM or vulnerability scanning of MCP servers, CLI tools or extensions. Admin approval of BYO MCP tools is gating, not scanning.

Research detail: BYO MCP servers need admin approval and consent before use, and admins see a snapshot of declared tools. The CLI command a365 develop-mcp evaluate scores tool names, descriptions and schemas. Defender monitors gateway tool invocations, and Defender for Endpoint discovers MCP server configurations on devices.
