## Answer

Not covered. No declared scope of permitted file, command or tool actions on the agent's host. Defender endpoint runtime protection detects and blocks harmful actions but does not set permissions.

Research detail: Defender for Endpoint runtime protection inspects prompts, pre-tool calls and tool responses of local agents such as Claude Code, Codex CLI and GitHub Copilot CLI and can block supported actions. Conditional Access has an agent execution environments condition for Windows 365 Cloud PCs for agents, and Researcher computer use has a website allow list.

<!-- chunk: products -->
## Products

Defender for Endpoint AI agent runtime protection (preview), Conditional Access, Computer use tab

<!-- chunk: gaps -->
## Gaps

This is threat detection on a short list of local agents, not a declared scope of permitted host actions. File system and command permissions are left to the agent itself.

<!-- chunk: options -->
## Options

Combine endpoint runtime protection in block mode with the local agent's own permission settings and test on a demonstration device.
