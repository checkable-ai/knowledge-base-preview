## Answer

Covered. Platform sync is manual. Discovery is limited to listed platforms and endpoints running Defender.

Source statement: "After you create a connection, Agent 365 can discover supported agents and add them to the Microsoft 365 agent registry." (https://learn.microsoft.com/en-us/microsoft-agent-365/admin/connected-platforms)

Research detail: The registry counts unmanaged agents created outside Agent 365. Connected platforms sync agents from Amazon Bedrock, Google Vertex AI, Salesforce Agentforce, Databricks, Anthropic Claude Managed Agents, Oracle and Snowflake. Defender adds local AI agents and MCP server configurations found on endpoints.
