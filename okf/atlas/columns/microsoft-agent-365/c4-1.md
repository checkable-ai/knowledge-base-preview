## Answer

Covered. Entra agent identity applies to agents registered through the Agent 365 SDK, Foundry and Copilot Studio. Agents from connected third-party platforms appear in the registry but may lack an Entra agent identity. Release linkage is registry metadata, not a build binding.

Source statement: "Agent 365 uses Microsoft Entra Agent ID to represent each agent with a distinct agent identity." (https://learn.microsoft.com/en-us/microsoft-agent-365/developer/identity)

Research detail: Each agent gets a Microsoft Entra agent identity, a service principal of type agentIdentity created from an agent identity blueprint, with its own object ID and at least one required sponsor. The registry records publisher, platform, version and owner for each agent, so the identity links to an accountable human and a release.

## Gaps

Release linkage is a registry metadata field, not a cryptographic binding to a build. Agents from connected third-party platforms appear in the registry but may not have an Entra agent identity.

<!-- chunk: options -->
## Options

Require every production agent to have an Entra agent identity and sponsor, and check registry version against deployment records.
