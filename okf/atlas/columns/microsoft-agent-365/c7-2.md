## Answer

Covered. Threat detection is in preview. Agents on other platforms need the Agent 365 SDK to send telemetry. Unpublished Foundry agents are not supported.

Source statement: "Microsoft Defender correlates AI agent alerts into incidents and surfaces the related context so security teams can quickly assess impact and prioritize response." (https://learn.microsoft.com/en-us/defender-xdr/security-for-ai/ai-agent-detection-protection)

Research detail: Defender correlates agent alerts into incidents and exposes Agent 365 observability data in Advanced Hunting tables such as CloudAppEvents, AgentsInfo and BehaviorInfo. Prompt evidence in alerts includes only suspicious snippets with sensitive data and secrets redacted. Agent risk data can be exported to a SIEM.
