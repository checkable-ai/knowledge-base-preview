## Answer

Partly covered. For each agent, the Configure tab lists the systems it can reach: Zoom tools, third-party tools such as Jira, Confluence and Google Drive, and knowledge sources. The agent's tool permissions settings show each tool individually as Needs approval, Always allow or Blocked. Together these give a readable view of which downstream systems each agent can reach and what it can do there. The outcome is per agent and does not require a consolidated cross-agent map.

Source statement: "In the tools permissions' box, click the dropdown menu next to each tool and select one of the following options:" (https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0085693)

Last checked 16 November 2026. This platform is checked on demand, so this answer has not been rechecked since.

Research detail: Developers must list requested permissions for Marketplace apps so admins can see what data an app can access. AI Studio shows the tools and knowledge attached to each custom agent.
