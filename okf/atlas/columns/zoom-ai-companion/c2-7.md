## Answer

Not covered. No documented limits on agent filesystem, process or network egress across Zoom AI Companion agents, and no documented immediate revocation of an agent's or connector's access. Nearby features fall short: the ZoomMate Cloud Browser Operator runs in a sandbox for the cloud browser session only, and a user can pause ZoomMate within a task. Neither is an organisation-wide emergency stop or a general agent sandbox.

Research detail: ZoomMate runs code execution and file generation in a containerised, restricted Sandbox on Zoom's AWS infrastructure that is removed after a limited period. Administrators can disable and lock AI features at account, group and user level, and can unpublish or delete custom agents in AI Studio. No filesystem or egress policy, and no way to stop a running agent task, is documented.

## Gaps

Egress control and customer configuration of the Sandbox are not documented. Disabling a feature is a setting change, not a documented immediate stop of a running task or revocation of connector tokens.

## Options
