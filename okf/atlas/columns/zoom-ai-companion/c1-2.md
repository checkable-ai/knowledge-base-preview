## Answer

Not covered. Admins scope which content is indexed and which tools an agent has, but cannot limit what actions an agent may take in connected systems (no per-action or parameter scoping).

Research detail: Admins choose which tools each custom agent can use (built-in, custom, Marketplace and MCP tools) and set 'Who can use this' for each agent. Admins choose which repositories, spaces, folders or drives are indexed. Marketplace admins can pre-approve, require approval for, disable or remove apps.

<!-- chunk: products -->
## Products

AI Studio tool selection, ZoomMate account-level integrations, Marketplace Admin App Management

<!-- chunk: gaps -->
## Gaps

Scoping is per tool, not per action or parameter. Tools from a connected MCP server become available to users in the account once connected.

<!-- chunk: options -->
## Options

Connect only purpose-built MCP servers that expose limited tools, and require Marketplace pre-approval.
