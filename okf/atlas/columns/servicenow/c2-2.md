## Answer

Covered. Provider choice is global for AI Agent Studio, not per agent; rate limits per provider via Generative AI Controller.

Source statement: "Choose the large language model (LLM) service provider for Now Assist AI agents in AI Agent Studio." (https://www.servicenow.com/docs/r/intelligent-experiences/select-aia-llm-new.html)

Research detail: Administrators choose the provider for agentic AI (Now LLM Service, AWS Claude, Azure OpenAI or Google Gemini) and can set target model versions per instance or skill (Brazil). Zurich settings cover regional or global data routing and an overflow option that keeps traffic in ServiceNow datacentres, and Generative AI Controller sets hourly request limits per provider, capability, instance or user.
