## Answer

Not covered. The AI user is optional and agents default to the invoking user. No documented binding of an agent identity to a runtime or release version. AI Control Tower owner records and AI user fall short of the outcome.

Research detail: AI agents can run as a dedicated AI user, a User [sys_user] record with the AI user identity type and its own fixed roles (Zurich and Brazil). AI Control Tower registers agents as AI assets with lifecycle, risk and owner roles, and Build Agent registers generated agents there (Brazil). The default identity is the dynamic invoking user, so most agents have no distinct workload identity.
