## Answer

Not covered. No documented binding of approval to exact parameters or replay handling; Allow always covers later same-type actions.

Research detail: Each tool can be set to Supervised so the agent pauses for human approval before it runs, and unattended runs stall until someone responds (Brazil). Cowork holds actions for approval, hard gate actions always need a human decision, and TOTP can be required for sensitive action approvals (Brazil). Build Agent shows the script, intent and target scope before each background script run.
