## Answer

Covered. Long-term memory toggled by administrators and mapped to agents by category.

Source statement: "Make AI agents remember your preference or facts from previous interactions and use memories for more focused conversations." (https://www.servicenow.com/docs/r/intelligent-experiences/long-term-memory-aia-new.html)

Research detail: Long-term memory stores user facts and preferences, and optionally learning from past executions, as semantic memories scoped by user and category in the AI Agent Memories table (Brazil). Administrators toggle retention and map categories to agents individually.
