## Answer

Covered. Cowork sandbox rules set by administrators; Brazil. Local MCP servers run outside the sandbox.

Source statement: "Sandbox rules set the file system boundary and network access for the execution environment." (https://www.servicenow.com/docs/r/intelligent-experiences/environment-capability-controls.html)

Research detail: Cowork runs actions inside an isolated virtual environment with file system boundaries, protected credential paths, file type read, write or deny rules and a network allow list, set by administrators per user or group (Brazil). On the instance, ACLs, run-as identity and role masking bound what an agent can do, and Build Agent scripts run only in the target app scope (Brazil).
