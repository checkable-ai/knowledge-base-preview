## Answer

Not covered. No vendor statement for this control could be checked by code after four rounds of agent checks, so coverage is not claimed.

Research detail: ServiceNow Cowork runs actions inside an isolated virtual environment whose sandbox rules set the file system boundary, fixed protections for credential paths and system directories, filesystem deny rules and file type rules. Network rules block all outbound traffic except an allow list. Agent limits set a maximum turn count and check-ins, and a policy block stops the action with no further attempts. An AI specialist can be deactivated in AI Agent Studio so it no longer acts on records, and a Cowork policy capability override can turn off local MCP servers for users or groups.

## Products

Cowork sandbox rules and network rules, agent limits and safeguards, Deactivate in AI Agent Studio, Cowork capability overrides, Build Agent background script containment

## Gaps

No documented process policy, no documented way to stop a running Cowork task or agent execution immediately, and the deactivate page does not say what happens to executions in progress. AI Agent Studio script tools run on the instance without a documented sandbox.

<!-- chunk: options -->
## Options

Use deactivation and capability overrides as the stop path and test their effect on a run in progress. Keep the Cowork network allow list minimal and mark script tools Supervised.
