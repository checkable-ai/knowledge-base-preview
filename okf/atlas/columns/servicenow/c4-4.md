## Answer

Not covered. No documented per-agent exposure filter or per-caller authorisation beyond service account roles.

Research detail: AI Agent Studio supports the Agent2Agent protocol for external agents and exposes ServiceNow agents as secondary agents through an Agent Card endpoint (Brazil). Inbound calls authenticate with OAuth 2.0 or an API key tied to a service account and an A2A auth scope, attached to the AI Agent A2A API Access Policy. Outbound calls use Connection and Credential Alias records, and ACLs apply to external AI agents.
