## Answer

Not covered. MCP server ACL does not apply when an AI agent uses the server; external scope otherwise depends on the credential.

Research detail: Agents act on connected systems through tools the builder adds, with each tool's run-as identity and role masking applied (Brazil). MCP tools can be set to allow, block or supervised in the Assistant, MCP Server Console limits exposed tools and fields, and Cowork connector scopes limit actions on a service regardless of the credential (Brazil).

## Gaps
