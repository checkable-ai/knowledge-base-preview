## Answer

Covered. AI steward approval and block of unapproved MCP servers are off by default and must be enabled, including on upgraded instances.

Source statement: "Activating AI systems, all the AI skills and agents need approval by an AI steward before being deployed." (https://www.servicenow.com/docs/r/intelligent-experiences/ai-control-tower/explore-approvals.html)

Research detail: AI Control Tower can require AI steward approval before AI skills, agents and models deploy, and can block unapproved MCP servers in AI Agent Studio, though these controls are off by default (Brazil). AI users are created as User records, ACLs and role masks are set in guided setup, and new instances from the Australia release deny agents lacking explicit ACLs. Agents can be deactivated, and AI Control Tower flags dormant agents holding permissions.

## Products

AI Control Tower approvals, AI Agent Studio guided setup, deactivation
