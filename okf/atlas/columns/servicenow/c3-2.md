## Answer

Not covered. MCP only; no per-agent tool policy; MCP rate limits not configurable.

Research detail: AI Gateway mediates MCP traffic with global and per-server pause, OAuth 2.1 client registration, a data sensitivity policy, and tool scanning against OWASP MCP Top 10 categories with auto-deactivation of vulnerable tools (Brazil). Cowork blocks outbound traffic except to an allow list, and MCP tools can be allowed, blocked or supervised.
