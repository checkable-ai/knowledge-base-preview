## Answer

Covered. Covers keys, members and workspaces via Management API and SCIM, not agent configurations.

Source statement: "Every change made through SCIM mappings is recorded." (https://openrouter.ai/docs/guides/features/scim-mappings.md)

Research detail: Management API keys list, create, get, update and delete keys. Workspaces and guardrails are assigned to members and keys. SCIM syncs users and groups from an IdP and deactivation removes the user's keys. Private endpoints can be managed with Terraform.
