## Answer

Not covered. No agent identity object tying an agent to an owner, runtime and release. Identity is the API key or workspace, with optional user and session tags.

Research detail: Every API key lives in one workspace and follows that workspace's settings. Requests can carry a user ID and session ID. Workload Identity Federation ties a workload's own JWT to a target API key.
