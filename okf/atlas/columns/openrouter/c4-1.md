## Answer

Not covered. No per-agent identity tied to an owner, runtime and release. Workload identity federation (Business and Enterprise plans) exchanges a workload JWT for access to an organisation API key and attributes usage to that key. It does not record an owner or release for an agent.

Last checked 13 November 2026.

Research detail: Every API key lives in one workspace and follows that workspace's settings. Requests can carry a user ID and session ID. Workload Identity Federation ties a workload's own JWT to a target API key.

## Products

## Gaps

There is no agent identity object with owner, runtime and release links. Identity is the key or workspace.

<!-- chunk: options -->
## Options

Use one key per agent and record owner and release in metadata.
