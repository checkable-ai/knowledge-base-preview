## Answer

Not covered. Broadcast forwards traces with user and session IDs and Privacy Mode, but there are no documented security detections beyond prompt injection flags and no named response owner or workflow. It only helps the customer build monitoring in their own SOC tooling.

Research detail: Broadcast sends per-request traces to more than 20 destinations including Datadog and a generic webhook. Traces can carry user and session IDs, filter by key, sample, and strip content with Privacy Mode. Prompt injection detections are logged.
