## Answer

Not covered. Workload Identity Federation identifies the calling workload and the user field only tags traces. Neither passes a person's identity or permissions to downstream systems.

Research detail: Workload Identity Federation passes a trusted issuer's JWT into an OpenRouter token bound to a key, with optional claim checks. Requests can carry an end user ID for tracing.
