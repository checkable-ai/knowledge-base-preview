## Answer

Covered. Agent SDK callModel only. Approval logic and approver identity are implemented in the customer's application.

Source statement: "passing `approveToolCalls` and/or `rejectToolCalls` arrays of tool call IDs" (https://openrouter.ai/docs/agent-sdk/call-model/tool-approval-state.md)

Research detail: In the Agent SDK a tool can set requireApproval, as a flag or a function of its arguments. Pending calls pause the run, and approveToolCalls or rejectToolCalls arrays carry decisions by tool call ID. A rejected call returns an error to the model.
