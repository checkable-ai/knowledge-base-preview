## Answer

Covered. Served version depends on upstream provider. EU and US regions only. Fallbacks can change the answering model.

Source statement: "It is automatically updated when there are changes to a provider's data policy." (https://openrouter.ai/docs/guides/features/zdr.md)

Research detail: Requests name a model slug and can set provider routing, ZDR, data collection deny and an ordered fallback list. Regional base URLs route to EU or US endpoints only. Private endpoints add a customer deployment of a catalog model. Key credit limits set operating limits.
