## Answer

Covered, with conditions. ZDR enforcement covers inference provider routing only; plugins and tools such as web search may have their own retention policies. Data-region guardrails require a Business or Enterprise plan. Enforcing Anthropic ZDR excludes first-party Anthropic endpoints while retaining Bedrock and Vertex routes.

Source statement: "The request-level zdr parameter operates as an "OR" with your account-wide and guardrail ZDR settings." (https://openrouter.ai/docs/guides/features/zdr)

Last checked 13 November 2026. This platform is checked on demand, so this answer has not been rechecked since.

Research detail: Requests name a model slug and can set provider routing, ZDR, data collection deny and an ordered fallback list. Regional base URLs route to EU or US endpoints only. Private endpoints add a customer deployment of a catalog model. Key credit limits set operating limits.
