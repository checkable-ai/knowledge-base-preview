## Answer

Covered, with conditions. A guardrail enforces nothing until it is assigned to a member, an API key or the workspace default. Data-region guardrails require a Business or Enterprise plan. Prompt injection and jailbreak screening is regex-based. Guardrails and per-key settings cap spend in USD, but they cannot set request-rate limits per key or member. OpenRouter governs request rate limits globally, per account and per model.

Source statement: "Guardrails let organizations control how their members and API keys can use OpenRouter." (https://openrouter.ai/docs/guides/features/guardrails)

Last checked 13 November 2026.

Research detail: Guardrails assigned to members, keys or workspaces enforce USD budgets that reset daily, weekly or monthly, model and provider allowlists, ZDR per model group, allowed data regions, regex content filters, prompt injection detection and sensitive information redaction or blocking. Workspace guardrails can only tighten account policy.
