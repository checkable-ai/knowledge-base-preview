## Answer

Not covered. No emergency stop for a running agent. Hosted containers (beta) isolate files and default to no outbound access, but the page describes no stop or kill control, and the limits do not apply to the agent's own host.

Last checked 13 November 2026. This platform is checked on demand, so this answer has not been rechecked since.

Research detail: Keys can be disabled or deleted and key state is checked on every request, so access can be cut at once. Per-key and per-workspace spend limits cap damage.

## Gaps

No sandbox or egress control for agent code. Issued federation tokens last up to 15 minutes. No stop control for a running agent.
