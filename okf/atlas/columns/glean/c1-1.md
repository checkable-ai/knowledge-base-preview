## Answer

Not covered. No customer-configurable policy for actions on the agent's machine. The hosted Agent Sandbox has fixed limits only and Glean runs no local harness.

Research detail: Glean's local execution surface is its hosted Agent Sandbox. Processes run as non-root with CPU and memory limits, the file system is session scoped, and Programmatic Tool Calling exposes only an allowlist of read-only tools with a per-session call cap.

<!-- chunk: products -->
## Products

Glean Agent Sandbox and Programmatic Tool Calling

<!-- chunk: gaps -->
## Gaps

No customer-configurable policy for actions inside the sandbox is documented. Glean does not run a local harness on user endpoints, so host-level scopes on user machines sit outside the product.

<!-- chunk: options -->
## Options

Treat the sandbox as Glean managed and control endpoint coding hosts with their own tooling.
