## Answer

Covered. Write confirmation in the web app. Automated agents can run without review.

Source statement: "Only tools you explicitly approve are executed." (https://docs.glean.com/tools/human-in-the-loop-experience-for-tools)

Research detail: Users review planned writes in an editable preview before they run. Flagged AI security events go to a findings dashboard showing the prompt, response and tool response for admin review. Users can vote on agent output.
