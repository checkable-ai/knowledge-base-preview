## Answer

Partly covered. Changes to agent permissions, sharing settings and publishing options are not versioned. There is no documented approval, versioning or rollback for models, knowledge or tool permissions.

Source statement: "Only changes to the core agent workflow are versioned." (https://docs.glean.com/agents/concepts/agents-draft-version)

Last checked 17 November 2026.

Research detail: Agents have published versions, version history, restore and moderator approval. Model deprecations switch agents to a fallback.

<!-- chunk: products -->
## Products

Agent versioning, moderator approval

<!-- chunk: gaps -->
## Gaps

No versioning for tool permissions or policies.

<!-- chunk: options -->
## Options

Track tool and policy changes in audit logs.
