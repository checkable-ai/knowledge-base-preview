## Answer

Covered. Revocation and disablement propagate in about 5 to 10 minutes. Kill switch is for independent agents.

Source statement: "Pause or unpublish the agent using agent management controls." (https://docs.glean.com/administration/managing-agents/independent-agents)

Research detail: Code in Data Analysis and the agent sandbox runs in a per-session sandbox with no outbound internet by default, allowlisted egress where needed, a session-scoped filesystem wiped at session end and enforced CPU and memory limits. Independent agents have a documented kill switch, where an admin pauses or unpublishes the agent, and credentials can be removed from the agent or revoked in the connected system. MCP servers and clients can be disabled or revoked, taking effect after a propagation window of about 5 to 10 minutes.

<!-- chunk: products -->
## Products

Agent sandbox, Data Analysis sandbox, independent agent pause and unpublish, MCP server disable and client revocation, tool call cap

<!-- chunk: gaps -->
## Gaps

The sandbox technology is not named and no execution timeout or stop control is documented for the sandbox. Users cannot cancel a run according to the execution limits page, which describes only a 30 minute cap on scheduled runs. Revocation is not immediate, and the independent agent page does not say whether active runs stop at once.

<!-- chunk: options -->
## Options

Time a pause, unpublish and MCP revocation against a running agent, and ask Glean for the sandbox isolation specification.
