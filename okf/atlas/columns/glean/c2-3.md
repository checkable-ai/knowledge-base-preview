## Answer

Covered, with conditions. Egress is limited to pre-approved domains set by Glean, not customer controlled. For eligible customers, Glean enables the sandbox for Glean in Thinking mode. Only models that support the shell tool work with the sandbox. The sandbox runs on infrastructure Glean operates for the customer environment. Prisma AIRS integration is an optional Palo Alto Networks add-on.

Source statement: "Processes run with non-root permissions and cannot escalate privileges." (https://docs.glean.com/security/agent-sandbox-ptc)

Last checked 17 November 2026.

Research detail: The Agent Sandbox serves one customer environment and one session, cannot reach other sandboxes, and is ephemeral. Outbound internet is off by default with an allowlist of approved domains, ingress is limited to authenticated internal systems, and the sandbox has no IAM credentials or secrets.
