## Answer

Covered, with conditions. Programmatic tool calling only runs inside an active Agent Sandbox session. Models that omit the shell tool do not support Agent Sandbox or PTC. By default only allowlisted read-only native tools are exposed. The runtime is managed by Glean. Agent Sandbox and PTC are enabled together for eligible customers using Glean in Thinking mode.

Source statement: "Tool calls are mediated by the host agent - no credentials cross the sandbox boundary." (https://docs.glean.com/security/agent-sandbox-ptc)

Last checked 17 November 2026.

Research detail: Glean's hosted agent runtime executes tools for Assistant and agents. In Programmatic Tool Calling the host agent mediates all tool calls from the sandbox, and tools run with the user's or the service credential's permissions.
