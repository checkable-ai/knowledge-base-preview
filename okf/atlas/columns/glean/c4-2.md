## Answer

Not covered. Credentials are scoped, revocable and kept out of the LLM context, but no general short-lived or automatically rotated credentials are documented. Short-lived tokens appear only for some integrations. Agent identity is beta.

Research detail: Admins register service credentials, which are stored encrypted and not shown again. The agent runtime never receives the raw secret, it never enters the LLM context or sandbox, and Glean adds the auth header only to requests for the app's approved domain. Credentials can be revoked per system. MCP OAuth tokens have admin-configurable lifetimes.

<!-- chunk: products -->
## Products

Agent identity service credentials, Glean OAuth for MCP, A2A host token storage

<!-- chunk: gaps -->
## Gaps

Rotation is a manual process (issue new credential in the app, update Glean, revoke old). No documented automatic expiry for service credentials. Agent identity is part of the beta independent agents feature.

<!-- chunk: options -->
## Options

Rotate service credentials on a schedule in the source app and test that revocation cuts agent access promptly.
