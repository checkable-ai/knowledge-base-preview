## Answer

Not covered. No scanning of public registries for look-alike names, poisoned tool descriptions or compromised packages. Skill scanning covers only Skills uploaded locally or imported from a third-party repository, checking prompt injection, malicious code, harmful content and bundle structure. It does not cover other tools or plugins.

Last checked 17 November 2026.

Research detail: External MCP servers are proxied through Glean with admin enablement per tool. Protect+ detects prompt injection in tool outputs.
