## Answer

Covered. Admins can turn off learned memories but not saved memories.

Source statement: "Glean stores memory data at the individual user level and does not share memory data across users." (https://docs.glean.com/administration/assistant/configuration/memory-personalization)

Research detail: Glean memory stores saved memories and learned memories per user, not shared across users, holding facts rather than document content. Users can view, edit and delete memories, and admins can turn off learned memories. Chat and agent run history is kept for an admin-set period.

<!-- chunk: products -->
## Products

Glean memory and personalization, chat history

<!-- chunk: gaps -->
## Gaps

Admins cannot turn off saved memories. Learned memories fade gradually rather than on a fixed schedule.

<!-- chunk: options -->
## Options

Disable learned memories where policy requires and set a chat history period.
