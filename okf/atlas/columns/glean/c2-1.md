## Answer

Not covered. No documented step-level retry, cancellation or recovery for agent runs. The nearest features are conditional branching with a fallback branch and sub-agent handoff that returns outputs to the parent. They cover ordering and handoff only. Cancellation is documented only for A2A tasks.

Last checked 17 November 2026.

Research detail: The agent builder supports workflow and auto mode agents, sub-agents with separate memory, external A2A sub-agents and schedule or event triggers. Scheduled runs have a limit of about 30 minutes and a hard cap on tool calls per run.

## Products

Glean Agent Builder, sub-agents, A2A host

## Gaps

Retry, cancellation and recovery behaviour are not documented beyond A2A tasks/cancel. Oversized chat sessions cannot be resumed.

<!-- chunk: options -->
## Options

Design long jobs as separate scheduled agents and monitor failed runs in Agents insights.
