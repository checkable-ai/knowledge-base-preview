## Answer

Not covered. No public Glean documentation describes a record of agent actions (tool calls, data access, changes) kept in write-once or integrity-validated storage, or a documented export of that record to such storage. Admin audit logs and SIEM export of logs exist but are not documented as tamper-evident or as covering per-agent actions by user or session.

Research detail: Admin audit logs record configuration changes and are kept 30 days by default with CSV export. Glean Customer Event logs record chats, workflow runs, actions, MCP usage and LLM calls. Sandbox code is logged.

<!-- chunk: products -->
## Products

Admin audit logs, Glean Customer Event logs

<!-- chunk: gaps -->
## Gaps

Admin audit logs exclude end-user activity. Tamper evidence is not documented. Reasoning capture is not stated. Customer export is not on by default.

<!-- chunk: options -->
## Options

Arrange GCE log export to a write-once store.
