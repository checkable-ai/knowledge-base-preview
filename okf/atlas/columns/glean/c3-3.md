## Answer

Covered. Agent access policies and auto-hide need Protect+. Agent access policies are beta.

Source statement: "The Glean runtime evaluates applicable policies at two distinct phases of a tool invocation." (https://docs.glean.com/administration/protect/ai-security/agent-access-policies)

Research detail: Retrieval is permission aware and an agent cannot reach data the user cannot. Agent access policies (Protect+) can filter sensitive or labelled documents out of an agent's context. Sensitive findings scan indexed content and can auto-hide overshared items, and Purview labels can restrict indexing.

<!-- chunk: products -->
## Products

Permission-aware retrieval, agent access policies, Glean Protect sensitive findings and auto-hide

<!-- chunk: gaps -->
## Gaps

Continuous scanning, auto-hide and agent access policies need Protect+. Scanning covers only indexed content, not live federated fetches.

<!-- chunk: options -->
## Options

Run sensitivity scans before launch and enable auto-hide for high-severity findings.
