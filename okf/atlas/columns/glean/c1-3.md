## Answer

Covered. Web app. New execution and MCP write tools default to no confirmation and must be configured. Scheduled agents skip confirmations.

Source statement: "Only tools you explicitly approve are executed." (https://docs.glean.com/tools/human-in-the-loop-experience-for-tools)

Research detail: Write tools can require confirmation in the web app. The panel shows the target app, the record and a description of the action, supported tools open an editable preview, and Cancel stops the write. Only explicitly approved tools run. Agent Inbox can notify users of runs waiting for approval.

<!-- chunk: products -->
## Products

Write tool confirmation, Agent Inbox

<!-- chunk: gaps -->
## Gaps

New execution tools and MCP write tools default to running without confirmation, and destructive tools are not restricted automatically. Scheduled agents skip confirmations. Replay handling and binding of approval to exact parameters are not documented.

<!-- chunk: options -->
## Options

Set write tools to require confirmation by default and test approval with changed parameters.
