## Answer

Covered. Moderator approval is an admin setting. Independent agents are beta.

Source statement: "A version that's ready to publish doesn't go live until a moderator publishes it." (https://docs.glean.com/administration/managing-agents/review-and-publish-agents)

Research detail: Admins control who can create and publish agents through roles (Agent Creator, Agent Moderator, Departmental Agent Moderator). An approval setting can require moderator review before changes publish. Admins and moderators can disable agents, owners can transfer ownership, and admins register service credentials and set who can attach them.

<!-- chunk: products -->
## Products

Agent roles and sharing settings, moderator approval, agent disable, agent identity credential registration

<!-- chunk: gaps -->
## Gaps

Retirement is guidance plus disable or delete, with no documented retirement workflow. Independent agents and agent identity are beta.

<!-- chunk: options -->
## Options

Limit publishing to moderators and require approval for company-wide agents.
