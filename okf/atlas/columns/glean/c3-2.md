## Answer

Covered, with conditions. Glean Protect+ policies are needed to block prompt injection, malicious code and misaligned behaviour on external MCP tool calls. Agent access policies are in beta. By default all gateway tools are on for all users. Glean Protect+ is a separately licensed add-on required for its AI security guardrails.

Source statement: "One MCP endpoint exposes thousands of tools across native, connector, and custom tools to external AI hosts." (https://docs.glean.com/administration/platform/mcp/mcp-gateway)

Last checked 17 November 2026.

Research detail: The MCP Gateway proxies external MCP servers and custom tools through one Glean endpoint with per-tool access. Protect+ adds agent access policies that check tool calls and outputs, prompt injection detection in tool outputs, an agent alignment check for write tools and untrusted URL redaction. Sandbox egress is allowlisted.

## Products

Glean MCP Gateway, agent access policies, AI security policies, untrusted URL monitoring

## Gaps

Rate limits are not documented. Gateway tools are enabled for all users by default. Most filtering needs Protect+ and agent access policies and alignment checks are beta.
