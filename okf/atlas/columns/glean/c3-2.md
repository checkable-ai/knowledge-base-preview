## Answer

Covered. Runtime filtering needs Protect+ and agent access policies are beta. Gateway tools are on for all users by default.

Source statement: "The Glean MCP Gateway brings tools from outside Glean's own platform into your Glean MCP servers." (https://docs.glean.com/administration/platform/mcp/mcp-gateway)

Research detail: The MCP Gateway proxies external MCP servers and custom tools through one Glean endpoint with per-tool access. Protect+ adds agent access policies that check tool calls and outputs, prompt injection detection in tool outputs, an agent alignment check for write tools and untrusted URL redaction. Sandbox egress is allowlisted.

## Products

Glean MCP Gateway, agent access policies, AI security policies, untrusted URL monitoring

## Gaps
