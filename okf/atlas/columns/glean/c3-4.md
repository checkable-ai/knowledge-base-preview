## Answer

Not covered. No policy for approved agent pairs, format enforcement or A2A-specific logging. Admin registration of A2A servers falls short.

Research detail: External A2A agents must be registered by an admin and added as sub-agents by a builder. Exposed Glean agents check each caller's permission and return not found to unpermitted callers.
