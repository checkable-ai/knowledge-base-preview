## Answer

Covered.

Source statement: "You can view agents discovered in the last 30 days as well as those marked as unsanctioned or missing an owner." (https://documentation.sailpoint.com/saas/help/agentic_fabric/nhi/agent_registry.html)

Research detail: Each agent has a primary owner and up to 10 additional owners. If the primary owner becomes inactive, ownership passes to the first active additional owner, then to the owner's manager. MCP servers, credentials and non-human accounts also carry owners, and filters show agents with no owner.

<!-- chunk: products -->
## Products

Agent Identity Security, Agent Registry, Credentials, MCP Servers

<!-- chunk: gaps -->
## Gaps

An agent can end up with no owner when the owner has no manager. Ownership of individual decisions is not tracked.

<!-- chunk: options -->
## Options

Set additional owners for every agent and review the missing-owner filter regularly.
