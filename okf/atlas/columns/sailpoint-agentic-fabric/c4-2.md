## Answer

Not covered. Credentials page is an inventory only; no documented rotation, vaulting or brokered delivery keeping secrets from the model. JIT entitlements fall short of scoped agent credentials.

Research detail: The Credentials page inventories IAM access keys, PATs, client secrets, SAML certificates, service account keys and API keys with owner and status (Active, Expired, Inactive). Just-In-Time entitlements provision access only for an activation period on direct-connect sources, and non-human accounts can be disabled. Secret rotation appears only in product page claims.
