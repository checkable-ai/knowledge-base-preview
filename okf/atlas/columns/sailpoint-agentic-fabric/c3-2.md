## Answer

Covered. Applies to tool calls through the MCP or agent gateway. Gateway Access policies must be created and enabled, as new ones are saved disabled. Input format checks, rate limits and internet access control are not documented.

Source statement: "Access requests are automatically denied unless you create policies that allow them." (https://documentation.sailpoint.com/saas/help/policy_center/gateway_access.html)

Research detail: The Protect product page claims JIT MCP access, continuous authorisation per agent request and blocking of malicious CLI commands. Admin documentation describes MCP server discovery only, states that business app sanction statuses are not enforced, and gives the endpoint agent no blocking role.
