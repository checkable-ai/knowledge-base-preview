## Answer

Covered, with conditions. Needs an Agentic Fabric tenant with Endpoint Agent Security enabled. Endpoint agent supports macOS Tahoe 26 or later and Windows 11, deployed via Jamf Pro or Microsoft Intune. Needs a SAF Admin role to generate deployment artifacts. Discovery covers managed laptops and desktops. Browser and cloud sensors also contribute. Standalone packages are sold by NHI quantity tier.

Source statement: "You can configure SailPoint Endpoint Agent Security to discover AI agent software" (https://documentation.sailpoint.com/saas/help/agentic_fabric/onboarding/sensors/endpoint_sensor.html)

Last checked 16 November 2026.

Research detail: Endpoint agents on macOS and Windows discover installed AI agent software, MCP clients and credentials. A browser extension detects sign-ins to sanctioned and unsanctioned web apps and logs uploads and pastes. Cloud connectors (AWS Bedrock, Microsoft Entra) and EDR or SIEM feeds add agents, and business apps are classified Sanctioned, Unsanctioned or Unknown.

<!-- chunk: products -->
## Products

Endpoint Agent Security, Browser Agent Security, AWS and Entra connectors, Business Apps

<!-- chunk: gaps -->
## Gaps

Sanction status is not enforced. The endpoint agent needs macOS 26 or Windows 11. The extension captures personal activity, which raises notice and consent duties.

<!-- chunk: options -->
## Options

Deploy sensors through MDM and check legal notice requirements before rollout.
