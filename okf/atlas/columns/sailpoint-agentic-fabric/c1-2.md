## Answer

Covered. Gateway Access policies apply to tool calls routed through the MCP or agent gateway.

Source statement: "Access requests are automatically denied unless you create policies that allow them." (https://documentation.sailpoint.com/saas/help/policy_center/gateway_access.html)

Research detail: Standard IGA controls apply to agent access in connected systems: entitlements on correlated non-human accounts show in the Access tab, access requests for machine identities are on by default, Just-In-Time entitlements limit standing access, and accounts can be disabled. Enforcement happens through provisioning on sources, not per action. Continuous runtime authorisation is claimed on the Protect page only.

<!-- chunk: products -->
## Products

Agent Registry Access tab, Access Requests for Machine Identities, Just-In-Time access

<!-- chunk: gaps -->
## Gaps

Scopes are coarse entitlements on machine accounts, which the docs warn may be shared by more than one agent. No per-action runtime check is documented.

<!-- chunk: options -->
## Options

Test whether entitlement changes reach the agent platform. Ask for documentation of the Protect continuous authorisation feature.
