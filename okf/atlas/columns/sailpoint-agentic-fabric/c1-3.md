## Answer

Not covered. Approval workflows cover agent activation, deactivation and access requests, not the exact tool call before it runs. Expiry and replay handling are not described.

Last checked 16 November 2026.

Research detail: Agent activation and deactivation requests can require single or multi-step approval by owners, managers, governance groups or named identities, with optional comments. One denial ends the request. Approvals cover lifecycle and access requests, not individual agent actions at runtime.
