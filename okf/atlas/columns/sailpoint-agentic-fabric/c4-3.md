## Answer

Not covered. Gateway Access policies match on the identity the call is made for, but no passing of the person's identity to downstream systems is documented, and calls are not limited to that person's own permissions there. Policies are written by admins.

Research detail: No documented propagation of the initiating user identity to downstream services. The SailPoint MCP server lets an agent raise access requests for a user, which is an IGA workflow and not delegated authority.
