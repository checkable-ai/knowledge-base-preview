## Answer

Not covered. The Agent Registry gives each agent a non-human identity record with owners, but no model, version, runtime or release fields are documented. It is a governance record, not an issued workload identity.

Research detail: The Agent Registry records each enterprise, endpoint or browser agent as a non-human identity with a unique native identity, type, business app, status, primary owner and additional owners. Agents link to correlated non-human accounts, MCP clients and credentials. No model, version, runtime build or release fields are documented.
