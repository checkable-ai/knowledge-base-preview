## Answer

Not covered. No documented file or network egress limits for code steps and no organisation-wide stop. Task-level cancel/pause and timeouts fall short.

Research detail: Python code steps run on a chosen Modal Labs or Daytona backend with a configurable timeout, a four hour hard limit and, on Modal, set RAM and GPUs. Users can cancel, complete or pause individual tasks, including tasks in progress, and cancel queued tasks in bulk. Admins can toggle integrations off for the organisation. The docs do not describe sandbox isolation, filesystem or network egress policy for code, and any package from PyPI can be installed.
