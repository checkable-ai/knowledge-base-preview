## Answer

Not covered. No short-lived scoped credentials, rotation, expiry or revocation. Encrypted secret storage and custom API keys fall short, and any builder in a project can use a custom key.

Research detail: Relevance stores API keys, certificates and service accounts encrypted. Custom API keys are referenced in code steps as secrets and redacted when printed. Org and project API keys can be set by admins.

<!-- chunk: products -->
## Products

Custom API keys, org and project API keys

<!-- chunk: gaps -->
## Gaps

Any builder in the project can use a custom API key. Rotation, expiry and revocation are left to the customer.

<!-- chunk: options -->
## Options

Use narrow-scope keys and limit builder membership on projects with sensitive keys.
