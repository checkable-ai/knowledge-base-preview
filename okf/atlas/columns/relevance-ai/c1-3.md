## Answer

Covered. Approval Required mode must be set on the action; Let Agent Decide leaves the choice to the model.

Source statement: "This mode forces the agent to seek explicit approval before executing an action." (https://relevanceai.com/docs/build/workforces/workforce-features/approvals-and-escalations)

Last checked 11 November 2026.

Research detail: Each tool or workforce edge can be set to Approval Required, where the agent drafts its intended action and waits. Reviewers approve, reject or give guidance in the task view, and unapproved tasks stay pending. Invent marks destructive actions as Always ask.
