## Answer

Covered. Enterprise only, rolling out. OAuth tools only, not API key tools, Python steps or embedded chat.

Source statement: "Actions taken by agents are attributed to individual user accounts in external integrations." (https://relevanceai.com/docs/enterprise/user-level-authentication)

Research detail: User Level Authentication makes each user connect their own OAuth account for a tool, so a shared agent only reaches that user's data and actions are attributed to the individual account. It also applies when a workforce delegates to an agent.
