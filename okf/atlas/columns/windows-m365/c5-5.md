## Answer

Covered, with conditions. The Data & tools tab is read-only and needs the AI Administrator or Global Administrator role. Microsoft 365 admin center does not yet have data and tools information for all agents, and the tab can be empty depending on agent type or metadata sync. Security tab details need a Microsoft E7 or Agent 365 license.
