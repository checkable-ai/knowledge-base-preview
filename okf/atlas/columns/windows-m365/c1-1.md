## Answer

Covered. Experimental Windows Insider preview of Copilot Actions; disabled by default and enabled by the user under Settings > System > AI components > Agent tools > Experimental agentic features.

Source statement: "An agent starts with limited permissions and only obtains access to resources you explicitly provide permission to, like your local files." (https://learn.microsoft.com/en-us/windows/security/book/operating-system-agentic-security)

Research detail: Source statement: Windows documents experimental agent accounts/workspaces. Windows 365 for Agents has a Cloud PC security baseline.

Assessment: Desktop experimental features and managed Cloud PCs have different boundaries.
