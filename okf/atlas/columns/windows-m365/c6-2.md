## Answer

Covered, with conditions. Applies to agents in the Agent Registry in the Microsoft 365 admin center, not to models or tools generally. Approval is by an AI administrator. Applying a template draws on Microsoft Entra, Microsoft Purview and SharePoint policies. AI Administrators cannot configure Conditional Access or Microsoft Entra access package policies. Basic registry and approval actions are included with Microsoft 365 Enterprise, Business, Education and Front Line Worker plans. MCP registration requests use a preview workflow and require administrator approval followed by Microsoft Entra consent.

Source statement: "When a user requests activation so they can create instances of an agent, the request requires AI admin approval before the requester can create instances." (https://learn.microsoft.com/en-us/microsoft-agent-365/admin/agent-actions)
