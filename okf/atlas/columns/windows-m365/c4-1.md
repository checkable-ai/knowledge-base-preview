## Answer

Covered. Agents created from May 2026 get Entra Agent IDs; older agents keep legacy app registrations until migrated, and some preexisting agents have no sponsor yet. GitHub Copilot harness agents get the ID on first publish.

Source statement: "Copilot Studio automatically provisions Entra Agent IDs for new agents." (https://learn.microsoft.com/en-us/microsoft-copilot-studio/govern-agents-identities-overview)

Research detail: Source statement: Studio uses agent identities. Windows documents distinct agent accounts.

Assessment: An identity alone does not define downstream resource access.
