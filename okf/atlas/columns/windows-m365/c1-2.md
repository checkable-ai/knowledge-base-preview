## Answer

Covered. Entra Agent ID connector scopes apply only to first-party and certified Power Platform connectors, not custom connectors, MCP servers or REST tools. Conditional Access on the agent identity is enforced only in Teams. Connector and data policies apply at runtime on all channels.

Source statement: "Only the operations the agent actually uses are permitted." (https://learn.microsoft.com/en-us/microsoft-copilot-studio/govern-agents-identities-overview)
