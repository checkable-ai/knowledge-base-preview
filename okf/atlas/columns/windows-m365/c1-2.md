## Answer

Covered. Entra Agent ID connector scopes apply only to first-party and certified Power Platform connectors. Custom connectors, MCP servers and REST API tools add no scopes. Conditional Access on the agent identity is enforced only when the agent runs in Microsoft Teams. Connector and data policies are revalidated at runtime. Connector scopes are added only to Entra Agent IDs, not legacy app registrations.

Source statement: "At runtime, the connector platform revalidates that the agent can call the connector under your tenant's advanced connector policies and data policies." (https://learn.microsoft.com/en-us/microsoft-copilot-studio/govern-agents-identities-overview)
