## Answer

Covered. Covers Power Platform connector-based tools. Conditional Access on the agent identity is enforced only in Teams. Custom connectors, MCP servers and REST tools add no Entra scopes. Direct desktop actions need separate controls.

Source statement: "If an attacker gets an agent's identity, the attacker can't use these scopes to call Microsoft Graph, Outlook, or any other API directly because the connector platform mediates every call and applies your governance policies." (https://learn.microsoft.com/en-us/microsoft-copilot-studio/govern-agents-identities-overview)
