## Answer

Covered, with conditions. Covers Power Platform connector-based tools. Advanced connector policies apply to certified connectors only, and block MCP servers at whole-server level, not per tool. Custom and HTTP connectors need classic data policies and endpoint filtering. Conditional Access on the agent identity is enforced only in Microsoft Teams. Custom connectors, MCP servers and REST API tools add no Entra scopes. Design-time enforcement for advanced connector policies is rolling out per maker portal.

Source statement: "If an attacker gets an agent's identity, the attacker can't use these scopes to call Microsoft Graph, Outlook, or any other API directly because the connector platform mediates every call and applies your governance policies." (https://learn.microsoft.com/en-us/microsoft-copilot-studio/govern-agents-identities-overview)
