## Answer

Covered, with conditions. Applies to Windows 365 for Agents Cloud PCs, exposed as an MCP tool within Microsoft Agent 365. Network filtering needs Global Secure Access (GSA) to be configured. Microsoft Defender for Endpoint sensor can be deployed on the Cloud PC as optional extra protection. Declarative-agent code interpreter is available to Microsoft 365 Copilot license holders and Copilot Chat users without metered usage enabled. Data residency follows the applicable Microsoft 365 or Power Platform regional commitments.

Source statement: "Cloud PCs are stateless and reset after every agent session, which ensures that no credentials persist and no trust carries across workloads." (https://learn.microsoft.com/en-us/windows-365/agents/security-overview)

Research detail: Source statement: Windows 365 provides a managed PC for agents. Windows documents an experimental workspace.

Assessment: Studio cloud execution differs from desktop execution.
