## Answer

Covered, with conditions. Applies to Windows 365 for Agents Cloud PCs. Limits rely on Microsoft Intune device policies and Global Secure Access network controls. Access can be cut with Microsoft Entra Conditional Access. Microsoft Defender for Endpoint and Microsoft Purview are optional extras. The time for a block to take effect is not stated.

Source statement: "Cloud PCs are stateless and reset after every agent session, which ensures that no credentials persist and no trust carries across workloads." (https://learn.microsoft.com/en-us/windows-365/agents/security-overview)

Last checked 15 November 2026.

Research detail: Admins can block an agent across the organisation in the Microsoft 365 admin center, which stops any user from using it, and can uninstall or delete it. Entra Agent ID can disable an agent identity, and Conditional Access can block agent token issuance. Power Platform data policies limit which connectors Copilot Studio agents can use, and Defender real-time protection (preview) detects and blocks suspicious agent activity at runtime.

## Products

Microsoft 365 admin center agent block, Microsoft Entra Agent ID, Power Platform data policies, Microsoft Defender for Agent 365

## Gaps
