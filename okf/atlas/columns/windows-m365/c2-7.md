## Answer

Covered. Applies to Windows 365 for Agents Cloud PCs. The time for a block to take effect is not stated.

Source statement: "Conditional Access policies can explicitly block agent identities from accessing resources." (https://learn.microsoft.com/en-us/windows-365/agents/security-overview)

Research detail: Admins can block an agent across the organisation in the Microsoft 365 admin center, which stops any user from using it, and can uninstall or delete it. Entra Agent ID can disable an agent identity, and Conditional Access can block agent token issuance. Power Platform data policies limit which connectors Copilot Studio agents can use, and Defender real-time protection (preview) detects and blocks suspicious agent activity at runtime.

## Products

Microsoft 365 admin center agent block, Microsoft Entra Agent ID, Power Platform data policies, Microsoft Defender for Agent 365
