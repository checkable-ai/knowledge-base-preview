## Answer

Covered, with conditions. Applies to agents that run on Windows 365 for Agents Cloud PCs, which are managed and monitored in the Microsoft Intune admin center. The Copilot Studio route, a Cloud PC pool for computer use runs, is in preview. CPU and RAM performance scores, spike percentages and baseline comparisons come from the Endpoint analytics Resource performance report. The Cloud PCs must be enrolled in Endpoint analytics.

Source statement: "You can review the CPU spike time and RAM spike time scores and percentages for each Cloud PC device in your organization." (https://learn.microsoft.com/en-us/windows-365/enterprise/report-resource-performance)

Last checked 15 November 2026.

Research detail: Source statement: Studio Monitor exposes health metrics. Cloud PCs support managed security settings.
