## Answer

Covered. Production-ready preview, GitHub Copilot harness only. Memory is disabled in group chats and Teams channels. Turning memory off does not delete stored memories. Memories are deleted after 28 days of user inactivity.

Source statement: "Each agent maintains a separate memory store for every user, so one person's context is never shared with another." (https://learn.microsoft.com/en-us/microsoft-copilot-studio/agents-experience/memory-overview)

Research detail: Source statement: Memory preview retains context for future interactions in the GitHub Copilot harness experience.

Assessment: This does not establish the same memory controls across all M365 products.
