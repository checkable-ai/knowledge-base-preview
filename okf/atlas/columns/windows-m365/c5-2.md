## Answer

Covered, with conditions. ID Protection for agents will require a Microsoft Agent 365 licence. It covers only agents that have Microsoft Entra Agent IDs. At this time all agent risk detections are offline. Risk detections are retained for up to 90 days. In on-behalf-of flows, risky activity is attributed to the user rather than the agent. Runtime security monitoring uses Microsoft Defender integrated with separately licensed Microsoft Agent 365 or Microsoft 365 E7/G7.

Source statement: "Once an agent exhibits suspicious behavior, ID Protection flags the activity as risky." (https://learn.microsoft.com/en-us/entra/id-protection/concept-risky-agents)
