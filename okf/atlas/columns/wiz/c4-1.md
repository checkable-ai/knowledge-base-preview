## Answer

Not covered. Wiz discovers agents and maps them to existing identities and workloads, but does not issue per-agent identities bound to an owner, location and release.

Research detail: Wiz does not issue agent identities. The AI-SPM Agent Inventory View and contextual correlation map each discovered agent to the cloud and application identities, workloads and data it uses, and the AI inventory groups components into Services with ownership. This is a discovered view of identity, not a managed identity bound to a release.
