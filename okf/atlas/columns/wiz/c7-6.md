## Answer

Not covered. No scanning of tools, plugins or skills from public registries for look-alike names or poisoned descriptions. The Sensor for Developer Workstations (Private Preview) alerts when a known-malicious package lands on a workstation, using the Wiz Reputation Database, and uses behavioural detection for emerging threats. That is install-time detection, not registry scanning of agent tools.

Research detail: Wiz scans files of hosted MCP servers and agents for malicious payloads and its runtime discovery flags remote MCP interactions and unknown MCP servers. No public page describes scanning MCP registries, skills or plugins for squatting or tool metadata poisoning.
