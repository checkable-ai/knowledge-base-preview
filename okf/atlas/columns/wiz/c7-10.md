## Answer

Not covered. Wiz does not document a feature for authorised automated attack testing of models, retrieval, tools and runtime. The nearest feature is the Red Agent (GA since 29 July 2026, part of Wiz Attack Surface Management, which earlier pages name as ASM Advanced). Wiz describes it as continuous AI pentesting of custom-built software, vibe-coded apps and APIs: an API crawler, an API DAST attacker and a check on the reach of exposed secrets. It probes endpoints exposed to the internet from outside. Wiz does not document any testing of the model itself, retrieval or RAG pipelines, or tool and agent runtime, and an AI chatbot exfiltration example is the only place the Red Agent touches these. The AI Security Agent (Public Preview, 16 Nov 2026) analyses code and configuration to find risk. It does not run attack tests. Adversarial testing aimed at AI endpoints comes through Pillar Security's RedGraph, a separate partner product.

Last checked 17 November 2026.

Research detail: Wiz finds publicly reachable AI endpoints and probes them as an outside attacker to test for prompt injection risk. The Red Agent runs continuous AI-driven external pentesting of applications and APIs, but its page does not name AI, retrieval or tool boundaries as targets. Scope and authorisation settings are not described publicly.
