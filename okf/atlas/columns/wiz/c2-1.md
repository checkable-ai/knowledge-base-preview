## Answer

Out of scope. Wiz is a cloud security platform, not a runtime that runs agent tasks. Wiz Workflows (in Public Preview) is described as 'a centralized control plane for operational security processes'. It chains triggers, approvals, notifications and remediation for Wiz's own security processes and Wiz agents. It is not a feature for ordering, handing off, cancelling, retrying and recovering the steps of a customer's agent task. The page also never mentions cancel, retry or recovery. The adversary's partial verdict would mean judging Wiz's internal security automation as if it were an agent orchestration runtime, which is not what this control asks about.

Last checked 15 November 2026.

Research detail: Wiz is not an agent orchestration runtime. Its own Blue, Green and Red agents and Wiz Workflows orchestrate security tasks inside Wiz, not customer agent workflows.
