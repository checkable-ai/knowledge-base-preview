## Answer

Covered. Runtime Sensor is an add-on to Wiz Defend; not deployable on managed SaaS model runtimes.

Source statement: "The sensor blocks sophisticated cloud and AI threats in real time" (https://www.wiz.io/solutions/runtime-sensor)

Research detail: The eBPF Runtime Sensor runs on VMs, containers and serverless containers hosting AI workloads, detects rogue agents and sensitive data exposure, blocks threats, terminates malicious processes and monitors file integrity and image drift. Agentless posture checks cover the cloud AI services and inference endpoints around them. The sensor is an add-on to Wiz Defend.
