## Answer

Not covered. No documented owner record for every agent, model and tool. Falcon Next-Gen Identity Security maps non-human identities (service accounts, API keys, OAuth tokens, cloud service principals) to human owners and flags unowned or orphaned ones. The blog lists AI agents separately from NHIs, and it does not extend owner records to agents, models or tools. The identity page only says the Agentic Identity Provider 'connects each agent to the humans and workloads behind it', which is attribution, not an accountable-owner record.

Last checked 14 November 2026.

Research detail: The Guardian release says inventory shows who deployed each agent, and the Agentic Identity Provider release ties every agent action to an accountable human or workload.
