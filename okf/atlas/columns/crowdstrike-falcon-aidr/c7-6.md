## Answer

Not covered. No scanning of public registries, packages or plugins for look-alike names or compromise. MCP Validation checks tool listings at runtime only.

Last checked 14 November 2026.

Research detail: The MCP proxy is documented to protect against tool poisoning from third-party MCP servers, and MCP Validation flags poisoned and conflicting tool names or descriptions at tool listing time.
