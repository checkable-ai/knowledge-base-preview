## Answer

Not covered. No sandbox or limits on agent files, processes or network access, and no documented way to stop a running agent or cut its access at once. Guard checkpoint blocking of individual requests and tool calls falls short.

Research detail: AIDR can block an agent action before it runs. The Claude Code collector uses PreToolUse, PostToolUse and UserPromptSubmit hooks and returns allow, block or transform, and the MCP proxy blocks maliciously crafted tools. Falcon Guardian, announced on 1 September 2026, adds agent access controls that block unauthorised agents on managed endpoints.

<!-- chunk: products -->
## Products

AIDR agentic collectors, Claude Code collector, MCP proxy, Falcon Guardian agent access controls

<!-- chunk: gaps -->
## Gaps

No sandbox, filesystem policy or general egress control for agent code. No documented way to stop a running agent or revoke its credentials. Log-only mode skips blocking. Guardian features are announced without availability dates.

<!-- chunk: options -->
## Options

Run agents in a sandboxed runtime and use AIDR hooks in block mode as a second layer. Test Guardian blocking once it is generally available.
