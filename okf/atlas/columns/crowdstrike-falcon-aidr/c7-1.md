## Answer

Not covered. No publicly documented write-once or integrity-validated storage of agent action records, and no documented export of such a record to tamper-evident storage. Nearby features (AIDR findings event logs, Falcon settings activity log, Next-Gen SIEM retention) are not documented as tamper-evident and do not capture each agent tool call, data access and change with agent and user or session attribution.

Research detail: Findings logs record prompt content, detections, user and application per event, and the Settings Activity log records configuration changes with user, action, old and new values.
