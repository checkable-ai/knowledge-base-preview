## Answer

Covered. Requires Falcon Next-Gen SIEM. Metadata-only events omit prompt and response content, so content-level investigation needs full logging. trace_id is per request.

Source statement: "AIDR event metadata includes detection results, model information, collector details, and timestamps without prompt content or sensitive entity values." (https://aidr-docs.crowdstrike.com/docs/aidr/visibility/next-gen-siem)

Research detail: AIDR writes events to Falcon Next-Gen SIEM with user, actor, collector, application, outcome, findings and trace_id fields. Metadata-only events omit prompt and response content. Dashboard templates map findings to MITRE ATLAS indicators.
