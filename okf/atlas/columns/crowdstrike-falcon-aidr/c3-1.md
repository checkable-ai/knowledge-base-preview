## Answer

Not covered. No routing, quotas, cost or rate limits per agent, user or workload. AIDR gateway collectors only add security inspection inside another vendor's gateway.

Research detail: AIDR plugs into Apigee, Azure API Management, Kong, LiteLLM, Portkey, TrueFoundry and JetStream gateways to screen prompts and responses for injection, jailbreak and sensitive data, and can block or redact. Access rules can allow or block by user, app, model name and groups.

## Products

AIDR gateway collectors, access rules, prompt rules

## Gaps

AIDR does not route traffic or enforce quotas, cost or rate limits. Those stay with the host gateway.

## Options
