## Answer

Not covered. No per-system or per-tool permission model. Access rules do not scope by tool or destination, and MCP proxy enforcement is detector based.

Research detail: The MCP proxy can block or transform tool inputs and outputs, and the Copilot Studio collector returns allow or block for each tool invocation before execution. Access rules can match user, app and model attributes and IdP groups. Continuous Identity announces task-scoped access to connected systems.

## Products

AIDR MCP proxy, Copilot Studio collector, access rules, Continuous Identity

## Gaps

Access rule attributes do not include tool name or destination, so per-tool scope is enforced through detectors rather than declared permissions.
