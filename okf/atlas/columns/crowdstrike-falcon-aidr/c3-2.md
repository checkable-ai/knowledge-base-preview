## Answer

Not covered. No allowed tools list, schema validation, quotas or rate limits, and no general egress or non-MCP API control. The MCP proxy only inspects and blocks MCP traffic.

Research detail: The MCP proxy inspects tool listings, tool inputs and tool outputs with separate rules per checkpoint, and can block, allow or redact. The MCP Validation detector flags tool poisoning and conflicting tool names. Claude Code and Copilot Studio collectors gate tool calls before they run.

## Products

AIDR MCP proxy, MCP Validation and Malicious Skills and Tools detectors, Claude Code and Copilot Studio collectors

## Gaps
