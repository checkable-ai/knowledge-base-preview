## Answer

Not covered. No allow list of local actions, paths or commands. The Claude Code collector applies content-based detector rules to tool inputs, and the page does not document filtering by tool name.

Last checked 14 November 2026.

Research detail: The Claude Code collector uses PreToolUse and PostToolUse hooks so AIDR policy can block or transform a tool call before it runs, deployable through enterprise managed settings that users cannot override. Falcon Guardian is announced to let organisations define which agents may run on managed endpoints and block the rest.
