## Answer

Not covered. No control over which data sources or documents an agent or user can retrieve. Redaction and blocking of prompt content is DLP on content, and network and browser output rules are report only.

Research detail: Prompt rules detect PII, confidential data, secrets and custom regex entities and can block, mask, hash or apply format-preserving encryption, with an unredact API. Topic detection blocks restricted subjects. Rules apply per user, app or model through access rules.
