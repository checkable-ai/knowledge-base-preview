## Answer

Not covered. No control that filters what data each agent or user can retrieve. MCP Proxy PII monitoring and the guardrail PII filter on TOOL_CALL_INPUT are nearby features, but they monitor or filter content and do not authorise retrieval per user or agent.

Research detail: Guardrail fast filters can catch sensitive text such as card numbers and SSNs, and a PII filter on TOOL_CALL_INPUT can stop data reaching third-party APIs. MCP Proxy monitors for PII exposure and alerts. No retrieval authorisation is documented.
