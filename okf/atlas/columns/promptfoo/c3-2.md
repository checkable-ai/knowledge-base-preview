## Answer

Not covered. MCP Proxy (Enterprise) limits which MCP servers are reachable and by whom, but documents no input format enforcement, rate limits, internet egress control or blocking of dangerous actions. Guardrails on tool call input and output are evaluated through an API and the customer's code enforces the result.

Research detail: MCP Proxy allowlists approved MCP servers and grants users and apps access to specific servers. Guardrails support TOOL_CALL_INPUT and TOOL_CALL_OUTPUT placements to validate tool arguments and results. Schema enforcement, quotas and internet egress control are not documented.
