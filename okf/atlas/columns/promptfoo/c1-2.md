## Answer

Covered. Enterprise MCP Proxy only. Applies to systems the agent reaches through MCP servers routed via the proxy. Granularity is per MCP server and tool for each application and user. No public configuration or policy syntax docs, only the product page.

Source statement: "Ensure each application and user only has access to the tools and data it requires." (https://www.promptfoo.dev/mcp/)

Research detail: The MCP Proxy product page says administrators can give specific users and applications access to specific MCP servers, limited to the tools and data they need. Other connected systems are not covered, and the detail comes from a product page rather than configuration docs.
