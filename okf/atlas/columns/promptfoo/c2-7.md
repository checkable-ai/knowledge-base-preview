## Answer

Not covered. No native sandbox, egress policy or kill switch. MCP Proxy docs do not describe blocking calls or revocation. The sandboxed code eval guide uses third-party epicbox.

Research detail: Promptfoo is a testing tool and does not run or contain production agents. The MCP Proxy allowlists approved MCP servers, grants server access per application and user, and logs and alerts on requests, but its page does not describe blocking individual calls, egress control, revocation or an emergency stop. The sandboxed code eval guide runs generated code in Docker through the third-party epicbox library, not a native Promptfoo sandbox. Red team plugins test containment from outside, which sits under automated pen-testing.
