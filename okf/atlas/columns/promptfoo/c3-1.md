## Answer

Not covered. No model gateway. Enterprise guardrails are an endpoint the application must call itself. They provide no routing, quotas, cost limits or rate limits per agent, user or workload. Nearby feature that falls short: guardrails prompt screening.

Last checked 16 November 2026.

Research detail: Enterprise guardrails screen INPUT and OUTPUT through a REST evaluate endpoint that returns an allow, log, warn or block action. Policies are generated from successful red team attacks, plus manual policies. The application must call the endpoint itself, and there is no routing, quota or cost enforcement.

## Gaps
