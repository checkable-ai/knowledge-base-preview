## Answer

Not covered. No documented retention and deletion rules for threads, memory and observability events. Thread deletion and cross-region settings are nearby features that fall short.

Research detail: CORTEX_ENABLED_CROSS_REGION controls where inference runs and customer data is not persisted in the processing region. Threads can be deleted by API, CoWork uploads are deleted after the thread TTL, and observability rows can be deleted by an admin role. Cortex Analyst does not train on customer data, and web search uses Brave with zero data retention.
