## Answer

Not covered. No approval step for changes. Versioning and rollback cover agents only; semantic views, permissions and search indexes are not versioned with the agent.

Last checked 18 November 2026.

Research detail: Agent specs, including instructions, tools and models, are versioned as immutable commits with comments, and rollback repoints an alias. Versions can be imported from a stage or Git, and skills can be pinned by commit hash.

## Products

Agent versioning, skills from Git

## Gaps

No approval step, and no change audit of who committed each version is described. Semantic views, permissions and search indexes are not versioned with the agent.

## Options
