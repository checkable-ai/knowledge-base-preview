## Answer

Covered. Threads must be used. Retention is by explicit deletion, with no automatic retention period documented.

Source statement: "This request is only successful if the thread ID belongs to the user." (https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents-threads-rest-api)

Research detail: Threads hold conversation context across turns, with older turns compacted into summaries. Describe and list thread calls succeed only for the thread's owning user, and a delete endpoint removes a thread and its messages.
