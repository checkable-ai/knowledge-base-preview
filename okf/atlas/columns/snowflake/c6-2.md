## Answer

Not covered. The certification flow applies only to Cortex Code skills and plugins. There is no submission, registration and approval workflow for models, agents or MCP servers. Only admin enablement or privilege grants gate them.

Research detail: Admins can curate which agents appear in Snowflake CoWork, and only account admins can create external MCP server objects by default. Model access is granted per model through application roles.

<!-- chunk: products -->
## Products

Snowflake CoWork object, CREATE EXTERNAL MCP SERVER privilege, model RBAC

<!-- chunk: gaps -->
## Gaps

No submission and approval workflow. Agents outside the curated list remain reachable by direct link.

<!-- chunk: options -->
## Options

Run approvals in a ticketing tool and restrict object creation privileges to a release role.
