## Answer

Covered. Orchestration is Snowflake-managed. The harness version is not visible to customers.

Source statement: "The agent evaluates the results from each tool to decide what to do next" (https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents)

Research detail: Snowflake hosts the agent harness that plans, selects and executes Cortex Analyst, Cortex Search, custom, MCP, web search, skills and code execution tools. It emits thinking, tool use and tool result events, checks tool access before a run and applies tool_choice.
