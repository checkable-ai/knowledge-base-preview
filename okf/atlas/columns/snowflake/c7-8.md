## Answer

Covered, with conditions. Sensitive data classification requires Enterprise Edition or higher. Masking policies must be assigned directly or via tags.

Source statement: "Sensitive data classification requires Enterprise Edition or higher." (https://docs.snowflake.com/en/user-guide/classify-intro)

Last checked 18 November 2026.

Research detail: Horizon sensitive data classification tags columns by semantic and privacy category and can apply tag-based masking automatically. Cortex Search requires change tracking on source tables and suspends after repeated refresh failures. AI_REDACT can sanitise text before indexing.
