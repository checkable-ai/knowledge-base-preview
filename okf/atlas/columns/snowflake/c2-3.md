## Answer

Covered. The code execution tool must be added to the agent. Package installs need an Artifact Repository.

Source statement: "By default, the code execution tool runs in a sandboxed, isolated environment" (https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents-code-execution-tool)

Research detail: The code execution tool provides a Snowflake-hosted Python 3.12 sandbox with preinstalled data libraries and optional PyPI packages. Each sandbox is scoped to one thread, reused across its requests, suspended when idle and cannot query account data. Files persist on the user's workspace stage.
