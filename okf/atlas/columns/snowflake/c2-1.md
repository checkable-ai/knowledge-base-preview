## Answer

Covered. Background runs need threads and time out after 6 hours. Synchronous runs time out after 15 minutes. No automatic retry is documented, so the client resubmits failed runs. No agent-to-agent handoff is documented.

Source statement: "the agent runs asynchronously in the background with a 6 hour timeout, even if the client disconnects." (https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents-run)

Research detail: Cortex Agents run a plan, use tools, reflect loop that can split requests into subtasks and select tools per subtask. An orchestration budget caps seconds or tokens, background mode supports longer runs, and requests otherwise time out after 15 minutes.

## Gaps

Cancellation, retry and recovery of runs are not documented. The run API notes that the assistant message can occasionally fail to store.

<!-- chunk: options -->
## Options

Implement retry and cancellation in the client, or use Snowflake tasks for scheduled workflows.
