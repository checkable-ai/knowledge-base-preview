## Answer

Covered. Background runs need threads. Synchronous runs time out after 15 minutes. Retry is left to the client.

Source statement: "The agent repeats this loop as needed within a single request." (https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents)

Last checked 18 November 2026.

Research detail: Cortex Agents run a plan, use tools, reflect loop that can split requests into subtasks and select tools per subtask. An orchestration budget caps seconds or tokens, background mode supports longer runs, and requests otherwise time out after 15 minutes.

## Gaps

## Options
