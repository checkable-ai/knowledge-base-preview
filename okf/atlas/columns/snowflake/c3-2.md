## Answer

Not covered. Tools in Cortex AI Gateway allow-lists tools, but no input format validation, rate limits, internet egress control or dangerous-action blocks are documented. Allow-listing alone falls short.

Research detail: Tools in Cortex AI Gateway, which Snowflake states follows its acquisition of Natoma, is in private preview with a catalogue of more than 100 MCP servers with OAuth handled by Snowflake. Administrators enable specific tools, all published tools or all current and future tools, and tools that are not enabled are hidden and cannot be invoked. For Cortex Agents, access to an MCP server does not grant its tools, per-user OAuth is required, Snowflake checks the server and its API integration are enabled before each tool call, and disabling the integration invalidates all user tokens.

## Products

Tools in Cortex AI Gateway (from Natoma), Cortex Agents MCP connectors, API integrations

<!-- chunk: gaps -->
## Gaps

The gateway Tools feature is private preview and has no public documentation page. Schema validation, dangerous action filtering, per-tool rate limits and prompt injection screening on gateway tool traffic are not documented. Third-party identity integrations are announced for private preview.

<!-- chunk: options -->
## Options

Request private preview access and test whether a disabled tool can be called by a third-party agent through the gateway. Keep using per-tool grants and integration disablement on Cortex Agents.
