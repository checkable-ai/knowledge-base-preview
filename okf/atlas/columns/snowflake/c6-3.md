## Answer

Covered. The organisation-level view needs an Organization account and is view-only. AI-specific security scanners are limited.

Source statement: "A scanner run that finds no security concern generates no finding in the Trust Center." (https://docs.snowflake.com/en/user-guide/trust-center/overview)

Research detail: Trust Center scans accounts against Security Essentials, CIS Benchmarks, Threat Intelligence and an AI Security package, recording persistent violations and one-time detections with organisation-level views of violations. AI scanners cover privileged Cortex Search owners, unrestricted Cortex Code tokens, unmasked sensitive data used by agents and a disabled prompt injection guardrail.
