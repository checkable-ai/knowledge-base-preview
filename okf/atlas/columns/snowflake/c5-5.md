## Answer

Not covered. Agent lineage shows declared data dependencies and DESCRIBE AGENT lists configured tools. Neither gives a readable map of downstream systems reached and what the agent can do there.

Last checked 18 November 2026.

Research detail: DESCRIBE AGENT shows an agent's configured tools and resources, and inaccessible tool handling warns when a caller's role cannot use a named tool. External MCP server and API integration objects record which remote endpoints are reachable.
