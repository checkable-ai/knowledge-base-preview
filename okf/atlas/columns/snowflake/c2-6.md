## Answer

Covered. Snowflake CoWork only, not direct Cortex Agent API calls. Users can turn memory off in Settings.

Source statement: "User memory lets Snowflake CoWork remember preferences you ask it to save and use them in later conversations." (https://docs.snowflake.com/en/user-guide/snowflake-cortex/snowflake-cowork)

Research detail: Snowflake CoWork user memory remembers preferences a user asks it to save and uses them in later conversations. Users can turn it off under Settings, which does not delete existing memories. Threads also persist until deleted.
