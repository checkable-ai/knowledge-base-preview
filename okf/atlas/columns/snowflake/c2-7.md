## Answer

Not covered. Sandbox egress and process limits are not stated, and no immediate kill switch is documented. The run cancel endpoint and REVOKE USAGE are nearby but quota enforcement and revocation are not described as immediate.

Research detail: The Cortex Agents code execution tool runs in an isolated sandbox scoped to one thread that can read and write only the mounted workspace stage and cannot reach data not passed into the session. Tools that modify state need user approval by default. Revoking USAGE on the agent or on the Cortex AI Gateway object stops a role from sending further requests, and per-user quotas block AI functions, agents, CoWork and the gateway within minutes. Snowflake does not document network egress rules for the sandbox, and the sandbox can still call Snowflake REST endpoints that do not act on a securable object.

## Products

Cortex Agents code execution tool, sandbox permission policy, REVOKE USAGE on agents and AI GATEWAY, per-user quotas

<!-- chunk: gaps -->
## Gaps

No documented way to cancel a running agent turn or terminate a sandbox, which suspends only after inactivity. Quota enforcement takes minutes, not immediate. Isolation technology and egress controls for the sandbox are not stated.

<!-- chunk: options -->
## Options

Revoke USAGE on the agent and gateway as the stop path and time how long an in-flight run continues. Test sandbox egress to an external host. Use network policies and external access integrations to limit custom tool egress.
