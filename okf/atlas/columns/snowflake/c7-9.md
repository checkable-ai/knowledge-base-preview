## Answer

Covered. Tools Activity Dashboard is in Public Preview. AWS commercial regions only, excluding Asia Pacific (New Zealand), Asia Pacific (Malaysia) and Europe (Spain). Only ACCOUNTADMIN can administer MCP servers in Tools. Detection covers access Snowflake observes.

Source statement: "Any AI access discovered outside of Tools" (https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-ai-gateway/tools/admin-activity)

Research detail: Within an account, SHOW AGENTS IN ACCOUNT lists agents and CORTEX_AI_FUNCTIONS_USAGE_HISTORY shows which users call which models. External AI apps can be registered as External Agent objects for observability.
