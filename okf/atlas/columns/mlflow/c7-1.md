## Answer

Not covered. MLflow Tracing records tool calls and spans with session and user metadata, and can export via OpenTelemetry, but traces can be edited or deleted through the API and the documentation describes no write-once or integrity-validated storage, hash chaining, or tamper-detection for the trace record. No documented export of the record to immutable storage as a tamper-evident control.

Research detail: Traces record inputs, outputs and metadata for every intermediate step, with user and session IDs, and the gateway logs requests and responses for audit trails. Feedback records its source and keeps overridden items. Traces can be deleted through the API and MCP server, so the record is not tamper-proof, and no administrative audit log of permission changes is documented for open source.

## Gaps

Not tamper-proof. Reasoning is captured only if the app logs it. Databricks relies on Databricks audit logs for model activity.

<!-- chunk: options -->
## Options

Export traces to write-once storage and restrict delete permissions.
