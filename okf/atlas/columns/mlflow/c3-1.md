## Answer

Not covered. No documented per-user, per-agent or workload rate limits and quotas in the open source gateway; prompt injection screening only via custom judges or guardrails.

Research detail: AI Gateway routes requests to providers with traffic splits and fallbacks, requires USE permission per endpoint, caps spend with global or workspace budget policies that alert or reject with HTTP 429, and runs LLM-judge guardrails that block or sanitise requests and responses. Prompt injection is not a built-in guardrail type and must be written as a custom one. Budgets are not per user or per endpoint, no request rate limits are documented, and post-LLM guardrails do not run on streaming requests.

MLflow AI Gateway, Guardrails, Budget policies

## Gaps

No rate limits, no per-user quota, injection screening only via a custom judge. Databricks AI Gateway adds rate limits and per-user budgets.
