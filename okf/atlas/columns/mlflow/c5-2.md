## Answer

Covered, with conditions. Scheduled issue detection needs a server on Linux or macOS with a SQL backend (SQLite or PostgreSQL) and background job execution enabled. It needs a provider API key or an MLflow AI Gateway endpoint, and each run incurs model usage costs. Schedules are weekly or daily and analyse sampled traces.

Source statement: "MLflow Issue Detection analyzes traces in an experiment to find recurring quality and operational problems." (https://mlflow.org/docs/latest/genai/eval-monitor/ai-insights/detect-issues/)

Last checked 17 November 2026. This platform is checked on demand, so this answer has not been rechecked since.

Research detail: Automatic evaluation runs LLM judges inside the server on new traces and sessions at a set sample rate, for issues such as hallucination, PII leakage and user frustration. Evaluation datasets and mlflow.genai.evaluate support regression testing, and judges can be aligned to human labels. No anomaly detection or alerting is documented, and only LLM judges run automatically.
