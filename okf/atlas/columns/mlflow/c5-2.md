## Answer

Not covered. No anomaly detection or alerting documented; LLM judge evaluation of sampled traces and issue detection fall short of continuous anomaly detection.

Research detail: Automatic evaluation runs LLM judges inside the server on new traces and sessions at a set sample rate, for issues such as hallucination, PII leakage and user frustration. Evaluation datasets and mlflow.genai.evaluate support regression testing, and judges can be aligned to human labels. No anomaly detection or alerting is documented, and only LLM judges run automatically.
