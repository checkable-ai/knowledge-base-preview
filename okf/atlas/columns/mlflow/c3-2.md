## Answer

Not covered. MLflow gateway covers LLM traffic only; no control point for tool calls or internet access. Databricks tool governance is a separate feature.

Research detail: Open source MLflow has no tool gateway. On Databricks, AI Gateway governs MCP servers as Unity Catalog securables with tool filtering, service policies and rate limits, and HTTP connections control access to external APIs. This is a Databricks feature.
