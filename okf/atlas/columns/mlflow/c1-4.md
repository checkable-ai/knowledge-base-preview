## Answer

Not covered. No agent provisioning, permission change or retirement process; registries and RBAC cover model and prompt configuration only.

Research detail: Registered models, prompts, gateway endpoints and LoggedModel versions are created and changed through the API and UI under RBAC roles (READ, USE, EDIT, MANAGE), and creators get MANAGE. This controls agent configurations and model versions. It does not provision agent identities or their runtime permissions.
