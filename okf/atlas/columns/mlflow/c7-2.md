## Answer

Not covered. No security detections, SIEM schema, routing to a security operations team or named response owner. User and session tracing, masking and OTLP export are observability features that fall short.

Last checked 17 November 2026. This platform is checked on demand, so this answer has not been rechecked since.

Research detail: Traces carry user and session metadata and export over OTLP to existing observability backends, including dual export. Client-side span processors can redact data before export. MLflow has no security detections or response ownership.
