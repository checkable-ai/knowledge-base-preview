## Answer

Not covered. Registration exists, but there is no native approval step. Experimental webhooks only let an external system build one.

Research detail: Models and prompts are registered through the API or UI. There is no native approval step. Webhooks (experimental, SQL backend only) send HMAC-signed events on model version creation, alias changes and prompt version creation, so an external system can run approvals. Unity Catalog on Databricks does not support stages or webhooks.
