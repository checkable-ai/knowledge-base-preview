## Answer

Not covered. LoggedModel versions identify a release and link traces to it, but there is no per-agent workload identity or credential, no owner field and no runtime binding.

Research detail: LoggedModel gives each GenAI app or agent version a named record that can be built from the git commit, and traces logged after set_active_model link to that version. This identifies a release for observability. It is not a workload identity or credential, and no owner field is described.
