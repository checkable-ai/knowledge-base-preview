## Answer

Not covered. Gateway usage tracking shows token and cost by model, but no infrastructure, staff time or return measures, and no per-user view.

Research detail: Tracing records token usage per step. AI Gateway usage tracking shows token use, tokens per request and cost by model or provider over time, per endpoint. Cost data depends on LiteLLM pricing and is missing for some models. Labour, savings and yield are not covered.
