## Answer

Covered, with conditions. MCP Registry is an experimental feature introduced in MLflow 3.15.0, and its APIs and behaviour may change. Tool snapshots and registration must be configured and refreshed to stay current.

Source statement: "Automatically discover and catalog the tools that each MCP server exposes." (https://mlflow.org/docs/latest/genai/mcp-registry/)

Last checked 17 November 2026.

Research detail: Model Registry, Prompt Registry and LoggedModel versions inventory models, prompts and agent versions, and AI Gateway holds connections, model definitions and endpoints. Tools and MCP servers are not registered in open source MLflow. On Databricks, Unity Catalog registers MCP servers, functions and connections alongside models.

<!-- chunk: products -->
## Products

Model Registry, Prompt Registry, LoggedModel, Unity Catalog (Databricks)

<!-- chunk: gaps -->
## Gaps

No tool inventory in open source, no software component records.

<!-- chunk: options -->
## Options

Add a tool registry, or use Unity Catalog on Databricks.
