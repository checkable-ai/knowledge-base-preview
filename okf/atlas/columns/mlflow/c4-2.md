## Answer

Not covered. No short-lived scoped credentials, expiry or revoke; gateway LLM connections store provider keys centrally but fall short.

Research detail: AI Gateway LLM Connections store provider API keys centrally so applications call gateway endpoints without holding provider keys. Rotation is done by editing the connection, and endpoints pick up the new key. Using a connection requires USE permission. No expiry, short-lived credentials or explicit revoke action is documented, and the encryption page could not be fetched.

## Products

AI Gateway LLM Connections, basic auth AI Gateway permissions

## Gaps

No expiry or automatic rotation. At-rest encryption not confirmed. Gateway callers authenticate with basic auth or a plugin token.
