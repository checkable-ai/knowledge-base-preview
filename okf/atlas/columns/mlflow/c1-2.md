## Answer

Not covered. MLflow does not scope what an agent may do in connected systems. Resource permissions only control access to MLflow's own experiments, traces and models.

Research detail: Open source MLflow does not scope agent actions against connected systems. Databricks managed MLflow sits with Databricks AI Gateway, where Unity Catalog privileges govern access to MCP servers, functions and HTTP connections, with tool filtering. This is a Databricks platform feature, not MLflow open source.
