## Answer

Not covered. Model Registry lineage links versions to runs, but no model file inspection, AI bill of materials or compliance attestation.

Research detail: Model Registry versions link to the run, logged model or notebook that produced them, with tags and descriptions. On Databricks, Unity Catalog records lineage to training tables and requires a model signature. MLflow does not scan model files, produce an AI BoM or issue compliance attestations.
