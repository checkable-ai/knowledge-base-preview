## Answer

Covered. Requires Enterprise DLP with AI Access Security; responses are not scanned.

Source statement: "block exfiltration of sensitive data for file and non-file-based traffic and text prompts." (https://docs.paloaltonetworks.com/ai-access-security/getting-started/introducing-ai-access-security)

Research detail: Enterprise DLP inspects text prompts, non-file inputs and file uploads sent to GenAI apps and can block exfiltration. The browser GenAI Prompt control blocks whole prompts that match local or cloud DLP profiles, and Typing Guard masks sensitive data. Enforcement is per user, group and tenant.

<!-- chunk: products -->
## Products

Enterprise DLP with AI Access Security, Prisma Browser GenAI Prompt and Typing Guard

<!-- chunk: gaps -->
## Gaps

AI Access Security does not scan responses. Safari prompt collection is not supported.

## Options

Test DLP profiles against sample prompts and uploads.
