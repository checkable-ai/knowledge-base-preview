## Answer

Not covered. No tool call gateway, tool allow-listing by schema, input format checks, limits or MCP traffic inspection. Nearby features (runtime blocking of unsafe actions, step-up MFA approval) fall short of controlling agent tool calls.

Research detail: Web access rules control internet egress from the browser per user and device, and extension controls block extensions by permission, risk or verdict. GenAI app extensions, plugins and custom GPTs can be controlled. No tool schemas or MCP traffic are inspected.
