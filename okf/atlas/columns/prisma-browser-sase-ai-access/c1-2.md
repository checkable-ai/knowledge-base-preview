## Answer

Not covered. The GenAI app filter and web access rules scope which apps users reach. They do not define what an agent may do in connected systems, and there are no per-agent scopes.

Research detail: Web access, login and tenant controls restrict which SaaS apps, URLs and enterprise tenants a session can reach, for example only the organisation's Claude or ChatGPT tenant. AI Access Security rules allow or block GenAI apps by source user and app filter. These scope human sessions and any agent in them, not agent identities.
