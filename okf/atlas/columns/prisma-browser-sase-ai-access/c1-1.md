## Answer

Not covered. Agent-specific action rules are announced in a blog but not documented in the admin guide; browser data controls do not govern local file or command use by agents.

Research detail: Access and Data Control rules limit what can be done in the browser per user, group and device group, including file upload, download, typing guard, screenshots and printing. The blog says policy can be set separately for humans and agents, controlling what actions each may perform. The admin guide does not yet describe agent-specific rules.
