## Answer

Not covered. No public sandboxing of agent code execution, no network egress policy and no stop or kill control for a running agent. Admin articles that might describe these sit behind customer sign-in.

Last checked 19 October 2026.

Research detail: No public Harvey page describes sandboxing of agent code execution, network egress policy or a stop control for a running agent. The 14 October 2026 release note on custom agents says admin approval applies only at the sharing levels a firm selects, and users can run agents as soon as they save them. That is a sharing governance setting and not a containment or kill control.
