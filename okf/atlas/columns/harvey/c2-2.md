## Answer

Covered. Model is chosen per request through the API model parameter or Model Selector, with the workspace default otherwise. Some models are opt-in per workspace. Zero data retention is required of model providers, and per-organisation rate limits apply.

Source statement: "You can pass an optional model form parameter to choose which model handles the request." (https://developers.harvey.ai/guides/assistant)

Last checked 19 October 2026.

Research detail: Users pick named models in a Model Selector and the API accepts model slugs such as gpt-5-5 and claude-opus-4-7, with the workspace default used otherwise. Harvey requires zero data retention from model providers, publishes its AI subprocessors with processing locations, and sets per-organisation API rate limits.
