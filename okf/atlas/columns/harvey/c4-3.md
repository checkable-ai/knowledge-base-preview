## Answer

Covered. Applies to calls through the Harvey MCP server, where the caller authenticates per user through OAuth. Downstream connector identity propagation from Harvey's own agents is not documented.

Source statement: "The server resolves each request to the authenticated user and enforces their specific permissions and feature gates." (https://developers.harvey.ai/guides/harvey_mcp)
