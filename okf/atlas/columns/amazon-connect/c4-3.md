## Answer

Not covered. In agent assistance the AI agent is authorised against the representative's and its own security profiles, but the person's identity is not documented as passed to downstream MCP tools or systems.

Research detail: For agent assistance, the AI agent runs in the human representative's session and tool calls are authorised against both the AI agent's and the representative's security profiles. Security profiles also govern whether an employee may have an AI agent act on their behalf.
