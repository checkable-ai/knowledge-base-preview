## Answer

Not covered. No customer-facing sandbox, filesystem or egress controls and no single kill switch. Security profile tool permissions and removing tools are configuration changes.

Research detail: Security profiles control which tools an AI agent can invoke, and tools can be selected per AI agent. Return to Control tools such as Complete and Escalate signal the AI agent to stop and hand control back to the contact flow. MCP tool calls time out at 30 seconds. The agent runtime is managed by AWS.

<!-- chunk: products -->
## Products

Security profile tool permissions, per-agent tool selection, Return to Control tools, MCP tool timeout

## Gaps

No customer-facing sandbox, filesystem or egress controls are documented, and no single control stops a running AI agent. Removing tools or changing flows is a configuration change rather than a documented kill switch.
