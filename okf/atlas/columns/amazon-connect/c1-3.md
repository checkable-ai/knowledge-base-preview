## Answer

Not covered. A per-tool isUserConfirmationRequired flag exists, but who approves, binding to the exact action, and handling of refusal and replay are not documented.

Research detail: The tool configuration API has a userInteractionConfiguration with an isUserConfirmationRequired flag per tool. Return to Control tools such as Escalate hand control back to the contact flow.
