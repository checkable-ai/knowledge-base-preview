## Answer

Covered. Connect Customer tier (not Customer Basic). External agent setup is API only with SigV4-signed requests. Needs an Amazon Lex V2 bot with AMAZON.QInConnectIntent.

Source statement: "The security profile attached to your Connect AI agent must explicitly allow the third-party application, or collaboration fails at runtime." (https://docs.aws.amazon.com/connect/latest/adminguide/a2a-setup-external.html)

Research detail: Connect AI agents collaborate with other Connect AI agents and with external agents over A2A with Connect extensions. External agents are registered as applications, authenticated with an API key held in Secrets Manager, and allowed through the AI agent's security profile.

## Gaps

## Options
