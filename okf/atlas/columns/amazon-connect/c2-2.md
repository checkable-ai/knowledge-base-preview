## Answer

Covered, with conditions. Connect Customer might use cross-region inference, so inference Regions vary by the Region of the Connect Customer instance (for example the Sydney instance may use Sydney and Melbourne). Some Agentic CX designer nodes (User input and User choice) may use additional inference Regions in Asia Pacific for Sydney and Tokyo instances. For many features Connect Customer manages model selection itself and changes the model over time. Models run through Amazon Bedrock.

Source statement: "The models available on Amazon Bedrock never store, log, or share customer prompts (input) and responses (output), and never use this data to train these models." (https://docs.aws.amazon.com/connect/latest/adminguide/ai-in-connect.html)

Last checked 12 November 2026. This platform is checked on demand, so this answer has not been rechecked since.

Research detail: AI features use Amazon Bedrock models, and AWS states Bedrock models do not store or train on prompts and responses. Each AI prompt names its model, Connect notifies before deprecation and redirects to a supported model afterwards, and the docs list the inference Regions each instance Region may use under cross-region inference.
