## Answer

Covered. Rights inside third-party systems also depend on the AgentCore gateway's own outbound credentials.

Source statement: "Security profiles control both user capabilities and AI agent tool access in Connect." (https://docs.aws.amazon.com/connect/latest/adminguide/ai-agent-security-profile-permissions.html)

Research detail: Security profiles control which tools an AI agent can invoke, covering AgentCore gateway tools, flow modules saved as tools and built-in tools such as cases and tasks. Tools are also selected per AI agent, with input overrides and output filters.
