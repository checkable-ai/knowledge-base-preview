## Answer

Not covered. External A2A agent API keys sit in Secrets Manager but rotation and revocation are not described and the keys are long-lived. The MCP gateway JWT is separate and identifies the instance.

Research detail: External A2A agent API keys are stored in AWS Secrets Manager under a customer managed KMS key, and Connect presents them as bearer tokens. For MCP tools, Connect sends a JSON Web Token to the AgentCore gateway, which validates it against the instance's OpenID discovery URL and allowed audiences.
