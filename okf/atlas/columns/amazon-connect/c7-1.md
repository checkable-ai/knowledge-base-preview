## Answer

Not covered. No public documentation of a per-action record of Connect Customer AI agent tool calls, data access and changes held in write-once or integrity-validated storage. CloudTrail records API and configuration events (such as agent status changes) and offers log file integrity validation, but it is not documented as capturing AI agent tool invocations by agent and session. AI agent conversation and trace logs are not documented as supporting S3 Object Lock or an equivalent tamper-evident export.

Research detail: CloudTrail records Connect API calls and can deliver them to S3. Agentic CX designer Audit lists write and delete events with user and time. AI agent traces show flow, bot and AI agent spans with the transcript, stored through automated interaction logs in S3.

## Products

CloudTrail, Agentic CX designer Audit, AI agent traces

## Gaps

Traces do not support S3 buckets with Object Lock, which limits write-once storage.

<!-- chunk: options -->
## Options

Enable a CloudTrail trail with log file validation and keep trace buckets under restricted access.
