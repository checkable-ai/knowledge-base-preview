## Answer

Covered. Tool calls are limited to the tools added to each AI agent, and security profiles set the bounds on what the agent may do. Admins can override input values, filter outputs and require user confirmation per tool. MCP tool calls time out after 30 seconds. Third-party MCP servers are reachable only through a registered Amazon Bedrock AgentCore Gateway. AI agents have no general internet access outside configured tools. Dangerous actions are blocked by permission scoping and confirmation, not by inspecting the content of each call.

Source statement: "Connect Customer reuses security profiles for Connect Customer users for AI agents, allowing you to govern the boundaries of what abilities your AI agents can perform, just as you govern the abilities your customer service representatives can take in the Connect Customer system." (https://docs.aws.amazon.com/connect/latest/adminguide/ai-agent-mcp-tools.html)

Research detail: Tool use is limited by security profiles and per-agent tool selection, with input overrides, output filters and an optional user confirmation flag. Third-party MCP servers are reached only through a registered AgentCore gateway.
