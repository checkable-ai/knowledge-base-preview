## Answer

Covered. ACS v0.1.0 reference Guardian; wire authentication not implemented there. ASI02 guidance.

Source statement: "An agent that implements ACS sends a hook request before it acts." (https://github.com/GenAI-Security-Project/agent-control-standard)

Research detail: ASI02 sets a pre-execution policy enforcement point that validates intent and arguments, enforces schemas and rate limits and issues short-lived credentials, plus egress allowlists and fully qualified tool names with version pins. ACS defines a Guardian that can allow, deny or modify a tool call before it runs.
