## Answer

Covered. Guidance only. Session resumption is not addressed.

Source statement: "Isolate user sessions and domain contexts to prevent knowledge and sensitive data leakage." (https://raw.githubusercontent.com/GenAI-Security-Project/GenAI-Security-Corpus/main/corpus/_extracted/agentic-top10/2026-final/OWASP-Top-10-for-Agentic-Applications-2026-v1.0.pdf.txt)

Research detail: ASI06 asks for memory segmentation that isolates user sessions, and ASI03 for per-session sandboxes with separated permissions and memory, wiping state between tasks.
