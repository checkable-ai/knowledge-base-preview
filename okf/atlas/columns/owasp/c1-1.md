## Answer

Source statement: "Run code in sandboxed containers with strict limits including network access" (https://raw.githubusercontent.com/GenAI-Security-Project/GenAI-Security-Corpus/main/corpus/_extracted/agentic-top10/2026-final/OWASP-Top-10-for-Agentic-Applications-2026-v1.0.pdf.txt)
