## Answer

Covered. Guidance only. No token format is prescribed. The same mitigation appears in LLM03:2026 and ASI03 (signed intent binding).

Source statement: "actions taken on behalf of a user are executed on downstream systems in the context of that specific user" (https://genai.owasp.org/llmrisk/llm062025-excessive-agency/)

Research detail: LLM03:2026 says tools acting for a user must run in that user's context with minimum scope, and delegated or multi-agent workflows must preserve the original user context across chained calls. ASI03 adds binding OAuth tokens to a signed intent with subject, audience, purpose and session.
