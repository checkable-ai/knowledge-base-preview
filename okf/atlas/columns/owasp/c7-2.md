## Answer

Not covered. ACS Trace exports hook and decision telemetry as OpenTelemetry and OCSF, but specifies no redaction of sensitive data, detections, session or person linkage, or named response owner; the reference exporter is not Trace conformant.

Research detail: The ACS Trace profile records every hook and decision as an OpenTelemetry span and an OCSF event for existing security tooling. LLM02:2026 recommends AI-aware audit logging into the SIEM.
