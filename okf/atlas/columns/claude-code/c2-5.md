## Answer

Covered. Hooks, plugins and local MCP servers run with the user's privileges outside the sandbox.

Source statement: "Hooks are user-defined shell commands, HTTP endpoints, MCP tool calls, LLM prompts, or subagents that execute automatically at specific points in Claude Code's lifecycle." (https://code.claude.com/docs/en/hooks)

Research detail: Claude Code is itself the harness that executes tools: built-in file, shell, web and task tools, MCP servers, skills, plugins and subagents, with hooks at each lifecycle point. The Agent SDK exposes the same loop to other applications.

## Products

## Gaps

Plugins, hooks and mods execute arbitrary code with the user's privileges outside the permission system.

## Options
