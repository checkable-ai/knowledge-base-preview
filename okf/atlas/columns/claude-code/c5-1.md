## Answer

Covered. Auto mode and acceptEdits reduce per-action review. Code Review is on Team and Enterprise plans. Plan approvals by teammates are granted by the lead without the user.

Source statement: "In Manual mode, Claude Code stops and asks you before most actions that edit files, run shell commands, or reach the network." (https://code.claude.com/docs/en/permission-modes)

Research detail: Users review each proposed edit and command before approval in Manual mode, approve plans in plan mode, and can rewind code and conversation with checkpoints. Code Review runs multi-agent review on pull requests for Team and Enterprise plans.
