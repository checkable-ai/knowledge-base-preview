## Answer

Covered. Transcripts are stored locally with 30-day default retention (cleanupPeriodDays); claude purge deletes sooner. Desktop app, claude.ai/code and VS Code keep their own session lists.

Source statement: "Claude Code stores it locally as you work, so you can resume where you left off, branch to try a different approach, or switch between tasks." (https://code.claude.com/docs/en/sessions)

Research detail: Sessions are saved continuously as JSONL transcripts that can be resumed, branched, exported and deleted. Retention defaults to 30 days and is set with cleanupPeriodDays, and transcript writes can be suppressed. Cloud session transcripts are stored by Anthropic and can be deleted.

<!-- chunk: products -->
## Products

Session transcripts, --resume, /branch, cleanupPeriodDays, claude purge

<!-- chunk: gaps -->
## Gaps

Local transcripts are plaintext under the user's home directory with only OS file permissions as access control. Any process running as the user can read them.

<!-- chunk: options -->
## Options

Lower cleanupPeriodDays through managed settings, use disk encryption, and set CLAUDE_CODE_SKIP_PROMPT_HISTORY on sensitive hosts.
