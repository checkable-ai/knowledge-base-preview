## Answer

Not covered. No documented write-once or integrity-validated storage for agent action records, and no documented tamper-evidence mechanism. Nearby features fall short: OpenTelemetry events export tool calls and user/session attributes but carry no integrity guarantee, local session transcripts are editable files, and gateway and cloud session audit logs are not documented as immutable or integrity-checked.

Research detail: OpenTelemetry logs carry prompts (opt-in), tool decisions, tool parameters (opt-in) and API requests with session and user attributes. Cloud session operations are logged for audit, settings changes are available through the compliance API or audit export, and the Claude apps gateway records a per-request audit log with IdP identity.

<!-- chunk: products -->
## Products

OpenTelemetry events, cloud session audit logging, Compliance API, Claude apps gateway audit log

<!-- chunk: gaps -->
## Gaps

No tamper-evident ledger. Content capture is off by default and model reasoning is not exported. Local transcripts are editable by the user.

<!-- chunk: options -->
## Options

Enable OTEL_LOG_USER_PROMPTS and OTEL_LOG_TOOL_DETAILS through managed settings and ship to write-once storage.
