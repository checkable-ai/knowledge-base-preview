## Answer

Not covered. OpenTelemetry export carries session and user attributes, but no built-in detections, alerting or named response owner are documented.

Research detail: Administrators can force OTLP export through managed settings so developers cannot redirect it. Every event carries session.id, account, email and organisation IDs, and content is redacted by default. Plugin install and load events support supply-chain monitoring.

## Products

OpenTelemetry export, managed telemetry configuration

<!-- chunk: gaps -->
## Gaps

No built-in detections, alerting or response ownership. Third-party plugin and MCP names are redacted unless tool details are enabled.

## Options
