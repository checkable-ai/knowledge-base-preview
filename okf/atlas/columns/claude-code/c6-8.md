## Answer

Not covered. Immutable plugin versions with pinning and rollback exist for plugins only. No approval, versioning or rollback for prompts, permissions, models or knowledge.

Last checked 18 November 2026.

Research detail: Administrators can set minimum and maximum client versions, control plugin auto-update per marketplace or fleet, run stable and early-access plugin channels per group, and audit settings changes. Checkpointing lets users rewind code changes within a session.

<!-- chunk: products -->
## Products

requiredMinimumVersion and requiredMaximumVersion, plugin update policy and release channels, settings audit events

<!-- chunk: gaps -->
## Gaps

No approval step for changes to prompts, permissions or tools before release, and no rollback of managed settings beyond editing them.

<!-- chunk: options -->
## Options

Gate managed settings and marketplace changes through pull request review and staged release channels.
