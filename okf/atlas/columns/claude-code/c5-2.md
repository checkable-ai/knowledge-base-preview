## Answer

Not covered. No task training, behavioural baselining, drift monitoring or anomaly detection. OpenTelemetry events are raw observations for the customer's own tooling, and auto mode checks actions at runtime only.

Last checked 18 November 2026.

Research detail: In auto mode a separate classifier evaluates each action, subagent spawn and inter-agent message at runtime and blocks those it judges unsafe, falling back to prompts after repeated blocks. No anomaly detection or behavioural baselining across sessions is documented.
