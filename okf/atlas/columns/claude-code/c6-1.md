## Answer

Not covered. No organisation-wide register of models, agents and tools with components. Plugin marketplaces and analytics list plugins only.

Research detail: Plugin marketplaces act as catalogues of plugins and their components, and the Enterprise Analytics API returns per-plugin install and invocation counts. The documentation states Claude Code has no built-in MCP server registry.
