## Answer

Covered. Applies in Manual mode and plan mode; auto mode replaces most prompts with a classifier.

Source statement: "In Manual mode, Claude Code stops and asks you before most actions that edit files, run shell commands, or reach the network." (https://code.claude.com/docs/en/permission-modes)

Research detail: In Manual mode Claude Code shows the exact command or edit and asks before running it, with approve once, always allow or deny. Unmatched or unanalysable commands fail closed to a prompt. Teammates cannot approve prompts or relay a denied action, and each decision is emitted as a tool_decision event with its source.

<!-- chunk: products -->
## Products

Permission prompts, Manual and plan modes, tool_decision OpenTelemetry event

<!-- chunk: gaps -->
## Gaps

Auto mode, the default in recent versions, replaces most human prompts with a classifier. Always-allow grants persist per repository. The approver is the local user with no separate authorisation check.

<!-- chunk: options -->
## Options

Set permissions.defaultMode or disableAutoMode in managed settings where a human must approve, and export tool_decision events.
