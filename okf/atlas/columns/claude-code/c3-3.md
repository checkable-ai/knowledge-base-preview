## Answer

Not covered. No control point filtering retrieved data per agent or user and no DLP or content classification on prompts, outputs or tool results. Read deny rules and sandbox filesystem rules restrict by path only.

Research detail: Read deny rules block file reads by path, sandbox filesystem rules and credential denies restrict what shell commands can read, and WebFetch passes most pages through a separate summarising model call. These limit retrieval by path but do not inspect content.

## Products

Read permission rules, sandbox filesystem isolation, sandbox.credentials

## Gaps
