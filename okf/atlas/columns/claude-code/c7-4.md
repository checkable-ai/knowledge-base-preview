## Answer

Not covered. No scanning of hosts, containers or images. The dev container is a reference example and the sandbox is off by default; hardening of self-hosted hosts stays with the customer.

Research detail: The sandbox is enforced by the operating system, cloud sessions run in isolated VMs that are reclaimed after inactivity, and administrators can set a required version range and fail-closed settings refresh. Server-managed settings are a client-side control that a user with a modified binary can bypass.

<!-- chunk: products -->
## Products

Sandbox, cloud session VMs, requiredMinimumVersion, forceRemoteSettingsRefresh

<!-- chunk: gaps -->
## Gaps

No attestation of the harness binary or host. Self-hosted environment isolation is the customer's responsibility.

<!-- chunk: options -->
## Options

Deploy endpoint-managed settings on MDM-enrolled devices and run Claude Code in a dev container or VM for untrusted work.
