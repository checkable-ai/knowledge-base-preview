## Answer

Not covered. No scanning of hosts, containers or images is documented. Nearby features fall short: the built-in sandbox (off by default, Bash, PowerShell and Monitor commands only), the sandbox runtime (beta research preview), the example dev container with a default-deny firewall, and Anthropic-hosted cloud VMs. Hardening and scanning of self-hosted hosts and runners stays with the customer, and Claude Code does not require a container.

Research detail: The sandbox is enforced by the operating system, cloud sessions run in isolated VMs that are reclaimed after inactivity, and administrators can set a required version range and fail-closed settings refresh. Server-managed settings are a client-side control that a user with a modified binary can bypass.
