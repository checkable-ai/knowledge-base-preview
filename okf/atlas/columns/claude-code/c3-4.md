## Answer

Not covered. No policy defining which agent pairs may communicate and no message schema or format enforcement. Messages are plain text only. Inbound accept, hold or refuse, approval dialogs, size caps and loop throttling gate delivery but are not an allowed-pair and format gateway.

Last checked 18 November 2026.

Research detail: There is no policy layer that defines which agent pairs may communicate or what message schemas they use. In auto mode the classifier reviews inter-agent messages before delivery, but that is per-message screening within one user's sessions, not pair or schema enforcement.
