## Answer

Not covered. No scheduled reassessment of external models, tools and services. MCP allowlists, denylists and managed marketplaces give approval and blocking only.

Last checked 18 November 2026.

Research detail: Administrators approve external tools by allowlisting MCP servers and marketplace sources and can block or retire them with denylists and managed enabledPlugins set to false, applied at the next session start. Anthropic reviews directory connectors against listing criteria only.
