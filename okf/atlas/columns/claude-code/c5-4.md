## Answer

Not covered. No built-in load monitoring, dashboards, alerting or anomaly detection for the systems agents run on. OpenTelemetry and gateway metrics are raw telemetry for the customer's own stack.

Research detail: Per-request api_request events and gateway OTLP metrics carry latency and token counts that can feed an observability stack. Claude Code does not provide load monitoring or anomaly detection itself.
