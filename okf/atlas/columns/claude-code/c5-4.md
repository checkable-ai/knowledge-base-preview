## Answer

Not covered. No built-in monitoring, dashboards or anomaly detection for the systems agents run on. Nearby: in self-hosted environments (public beta, Team and Enterprise), the runner and orchestrator expose Prometheus metrics and come with sample alert rules. Collecting, monitoring and alerting all happen in the customer's own Prometheus stack, and the local CLI, IDE and Anthropic-hosted sessions have nothing like it. OpenTelemetry export is also only raw telemetry for the customer's own tools.

Last checked 18 November 2026.

Research detail: Per-request api_request events and gateway OTLP metrics carry latency and token counts that can feed an observability stack. Claude Code does not provide load monitoring or anomaly detection itself.
