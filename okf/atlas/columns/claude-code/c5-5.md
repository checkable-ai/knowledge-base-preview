## Answer

Covered. Per-installation text views (/permissions, /mcp, claude mcp list, /status). Server-delivered managed permission rules need Team or Enterprise. No graphical or fleet-wide map.

Source statement: "Claude Code supports fine-grained permissions so that you can specify exactly what the agent is allowed to do and what it can't." (https://code.claude.com/docs/en/permissions)

Research detail: Per machine, /permissions shows effective rules, /mcp and claude mcp list show connected servers, /status shows which managed source is in force, and claude plugin details prints a component inventory of hooks, MCP and LSP servers. These are text views for one installation.
