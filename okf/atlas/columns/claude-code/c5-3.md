## Answer

Covered, with conditions. Contribution metrics are available on the Claude for Teams and Claude for Enterprise plans. Contribution metrics are in public beta. Contribution metrics are not available for organisations with Zero Data Retention enabled. Contribution metrics cover only users in the claude.ai organisation and exclude usage through the Claude Console API or third-party integrations. For API (Claude Console) customers, the dashboard shows usage and spend metrics only, without contribution metrics, and its spend figures are estimates. The Claude Enterprise Analytics API, which gives per-user usage and cost reports, is on the Enterprise plan only and not on the Teams plan. Contribution metrics need the Claude GitHub app and cover repositories on github.com, not GitHub Enterprise Server.

Source statement: "Use contribution metrics to demonstrate ROI, identify adoption patterns, and find team members who can help others get started." (https://code.claude.com/docs/en/analytics)

Last checked 18 November 2026.

Research detail: OpenTelemetry exports cost and token counters per model, session and user. Analytics dashboards show accepted lines, accept rate, active users, and with GitHub integration the PRs and lines shipped with Claude Code. Spend reports, the Enterprise Analytics API and the Console Claude Code Analytics API give per-user cost.

<!-- chunk: products -->
## Products

OpenTelemetry metrics, analytics dashboard, contribution metrics, Analytics APIs, modelPricing

<!-- chunk: gaps -->
## Gaps

Cost figures are list-price estimates unless modelPricing is set. Contribution metrics are unavailable with ZDR and for API and cloud-provider usage. Labour savings and profit are not measured.

<!-- chunk: options -->
## Options

Set modelPricing to contracted rates and combine contribution metrics with DORA metrics as the documentation suggests.
