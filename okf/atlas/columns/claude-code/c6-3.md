## Answer

Covered, with conditions. Security posture is in beta. It is available to organisations on Claude Enterprise whose parent organisation has the Compliance API enabled; other plans and Claude Console organisations get no results. It needs a Compliance Access Key with the matching scope.

Source statement: "Security posture evaluates a list of controls and gives each one a result." (https://platform.claude.com/docs/en/manage-claude/compliance-security-posture/overview)

Research detail: On each machine /status and claude doctor report which managed source is in force, failed fetches and dropped policy entries. There is no organisation-wide view of control coverage or breaches.
