## Answer

Not covered. Telemetry covers managed Claude Code installs only; no discovery of unapproved AI tools or unmanaged installs.

Research detail: Within managed installations, OpenTelemetry and the Enterprise Analytics API report which MCP servers and plugins users actually load and invoke, and analytics show active users. Administrators can restrict logins to their organisation with forceLoginOrgUUID.
