## Answer

Covered. CLAUDE.md and auto memory are context, not enforced configuration. Auto memory is machine-local and loads the first 200 lines or 25KB.

Source statement: "Each Claude Code session begins with a fresh context window." (https://code.claude.com/docs/en/memory)

Research detail: CLAUDE.md files at managed, project and user scope carry persistent instructions, and auto memory lets Claude write learnings per repository that load in every session. Subagents can have their own persistent memory directories. A managed policy CLAUDE.md cannot be excluded.

## Products

CLAUDE.md, auto memory, subagent memory

## Gaps

Auto memory is machine-local plaintext with no documented expiry or organisational review. Memory is context, not enforced policy.

<!-- chunk: options -->
## Options

Disable auto memory with CLAUDE_CODE_DISABLE_AUTO_MEMORY where retention must be controlled, and audit memory files with /memory.
