## Answer

Not covered. No SBOMs and no scanning or security review of MCP servers, CLI tools, skills or plugins by the vendor for what agents use. Skill and plugin scanning covers only uploaded items. Allowlists only gate what loads, and the sandbox covers shell commands only. The plugin security page is guidance for users to review what a plugin adds and where it comes from, and plugin processes run outside the shell sandbox.

Last checked 18 November 2026.

Research detail: Plugin details show a component inventory of commands, agents, skills, hooks and MCP and LSP servers before and after install.
