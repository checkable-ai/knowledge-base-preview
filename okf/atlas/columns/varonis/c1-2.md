## Answer

Not covered. Varonis for Copilot and Agentforce limit agent access to data (remediating excessive access), but there is no documented policy on which actions an agent may take in connected systems, and nothing for custom agents.

Research detail: Varonis for Agentforce automatically right-sizes agent access so agents act within intended scope (least privilege and least agency). Varonis for Microsoft 365 Copilot enforces policies that limit Copilot access to sensitive data and remediates excessive access. Scope is data permissions in the covered SaaS, not a general action policy for agents.
