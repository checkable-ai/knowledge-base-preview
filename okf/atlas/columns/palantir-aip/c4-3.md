## Answer

Covered. Authorization code grant only. Client credentials grant runs as a service user.

Source statement: "Use this grant type when the MCP client should act on behalf of an end user." (https://www.palantir.com/docs/foundry/ontology-mcp/authentication-and-authorization/)

Research detail: Ontology MCP supports the OAuth authorization code grant for clients acting for a user, and the token reflects that user's Foundry permissions. Effective token scope is the intersection of user permissions, application restrictions and requested scope. A pro-code agent run from Automate runs as the triggering user or the automation's service user.
