## Answer

Covered. Unrestricted Developer Console applications drop the resource allowlist.

Source statement: "This tool specifies the object types that the LLM can access." (https://www.palantir.com/docs/foundry/chatbot-studio/tools/)

Research detail: Chatbot tools are configured per chatbot: object query tools name the object types and properties the LLM may access, and action tools name specific ontology actions. Action submission criteria can require user, group or parameter conditions. Developer Console restricted applications and the Ontology binding limit which object types, actions, functions and projects an agent or MCP client can reach.

## Products

Chatbot Studio tools, action submission criteria, Developer Console application restrictions, Ontology binding

## Gaps

Unrestricted applications drop the resource allowlist. Platform API requests by agents are not branch-aware.

<!-- chunk: options -->
## Options
