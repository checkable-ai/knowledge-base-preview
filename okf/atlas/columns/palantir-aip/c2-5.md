## Answer

Covered. Pro-code agents are beta. AIP Chatbot Studio hosts tool calling.

Source statement: "Supported third-party agent SDKs include the Claude Agent SDK, OpenAI Agents SDK, and Google ADK." (https://www.palantir.com/docs/foundry/agents/overview/)

Research detail: AIP Chatbot Studio is a hosted harness that runs LLM tool calls across actions, object queries, functions, commands and application variables. Pro-code agents use templates for the Claude Agent SDK, OpenAI Agents SDK and Google ADK, with Ontology MCP and Palantir MCP configured.
