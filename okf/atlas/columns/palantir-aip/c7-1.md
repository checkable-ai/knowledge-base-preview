## Answer

Not covered. Audit.3 logs record user and agent activity and can be exported to a SIEM or a Foundry dataset, but the documentation does not describe write-once or integrity-validated (hash-chained, signed) storage, or an export to such storage. The export dataset has only an optional retention limit. Agent session logs and trace views are observability features, not tamper-evident records.

Research detail: audit.3 logs record who did what, when and to which resources in standard categories. Chatbot session logs record user requests, the compiled system prompt, tool calls with inputs and results, and responses with trace IDs. The action log records each successful action submission as an object.

## Products

audit.3 logs, chatbot session logging, action log

<!-- chunk: gaps -->
## Gaps

No tamper-proof or write-once claim is made, and origin fields can be spoofed. Reasoning is not logged separately. Session log export needs extra setup and roles.

<!-- chunk: options -->
## Options

Export audit and session logs to an external immutable store.
