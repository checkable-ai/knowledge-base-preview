## Answer

Not covered. No permission model for local files, commands or network. The code execution sandbox has only timeout and output limits.

Research detail: Agent-generated code can run in a Docker-based local sandbox or a Piston server with timeout and output limits. The toolkit security page recommends sandboxing and containerisation for system integrity.
