## Answer

Covered. Requires an external OAuth 2.1 authorisation server such as Keycloak; scopes and audience only.

Source statement: "Ensuring required scopes are present (if configured)" (https://docs.nvidia.com/nemo/agent-toolkit/latest/components/auth/a2a-auth.html)

Research detail: The toolkit adds an OAuth 2.1 authorisation code flow to A2A. The A2A server validates JWTs against JWKS keys and checks issuer, expiry, required scopes and audience. Clients learn requirements from the agent card.

## Products

NeMo Agent Toolkit A2A client and server, server_auth

<!-- chunk: gaps -->
## Gaps

Relies on an external authorisation server such as Keycloak. Trust boundaries beyond scopes and audience are left to the deployer.

<!-- chunk: options -->
## Options

Configure audience and scopes on every A2A server and test rejection of tokens issued for another server.
