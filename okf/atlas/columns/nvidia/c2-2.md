## Answer

Covered. Self-hosted NIM, including air-gapped sites. Model version is set through explicit model profiles. Per-endpoint rate limits are not documented for NIM.

Source statement: "Your sensitive data never leaves your infrastructure." (https://developer.nvidia.com/blog/securely-deploy-ai-models-with-nvidia-nim/)

Research detail: NIM microservices run models on customer infrastructure, including air-gapped sites, so data stays in the deployer environment. Each NIM uses an explicit model profile ID mapped to an NGC version tag. NIM Operator deploys NIMService resources with autoscaling and model caching.
