## Answer

Not covered. The toolkit code sandbox documents no filesystem or egress policy and no kill switch. OpenShell is a separate early-release runtime outside the product scope.

Research detail: The NeMo Agent Toolkit code execution tool runs code in a local Docker sandbox or a Piston server, with a 10 second default timeout and output limits, and returns only standard output. NVIDIA OpenShell, a separate NVIDIA sandbox runtime at v0.1.4, runs agents as a non-root user with Landlock filesystem limits, seccomp staging of network calls and a network fence so the supervisor is the only egress path. Deleting an OpenShell sandbox cuts off its supervisor, and a dropped supervisor connection freezes the agent.

## Gaps

The toolkit sandbox documents no egress or filesystem policy beyond the container. OpenShell is early (v0.1.x), is not part of the documented NVIDIA AI Enterprise scope of this column and its release status is not stated. NIM itself has no agent kill switch.
