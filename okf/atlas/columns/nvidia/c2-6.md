## Answer

Covered. Requires a configured memory backend (Mem0, Redis or Zep plugin); retention and deletion depend on the backend.

Source statement: "The NeMo Agent Toolkit Memory subsystem is designed to store and retrieve a user's conversation history, preferences, and other "long-term memory."" (https://docs.nvidia.com/nemo/agent-toolkit/latest/build-workflows/memory.html)

Research detail: Long-term memory plugins for Mem0, Redis and Zep store conversation history and preferences, and auto_memory_agent saves and retrieves memory automatically.

<!-- chunk: products -->
## Products

Memory plugins (Mem0, Redis, Zep), auto_memory_agent

<!-- chunk: gaps -->
## Gaps

Retention and deletion are not covered and are left to the backend.

<!-- chunk: options -->
## Options

Set retention in the chosen backend and test deletion per user.
