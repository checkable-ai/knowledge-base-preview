## Answer

Not covered. No verified quote. Research cites the harness advisory, but the page could not be fetched.

Research detail: The Agentic AI harnesses advisory defines the harness as the layer that connects an LLM to tools, data, memory and planning, and lists its components: user interface, prompt and policy layer, context manager, model interface, tool registry, permission system, execution environment, connector layer, memory store, audit and update path. It recommends configuring the harness to prohibit unsafe actions, validate tool parameters and outputs, require approval for sensitive actions and read an organisational rules file each session.
