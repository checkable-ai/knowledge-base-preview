## Answer

Not covered. No verified quote for the mutual TLS guidance. The page could not be fetched.

Research detail: Careful adoption of agentic AI services recommends authenticating all inter-agent and agent-to-service API calls with mutual TLS, denying access to any agent or key not in a trusted registry, and message validation with integrity and freshness checks. It says a compromised agent can alter, replay or spoof messages between agentic components. The ISM has no control specific to agent to agent communication.
