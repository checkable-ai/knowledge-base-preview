## Answer

Not covered. ISM-2090 and ISM-2091 set rate and resource limits, and ISM-2103 and ISM-2112 govern data handling. No control requires recording or pinning the model version and endpoint each agent uses, or where it runs.

Research detail: ISM-2090 requires rate limiting on inference queries and ISM-2091 requires resource limits for AI models. ISM-2103 forbids using organisational data for training or fine-tuning without informed consent, and ISM-2112 disables external data access for classified AI applications. The harness advisory says the model interface connects to organisation-approved LLM services, and the register context suggests recording model versions.
