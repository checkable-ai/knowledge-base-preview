## Answer

Not covered. Code Interpreter sandbox and Customer Networking Mode limit files and network, but there is no documented single control to stop a running agent or cut all its access at once. Hosted applications default to public outbound internet access.

Research detail: The OCI Code Interpreter tool runs model-written Python in an isolated sandbox container with no external network access, and its files last only until the container expires. Hosted applications set egress for agent workloads, and Customer Networking Mode routes all outbound traffic through a customer VCN subnet where security groups, route tables and firewalls govern it. An application can be deleted, and IAM policies control access to Generative AI resources.

## Products

OCI Generative AI Code Interpreter, Hosted Applications with Customer Networking Mode, OCI IAM

<!-- chunk: gaps -->
## Gaps

Hosted applications default to outbound public internet access. No documented single control stops a running agent session or revokes all its access at once, and deleting the application is the only stop action listed.

<!-- chunk: options -->
## Options

Use Customer Networking Mode with egress rules, and test how quickly deleting an application or removing an IAM policy ends in-flight calls.
