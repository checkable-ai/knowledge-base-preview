## Answer

Not covered. No central tool gateway with per-agent policy, rate limits or dangerous action filtering.

Research detail: MCP allowed_tools and tool_choice limit tools per request. API endpoint calling tool traffic routes through a customer VCN subnet, and hosted applications in Customer Networking Mode use NSGs, route tables and firewalls for egress. Guardrails detect indirect prompt injection in retrieved content.

## Products

Responses API tools, Generative AI Agents API endpoint calling tool, OCI networking

## Gaps

No central tool gateway with per-agent policy, rates or dangerous action filtering. MCP calls from the Responses API go directly from OCI to the remote server.

<!-- chunk: options -->
## Options

Route tool traffic through a customer subnet with an egress proxy and test blocked tools.
