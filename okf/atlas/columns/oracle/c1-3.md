## Answer

Covered. Generative AI Agents API endpoint calling tool; set x-requires-approval on the OpenAPI operation (recommended for POST, PUT, PATCH, DELETE). Not shown for the Responses API.

Source statement: "Including the `x-requires-approval` header signals to Generative AI Agents that a confirmation must be requested from a human before executing the API endpoint in the agent tool call." (https://docs.oracle.com/en-us/iaas/Content/generative-ai-agents/api-calling-tool-guidelines.htm)

Research detail: In Generative AI Agents, adding the x-requires-approval header to an OpenAPI operation makes the agent request human confirmation before the call, raising a HumanApprovalRequiredAction step. Oracle recommends it for POST, PUT, PATCH and DELETE.

## Gaps

Binding of the approval to exact arguments, approver authority, denial and replay handling are not documented. The Responses API examples only show require_approval set to never.

## Options

Test that a modified request after approval is refused. Use function calling so the application enforces approval before running the action.
