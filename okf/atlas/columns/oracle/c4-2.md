## Answer

Not covered. Vault-held API keys in the API endpoint calling tool keep keys out of prompts, but there are no short-lived scoped agent credentials, rotation is manual (secret contents cannot be updated), and no statement that secrets never reach the model.

Research detail: The API endpoint calling tool reads API keys, basic, bearer and IDCS client secrets from OCI Vault secrets rather than from the prompt. For MCP calling, OCI states it does not decode, inspect, store or log the passed authorization token. Vault secret rules set expiry and block reuse, and Generative AI API keys carry two secrets with expiry, deactivation and revocation.

<!-- chunk: products -->
## Products

OCI Vault and Secret Management Service, Generative AI Agents API endpoint calling tool, Generative AI API keys

<!-- chunk: gaps -->
## Gaps

Secret rules state there is no mechanism to update secret contents, so rotation is manual. The MCP token is supplied by the caller per request, so the calling application handles it. No statement that secrets never reach model context.

<!-- chunk: options -->
## Options

Automate rotation with a function or pipeline that writes new secret versions. Test that tool credentials never appear in traces or responses.
