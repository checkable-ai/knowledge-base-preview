## Answer

Not covered. Hosted endpoints can validate identity domain tokens or IAM-signed requests from callers, but Oracle documents no agent-to-agent authentication or authorisation across trust boundaries. The page says it does not describe how scope and audience map to allowed actions.

Last checked 12 November 2026.

Research detail: Generative AI Agents can include another agent as a tool when the subagent has an active agent endpoint. Hosted applications authenticate inbound calls with OAuth 2.0 through an identity domain before routing to the deployment.

## Gaps

How the parent agent authenticates to the subagent endpoint and how authorisation is scoped between agents is not documented. No cross-tenancy trust boundary model.

<!-- chunk: options -->
## Options

Use IAM policies on genai-agent-endpoint chat permission and separate compartments per agent, then test cross-agent calls are refused without the grant.
