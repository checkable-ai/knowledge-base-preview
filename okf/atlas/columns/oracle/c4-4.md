## Answer

Not covered. Agent-as-tool exists but authentication and authorisation between agents are not documented.

Research detail: Generative AI Agents can include another agent as a tool when the subagent has an active agent endpoint. Hosted applications authenticate inbound calls with OAuth 2.0 through an identity domain before routing to the deployment.

## Products

Generative AI Agents agent tool, Hosted Applications OAuth

## Gaps

How the parent agent authenticates to the subagent endpoint and how authorisation is scoped between agents is not documented. No cross-tenancy trust boundary model.

## Options
