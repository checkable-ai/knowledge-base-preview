## Answer

Covered. Responses API (managed tool execution for Code Interpreter, File Search and remote MCP); function calls are run by the customer's application.

Source statement: "This approach is useful when you want to build agents quickly while keeping model execution, tool use, and supporting services OCI-managed." (https://docs.oracle.com/en-us/iaas/Content/generative-ai/agents.htm)

Research detail: The Responses API is a managed harness that calls remote MCP servers, runs Code Interpreter and File Search, and returns function calls for the application to run. Hosted applications run a customer's own agent harness as a container.
