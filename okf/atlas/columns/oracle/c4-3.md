## Answer

Not covered. No general on-behalf-of token exchange for MCP, function or API tools. App auth uses client credentials.

Research detail: Enterprise AI NL2SQL generates SQL and the Database Tools MCP Server runs it using the end user's identity through a lower-privileged query connection. Hosted applications use identity domain applications that the docs say support identity propagation. The documented app authentication flow uses OAuth client credentials only.

## Products

Enterprise AI NL2SQL with Database Tools MCP Server, OCI identity domains

## Gaps

No general on-behalf-of token exchange is documented for MCP, function or API endpoint tools. Client credentials carry the application identity, not the user.

<!-- chunk: options -->
## Options

Test whether downstream logs show the end user for NL2SQL queries. For other tools, pass user tokens through the MCP authorization field and validate them downstream.
