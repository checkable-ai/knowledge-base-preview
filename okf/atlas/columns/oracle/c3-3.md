## Answer

Not covered. Agent endpoint PII guardrails (English only) and Data Safe for databases help, but there is no per-agent or per-user retrieval filtering gateway for data access.

Research detail: Agent endpoint PII guardrails can block or inform on input and output. NL2SQL queries run with the end user's identity. Data Safe offers sensitive data discovery, masking and SQL Firewall allowlists for Oracle databases.

## Products

## Gaps
