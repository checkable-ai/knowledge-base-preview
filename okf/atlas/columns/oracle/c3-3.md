## Answer

Not covered. No control point filtering what data each agent and user can retrieve. PII guardrails at model endpoints block content but do not filter retrieval per agent or user.

Last checked 12 November 2026. This platform is checked on demand, so this answer has not been rechecked since.

Research detail: Agent endpoint PII guardrails can block or inform on input and output. NL2SQL queries run with the end user's identity. Data Safe offers sensitive data discovery, masking and SQL Firewall allowlists for Oracle databases.
