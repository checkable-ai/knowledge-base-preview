## Answer

Not covered. allowed_tools is caller-set per request, and IAM scoping covers OCI APIs only.

Research detail: MCP calling accepts allowed_tools to limit a remote server's tools, and tool_choice can restrict functions to an allowed list. The API endpoint calling tool limits actions to operations in the supplied OpenAPI schema. IAM conditions on the genaiagent principal limit which OCI resources an agent can reach, and NL2SQL uses a lower-privileged query connection.

## Products

Responses API allowed_tools, Generative AI Agents API endpoint calling tool, OCI IAM

## Gaps

allowed_tools is set per request by the caller, not enforced by an administrator. IAM scoping applies to OCI APIs, not to third-party systems.

<!-- chunk: options -->
## Options

Set allowed_tools centrally in the calling service and least-privilege credentials on each downstream system.
