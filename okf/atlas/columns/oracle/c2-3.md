## Answer

Covered. Hosted applications; Customer Networking Mode must be enabled to control egress.

Source statement: "After enabled, all outbound (egress) traffic from the agent is routed through the customer-specified subnet." (https://docs.oracle.com/en-us/iaas/Content/generative-ai/applications.htm)

Research detail: Code Interpreter containers are isolated with no external network access and expire after 20 minutes idle. Hosted applications default to public internet egress, but Customer Networking Mode routes traffic through a customer subnet where NSGs, route tables and firewalls govern egress, and endpoints can be private.

## Gaps

## Options
