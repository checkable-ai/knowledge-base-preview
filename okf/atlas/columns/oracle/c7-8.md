## Answer

Not covered. No document sanitisation before indexing. IAM isolation and Data Safe fall short for agent data governance.

Research detail: Vector stores, files and projects are IAM resource types and projects are isolated. Hosted application managed storage is accessible only to its application and deleted with it. Data Safe discovers and masks sensitive data in Oracle databases.
