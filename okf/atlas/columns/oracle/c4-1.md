## Answer

Not covered. No documented per-agent identity tied to an owner, runtime location and release. Hosted application resource principals and versioned deployments supply parts, but are not documented as one identity bound to owner and release.

Last checked 12 November 2026.

Research detail: Generative AI Agents act as a resource principal of type genaiagent, which IAM policies and dynamic groups match with request.principal.type or resource.type rules. Hosted agentic applications are each tied to a registered application in an OCI identity domain. Agents, endpoints and tools are OCI resources with OCIDs in a compartment.

<!-- chunk: products -->
## Products

OCI IAM resource principals and dynamic groups, OCI identity domain applications, Generative AI Agents

<!-- chunk: gaps -->
## Gaps

The genaiagent principal type is shared by every agent unless policies add compartment conditions. No documented link from an agent identity to an owner or a release version.

<!-- chunk: options -->
## Options

Place each agent in its own compartment and scope dynamic group rules by compartment OCID. Record owner and release in defined tags.
