## Answer

Covered. Session must be enabled when creating the agent endpoint (cannot be changed later).

Source statement: "You can set it as low as 1 hour and as high as 7 days." (https://docs.oracle.com/en-us/iaas/Content/generative-ai-agents/create-endpoint.htm)

Research detail: Agent endpoints can enable sessions with an idle timeout from 1 hour to 7 days, and sessions are an IAM resource type. The Conversations API keeps short-term memory within a conversation inside a project, with configurable conversation retention, and projects are isolated from each other.

## Products

Generative AI Agents sessions, Conversations API, Projects

## Gaps
