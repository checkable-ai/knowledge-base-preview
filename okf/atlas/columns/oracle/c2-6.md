## Answer

Covered. Long-term memory must be enabled on a project.

Source statement: "Long-term memory provides persistent context across conversations." (https://docs.oracle.com/en-us/iaas/Content/generative-ai/projects.htm)

Research detail: Long-term memory extracts key information from conversations and recalls it in later conversations in the same project. memory_subject_id shares memory across conversations and memory_access_policy controls read and write.
