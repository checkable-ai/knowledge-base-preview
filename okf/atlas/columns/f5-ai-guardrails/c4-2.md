## Answer

Not covered. Provider keys are stored as secrets and not returned by the API, but API tokens only document scopes (Personal, Organization, Project). Expiry, rotation, revocation behaviour and MCP Gateway tool credential handling are not documented.

Research detail: Providers store model API keys as secrets that the API never returns in plain form, and agents such as Claude Code call the proxy with an AI Security token instead of the provider key. This keeps upstream model keys out of the agent. Rotation, expiry and revocation of provider secrets or API tokens are not documented, and tool credentials through the MCP Gateway are not described.

## Gaps

## Options
