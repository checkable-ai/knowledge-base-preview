## Answer

Not covered. No sandbox for files, processes or network egress, and no kill switch or central revocation of a running agent. Tool allow/deny lists only act on gateway traffic.

Research detail: AI Guardrails inspects interactions at runtime and blocks prompt injection, jailbreaks and unauthorised tool calls and agent actions. The AI Gateway page describes an MCP server registry and per-tool allow and deny lists, access controls and budgets, with fail-closed enforcement. Deployment can be on-premises or air-gapped.

## Products

AI Guardrails agent and tool-use guardrails, AI Gateway MCP Gateway allow and deny lists.

<!-- chunk: gaps -->
## Gaps

No sandbox for agent code, no network egress control and no kill switch or central revocation of a running agent are described. Controls act on the traffic that passes through the gateway.

<!-- chunk: options -->
## Options

Combine with host sandboxing and an identity platform that can revoke agent credentials, and test whether a deny rule stops an in-flight session.
