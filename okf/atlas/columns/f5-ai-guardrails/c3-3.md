## Answer

Covered, with conditions. F5 AI Gateway was announced in August 2026 and is offered through an F5 AI Gateway Early Access sign-up. AI Guardrails policies, including redaction of personal and health information, run on the gateway. F5 AI Gateway supports SaaS, hybrid SaaS and hybrid multicloud deployments. Air-gapped support is planned.

Source statement: "Per-tool allow/deny and access controls ensure agents only reach tools they're explicitly authorized to use." (https://www.f5.com/company/blog/f5-ai-gateway-single-control-point-for-all-enterprise-ai)

Last checked 16 November 2026. This platform is checked on demand, so this answer has not been rechecked since.

Research detail: Guardrails detect PII, PCI and PHI in prompts and responses, with country PII packages and custom regex, keyword and GenAI guardrails applied per project. The gateway announcement says sensitive data is redacted. Retrieval authorisation per agent or user is not offered.
