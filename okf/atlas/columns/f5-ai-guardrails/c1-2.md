## Answer

Covered. MCP Gateway is part of the F5 AI Gateway announced in 2026. Granularity is per tool.

Source statement: "Per-tool allow/deny lists, access controls, and budgets ensure only authorized users and agents can invoke specific tools" (https://www.f5.com/products/ai-gateway)

Research detail: The AI Gateway MCP Gateway lists RBAC, per-tool allow and deny lists, budgets and quotas for agent tool access, and the announcement says it limits agents to resources they are explicitly authorised to use. AI Guardrails claims blocking of unauthorised tool calls. No public configuration documentation was found for either.
