## Answer

Not covered. F5 AI Guardrails documents audit logs and prompt history, but no write-once, immutable or integrity-validated storage, and no documented export of an agent action record to such storage. Nothing documented ties each agent action (tool calls, data access) to a specific agent and user or session in tamper-evident form.

Research detail: Audit logs record configuration changes to organisation, project, provider and user settings with the acting user and token. Prompt history records prompts, responses and outcomes, and fingerprints record system prompts, reasoning steps and tool calls. No tamper-proof or immutable storage is described.

## Products

## Gaps
