## Answer

Covered. Muse Code local memory only. No retention or access controls documented for memory.

Source statement: "Memory is Markdown you keep for the agent, so it recalls durable facts on its own." (https://dev.meta.ai/docs/muse-code/configuration.md)

Research detail: Muse Code keeps local memory in three scopes (personal project, committed project under .agents/memory, personal) as a MEMORY.md index plus topic files, recalled at session start. Memories saved on another device appear in a running session at the next turn.

## Products

Muse Code local memory

## Gaps

Committed project memory loads even in untrusted workspaces. No retention or access controls documented. Model API applications have no memory feature.

<!-- chunk: options -->
## Options

Review MEMORY.md on untrusted checkouts and keep project memory under code review.
