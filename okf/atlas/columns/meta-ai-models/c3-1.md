## Answer

Not covered. No gateway with per-agent or per-key routing, quotas or caps. Team-level rate limits and self-hosted Prompt Guard fall short.

Research detail: Rate limits apply per team across all keys, and spend control is an emailed monthly alert with no hard cap. Injection screening is available as self-hosted Prompt Guard 2 and LlamaFirewall. Meta's Llama security guide recommends an LLM security gateway but Meta does not ship one.

<!-- chunk: products -->
## Products

Model API team rate limits, spend alerts, Prompt Guard 2, LlamaFirewall

<!-- chunk: gaps -->
## Gaps

No per-key, per-user or per-agent quotas, routing or hard spend caps.

<!-- chunk: options -->
## Options

Front the API with a third-party model gateway for per-agent quotas and run Prompt Guard 2 in it.
