## Answer

Not covered. Session messaging is local and same-user only, with no authentication across trust boundaries or A2A support.

Research detail: Muse Code session messaging lets interactive sessions of the same user on one macOS or Linux machine message each other. Unverified senders trigger an admission prompt and message bodies are treated as data that cannot approve tools or change permissions. There is no cross-user or cross-machine transport.
