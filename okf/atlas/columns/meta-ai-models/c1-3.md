## Answer

Covered. Muse Code only. The default profile may use a model-based reviewer to pre-clear some requests.

Source statement: "If you reject one stage, Muse Code denies the entire command and runs nothing." (https://dev.meta.ai/docs/cookbook/staged-approvals.md)

Research detail: Muse Code splits compound commands into stages and pauses at the first unresolved stage, showing its argv. Approval can be once or a workspace prefix rule, rejecting any stage denies the whole command, and each review is journaled with the decision source. Intents carry idempotency keys and resumed interrupted effects are marked unknown for verification.

## Gaps
