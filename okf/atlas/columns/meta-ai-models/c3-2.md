## Answer

Not covered. No central gateway for tool calls. Per-session Muse Code approval rules and egress proxy fall short, and MCP tools bypass the sandbox.

Research detail: Muse Code mediates tool calls through approval policy, deny rules, a network egress proxy and protected paths. LlamaFirewall can block insecure code through CodeShield and audit agent reasoning for goal hijacking through AlignmentCheck. Neither is a central gateway across agents.

<!-- chunk: products -->
## Products

Muse Code approvals and network proxy, LlamaFirewall, CodeShield

<!-- chunk: gaps -->
## Gaps

MCP tools bypass the sandbox. LlamaFirewall policy is a per-role scanner map, AlignmentCheck needs a Together API key, and tool output scanning is not documented as a role.

<!-- chunk: options -->
## Options

Wrap agent tool calls with LlamaFirewall scans or a third-party tool gateway with per-agent allowlists.
