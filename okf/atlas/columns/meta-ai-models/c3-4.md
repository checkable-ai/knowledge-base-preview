## Answer

Covered. Local same-user Muse Code sessions on the same macOS or Linux machine only. No cross-machine support or custom schemas.

Source statement: "Messages contain plain text and can use up to 8,192 bytes." (https://dev.meta.ai/docs/muse-code/session-messaging)

Research detail: Muse Code session messaging enforces admission per sender with allow once, allow for session, reject or block for session, with 30-minute expiry and retry cooldown. Messages are capped at 8,192 bytes of plain text. It applies only to local sessions of one user.
