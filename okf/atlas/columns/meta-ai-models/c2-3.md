## Answer

Covered. Muse Code only. Flags can disable the sandbox. Hooks and MCP tools run outside it.

Source statement: "The policy grants write access to the workspace and a temp directory, and keeps the rest of the filesystem read-only." (https://dev.meta.ai/docs/muse-code/permissions.md)

Research detail: Muse Code runs shell commands under an OS sandbox (Seatbelt, bubblewrap, Windows sandbox) with workspace-only writes, a network proxy and a live probe that fails closed. The Linux sandbox drops all capabilities. The Model API offers no server-side code execution tool, so execution is local.

## Products

Muse Code sandbox

## Gaps

Not a container or VM. Hooks and MCP tools run outside it, and flags can disable it.

## Options
