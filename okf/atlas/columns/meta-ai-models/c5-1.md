## Answer

Not covered. Staged approvals in Muse Code have a person allow or reject shell command stages before they run. They do not send the finished agent output to a person for review. Read-only stages resolve automatically with no prompt, and --yolo disables approval.

Last checked 16 November 2026.

Research detail: Muse Code holds risky actions and writes to guardrail files for human review and lets users rewind to an earlier message. Review of ordinary file edits after the fact relies on the user's own diff or git review. The Model API has no output review queue.

<!-- chunk: products -->
## Products

Muse Code approvals, /rewind

<!-- chunk: gaps -->
## Gaps

No review workflow for generated output in API applications. Rewind does not revert workspace files.

<!-- chunk: options -->
## Options

Gate agent output through pull request review or an application review queue.
