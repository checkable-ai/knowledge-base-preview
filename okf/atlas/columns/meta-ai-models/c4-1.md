## Answer

Not covered. No agent object, registry or owner/release binding. API keys are team scoped.

Research detail: The Model API has no agent object. Keys are created per team in the dashboard and carry no agent, owner or release binding. Muse Code sessions get a canonical name and UUID for peer messaging, and exports embed the CLI version, but a session is not a stable agent or workload identity.
