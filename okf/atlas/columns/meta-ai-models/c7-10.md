## Answer

Not covered. CyberSecEval is an open-source benchmark suite for LLMs. It does not run authorised automated attack tests against a customer's retrieval pipeline, tools or deployed runtime.

Last checked 16 November 2026.

Research detail: CyberSecEval runs prompt injection, visual prompt injection, code interpreter abuse, MITRE compliance and autonomous uplift tests against hosted or custom model endpoints and writes JSON results. It tests the model, not a deployed agent's retrieval or tool boundaries.
