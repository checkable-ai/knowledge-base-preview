## Answer

Not covered. No documented retention periods, deletion controls or residency options for Meta Model API inputs, outputs or memory. Muse Code session_retention_days and --no-session-log cover local CLI session files only.

Research detail: Standard tier content is not used for training, contributor tier content is. ZDR for qualified organisations removes stored state, but Meta still keeps flagged content for up to 2 years plus usage and operational metadata. Stored responses can be soft deleted, Muse Code can run without a session log, and accounts can be deleted.

<!-- chunk: products -->
## Products

Standard and Contributor tiers, ZDR, Responses delete, --no-session-log

<!-- chunk: gaps -->
## Gaps

Retention periods and data residency are not stated. ZDR is by sales request. Residency is not configurable.

<!-- chunk: options -->
## Options

Negotiate ZDR and retention terms, and route sensitive traffic only to Standard tier.
