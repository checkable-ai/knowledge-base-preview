## Answer

Covered. Muse Code only. No hosted agent runtime for Model API apps.

Source statement: "Approval: before a tool call with side effects runs, the agent checks it against the approval policy." (https://dev.meta.ai/docs/muse-code/permissions.md)

Research detail: Muse Code is Meta's harness for Muse Spark, running interactively or headless in CI with tools, skills, hooks, MCP, subagents and workflows. It records an event-sourced log and enforces approvals and sandboxing. Headless runs can be capped with --max-model-steps.
