## Answer

Covered. Muse Code local sessions. Retention deletion works on macOS and Linux only. Unset keeps sessions forever.

Source statement: "Leave it unset to keep sessions forever." (https://dev.meta.ai/docs/muse-code/configuration.md)

Research detail: The Responses API stores responses by default and rebuilds conversations from previous_response_id, with soft delete by ID. Muse Code keeps an append-only session log per workspace with resume, compaction, rewind and a --no-session-log option. Access is by team key, and retention periods are not stated.

<!-- chunk: products -->
## Products

Responses API stored responses, Muse Code session log

<!-- chunk: gaps -->
## Gaps

No stated retention for stored responses or session logs. Any key on the team can read stored responses by ID. ZDR disables stateful requests.

<!-- chunk: options -->
## Options

Set store false and manage state client-side, or use separate teams per application to bound access.
