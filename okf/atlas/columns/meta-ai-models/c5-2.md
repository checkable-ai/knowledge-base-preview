## Answer

Partly covered. AlignmentCheck audits agent reasoning in real time and checks that agent decisions stay consistent with user intent. Through scan_replay it catches goal hijacking, misalignment or compromised behaviour across many interactions, which meets the continuous validation and anomaly-detection core of this monitoring control. Training agents on their tasks is the customer's own process, not a monitoring feature, and the vendor does not document it. That absence does not undo the documented monitoring capability.

Source statement: "A chain-of-thought auditing module that inspects the reasoning process of an LLM agent in real time." (https://github.com/meta-llama/PurpleLlama/tree/main/LlamaFirewall)

Last checked 16 November 2026.

Research detail: CyberSecEval benchmarks measure insecure code, prompt injection susceptibility, attack compliance and false refusal for any model endpoint. LlamaFirewall AlignmentCheck audits agent reasoning in real time for goal hijacking. Meta documents fine-tuning and RL for Muse Glimmer.
