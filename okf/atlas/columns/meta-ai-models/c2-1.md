## Answer

Covered. Muse Code workflows; availability may vary by build.

Source statement: "The resumed workflow evaluates the script from the top and reuses the longest unchanged prefix of completed child calls." (https://dev.meta.ai/docs/muse-code/workflows.md)

Research detail: Muse Code workflows run parallel groups and dependent stages with up to 1,000 child calls and 16 active children. Users can cancel, pause, skip or restart a running child, resume a revised script from a run ID reusing completed children, and recover after restart. Responses API background mode supports queueing and cancellation.

<!-- chunk: products -->
## Products

Muse Code workflows and subagents, Responses API background mode

<!-- chunk: gaps -->
## Gaps

Restart applies only to running children, not failed ones. Recovery needs a retained session. Workflows are missing from some builds.

<!-- chunk: options -->
## Options

Use a durable external orchestrator for production pipelines beyond a developer workstation.
