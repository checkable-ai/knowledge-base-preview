## Answer

Not covered. No documented short-lived, scoped, rotated or revocable agent credentials, and no guarantee secrets stay out of model context. Static API keys and MCP OAuth sign-in in Muse Code fall short.

Research detail: API keys are shown once, can be deleted in the dashboard and are team scoped. Muse Code signs in to remote MCP servers with OAuth 2.1 and stores and refreshes those tokens itself, and its transport trace and redacted exports scrub credential-shaped strings. Keys have no documented scopes, expiry or rotation feature.

<!-- chunk: products -->
## Products

Model API keys, Muse Code MCP OAuth (muse mcp login), muse export --redacted

<!-- chunk: gaps -->
## Gaps

No key scopes, expiry or automated rotation. Rotation is described only as a response to a leak. Not stated whether MCP tokens are kept out of model context.

<!-- chunk: options -->
## Options

Hold keys in a secrets manager with external rotation, one key per app. Test whether MCP OAuth tokens appear in session logs or prompts.
