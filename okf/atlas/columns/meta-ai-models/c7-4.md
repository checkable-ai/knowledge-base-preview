## Answer

Not covered. The commitments page describes Meta's corporate vulnerability management in general terms. It does not document hardening baselines or scanning of the hosts, containers or agent software that run models and tools. The Muse Code sandbox only confines shell commands.

Research detail: Muse Code verifies the sandbox is enforced with a live probe before running commands and fails closed, and runs background git checks inside the sandbox. Hosted inference runtime assurance is not documented beyond Data Security Terms referenced by the terms of service.
