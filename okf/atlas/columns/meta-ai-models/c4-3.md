## Answer

Not covered. No token exchange or on-behalf-of identity delegation. safety_identifier is attribution only.

Research detail: Meta AI Connectors have each user link their own account to a connected service through OAuth, so Meta AI calls the service with that user's authority. Muse Code MCP OAuth sign-in acts as the signed-in developer. The Model API safety_identifier attributes requests to an end user for enforcement only.

<!-- chunk: products -->
## Products

Meta AI Connectors (developer preview), Muse Code MCP OAuth, Responses API safety_identifier

<!-- chunk: gaps -->
## Gaps

Connectors are a limited developer preview for Meta AI, not a general agent feature. No token exchange or downstream propagation for Model API applications.

<!-- chunk: options -->
## Options

Build OBO token exchange in the application or an identity gateway. Use safety_identifier with a hashed user ID for attribution.
