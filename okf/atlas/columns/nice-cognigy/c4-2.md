## Answer

Not covered. Short-lived scoped credentials, rotation, expiry and revocation are not documented. Connections (Custom Header, OAuth 2.0 client credentials) are hidden from the model, which meets only the secrets-never-reach-the-model part. The vendor page does not say it covers part of the outcome.

Last checked 15 November 2026.

Research detail: Connections encrypt and store credentials for APIs, LLMs and other services, and Nodes reference them rather than holding secrets inline. MCP Tool and A2A Agent Nodes support OAuth2, with A2A also accepting bearer tokens, basic auth or API keys held as Connections.

## Products

Connections, MCP Tool Node, A2A Agent Node

## Gaps

Rotation and expiry are not described, and custom headers built with CognigyScript could expose values to Flow data.

<!-- chunk: options -->
## Options

Use OAuth2 Connections where offered and review custom headers for secrets.
