## Answer

Covered. The Profile object is long-term memory tied to a unique Contact Profile per user ID. Each profile holds up to 1.5 MB. Contact Profiles expire after 30 days by default. The AI Agent Node can inject the whole profile or selected fields.

Source statement: "the Contact Profile retains the data and retrieves it upon reconnection with the same user ID." (https://docs.cognigy.com/ai/agents/develop/ai-agent-memory/profile)

Last checked 15 November 2026.

Research detail: The Profile object is long-term memory tied to a Contact Profile and retrieved when the same user ID returns. The AI Agent Node can inject the whole profile or selected fields. Contact Profiles expire after 30 days by default.
