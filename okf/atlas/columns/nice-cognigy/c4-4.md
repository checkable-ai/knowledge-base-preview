## Answer

Covered. A2A Server Endpoint with API Key authentication. The URL token is always required. The API key header name is fixed. Authentication is per Endpoint, and per-skill authorisation is not documented.

Source statement: "The URL token embedded in the Endpoint URL is always required and can't be disabled." (https://docs.cognigy.com/ai/agents/deploy/endpoint-reference/a2a-server)

Last checked 15 November 2026.

Research detail: The A2A Agent Node calls a remote A2A agent with OAuth2, bearer token, basic auth or API key authentication, and can authenticate Agent Card discovery. The A2A Server Endpoint exposes a Flow to A2A clients over protocol versions 1.0 and 0.3 with API key authentication.

<!-- chunk: products -->
## Products

A2A Agent Node, A2A Server Endpoint

<!-- chunk: gaps -->
## Gaps

Inbound API key header name is fixed, and push notifications are not supported.

<!-- chunk: options -->
## Options

Use OAuth2 for outbound calls and restrict who holds the inbound endpoint key.
