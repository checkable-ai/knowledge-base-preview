## Answer

Not covered. Tool Choice None, call caps and timeouts exist, but no limits on files, processes or egress, and no single emergency stop. Stopping relies on editing a Flow, deleting a Snapshot or changing roles.

Research detail: Extensions run in an isolated environment per organisation with a 20-second default timeout, and the platform runs as containers on Kubernetes. MCP tool calls default to a 30-second timeout and the A2A endpoint is limited to 120 requests per 60 seconds. In the AI Agent Node, Tool Choice set to None stops tool use, Max autonomous calls per turn is capped at 1 to 10, and an error can stop Flow execution. Deleting a Snapshot used by a production Endpoint stops the AI agent.

## Products

Extension runtime isolation, AI Agent Node Tool Choice and call limits, Endpoint rate limits, Snapshots

<!-- chunk: gaps -->
## Gaps

No egress allowlist for SaaS and no single kill switch are documented. Stopping a running agent relies on editing a Flow, deleting a Snapshot or removing access through roles. Several limits are changeable only for on-premises installations.

## Options

Test whether deleting a Snapshot or setting Tool Choice to None ends an in-flight conversation, and ask NiCE for an Endpoint disable control.
