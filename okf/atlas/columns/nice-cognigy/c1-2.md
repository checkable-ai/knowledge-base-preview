## Answer

Covered. Each AI Agent job uses explicit Tool Nodes with defined parameters. A tool runs only when its condition is true. MCP and A2A tools can be filtered. Actual rights in the connected system still depend on the credential in the Connection.

Source statement: "Sets a condition that must be evaluated as true to activate the tool." (https://docs.cognigy.com/ai/agents/develop/node-reference/ai/ai-agent)

Research detail: Each AI Agent job is given explicit Tool Nodes with JSON Schema parameters. MCP Tool Nodes can whitelist or blacklist loaded tools and enable a tool only when a condition is true, and A2A Agent Nodes filter remote skills and cap autonomous calls per turn.
