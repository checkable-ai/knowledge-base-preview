## Answer

Covered. Session data is held in the Context object. The default session expiration is 30 minutes and an expired session restarts with the next user input. Session expiration is documented for messaging endpoints such as Facebook Messenger, Line, Slack, TwilioSMS, Azure Bot Services and WhatsApp, not voice. Access follows Project roles.

Source statement: "The default session expiration is set to 30 minutes." (https://docs.cognigy.com/ai/agents/deploy/endpoints/session-management)

Research detail: The Context object holds session data for the whole chat or call, and endpoints expire sessions after 30 minutes by default. The AI Agent Node includes up to 50 transcript turns.
