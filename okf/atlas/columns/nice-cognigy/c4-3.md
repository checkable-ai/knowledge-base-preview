## Answer

Not covered. Get Token Node supports Microsoft SSO for Azure Bot Service Endpoints only. The MCP Server Endpoint states user-level authentication is not supported. No general on-behalf-of propagation to tools.

Last checked 15 November 2026.

Research detail: The Get Token Node triggers Microsoft SSO for Azure Bot Services endpoints such as Teams, so a Flow can act with the signed-in user's token. The MCP Server Endpoint states that user-level authentication is not supported.
