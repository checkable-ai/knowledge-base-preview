## Answer

Covered. The AI Agent Node selects tools by Tool Choice (Auto, Required or None) and runs the branch under the chosen Tool, MCP Tool or A2A Agent Node. Which Tool Choice modes are available depends on the LLM provider. Results go back to the agent through a Resolve Tool Action Node at the end of the tool branch. The harness internals are managed by the vendor.

Source statement: "use a Resolve Tool Action Node at the end of a tool branch to return to the AI Agent after tool execution" (https://docs.cognigy.com/ai/agents/develop/node-reference/ai/ai-agent)

Last checked 15 November 2026.
