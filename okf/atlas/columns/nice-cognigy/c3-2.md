## Answer

Not covered. No central control point for all tool calls and internet access. Per-node tool conditions, MCP tool whitelist or blacklist and timeouts help a builder but do not enforce input formats or block dangerous actions across tool calls. No tool result screening is documented.

Research detail: MCP tools can be allowed or blocked by name and gated by a condition, tool calls have timeouts, and A2A calls are capped per turn. Outbound requests leave from published IP ranges so target systems can allowlist them.

## Products

## Gaps

No dangerous action filtering or injection screening of tool results. Cognigy only advises connecting to trusted MCP servers.

## Options
