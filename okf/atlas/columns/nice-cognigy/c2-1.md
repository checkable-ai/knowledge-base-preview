## Answer

Covered, with conditions. Fallback model is limited to one per main model. Fallbacks for embedding models are not supported. Fallback stays active for up to 30 minutes. HTTP Request Node timeouts default to 15 seconds in shared SaaS installations. They default to 8 seconds in dedicated SaaS and on-premises installations. Dedicated SaaS timeout increases require Cognigy technical support, up to 15 seconds. On-premises timeouts can be configured with HTTP_NODE_TIMEOUT_IN_SECONDS.

Source statement: "If all retry attempts are exhausted, it then switches to the fallback model." (https://docs.cognigy.com/ai/agents/develop/gen-ai-and-llms/fallback)

Last checked 15 November 2026.

Research detail: Flows sequence Nodes, the AI Agent Handover Node passes control between AI Agents, and A2A calls run blocking or non-blocking with task timeouts. LLM calls retry up to three times and then switch to a configured fallback model, and the AI Agent Node has a selectable error handling approach.
