<!-- chunk: answer -->
## Answer

Covered, with conditions. Enterprise, Preview, OAuth credential types only.

Source statement: "At runtime, n8n resolves the credential to the connected account of the user who triggers the workflow." (https://docs.n8n.io/administer/manage-credentials/end-user-credentials)

Research detail: End-user credentials resolve an OAuth credential template to the account of the user who triggers the workflow, for manual, Chat Hub, MCP Server Trigger and authenticated form and chat triggers. Token exchange (RFC 8693) lets an embedding partner act on behalf of a user, with an optional actor token. Both are Enterprise and in Preview.

<!-- chunk: products -->
## Products

End-user credentials, Token exchange

<!-- chunk: gaps -->
## Gaps

OAuth credential types only. Preview status, not recommended for production. Token exchange records scopes but does not enforce them.

<!-- chunk: options -->
## Options

Pilot end-user credentials on a non-production instance and test that executions by user A cannot use user B's connection.
