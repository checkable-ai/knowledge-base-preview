## Answer

Not covered. No documented control over where inference runs or how the provider handles prompt data. Chat model nodes only let a builder pick the model and set options such as token limits.

Research detail: Chat model sub-nodes name an explicit model and set maximum tokens, timeout, retries and temperature. The AI Agent Tool supports a fallback model. Data handling is set by the chosen model provider, not n8n.
