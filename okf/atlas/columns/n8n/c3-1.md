## Answer

Not covered. No gateway that every model call passes through enforcing per-agent, per-user or per-workload routing, quotas, cost and rate limits. Gateway credits are an instance-wide prepaid balance, and calls using your own credentials bypass it. The Guardrails node screens prompts per workflow only.

Last checked 17 November 2026.

Research detail: n8n has no model gateway for routing, quota or cost limits. The Guardrails node can screen input or output for jailbreak attempts and other violations before a model call, using an LLM-based check.
