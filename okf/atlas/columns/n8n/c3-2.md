## Answer

Not covered. No central gateway for tool calls. Node type policies and MCP tool filters do not enforce input formats, limits or internet access controls.

Last checked 17 November 2026.

Research detail: Tool reach can be limited by node blocking, MCP tool include and exclude filters, SSRF host and IP allowlists for egress, and human approval for tool calls.

## Products

NODES_EXCLUDE, MCP Client Tool filter, SSRF protection, Human-in-the-loop

## Gaps

No central tool policy, quotas, schema enforcement or injection screening on tool results. Controls are per instance or per node.
