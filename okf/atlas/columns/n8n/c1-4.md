## Answer

Covered, with conditions. Agents are in Preview. Self-hosted agents need n8n 2.32.3 or later. Self-hosted agents must run in regular mode, because queue mode isn't supported for agents yet. Project roles on self-hosted n8n require Registered Community, Business or Enterprise.

Source statement: "Users, channels, and schedules can no longer run the agent until you publish it again." (https://docs.n8n.io/build/build-and-manage-agents)

Last checked 17 November 2026.

Research detail: Agents are created and changed as workflows under project RBAC, with custom roles on Enterprise. Workflow reviews (Enterprise, Preview) can require approval before a version is published. Source control moves workflows between environments.

<!-- chunk: products -->
## Products

RBAC, Custom roles, Workflow reviews, Source control

<!-- chunk: gaps -->
## Gaps

Reviews do not cover credentials, settings or sub-workflows. No dedicated agent retirement process beyond archiving workflows.

<!-- chunk: options -->
## Options

Restrict publish rights to a release role and require reviews for agent workflows.
