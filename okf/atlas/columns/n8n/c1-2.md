## Answer

Covered. Approval channels include Chat, Slack, Discord, Telegram, Microsoft Teams, Gmail, WhatsApp Business Cloud, Google Chat and Outlook, each needing its own credentials.

Source statement: "HITL can be applied to all tools connected to an AI Agent node, or just selected individual tools." (https://docs.n8n.io/build/integrate-ai/ai-examples/human-in-the-loop-for-tools)

Last checked 17 November 2026.

Research detail: An agent can only use the tool nodes and credentials attached to it, and credentials are scoped by project RBAC. The MCP Client Tool can expose all, selected, or all-except tools from an MCP server. SSRF protection can restrict which hosts and IP ranges nodes can reach.

<!-- chunk: products -->
## Products

Project RBAC, MCP Client Tool tool filter, SSRF protection

<!-- chunk: gaps -->
## Gaps

Action scope within a connected system depends on the credential's own scopes. No per-agent policy layer over tool parameters. SSRF protection is off unless enabled.

<!-- chunk: options -->
## Options

Use least-privilege service credentials per project, filter MCP tools, and enable SSRF protection with an allowlist.
