## Answer

Covered, with conditions. Pruning by age (default 14 days) and count is configured by environment variables on self-hosted instances and workflow settings. Memory retention depends on the memory node chosen (Redis Chat Memory has a TTL; Simple Memory is in-process). Self-hosted customers choose data location; Cloud is hosted in a fixed region.

Source statement: "For performance reasons, pruning first marks targets for deletion, and then later permanently removes them." (https://docs.n8n.io/deploy/host-n8n/configure-n8n/scaling/manage-execution-data)

Research detail: Execution data is pruned by age (default 14 days) and count, and saving can be limited. n8n Cloud data is hosted in the EU.
