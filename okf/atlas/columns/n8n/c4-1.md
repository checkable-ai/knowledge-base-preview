## Answer

Not covered. No per-agent identity tied to an owner, runtime and release. Agents have only a name and icon, and belong to a project. Workflow IDs and publish versions are not an identity binding.

Last checked 17 November 2026.

Research detail: An n8n agent is an AI Agent node inside a workflow. The workflow has an ID, belongs to a project with role-based ownership, and has saved versions in workflow history. There is no separate agent or workload identity object linked to a runtime and release.

## Gaps

No dedicated agent identity, no workload credential issued to the agent, and full version history needs Enterprise.

## Options

Treat workflow ID plus project plus named version as the agent identifier and record it in an external registry.
