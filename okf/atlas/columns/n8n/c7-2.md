## Answer

Not covered. Log streaming (Enterprise) exports events and can mask user email and name, but it has no detections, no session linkage, no named response owner, and no redaction guarantee across all paths. It only supports building monitoring elsewhere.

Research detail: Log streaming sends audit, workflow and AI node events to syslog, webhook or Sentry, including login failures and execution data reveals.
