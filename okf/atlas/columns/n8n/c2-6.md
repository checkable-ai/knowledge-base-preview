## Answer

Covered, with conditions. Needs an external Redis server attached to the AI Agent node. Agents are in Preview. Self-hosted agents require n8n 2.32.3 or later. Self-hosted agents currently require regular mode because queue mode is unsupported.

Source statement: "Use this parameter to make the session expire after a given number of seconds." (https://docs.n8n.io/integrations/builtin/cluster-nodes/sub-nodes/n8n-nodes-langchain.memoryredischat/)

Last checked 17 November 2026.

Research detail: Postgres and other database chat memory nodes keep chat history in a table across executions, keyed by session.
