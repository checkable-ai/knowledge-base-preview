## Answer

Not covered. n8n has no control point that sits between agents and allows only approved agent pairs to talk in approved formats. The nearby feature is the workflow setting 'This workflow can be called by'. It limits which other workflows can run a sub-workflow, and Execute Workflow Trigger input fields set the shape of the data a sub-workflow takes. Both are controls on calling sub-workflows. n8n does not document them as controls for agent-to-agent traffic. They do not cover sub-agents inside one workflow (AI Agent Tool), and they do not cover agents that call each other over HTTP or MCP.

Research detail: Checked agent, MCP and security docs. There is no gateway that enforces which agents may call which other agents.
