## Answer

Covered, with conditions. Self-hosted only, using external mode task runners with the n8nio/runners sidecar image. Internal mode is deprecated from n8n 3.0 and is not recommended for production.

Source statement: "This sidecar container is independent from the n8n instance." (https://docs.n8n.io/deploy/host-n8n/configure-n8n/set-up-task-runners)

Last checked 17 November 2026.

Research detail: Code node execution runs in task runners. External mode runs a launcher and runners in a separate sidecar container with module and environment variable allowlists. Internal mode runs as a child process with access to n8n's database and keys and is deprecated from 3.0.
