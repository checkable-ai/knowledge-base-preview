## Answer

Not covered. No gateway that filters what each agent and user can retrieve. The Guardrails node checks only the text mapped into it for PII and secrets. It is a workflow node, not a data access control point, and the page says nothing about per-user filtering.

Last checked 17 November 2026.

Research detail: The Guardrails node can detect PII and secret keys and replace them with placeholders. Execution data redaction (Enterprise) hides node input and output in the execution viewer.

<!-- chunk: products -->
## Products

Guardrails node, Execution data redaction

<!-- chunk: gaps -->
## Gaps

Redaction affects viewing only, not downstream nodes or the database. No per-user retrieval policy.

<!-- chunk: options -->
## Options

Place Sanitize Text before model calls and enforce redaction instance-wide.
