## Answer

Not covered. NODES_EXCLUDE and task runners are instance-wide self-hosted settings, not per-agent limits on local actions. Internal runner mode is described as insecure by design.

Research detail: Self-hosted admins can block node types with NODES_EXCLUDE, and Execute Command is blocked by default. External task runners isolate Code node JavaScript and Python with module allowlists. The security audit flags nodes that touch the file system or run code on the host.

<!-- chunk: products -->
## Products

NODES_EXCLUDE, Task runners, Security audit

<!-- chunk: gaps -->
## Gaps

Controls are instance-wide, not per agent or workflow. Internal task runner mode gives code access to n8n secrets and is still possible.

<!-- chunk: options -->
## Options

Run external task runners, block Execute Command and Read/Write Files, and run n8n audit after changes.
