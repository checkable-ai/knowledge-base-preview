## Answer

Not covered. No scanning of tools, plugins or skills from public registries for look-alike names, poisoned descriptions or compromised packages. FIDES treating MCP metadata as untrusted falls short of registry scanning.

Research detail: Checked MCP, skills and FIDES pages. Docs advise vetting MCP servers and watching for typosquatted skill names, and FIDES stops MCP annotations from relaxing local policy, but there is no scanning for squatting, metadata poisoning or package compromise.
