## Answer

Covered. Work after the last checkpoint can repeat, so side effects must be idempotent. In Python, durable storage needs the file or Cosmos DB provider because in-memory storage is not durable. Go SDK is in public preview and has no functional workflows.

Source statement: "Checkpoints allow you to save the state of a workflow at specific points during its execution, and resume from those points later." (https://learn.microsoft.com/en-us/agent-framework/workflows/checkpoints)

Research detail: Graph and functional workflows provide sequential, concurrent, handoff, group chat and Magentic orchestrations. Checkpoints are written at each superstep and runs can resume or rehydrate from them, with in-memory, file and Cosmos DB storage. Foundry hosting adds resilient background recovery from the latest durable checkpoint.
