## Answer

Covered. Applies to Foundry-hosted agents using the default session stores (the Python hosting integration is prerelease). Custom store providers and self-hosted history, memory and checkpoints control their own retention. Residency follows the Foundry region chosen from the listed hosted-agent regions.

Source statement: "New default stores expire sessions 30 days after their last write." (https://learn.microsoft.com/en-us/agent-framework/hosting/foundry-hosted-agent)

Research detail: Hosted session stores expire sessions 30 days after last write and Foundry deletes inactive sessions after 30 days. A Responses request with store=false saves no host state. Purview logging supports Data Lifecycle Management.

<!-- chunk: products -->
## Products

Foundry hosted session stores, Responses store flag, Purview middleware

<!-- chunk: gaps -->
## Gaps

Self-hosted history, memory and checkpoint retention is left to the developer. Residency follows the chosen provider.

<!-- chunk: options -->
## Options

Set retention on each backing store and choose regions for model and storage resources.
