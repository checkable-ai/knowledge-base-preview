## Answer

Not covered. No per-agent governance of model version, endpoint, data handling location or limits. Explicit client endpoints and run-option token limits are configuration only, and docs place data handling responsibility on the customer.

Research detail: Model clients name an explicit provider endpoint and model deployment, and run options include output token limits. The .NET SDK has an experimental routing chat client to switch models per session. The safety page states the framework imposes no input, output or rate limits.

## Gaps
