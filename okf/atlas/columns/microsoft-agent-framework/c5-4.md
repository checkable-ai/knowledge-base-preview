## Answer

Covered. Applies to Foundry hosted agents, where the platform links Application Insights automatically. Outside Foundry, OpenTelemetry or Azure Monitor must be configured. No anomaly detection or load alerting is documented on these pages.

Source statement: "Review CPU, available memory, request rate, and average request duration over the time range you tested." (https://learn.microsoft.com/en-us/azure/foundry/agents/concepts/hosted-agents)

Research detail: The SDK emits operation and function invocation duration histograms and can configure Azure Monitor with live metrics. Foundry hosted agents expose CPU, memory, request rate and duration in Application Insights.

<!-- chunk: products -->
## Products

OpenTelemetry metrics, Azure Monitor, Application Insights

<!-- chunk: gaps -->
## Gaps

No built-in anomaly detection or load alerting in the framework.

<!-- chunk: options -->
## Options

Configure Azure Monitor alerts or another backend on the emitted metrics.
