## Answer

Covered. DockerShellTool is in the beta agent-framework-tools package and needs Docker or Podman. Hyperlight CodeAct is preview. Self-hosted harness hosts remain the developer's responsibility.

Source statement: "The defaults disable networking, run as a non-root user, use a read-only root filesystem, drop capabilities, limit memory to 512 MiB, and cap the container at 256 processes." (https://learn.microsoft.com/en-us/agent-framework/integrations/by-component/tools/shell-tools)

Research detail: Hyperlight CodeAct runs generated code in a hardware-virtualised sandbox with read-only input mounts and an outbound allow list. DockerShellTool isolates shell commands in an OCI container. Foundry hosted agents run in per-session VM-isolated sandboxes with optional customer VNet egress.

## Gaps

## Options
