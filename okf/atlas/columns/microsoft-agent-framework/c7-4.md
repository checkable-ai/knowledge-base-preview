## Answer

Not covered. No hardening or scanning of the hosts and containers that run tools. Runtime isolation (Hyperlight, DockerShellTool, Foundry sandboxes) limits blast radius but does not harden or scan hosts. No runtime attestation.

Research detail: Runtime isolation is available through Foundry per-session VM sandboxes, Hyperlight microVMs that restore a clean snapshot each run, and hardened DockerShellTool defaults. Checkpoint stores use a restricted unpickler to limit deserialisation risk.

<!-- chunk: products -->
## Products

Foundry Hosted Agents, Hyperlight CodeAct, DockerShellTool, restricted checkpoint unpickler

<!-- chunk: gaps -->
## Gaps

No runtime attestation or host scanning. Tool and harness hosts in self-hosted deployments are unmanaged.

<!-- chunk: options -->
## Options

Run on Foundry or a hardened container platform with image scanning and runtime security tooling.
