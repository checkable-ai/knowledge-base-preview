## Answer

Covered. Available in .NET, Python and Go. The Go SDK is in public preview; declarative agents, CodeAct and functional workflows are not implemented in Go.

Source statement: "Individual agents that use LLMs to process inputs, call tools and MCP servers, and generate responses." (https://learn.microsoft.com/en-us/agent-framework/overview/)

Research detail: The framework is the harness that runs the function-calling loop, with agent, chat and function middleware around each step. The Harness Agent adds planning, context compaction, file access, memory, tool approval and telemetry for long multi-step tasks.

<!-- chunk: products -->
## Products

Agent, Harness Agent, middleware pipeline

<!-- chunk: gaps -->
## Gaps

The Go harness is not packaged. Middleware ordering is developer-controlled.
