## Answer

Covered, with conditions. The Go SDK is in public preview. Declarative agents, CodeAct and functional workflows are not implemented in Go.

Source statement: "Since you now have a function that requires approval, the agent might respond with a request for approval instead of executing the function directly and returning the result." (https://learn.microsoft.com/en-us/agent-framework/agents/tools/tool-approval)

Last checked 15 November 2026.

Research detail: The framework is the harness that runs the function-calling loop, with agent, chat and function middleware around each step. The Harness Agent adds planning, context compaction, file access, memory, tool approval and telemetry for long multi-step tasks.

<!-- chunk: products -->
## Products

Agent, Harness Agent, middleware pipeline

<!-- chunk: gaps -->
## Gaps

The Go harness is not packaged. Middleware ordering is developer-controlled.

<!-- chunk: options -->
## Options
