## Answer

Covered. The application must build the review interface. There is no review queue or reviewer UI.

Source statement: "When a checkpoint is created, pending requests are also saved as part of the checkpoint state." (https://learn.microsoft.com/en-us/agent-framework/workflows/human-in-the-loop)

Research detail: Workflow executors can pause with request_info or a RequestPort and wait for a human response before continuing, and pending requests survive checkpoints. Handoff orchestration returns control to the user between turns.
