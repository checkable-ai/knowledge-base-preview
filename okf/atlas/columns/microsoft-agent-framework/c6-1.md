## Answer

Not covered. The SDK keeps no inventory of models, agents and tools. Foundry Toolbox bundles and hosted agent versions record only Foundry-managed items, not locally defined agents or tools.

Research detail: The SDK keeps no inventory. Foundry provides named, versioned Toolbox bundles of tool configuration and immutable hosted agent versions, and the observability page describes registering a custom agent in Foundry.

## Products

Foundry Toolbox, Foundry hosted agent versions

## Gaps
