<!-- chunk: answer -->
## Answer

Covered. Applies to agents deployed to Foundry Hosted Agents (hosting service GA, Python agent-framework-foundry-hosting integration is prerelease). Self-hosted agents get no identity from the SDK and rely on the host.

Source statement: "every deployed agent gets its own Entra identity for secure access to models, tools, and downstream services." (https://learn.microsoft.com/en-us/agent-framework/hosting/foundry-hosted-agent)

Research detail: The SDK gives agents an id and name that appear in OpenTelemetry spans, but has no identity of its own. When deployed through the Foundry hosting integration, each hosted agent gets a dedicated Microsoft Entra agent identity and endpoint at deploy time, and each version is an immutable snapshot of image and configuration.

<!-- chunk: products -->
## Products

Foundry Hosted Agents integration, gen_ai.agent.id telemetry attribute

<!-- chunk: gaps -->
## Gaps

Self-hosted agents have no workload identity beyond what the host supplies. No documented owner field linked to the identity.

<!-- chunk: options -->
## Options

Deploy to Foundry Hosted Agents for an Entra agent identity, or bind the agent id to a managed identity and an owner record in an external registry.
