## Answer

Covered. Agentic Access Management; supported environments such as AWS, Snowflake, Databricks, GitHub.

Source statement: "Each request runs on a short-lived, least-privilege identity." (https://www.oasis.security/agentic-access-management)

Research detail: Agentic Access Management turns each request into structured intent (resource, operation, scope, purpose) and applies deterministic policy, with examples such as read-only access to production databases and blocking destructive Databricks actions. Cyera Identity gives each task a short-lived scoped identity that expires when work is done and blocks risky actions such as mass exports. Supported environments include AWS, Google, Snowflake, Databricks, GitHub and Salesforce.
