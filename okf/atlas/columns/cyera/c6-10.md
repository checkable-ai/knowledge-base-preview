## Answer

Not covered. No retention, deletion or residency rules for agent inputs, outputs or memory; DSPM and Access Trail cover data stores generally.

Research detail: DSPM classifies data and can run within the customer's cloud or on-prem, with Privacy, Data Subject Request and data minimisation offerings. Access Trail enriches events with retention settings and Activity Tracking traces copies and derivatives of sensitive files made through AI. Governance of agent inputs, outputs and memory stores as a distinct scope is not described.
