## Answer

Not covered. No allow list for local commands, files or processes. Agent Guardian and Cyera Endpoint are data-centric and block risky actions only.

Research detail: Cyera Endpoint gives live visibility into sanctioned and shadow local agents, classifies and protects sensitive files before access or exit, and blocks data flowing to unauthorised personal AI accounts. Agent Guardian deploys through agent framework hooks for tools such as Claude Code and Cursor to block dangerous tool calls. Coverage is data-centric and does not define general command or filesystem permissions for the local host.
