## Answer

Not covered. No sandboxing of agent files, processes or network. Agent Guardian quarantine and blocking are nearby but the mechanism and revocation are not described.

Research detail: Cyera enforces policy on agent and AI activity at runtime. AI Firewall returns allow or block decisions, and Agent Guardian can block unsafe actions on risky tool calls and, per its product page, quarantine agents. Oasis Agentic Access Management issues short-lived, time-bound identities that are decommissioned when the task ends.

<!-- chunk: products -->
## Products

AI Runtime Protection (AI Firewall, Browser Shield, Omni DLP), Agent Guardian, Cyera Identity (Oasis Agentic Access Management)

<!-- chunk: gaps -->
## Gaps

Cyera does not run or sandbox agent code, so filesystem, process and network egress policy for the agent itself is out of its scope. The documentation does not describe how quarantine works, and the Oasis article describes no revocation call.

<!-- chunk: options -->
## Options

Pair Cyera with a runtime sandbox for the agent, and test in a pilot whether a quarantine action halts an in-flight agent session.
