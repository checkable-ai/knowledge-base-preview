## Answer

Not covered. No detection of unapproved AI tools or agents. Agent Console shows only coding agents with an integration set up, and no approval comparison is documented.

Research detail: Agent Console, in Preview, shows spend, users, sessions and detected problems for Claude Code, Cursor and GitHub Copilot alongside Bits agent activity, from logs and metrics those agents send. Cloud SIEM's Claude Compliance pack monitors activity in a sanctioned Anthropic organisation and IDE-SHEPHERD monitors VS Code and Cursor extensions. All of these depend on configured telemetry or integrations, and the docs do not claim discovery of agents that send none, so unsanctioned AI services are not discovered.
