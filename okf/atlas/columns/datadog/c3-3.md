## Answer

Not covered. No filtering of what data each agent or user can retrieve. AI Guard sensitive data scanning and redaction (manual SDK integration, Preview) and Sensitive Data Scanner on telemetry are DLP on content only, not retrieval authorisation.

Research detail: AI Guard sensitive data scanning can be set to scanning or scanning and redacting for PII and secrets in LLM conversations, and redaction requires manual SDK integration. Sensitive Data Scanner also redacts LLM trace data in the Datadog backend before indexing, which protects telemetry rather than the live request. There is no retrieval authorisation per agent or user.

AI Guard (Sensitive Data Protection), Sensitive Data Scanner

## Gaps

No retrieval policy enforcement. Inline redaction only through manual AI Guard integration in Preview.

## Options
