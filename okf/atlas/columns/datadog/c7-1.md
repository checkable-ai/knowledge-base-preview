## Answer

Not covered. No documented write-once or integrity-validated storage for agent action records, and no documented export of them to such storage. LLM Observability traces record tool calls but are retained for a limited period and are not described as tamper-evident. Audit Trail records platform configuration, access and billing events, not agent actions, and is not documented as immutable.

Research detail: LLM Observability traces record inputs, outputs, tool calls and spans per request, retained 15 days by default and up to 90 days with add-ons. Audit Trail records actions in the Datadog platform, including Datadog MCP Server tool calls, with archiving to cloud storage. Neither page claims tamper-proof storage.
