## Answer

Not covered. AI Guard Tool Protection and the tool blocklist block tool calls, but there is no input format or schema enforcement, no rate limits or quotas, and no internet egress control. It is an SDK-level check, not a gateway.

Research detail: AI Guard Tool Protection evaluates tool calls in context and can block them, and policies include a tool blocklist per service and environment. Datadog does not enforce tool schemas, tool auth configuration, quotas or internet egress.

<!-- chunk: products -->
## Products

AI Guard (Tool Protection, tool blocklist)

<!-- chunk: gaps -->
## Gaps

No schema validation, rate limiting or egress control. LLM-based judgement has false positive and negative risk, tuned by a sensitivity setting. Preview.

<!-- chunk: options -->
## Options

Use a tool or MCP gateway for allow-lists, schemas and egress, and add AI Guard as an inline screening step.
