## Answer

Out of scope. The stated product observes and guards the organisation's agents. It does not set up, re-permission or retire them. The objection relies on Bits Security Analyst, but turning that vendor feature on or off (which resets its settings) only configures Datadog's own feature. It is not a controlled lifecycle process for the organisation's agents. Bits Agent Builder can create custom agents, but it is not part of the stated platform.

Research detail: Datadog does not create, change or retire agent identities or permissions. Its RBAC covers access to Datadog data, not agent provisioning.
