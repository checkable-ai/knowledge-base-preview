## Answer

Not covered. Agent Monitoring and the AI Guard Discover page show observed tool use and agent interactions in instrumented traffic only. They do not show which downstream systems an agent can reach, nor its credentials, permissions or potential action scope.

Research detail: Agent Monitoring visualises tools used and handoffs between agents, and MCP client spans record the tool list each server returns and the server name. The AI Guard Discover page maps agents and services. These views show observed reach, not the full potential action scope.

<!-- chunk: products -->
## Products

Agent Monitoring, MCP client instrumentation, AI Guard Discover page

<!-- chunk: gaps -->
## Gaps

Only instrumented traffic is shown. Credentials and permissions behind tools are not shown.

<!-- chunk: options -->
## Options

Combine observed tool use with an inventory of credentials and permissions held by each agent.
