## Answer

Covered. Costs are estimates for text models from token counts and public pricing. Yield metrics (cost per line of code, impact) cover coding agents in Agent Console only. No labour cost or profit model.

Source statement: "Each tile shows a summary of that agent's activity, including total users, total spend, and cost per line of code." (https://docs.datadoghq.com/ai_agents_console/)

Research detail: LLM Observability estimates cost per request from token counts and public pricing for 800+ models, accepts manual costs, and lets span tags such as team be promoted onto cost metrics. Agent Console reports coding agent spend, cost per line of code and DORA-style impact metrics. Labour savings and profit are not modelled.
