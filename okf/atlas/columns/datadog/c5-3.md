## Answer

Partly covered. Infrastructure cost and staff-time cost set against what agents deliver. Agent Console (Preview) shows AI-tool spend against productivity for coding agents, and LLM Observability shows estimated model cost, but neither covers infrastructure or labour.

Source statement: "The Productivity section shows merged pull requests, time to merge, cost per observed pull request, and resolved Jira issues, plotted against AI cost." (https://docs.datadoghq.com/ai_agents_console/)

Last checked 15 November 2026.

Research detail: LLM Observability estimates cost per request from token counts and public pricing for 800+ models, accepts manual costs, and lets span tags such as team be promoted onto cost metrics. Agent Console reports coding agent spend, cost per line of code and DORA-style impact metrics. Labour savings and profit are not modelled.

## Products

LLM Observability cost monitoring, Agent Console

<!-- chunk: gaps -->
## Gaps

Costs are estimates for text models. Yield metrics cover coding agents only. No profit or labour cost model.

## Options
