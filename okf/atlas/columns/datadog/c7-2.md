## Answer

Covered. AI Guard in Limited Access/Preview; Bits Security Analyst unsupported on US government sites; content packs limited to Claude and IDE extensions.

Source statement: "AI Guard protects against prompt injection, jailbreaking, and sensitive data exfiltration attacks." (https://docs.datadoghq.com/security/ai_guard/)

Research detail: AI Guard generates security signals for prompt injection, jailbreak and tool misuse that are investigated in the App and API Protection or Cloud SIEM signals explorer and link to the AI Guard spans. Cloud SIEM adds a Claude Compliance content pack with detection rules over Anthropic Compliance API audit logs and an IDE-SHEPHERD pack for VS Code and Cursor extensions. Bits Security Analyst investigates eligible Cloud SIEM signals above medium severity, recommends a Benign or Suspicious verdict with evidence and the queries it ran, and lists Claude Compliance Logs among its sources. Response runs through workflows, cases and incidents.

<!-- chunk: products -->
## Products

AI Guard signals, Cloud SIEM, Claude Compliance and IDE-SHEPHERD content packs, Bits Security Analyst

<!-- chunk: gaps -->
## Gaps

No content packs for OpenAI, Bedrock, Azure OpenAI, Gemini or GitHub Copilot. Bits Security Analyst takes no autonomous response and is not supported on US government sites. AI Guard is in Limited Access or Preview.

<!-- chunk: options -->
## Options

Enable the Claude Compliance pack and Bits Security Analyst, and write custom detections for other AI provider audit logs.
