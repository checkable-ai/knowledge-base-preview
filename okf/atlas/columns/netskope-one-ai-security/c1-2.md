## Answer

Covered. Requires the AI Gateway virtual appliance for MCP Gateway. DLP and Agentic Broker may need extra licences. Agent Action Control is beta.

Source statement: "Allow or block traffic by server, tool, resource, prompt, activity type, or token group." (https://docs.netskope.com/en/mcp-gateway-overview/)

Research detail: Agentic Broker real-time protection policies can block specific MCP servers, all MCP traffic, or specific MCP activities such as CallToolRequest. MCP Gateway access control permits or blocks by server, tool, resource, prompt, activity or token group. Agent Action Control (beta) controls high-impact agent actions in 79 SaaS apps.

<!-- chunk: products -->
## Products

Agentic Broker RTP policies, MCP Gateway access control, Agent Action Control (beta)

<!-- chunk: gaps -->
## Gaps

Per-user or per-agent scoping for broker policies is not documented. Agent Action Control is beta and gives no full action catalogue.

## Options

Test policies per token group and per user against a pilot MCP server set and confirm Agent Action Control availability with Netskope.
