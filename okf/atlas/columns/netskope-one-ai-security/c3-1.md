## Answer

Covered. Requires the AI Gateway virtual appliance (AWS, GCP, Azure or ESXi). Quotas are by API calls or tokens, with no monetary budget.

Source statement: "You can limit traffic by the number of API calls or the number of tokens consumed." (https://docs.netskope.com/en/rate-limit/)

Research detail: AI Gateway sits between agents and LLMs with token-based authentication, rate limits by requests or tokens per token group, model and provider, and ordered policies for access control, threat protection, DLP and AI Guardrails including prompt injection. It runs as a VM on AWS, GCP, Azure or ESXi.

## Products

AI Gateway, AI Guardrails, Rate Limit

## Gaps

No cost or budget limits, only request and token counts. Routing logic beyond provider configuration is not described. Supported LLMs are OpenAI-compatible, Gemini and Claude.
