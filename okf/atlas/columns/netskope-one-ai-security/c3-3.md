## Answer

Covered. Traffic must be steered through the licensed AI Gateway appliance. DLP needs an additional licence.

Source statement: "Inspect tool call arguments, tool call results, and resource content before data reaches the wrong destination." (https://docs.netskope.com/en/mcp-gateway-overview/)

Research detail: DLP profiles such as PII or PCI apply to MCP CallToolRequest, CallToolResult, ReadResourceRequest and ReadResourceResult, and to AI Gateway prompts and responses. Blocked events are logged.

<!-- chunk: products -->
## Products

Agentic Broker DLP, MCP Gateway DLP, AI Gateway DLP

<!-- chunk: gaps -->
## Gaps

DLP needs a separate add-on licence. No per-agent retrieval entitlement is enforced. Response-side inspection behaviour is not explained.

<!-- chunk: options -->
## Options

Pair with a retrieval layer that enforces document permissions, and test DLP on tool results.
