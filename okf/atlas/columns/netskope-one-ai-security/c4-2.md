## Answer

Not covered. No documented short-lived, scoped, rotated or revocable agent credentials. Gateway-held provider keys and OAuth2 relay fall short.

Research detail: AI Gateway holds the upstream LLM API keys and issues its own tokens to callers, so applications do not hold provider keys. The MCP Gateway relays OAuth2 discovery and credentials transparently and says it does not store them.

<!-- chunk: products -->
## Products

AI Gateway (AI Provider List, Authentication Token and Group), MCP Gateway (OAuth2 transparent relay)

<!-- chunk: gaps -->
## Gaps

No documented token scoping, expiry, rotation or revocation for gateway tokens. Nothing keeps downstream credentials out of model context.

<!-- chunk: options -->
## Options

Pair with a secrets broker or vault for rotation and expiry, and test whether gateway tokens can be revoked per caller.
