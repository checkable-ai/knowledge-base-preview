## Answer

Not covered. Netskope documents AI Guardrails incidents in the console with user and conversation ID fields. The documentation checked does not tie AI Guardrails or agent events to Log Streaming or Cloud Exchange export. The Log Streaming data sets page lists seven generic data sets, none labelled AI, and does not mention redaction. Field-level filtering exists only for generic streams. No documented way to keep sensitive content out of exported AI events.

Research detail: Log Streaming exports Application Events, Alerts, Incidents and Transaction Events to SIEMs. MCP events carry user, client, server, tool and mcp_session_id, and guardrail detections map to MITRE ATLAS and OWASP Top 10 for LLMs.
