## Answer

Covered. MCP traffic only. Requires the AI Gateway appliance. DLP and Agentic Broker may need extra licences.

Source statement: "Apply per-server and per-token-group limits separately from LLM provider rate limits." (https://docs.netskope.com/en/mcp-gateway-overview/)

Research detail: MCP Gateway permits or blocks MCP traffic by server, tool, resource, prompt, activity or token group, rate limits per MCP server and token group, and runs DLP and AI Guardrails on tool arguments and results. Agentic Broker applies inline real-time protection policies to remote MCP traffic.

## Products
