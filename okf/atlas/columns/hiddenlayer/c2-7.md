## Answer

Not covered. No sandbox, file/process/network limits, session kill or access revocation. Nearby feature: gating of shell, MCP and file actions in coding agents.

Research detail: Agent Harness Security gates AI coding agents before prompts, tool calls, shell commands, MCP execution and file reads, and project policy can block the action, redact content or record it. Gates that fire after an action, such as after a shell command completes, only record findings.

## Gaps

HiddenLayer provides no sandbox or network egress control, and enforcement depends on the hooks each coding agent exposes. No documented control stops a whole running agent session or revokes its access.

<!-- chunk: options -->
## Options

Pair Agent Harness Security with the coding agent's own sandbox and egress settings, and test a block at the before-shell-execution gate for each supported agent.
