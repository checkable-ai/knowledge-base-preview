## Answer

Not covered. No allow-list or permission model for downstream systems, parameters or credentials. Nearby feature: tool-call screening and blocking of named tools, which relies on the application honouring the block.

Research detail: Agentic Runtime Security screens model tool calls in response-evaluations before the application runs the tool, and CEL detection rules can match tool_use content by tool_name with a Block action. This lets a policy deny named tools per project.
