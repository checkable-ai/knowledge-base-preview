## Answer

Covered. Model Intelligence not available for container scans; model signing not documented.

Source statement: "AIBOM provides an inventory of AI artifacts for every scanned model in an industry-standard SBOM format" (https://docs.hiddenlayer.ai/docs/products/supply-chain/aibom/overview)

Research detail: Model Scanner inspects model files for malware, code execution, backdoors, tampering and embedded payloads, including models inside containers. AIBOM exports an SBOM-format inventory per scanned model, and Model Intelligence reports family, architecture and ancestry from the computational graph.
