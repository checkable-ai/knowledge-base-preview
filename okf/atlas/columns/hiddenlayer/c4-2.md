## Answer

Not covered. No issuance, short-lived scoping, rotation or revocation of agent credentials is documented. Agent Harness Security secret redaction only limits what reaches the model. The Embedded Credentials remediation page covers credentials found in scanned models, not agent credential handling.

Last checked 17 November 2026. This platform is checked on demand, so this answer has not been rechecked since.

Research detail: No credential vault or brokerage is documented. Agent Harness Security can detect and redact secrets flowing into AI tool calls, which limits exposure but does not deliver, rotate or revoke credentials.
