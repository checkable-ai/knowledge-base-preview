## Answer

Covered. Agent Harness Security is available by request; supports Claude Code, Cursor and GitHub Copilot CLI; some gates (for example after shell execution) are visibility only.

Source statement: "HiddenLayer Agent Harness Security can gate AI coding agents at every risky step of a session." (https://docs.hiddenlayer.ai/docs/products/runtime/agent_harness/architecture)

Research detail: Agent Harness Security hooks into Claude Code, Cursor and GitHub Copilot CLI and evaluates prompt submission, tool calls, shell execution, MCP execution and file reads against the project policy, returning block, redact or detect. Enforcement depends on the gate, and several gates (for example after shell execution) are visibility only.

## Gaps

Decisions are driven by content detections and CEL rules rather than a declared permission scope model. Only three coding agents are supported. Access is by request through HiddenLayer.
