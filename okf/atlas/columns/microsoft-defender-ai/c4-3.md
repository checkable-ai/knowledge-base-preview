## Answer

Not covered. No propagation of the end user's identity or permissions to downstream systems. UserSecurityContext only enriches alerts.

Last checked 12 November 2026.

Research detail: Defender does not propagate user identity to downstream services. Applications can pass a UserSecurityContext with end-user ID, source IP and application name in Azure OpenAI calls, but this only enriches Defender alerts.
