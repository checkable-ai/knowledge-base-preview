## Answer

Not covered. No allowed-tool lists, input format checks, limits or egress allow-lists. Nearby feature: real-time protection blocking of risky tool calls.

Research detail: Real-time protection evaluates tool invocations before they run for Agent 365, Copilot Studio (preview) and Foundry (preview) agents, and custom rules block matching detection types for chosen agents, with a default rule that audits all agents. Defender for Endpoint blocks pre-tool calls and tool responses carrying prompt injection for supported local agents.
