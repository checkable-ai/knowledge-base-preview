## Answer

Not covered. No routing, quotas, cost or rate limits. Nearby features: network inspection for prompt injection and wallet attack alerts, which detect but do not enforce.

Research detail: Defender is not a model gateway and does no routing, quotas or rate limits. It screens model traffic for injection in two places: Defender for Endpoint network inspection inspects supported local agent to LLM flows for prompt injection in transit, and Defender for AI Services raises jailbreak alerts from Prompt Shields, which itself is part of Azure AI Content Safety. Wallet attack alerts detect request volume anomalies but do not enforce limits.

<!-- chunk: products -->
## Products

Defender for Endpoint network inspection, Defender for AI Services with Prompt Shields

<!-- chunk: gaps -->
## Gaps

No per-agent routing, quota or cost enforcement. Network inspection supports only listed agents such as OpenClaw.

<!-- chunk: options -->
## Options

Use Azure API Management or another AI gateway for routing and quotas, and pass UserSecurityContext so Defender alerts identify the caller.
