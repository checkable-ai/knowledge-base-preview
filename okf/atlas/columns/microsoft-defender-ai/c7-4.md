## Answer

Covered. Defender CSPM plan for container image and IaC scanning. Local agent runtime protection is preview and limited to listed agents.

Source statement: "Defender for Cloud can also discover vulnerabilities within generative AI library dependencies such as TensorFlow, PyTorch, and Langchain by scanning source code for Infrastructure as Code (IaC) misconfigurations and container images for vulnerabilities." (https://learn.microsoft.com/en-us/azure/defender-for-cloud/ai-security-posture)

Research detail: Defender for Endpoint runtime protection inspects local agent loops and can block prompt injection, with the setting covered by tamper protection. Defender for AI Services detects runtime threats to Azure AI deployments, Defender for Containers raises AI-relevant Kubernetes alerts, and Defender CSPM scans container images and IaC for AI workloads.
