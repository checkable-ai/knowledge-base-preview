## Answer

Covered. Anomaly alerts need Defender for AI Services on Azure OpenAI or Azure AI Model Inference deployments. Agent detections are preview and need Agent 365 observability data. Does not train agents or validate quality.

Source statement: "This alert analyzes anomalous activity from an AI application connected to an Azure OpenAI model deployment." (https://learn.microsoft.com/en-us/azure/defender-for-cloud/alerts-ai-workloads)

Research detail: Defender detects anomalous behaviour: access anomaly in AI resources, anomalous tool invocation by applications using Azure OpenAI, request volume anomalies and LLM reconnaissance, plus near-real-time agent detections from Agent 365 observability data. It does not do task training or continuous quality validation.
