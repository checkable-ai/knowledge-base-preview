## Answer

Covered. Agent threat detections are preview and need Agent 365 observability data. Azure AI threat protection supports commercial clouds only (not Azure Government or connected AWS accounts) and text tokens only.

Source statement: "Microsoft Defender correlates AI agent alerts into incidents and surfaces the related context so security teams can quickly assess impact and prioritize response." (https://learn.microsoft.com/en-us/defender-xdr/security-for-ai/ai-agent-detection-protection)

Research detail: Defender raises AI alerts for Azure AI deployments, Agent 365 agents and local agents, correlates them into Defender XDR incidents and exposes them in Advanced Hunting. Alerts can carry end-user ID, source IP and application name passed in UserSecurityContext, and prompt evidence is redacted for sensitive data and secrets.

## Products

Defender for AI Services, Defender XDR incidents and Advanced Hunting, Defender for Endpoint

## Gaps

Agent detections are preview. Text tokens only. Azure Government and connected AWS accounts are not supported for AI threat protection.
