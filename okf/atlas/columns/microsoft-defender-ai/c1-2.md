## Answer

Not covered. Rules select threat types, not permitted operations on connected systems. Nearby feature: real-time protection custom rules.

Research detail: Real-time protection evaluates Agent 365 tool invocations through Work IQ MCP, Copilot Studio tool invocations and Foundry requests and tool calls, and custom rules block selected detection types (secret exfiltration, malicious content propagation, evasion techniques, unsafe email domain) for chosen agents. Posture assessment flags privileged business-system access. Defender does not define which actions an agent may take on connected systems.
