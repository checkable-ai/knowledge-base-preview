## Answer

Covered, with conditions. Requires a Microsoft Defender for Endpoint Plan 2 license. Environment must be in the commercial cloud; sovereign and national clouds aren't supported. Devices must be onboarded to Defender for Endpoint, with Defender Antivirus in active mode and real-time protection enabled (except for VS Code extension inventory). Risk level, risk indicators and security recommendations need Microsoft 365 E7, or Microsoft Agent 365 together with Defender for Endpoint Plan 2. The macOS VS Code extension entries remain in preview.

Source statement: "Microsoft Defender discovers local AI agents and their configured MCP servers on onboarded devices." (https://learn.microsoft.com/en-us/defender-endpoint/local-agent-discovery-overview)

Research detail: Defender for Endpoint discovers local AI agents such as Claude Code, Cursor, ChatGPT Desktop and OpenClaw, and their MCP servers, on Windows and macOS with Plan 2. Defender for Cloud Apps flags untagged generative AI apps and blocks unsanctioned apps through Defender for Endpoint. Defender CSPM discovers AI workloads across Azure, Bedrock and Vertex AI.

## Products
