## Answer

Not covered. No definition of permitted commands, files or network access per agent. Nearby feature: Defender for Endpoint runtime protection (preview) blocks harmful tool actions by detection, not by an allow-list.

Research detail: Defender for Endpoint runtime protection (preview) inspects user prompts, pre-tool calls and post-tool responses for local agents such as Claude Code, Codex CLI and GitHub Copilot CLI through their hooks, and can block a requested tool action before it runs. Discovery also reports whether a local agent auto-approves its own actions. Blocking is driven by prompt injection and high-risk activity detection, not by an allow-list of permitted local actions.
