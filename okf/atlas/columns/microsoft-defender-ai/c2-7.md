## Answer

Not covered. No sandbox for files, processes or egress and no action to stop or disable a whole agent. Nearby feature: real-time protection blocking of risky actions.

Research detail: Defender real-time protection custom rules block matching user requests, model responses, tool requests and tool responses before they proceed for Agent 365 tools, Copilot Studio (preview) and Foundry (preview) agents. Defender for Endpoint runtime protection in block mode stops harmful local agent actions for Claude Code, Codex CLI and GitHub Copilot CLI through their event hooks, or by network inspection, and the setting is covered by tamper protection. Defender does not sandbox agent code or set filesystem and egress policy.

<!-- chunk: products -->
## Products

Microsoft Defender real-time protection for AI agents, Defender for Endpoint AI agent runtime protection

<!-- chunk: gaps -->
## Gaps

Blocking is detection driven for four threat scenarios, not an allow list or a stop control for a whole agent. The default rule audits only. Endpoint runtime protection is in preview, and network inspection does not support certificate pinning or HTTP/3. No Defender action to disable an agent or revoke its identity is documented on the pages read.

<!-- chunk: options -->
## Options

Switch high-confidence scenarios to block rules, pair Defender with Agent 365 block, Copilot Studio quarantine and Entra Agent ID disablement for a full kill path, and test block mode on a pilot device group.
