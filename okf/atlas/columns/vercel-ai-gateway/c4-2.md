How [Vercel AI Gateway](profile.md) addresses the [Credential Brokerage](../../controls/c4-2.md) control. Researcher verdict: escalated. Verification state: contested. Agents must not retrieve this page: escalated by the confirm agents, so a person settles it.

<!-- chunk: answer -->
## Answer

Escalated for a person to settle. The agent checks did not agree on this finding.

Research detail: Applications hold one AI Gateway credential and Vercel holds the provider keys, so provider secrets never reach the application or model. Deployed code can use short-lived OIDC tokens that Vercel rotates in under an hour. API keys can carry an expiry, can be revoked and are deactivated when their creator leaves. BYOK provider keys are stored by the gateway per team.

<!-- chunk: products -->
## Products

AI Gateway API keys, OIDC tokens, BYOK

<!-- chunk: gaps -->
## Gaps

API keys do not expire unless an expiry is set. No automated rotation of API keys is documented. Nothing addresses model context beyond the gateway holding the provider keys.

<!-- chunk: options -->
## Options

Prefer OIDC on Vercel deployments and set an expiry on every API key.
