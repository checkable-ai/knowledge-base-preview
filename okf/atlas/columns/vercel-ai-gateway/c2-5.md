## Answer

Not covered. AI Gateway is a model-access endpoint and does not run tools or pass tool results back to the agent. Tool execution happens in the client application, SDK or coding agent that points at the gateway base URL. The coding agents page only documents routing such harnesses through the gateway.

Last checked 17 November 2026.

Research detail: The gateway is not a harness. The coding agents page describes routing tools such as Claude Code and Codex through the gateway with a base URL change.
