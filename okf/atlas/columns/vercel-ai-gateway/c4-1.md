## Answer

Not covered. No agent identity record tied to an owner, a runtime and a release. The nearest features are named AI Gateway API keys (optionally scoped to a project, attributed to a team or member) and the project OIDC token. These identify a credential, team or project, not an individual agent or its release.

Research detail: Requests are identified by an AI Gateway API key (named, optionally scoped to a project and given an expiry) or by the OIDC token Vercel attaches to a project deployment. Request logs show which key, project, app token or personal access token authenticated each call. There is no agent identity with an owner, runtime and release.

## Products

AI Gateway API keys, project OIDC tokens

## Gaps

Identity is a credential tied to a team, project or member, not an agent record. Keys are deactivated when their creator leaves the team.
