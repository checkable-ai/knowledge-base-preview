## Answer

Not covered. No controlled lifecycle for agents. API keys can be created, scoped, given a budget or expiry and deleted, and budget changes are recorded with a reason in the activity log, but this manages credentials and spend limits, not agent set-up, permission changes or retirement.

Last checked 17 November 2026.

Research detail: API keys can be created in the dashboard, with the CLI or by API with a name, project scope and expiry, then viewed, deleted or revoked. Virtual models store a reusable model configuration that agents can call by name. Team roles and SAML sign-in control who can change them, and SAML adds new users automatically.

<!-- chunk: products -->
## Products

API keys, virtual models, team roles, SAML

<!-- chunk: gaps -->
## Gaps

Provisioning is for keys and model configurations and does not manage agent identities or retirement. Team roles are Pro and Enterprise, and Directory Sync is Enterprise.

<!-- chunk: options -->
## Options

Create keys and virtual models through the CLI in a reviewed pipeline.
