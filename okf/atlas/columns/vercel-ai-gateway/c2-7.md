## Answer

Not covered. No limits on an agent's files, processes or network access. Deleting an API key invalidates it immediately and budgets reject requests once exceeded, but these cut model access at the gateway only and are not documented as an agent emergency stop. A budget is a soft cap and routing rule and allowlist changes take a short time to propagate.

Last checked 17 November 2026.

Research detail: There is no sandbox. Access can be stopped at the gateway by revoking a key, by a budget that rejects requests once exceeded and by a routing rule that denies a model. Budget checks run before each request.

<!-- chunk: products -->
## Products

API key revocation, budgets, routing rule deny, allowlists

<!-- chunk: gaps -->
## Gaps

No filesystem, process or network containment is documented. Routing rule changes take a short time to propagate and in-flight requests finish under the old rule.

<!-- chunk: options -->
## Options

Issue a key per agent so a revoke or a zero budget acts as the stop switch.
