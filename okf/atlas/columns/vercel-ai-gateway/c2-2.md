## Answer

Covered, with conditions. Per-request region pinning is available on all plans. Team-wide region pinning needs a Pro or Enterprise plan (not a Pro trial) and costs $0.10 per 1,000 requests. Zero data retention needs a Pro or Enterprise plan or purchased AI Gateway credits, and team-wide ZDR costs $0.10 per 1,000 requests. Regions available are us, eu, au and jp, and not every model supports them. Image, video, speech, transcription and realtime models have no regional endpoints yet. Web search tools that AI Gateway runs are not region-pinned. Regional hosting is in beta.

Source statement: "If AI Gateway can't honor the chosen region, the request fails instead of silently running somewhere else." (https://vercel.com/docs/ai-gateway/security-and-compliance/regional-inference)

Last checked 17 November 2026.

Research detail: Models are named as creator and model, and provider order, an only filter and fallbacks set which endpoint serves each call. Teams or single requests can pin the inference region, require zero data retention or block prompt training. If the chosen region cannot be honoured the request fails rather than running elsewhere.

<!-- chunk: products -->
## Products

Models and providers, provider options, regional inference, ZDR, virtual models

<!-- chunk: gaps -->
## Gaps

The gateway routes to provider-hosted models and does not run them. Region pinning depends on the model and provider and tools that AI Gateway runs, such as web search, are an exception.

<!-- chunk: options -->
## Options

Pin region and ZDR in a virtual model so agents inherit them.
