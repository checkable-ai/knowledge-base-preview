## Answer

Out of scope. AI Gateway is a hosted endpoint for model requests. It cannot govern what an agent does on its own machine, such as reading files or running commands. That belongs to the agent harness and the operating system.

Last checked 17 November 2026.

Research detail: AI Gateway does not govern actions on an agent's local host. Coding agents are pointed at the gateway by changing a base URL and the gateway then controls their model access.
