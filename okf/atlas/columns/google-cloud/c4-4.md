## Answer

Covered, with conditions. Needs Agent Identity, Agent Gateway and access policies. A2A on Agent Runtime is preview.

Source statement: "UAPs control whether one or more agent principals can access one or more destination resources." (https://docs.cloud.google.com/gemini-enterprise-agent-platform/govern/policies/iam-overview-uap)

Last checked 17 November 2026.

Research detail: Agent Runtime hosts A2A agents that serve only an authenticated agent card, with every call carrying a bearer token. Agent Gateway carries A2A traffic, and IAM access policies bind agent principals to registered agents, with mTLS between agent and gateway. For agent-to-agent calls the parent agent identity needs Agent Registry viewer and Agent Platform user roles.

<!-- chunk: products -->
## Products

Agent Runtime A2A support, Agent Identity, Agent Gateway, Agent Registry

<!-- chunk: gaps -->
## Gaps

A2A on Agent Runtime is preview. Share an agent warns that Agent Runtime provides only coarse access control and A2A agents need their own authentication for untrusted callers. Trust boundaries across organisations are not described.

<!-- chunk: options -->
## Options

Expose A2A agents only through Agent Gateway with access policies per caller principal. Add caller checks in agent code for external callers.
