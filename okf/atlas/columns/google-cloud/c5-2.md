## Answer

Covered. Online monitors need Cloud Trace telemetry; Agent Anomaly Detection is preview and allowlisted.

Source statement: "Online monitoring lets you continuously assess the quality of your agents in production." (https://docs.cloud.google.com/gemini-enterprise-agent-platform/optimize/evaluation/evaluate-online)

Research detail: Online monitors sample live traces on a schedule, score them with predefined or custom metrics such as safety, and write results to Cloud Logging and Monitoring. Offline and simulated evaluation test agents before release. Agent Anomaly Detection analyses reasoning traces and tool interactions for tool misuse, privilege abuse, cascading failures, rogue agents and resource exhaustion, with findings in Security Command Center.
