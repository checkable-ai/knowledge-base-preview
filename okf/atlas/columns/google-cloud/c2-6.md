## Answer

Covered. Memory Bank; IAM Conditions limit access per scope.

Source statement: "Set a time to live (TTL) on memories to ensure stale information is automatically deleted." (https://docs.cloud.google.com/gemini-enterprise-agent-platform/scale/memory-bank)

Research detail: Memory Bank generates and stores memories that persist across sessions in isolated per-scope collections, typically per user. It supports TTL expiry, immutable revisions with rollback, and IAM Conditions to limit which principals read or write memories for a scope.

## Gaps

No built-in memory poisoning protection. The docs recommend Model Armor, red teaming and sandboxing.

## Options

Screen memory inputs with Model Armor and set TTLs on generated memories.
