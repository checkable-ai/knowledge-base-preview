## Answer

Covered. Most detections need Security Command Center Premium or Enterprise; Agent Platform Threat Detection is in Preview.

Source statement: "provides runtime threat detection for agents deployed to Agent Runtime." (https://docs.cloud.google.com/security-command-center/docs/ai-protection-overview)

Research detail: Security Command Center AI Protection reports Model Armor findings, Event Threat Detection for agentic identity abuse, and Agent Platform Threat Detection for running agents. Gateway logs carry trace IDs for correlation and Model Armor logs are redacted by Sensitive Data Protection settings.
