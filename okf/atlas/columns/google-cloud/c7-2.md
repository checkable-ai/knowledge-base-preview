## Answer

Not covered. Agent Platform Threat Detection generates Security Command Center findings, but there is no documented redaction of sensitive data in telemetry and no named response owner. Most detections need Security Command Center Premium or Enterprise, and Threat Detection is in Preview.

Last checked 17 November 2026.

Research detail: Security Command Center AI Protection reports Model Armor findings, Event Threat Detection for agentic identity abuse, and Agent Platform Threat Detection for running agents. Gateway logs carry trace IDs for correlation and Model Armor logs are redacted by Sensitive Data Protection settings.
