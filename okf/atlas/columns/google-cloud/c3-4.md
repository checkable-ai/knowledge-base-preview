## Answer

Covered. Requires Agent Gateway, Agent Registry and IAM policies; format enforcement limited (attribute parsing MCP only).

Source statement: "Unlike IAM allow policies and deny policies, each rule in a UAP can have both an allow effect and a deny effect." (https://docs.cloud.google.com/gemini-enterprise-agent-platform/govern/policies/iam-overview-uap)

Research detail: Agent Gateway carries A2A traffic and access policies bind calling agent principals to registered destination agents with allow and deny rules. Model Armor screens A2A Send Message operations and agent cards on egress.

<!-- chunk: products -->
## Products

Agent Gateway, IAM access policies, Agent Registry, Model Armor

<!-- chunk: gaps -->
## Gaps

Only MCP traffic gets attribute parsing, so A2A schemas and skills are not enforced. A2A streaming and gRPC are not sanitised.

<!-- chunk: options -->
## Options

Register each A2A agent and write per-pair access policies. Validate A2A payload schemas in a custom extension.
