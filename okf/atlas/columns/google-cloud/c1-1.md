## Answer

Covered. Applies to Agent Sandbox code execution; Managed Agents API is pre-GA.

Source statement: "The sandbox offers a limited file system and no network access." (https://docs.cloud.google.com/gemini-enterprise-agent-platform/scale/sandbox/code-execution-overview)

Research detail: Agent Sandbox runs untrusted code, shell and browser work in container-isolated sandboxes. Code execution sandboxes have a limited file system and no network access. Managed Agents run each agent in an isolated sandbox with network access off by default.

<!-- chunk: products -->
## Products

Agent Sandbox (code execution, computer use, shell), Managed Agents API

<!-- chunk: gaps -->
## Gaps

No per-action allow list for local commands or file paths. Sandbox isolation technology is not named. Managed Agents API is pre-GA and not for production data.

<!-- chunk: options -->
## Options

Run tool code in code execution sandboxes rather than the agent runtime. Use custom containers with only the needed binaries and VPC Service Controls for sandbox egress.
