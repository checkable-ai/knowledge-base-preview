## Answer

Covered. Gateway tracing is in preview. Alerting uses Cloud Monitoring alerts.

Source statement: "Built-in agent metrics are automatically collected and visualized in Cloud Monitoring pages in the Google Cloud console." (https://docs.cloud.google.com/gemini-enterprise-agent-platform/scale/runtime/monitoring)

Research detail: Agent Runtime exports request count, latency, CPU and memory metrics to Cloud Monitoring with alerting, and ADK telemetry adds generative AI metrics. Agent Gateway has an observability tab for request and failure rates with Cloud Trace. Agent Anomaly Detection flags resource exhaustion.

## Products

Cloud Monitoring, Agent Runtime metrics, Agent Gateway observability, Agent Anomaly Detection

## Gaps
