## Answer

Covered, with conditions. Alerting uses Cloud Monitoring alerts. Gateway tracing is in preview.

Source statement: "You can use the Agent Runtime Overview dashboard to monitor the operational health and performance of your agents." (https://docs.cloud.google.com/gemini-enterprise-agent-platform/scale/runtime/monitoring)

Last checked 17 November 2026.

Research detail: Agent Runtime exports request count, latency, CPU and memory metrics to Cloud Monitoring with alerting, and ADK telemetry adds generative AI metrics. Agent Gateway has an observability tab for request and failure rates with Cloud Trace. Agent Anomaly Detection flags resource exhaustion.

## Products

## Gaps
