## Answer

Not covered. No scanning of public-registry tools for look-alike names, poisoned descriptions or compromised packages is documented.

Research detail: External MCP servers are registered with an uploaded tool spec and the console lets an administrator choose which tools to include. Agent Gateway blocks unregistered destinations without a policy, and Model Armor screens tool call responses for injection.

## Products

Agent Registry, Agent Gateway, Model Armor

## Gaps

No scanning for squatting, tool metadata poisoning or package compromise. MCP tools/list responses pass without Model Armor sanitisation.
