## Answer

Covered, with conditions. Retry plugin is supported in ADK Python v1.16.0 and Go v0.5.0. Graph workflows need ADK 2.0 or later; graph retries and timeouts are experimental in ADK TypeScript, Java and Kotlin.

Source statement: "can help your agent recover from error responses from ADK Tools" (https://adk.dev/integrations/reflect-and-retry/)

Last checked 17 November 2026.

Research detail: ADK provides graph-based, dynamic, collaborative (coordinator with sub-agents) and template workflows with sequential, loop and parallel agents, plus experimental routing. Agent Runtime A2A agents expose get task and cancel task operations. Agent Runtime also offers autonomous agent scheduling.
