## Answer

Covered. Agent Registry automatically registers supported workloads in the governance project. Other components and external endpoints must be registered manually.

Source statement: "Agent Registry maintains the authoritative registry of agents, MCP servers, tools, skills, and external endpoints" (https://docs.cloud.google.com/agent-registry/overview)

Research detail: Agent Registry catalogues agents, MCP servers with tool specs, endpoints and skills, registering supported runtimes automatically. Model Registry tracks custom model versions, and AI Protection maintains an AI inventory.
