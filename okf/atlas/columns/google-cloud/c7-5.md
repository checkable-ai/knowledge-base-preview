## Answer

Not covered. Agent Registry scans uploaded skill packages only (LLM-based, with false positives and negatives). No SBOMs and no scanning or review of MCP servers, CLI tools, extensions, external services or egress.

Research detail: Skill Registry validates skill archives for path traversal, symbolic links, size and SKILL.md format. MCP servers can be protected with IAP, and Model Armor screens MCP tool call responses on the gateway.

<!-- chunk: products -->
## Products

Skill Registry payload validation, IAP for MCP servers, Model Armor
