## Answer

Covered. Per-user access via IAM Conditions; ListSessions does not support IAM conditions. Default lifetime 365 days if no TTL set.

Source statement: "The session and its child events are automatically deleted after the expiration time elapses." (https://docs.cloud.google.com/gemini-enterprise-agent-platform/scale/sessions/manage-with-api)

Research detail: Sessions store events and temporary state for a conversation, can be retrieved to resume a paused conversation and deleted when finished. IAM Conditions on the sessionUserId attribute with sessionViewer, sessionEditor and sessionUser roles restrict access per user.
