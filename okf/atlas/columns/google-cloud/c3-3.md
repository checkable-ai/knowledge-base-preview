## Answer

Not covered. No control point filters retrieved data per agent and user. Agent Gateway IAM policies and Model Armor scanning are destination-level control and payload scanning.

Research detail: Model Armor on Agent Gateway applies Sensitive Data Protection detectors to tool and model payloads and redacts content that violates only that detector. VPC Service Controls perimeters cover the Agent Platform API and Agent Registry. Retrieval access follows the IAM permissions granted to each agent principal.
