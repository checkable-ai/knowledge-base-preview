## Answer

Not covered. Observability covers model consumption, latency and token usage only. No staff time or cost-versus-value view is documented.

Last checked 17 November 2026.

Research detail: The observability dashboard shows input and output token usage by agent and model. Labels on generateContent and partner model calls flow to Cloud Billing reports and exports for cost breakdown by team, component or environment.
