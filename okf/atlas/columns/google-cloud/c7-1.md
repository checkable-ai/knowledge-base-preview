## Answer

Covered. Needs Agent Observability set up: ADK or OpenTelemetry telemetry, with prompt and response capture to Cloud Storage (Google's recommendation) or Cloud Logging. For tamper evidence, content must go to a locked log bucket or a Cloud Storage bucket with a locked retention policy; locking is irreversible. To attribute actions to a user, the user and session identifiers must be set up in telemetry.

Source statement: "A trace is a factual, immutable record of the agent's behavior, including model inputs, responses, and tool calls." (https://docs.cloud.google.com/gemini-enterprise-agent-platform/optimize/observability/traces)

Last checked 17 November 2026.

Research detail: Cloud Audit Logs entries are immutable, Admin Activity logs cannot be disabled, and the caller identity is recorded. Data Access logs for model endpoint use must be enabled. Agent Gateway logs allow and deny decisions with the MCP method and tool name, and request-response logging can sample full requests and responses to BigQuery.

<!-- chunk: products -->
## Products

Cloud Audit Logs, Agent Gateway logs, request-response logging

<!-- chunk: gaps -->
## Gaps

Agent Runtime logs only what agent code writes, and Cloud Logging does not cover Sessions or Memory Bank. Reasoning is not captured by a ledger. Request-response logging is preview and sampled.

<!-- chunk: options -->
## Options

Enable Data Access logs, route through Agent Gateway and export logs to a locked bucket.
