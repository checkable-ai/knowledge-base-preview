## Answer

Covered. Needs setup: Cloud Audit Logs with Data Access logs enabled, routed to a locked log bucket. Locking is irreversible. User or session attribution depends on identity setup.

Source statement: "To prevent anyone from updating or deleting a log bucket, lock the bucket." (https://docs.cloud.google.com/logging/docs/buckets)

Research detail: Cloud Audit Logs entries are immutable, Admin Activity logs cannot be disabled, and the caller identity is recorded. Data Access logs for model endpoint use must be enabled. Agent Gateway logs allow and deny decisions with the MCP method and tool name, and request-response logging can sample full requests and responses to BigQuery.

<!-- chunk: products -->
## Products

Cloud Audit Logs, Agent Gateway logs, request-response logging

<!-- chunk: gaps -->
## Gaps

Agent Runtime logs only what agent code writes, and Cloud Logging does not cover Sessions or Memory Bank. Reasoning is not captured by a ledger. Request-response logging is preview and sampled.

<!-- chunk: options -->
## Options

Enable Data Access logs, route through Agent Gateway and export logs to a locked bucket.
