## Answer

Covered. Private egress needs a Private Service Connect interface; otherwise Google-managed network.

Source statement: "Use security features including VPC-SC compliance and configuration of authentication and IAM." (https://docs.cloud.google.com/gemini-enterprise-agent-platform/build/runtime)

Research detail: Agent Runtime is a managed container runtime that deploys from images, Dockerfiles or packages, with VPC-SC compliance and Private Service Connect interfaces for private egress. Agents otherwise run in a Google-managed network without VPC access, and internet egress needs a proxy you configure. Agent Sandbox provides isolated code execution, computer use and shell environments.

<!-- chunk: products -->
## Products

Agent Runtime, Private Service Connect interface, VPC Service Controls, Agent Sandbox

<!-- chunk: gaps -->
## Gaps

Firewall rules for agent traffic are not described. Changing a PSC interface needs the agent recreated.

<!-- chunk: options -->
## Options

Deploy with a PSC interface and a proxy with Cloud NAT inside a VPC-SC perimeter for controlled egress.
