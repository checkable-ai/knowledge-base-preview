## Answer

Not covered. Model Registry manages versions, aliases, evaluation and deployment for ML models only (custom, AutoML, BigQuery ML). It has no proposal or approval stage, no retirement stage, and does not cover agents or use cases. Agent Runtime revisions are technical versioning only.

Last checked 17 November 2026.

Research detail: Agent Runtime revisions, evaluation and model retirement tables cover testing, release, change and retirement of agents and models. Model Registry aliases mark versions ready for production.
