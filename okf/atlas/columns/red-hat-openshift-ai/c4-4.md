## Answer

Not covered. AgentCard (discovery) and AgentRuntime sidecars are Developer Preview and wound down; no documented authorisation rules or trust boundaries between agents.

Research detail: A Developer Preview AgentCard resource is created for labelled agents and advertises their capabilities, endpoints and protocols for agent-to-agent discovery. The related AgentRuntime preview injects authentication sidecars into agent pods. Red Hat states it is no longer advancing Kagenti, which both features rely on.

## Products

AgentCard (Developer Preview), AgentRuntime authentication sidecars (Developer Preview)

## Gaps

Developer Preview, being wound down downstream. No documented authorisation rules between agents or trust boundary definitions.

## Options
