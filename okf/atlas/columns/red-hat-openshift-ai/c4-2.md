## Answer

Not covered. No documented per-agent scoped, short-lived credentials with automatic rotation and revocation. MaaS API keys and Technology Preview gateway credential injection fall short of the outcome.

Research detail: The Connectivity Link MCP gateway injects backend MCP server credentials from labelled Kubernetes Secrets referenced by credentialRef, or fetches per-user secrets from HashiCorp Vault through Authorino, so the agent does not hold them. Models-as-a-Service issues API keys that can be time limited and revoked individually. OGX takes provider keys only through SecretKeyRef and a Secret rotation triggers a rollout.

<!-- chunk: products -->
## Products

Connectivity Link MCP gateway with Authorino and Vault, Models-as-a-Service API keys, OGX SecretKeyRef handling

<!-- chunk: gaps -->
## Gaps

The MCP gateway is Technology Preview. No documented automatic rotation of backend credentials. AWS STS for Bedrock is Technology Preview.

<!-- chunk: options -->
## Options

Use Vault backed AuthPolicy for per-user tool credentials and set short MaaS key expiry. Test that a revoked key and an expired token are refused at the gateway.
