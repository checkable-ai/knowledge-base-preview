## Answer

Covered. The Responses API is generally available, but the Tool Runtime API and its MCP provider are Developer Preview and not supported in disconnected environments.

Source statement: "The Tool Runtime API allows a model to dynamically call a tool at runtime." (https://docs.redhat.com/en/documentation/red_hat_openshift_ai_self-managed/3.5/html/working_with_ogx/ogx-apis_rag)

Research detail: OGX executes tool calls for agents through the Responses API and a Tool Runtime API that lists a Model Context Protocol provider. Developer Preview starter kits deploy Claude Code and OpenClaw agents with tracing.

<!-- chunk: products -->
## Products

OGX Responses API, Tool Runtime API (Developer Preview), agent starter kits (Developer Preview)

<!-- chunk: gaps -->
## Gaps

Tool Runtime API and starter kits are Developer Preview. MCP tool authentication is not documented in the OGX security reference.

<!-- chunk: options -->
## Options

Route OGX tool calls through the MCP gateway so policy applies, and test a denied tool.
