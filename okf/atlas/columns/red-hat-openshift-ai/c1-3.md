## Answer

Covered. Developer Preview only (OGX agent Human-in-the-Loop), not for production. Only tools configured as HIL-enabled pause for approval. Approver identity depends on OGX authentication and ABAC. Handling of replayed approvals is not documented.

Source statement: "Tool calls pause until user approval is received for HIL-enabled tools." (https://docs.redhat.com/en/documentation/red_hat_openshift_ai_self-managed/3.5/html-single/release_notes/index)

Research detail: The 3.5 release notes list Human-in-the-Loop functionality in the OGX (formerly Llama Stack) agent as a Developer Preview. Calls to HIL-enabled tools pause until a user approves or rejects them through the Responses API, while other tools run without interruption.

## Products

OGX Human-in-the-Loop (Developer Preview)

## Gaps

Developer Preview only. No documented binding of the approval to exact arguments, approver authorisation, or replay handling.

<!-- chunk: options -->
## Options

Require approval on write tools and test that an approval cannot be reused for a changed call.
