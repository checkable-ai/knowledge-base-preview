## Answer

Not covered. Agent provisioning is preview only and no agent retirement workflow is documented; MCP Lifecycle Operator covers MCP servers, not agents.

Research detail: Agent onboarding is offered through Developer Previews: OpenShell Helm onboarding, AgentRuntime resources and saving Gen AI Studio configurations as reusable agents. MCP servers are created and retired through MCPServer resources managed by the MCP Lifecycle Operator (Technology Preview). OpenShift AI users and admin groups are managed through OpenShift groups.
