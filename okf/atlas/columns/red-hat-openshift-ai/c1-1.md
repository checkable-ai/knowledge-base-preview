## Answer

Not covered. OpenShell sandboxing is Developer Preview only; no documented per-action local allowlist for files, commands or tools.

Last checked 4 November 2026.

Research detail: OpenShell, a Developer Preview in 3.5, runs agents in isolated sandboxes with controlled network egress. The Claude Code starter kit (Developer Preview) runs under the restricted-v2 security context constraint. Project administrators can define custom Roles for project resources.

## Products

## Gaps

Agent sandboxing is Developer Preview only. No documented per-action local allowlist inside the sandbox.

## Options
