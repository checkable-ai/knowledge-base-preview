## Answer

Not covered. AgentRuntime SPIFFE identity is Developer Preview only, Kagenti is no longer advanced, and no documented tie of identity to an owner or release record.

Research detail: The 3.5 release notes list Agent deploy and runtime management as a Developer Preview. An AgentRuntime resource targets an agent Deployment and the operator injects authentication and SPIFFE identity sidecars plus per-agent OpenTelemetry settings. The same notes say Red Hat is no longer advancing Kagenti, which this feature is built on, and that OpenShell (also Developer Preview, with mTLS onboarding) is the downstream direction.

## Products

AgentRuntime (Developer Preview, Kagenti based), OpenShell agent sandboxing (Developer Preview)

## Gaps
