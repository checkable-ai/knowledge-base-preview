## Answer

Covered. Technology Preview only; Red Hat does not recommend production use. Requires the MCP gateway (Connectivity Link) with AuthPolicy, rate-limit resources and NeMo Guardrails configuration.

Source statement: "Integrate NeMo Guardrails with the MCP gateway to enforce guardrails on agent tool calls at the gateway layer." (https://docs.redhat.com/en/documentation/red_hat_openshift_ai_self-managed/3.5/html-single/enabling_ai_safety_with_guardrails/index)

Research detail: The Connectivity Link MCP gateway federates MCP servers behind one endpoint and applies AuthPolicy and rate-limiting resources. It authorises each tool call against user roles, filters tools/list, and injects backend credentials. NeMo Guardrails can enforce rails on agent tool calls at the gateway, and OpenShell (Developer Preview) controls agent egress.

<!-- chunk: products -->
## Products

Connectivity Link MCP gateway, NeMo Guardrails MCP integration, OpenShell (Developer Preview)

<!-- chunk: gaps -->
## Gaps

The gateway and the guardrails integration are Technology Preview, not for production. No rate limit configuration example and no schema validation are documented.

<!-- chunk: options -->
## Options

Deploy the gateway in front of all MCP servers and test a denied tool, a guardrail block and a rate limit breach.
