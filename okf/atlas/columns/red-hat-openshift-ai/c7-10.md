## Answer

Not covered. Garak red teaming covers model endpoints only. Retrieval and runtime testing are not documented, and MiDojo tool testing is Developer Preview.

Research detail: Automated Red Teaming with Garak is GA in 3.5. It tests a model endpoint or a model with external guardrails using generated harm prompts and escalating attack strategies, and records results in MLflow. MiDojo, a Developer Preview, injects attack payloads into agent tool traffic.
