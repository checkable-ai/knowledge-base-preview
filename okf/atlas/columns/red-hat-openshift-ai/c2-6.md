## Answer

Not covered. No long-term agent memory feature. The Conversations API (Technology Preview) stores conversations but is not cross-session memory.

Research detail: Conversations created with the OGX Conversations API persist server side until deleted, so later requests can continue a stored conversation. No separate long-term memory feature is documented.

## Products

## Gaps
