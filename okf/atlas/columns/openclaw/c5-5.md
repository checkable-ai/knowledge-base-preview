## Answer

Not covered. No view of which downstream systems each agent can reach and what it can do there. openclaw sandbox explain shows only sandbox mode, workspace access, Docker mounts, tool policy and elevated gates for one agent or session, and agents list --bindings shows message routing.

Research detail: Sandbox explain shows effective sandbox mode, mounts and tool policy for an agent or session, agents list with bindings shows routing, and the security audit and policy checks report exposure. There is no single graphical map of an agent's downstream reach.
