<!-- chunk: answer -->
## Answer

Partly covered. No rate limits per agent, user or workload are documented. The ClawRouter budget is policy-wide, not per user or agent, and OpenClaw's own model path only reports usage and does not screen prompts for injection.

Source statement: "ClawRouter checks current grants and budgets when a model request is dispatched." (https://docs.openclaw.ai/providers/clawrouter)

Last checked 17 November 2026.

Research detail: Each agent has its own model registry and auth profiles, and the Gateway rotates auth profiles and falls back across models. Provider quota and cost are tracked. There is no enforcement of per-user quotas or cost caps, and no injection screening at the model call boundary, in the pages read.

<!-- chunk: products -->
## Products

Per-agent model registry, auth profiles, model failover, usage tracking

<!-- chunk: gaps -->
## Gaps

OpenClaw is the agent's own gateway and not a shared model gateway. Quota and cost caps by user are not documented.

<!-- chunk: options -->
## Options

Put a model gateway in front of the providers when per-user quotas are needed.
