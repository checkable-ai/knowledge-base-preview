## Answer

Covered.

Source statement: "Eligible durable sessions archive in place with their identity and history intact." (https://docs.openclaw.ai/gateway/config-agents/sessions.md)

Last checked 17 November 2026.

Research detail: Each agent keeps its session store in a per-agent SQLite database. Session config sets how conversations map to sessions, reset rules, thread bindings, sharing and maintenance. DM session isolation separates users, and each A2A peer and context gets its own session.

<!-- chunk: products -->
## Products

Session store, session reset and maintenance config, DM session isolation

<!-- chunk: gaps -->
## Gaps

Sessions are routing selectors and not an authorisation boundary. Any process with filesystem access can read transcripts.

<!-- chunk: options -->
## Options

Set dmScope for multi-user use and tune reset and pruning to policy.
