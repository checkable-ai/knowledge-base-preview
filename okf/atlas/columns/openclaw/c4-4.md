## Answer

Covered.

Source statement: "Every JSON-RPC request requires a configured peer bearer token." (https://docs.openclaw.ai/channels/a2a.md)

Last checked 17 November 2026.

Research detail: The A2A plugin implements the A2A 1.0 JSON-RPC binding. External agents find the gateway through an Agent Card and submit tasks with a separate bearer token per trusted peer. Each peer and context ID pair gets its own session, and requests are rate limited per peer.

<!-- chunk: products -->
## Products

A2A channel plugin, tools.agentToAgent

<!-- chunk: gaps -->
## Gaps

Authentication is bearer tokens and tasks are text only. Inside one Gateway, agent-to-agent messaging is on by default across agents.

<!-- chunk: options -->
## Options

Set a distinct token per peer, limit exposeAgents and restrict tools.agentToAgent.allow.
