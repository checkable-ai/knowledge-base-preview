## Answer

Partly covered. The audit page does not describe detecting look-alike or typosquat names, and does not name compromised-package detection explicitly. It tells the user to review owner and source themselves.

Source statement: "ClawHub security audits help you decide whether a skill or plugin is safe enough to install." (https://docs.openclaw.ai/clawhub/security-audits)

Last checked 17 November 2026.

Research detail: ClawHub audits each published skill and plugin release with SkillSpector, A.I.G and a risk analysis, shows a status (Pass, Review, Warn, Malicious, Pending, Error) with findings, and supports reports, moderation holds and namespace claims. OpenClaw install commands apply trust and install policy, version pins and integrity checks, and skills can be verified against ClawHub.

## Gaps
