## Answer

Covered. Sandbox backends are Docker, Podman, SSH, OpenShell and Crabbox; throwaway cloud workers are also available.

Source statement: "OpenClaw can run tool execution inside a sandbox backend to limit the damage tools can cause." (https://docs.openclaw.ai/gateway/sandboxing.md)

Last checked 17 November 2026.

Research detail: The Gateway runs on the host and tool execution can move into Docker, Podman, SSH, OpenShell or Crabbox sandboxes, or onto throwaway cloud workers. A sandbox capability matrix compares shell, file, workspace, network and browser support per backend.

<!-- chunk: products -->
## Products

Sandbox backends, cloud workers, sandboxed browser

<!-- chunk: gaps -->
## Gaps

Sandboxing is off by default and the docs call it not a perfect boundary.

<!-- chunk: options -->
## Options

Enable sandboxing per agent and choose the backend with the isolation the deployment needs.
