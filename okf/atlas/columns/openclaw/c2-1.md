## Answer

Covered. Cloud workers are single-session throwaway machines, and Gateway-owned tools on them need the same-build worker-gateway-tools-v1 feature.

Source statement: "Credential rotation and owner-epoch fencing guarantee at most one live owner per session." (https://docs.openclaw.ai/gateway/cloud-workers/security-model.md)

Last checked 17 November 2026.

Research detail: OpenClaw schedules cron automations that keep running after the original chat ends, spawns sub-agents and sessions, and supports cloud worker turns with stop and reclaim. Cancelling a queued Gateway tool call prevents it from starting and a running tool keeps cooperative cancellation.

<!-- chunk: products -->
## Products

Automations (cron), sub-agents, session tools, cloud workers

<!-- chunk: gaps -->
## Gaps

A restart resume is treated as a new admitted input and interrupted turns are not restored from an identity token.

<!-- chunk: options -->
## Options

Test restart recovery and cancel behaviour before relying on long running automations.
