## Answer

Partly covered. No schema validation of agent-to-agent messages is documented. Agent-to-agent messaging is enabled by default for every agent pair inside one Gateway.

Source statement: "Every JSON-RPC request requires a configured peer bearer token." (https://docs.openclaw.ai/channels/a2a.md)

Last checked 17 November 2026.

Research detail: Agent-to-agent messaging inside a Gateway is on by default but can be turned off or limited to listed pairs with tools.agentToAgent, and per agent send-only rules can allow sessions_send alone. External A2A peers need their own token and are rate limited per peer.

## Products

tools.agentToAgent, per-agent send allow list, A2A peers

## Gaps

No schema validation of agent-to-agent messages is documented. The default allows every agent pair.

<!-- chunk: options -->
## Options

Set tools.agentToAgent.allow to the pairs needed and disable the default.
