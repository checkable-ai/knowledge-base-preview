## Answer

Covered. Full access mode requires the operator.admin scope; the other modes require operator.write.

Source statement: "Session permission modes set one session's filesystem boundary and exec escalation reviewer." (https://docs.openclaw.ai/gateway/permission-modes.md)

Last checked 17 November 2026.

Research detail: Session permission modes (read-only, guarded, workspace and full) set each session's filesystem boundary and who reviews exec escalation. Sandbox modes, tool allow and deny policy and exec approvals add further limits. Full access requires operator.admin.

<!-- chunk: products -->
## Products

Session permission modes, sandboxing, tool policy, exec approvals

<!-- chunk: gaps -->
## Gaps

The documented trusted single operator default allows host exec without approval prompts and sandboxing is off by default. Permission modes describe OpenClaw managed tools only.

<!-- chunk: options -->
## Options

Choose guarded or workspace mode as the default and turn on sandboxing for agents that handle untrusted content.
