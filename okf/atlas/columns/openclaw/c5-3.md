## Answer

Partly covered. Estimated cost is shown only for API key models. Labour cost, savings and output yield are not covered.

Source statement: "Pulls provider usage/quota directly from each provider's usage endpoint." (https://docs.openclaw.ai/concepts/usage-tracking.md)

Last checked 17 November 2026.

Research detail: Usage tracking pulls provider quota, balances and spend, shows per response token usage and a local cost summary from session logs, and OpenTelemetry metrics carry token and model data. Labour cost, savings and output yield are not covered.
