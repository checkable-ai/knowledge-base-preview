## Answer

Partly covered. No software bill of materials, no scanning of MCP servers beyond doctor and probe connection checks, and no review of external services or network egress. Dependency advisories never block CI or release verification.

Source statement: "The release has meaningful authority, such as account access or data changes." (https://docs.openclaw.ai/clawhub/security-audits.md)

Research detail: The project commits a lockfile as its dependency review boundary, runs CodeQL, secret scanning and a security review check in CI, and publishes GitHub security advisories with fixed versions. Saved MCP servers are checked by doctor and probe. No SBOM is documented.
