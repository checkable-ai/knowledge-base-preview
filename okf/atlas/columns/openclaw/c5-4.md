## Answer

Covered. Diagnostics are enabled by default. Metrics export through OpenTelemetry or Prometheus needs the diagnostics plugin and an exporter enabled. The page describes no built-in alerting.

Source statement: "Event-loop delay and utilization describe the main thread separately." (https://docs.openclaw.ai/gateway/health)

Last checked 17 November 2026.

Research detail: Gateway query commands report health, stability and connectivity, diagnostics bundles can be exported, and Prometheus and OpenTelemetry plugins export diagnostics and metrics. Load testing of the Control UI protocol is documented. Anomaly detection is left to the monitoring stack.
