## Answer

Partly covered. The docs describe per-process grants that are revoked on exit, cancellation or timeout, but not short-lived stored credentials or scheduled rotation of stored secrets. Store values are not encrypted at rest, and agent-readable environment entries are plaintext to the agent.

Source statement: "The value never enters the chat, the transcript, or the model's context, and the same automatic runtime refresh applies." (https://docs.openclaw.ai/gateway/secrets/secret-store-and-egress)

Last checked 17 November 2026.

Research detail: A shared secret store holds protected secrets that are write-only after saving and are never injected into subprocess environments by default. SecretRef config fields point at the store or external providers, and a default-off egress proxy can hand exec commands sentinels in place of real values. Device and gateway tokens can be rotated and revoked.

<!-- chunk: products -->
## Products

Shared secret store, SecretRef, secret egress proxy, device pairing token rotation

<!-- chunk: gaps -->
## Gaps

The egress proxy is off by default. Agent-readable environment entries are plaintext to the agent. Transcripts and tool results keep any credentials that appear in them.

<!-- chunk: options -->
## Options

Store keys as protected secrets, enable the egress proxy for destinations that need it and keep secrets out of the agent workspace.
