## Answer

Covered.

Source statement: "gateway validation rejects caller edits to command/cwd/session context after the approval request was created." (https://docs.openclaw.ai/gateway/security/tool-permissions.md)

Research detail: Exec approvals let an operator allow once, allow always or deny a pending request, with request ids, expiry and attribution to agent and session. Gateway approval-backed commands bind the resolved executables before review and re-check them before launch. Standing grants can be listed, expired and revoked.

<!-- chunk: products -->
## Products

Exec approvals, openclaw approvals, standing grants, plugin approvals

<!-- chunk: gaps -->
## Gaps

Approvals are guardrails for operator intent and do not model every interpreter path. The trusted single operator default has no prompts. Allow always grants persist until revoked unless an expiry is set.

<!-- chunk: options -->
## Options

Use guarded mode, set grant expiry and review standing grants regularly.
