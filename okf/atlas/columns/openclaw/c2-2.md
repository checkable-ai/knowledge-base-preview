## Answer

Covered.

Source statement: "Per-agent model entries take precedence over global entries and configured provider catalogs." (https://docs.openclaw.ai/concepts/models)

Research detail: Models are provider plugins and can be swapped, including local models, and prompts go only to the providers configured. Each agent has its own model registry and the docs recommend model choice as a first prompt injection layer. Usage and quota are read from each provider.

<!-- chunk: products -->
## Products

Model providers, per-agent model registry, usage tracking

<!-- chunk: gaps -->
## Gaps

Version pinning, endpoint data handling and operating limits are those of the chosen provider. No enforced per-model quota is documented in the pages read.

<!-- chunk: options -->
## Options

Record the provider, model and region per agent and pin model refs in config.
