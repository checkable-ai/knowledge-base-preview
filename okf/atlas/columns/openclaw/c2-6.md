## Answer

Covered.

Source statement: "The model only remembers what gets saved to disk; there is no hidden state." (https://docs.openclaw.ai/concepts/memory.md)

Last checked 17 November 2026.

Research detail: Long term memory is written to plain Markdown files in the agent workspace with an optional dreaming sweep, and there is no hidden state. Session-derived memories carry source lineage, and memory forget removes tracked entries and artifacts and blocks later re-ingestion of the forgotten sessions.

<!-- chunk: products -->
## Products

Memory (MEMORY.md, daily notes), dreaming, memory provenance and forget

<!-- chunk: gaps -->
## Gaps

Forget does not delete original session transcripts, every freeform edit or copies outside scanned stores. Other memory plugins may behave differently.

<!-- chunk: options -->
## Options

Run memory forget with dry-run before sensitive deletions and set memory admission policy.
