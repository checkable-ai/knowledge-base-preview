## Answer

Partly covered. No built-in detections and no named owner for response. Session linkage depends on enabling content capture, which sends prompts and tool data to the collector.

Source statement: "Raw model/tool content is not exported by default." (https://docs.openclaw.ai/gateway/opentelemetry/privacy-and-trace-context.md)

Last checked 17 November 2026.

Research detail: OpenTelemetry export covers traces, metrics and logs with spans for runs, model calls and tool execution. Raw content is not exported by default and session identity is added only when captureContent is enabled. W3C trace context can be continued from an upstream client. Detections and response ownership are not provided.
