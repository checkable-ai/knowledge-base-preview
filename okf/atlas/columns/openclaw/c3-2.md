## Answer

Covered.

Source statement: "Tool allow/deny policies still apply before sandbox rules." (https://docs.openclaw.ai/gateway/sandboxing.md)

Last checked 17 November 2026.

Research detail: Tool policy applies allow and deny layers per global, agent and sandbox scope before any sandbox rule. High risk tools can be limited to trusted agents, interpreter inline eval needs approval, and web fetch and browser tools are bounded by a strict SSRF policy. Untrusted content is wrapped and tool authority stays with the Gateway for cloud workers.

<!-- chunk: products -->
## Products

Tool policy, exec approvals, browser SSRF policy, untrusted input wrapping, rate limiting

<!-- chunk: gaps -->
## Gaps

Prompt injection screening is by wrapping and model choice, not a classifier. Per tool quotas are not documented in the pages read.

<!-- chunk: options -->
## Options

Deny high risk tools by default for agents that read untrusted content and use a reader agent for summaries.
