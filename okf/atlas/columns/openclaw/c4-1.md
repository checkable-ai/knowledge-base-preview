## Answer

Partly covered. An agent identity is not tied to a named owner or to a release. Execution identity records (run attribution kept 30 days) are off by default and need logging.audit.enabled and logging.audit.executionIdentity.

Source statement: "An **agent** is the full per-persona scope: workspace files, auth profiles, model registry, and session store." (https://docs.openclaw.ai/concepts/multi-agent.md)

Research detail: Each OpenClaw agent has an ID and its own workspace, state directory, auth profiles, model registry and session store, and reserved system-agent IDs are protected. Opt-in execution identity records attribute each admitted run for 30 days. There is no documented link from an agent identity to a named owner and a release.

## Products

Agents (agents.entries), execution identity audit context, bindings

<!-- chunk: gaps -->
## Gaps

Execution identity recording is off by default. Owner and release are not fields of the agent identity.

<!-- chunk: options -->
## Options

Turn on logging.audit.executionIdentity and keep an external register mapping agent IDs to owners and versions.
