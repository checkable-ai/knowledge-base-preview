## Answer

Covered, with conditions. Applies to the OpenClaw Enterprise control plane, where IAM checks every resource operation. The open source Gateway alone offers the agents CLI and config RPC with operator scopes.

Source statement: "No Agent revision is created and no workload or model starts until an authorized caller requests deployment." (https://docs-enterprise.openclaw.org/reference/agents/)

Last checked 17 November 2026.

Research detail: Operators create, bind and delete agents with the agents CLI and the Gateway config RPC. High-risk changes need operator.admin and the openclaw delegation tool needs human approval for restricted defaults. Device and node pairing is approved, rotated and revoked by an operator.

<!-- chunk: products -->
## Products

openclaw agents, config RPC, operator scopes, pairing, openclaw delegation tool

<!-- chunk: gaps -->
## Gaps

No approval workflow, versioning or retirement review for agent definitions is documented beyond operator authority.

<!-- chunk: options -->
## Options

Keep agent and policy config in version control and review changes before apply.
