## Answer

Covered, with conditions. Model Runtime endpoints are part of Private AI Services on VMware Cloud Foundation and are deployed on vSphere Kubernetes Service in the customer's own environment. The matching model endpoint must already be deployed in the same namespace as the PAIS instance. NVIDIA AI Enterprise is separately licensed when using NVIDIA NIMs or vGPU.

Source statement: "ID of the model to be used by the agent for generating completions." (https://developer.broadcom.com/xapis/vmware-private-ai-service-api/latest/api/v1/compatibility/openai/v1/agents/post/)

Last checked 16 November 2026.

Research detail: Model Runtime runs completion and embedding models as endpoints with vLLM, Infinity or llama.cpp, from a model URL in the Harbor gallery, with an OpenAI-compatible API. Each model push is an immutable revision with a digest. The design notes say inference traffic for managed endpoints does not leave the namespace, and cloud models send prompts outside the environment.

## Products

## Gaps
