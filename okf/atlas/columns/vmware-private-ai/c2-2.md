## Answer

Covered. Model endpoints run as Kubernetes resources in a namespace on GPU or CPU VMs; models come from the Model Gallery. Cloud-hosted models send prompts outside the environment.

Source statement: "Identifies the model in API calls." (https://techdocs.broadcom.com/us/en/vmware-cis/private-ai/foundation-with-nvidia/9-0/private-ai-foundation-9-x/what-is-private-ai-services/deploying-model-endpoints.html)

Research detail: Model Runtime runs completion and embedding models as endpoints with vLLM, Infinity or llama.cpp, from a model URL in the Harbor gallery, with an OpenAI-compatible API. Each model push is an immutable revision with a digest. The design notes say inference traffic for managed endpoints does not leave the namespace, and cloud models send prompts outside the environment.

## Products

Model Runtime, Model Gallery, InferenceGatewayRoute
