## Answer

Not covered. No feature sets which files, commands or local tools an agent may use. Pod Security Standards and container isolation restrict pod privileges, not agent actions.

Last checked 16 November 2026. This platform is checked on demand, so this answer has not been rechecked since.

Research detail: Agent Builder agents run as a managed service in a Supervisor namespace and act only through model calls, knowledge base retrieval and approved MCP tools. They do not execute code or commands on a local host.
