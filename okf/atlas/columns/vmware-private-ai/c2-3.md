## Answer

Covered, with conditions. Execution isolation uses VMware Cloud Foundation 9.1 virtual machines or containers. VMware vDefend is separately licensed for network-security enforcement.

Source statement: "AI workloads run as virtual machines and containers." (https://github.com/vmware/vcf-security-and-compliance-guidelines/blob/main/security-design/vcf-91-securing-ai-workloads.md)

Last checked 16 November 2026. This platform is checked on demand, so this answer has not been rechecked since.

Research detail: Services run on vSphere Supervisor namespaces and VKS clusters, with deep learning VMs for development and validation. Microservices in a namespace use mutual TLS. MCP servers are recommended to run as Pod VMs in the same namespace.
