## Answer

Not covered. No per-agent identity tied to owner, runtime and release. Agent IDs in Agent Builder are object references only.

Last checked 16 November 2026. This platform is checked on demand, so this answer has not been rechecked since.

Research detail: Agents are API objects in a namespace and carry an agent ID that appears in traces as com.vmware.pais.agent_id. Callers authenticate as users or with API tokens. No separate agent or workload identity linked to an owner or release is documented.
