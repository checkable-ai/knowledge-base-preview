## Answer

Not covered. Retrieval and tool calls use fixed connection credentials, not the end user's identity.

Research detail: Users sign in through OIDC or VCF Automation, and access is checked against organisation and group membership. Data sources index with a fixed service account, user name and password, personal access token or S3 key. MCP servers receive static headers. No passing of the end user's identity to data sources or tools is documented.
