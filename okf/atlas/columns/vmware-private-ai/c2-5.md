## Answer

Covered. MCP tool calling and knowledge base tools only; MCP prompts, sampling and resources unsupported.

Source statement: "The model selects MCP tools according to their description and provided instructions and the agent calls them." (https://techdocs.broadcom.com/us/en/vmware-cis/private-ai/foundation-with-nvidia/9-1/what-is-private-ai-services/deploy-an-agent-for-a-rag-application.html)

Research detail: Agent Builder is a managed harness that calls approved MCP tools and knowledge base tools from an agent definition, with static tool execution for models that do not call tools reliably and pre-loading of tool results into context.
