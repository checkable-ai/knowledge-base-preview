## Answer

Not covered. No action, parameter or per-user permission scopes in connected systems. MCP tool approval and agent tool links only choose which tools an agent can use.

Last checked 16 November 2026.

Research detail: Administrators connect MCP servers, review each tool's capabilities and parameters, and approve only suitable tools. Only approved tools in the namespace tool gallery can be added to an agent, and each agent lists its own tools. The 9.1 release notes say MLOps keeps governance over which tools each agent can access.

## Products

MCP Tool Gallery, Agent Builder Tools tab

## Gaps

No per-tool parameter limits, per-user tool rules or read and write distinction is documented. Scope is set by namespace approval and agent configuration only.

<!-- chunk: options -->
## Options

Run MCP servers with least-privilege back-end credentials and approve only read tools where possible. Test that an unapproved tool cannot be called.
