## Answer

Not covered. The MCP Tool Gallery lets administrators approve which tools an agent can see, but this is tool visibility, not a control over what an agent may do in the connected system. No parameter limits, per-user rules or read/write action policy is documented. The vendor states the MCP server or the system behind it must still authenticate the caller and authorise each action, so the customer must address this.

Research detail: Administrators connect MCP servers, review each tool's capabilities and parameters, and approve only suitable tools. Only approved tools in the namespace tool gallery can be added to an agent, and each agent lists its own tools. The 9.1 release notes say MLOps keeps governance over which tools each agent can access.

## Gaps

## Options
