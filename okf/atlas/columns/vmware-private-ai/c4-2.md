<!-- chunk: answer -->
## Answer

Not covered. No short-lived, rotated or revocable agent credentials documented. MCP header tokens are static and Kubernetes Secrets do not meet the lifecycle outcome.

Research detail: Cloud model API keys and service account keys are stored as Kubernetes Secrets referenced by each InferenceGatewayRoute, and Google service account keys are exchanged for short-lived OAuth2 tokens before each request. Data sources store their own retrieval credentials. MCP servers take static tokens as custom request headers. Secrets are held by the platform rather than placed in prompts.

<!-- chunk: products -->
## Products

InferenceGatewayRoute with api-token-credentials Secrets, data source credentials, MCP connection headers, API tokens

<!-- chunk: gaps -->
## Gaps

No rotation or expiry for MCP header tokens or data source credentials is documented. MCP header values cannot be edited, only deleted and re-created. The design notes say local-auth tokens have no per-token revocation. The API token page gives no expiry or revocation detail.

<!-- chunk: options -->
## Options

Use short-lived credentials where the source allows, rotate Secrets with an external secrets manager, and test revocation of a shared-model API token.
