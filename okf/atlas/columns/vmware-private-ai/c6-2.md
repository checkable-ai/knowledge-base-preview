## Answer

Not covered. A documented submit, register and approve process for models and agents. Only MCP servers are registered and their tools approved or unapproved (batch-approval API); that is a tool-level step that falls short of a registration and approval process for new models, agents and tools. Model Gallery uploads and agent creation have no documented approval step.

Last checked 16 November 2026.

Research detail: MCP tools must be approved in the tool gallery before agents can use them. Models are validated by MLOps and can be tagged, for example as approved, when pushed.

<!-- chunk: products -->
## Products

MCP Tool Gallery, model gallery tags

<!-- chunk: gaps -->
## Gaps

Model approval is a tag convention, not an enforced gate. Agents have no registration approval.

<!-- chunk: options -->
## Options

Use separate dev and production galleries and restrict push rights to production.
