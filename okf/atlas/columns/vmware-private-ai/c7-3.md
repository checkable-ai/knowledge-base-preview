## Answer

Not covered. Manual validation procedure and immutable digests only; no product gate, signing, attestation or AI BoM.

Last checked 16 November 2026.

Research detail: A model gallery is a Harbor project with user access controls, and each model revision is an immutable OCI artifact identified by digest. The documented validation procedure has MLOps engineers check file hashes, scan for malware and serialisation attacks, and test inference in a deep learning VM before pushing.
