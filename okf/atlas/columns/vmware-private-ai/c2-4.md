## Answer

Not covered. Agent Builder documents max chat history characters (oldest messages deleted) and idle-day session deletion. Who can read session memory and how a session resumes are not documented.

Research detail: Agents keep chat history per session up to a maximum length in characters, remove the oldest messages first, and delete sessions after a set number of idle days.
