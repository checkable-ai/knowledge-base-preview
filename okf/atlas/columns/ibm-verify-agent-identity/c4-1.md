## Answer

Not covered. Agent record (displayName, description, externalIds, authMethods, owners, tags) has no field for where the agent runs or which release it is. Agent ID and owners exist but do not meet the full outcome.

Research detail: Each agent gets a purpose-built non-human identity with an Agent ID, and every issued token is permanently bound to that Agent ID. The agent record holds a display name, description, owners, tags, external IDs and auth methods. Runtime and release are not recorded fields.
