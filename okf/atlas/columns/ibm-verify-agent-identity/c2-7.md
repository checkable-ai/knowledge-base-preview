## Answer

Not covered. Agent Identity does not run agent code, so it sets no limits on files, processes or network access. The sandboxes and kill switch belong to watsonx Orchestrate, a separate product, and apply to agents it runs.

Last checked 13 November 2026. This platform is checked on demand, so this answer has not been rechecked since.

Research detail: An agent in the Suspended state has its linked OAuth clients disabled immediately, and token requests fail until it is reactivated, without revoking individual credentials. Privileged tokens are short lived and not renewable. Agent Identity does not run agent code, so sandboxing and egress control sit outside it.
