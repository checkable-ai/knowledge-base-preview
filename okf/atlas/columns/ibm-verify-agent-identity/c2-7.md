## Answer

Not covered. No limits on an agent's files, processes or network access, since Agent Identity does not run agent code. Suspension disables OAuth clients but does not state that already-issued tokens stop working.

Research detail: An agent in the Suspended state has its linked OAuth clients disabled immediately, and token requests fail until it is reactivated, without revoking individual credentials. Privileged tokens are short lived and not renewable. Agent Identity does not run agent code, so sandboxing and egress control sit outside it.
