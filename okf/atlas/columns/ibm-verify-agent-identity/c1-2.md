## Answer

Covered. Public preview. Policy evaluation applies to privileged token issuance; enforcement occurs at the resource server or Identity Runtime Proxy.

Source statement: "IBM Verify evaluates the subject, actor, requested action, and audience against policy before issuing the token." (https://www.ibm.com/docs/en/agent-identity?topic=overview-concepts)

Research detail: Tokens are scoped per request and bound to an audience, and an agent can have separate token exchange clients per resource server. Before issuing a privileged token Verify evaluates subject, actor, requested action and audience against policy. Enforcement happens at the resource server or an Identity Runtime Proxy in front of it.
