## Answer

Covered. Public preview.

Source statement: "The agent is suspended. Its linked OAuth clients are disabled immediately." (https://www.ibm.com/docs/en/agent-identity?topic=overview-concepts)

Research detail: Agents are created by an Agent Developer and start under review. A separate Approver with manageAgentStatus activates them, and only active agents can bind OAuth clients and get tokens. Agents can be edited, suspended or deleted, and suspension disables linked OAuth clients immediately.
