## Answer

Not covered. Client secret rotation is not documented, and keeping secrets out of model context is not addressed. Short-lived non-renewable privileged tokens and suspension fall short of the full outcome.

Research detail: Agents obtain tokens through client credentials or JWT bearer from a trusted issuer such as SPIFFE. Privileged tokens are short-lived and not renewable, and suspending an agent disables its OAuth clients at token issuance. In the Vault use case an API key is released only after Vault validates the delegated token, so the agent never stores it. The agent still holds long-lived client secrets shown once at onboarding.
