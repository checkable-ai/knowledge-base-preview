## Answer

Not covered. No schema or input format checks, quotas, egress control or blocking of dangerous actions. The Identity Runtime Proxy only validates tokens (sub, act, aud).

Research detail: An Identity Runtime Proxy can sit in front of a resource server and check that sub is a known user, act is a known Agent ID and aud matches. In the MCP use case the delegated token travels with each tool call so the MCP server enforces subject, actor and authorisation context. This is token validation, not a full tool gateway.
