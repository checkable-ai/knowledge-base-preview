## Answer

Not covered. Model Proxy routes to providers and controls limits, but model region and prompt data handling are not stated and sit with each provider.

Research detail: Model Proxy fronts OpenAI, Azure OpenAI, Gemini, Anthropic, Bedrock Anthropic and NVIDIA Nemotron, with model-based routing that can override the requested model version. Only the OpenAI endpoint format supports multi-routing and fallback, and the format cannot be changed later. MuleSoft brokers inference rather than running models.
