## Answer

Covered. Omni Gateway authentication and authorisation policies applied to A2A server instances. Not supported in Local Mode.

Source statement: "protect server instances through rate limiting, authentication, authorization" (https://docs.mulesoft.com/gateway/latest/agent-policies)

Research detail: A2A Connector lets a Mule app act as an A2A server, client or both, with capability discovery and distributed tracing, and A2A Bridge makes non-A2A agents A2A compliant. Omni Gateway is described as requiring authentication and authorisation on agent requests. A2A authentication methods are not described on the connector page.
