## Answer

Not covered. MCP Connector hosts MCP client or server runtimes, but no safeguards for tool execution harness are documented.

Research detail: MCP Connector hosts MCP server or client runtime inside a Mule app over Streamable HTTP or deprecated SSE, and AI Chain Connector has tools operations that call APIs. Agent Broker executes work across agents and MCP servers. SSE server transport is supported only in single-replica deployments.
