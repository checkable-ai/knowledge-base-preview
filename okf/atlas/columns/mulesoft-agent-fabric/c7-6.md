## Answer

Not covered. MCP Schema Validation Tool Poisoning Detection checks tools against a trusted set pinned from Exchange. It does not scan public registries or detect compromised packages or registry squatting.

Research detail: The MCP Schema Validation policy offers Tool Poisoning Detection against a trusted tool set pinned from Exchange. It detects descriptor drift, shadow tool names that are near-twins of pinned tools, and prompt injection patterns in descriptors, and can log, remove the tool or block the response. Akamai risk correlation adds findings for owned MCP services.

## Products

MCP Schema Validation Tool Poisoning Detection, Akamai risk correlation

## Gaps

Package or plugin compromise and registry squatting are not covered. Detection types are off by default, not supported in Local Mode, and support MCP 2025-06-18 and earlier.

<!-- chunk: options -->
## Options

Enable descriptor drift and shadow detection with RemoveTool or BlockResponse on each MCP API.
