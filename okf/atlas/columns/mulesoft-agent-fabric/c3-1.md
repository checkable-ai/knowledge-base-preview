## Answer

Covered. Managed or Connected Mode. Wallets need an identity provider. Semantic caching supports only Azure AI Search.

Source statement: "Model Proxy provides a unified access layer for multiple Large Language Model (LLM) providers." (https://docs.mulesoft.com/general/model-proxy)

Research detail: Model Proxy gives one governed endpoint for several LLM providers with model or semantic routing, fallback in OpenAI format and semantic caching. LLM policies include LLM Token Based Rate Limit, LLM PII Detection, Regex Prompt Guard, Azure Content Safety and Amazon Bedrock Guardrails. Model wallets cap a caller's token or dollar spend per provider.

## Products

Model Proxy, Omni Gateway LLM policies, model wallets

## Gaps
