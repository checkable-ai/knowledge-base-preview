## Answer

Covered. On Australia Cloud, Basic Alerts are available but Advanced Alerts and Custom Dashboards are not yet available.

Source statement: "Send alerts to Slack, Microsoft Teams, and email." (https://docs.mulesoft.com/general/agent-fabric-overview)

Research detail: Agent Fabric monitoring reports latency, error rate and request volume with alerts to Slack, Teams and email, and Agent Visualizer shows throughput and error metrics. On Australia Cloud the Hyperforce matrix lists Basic Alerts as available, Advanced Alerts and Custom Dashboards as planned, and Traces Beta, API Alerts and API Analytics as not planned.
