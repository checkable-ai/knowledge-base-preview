## Answer

Covered. Needs Omni Gateway 1.13.5 or later. The Rogue Agent Detection policy has to be applied to each model proxy and given detection rules. With no rules it detects nothing. It covers model proxy (LLM) traffic only, not MCP or A2A, and adds extra inference calls and token usage. MuleSoft documents no feature for training agents on their tasks.

Source statement: "The policy checks each incoming prompt against the anomaly detection rules to identify rogue or compromised agent behavior." (https://docs.mulesoft.com/general/exp-detect-and-contain-rogue-agents)

Research detail: Rogue Agent Detection flags PII leak, privilege escalation, prompt injection and custom rule matches on model proxy traffic, using extra inference calls per prompt. With no rules configured the policy forwards every request and detects nothing.
