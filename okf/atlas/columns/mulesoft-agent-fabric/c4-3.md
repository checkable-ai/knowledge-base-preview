## Answer

Covered. Omni Gateway Managed or Connected Mode, not supported in Local Mode. Claims depend on the authorisation server.

Source statement: "exchanges an incoming bearer token for a new token to target specific upstream services." (https://docs.mulesoft.com/gateway/latest/policies-outbound-oauth-obo)

Research detail: The OAuth 2.0 OBO Credential Injection policy takes the incoming bearer token, exchanges it through RFC 8693 token exchange, Microsoft Entra ID on-behalf-of or token exchange with CIBA, and replaces the Authorization header before the request reaches the backend. Rogue agent tokens must carry both the agent identifier and the person it acts for.
