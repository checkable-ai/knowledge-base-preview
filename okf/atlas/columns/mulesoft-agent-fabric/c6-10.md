## Answer

Not covered. Australia Cloud gives control plane data residency, but retention and deletion rules for agent inputs, outputs and memory are not described.

Research detail: Australia Cloud (au1.platform.mulesoft.com) is a Hyperforce control plane with Australia data residency and one in-country runtime region, and an organisation lives in exactly one cloud. Runtime region is independent of control plane residency, and external vaults keep secrets out of MuleSoft. Feature availability on Australia Cloud is per row in the Hyperforce matrix, not portfolio wide.
