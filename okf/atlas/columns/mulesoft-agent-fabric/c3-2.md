## Answer

Covered. Omni Gateway 1.9.3 or later. Not supported in Local Mode. Applies to MCP tool calls.

Source statement: "Controls access to tools, resources, and prompts based on user information such as Tiers, IP, Headers, or Claims" (https://docs.mulesoft.com/gateway/latest/policies-included-mcp-attribute-access-control)

Research detail: Omni Gateway MCP policies cover MCP Support, Global Access, Attribute-Based Access Control, Tool Mapping, Schema Validation, PII Detector, Payload Optimization and Tools Progressive Disclosure. Access policies filter tools, resources and prompts and can bind to JWT claims. All agent policies are inbound policies.
