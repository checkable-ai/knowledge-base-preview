## Answer

Not covered. Agent Kill Switch blocks a quarantined agent's access to model proxies only, after human review. No sandbox for files, processes or network.

Research detail: The Agent Kill Switch policy blocks a quarantined agent's access to each model proxy it is applied to on Omni Gateway 1.13.5 or later. Rogue Agent Detection flags risky behaviour in real time, quarantine starts only after a person reviews the flag, and it is reversible with an audit record. Omni Gateway also limits which tools an agent can call. There is no sandbox, filesystem or process policy for agent code.

## Products

## Gaps

Containment covers model proxy access only. Agents can still reach tools or APIs not behind a kill switch policy. No latency for quarantine is stated. Requires tokens carrying both agent and user identity.

## Options

Apply the kill switch to every model proxy and front tools with Omni Gateway policies. Test quarantine time end to end.
