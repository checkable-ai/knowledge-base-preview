## Answer

Covered. Beta, opt-in from the Previews page. MCP services only, input phase.

Source statement: "on an MCP Service, the policy pauses a request for user approval before the tool runs." (https://docs.databricks.com/aws/en/data-governance/unity-catalog/service-policies/)

Research detail: Service policies on MCP services can return ASK, which pauses the tool call until a user approves it. External agents get an MCP URL-mode elicitation link and retry after approval. An identical call is not prompted again for one hour.

<!-- chunk: products -->
## Products

Unity Catalog service policies (ASK decision) on MCP services

<!-- chunk: gaps -->
## Gaps

Only MCP services, input phase. Model services block on ASK. Denial, timeout and replay outside the one hour window are not described. Approver identity rules and binding beyond identical calls are not documented. Beta.

## Options

Test decline and timeout behaviour, and check that the approval is logged with the approver in audit or trace tables.
