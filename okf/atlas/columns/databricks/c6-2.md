## Answer

Covered, with conditions. MLflow deployment jobs are in Public Preview. The approval mechanism is experimental. The workflow applies to model versions registered in Unity Catalog and runs on Lakeflow Jobs. It needs APPLY TAG on the model and CAN MANAGE RUN on the deployment job.

Source statement: "At this point, an approver can manually approve this version to be deployed or reject it." (https://docs.databricks.com/aws/en/mlflow/deployment-job)

Last checked 15 November 2026.

Research detail: Deployment jobs have an approval task that blocks deployment until an approval tag is set, and governed tags limit who can approve. GRANT policies only grant EXECUTE on MCP and model provider services tagged as approved.

## Products

MLflow deployment jobs, GRANT policies with governed tags

## Gaps
