## Answer

Not covered. Built-in agent detections in a GA product, a SOC delivery workflow and a named response owner. Trace redaction and system tables fall short.

Research detail: Audit logs, the outbound network denials table and enhanced security monitoring events (antivirus, file integrity) are queryable as system tables. Trace PII can be redacted client side or by pipeline.

<!-- chunk: products -->
## Products

Audit log system table, system.access.outbound_network, enhanced security monitoring, trace redaction

<!-- chunk: gaps -->
## Gaps

No built-in detections or response ownership. Enhanced security monitoring does not cover serverless compute. Outbound network table is Public Preview.

<!-- chunk: options -->
## Options

Stream system tables to a SIEM and build detections there.
