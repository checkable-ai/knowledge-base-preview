## Answer

Covered. Beta. A workspace admin must opt in to the Unity Gateway Service Policies preview. Direct USE CONNECTION calls bypass MCP tool selection.

Source statement: "For example, block a request that invokes a destructive MCP tool." (https://docs.databricks.com/aws/en/data-governance/unity-catalog/service-policies/)

Research detail: MCP services enforce Unity Catalog EXECUTE grants, tool selection, per-call QPM rate limits and service policies on call and on result, including ASK and partner guardrails. Credentials come from HTTP connections. Egress to MCP servers goes through serverless compute and is subject to network policies.

<!-- chunk: products -->
## Products

Unity Gateway MCP services, service policies, HTTP connections, serverless egress control

<!-- chunk: gaps -->
## Gaps

Jailbreak policy runs only on input. No exclusion patterns in tool selection. Policies are Beta. Calls made directly with USE CONNECTION bypass tool selection.

<!-- chunk: options -->
## Options

Use restricted network policies with allowed MCP domains, and attach output side policies for tool results.
