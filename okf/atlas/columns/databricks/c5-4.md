## Answer

Covered. Applies to Model Serving endpoints. Metrics are kept for up to 14 days in the Serving UI and can be exported to tools such as Prometheus and Datadog.

Source statement: "Provides insights into infrastructure metrics like latency, request rate, error rate, CPU usage, and memory usage." (https://docs.databricks.com/aws/en/machine-learning/model-serving/monitor-diagnose-endpoints)

Last checked 15 November 2026.

Research detail: Each model and MCP service has a Metrics tab, and the usage table records latency and time to first byte. Model Serving keeps metrics up to 14 days.
