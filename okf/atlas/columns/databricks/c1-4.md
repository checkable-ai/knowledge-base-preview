## Answer

Covered. Agent Bricks CLI is Beta. Changing permissions requires CAN MANAGE on the app.

Source statement: "Only users with `CAN MANAGE` permissions can assign or revoke permissions on an app." (https://docs.databricks.com/aws/en/dev-tools/databricks-apps/permissions)

Research detail: agent.toml declares an agent's stores, tracing and tool bindings, and agentbricks deploy provisions them and grants the app service principal access, stopping before upload if a grant fails. Deployments can be listed, stopped and deleted. Service principals are created and managed by account and workspace admins and service principal managers.

<!-- chunk: products -->
## Products

Agent Bricks CLI and agent.toml, Agent Runtime deployments, service principal management

<!-- chunk: gaps -->
## Gaps

No documented approval workflow for creating or changing agent identities. Grants for dependencies not declared in agent.toml must be applied by hand. Agent Bricks CLI is Beta.

<!-- chunk: options -->
## Options

Keep agent.toml in source control with review, and deploy only from CI using a dedicated service principal.
