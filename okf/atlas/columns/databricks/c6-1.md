## Answer

Covered, with conditions. Agent services are in Beta. An account admin must turn on the Unity Gateway beta features from the Previews page. During the beta, the owner and full_name fields return null. Agents cannot be invoked through a registered agent service during the beta. Users need an explicit privilege such as EXECUTE to see an agent service.

Source statement: "Register agents in Unity Catalog so every team's agents live in one place." (https://docs.databricks.com/aws/en/ai-gateway/agent-services)

Last checked 15 November 2026.

Research detail: Unity Catalog registers models with signatures, MCP services, skills, functions and connections as securables. The MCPs page lists registered servers.
