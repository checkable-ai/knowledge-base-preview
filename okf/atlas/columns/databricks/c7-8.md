## Answer

Covered. ABAC row and column policies are Beta; AI Search lacks row and column permissions; classification tagging can lag up to 24 hours.

Source statement: "Attribute-based access control (ABAC) is an access control model in Unity Catalog where access is determined by evaluating" (https://docs.databricks.com/aws/en/data-governance/unity-catalog/abac/)

Research detail: Unity Catalog governs tables, features and AI Search indexes with grants, ABAC row filters and column masks, lineage and LLM based data classification that tags sensitive columns. AI Search supports customer managed keys.
