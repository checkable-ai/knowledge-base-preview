## Answer

Not covered. Compliance security profile hardening applies to classic compute and is not documented for agent tool hosts or sandboxes. No scanning is documented.

Research detail: The compliance security profile adds a CIS hardened, FIPS image, enhanced security monitoring and Nitro enforcement on AWS. Enhanced security monitoring adds antivirus, file integrity monitoring and vulnerability scanning on classic compute.
