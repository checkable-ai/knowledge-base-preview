## Answer

Not covered. No documented per-command or file system scope controls for what an agent does on its own machine. Unity Catalog grants scope data access and Sandbox (Beta) egress is not configurable.

Research detail: Databricks Sandbox runs agent-written code as the requesting user by default or as the app service principal, and agent.toml tool policies can downscope sandbox table access to read only. Supervisor Agent's built-in code tool runs in a sandbox with no internet access and only the tables and volumes added.

<!-- chunk: products -->
## Products

Databricks Sandbox, agent.toml tool policies, Supervisor Agent code execution tool

<!-- chunk: gaps -->
## Gaps

Sandbox network egress is unrestricted and not configurable. Sandbox is Beta. No documented per-command or file system scope controls inside the sandbox.

<!-- chunk: options -->
## Options

Keep sensitive data out of sandboxes, use downscope policies, and wait for egress controls before using Sandbox with untrusted code.
