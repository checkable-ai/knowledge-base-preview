## Answer

Not covered. Gateway cost observability covers model spend only. Staff time, other infrastructure, savings and delivered value are not measured, and nothing compares cost with return.

Last checked 15 November 2026.

Research detail: Usage and billing system tables attribute model spend to the requesting user or service principal and service tags, external model spend is estimated hourly, and a usage dashboard breaks down cost. Budgets alert or block.
