## Answer

Covered. Egress network policies need the Enterprise tier. Agent Sandbox is Beta.

Source statement: "Network policies are only available on the Enterprise tier." (https://docs.databricks.com/aws/en/dev-tools/databricks-apps/networking)

Research detail: Agents run on serverless Databricks Apps, which support ingress IP access lists, front-end private connectivity and egress network policies. Databricks Sandbox gives agent-written code an isolated serverless environment with closed ingress.

<!-- chunk: products -->
## Products

Agent Runtime on Databricks Apps, Databricks Sandbox, serverless egress control

<!-- chunk: gaps -->
## Gaps

Sandbox egress is unrestricted and Beta. Apps have limited egress control support. Isolation between apps is not described. Network policies need the Enterprise tier on AWS and Premium on Azure.

<!-- chunk: options -->
## Options

Apply a restricted network policy in dry run first, then enforce, and keep untrusted code out of Sandbox until egress controls exist.
