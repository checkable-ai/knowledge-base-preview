## Answer

Not covered. No gateway for agent-to-agent calls, approved agent pairs or format checks. Service policies do not support Agent Services. App and endpoint permissions fall short.

Last checked 15 November 2026.

Research detail: Allowed agent pairs are set by app and endpoint permissions, where the caller's service principal needs CAN_USE or CAN_QUERY on the target. No gateway mediates agent to agent calls.
