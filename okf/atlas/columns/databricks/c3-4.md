## Answer

Not covered. No gateway, schema checks or content policies for agent-to-agent traffic. Only app and endpoint permissions exist.

Research detail: Allowed agent pairs are set by app and endpoint permissions, where the caller's service principal needs CAN_USE or CAN_QUERY on the target. No gateway mediates agent to agent calls.
