## Answer

Not covered. No SBOMs. No scanning or review of external MCP servers, command-line tools, skills or extensions. Egress and external-service defence is not covered. Apps code scanning (Beta) covers an app's own source only.

Research detail: Egress from MCP services and Model Serving is controlled by network policies, and the built-in GitHub MCP policy can disallow write tools. External policies call partner guardrails on tool traffic.

<!-- chunk: products -->
## Products

Serverless egress control, service policies, built-in MCP policies

## Gaps

## Options
