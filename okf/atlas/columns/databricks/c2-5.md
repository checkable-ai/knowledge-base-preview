## Answer

Covered, with conditions. The agent server is hosted on Databricks Apps. The agent server of an existing deployment can't be changed. The system.ai.dbsql, system.ai.sandbox and system.ai.web_search MCPs are Beta and need the Enhanced Unity Gateway preview enabled by an account admin.

Source statement: "The agent server is a library that wraps your agent loop and turns it into a service." (https://docs.databricks.com/aws/en/agents/deploy)

Last checked 15 November 2026.

Research detail: Agent Bricks provides the agent server (DurableAgentServer) and Agent Runtime, with LangGraph and OpenAI templates, tool bindings for MCP and Unity Catalog functions, and tracing configured at deploy time.
