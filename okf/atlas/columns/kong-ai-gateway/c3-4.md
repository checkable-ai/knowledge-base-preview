## Answer

Covered. Each calling agent needs its own AI Consumer identity. No skill-level ACLs or payload schema validation.

Source statement: "Access is enforced before traffic reaches the upstream agent." (https://developer.konghq.com/ai-gateway/entities/ai-agent/)

Research detail: AI Agent entities enforce which consumers or groups may call each agent, detect A2A JSON-RPC and REST bindings, rewrite agent card URLs and limit request body size. Unknown schema properties in the entity config are rejected.

<!-- chunk: products -->
## Products

AI Agent entity

<!-- chunk: gaps -->
## Gaps

No skill-level ACLs. Message payloads are not validated against a schema beyond envelope detection. Allowed pairs depend on each calling agent having its own consumer identity.

<!-- chunk: options -->
## Options

Give each agent its own consumer and per-agent ACLs, and validate payloads in the receiving agent.
