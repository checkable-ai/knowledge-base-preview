## Answer

Covered. Konnect Catalog. Agents in Catalog are beta; MCP Registry is tech preview and not for production. AI Models and MCP servers have no preview label.

Source statement: "Model your organization's AI models as first-class interfaces in Catalog." (https://developer.konghq.com/catalog/)

Research detail: Konnect Catalog inventories APIs, AI models, MCP servers with tools, resources, prompts and input schemas, and agents built from A2A cards. MCP server records carry semver versions and npm, PyPI or OCI packages. The MCP Registry adds a publishing and discovery endpoint based on the MCP Registry API specification.

## Products

Konnect Catalog, MCP Registry

## Gaps

Agents are beta and the MCP Registry is tech preview, not for production and not available on-prem. Catalog links to gateway entities are snapshots that do not sync.
