## Answer

Covered. MCP traffic only. Token exchange needs the AI Gateway Enterprise tier and Kong Gateway 3.14 or later.

Source statement: "The plugin can extract claims from a validated token and forward them to the upstream MCP server as HTTP headers." (https://developer.konghq.com/plugins/ai-mcp-oauth2/)

Research detail: The AI MCP OAuth2 plugin validates the user's token, then can exchange it as the subject token (with an optional actor token) for a token scoped to the upstream MCP server. It can also forward token claims, including nested claims, to the upstream as headers.

## Products

AI MCP OAuth2 plugin token exchange and claim forwarding

## Gaps

Documented for MCP traffic only. LLM and A2A delegation is not described. Requires Kong Gateway 3.14 or later and the AI Gateway Enterprise tier.
