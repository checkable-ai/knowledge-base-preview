## Answer

Covered. Gateway-level only: Kong does not run models, so model hosting location and data-handling terms stay with the upstream provider.

Source statement: "distributes requests across one or more concrete upstream models declared in its targets array." (https://developer.konghq.com/ai-gateway/entities/ai-model/)

Research detail: Kong does not run models but the AI Model entity defines explicit upstream targets, provider, endpoint paths, format, failover criteria, circuit breaking and per-target pricing. Routing rules let clients send an alias so the upstream model can change without client changes. Payload logging is optional.
