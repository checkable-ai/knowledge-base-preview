## Answer

Covered. CEL-based ACLs need Kong Gateway 3.16 or later data planes. Passthrough mode needs a minimum runtime version of 2.2, and Baseten targets need 2.3. The gateway does not host models, so where the model runs and how the provider handles prompt data stay with the upstream provider.

Source statement: "Each entry represents a single upstream model instance with one URL." (https://developer.konghq.com/ai-gateway/entities/ai-model/)

Last checked 16 November 2026.

Research detail: Kong does not run models but the AI Model entity defines explicit upstream targets, provider, endpoint paths, format, failover criteria, circuit breaking and per-target pricing. Routing rules let clients send an alias so the upstream model can change without client changes. Payload logging is optional.
