## Answer

Not covered. AI Consumers and AI Agent entities identify gateway callers, but no documented link from an identity to an owner, the runtime it runs in, or the release version. Nearby AI Auth Strategy and Kong Identity only identify callers.

Research detail: Callers are identified as AI Consumers, resolved by an AI Auth Strategy from an API key or an OIDC token claim. Kong Identity issues client credentials whose client ID becomes the consumer's custom_id, giving a machine identity for an agent. Upstream agents are registered as AI Agent entities with an immutable name.

## Gaps
