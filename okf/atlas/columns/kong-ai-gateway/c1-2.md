## Answer

Covered. Applies only to systems reached through the gateway (MCP servers). Per-tool ACLs override defaults entirely, not merged.

Source statement: "A tool's own `acls` fully overrides the default ACL for that tool." (https://developer.konghq.com/ai-gateway/entities/ai-mcp-server/)

Research detail: AI MCP Server ACLs filter tools/list and check each tools/call per consumer, consumer group or OAuth token claim, with deny rules winning. OAuth2 scoping can give write tools stricter access than read tools, and 2.1.0 added CEL allow_when and deny_when expressions. AI Models and AI Agents carry their own allow or deny ACLs.

## Products

AI MCP Server access.acls, AI Auth Strategy, AI Model and AI Agent ACLs

## Gaps
