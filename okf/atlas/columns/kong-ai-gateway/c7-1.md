## Answer

Not covered. Kong documents no write-once or integrity-validated storage for AI traffic or agent action logs, and no documented export of agent action records to such storage. Konnect audit logs cover platform administration for a short retention period and are not a record of agent tool calls and data access. AI logging plugins export logs to external sinks, but payload logging is off by default and no tamper-evidence is documented.

Research detail: AI Gateway logs record consumer, request and response payloads, tokens, cost, MCP tool calls and every MCP ACL allow or deny decision. Konnect platform audit logs record authentication, authorisation and API access and can carry ED25519 signatures for verification.

## Products

AI Gateway audit log, Konnect audit logs

<!-- chunk: gaps -->
## Gaps

AI traffic logs have no documented signing or immutability. Konnect audit logs are kept 7 days. Payload logging is off by default and may expose sensitive data. No reasoning capture.

<!-- chunk: options -->
## Options

Forward logs to a WORM store or SIEM and verify Konnect signatures on ingest.
