## Answer

Not covered. Kong's AI Gateway documentation does not describe any tamper-evident, write-once or signed record of agent actions. The A2A audit logs record task IDs, JSON-RPC method calls, payloads, latencies and errors. Nothing documents how those logs are protected from change, and they do not capture agent reasoning. Logging policies send logs to outside systems, with no integrity protection documented. Konnect audit log signatures cover platform administration only, not agent traffic. The 'tamper-evident audit trails' line appears only on the Agent Gateway solution page, a marketing page with no documented mechanism behind it.

Last checked 16 November 2026.

Research detail: AI Gateway logs record consumer, request and response payloads, tokens, cost, MCP tool calls and every MCP ACL allow or deny decision. Konnect platform audit logs record authentication, authorisation and API access and can carry ED25519 signatures for verification.

## Products

AI Gateway audit log, Konnect audit logs

<!-- chunk: gaps -->
## Gaps

AI traffic logs have no documented signing or immutability. Konnect audit logs are kept 7 days. Payload logging is off by default and may expose sensitive data. No reasoning capture.

<!-- chunk: options -->
## Options

Forward logs to a WORM store or SIEM and verify Konnect signatures on ingest.
