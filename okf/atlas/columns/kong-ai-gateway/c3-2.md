## Answer

Covered. AI Guardrails are not supported on MCP traffic, so tool results are not injection screened. No general internet egress allow list.

Source statement: "The runtime returns `HTTP 403 Forbidden` if denied, or forwards the request to the upstream MCP server if allowed." (https://developer.konghq.com/ai-gateway/entities/ai-mcp-server/)

Research detail: AI MCP Server entities convert REST APIs to MCP tools or proxy upstream MCP servers, validate tool calls against OpenAPI or JSON Schema parameters, enforce per-consumer tool ACLs and inbound OAuth2, and run attached rate limiting and logging policies. Outbound traffic can go through a forward proxy.
