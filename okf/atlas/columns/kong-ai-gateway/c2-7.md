## Answer

Not covered. No sandbox for files, processes or network. MCP tool ACLs deny tool access only for MCP tools; propagation speed and cut-off of open sessions are undocumented.

Research detail: AI Gateway 2.1 and later can block a consumer from MCP tools by placing it in a consumer group that no tool ACL allows, such as a suspended group, and denied tool calls are rejected with HTTP 403 at the route. Per-tool deny lists also hide tools from discovery. Kong does not run agent code, so sandboxing, filesystem and process policy sit outside the product.
