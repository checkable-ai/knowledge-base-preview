## Answer

Not covered. Only registration plus OAuth for an external client calling the Self-Service Agent is described; no agent-pair trust boundary model could be verified.

Research detail: External assistants such as Google Gemini Enterprise can call the Self-Service Agent over the Agent2Agent protocol through Agent Gateway. The external client is registered in ASOR, fetches an agent card, and authenticates with OAuth and PKCE on behalf of an authorised user. Documentation covers the Self-Service Agent as the A2A target only.
