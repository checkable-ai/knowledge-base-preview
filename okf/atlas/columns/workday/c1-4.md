## Answer

Covered. Deactivation hides the agent but keeps it in Agent Management Hub; no tenant migration.

Source statement: "Register an agent in the Agent Management Hub to prepare it for configuration and activation." (https://doc.workday.com/admin-guide/en-us/workday-ai/agents/setup-considerations--agent-system-of-record.html)

Research detail: Agents move through define, register, configure, activate and deactivate in the Agent Management Hub. ASOR creates ASUs in a disabled state when skills are enabled and enables them on activation, and management tasks are secured to separate ASOR domains. External agents are registered and updated through the ASOR API.

<!-- chunk: products -->
## Products

Agent Management Hub, ASOR API, Manage: Agents and Setup: Agents domains

<!-- chunk: gaps -->
## Gaps

No documented hard retirement beyond deactivation. Configurations cannot be migrated between tenants. Only unconstrained groups can be used on ASOR policies.

<!-- chunk: options -->
## Options

Restrict Setup: Agents and Manage: Agents to a small admin group and review the Agent Registry last-updated column.
