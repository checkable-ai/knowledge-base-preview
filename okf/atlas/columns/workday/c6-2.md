## Answer

Not covered. Agents are registered in the Agent Management Hub or through the API and activated separately, but no submission or approval workflow is documented.

Research detail: Workday-built agents are registered from the Unregistered tab with a confirmation step, and external agents are registered through the ASOR API by a user with Setup: Agents access. Activation is a separate step. No multi-party approval workflow is documented.

## Products

Agent Management Hub, ASOR API

## Gaps
