## Answer

Covered. Scopes apply to Workday APIs; delegate-mode skills use the Agent Interaction Policy and domain security.

Source statement: "Each agent has a unique identity, or Agent System User account (ASU)." (https://doc.workday.com/admin-guide/en-us/workday-ai/agent-security/concept--agent-security.html)

Research detail: Each skill lists tools by Workday ID, and tools run only if the security group is on both the agent skill and the API's domain or business process policy. Ambient skills get a generated Ambient Agent Security Group that must be assigned to policies. Domain security is also checked at field level at runtime.
