## Answer

Not covered. Agent Gateway covers calls into Workday only; no injection screening or egress control verified.

Research detail: All third-party agents must route Workday API traffic through Agent Gateway using ASU security. The gateway authenticates and authorises every call, applies rate limiting and performance guardrails, and tracks API consumption, and each skill's tools are fixed by Workday ID at registration. Injection screening, dangerous action filtering and internet egress control are not documented.

## Products

Agent Gateway, MCP Gateway, ASOR skill tool definitions

## Gaps

Rate limits are not customer configurable in the docs. Covers calls into Workday only, not agent calls to other systems.

<!-- chunk: options -->
## Options

Combine Agent Gateway with a tool gateway on the external agent platform for non-Workday tools.
