## Answer

Not covered. Only per-agent session behaviours; no platform-wide admin session memory control.

Research detail: Session handling is documented per agent. Payroll Agent keeps only the last 20 interactions in a thread, the Deployment Agent summarises long threads, isolates chat history by tenant and deletes it after 14 days, and ASOR exposes session IDs on the Monitoring tab. There is no platform-wide session memory policy.
