## Answer

Covered. Delegate mode; documented for Workday APIs only.

Source statement: "The agent uses the OAuth 2.0 in the On-Behalf-Of flow." (https://doc.workday.com/admin-guide/en-us/workday-ai/agent-security/concept--agent-security.html)

Research detail: Delegate mode uses an OAuth 2.0 On-Behalf-Of flow that exchanges the user token for a delegated access token. Authorisation is the intersection of the user's permissions and the agent's allowed skills, and the audit log records the agent as By User and the human as On Behalf Of User. Delegated interactions cannot be further delegated or proxied.
