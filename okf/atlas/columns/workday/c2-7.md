## Answer

Not covered. Deactivation stops Workday access but no file, process or network sandbox is documented.

Research detail: Admins deactivate an agent in Agent System of Record, and the guide says the status change reaches Agent Gateway and MCP Gateway requests within up to 1 minute, which gives a deterministic stop for agent access to Workday. Agent System Users are created disabled and enabled only on activation. Sana runs data analysis code on Workday-hosted infrastructure. No sandbox design, filesystem or process policy, or network egress control is documented.

## Products

Agent System of Record deactivation, Agent Gateway, MCP Gateway, Agent System Users

## Gaps

Stop takes up to a minute and covers Workday API access only, not the external agent's own runtime. Effect on issued OAuth tokens is not stated. Sana code execution isolation and egress are undocumented.
