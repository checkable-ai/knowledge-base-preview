## Answer

Not covered. Workday documents an audit trail separating By User and On Behalf Of User, and input/output reports for Workday-built agents retained for 30 days. No write-once, immutable or integrity-validated storage is documented, and no documented export of the agent action record to such storage. Nearby features (audit logging, agent reports) fall short on tamper evidence and retention.

Research detail: Every agent transaction is logged, with the agent ASU as By User and the human as On Behalf Of User in delegate mode. Agent Compliance reports provide input and output details for the past 30 days. Tamper resistance and capture of model reasoning are not stated.
