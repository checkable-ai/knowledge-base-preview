## Answer

Not covered. Each agent gets a unique Agent System User account, but the documentation does not define an accountable owner on the agent or ASU, and the version field is not a release record tied to a deployed build.

Research detail: Each agent gets a unique Agent System User (ASU) account, up to one for delegate and one for ambient mode, each with its own OAuth 2.0 client. Agent definitions record the provider (Built By), platform (Built On) and a version field. The admin guide does not define an accountable owner on the agent identity.
