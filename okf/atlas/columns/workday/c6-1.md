## Answer

Not covered. Agent Registry lists agents but no models or component records; HiredScore and Evisort agents sit outside ASOR.

Research detail: The Agent Registry lists registered agents with status and last admin change, and the All Agent Definitions data source reports on registered and unregistered definitions. Definitions include skills, input and output modes, and tools by Workday ID. Models and software component records are not registered.
