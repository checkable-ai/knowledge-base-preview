## Answer

Not covered. The MCP allowlist works per server name, not per tool or action, and applies to managed developer machines only (open preview).

Research detail: MCP Governance lets an admin define an Allowed MCP Servers policy. With enforcement on, Evo blocks any agent that tries to execute an out-of-policy server on the developer machine at invocation and tells the developer which policy fired.
