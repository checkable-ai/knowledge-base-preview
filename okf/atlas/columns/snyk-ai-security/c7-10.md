## Answer

Covered. Continuous Offensive Security (COS); snyk cos commands are Closed Beta, Enterprise plans only. Targets must be added to scope; out-of-scope hostnames are rejected at the proxy. Coverage reaches LLM-backed endpoints (prompt injection, tool abuse). The snyk redteam CLI is experimental.

Source statement: "An endpoint backed by an LLM is detected automatically." (https://docs.snyk.io/agent-security/evo-by-snyk/continuous-offensive-security-cos/targets)

Research detail: Continuous Offensive Security is an AI-driven pentesting engine for web applications, with a proxy that rejects requests outside the authorised scope and a reject list. The product page lists Agent Red Teaming, which simulates prompt injection and data exfiltration against AI agents and LLM apps. The snyk redteam CLI is experimental.

## Products

Continuous Offensive Security, Agent Red Teaming, snyk redteam CLI

## Gaps

The COS docs describe web application targets only, with no documented agent or LLM test configuration. The redteam CLI page is no longer in the docs and its help file is marked experimental.
