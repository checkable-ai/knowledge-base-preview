## Answer

Covered, with conditions. Discovery covers agents installed on end user machines, code and Claude Enterprise only. Support varies by agent and OS. Not every stdio server is in the catalog, and unidentified servers carry no risk assessment. The Claude Enterprise integration is in early access.

Source statement: "Agent Supply Chain Security discovers these components and assesses each one for risk." (https://docs.snyk.io/agent-security/evo-by-snyk/agentic-development-security-ads/agent-supply-chain-security)

Last checked 16 November 2026.

Research detail: AI-SPM finds models, packages, agents, tools, MCP servers and datasets in repositories, with LLM-validated custom discovery for in-house frameworks. Agent Supply Chain Security finds MCP servers and skills on developer machines through scheduled scans. The Claude Enterprise integration adds models and MCP servers used in that tenant.

## Products

AI-SPM Discovery agent, Agent Supply Chain Security, Claude Enterprise integration

## Gaps
