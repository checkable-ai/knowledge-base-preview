## Answer

Covered. Covers code, managed developer machines and Claude Enterprise only. No network or SaaS discovery. Claude Enterprise is early access.

Source statement: "Agent Supply Chain Security discovers two types of assets that agents use: MCP servers and skills." (https://docs.snyk.io/agent-security/evo-by-snyk/agentic-development-security-ads/agent-supply-chain-security)

Research detail: AI-SPM finds models, packages, agents, tools, MCP servers and datasets in repositories, with LLM-validated custom discovery for in-house frameworks. Agent Supply Chain Security finds MCP servers and skills on developer machines through scheduled scans. The Claude Enterprise integration adds models and MCP servers used in that tenant.
