## Answer

Not covered. No documented look-alike or name squatting checks or registry reputation checks. Uncatalogued stdio servers get no assessment.

Research detail: Agent Supply Chain Security discovers MCP servers and skills across 14 coding agents and scores them for prompt injection and dangerous words in tool descriptions, untrusted content, malicious code, suspicious downloads, unverifiable dependencies and hardcoded secrets. Skills and MCP servers from Claude Code plugins are covered. The open-source Agent Scan CLI performs similar scans locally.

## Products

## Gaps

Name squatting and registry reputation checks are not documented. Stdio servers not yet in the Snyk catalog get no risk assessment. Skills from the Claude Skill Marketplace are not detected.

## Options

Add registry allowlisting and package reputation checks, and track catalog coverage of the servers in use.
