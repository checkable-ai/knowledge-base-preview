## Answer

Covered, with conditions. The Claude Enterprise integration is in early access. Contact your Snyk account team to enable it. It needs Snyk Evo with the Anthropic Claude Enterprise integration enabled. It needs a Claude Enterprise account and the Primary Owner role to create a Compliance Access Key.

Source statement: "The MCP servers tab lists every MCP server added to your Claude Enterprise organization." (https://docs.snyk.io/agent-security/cloud-ai-platforms/anthropics-claude-enterprise)

Last checked 16 November 2026.

Research detail: The MCP Servers page shows every MCP server across code, machines and runtime with its exposure spread and risks. For each server Evo shows the tools it exposes and its instructions, and risk indexes flag private data access and destructive capabilities. The Claude Enterprise integration shows approved MCP servers and tool-level permission restrictions.
