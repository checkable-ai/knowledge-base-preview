## Answer

Research detail: MCP Governance enforces an MCP server allowlist on developer machines through agent hooks, blocking out-of-policy servers at invocation. Agent Supply Chain Security scores each server for prompt injection in tool descriptions and destructive capabilities, which informs the allowlist.
