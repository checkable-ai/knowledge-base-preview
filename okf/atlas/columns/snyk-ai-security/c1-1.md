## Answer

Not covered. Agent Behavior Governance (open preview) has MCP Governance as its only documented use case. No documented policies for file, shell or network actions on the agent's machine.

Research detail: Agent Behavior Governance installs hooks in Claude Code, Codex, Cursor and GitHub Copilot and evaluates each action against policy before it runs, with session context. The only documented use case is MCP Governance. Snyk Studio sample hooks can block package install commands until a package health check runs, for Cursor only.
