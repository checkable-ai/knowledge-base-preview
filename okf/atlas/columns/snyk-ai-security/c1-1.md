## Answer

Not covered. Agent Behavior Governance documents MCP Governance as its only use case. The page names no policies for file, shell or network actions on the agent's machine.

Last checked 16 November 2026.

Research detail: Agent Behavior Governance installs hooks in Claude Code, Codex, Cursor and GitHub Copilot and evaluates each action against policy before it runs, with session context. The only documented use case is MCP Governance. Snyk Studio sample hooks can block package install commands until a package health check runs, for Cursor only.

## Products

Agent Behavior Governance (open preview), Snyk Studio guardrail directives

<!-- chunk: gaps -->
## Gaps

Open preview, not connected to Evo surfaces, limited to 5k hook calls per machine per day. No documented policies for file, shell or network actions beyond MCP blocking.

<!-- chunk: options -->
## Options

Run in managed install mode and keep the coding agent's own permission settings. Test whether non-MCP actions are evaluated.
