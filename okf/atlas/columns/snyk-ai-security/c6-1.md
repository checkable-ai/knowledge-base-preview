## Answer

Covered. Discovery-driven. Organisation-scoped users see lower counts and not machine-discovered assets.

Source statement: "Inventory surfaces the AI assets discovered across your environment" (https://docs.snyk.io/agent-security/evo-by-snyk/platform-surfaces/inventory)

Research detail: Evo Inventory lists models, packages, agents, tools, MCP servers, MCP clients, MCP resources, datasets, skills, repositories and developer machines with risk context. MCP server records include the tools exposed. snyk aibom exports a CycloneDX 1.6 AI-BOM.

## Gaps
