## Answer

Partly covered. The vendor limits Agent Supply Chain Security to two asset types, MCP servers and skills. Command-line tools, IDE extensions, external services and network egress are not discovered or assessed. Local stdio MCP servers that are not in the Snyk catalog, which includes most internal first-party servers, end as Discovery only with no risk assessment.

Source statement: "Agent Supply Chain Security discovers two types of assets that agents use: MCP servers and skills." (https://docs.snyk.io/agent-security/evo-by-snyk/agentic-development-security-ads/agent-supply-chain-security)

Research detail: AI-SPM scans repositories for MCP servers, clients, tools and agents built in first-party code, and aibom test gates CI on Evo policy. Snyk Studio runs Snyk Code and Open Source scans on agent-generated code and dependencies. Agent Supply Chain Security assesses remote MCP servers by contacting them and skills from their files.

<!-- chunk: products -->
## Products

AI-SPM, snyk aibom test, Snyk Studio, Agent Supply Chain Security

<!-- chunk: gaps -->
## Gaps

Local stdio MCP servers are assessed only by matching the Snyk catalog, so internal first-party stdio servers end as Discovery only. CLIs, extensions and egress are not assessed.

<!-- chunk: options -->
## Options

Scan first-party MCP server source with Snyk Code and Open Source, and test with the open-source Agent Scan in a sandbox.
