## Answer

Covered. Built-in server-side tools on the API; Grok Build and Grok Bot have their own harnesses.

Source statement: "Built-in tools run on SpaceXSI's servers" (https://docs.x.ai/developers/tools/overview)

Research detail: Grok Build is a coding agent harness that runs tools locally, with TUI, headless and ACP modes, plugins, hooks and MCP servers. Grok Bot is a hosted computer-use harness. The API runs server-side tool loops for built-in tools.
