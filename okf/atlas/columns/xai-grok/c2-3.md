## Answer

Covered. Applies to the API code execution tool; Grok Build sandbox is optional and off by default.

Source statement: "No access to external networks or file systems" (https://docs.x.ai/developers/tools/code-execution)

Research detail: The API code execution tool runs Python in an isolated sandbox with no external network access and no persistence between requests. Grok Bot runs each user's work in a dedicated Firecracker microVM. Grok Build sandbox profiles limit filesystem and child-process network access locally.

<!-- chunk: products -->
## Products

Code execution tool, Grok Bot cloud computers, Grok Build sandbox

<!-- chunk: gaps -->
## Gaps

Within one user, all Grok Bot Bots share one computer. Grok Bot cannot run on-premises. Code sandbox limits are stated only generally.

<!-- chunk: options -->
## Options

Give sensitive Grok Bot workloads their own Cursor user. Use the strict Grok Build profile for untrusted repositories.
