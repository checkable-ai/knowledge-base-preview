## Answer

Not covered. No vendor documentation found for write-once or integrity-validated storage of agent action records, or a documented export to such storage. The audit log covers admin, security and authentication events. Grok Bot Action Recording (Enterprise only, off by default, 90-day retention) and SIEM or OpenTelemetry export are nearby features, but none are documented as tamper-evident.

Research detail: The Console audit log and Management API list administrative events such as key creation and team changes, filterable by user, text and time. Per-key request logging can record full requests and responses unless ZDR is on. Grok Bot Enterprise Action Recording keeps sanitised Bot actions for 90 days.
