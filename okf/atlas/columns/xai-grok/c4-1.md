## Answer

Not covered. No agent identity object tying an agent to owner, runtime and release. API keys are credentials, and Grok Bot acts as the signed-in member.

Research detail: API keys are bound to a team, named, and associated with the user who created them, and can carry an expiry. Grok Bot Team Bots have a named owner and managers. Grok Bot states that a Bot has no identity of its own and acts as the signed-in member. No documented agent identity links an agent to an owner, runtime and release.
