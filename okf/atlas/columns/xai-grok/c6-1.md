## Answer

Not covered. No unified register of models, agents and tools in use. The Console lists API keys, models and team resources separately, and the Management API manages keys and teams, but none produces an inventory of agents and tools with their components.

Research detail: The Management API lists API keys and the models and endpoint ACLs available to a team. Grok Business lists provisioned connectors, and Grok Bot admins list Team Bots under Manage Team Bots.
