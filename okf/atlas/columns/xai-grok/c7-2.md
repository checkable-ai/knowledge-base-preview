## Answer

Not covered. Nearby features are Grok Bot Action Recording, OpenTelemetry Export and Audit Log streaming to a SIEM (Enterprise only, Bot only), with secret scrubbing. These fall short: no documented detections or alerting rules, no named response owner, session and user linking is not documented, and nothing for xAI API usage.

Last checked 15 November 2026.

Research detail: Grok Bot Enterprise streams audit logs to a SIEM and exports Action Recording events through OpenTelemetry, with secret scrubbing and opt-in conversation content. The API offers only a pull API for audit events. Grok Build hooks can POST lifecycle events to an HTTP endpoint.

<!-- chunk: products -->
## Products

Grok Bot OpenTelemetry Export, Management API audit events, Grok Build hooks

<!-- chunk: gaps -->
## Gaps

No native SIEM connector or detections for API or grok.com use. Grok Bot telemetry runs through Cursor.

<!-- chunk: options -->
## Options

Forward audit events and Grok Build hook events into the SOC pipeline.
