## Answer

Not covered. No native SIEM connector or detections for API use.

Research detail: Grok Bot Enterprise streams audit logs to a SIEM and exports Action Recording events through OpenTelemetry, with secret scrubbing and opt-in conversation content. The API offers only a pull API for audit events. Grok Build hooks can POST lifecycle events to an HTTP endpoint.

<!-- chunk: products -->
## Products

Grok Bot OpenTelemetry Export, Management API audit events, Grok Build hooks

<!-- chunk: gaps -->
## Gaps
