## Answer

Covered, with conditions. The US endpoint (us.api.x.ai) serves only grok-4.7 and grok-4.6. Files, Collections and server-side tools are outside the US guarantee. Image, video and voice APIs need the global endpoint, which may route between regions. Token usage on the US endpoint costs 10% more. Zero Data Retention is a team-level setting. Grok Build policy pinning is enterprise-only. API Zero Data Retention is team-wide and subject to environment availability or negotiated Enterprise terms.

Source statement: "SpaceXSI may route requests between regions for capacity or reliability, so the processing location is not guaranteed." (https://docs.x.ai/developers/advanced-api-usage/regions)

Last checked 15 November 2026. This platform is checked on demand, so this answer has not been rechecked since.

Research detail: Models have dated slugs for pinned versions plus aliases, published context and per-tier rate limits. The US endpoint keeps handling, inference, moderation and retained data in the US. API data is kept 30 days by default and not used for training, and ZDR can be enabled per team with a response header confirming it.

## Gaps

Retired slugs silently redirect to grok-4.3. The US guarantee excludes Files, Collections, server-side tools and image, video and voice APIs.
