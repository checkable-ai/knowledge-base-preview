<!-- chunk: answer -->
## Answer

Covered. Scope is per key or team, not per agent.

Source statement: "Use the allowed_tools parameter to selectively enable only specific tools from an MCP server." (https://docs.x.ai/developers/tools/remote-mcp)

Research detail: API keys have no access by default and are granted models and endpoints through ACLs. Remote MCP takes an allowed_tools list per server. Grok Business admins must add a connector before members can use it and can configure its access controls and allowed sites. Grok Bot inherits a connector policy and MCP allowlist, and Enterprise network controls restrict destinations.

<!-- chunk: products -->
## Products

API key ACLs, remote MCP allowed_tools, Grok Business connector management, Grok Bot connector and network policy

<!-- chunk: gaps -->
## Gaps

Connector scope is per team, not per agent. Remote MCP require_approval is not supported. In Grok Bot, blocking a plugin does not block the same service in the browser.

<!-- chunk: options -->
## Options

Issue narrow API keys per workload and set allowed_tools on every MCP server. Combine Grok Bot connector and network policies.
