## Answer

Not covered. Secret redaction exists (not for web Chat), but no DLP policy for other data types or per-agent retrieval filtering.

Research detail: GitLab Duo scans code for secrets such as API keys and tokens and removes them before sending to LLMs. Retrieval is limited by composite identity project access.
