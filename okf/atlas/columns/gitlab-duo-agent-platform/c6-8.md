## Answer

Not covered. Custom agent and flow versions are immutable and pinned, but models, permissions and knowledge changes are not versioned, and rollback is not described.

Research detail: Changes to a custom agent's system prompt or a flow's configuration create immutable semantic versions. Groups pin a version and a Maintainer or Owner must choose to update. Repository publishing puts changes through merge request review.

## Products

## Gaps

Foundational items are not versioned. GitLab can change default models without an upgrade. Explicit rollback is not described. Governance rule changes are not versioned.

## Options
