## Answer

Covered. Credit caps at subscription and user level, lag of a few hours. Controls are per group, feature or user, not per agent. Prompt guards default to log only and exclude external agents.

Source statement: "You can set a monthly GitLab Credits cap at the subscription and user level to prevent unexpected overage charges." (https://docs.gitlab.com/subscriptions/gitlab_credits_dashboard/)

Research detail: All model calls pass through the GitLab AI Gateway (hosted or self-hosted). Owners select models per feature, credit usage caps apply per subscription, as a flat user cap or a per-user override, and HiddenLayer prompt guards can log or interrupt detected prompt injection.

<!-- chunk: products -->
## Products

AI Gateway, model selection, GitLab Credits usage caps, prompt guards

<!-- chunk: gaps -->
## Gaps

Routing and quotas are per group, feature or user, not per agent. Cap enforcement lags by a few hours. Prompt guards default to log only on GitLab.com and do not cover external agents.

<!-- chunk: options -->
## Options

Set prompt guards to Interrupt and configure flat user caps. Test injection detection with benign probes.
