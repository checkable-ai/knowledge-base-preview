## Answer

Covered. Remote flows on runners.

Source statement: "Runs the GitLab Duo CLI, which uses WebSocket to connect to the GitLab Duo Workflow Service." (https://docs.gitlab.com/user/duo_agent_platform/flows/execution/)

Research detail: On runners, the GitLab Duo CLI binary connects over WebSocket to the GitLab Duo Workflow Service and runs file and Git tools as the model directs. The same platform drives Agentic Chat in the UI and IDE.

<!-- chunk: products -->
## Products

GitLab Duo CLI executor, Duo Workflow Service

<!-- chunk: gaps -->
## Gaps

External agents (Claude Code, Codex) run their own harness with limited isolation and no GitLab prompt injection scanning.

<!-- chunk: options -->
## Options

Prefer native agents for sensitive projects or apply strict network policy to external agent jobs.
