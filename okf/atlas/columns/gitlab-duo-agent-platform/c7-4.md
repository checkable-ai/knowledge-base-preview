## Answer

Not covered. Sandbox and hardened image option exist, but no host attestation or scanning, default image runs as root, and unsandboxed fallback is possible.

Last checked 12 November 2026.

Research detail: Remote flows run in an isolated VM and SRT sandbox, with a hardened UBI 9 Minimal image option and documented runner requirements.

<!-- chunk: products -->
## Products

Remote execution environment sandbox, default Agent Platform image

<!-- chunk: gaps -->
## Gaps

Silent fallback to unsandboxed execution. Default image runs as root. No attestation of runner or gateway hosts.

<!-- chunk: options -->
## Options

Use dedicated group runners with privileged sandbox support and fail jobs that log the sandbox warning.
