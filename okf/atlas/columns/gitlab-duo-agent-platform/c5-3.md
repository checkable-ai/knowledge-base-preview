## Answer

Covered. Impact dashboard is private beta, GitLab.com only, by request. Spend is in credits.

Source statement: "Individual usage events for each user, with links to session details for each credit-based feature" (https://docs.gitlab.com/subscriptions/gitlab_credits_dashboard/)

Research detail: The GitLab Credits dashboard shows usage by user, by product and per event with links to sessions, marking automated flow subjects. The Agent Platform Impact dashboard shows credits by flow type and model, adoption and merge request cycle time for Duo-created versus user-created merge requests.
