## Answer

Covered. Group Owners select models per top-level group. Self-hosted option via GitLab Duo Agent Platform Self-Hosted. Retention varies by provider.

Source statement: "Every GitLab Duo feature uses a default model." (https://docs.gitlab.com/user/duo_agent_platform/model_selection/)

Research detail: Each feature has a named default model and top-level group Owners (or instance admins) select specific model versions per feature and can restrict Agentic Chat to a model list. Self-hosted AI Gateway with vLLM, Bedrock or Azure OpenAI keeps prompts in the customer network, including offline. Data usage documents zero retention with Fireworks AI and limited retention elsewhere.

<!-- chunk: products -->
## Products

Model selection, AI Gateway, GitLab Duo Agent Platform Self-Hosted

<!-- chunk: gaps -->
## Gaps

GitLab can change default models through the AI Gateway without an upgrade. A selected model that becomes unavailable has no fallback. Retention varies by provider.

<!-- chunk: options -->
## Options

Pin explicit models per feature rather than defaults and use self-hosted models where data handling must be fixed.
