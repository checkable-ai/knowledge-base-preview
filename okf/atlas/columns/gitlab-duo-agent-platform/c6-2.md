## Answer

Not covered. No built-in approval workflow for catalog items. Merge request review is a customer practice, and maintainers can edit directly.

Research detail: Definitions can live in a repository under agents/ and flows/, reviewed by merge request and published by the AI Catalog CI/CD component. On Self-Managed only administrators add MCP servers, and on GitLab.com GitLab administrators manage them centrally.
