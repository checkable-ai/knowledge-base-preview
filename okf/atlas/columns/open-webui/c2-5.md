## Answer

Covered. Tools and Functions run arbitrary Python on the server, so only trusted administrators should create or import them. Native tool calling is the documented mode; the older XML-based mechanism is legacy.

Source statement: "Open WebUI adds that data as JSON text to the tool result the model sees." (https://docs.openwebui.com/features/extensibility/mcp)

Last checked 17 November 2026.

Research detail: Open WebUI is the harness that exposes tools to models through native tool calling, MCP and OpenAPI servers, and Open Terminal. Admins set which tools reach which models and users.

<!-- chunk: products -->
## Products

Native tool calling, Open Terminal, tools and functions

<!-- chunk: gaps -->
## Gaps

Tools and functions run arbitrary Python on the server, so the harness is only as safe as the tools admitted to it.

<!-- chunk: options -->
## Options

Admit only reviewed tools and keep Tools Access restricted.
