How [Open WebUI](profile.md) addresses the [Model Gateway](../../controls/c3-1.md) control. Researcher verdict: escalated. Verification state: contested. Agents must not retrieve this page: escalated by the confirm agents, so a person settles it.

<!-- chunk: answer -->
## Answer

With our team for a decision. The agent checks did not agree on this finding.

Last checked 17 November 2026.

Research detail: Open WebUI restricts which models a user or group can use and offers filter functions that can inspect or change requests before they reach the model. It is not a model gateway with routing, quota or rate control, and the docs point to external gateways such as LiteLLM for that.

<!-- chunk: products -->
## Products

Model access control, filter functions

<!-- chunk: gaps -->
## Gaps

Per-user quotas, rate limits and injection screening are not native. The docs say they can be built as plugins.

<!-- chunk: options -->
## Options

Put an external model gateway between Open WebUI and the providers.
