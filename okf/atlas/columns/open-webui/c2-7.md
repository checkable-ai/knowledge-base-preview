## Answer

Escalated for a person to settle. The agent checks did not agree on this finding.

Last checked 17 November 2026.

Research detail: Open Terminal containers can be given CPU and memory limits, an egress allowlist and a private network. Terminals stops idle workspaces. Admins can remove a user's API key or turn the API key feature off, and users can stop a running reply.

<!-- chunk: products -->
## Products

Container resource and egress limits, Terminals idle timeout, API key toggles

<!-- chunk: gaps -->
## Gaps

No single documented kill switch stops a running agent and revokes its access at once. Egress filtering needs extra container capabilities. Idle timeout is disabled by default.

<!-- chunk: options -->
## Options

Test how fast disabling a user and removing their keys stops an active session, and rely on network policy for hard cut-off.
