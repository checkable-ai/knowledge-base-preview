How [Open WebUI](profile.md) addresses the [Credential Brokerage](../../controls/c4-2.md) control. Researcher verdict: escalated. Verification state: contested. Agents must not retrieve this page: escalated by the confirm agents, so a person settles it.

<!-- chunk: answer -->
## Answer

With our team for a decision. The agent checks did not agree on this finding.

Last checked 17 November 2026.

Research detail: API keys can be replaced or deleted with immediate effect. Admin-configured Open Terminal connections keep the terminal API key on the server and out of users' browsers. Audit logging masks fields whose names end in password, secret, token, key or authorization. There is no documented brokered, expiring credential service.

<!-- chunk: products -->
## Products

API key management, admin-configured tool and terminal connections, audit log masking

<!-- chunk: gaps -->
## Gaps

The SCIM token is a static bearer token. No rotation schedule or expiry for keys is documented. The Session and OAuth modes pass user tokens to the tool server.

<!-- chunk: options -->
## Options

Keep credentials in an external secrets manager, use short-lived tokens at the tool server and rotate the static SCIM token.
