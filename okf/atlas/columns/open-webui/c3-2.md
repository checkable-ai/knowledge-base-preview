## Answer

Partly covered. No native tool schema enforcement, quotas, rate limits or injection screening, and no central policy for tool internet egress.

Source statement: "Tools the user cannot access are silently skipped, so the model won't be able to call them." (https://docs.openwebui.com/features/extensibility/plugin/tools)

Research detail: Admins control which tool and MCP servers are registered, users only reach tools they have access to, and the experimental Tool Permissions mode can require approval per call. Authoring tools is treated as granting server code execution.

<!-- chunk: products -->
## Products

Tool access control, MCP admin gating, Tool Permissions

<!-- chunk: gaps -->
## Gaps

No tool schema enforcement, quotas, rate limits or injection screening are documented as native features. Egress for tools is not governed by a central policy.

<!-- chunk: options -->
## Options

Place tool servers behind a gateway that enforces schemas, quotas and egress.
