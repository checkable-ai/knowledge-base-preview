## Answer

Partly covered. No approval gates, and no versioning or rollback described for prompts, tools, permissions or knowledge.

Source statement: "Every Save & Update that changes a model's configuration is kept as a version." (https://docs.openwebui.com/features/workspace/models)

Last checked 17 November 2026.

Research detail: Workspace models keep every saved configuration as a version with an author and a description, and any version can be set live. Event webhooks cover configuration and model events.

<!-- chunk: products -->
## Products

Model version history, event webhooks

<!-- chunk: gaps -->
## Gaps

Versioning is documented for models. Approval gates and rollback for prompts, tools and permissions are not described.

<!-- chunk: options -->
## Options

Use version history with an external approval step before saving to production.
