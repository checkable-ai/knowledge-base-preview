## Answer

Partly covered. No native data loss prevention engine; the vendor documents only access grants and permissions plus optional custom filters.

Source statement: "Access is governed by roles, groups, permissions, and resource-level access grants." (https://docs.openwebui.com/security/chat-data-privacy-and-encryption)

Last checked 17 November 2026.

Research detail: Knowledge retrieval checks the asking user's access to each attached knowledge base, so users do not see content they cannot access. File upload and knowledge permissions can be set by group. Filter functions can be written to mask sensitive content.

<!-- chunk: products -->
## Products

Knowledge access checks, upload permissions, filter functions

<!-- chunk: gaps -->
## Gaps

No native DLP engine is documented. Filters are custom code that an admin must write and maintain.

<!-- chunk: options -->
## Options

Connect a DLP service through a filter function or an upstream gateway.
