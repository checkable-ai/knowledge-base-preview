## Answer

Covered. Needs ENABLE_OTEL set and an OpenTelemetry-compatible backend such as the example Grafana LGTM stack. Outside the official Docker images, OpenTelemetry dependencies may not be installed by default. Anomaly detection and alerting are left to the backend.

Source statement: "WebUI exports the following metrics via OpenTelemetry:" (https://docs.openwebui.com/reference/monitoring/otel)

Last checked 17 November 2026.

Research detail: Open WebUI exports OpenTelemetry traces, metrics and logs, covering requests, database and Redis queries and response times, for tools such as Grafana and Prometheus. The architecture page lists observability integration for high availability setups.

## Products

OpenTelemetry export

## Gaps

## Options
