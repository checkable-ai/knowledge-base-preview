## Answer

Covered. Admins can turn memory off with ENABLE_MEMORIES (default on) or restrict it by role or group. Memory quality depends on the model.

Source statement: "Open WebUI includes a memory system that lets models remember facts, preferences, and context across conversations." (https://docs.openwebui.com/features/chat-conversations/memory)

Last checked 17 November 2026.

Research detail: A memory system lets models save and recall facts across conversations through memory tools. Users can view, edit and delete memories, and admins can turn memory off for the instance or restrict it by group or role.
