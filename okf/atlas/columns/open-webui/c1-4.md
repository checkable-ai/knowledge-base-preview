## Answer

Covered. Creating Tools and Functions is restricted to trusted administrators by default. Terminals policy changes apply only to newly provisioned workspaces. SCIM 2.0 manages user accounts, not agents.

Source statement: "Every Save & Update that changes a model's configuration is kept as a version" (https://docs.openwebui.com/features/workspace/models)

Last checked 17 November 2026.

Research detail: SCIM 2.0 lets an identity provider create and retire user accounts. Workspace models are shareable agent presets with access control and version history, and the Terminals orchestrator applies admin policies when it provisions a workspace. Creating tools and functions is restricted to trusted users.

<!-- chunk: products -->
## Products

SCIM user provisioning, workspace models, Terminals policies

<!-- chunk: gaps -->
## Gaps

SCIM manages users, not agents. Agent presets have no documented retirement workflow. Policy changes reach only newly provisioned workspaces. The SCIM page itself was refused by the reader, so only the hardening page was used.

<!-- chunk: options -->
## Options

Drive user lifecycle with SCIM and keep agent presets under an external change process.
