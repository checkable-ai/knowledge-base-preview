## Answer

Covered. Direct Tool Servers permission is needed for users to add personal OpenAPI servers and it also needs ENABLE_DIRECT_INTEGRATIONS. Access control can scope shared servers to users or groups.

Source statement: "MCP servers can only be added by administrators, under Settings > Integrations (admin section)." (https://docs.openwebui.com/features/extensibility/mcp)

Last checked 17 November 2026.

Research detail: Admins control which tool and MCP servers exist, and regular users cannot register MCP servers. Access control on each model, tool and knowledge base limits which users can reach it. Users only get tools they have read access to. Direct OpenAPI tool servers are off by default.

<!-- chunk: products -->
## Products

MCP admin gating, access grants on tools and knowledge, Direct Tool Servers permission

<!-- chunk: gaps -->
## Gaps

Scopes are per tool server and per tool, with no documented read versus write action scopes inside a connected system. Admin-added servers run with the connecting user's full scope.

<!-- chunk: options -->
## Options

Add only narrowly scoped tool servers and enforce action limits at the downstream system or a gateway.
