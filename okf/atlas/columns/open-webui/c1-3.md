## Answer

Covered, with conditions. The Tool Permissions feature is experimental and off by default; administrators must turn it on. Channel replies run with full access. Temporary chats deny a pending call after 120 seconds without an answer.

Source statement: "The reply stops at the first tool call." (https://docs.openwebui.com/features/extensibility/plugin/tools)

Research detail: An experimental Tool Permissions setting adds an Ask for approval mode where a tool call stops until the user picks Allow or Deny, and a denied call is returned to the model as an error. An Auto mode asks for approval only where a policy says so. Tool calls run immediately by default.

<!-- chunk: products -->
## Products

Tool Permissions (Ask for approval and Auto modes)

<!-- chunk: gaps -->
## Gaps

Experimental and off by default. The approval is by the same user, with no separate approver. In the default Auto engine the chat model judges its own calls and can be steered. No binding of a decision to the exact action or replay handling is documented.

<!-- chunk: options -->
## Options

Turn on Tool Permissions with Ask for approval for high-risk groups and prefer the Decisions API engine over the default Auto engine.
