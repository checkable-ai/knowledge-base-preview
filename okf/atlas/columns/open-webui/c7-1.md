## Answer

Not covered. Audit logging records API activity to a file or stdout, but it is off by default and the docs describe no write-once or integrity-validated storage and no tamper detection. No documented export to such storage.

Last checked 17 November 2026.

Research detail: Audit logging records API activity with user, IP, method, URL, timestamp and requested model. Levels run from metadata to full request and response bodies, output goes to a file or stdout, and sign-in events are always audited. Secret-like fields are masked.
