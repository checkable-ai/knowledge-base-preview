## Answer

Escalated for a person to settle. The agent checks did not agree on this finding.

Last checked 17 November 2026.

Research detail: Open WebUI connects to model providers and local runtimes, and admins can restrict which models each user or group sees. Saved model presets keep a version history. Offline mode stops its own outbound calls, and the docs state that prompts reach whatever model endpoint is configured.

<!-- chunk: products -->
## Products

Workspace model presets and access control, offline mode, model connections

<!-- chunk: gaps -->
## Gaps

Open WebUI does not host models. Model versions, data handling and limits depend on the connected provider. No per-model operating limits are documented.

<!-- chunk: options -->
## Options

Prefer private or local endpoints for sensitive data and record the approved model list per group.
