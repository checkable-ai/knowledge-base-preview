## Answer

Covered, with conditions. The Terminals orchestrator requires an Open WebUI Enterprise License for production use, and the code execution page says it is under active development and not yet ready for production. Open Terminal runs in a Docker container; self-hosted. Pyodide and Jupyter are legacy engines, and Jupyter is off unless an administrator enables it.

Source statement: "It provisions a dedicated computer substrate for every Open WebUI user." (https://docs.openwebui.com/features/open-terminal/terminals)

Last checked 17 November 2026.

Research detail: Open Terminal runs commands in a Docker container with its own filesystem and processes, and the Terminals orchestrator gives each user a separate workspace with resource limits and a network boundary. Pyodide runs Python in the browser sandbox. Server side engines such as Jupyter are opt-in.

<!-- chunk: products -->
## Products

Open Terminal, Terminals orchestrator, Pyodide, Jupyter engine

<!-- chunk: gaps -->
## Gaps

Terminals needs an enterprise licence for production use. Pyodide and Jupyter are described as legacy engines. Multi-user mode in one container shares the kernel.

<!-- chunk: options -->
## Options

Use one Terminals workspace per user on Kubernetes for isolation between users.
