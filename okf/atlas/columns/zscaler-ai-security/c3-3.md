## Answer

Not covered. No documented filtering of what data each agent or user can retrieve. Inline DLP and AI Guard detectors address prompts and responses only.

Research detail: Inline DLP blocks sensitive data in prompts using more than 100 dictionaries covering source code, PII, PCI and PHI, and browser isolation can restrict copy and paste into AI apps. AI Guard adds PII, PII DeepScan, Secrets and regex Text detectors on prompts and responses, applied per user or group.
