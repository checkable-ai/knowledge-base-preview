## Answer

Out of scope. Credential issuance, rotation and revocation for agents is a vault or identity function, not an AI security gateway or posture function.

Research detail: No credential vault or brokerage is documented. AI Guard has a Secrets detector that blocks API keys in prompts and responses, and MCP server scanning accepts authentication headers for its own connection. Neither delivers scoped credentials to agents.
