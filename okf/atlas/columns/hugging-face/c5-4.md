## Answer

Not covered. Endpoint analytics and logs show load and latency for endpoints only. No anomaly detection or alerting, and the OpenMetrics API is beta.

Last checked 16 November 2026.

Research detail: Inference Endpoints show requests by status, pending requests, latency percentiles, replicas and CPU, GPU and memory usage, plus runtime logs. Team and Enterprise can export metrics through an OpenMetrics API, in beta.
