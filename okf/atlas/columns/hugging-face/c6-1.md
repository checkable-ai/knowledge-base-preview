## Answer

Not covered. No organisational register of models, agents and tools in use with their components. Base-model metadata on model cards, repository lists and agent configuration files describe individual artefacts, not a current inventory of what an organisation uses.

Last checked 16 November 2026.

Research detail: The Hub is a registry of models, datasets and Spaces, each with model card metadata covering licence, datasets, base model and task. The Inference Endpoints dashboard lists deployed endpoints with creator and tags.

## Products

## Gaps
