## Answer

Not covered. Fine-grained tokens, rotation and revocation apply to Hugging Face credentials only. There is no broker for third-party secrets, and the sandbox docs say credentials reachable from a sandbox should be treated as potentially exposed to it, so secrets-never-reach-the-model is not met.

Research detail: Fine-grained tokens scope access to named repositories or organisations. Trusted Publishers exchange a CI OIDC token for a short-lived Hub token, and organisation Token Exchange issues tokens that expire after 8 hours by default. Admins can deny or revoke member tokens, and any leaked token can be revoked through a public endpoint. Sandboxes do not forward the HF token by default.

## Products

Fine-grained tokens, Trusted Publishers, OAuth Token Exchange, Tokens Management, service account token rotation, Spaces and Endpoints secrets

<!-- chunk: gaps -->
## Gaps

Covers Hugging Face credentials only. User access tokens have no documented mandatory expiry. No broker keeps third-party secrets out of model context. The sandbox docs warn that credentials reachable from a sandbox may be exposed to it.

<!-- chunk: options -->
## Options

Use Trusted Publishers or Token Exchange for short-lived tokens. Enforce the fine-grained-only or approval token policy. Keep other secrets in an external vault.
