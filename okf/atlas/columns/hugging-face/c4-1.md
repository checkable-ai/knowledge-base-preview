## Answer

Not covered. Service Accounts are generic organisation-owned identities with a free-text description. No agent identity type tied to owner, runtime and release.

Research detail: Enterprise organisations can create service accounts, which are organisation-owned identities for programmatic access with no password and no interactive sign-in. Access is defined entirely by fine-grained tokens issued to the account. The identity is generic, not agent-specific.

## Products

Service Accounts (Enterprise and Enterprise Plus)

## Gaps

No agent identity type, and no link from the identity to a runtime, release or accountable owner beyond a free-text description.

<!-- chunk: options -->
## Options

Create one service account per agent and record owner, runtime and release in an external inventory keyed by service account name.
