## Answer

Covered, with conditions. Applies to dedicated Inference Endpoints only. Hosting is on AWS, Microsoft Azure or Google Cloud Platform, chosen per endpoint. Available instance types depend on the selected deployment region. AWS PrivateLink is only available for endpoints deployed on AWS. Pinning a commit revision is optional. Inference Endpoints requires an active subscription and a credit card on file, with separate compute charges. Smolagents is an experimental API. A GDPR data processing agreement requires an Enterprise Hub subscription.

Source statement: "Commit Revision: Optionally specify a commit hash to which revision of the model repository on the Hugging Face Hub you want to download the model artifacts from" (https://huggingface.co/docs/inference-endpoints/guides/configuration)

Last checked 16 November 2026.

Research detail: Inference Endpoints deploy a chosen Hub model to a chosen cloud, region and instance, with an optional pinned commit revision, private, authenticated or public access, AWS PrivateLink and autoscaling limits. Inference Providers route requests to partner providers through one API, and Hugging Face states it does not store request or response bodies.

<!-- chunk: products -->
## Products

Inference Endpoints, Inference Providers

<!-- chunk: gaps -->
## Gaps

For Inference Providers, data handling at each partner follows that provider's own policy. Revision pinning is optional.

<!-- chunk: options -->
## Options

Pin commit revisions on Endpoints. Restrict Inference Providers to approved providers in organisation settings.
