## Answer

Covered. Applies to dedicated Inference Endpoints only. Commit revision pinning is optional. AWS PrivateLink is only available for endpoints on AWS. Inference Providers partner models follow the partners' own data policies.

Source statement: "Additionally, you can select the deployment region (e.g., East US) using the dropdown menu." (https://huggingface.co/docs/inference-endpoints/guides/configuration)

Research detail: Inference Endpoints deploy a chosen Hub model to a chosen cloud, region and instance, with an optional pinned commit revision, private, authenticated or public access, AWS PrivateLink and autoscaling limits. Inference Providers route requests to partner providers through one API, and Hugging Face states it does not store request or response bodies.

<!-- chunk: products -->
## Products

Inference Endpoints, Inference Providers

<!-- chunk: gaps -->
## Gaps

For Inference Providers, data handling at each partner follows that provider's own policy. Revision pinning is optional.

<!-- chunk: options -->
## Options

Pin commit revisions on Endpoints. Restrict Inference Providers to approved providers in organisation settings.
