## Answer

Not covered. No agent security telemetry, SIEM streaming, detections or response ownership. Audit log export covers admin events only.

Research detail: Audit logs can be exported through an API for ingestion into a SIEM, and events include token approvals, revocations and SSO logins. Secrets scanning emails owners about verified leaked secrets. Enterprise Plus can add request-level download logs as a custom export.
