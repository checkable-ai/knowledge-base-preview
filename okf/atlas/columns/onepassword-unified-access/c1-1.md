## Answer

Not covered. No general local permission model for files, commands or tools; limits rely on the AI client's own settings. Agentic Mode and Environments hooks cover only browser tab scope and .env validation.

Research detail: Agentic Mode in the browser extension limits 1Password to the tab the agent controls and hides its own interface there. Environments hooks validate mounted .env files before supported coding agents run shell commands. Apono documents how to force AWS access through its gateway using AI client managed settings and OS-level read denies.
