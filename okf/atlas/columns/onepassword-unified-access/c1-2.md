## Answer

Covered. Privileged Access (Apono) with managed or custom MCPs; action categories are coarse (Read, Create, Update, Delete, Admin).

Source statement: "Each agent gets a task-specific identity with scoped access." (https://1password.com/product/privileged-access)

Research detail: Privileged Access gives each agent task-scoped, time-limited access through agentic access flows that set resources, permissions, duration and approvals, provisioned in the target's native policy layer such as AWS IAM or Kubernetes RBAC. Intent policies on each MCP allow, pause for approval or block calls by action category. Service accounts are limited to chosen vaults with per-vault read, write or share permissions.
