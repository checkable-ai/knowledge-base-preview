## Answer

Covered. Requires Privileged Access (Apono Agent Privilege Guard). Human-in-the-loop applies by default to Create, Update and Delete actions on MCP servers. Approval is given in the client or an external channel such as Slack. The page does not document binding to exact parameters or retry behaviour beyond each gated action pausing for approval or rejection.

Source statement: "HIL approval determines whether a specific agent action can proceed." (https://docs.apono.io/docs/agent-privilege-guard/apono-agent-privilege-guard-reference/model-context-protocol-mcp-servers)

Research detail: Apono HIL guardrails pause a specific MCP tool call until a human approves or rejects it in the client or a channel such as Slack, separate from approval of the access grant. Agentic Autofill and 1Password for Claude require an approval prompt per request, release only selected items to that session, and do not carry approvals over.
