## Answer

Not covered. No documented propagation of the initiating user's identity or delegated scopes to downstream systems. Apono ties a session to a user but provisions access to the agent identity. Broker delegation logging is roadmap.

Research detail: Apono agentic access flows define on whose behalf an agent can request access, and each AI session is tied to the user the agent acts for. Agentic Autofill releases credentials only after the user approves in their own 1Password app. Credential Broker plans to log the delegating team member alongside the agent identity.
