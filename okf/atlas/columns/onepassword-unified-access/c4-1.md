## Answer

Not covered. Apono Agent Privilege Guard creates an identity per AI client and user bound to a human operator, but it is not tied to where the agent runs or to a release or version. Credential Broker agent identity is roadmap only.

Research detail: Apono Agent Privilege Guard creates an agent identity automatically when a user first connects an AI client through the Agentic Gateway, named from the client and user and bound to that human operator. Credential Broker verifies GitHub Actions workloads by a platform-signed token naming repo, branch and workflow, checked against a trust policy. Broker support for AI agents is planned for later in 2026.

## Gaps
