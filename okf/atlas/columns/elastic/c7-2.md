## Answer

Covered, with conditions. Requires Elastic Security. The prebuilt rule needs guardrails configured in AWS Bedrock. The rule is licensed under Elastic License v2. Security for AI is in technical preview. The Redact processor needs a commercial licence.

Source statement: "Identifies multiple violations of AWS Bedrock guardrails by the same user in the same account over a session." (https://www.elastic.co/docs/reference/security/prebuilt-rules/rules/integrations/aws_bedrock/aws_bedrock_guardrails_multiple_violations_by_single_user)

Last checked 16 November 2026.

Research detail: Elastic Security is a SIEM that ingests Bedrock model invocation logs, maps them to gen_ai fields and runs detection rules from the aws_bedrock rules folder. Attack Discovery groups alerts into attacks with users, hosts and MITRE ATT&CK mapping. The AI Assistant can anonymise fields sent to the LLM.

## Products

Elastic Security, AWS Bedrock integration, Attack Discovery

## Gaps

## Options
