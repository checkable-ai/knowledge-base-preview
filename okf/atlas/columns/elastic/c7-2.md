## Answer

Covered. Prebuilt LLM detection rules focus on Bedrock. Other providers need custom ingestion. Requires Elastic Security.

Source statement: "We use these LLM-specific fields collected for detection engineering purposes." (https://www.elastic.co/security-labs/threat-command/elastic-advances-llm-security)

Research detail: Elastic Security is a SIEM that ingests Bedrock model invocation logs, maps them to gen_ai fields and runs detection rules from the aws_bedrock rules folder. Attack Discovery groups alerts into attacks with users, hosts and MITRE ATT&CK mapping. The AI Assistant can anonymise fields sent to the LLM.

## Products

Elastic Security, AWS Bedrock integration, Attack Discovery

## Gaps
