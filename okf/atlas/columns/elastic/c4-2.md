## Answer

Not covered. No automatic rotation or short-lived per-call credentials; MCP connector auth is static headers. Expiring API keys fall short.

Research detail: LLM provider and MCP server credentials sit in inference endpoints or connectors, not in prompts. The MCP connector supports Secret-type headers that are encrypted. Elasticsearch API keys support optional expiry and deletion by owners or administrators. Rotation is not described on the API key page.

<!-- chunk: products -->
## Products

Inference endpoints, MCP connector Secret headers, Elasticsearch API keys

<!-- chunk: gaps -->
## Gaps

API keys have no expiry by default. MCP connector auth is static headers only, no OAuth. No documented automatic rotation or short-lived per-call credentials.

<!-- chunk: options -->
## Options

Set expiry on all keys, rotate through automation, and test that secrets never appear in conversation or trace data.
