## Answer

Not covered. No sandbox or file/process policy for agent code; host isolation and API key invalidation are not an agent stop.

Research detail: Agent Builder runs tools as Elasticsearch queries, workflows or remote MCP calls and offers no code sandbox. Elastic Defend host isolation blocks a host's network traffic except to Elastic Security and allowed addresses, triggered manually or by a rule response action, which can contain a host running an agent. The invalidate API key API stops a key from authenticating, which revokes an agent's Elasticsearch access.

<!-- chunk: products -->
## Products

Elastic Defend host isolation, Elasticsearch API keys

<!-- chunk: gaps -->
## Gaps

No sandbox, filesystem or process policy for agent code. Host isolation is whole-host network blocking and needs Elastic Defend installed. The API key page gives no timing for invalidation.

<!-- chunk: options -->
## Options

Run agents in a separate sandbox and use Elastic Defend isolation as the emergency stop for the host. Test key invalidation timing against a live agent session.
