## Answer

Covered. Require user confirmation (never, once, always) is generally available on Serverless only, planned for Stack. Bulk-imported MCP tools default to Never. Applies to agent calls only, direct Tools API calls skip it. Binding to exact arguments and replay handling are not documented.

Source statement: "Controls whether the agent asks you to approve a tool call before it runs." (https://www.elastic.co/docs/explore-analyze/ai-features/agent-builder/tools/mcp-tools)

Research detail: Custom tools can require user confirmation with never, once or always settings. In the UI this applies to workflow and MCP tools, and through the Tools API to all custom tool types. Confirmation applies only to agent calls, direct Tools API calls skip it, and sub-agents decline confirmation-requiring actions.
