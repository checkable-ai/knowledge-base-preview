## Answer

Covered, with conditions. Elastic Managed LLMs are available only through the Elastic Inference Service and use third-party providers for inference. On-premises (ECE, ECK, self-managed) needs version 9.3 or later and EIS with Cloud Connect. Billed per million tokens. Needs the manage_inference cluster privilege. Elastic Stack Agent Builder requires an Enterprise subscription. EIS region preferences constrain available models and processing locations. without a policy, nearest-region routing applies, with EU deployments routed within the EU.

Source statement: "The LLMs are configured for zero data retention: none of the prompts or outputs are stored by the service provider." (https://www.elastic.co/docs/reference/kibana/connectors-kibana/elastic-managed-llm)

Last checked 16 November 2026.

Research detail: The inference API creates named endpoints with an explicit inference_id for Elastic-hosted models and third-party providers including Bedrock, Anthropic, Azure and OpenAI. Agent Builder uses a default model or a per-request inference_id or connector_id. Agent Builder also routes low-effort tasks to a fast model, which cannot be turned off.
