## Answer

Covered. Per-agent tool assignment; Elasticsearch access follows the privileges of the user or API key. Scopes on external MCP servers depend on connector credentials.

Source statement: "Tools execute Elasticsearch requests with the privileges of the current user or API key." (https://www.elastic.co/docs/explore-analyze/ai-features/agent-builder/permissions)

Research detail: A request through Agent Builder must pass Kibana feature privileges, Elasticsearch cluster and index privileges and Kibana space scope. Tools run with the caller's privileges, and API keys cannot exceed their owner's rights. Each agent is assigned only selected tools, and index search tools are limited to named indices or patterns. DLS and FLS further restrict documents and fields.

<!-- chunk: products -->
## Products

Agent Builder permissions, Elasticsearch RBAC, DLS and FLS

<!-- chunk: gaps -->
## Gaps

Scopes on external MCP servers depend on the connector's static credentials. DLS has documented query limits and aggregation leakage.

<!-- chunk: options -->
## Options

Keep per-agent API keys with narrow index patterns, and test DLS against aggregation queries.
