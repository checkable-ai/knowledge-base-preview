## Answer

Covered. Agent Builder conversation history; retention controls not documented.

Source statement: "The persisted record of previous conversations between a user and the agents they've used." (https://www.elastic.co/docs/explore-analyze/ai-features/agent-builder/glossary)

Research detail: Agent Builder conversations persist and can be managed through the Kibana REST APIs. The Security AI Assistant keeps up to 99 recent conversations per user and has a knowledge base that stores specified information for reuse as context.
