## Answer

Not covered. No agent training on tasks and no continuous validation of agent behaviour. Trace dashboards show activity, token usage, latency and tool errors, but the page mentions neither alerting nor anomaly detection. The Security for AI anomaly jobs (technical preview, Platinum) cover only Bedrock tool use.

Last checked 16 November 2026.

Research detail: Elastic machine learning anomaly detection finds unusual patterns in time series data and can run on LLM and agent metrics. The AgentCore integration ships alert templates for runtime system errors, user errors and high latency from version 9.2.1. Bedrock Guardrails logs show whether guardrails blocked harmful responses.
