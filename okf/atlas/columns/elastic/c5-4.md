## Answer

Covered. Requires trace collection; integration coverage varies by provider.

Source statement: "Use them to break down usage and latency by model, agent, or tool." (https://www.elastic.co/docs/explore-analyze/ai-features/agent-builder/collect-traces)

Research detail: Elastic APM with EDOT SDKs traces LLM calls with duration, errors and token use, and integrations provide prebuilt metrics, logs and trace dashboards. The AgentCore integration adds runtime, gateway, memory and identity dashboards with sessions, latency, throttling and error splits, and alert templates. Machine learning anomaly detection can run on these metrics.
