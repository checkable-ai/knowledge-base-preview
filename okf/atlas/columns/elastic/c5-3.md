## Answer

Not covered. Token and model usage is tracked, but not infrastructure cost, staff time or return.

Research detail: Prebuilt LLM dashboards show model usage, performance and cost for Bedrock, Anthropic, Azure, Vertex AI and OpenAI integrations. Agent Builder traces record token usage per model, agent and tool, queryable with ES|QL. Labour cost, savings and output gains are not tracked.

<!-- chunk: products -->
## Products

Elastic Observability LLM and agent monitoring, Agent Builder traces

<!-- chunk: gaps -->
## Gaps

Cost is token and model based. The AgentCore integration has no token or cost dashboard of its own.

<!-- chunk: options -->
## Options

Join trace token data with price tables and business metrics in custom dashboards.
