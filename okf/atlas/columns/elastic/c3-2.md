## Answer

Not covered. No rate limits, egress control or dangerous-action filtering; per-agent tool assignment and confirmation are not a gateway.

Research detail: Each agent uses only its assigned tools, and MCP tools are imported one by one or in bulk by selection with a namespace. Tool calls run under the caller's privileges and can require confirmation. The input schema is fetched from the MCP server at call time.
