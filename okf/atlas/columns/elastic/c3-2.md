## Answer

Not covered. No gateway or control point for tool calls or internet access is documented: no rate limits, egress control, input-format enforcement or blocklist for dangerous actions. Per-tool confirmation prompts and inherited user privileges are nearby features, but they are approval and access control, and direct Tools API calls skip confirmation.

Last checked 16 November 2026. This platform is checked on demand, so this answer has not been rechecked since.

Research detail: Each agent uses only its assigned tools, and MCP tools are imported one by one or in bulk by selection with a namespace. Tool calls run under the caller's privileges and can require confirmation. The input schema is fetched from the MCP server at call time.
