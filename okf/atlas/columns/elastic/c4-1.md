## Answer

Not covered. Agent ID and creator exist, but no binding to where the agent runs or to a release version; agents are not Elasticsearch principals.

Research detail: Agent Builder custom agents have a unique agent ID set at creation, and the creating user is recorded as owner. Workloads calling Elasticsearch authenticate with API keys that carry metadata and show the creating user and realm. Neither links an agent to a runtime or release version.

## Gaps
