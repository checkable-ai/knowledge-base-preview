## Answer

Not covered. Retention settings apply only to security data held in SecOps (12 months by default, up to five years). They do not govern agent inputs, outputs or memory, and Gemini processing uses global endpoints.

Research detail: SecOps retains ingested data for 12 months by default, extendable to five years, applied instance wide with automated deletion. CMEK, VPC Service Controls and Assured Workloads boundaries including Australia are supported. Gemini processing uses global endpoints and may run in any global region.

## Gaps

Applies to security data held in SecOps, not agent inputs, outputs or memory in their own systems. No per log type retention and no manual deletion.
