## Answer

Not covered. UEBA targets users and devices, not AI agents. No curated AI agent threat detections. Customers must write their own rules.

Research detail: Risk Analytics for UEBA flags user and device activity that is unusual against historical baselines and peer groups. SecOps has default parsers for AI sources such as GCP Model Armor, Gemini Enterprise Agent Platform, Claude Code Observability and Model Context Protocol logs, so custom YARA-L rules can watch agent activity.

## Products

## Gaps
