## Answer

Not covered. No curated detections for AI agent threats, so customers write their own rules. Redaction of sensitive data in ingested agent content is not documented. Nearby features: default parsers for AI log types, cases, assignment to SOC roles and Triage Agent verdicts only help build the monitoring.

Research detail: SecOps is a SIEM and SOAR with default parsers for AI and agent log types including GCP_MODEL_ARMOR, GEMINI_ENTERPRISE_AGENT_PLATFORM, CLAUDE_CODE_OBSERVABILITY, CHATGPT_AUDIT_LOGS, MICROSOFT_COPILOT_INTERACTION, LANGSMITH_AUDIT and MCP log types. Detections become cases with playbooks, assignment to users or SOC roles, and Triage Agent verdicts. Data RBAC limits who sees which data.
