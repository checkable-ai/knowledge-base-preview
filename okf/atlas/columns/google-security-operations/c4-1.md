## Answer

Not covered. No per-agent identity, owner or release binding in SecOps. The MCP page accepts Google Cloud identities, which are issued outside SecOps.

Research detail: SecOps does not issue identities to customer agents. The MCP page lists an agent identity and credentials as one way an MCP client can authenticate, but that identity comes from Google Cloud agent tooling outside SecOps.
