## Answer

Covered. Applies to SOAR playbook actions set to Manual, assigned to a user or SOC role, with optional Approval links (Approve and Decline) and an optional Time to respond. Does not extend to arbitrary agent actions outside playbooks.

Source statement: "Use Approval links to send manual actions waiting for user input (pending actions) to users outside of the platform." (https://docs.cloud.google.com/chronicle/docs/soar/respond/working-with-playbooks/assign-approval-links-in-actions)

Research detail: SOAR playbook actions can be set to Manual and assigned to a user or SOC role. Approval links send Approve and Decline links for a pending action to people outside the platform, with an optional time to respond. Agent steps can also be set to Manual so an analyst runs them.

## Products

Google SecOps SOAR manual actions, approval links

<!-- chunk: gaps -->
## Gaps

The docs do not state how approval links are authenticated, whether they are single use, or what happens on decline or timeout. Approvals cover SOAR playbook actions, not arbitrary agent actions.

<!-- chunk: options -->
## Options

Test link reuse, expiry and decline handling before relying on approval links for containment actions.
