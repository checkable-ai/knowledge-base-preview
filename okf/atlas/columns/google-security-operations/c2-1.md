## Answer

Covered. Pre-GA. Agent steps in SOAR playbooks for the Triage and Investigation Agent on Google Cloud instances. Not general customer agents.

Source statement: "Toggle whether the step should attempt to rerun if the agent encounters a transient error." (https://docs.cloud.google.com/chronicle/docs/soar/respond/working-with-playbooks/agentic-automation)

Research detail: SOAR playbooks sequence deterministic steps with Pre-GA agent steps. Agent steps run asynchronously with Not Run, Running and Completed states, a retry on transient failure option, and error handling to stop the playbook or skip the step. Outputs such as verdict and confidence drive branching.

## Gaps
