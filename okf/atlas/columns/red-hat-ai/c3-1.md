## Answer

Covered, with conditions. Multi-tenancy and some external model passthrough are Technology Preview; prompt injection screening via separate NeMo Guardrails service.

Source statement: "Each model in a subscription can have different token limit configurations" (https://docs.redhat.com/en/documentation/red_hat_openshift_ai_self-managed/3.5/html/govern_llm_access_with_models-as-a-service/deploy-and-manage-models-as-a-service)

Last checked 13 November 2026. This platform is checked on demand, so this answer has not been rechecked since.

Research detail: Models-as-a-Service puts models behind an API gateway. Subscriptions give OpenShift or OIDC groups token rate limits per model with priority levels, authorisation policies control which groups reach which endpoints, and requests can route to external providers such as Bedrock, Azure OpenAI and Vertex AI. NeMo Guardrails adds jailbreak and prompt injection checks as a separate service.

## Products

## Gaps
