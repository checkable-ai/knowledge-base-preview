## Answer

Not covered. No ordering, hand-off, cancellation, retry or recovery of multi-step agent tasks. The Responses API is a single inference and tool endpoint, and orchestration is left to the application.

Last checked 13 November 2026.

Research detail: The OGX Responses API, generally available, combines inference, file search and tool calling through one endpoint. Multi-step agent workflows with retry and recovery are left to the application. AI pipelines cover ML workflows rather than agents.
