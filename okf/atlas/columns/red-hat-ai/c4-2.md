## Answer

Not covered. Models-as-a-Service API keys (custom expiry, per-key revocation) and secret references are user and provider oriented, not per-agent scoped credentials.

Research detail: Models-as-a-Service issues user API keys with an admin-set maximum expiry and revocation. External model providers are reached through ExternalProvider resources that reference a Kubernetes secret, so clients never see the provider key. OGX secrets are collected by the operator and rotated by updating the secret. Nothing is specific to agents.

## Products

Models-as-a-Service API keys and ExternalProvider secrets, OGX secrets management

## Options
