## Answer

Covered. OGX integration is Technology Preview in OpenShift AI 3.5; Tool Runtime API is Developer Preview.

Source statement: "generates model outputs by combining inference, file search, and tool-calling capabilities." (https://docs.redhat.com/en/documentation/red_hat_openshift_ai_self-managed/3.5/html-single/working_with_ogx/index)

Research detail: The OGX Responses API runs tool calls, including file search, inside a generally available endpoint. The Tool Runtime API that lets a model call a tool at runtime is Developer Preview. llm-d passes tool calling parameters through unchanged.
