## Answer

Not covered. Langfuse has no sandboxing of the files, processes or network access of customer agents, and no emergency stop for them. Halo's execution sandbox only isolates Langfuse's own assistant. Deleting a Langfuse API key only cuts the agent's access to Langfuse.

Research detail: Langfuse records traces of agents that run elsewhere and does not run or sandbox agent code, so it cannot contain or stop an agent. Deleting a Langfuse API key invalidates it immediately, which cuts off trace ingestion and API access for that key only. Self-hosted outbound URL allowlists and the aws-lambda dispatcher for code evaluators limit what Langfuse itself can reach, not what an agent can do.

## Gaps

No sandboxing, egress control or stop mechanism for agents. Key deletion and outbound allowlists apply to Langfuse's own access.

<!-- chunk: options -->
## Options

Contain and stop agents in the runtime or sandbox platform. Use Langfuse key deletion to cut an agent's telemetry or prompt fetch access.
