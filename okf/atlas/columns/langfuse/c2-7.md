## Answer

Not covered. No sandboxing, egress control or emergency stop for agents. Deleting an API key only cuts Langfuse access.

Research detail: Langfuse records traces of agents that run elsewhere and does not run or sandbox agent code, so it cannot contain or stop an agent. Deleting a Langfuse API key invalidates it immediately, which cuts off trace ingestion and API access for that key only. Self-hosted outbound URL allowlists and the aws-lambda dispatcher for code evaluators limit what Langfuse itself can reach, not what an agent can do.
