## Answer

Not covered. Prompt labels, versioning and dataset experiments cover prompt changes only. There is no proposal-to-retirement lifecycle for models, agents or use cases.

Research detail: Prompts move through labelled versions for environments such as staging and production, and experiments on versioned datasets test changes before promotion. Langfuse does not track models, agents or use cases from proposal to retirement.
