## Answer

Not covered. The Langfuse AI Gateway (public beta) lets admins choose allowed models per provider credential, but the documentation does not describe pinning a model version or endpoint per agent, setting where processing runs, or controlling how prompt data is handled. Tracing only records model use. The gateway's allowed-model list and rate limits are nearby features that fall short of the full outcome.

Research detail: Langfuse does not serve inference for applications. LLM connections call external providers only for the playground, prompt experiments and LLM-as-a-Judge.
