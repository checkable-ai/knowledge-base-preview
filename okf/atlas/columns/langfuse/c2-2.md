## Answer

Not covered. No per-agent model version or endpoint pinning, no control over where processing runs, and no provider-side prompt data handling controls. Gateway tracing and model approval fall short.

Last checked 15 November 2026.

Research detail: Langfuse does not serve inference for applications. LLM connections call external providers only for the playground, prompt experiments and LLM-as-a-Judge.

## Gaps

Model version and endpoint are recorded on generations when the application sends them, but Langfuse does not enforce them.

## Options
