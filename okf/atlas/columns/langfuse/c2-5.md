## Answer

Out of scope. Langfuse is an observability, evaluation and prompt-management platform. It records the tool calls of customer agents but does not run them. The Halo worker runs only Langfuse's own assistant, so it is not a tool runtime for customer agents.

Research detail: Langfuse does not execute tools. It records tool observations emitted by the application's harness.
