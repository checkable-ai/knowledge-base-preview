## Answer

Not covered. Langfuse does not control what customer agents may do in the external systems they connect to. Halo's role-filtered MCP tools and approval prompts for data changes cover only the built-in assistant's actions inside Langfuse. API key scoping limits access to Langfuse only.

Research detail: Langfuse does not grant or restrict agent actions against connected systems. Its RBAC scopes govern Langfuse users and API keys, not agents.
