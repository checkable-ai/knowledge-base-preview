## Answer

Not covered. No control over what customer agents may do in connected systems. Halo's permission limits and write approvals apply only to Langfuse's own assistant working in the Langfuse project. API key scopes only limit access to Langfuse.

Last checked 15 November 2026.

Research detail: Langfuse does not grant or restrict agent actions against connected systems. Its RBAC scopes govern Langfuse users and API keys, not agents.
