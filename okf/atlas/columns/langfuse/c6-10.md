## Answer

Covered. Data retention needs Cloud Pro or Enterprise, or self-hosted Enterprise Edition. It is not available on Hobby or Core. Retention is set per project, with no organization-level policy. Residency is through Cloud data regions or self-hosting.

Source statement: "Data retention is configured on a project level, and we accept a number of days with a minimum of 3 days." (https://langfuse.com/docs/administration/data-retention)

Research detail: Project retention deletes traces, observations, scores and media nightly after a set period (Pro, Enterprise, self-hosted EE). Deletion APIs remove traces, projects and accounts. Cloud offers separate US, EU, Japan and HIPAA regions, and self-hosting allows any location. This governs Langfuse's own copy of data, not agent inputs, outputs or memory elsewhere.

<!-- chunk: products -->
## Products

Data Retention, data deletion API, data regions, SDK masking

<!-- chunk: gaps -->
## Gaps

Retention does not cover datasets or audit logs. No permitted-use controls. ClickHouse trace data is not replicated cross-region.

<!-- chunk: options -->
## Options

Set retention per project, mask sensitive fields in the SDK, choose region or self-host, and delete datasets separately.
