## Answer

Not covered. No process for creating, changing permissions of or retiring agents. SCIM and the Organization API manage people and projects, not agents.

Research detail: SCIM and the Organization API provision human users, memberships, projects and project API keys (Enterprise). They do not manage agent identities or agent permissions.
