## Answer

Not covered. Nothing issues short-lived scoped credentials for customer agents, rotates them automatically or keeps secrets from models. The AI Gateway (public beta) holds provider keys and allows key rotation and revocation, and Langfuse project API keys only authenticate to Langfuse, so both fall short.

Last checked 15 November 2026.

Research detail: Langfuse stores LLM provider credentials, encrypted with ENCRYPTION_KEY, only for its own playground and evaluator calls. It does not broker credentials to agents or their tools.

## Gaps

LLM connections serve Langfuse features only. Key rotation for ENCRYPTION_KEY is not documented.

<!-- chunk: options -->
## Options

Use a secrets manager or credential broker for agents. Treat Langfuse project API keys as secrets in that broker.
