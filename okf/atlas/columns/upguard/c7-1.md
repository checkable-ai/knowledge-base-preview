## Answer

Not covered. UpGuard does not document a record of AI agent actions (tool calls, data access, changes) attributed to an agent and user or session. Its audit log covers administrative activity in the UpGuard platform only, and is not documented as write-once or integrity-validated. The shadow AI detection in User Risk shows AI tool usage but is not an agent action log. No documented export of agent actions to immutable storage.

Research detail: UpGuard keeps an audit log of platform events such as vendor, waiver, workflow, API key and User Risk policy changes, viewable for up to 18 months and exportable. It does not record agent actions, inputs, outputs or reasoning.
