## Answer

Not covered. UpGuard documents no submission, registration and approval workflow for new models, agents or AI tools. The nearest features fall short. In User Risk, employees can request access to a detected web app from the browser extension. Risk Automations can automate those requests and app usage reviews. Administrators then set app usage policies (Approve, Tolerate, Nudge, Block). These features control whether workforce members may use third-party browser applications. They do not record a new model, agent or tool in a register for governance approval before deployment. Vendor onboarding approval covers third-party vendors, not AI systems.

Research detail: Vendor onboarding requests, including an inbound portal on Professional plans and above, collect internal details so a vendor can be tiered and then approved or rejected. Users can request access to an app from the User Risk extension, routed to admins through Risk Automations, and admins approve or block apps.
