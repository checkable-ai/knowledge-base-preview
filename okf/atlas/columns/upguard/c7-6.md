## Answer

Not covered. Threat Monitoring surfaces MCP server definitions that reference the organisation in public registries. It does not scan the tools, plugins or skills the customer uses for look-alike names, poisoned descriptions or compromised packages.

Last checked 9 November 2026.

Research detail: Threat Monitoring surfaces MCP server definitions in public registries and marketplaces that reference the customer organisation. That can reveal lookalike or unofficial servers using the organisation's name.
