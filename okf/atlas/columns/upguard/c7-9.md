## Answer

Covered. User Risk; relies on directory integration and browser extension (Chromium browsers and Firefox); limited to apps on UpGuard's tracked list.

Source statement: "The number of SaaS applications that UpGuard has classified as shadow AI." (https://help.upguard.com/en/user-risk-executive-summary)

Research detail: User Risk discovers SaaS and AI apps through a directory integration (SSO and Entra OAuth consent) and a browser extension, and classifies some as Shadow AI. Detected apps appear in an Applications inventory with users, policy and security rating, and the executive summary counts Shadow AI apps.

## Products

UpGuard User Risk

<!-- chunk: gaps -->
## Gaps

Discovery is limited to apps on UpGuard's tracked list, seen in Chromium browsers or Firefox after a usage threshold (one minute by default). Safari, desktop clients, API keys and internally built agents are not covered.

## Options

Pilot the extension and Entra integration in a test tenant and compare detected AI apps against a known synthetic usage list.
