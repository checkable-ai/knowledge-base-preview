## Answer

Not covered. No sandbox or agent kill switch. Browser defence policies control employee app use only.

Research detail: UpGuard does not offer this. It is hosted SaaS for vendor, attack surface and user risk, and it does not run or sandbox agent code. The User Risk browser extension can apply browser defence policies to web apps a person uses, which is employee app control rather than containment or stopping of an agent.
