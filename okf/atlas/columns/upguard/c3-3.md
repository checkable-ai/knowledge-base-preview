## Answer

Not covered. The User Risk browser extension blocks uploads and paste into unapproved apps, but there is no content classification, no per-agent or per-user retrieval filtering and no coverage of APIs, desktop apps or agent traffic.

Research detail: The User Risk browser extension can block file uploads and copy and paste into apps flagged as Shadow AI when the user has Nudge access, and can block personal OAuth logins. This is per-user, browser-level data loss prevention toward AI web apps.

## Gaps

It is a coarse block, with no content classification or retrieval control documented. It covers Chromium browsers and Firefox only, not Safari, desktop apps, APIs or agent traffic.

## Options
