## Answer

Not covered. No retention, deletion or residency rules for agent data.

Research detail: MEASURE 2.10 asks for privacy risk to be examined and documented. MP-4.1-005 suggests policies for data collection and retention, GV-1.7-002 lists data retention among decommissioning factors, GV-6.2-007 raises secondary data use by vendors, and MG-3.1-002 names data localisation compliance as a value chain risk. Agent memory and residency rules are not set.
