## Answer

Not covered. Arize does not document ordering, cancelling, retrying or recovering the steps of a customer agent's task. The ag session subcommands are list, show, create, send, events, artifacts and delete, with no cancel or retry. PXI's parallel read-only subagents work inside Arize's own assistant and are not a control over agent task steps. Cancelling a playground run is about experiment runs, not agent steps.

Last checked 16 November 2026. This platform is checked on demand, so this answer has not been rechecked since.

Research detail: Arize does not orchestrate agent workflows. It traces orchestrators and sub-agents built in frameworks such as LangGraph, CrewAI and OpenAI Agents.
