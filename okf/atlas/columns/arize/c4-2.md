## Answer

Not covered. Arize documents a temporary, space-scoped credential per managed agent run and encrypted skill secrets, but not credential issuance for customers' own agents, automatic rotation or revocation of run credentials, or any guarantee that secrets never reach the model. The page says credentials belong on the skill or AI Provider integration, never in prompts, but it does not say whether the model can see secret values during a run.

Last checked 16 November 2026.

Research detail: Arize does not broker credentials to agents. AX service keys and Phoenix user and system API keys authenticate to Arize only. Phoenix stores secrets and AI provider credentials for its own evaluators and playground, managed by admins.
