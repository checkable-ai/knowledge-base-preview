## Answer

Not covered. Agent Trajectory graphs observed agent calls only. It does not show which downstream systems each agent can reach or what it can do there.

Research detail: The AX agent trajectory view draws agents as nodes and parent links as edges, showing which agents call which and where loops and failures occur. MCP tracing joins client and server spans into one trace.
