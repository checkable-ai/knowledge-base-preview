## Answer

Not covered. No agent sandbox limits and no kill switch. Arize does not run agent code.

Research detail: Arize AX and Phoenix trace, evaluate and monitor agents that run elsewhere. They do not run agent code, so they offer no sandbox, filesystem or egress policy, and no control to stop a running agent or revoke its access. Arize Guards can block or replace a single LLM message that fails a check, which is an output control inside the application, not a stop for the agent.
