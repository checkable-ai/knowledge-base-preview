## Answer

Covered, with conditions. PXI is in beta. PXI runs inside the customer's own Phoenix process. Arize AX managed agents are available on Enterprise. Codex, Cursor and OpenCode run only in the Arize sandbox. Claude Code can also run in a Claude Managed Agent environment when that option is enabled.

Source statement: "Bash runs in a sandboxed shell on the server with no network." (https://arize.com/docs/phoenix/pxi-advanced)

Last checked 16 November 2026. This platform is checked on demand, so this answer has not been rechecked since.

Research detail: Arize does not host the agent execution environment. Phoenix has sandbox providers for running code evaluators, configured by admins, but these run evaluation code only.

<!-- chunk: products -->
## Products

None for agents. Phoenix sandboxes for code evaluators.

<!-- chunk: gaps -->
## Gaps

No agent host or interpreter controls. Phoenix warns sandbox environment variables are readable by code running there.

<!-- chunk: options -->
## Options

Use a dedicated sandbox or container platform.
