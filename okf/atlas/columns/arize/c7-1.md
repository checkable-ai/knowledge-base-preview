## Answer

Not covered. Arize AX audit logs record platform user activity, not agent actions. Traces record agent tool calls but Arize documents no write-once or integrity-validated storage, and traces can be deleted. No documented export of agent action records to immutable storage.

Research detail: AX audit logs record login attempts, authenticated GraphQL mutations by users and data exports, retrieved by GraphQL with pagination. Traces separately store agent inputs, outputs and tool calls.

## Gaps

Audit logs cover Arize platform users, not agent actions. No tamper-proofing or retention period is documented, and the docs note operationName is client supplied. Traces can be deleted.

## Options
