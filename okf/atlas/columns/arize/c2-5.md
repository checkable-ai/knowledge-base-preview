## Answer

Covered, with conditions. Claude Code, Codex and OpenCode are supported. Cursor is available when enabled for the account. Hermes and OpenClaw are listed as coming soon. Codex, Cursor and OpenCode run only in the Arize sandbox. Claude Code can also run in a Claude Managed Agent environment when enabled. Custom Managed Agents require AX Enterprise.

Source statement: "Claude Code, Codex, and OpenCode are supported." (https://arize.com/docs/ax/agents/connect-your-harness)

Last checked 16 November 2026.

Research detail: Arize is not an agent harness and does not execute tools for customer agents. It instruments harnesses through OpenInference.
