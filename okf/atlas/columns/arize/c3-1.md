## Answer

Not covered. No gateway for routing, quotas, cost or rate limits. Guards run in application code and screen single messages, which falls short of a control point all model calls pass through.

Research detail: AX offers two Guards published on the Guardrails Hub. The Dataset Embeddings Guard flags jailbreak attempts by cosine distance to known bad prompts and the RAG LLM Guard judges relevance and hallucination. They run inside the application and can return a fixed response or reask. They do not route, rate limit or apply quotas.

Arize Dataset Embeddings Guard, RAG LLM Guard

## Gaps

Library-level screening only. Arize reports 86.43 percent detection on 656 jailbreak prompts with 13.95 percent false positives on 2,000 role-play prompts. No per agent or user routing, quota or cost enforcement.

<!-- chunk: options -->
## Options

Pair with a model gateway for routing and quotas. Test the Guard on local prompt sets before relying on it.
