## Answer

Covered, with conditions. PXI is in beta. The feature is in Phoenix (the PXI agent). The pxi terminal client requires Phoenix 20.0.0 or newer and a configured model provider.

Source statement: "Idle persisted chats are removed after 30 days without activity." (https://arize.com/docs/phoenix/settings/data-retention)

Last checked 16 November 2026. This platform is checked on demand, so this answer has not been rechecked since.

Research detail: Arize does not hold agent session state. Sessions group traces from a multi-turn conversation for viewing, search, latency and token use, which is a record of the session and not memory the agent reads.
