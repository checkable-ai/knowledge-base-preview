## Answer

Not covered. Prompt Hub and Phoenix tags version and roll back prompts only. No documented approval before a tag moves, and no versioning of models, tools, permissions or knowledge.

Research detail: AX Prompt Hub creates an immutable hashed version on each save, supports diffs and moves mutable tags to release or roll back without redeploying. Phoenix provides production, staging and development tags with linear history and retrieval by tag.
