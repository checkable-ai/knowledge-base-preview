## Answer

Covered. Select A2A v1.0 explicitly, because unversioned requests default to preview v0.3. Incoming v1.0 is JSONRPC and text only, with no streaming. Callers need the Foundry Agent Consumer role or equivalent.

Source statement: "The calling agent must present a valid Microsoft Entra token." (https://learn.microsoft.com/en-us/azure/foundry/agents/how-to/enable-agent-to-agent-endpoint)

Research detail: Source statement: A2A version 1.0 is generally available. Version 0.3 remains preview.

Assessment: Omitting version selection defaults to preview 0.3.

Source qualification: Requests without explicit version selection default to preview v0.3. Incoming v1.0 supports JSONRPC, text modality and no streaming. Select v1.0 explicitly for production integrations.
