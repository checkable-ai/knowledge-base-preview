## Answer

Covered, with conditions. Select A2A v1.0 explicitly, because unversioned requests default to preview v0.3. Incoming v1.0 is JSONRPC and text only, with no streaming. Callers need the Foundry Agent Consumer role or equivalent.

Source statement: "The calling agent must present a valid Microsoft Entra token." (https://learn.microsoft.com/en-us/azure/foundry/agents/how-to/enable-agent-to-agent-endpoint)
