## Answer

Covered. Needs Foundry agent tracing sent to workspace-based Application Insights (records land in Log Analytics tables), a Log Analytics data export rule on those tables (export is billed), and a Blob Storage account in the workspace's region with a version-level or container immutability (WORM) policy configured. Not every table type is supported for export, so check the supported tables list.

Source statement: "Export to a storage account set with immutability policies to keep data tamper protected." (https://learn.microsoft.com/en-us/azure/azure-monitor/logs/logs-data-export)

Research detail: Source statement: Tracing and Purview Audit record agent interactions under configured integrations.

Assessment: Retention and immutable export need separate controls.
