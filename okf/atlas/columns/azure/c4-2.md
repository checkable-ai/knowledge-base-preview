## Answer

Covered, with conditions. Applies to tools that use agent identity authentication, such as MCP servers and A2A endpoints. Other tool connections might use a project managed identity instead. Agent identity acting on behalf of the user (delegated access) is in preview. The AgentBlueprint endpoint authorization scheme is in preview. A new agent identity has no permissions until you grant them through the target service's authorization model. Uses Microsoft Foundry Agent Service with Microsoft Entra ID and service-managed tool authentication.

Source statement: "Agent Service uses the credential to create agent identities and request tokens at runtime through the hosted-agent token service or for a configured tool." (https://learn.microsoft.com/en-us/azure/foundry/agents/concepts/agent-identity)
