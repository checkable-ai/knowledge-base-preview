## Answer

Covered. Applies to tools that use agent identity authentication (e.g. MCP, A2A). Other tools may use project managed identity or keys. A new agent identity has no permissions until least-privilege RBAC is granted.

Source statement: "Let an agent authenticate to downstream systems (for example, Azure Storage) without embedding secrets in prompts, code, or connection strings." (https://learn.microsoft.com/en-us/azure/foundry/agents/concepts/agent-identity)

Research detail: Source statement: Tool connections support configured credentials and Entra authentication.

Assessment: Shared project credentials can widen the effective scope.
