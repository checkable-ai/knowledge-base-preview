## Answer

Not covered. Microsoft does not document a general Azure or Foundry workflow for submitting, registering and approving a new model, agent or tool. The closest feature is the Microsoft 365 publish flow for Foundry hosted agents published as autopilot blueprints. The blueprint is submitted, a Global Administrator or AI Administrator approves it in the Microsoft 365 admin center, and it then shows as Available on the Registry tab. This flow covers only autopilot blueprints. It needs Frontier preview enrolment, Microsoft Agent 365 terms acceptance, Microsoft 365 Copilot or Microsoft Agent 365 licences and a region that supports hosted agents. The approval only controls who can create instances in Microsoft 365. The hosted agent is built, versioned and receiving traffic in Foundry before anyone approves it. Models, tools, and agents that are not published to Microsoft 365, have no submission or approval step.

Last checked 17 November 2026.

Research detail: Source statement: Publishing and MCP approvals provide distinct approval surfaces.

Assessment: Tool-call approval does not approve an agent's business use.
