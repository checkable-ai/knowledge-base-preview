## Answer

Covered. Audit reports and scope statements are obtained from the Service Trust Portal. Microsoft Foundry is listed in scope for ISO/IEC 42001. IRAP and SOC 2 are covered on separate Azure pages.

Source statement: "Microsoft AI Systems undergo regular independent third-party audits for ISO/IEC 42001 compliance." (https://learn.microsoft.com/en-us/compliance/regulatory/offering-iso-42001)

Research detail: Microsoft's IRAP assessments cover Azure, Dynamics 365, Microsoft Managed Desktop and Office 365 up to and including PROTECTED, and Microsoft says agencies can use them in their own authority-to-operate risk assessment. Microsoft Foundry is listed in scope of Microsoft's ISO/IEC 42001 certification, and the Azure SOC 2 Type 2 report covers Azure services. Purview Compliance Manager has an assessment template for the Australian requirement.

<!-- chunk: products -->
## Products

IRAP PROTECTED assessments, ISO/IEC 42001, SOC 2 Type 2, Service Trust Portal, Purview Compliance Manager

<!-- chunk: gaps -->
## Gaps

The public IRAP page's latest dated assessment entry is December 2020, and the Foundry and Agent Service scope sits only in the Service Trust Portal. Agencies must still assess their own deployment.

<!-- chunk: options -->
## Options

Download the current Azure IRAP report from the Service Trust Portal and confirm Foundry Agent Service and each model deployment type are in scope.
