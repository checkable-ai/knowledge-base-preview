## Answer

Covered, with conditions. Skills in a toolbox are in preview. Not every tool is supported through a toolbox: function calling, Grounding with Bing, computer use, image generation, SharePoint, Fabric data agent and Azure Functions are direct-integration only. Backend permissions on the tools stay separate. MCP server governance supports Developer, Basic, Basic v2, Standard, Standard v2, Premium and Premium v2 tiers. Foundry network egress controls are in preview and apply only to hosted agents in the Foundry-managed sandbox.

Source statement: "Apply guardrails (Responsible AI policies) to tool inputs and outputs at the toolbox level." (https://learn.microsoft.com/en-us/azure/foundry/agents/concepts/toolbox-overview)
