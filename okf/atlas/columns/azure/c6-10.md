## Answer

Covered, with conditions. Configure each data store separately: standard setup keeps data in your own resources, Application Insights and Log Analytics retention apply to traces, and endpoints are regional. Memory is preview with region and model limits.

Source statement: "Foundry Agent Service endpoints are regional, and data is stored in the same region as the endpoint." (https://learn.microsoft.com/en-us/azure/foundry/agents/faq)
