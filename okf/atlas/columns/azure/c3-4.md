## Answer

Covered. Pair control is by Foundry Agent Consumer role assignment at agent scope. Use A2A v1.0 explicitly. v1.0 is text-only JSONRPC.

Source statement: "Assign the role at the target agent scope to allow the identity to call only that agent endpoint." (https://learn.microsoft.com/en-us/azure/foundry/agents/how-to/enable-agent-to-agent-endpoint)

Research detail: Source statement: Foundry supports incoming A2A and toolbox A2A tools.

Assessment: Protocol routing does not establish a universal agent-pair policy.

Source qualification: Requests without explicit version selection default to preview v0.3. Incoming v1.0 supports JSONRPC, text modality and no streaming. Select v1.0 explicitly for production integrations.
