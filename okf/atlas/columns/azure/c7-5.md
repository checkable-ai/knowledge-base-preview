## Answer

Not covered. No software bills of materials, no security scanning or review of MCP servers, skills, command-line tools or extensions, and no inspection of the tools' software supply chain. The nearest feature is the preview AI gateway (Azure API Management) for new MCP tools, which enforces authentication, rate limits, IP restrictions and audit logging on traffic. It does not inventory, scan or vet the tools themselves. It also excludes existing tools, SharePoint, OpenAPI, code-first MCP and managed OAuth tools, and does not log tool traces.

Last checked 17 November 2026.
