## Answer

Not covered. No documented per-action record of agent activity (tool calls, data access, changes) tied to an agent and user or session. Enterprise audit and access logs cover account and API activity, and the Data Security page says only that data access is logged and protected against tampering. Fireworks documents no write-once or integrity-validated storage for this record and no export of it to such storage. CMEK key-use events are recorded in the customer's cloud audit log, but that covers key operations, not agent actions.

Research detail: Enterprise audit logs record read, write and delete operations on storage with timestamp, principal, response code and resource path, filterable by email and API key ID. The security page states that customer data access is logged and protected against tampering.
