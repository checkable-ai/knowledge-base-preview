## Answer

Not covered. No documented security telemetry pipeline to a security operations team: no SIEM connector, detections, session or person correlation, redaction or named response owner. Audit log API polling falls short.

Last checked 17 November 2026.

Research detail: Audit logs can be pulled as JSON with firectl or the List Audit Logs REST API, and service account activity is kept separate from human activity.

<!-- chunk: products -->
## Products

Audit logs API

<!-- chunk: gaps -->
## Gaps

No native SIEM connector, detections or session correlation. Logs must be polled with pagination.

<!-- chunk: options -->
## Options

Poll the audit log API into a SIEM and build detections there.
