## Answer

Not covered. Provider Keys only brokers model provider keys. API keys have no documented scopes and do not expire unless expireTime is set; no short-lived scoped credentials for tools.

Research detail: Provider Keys let an admin store Anthropic, OpenAI or Bedrock keys once, encrypted at rest, so developers and gateways send only a Fireworks key and never receive the provider key. Keys can be replaced, unbound and deleted. Fireworks API keys support an optional expireTime and are shown only at creation, and account secrets are write-only.

<!-- chunk: products -->
## Products

Provider Keys, API keys, Secrets

<!-- chunk: gaps -->
## Gaps

Brokerage covers model provider credentials only, not tool or downstream system credentials. API keys have no documented scopes, and keys never expire if expireTime is unset. Provider Keys is not enabled on every account.

<!-- chunk: options -->
## Options

Set expireTime on every API key and use a vault or credential broker for tool credentials.
