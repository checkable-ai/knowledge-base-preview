## Answer

Covered. Applies to the Responses API. Stored responses are kept up to 30 days but sit in a cache and may be evicted sooner. Access is account-wide, with no per-user isolation documented.

Source statement: "You can immediately delete stored conversation data using the DELETE API endpoint by providing the `response_id`." (https://docs.fireworks.ai/guides/security_compliance/data_handling.md)

Last checked 17 November 2026. This platform is checked on demand, so this answer has not been rechecked since.

Research detail: Responses API conversations are stored by default and can be continued with previous_response_id, retrieved, listed and deleted. Stored conversation data is deleted automatically after 30 days, and store=false avoids storage.

## Products

Responses API

<!-- chunk: gaps -->
## Gaps

Access control is account-wide with no per-user or per-session isolation documented.

<!-- chunk: options -->
## Options

Set store=false and keep session state in the application where tighter access control is needed.
