## Answer

Covered. Prometheus metrics apply to on-demand (dedicated) deployments only; anomaly detection requires an external tool such as Datadog or Grafana.

Source statement: "Fireworks provides a metrics endpoint in Prometheus format," (https://docs.fireworks.ai/deployments/exporting-metrics.md)

Research detail: On-demand deployments expose Prometheus metrics for request rate, error rate, latency, tokens and KV cache use, which Prometheus, OpenTelemetry Collector, Datadog or Grafana can scrape.
