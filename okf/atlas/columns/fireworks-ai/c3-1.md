## Answer

Covered. Nexus Spend Limits are on request and apply to serverless models only. Model access policy is account-wide. No prompt injection screening documented.

Source statement: "After a user reaches their effective limit, requests to supported Fireworks serverless models return HTTP `402`." (https://docs.fireworks.ai/nexus/usage-limits.md)

Research detail: FireRouter is a single model ID that routes each turn across open and closed models. Spend Limits cap serverless spend per user, group or account default and return HTTP 402 when reached. Model access policy allows or denies models per capability, and rate limits apply per account and model.

<!-- chunk: products -->
## Products

FireRouter, Spend Limits, Model access policy, Serverless rate limits

<!-- chunk: gaps -->
## Gaps

Model access policy is account-wide with no per-user or per-group rules. No per-API-key limits and no prompt injection screening are documented. Spend Limits is on request and excludes dedicated deployments.

## Options

Front Fireworks with a gateway such as LiteLLM for per-key quotas and injection screening.
