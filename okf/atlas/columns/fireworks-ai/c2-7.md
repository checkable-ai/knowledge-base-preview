## Answer

Not covered. No sandbox, file/process/network limits or egress control. Key deletion and spend limits (excluding dedicated deployments) cut model access only, and policy changes take minutes.

Research detail: Fireworks hosts model inference and does not run customer agent code. Admins can delete API keys for users and service accounts, set Nexus spend limits that return HTTP 402 once a user reaches the cap (a cap of 0 blocks all supported serverless spend), and set an account-wide model access policy. Dedicated deployments can be deleted.

<!-- chunk: products -->
## Products

API key deletion, Nexus Spend Limits, model access policy.

<!-- chunk: gaps -->
## Gaps

Model access policy changes can take several minutes, and up to an hour for idle API keys, to apply, and the policy cannot differentiate users. The delete API key page does not state how quickly a deleted key stops working. Spend limits exclude dedicated deployments. No sandbox, egress control or immediate kill switch is documented.

<!-- chunk: options -->
## Options

Test how fast a deleted key stops requests, and run agent code in the customer's own sandbox rather than relying on the platform.
