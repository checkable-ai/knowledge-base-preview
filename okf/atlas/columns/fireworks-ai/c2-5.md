## Answer

Covered. Only server-executed tool types (mcp, sse, web_search, python) in the Responses API. Web search must be enabled for the account. Function tools run in the customer's application.

Source statement: "Server-executed (`mcp`, `sse`, `web_search`, `python`) run on Fireworks." (https://docs.fireworks.ai/guides/response-api.md)

Last checked 17 November 2026. This platform is checked on demand, so this answer has not been rechecked since.

Research detail: Fireworks does not ship its own agent harness. FireConnect is an open-source CLI that points third-party harnesses such as Claude Code, Codex, OpenCode and Cursor at Fireworks models, and the Responses API executes MCP and web search tools server side.
