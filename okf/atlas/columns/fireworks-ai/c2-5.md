## Answer

Covered. Applies to server-executed tool types only (mcp, sse, web_search, python) in the Responses API. Function tools and Codex namespace tools are run by the customer's application. The documented limit is max_tool_calls.

Source statement: "Pass an MCP server and Fireworks will discover its tools, call them, and feed the results back to the model." (https://docs.fireworks.ai/guides/response-api.md)

Research detail: Fireworks does not ship its own agent harness. FireConnect is an open-source CLI that points third-party harnesses such as Claude Code, Codex, OpenCode and Cursor at Fireworks models, and the Responses API executes MCP and web search tools server side.
