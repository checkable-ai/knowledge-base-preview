## Answer

Not covered. No sandbox, filesystem or process policy, egress control or kill switch. Agent Behavior Defense only flags, and the calling application decides the action.

Research detail: Lakera, now documented as Check Point AI Guardrails and AI Agent Security, screens content and tool calls and returns a flag. Agent Behavior Defense detects dangerous tool calls and a tool allow or deny list makes detection deterministic, but the integration guide says the calling application decides the action, so Lakera does not itself stop an agent. No sandbox, filesystem or process policy, egress control or kill switch is documented.

<!-- chunk: products -->
## Products

None. Agent Behavior Defense and the Guard API provide detection that a caller can act on.

<!-- chunk: gaps -->
## Gaps

No native containment or stop mechanism. What Enforce mode does to a flagged tool call is not stated, and fail open or fail closed behaviour is not documented.

## Options

Pair Guard API flags with a runtime or gateway that blocks the call and can halt the agent, and test the deny list path end to end.
