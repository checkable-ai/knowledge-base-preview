## Answer

Covered. Inline enforcement on Copilot Studio. Other platforms rely on the Guard API; Google Cloud and Bedrock AgentCore runtime integrations are coming soon. Enforce mode required.

Source statement: "Copilot Studio also supports a runtime connection that enforces AI Guardrails policy inline on tool executions" (https://docs.lakera.ai/docs/agent-security/connecting-platforms.md)

Research detail: Guard screens tool calls, tool responses and tool definitions, including MCP tool descriptions at handshake. Agent Behavior Defense adds a Tool Allow/Deny List and dangerous action detection. Copilot Studio supports inline enforcement on tool executions, other platforms rely on the Guard API.
