## Answer

Not covered. No per-user or per-agent retrieval authorisation. Data Leakage Prevention covers only the DLP half, and built-in PII detectors are US-centric.

Research detail: Data Leakage Prevention detects PII, system prompts and custom entity types in inputs, outputs, tool arguments and tool responses, with block or mask outcomes. The payload option returns match locations so the application can mask them. RAG documents can be screened at upload or in batch.
