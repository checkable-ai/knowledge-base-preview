## Answer

Covered. Set per policy and project. Blocking applies only in Enforce mode and the calling application must act on flagged results. Dangerous Deviation detector is beta.

Source statement: "The Tool Allow/Deny List enforces which tools an agent may call at runtime, at the moment of tool invocation." (https://docs.lakera.ai/docs/agent-behavior-defense.md)

Research detail: The Tool Allow/Deny List in Agent Behavior Defense detects calls to tools outside an allow list, or on a deny list, at invocation time. The Dangerous Deviation detector (beta) flags unwarranted data leakage, privilege escalation and destructive tool calls. Both are set per policy and project and only block when the project is in Enforce mode and the application acts on the flagged result.

## Gaps

Enforcement depends on the application calling the Guard API and honouring flagged responses. Scoping is by project and policy, not documented as per agent. No argument-level permissions on target systems.
