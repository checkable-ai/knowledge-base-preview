## Answer

Not covered. Connections store scoped credentials and refresh OAuth tokens, but docs do not state secrets are kept from the model, nor forced rotation or central revocation.

Research detail: Orchestrate connections hold credentials for tools, MCP toolkits, knowledge bases and virtual models, with team (shared) or member (per user) scope and separate draft and live configurations. Secrets are set through the CLI set-credentials command rather than in YAML files, and the platform refreshes OAuth2 access tokens with stored refresh tokens. Agent Identity adds short-lived task-scoped tokens in preview.

## Products

watsonx Orchestrate connections, Agent Identity (preview)

<!-- chunk: gaps -->
## Gaps

Docs do not state that secrets are kept out of model context, nor describe storage encryption, forced rotation or central revocation. Key-value connections pass secrets to tools as environment variables.

<!-- chunk: options -->
## Options

Prefer OAuth or SSO/OBO connections over static keys. Test that tool secrets never appear in traces or model prompts. Use the IdP to revoke refresh tokens.
