## Answer

Covered. Builder/Admin roles required; deploy to live not available in Developer Edition. Agent Identity registration is preview.

Source statement: "Deploying an agent is the act of taking an agent from a draft state into a live state." (https://developer.watson-orchestrate.ibm.com/agents/import_agent)

Research detail: Agents are imported into a draft state and deployed to live, undeployed back to the prior live version, and deleted, with a --safe confirmation on overwrite. Only Builder and Admin roles can build and deploy agents, and workspaces with Owner and Editor roles scope resources on IBM Cloud. Agent Identity registration with the IdP is preview.

<!-- chunk: products -->
## Products

watsonx Orchestrate agent import and deploy, roles, workspaces, Agent Identity (preview)

<!-- chunk: gaps -->
## Gaps

No native approval step before deploy. Identity provisioning and retirement are preview and lightly documented.

<!-- chunk: options -->
## Options

Make a CI/CD pipeline the only deployment path, as IBM's CI/CD guidance describes, and restrict Builder roles.
