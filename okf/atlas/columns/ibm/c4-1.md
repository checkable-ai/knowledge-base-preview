## Answer

Not covered. Agent Identity (preview) gives each agent a unique identity in an IdP, but no documented binding to an owner, runtime or release.

Research detail: Agent Identity in watsonx Orchestrate (preview, released 15 September 2026) gives each agent its own verifiable identity, separate from its builder and user, registered in an existing identity provider (IBM Verify or Microsoft Entra in the private preview). Disabling the identity in the IdP stops the agent running. Linkage to an owner, runtime and release is not described.
