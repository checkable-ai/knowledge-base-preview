## Answer

Not covered. No vendor-documented write-once or integrity-validated store for per-agent action records in watsonx Orchestrate. Nearby features fall short: OpenTelemetry traces and IBM Cloud Activity Tracker events are observability and audit logs, with no documented tamper-evidence guarantee. Activity Tracker events for watsonx.ai often resolve to a service ID, not the agent or end user.

Research detail: Orchestrate emits IBM Cloud activity tracking events for state-changing actions, viewable through IBM Cloud Logs. Traces record each agent request path, and tool logs attach to the tool's execution record. Agent Identity (preview) links audit records to the user, the agent and the tool called.

## Products

IBM Cloud Logs activity tracking, Orchestrate traces, Agent Identity (preview)

## Gaps

No tamper-proof or immutable ledger is documented. Tool logs are capped at 20 KB per invocation. Event action names were not on the page read.

<!-- chunk: options -->
## Options

Route activity events to an immutable store with IBM Cloud Logs routing and export traces to a retained log platform.
