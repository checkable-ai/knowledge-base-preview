## Answer

Covered. watsonx.governance; default inventory created by IBM Cloud admin.

Source statement: "You register agents and tools into inventory workspaces, where they're stored and managed." (https://www.ibm.com/docs/en/watsonx/w-and-w/2.2.0?topic=ai-using-governed-agentic-catalog)

Research detail: The Governance console has use case, agent, tool and foundation model libraries, with watsonx.ai models added automatically, and an AI Agent object type. The governed agentic catalog registers agents and tools by code or endpoint in inventory workspaces. Orchestrate lists registered agents and versions through its API.
