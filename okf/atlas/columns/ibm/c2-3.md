## Answer

Covered. Python tools; SaaS cannot reach internal network.

Source statement: "Each Python tool runs inside an isolated container with its own virtual environment." (https://developer.watson-orchestrate.ibm.com/tools/create_tool)

Research detail: Python tools run in Kubernetes containers with UV virtual environments (Python 3.12), 2 vCPUs, 2 GB memory and 5 workers, shared per tenant for standalone tools or dedicated per toolkit. The filesystem is read only and SaaS cannot reach internal networks. Local MCP servers run in the same runtime.
