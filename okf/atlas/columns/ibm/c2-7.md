## Answer

Not covered. No customer-set egress allowlist or execution timeout; cancel API effect on in-flight tools not documented. Read-only filesystem and container isolation fall short of network limits.

Research detail: watsonx Orchestrate runs each Python tool in an isolated container with its own virtual environment and a read-only filesystem, with 2 vCPUs and 2 GB of memory. The SaaS edition cannot reach a company's internal network. The API can cancel a run by run ID and undeploy a released agent version.

## Gaps

No customer-set internet egress allowlist is documented for SaaS, and on premises egress depends on cluster firewall rules. No execution timeout is stated. The cancel API does not describe its effect on in-flight tool calls.
