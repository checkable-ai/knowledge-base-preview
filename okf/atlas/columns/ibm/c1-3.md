## Answer

Not covered. No native approval bound to exact tool call with denial handling for agent tool calls; workflow user activity nodes and deprecated ToolPermission fall short.

Research detail: Agentic workflows can include user activity nodes that pause for a user to confirm or fill a form, including fields for selecting approvers. The older ToolPermission setting that made an agent confirm non read-only actions is deprecated. IBM's MCP guidance recommends approval gates for high-risk operations but describes them as a design pattern.

## Products

watsonx Orchestrate agentic workflows (user activity node)

## Gaps

No documented native approval bound to an exact tool call with parameters, denial handling or replay protection for agent tool calls outside workflows.

<!-- chunk: options -->
## Options

Route high-risk actions through a workflow with a user activity approval step, or have the tool itself require a signed approval token from an external system.
