## Answer

Not covered. IBM does not document a control point that approves particular pairs of agents and enforces approved message formats or schemas between them. The nearest features fall short. The watsonx Orchestrate collaborators field lists which agents an agent works with, but IBM documents it as configuration, not as an enforcement gateway. The AI Gateway (described only in a release announcement) is about discovering and importing third-party agents, and its controls apply to every connected agent, not to approved agent-to-agent pairs. agent_pre_invoke and agent_post_invoke control hooks exist, but no documentation says they validate pairs or message formats.

Research detail: An agent can only call the collaborators listed in its definition, and controls can run at agent_pre_invoke and agent_post_invoke hooks. IBM states that AI Gateway policies apply to every connected third-party agent regardless of platform.
