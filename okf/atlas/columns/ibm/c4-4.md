## Answer

Not covered. A2A auth scheme can be NONE; no mutual authentication or per-agent authorisation policy documented.

Research detail: Native Orchestrate agents can call external agents as collaborators over the A2A protocol (version 0.3.0, JSON-RPC 2.0 over HTTP) or a chat completions protocol, with BEARER_TOKEN or API_KEY auth. A2A push notifications back to Orchestrate use bearer tokens from API keys, and agent discovery can use a connection for authentication.
