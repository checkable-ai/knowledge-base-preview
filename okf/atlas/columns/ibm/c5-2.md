## Answer

Covered. Production evaluation samples live traffic (default 3 percent).

Source statement: "The evaluation framework uses this data to score agent behavior and identify areas for improvement." (https://developer.watson-orchestrate.ibm.com/evaluate/overview)

Research detail: The ADK evaluation framework compares agent trajectories against ground truth before deployment. Production evaluation runs six LLM-as-a-judge evaluators on sampled live traffic (generally available 30 September 2026), and watsonx.governance monitors Orchestrate agents and syncs evaluation metrics into the Governance console with thresholds.

## Products
