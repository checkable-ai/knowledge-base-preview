## Answer

Covered. Operations are bounded by selected tools and by connection credentials and OAuth scopes; finer scoping depends on the downstream provider. Agent Identity task-scoped tokens are preview.

Source statement: "A comma-separated list of tools to import, or `*` to import all available tools (e.g. `--tools="tool_1,tool_2"`)." (https://developer.watson-orchestrate.ibm.com/tools/toolkits/remote_mcp_toolkits)

Research detail: Agents only see the tools and collaborators listed in their definition, MCP toolkit imports can select specific tools, and connections carry OAuth scopes set by set-credentials. Member credentials limit actions to the user's own permissions. Controls can be bound to named tools at tool_pre_invoke and tool_post_invoke hooks.

## Products

watsonx Orchestrate agent tool lists, toolkits --tools, connections, controls

<!-- chunk: gaps -->
## Gaps

No documented per-operation permission model for connected systems beyond provider OAuth scopes. Agent Identity task-scoped tokens are preview.

<!-- chunk: options -->
## Options

Expose narrow facade tools and separate read and write tools, as IBM's MCP design guidance recommends. Scope OAuth clients tightly at the provider.
