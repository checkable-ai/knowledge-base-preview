## Answer

Covered. Builder must set memory_enabled on the agent.

Source statement: "If this parameter is not set to true, the agent will not save any memory even if you enable it in the chat interface." (https://www.ibm.com/docs/en/watsonx/watson-orchestrate/base?topic=memory-managing-agent)

Research detail: Agent memory stores information about a user across chat sessions. Users can view, search, delete single or all memories and turn memory off, and a builder or admin must set memory_enabled on the agent for any memory to be saved.
