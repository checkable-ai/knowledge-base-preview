## Answer

Not covered. No documented gateway for tool calls and internet access that enforces input formats, usage or rate limits, and internet or egress access. The nearby feature, OneTrust CORIE, enforces policy rules at the tool call by allowing, stopping or flagging an action for human review. Its announcement page does not document input-format validation, limits, internet access control or a list of allowed tools. Agent policy objects record permitted tools but are registration records, not a runtime gateway. The MCP Gateway is reported as private preview with no public enforcement documentation. The customer must provide the tool-call and internet access control point.

Research detail: CORIE enforces policy at the tool call and can allow, block or route an action, and the AI governance page states MCP policies are enforced with audit logs. The documentation does not describe schema validation, quotas, rate limits or egress control for tools.
