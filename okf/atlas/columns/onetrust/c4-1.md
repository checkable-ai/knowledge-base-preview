## Answer

Not covered. Registry records owner, lifecycle and version, but no runtime agent identity is issued or bound to a release.

Research detail: Agents are recorded in the AI registry with a stated purpose, accountable owner, version history and deployment status, and the March 2026 agent detection release records owners, integrations and lineage per agent. The runtime controls page says actions are traced through machine identities such as API keys, tokens and service accounts. OneTrust does not issue or manage the agent's runtime identity itself.
