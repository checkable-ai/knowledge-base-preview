## Answer

Not covered. No short-lived scoped credential issuance, rotation or revocation. Secret detection and masking fall short of brokering.

Last checked 16 November 2026.

Research detail: Noma does not document credential issuance, rotation or brokering. It detects secrets in agent instructions and MCP servers and can mask secrets inline, which is detection rather than brokerage. The Claude Code plugin itself reads a Noma API key from environment, settings or the OS credential store.
