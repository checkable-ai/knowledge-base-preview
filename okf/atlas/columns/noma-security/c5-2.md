## Answer

Source statement: "Noma analyzes agent intent and normal agent behavior to catch drift before it can become destructive." (https://noma.security/products/ai-dr)

Research detail: AI-DR builds a baseline of normal agent behaviour over time and flags deviations, using the context of each action to reduce false positives. Runtime control evaluates the full chain of actions in a session and flags drift from stated intent. Detection model details and tuning are not public.
