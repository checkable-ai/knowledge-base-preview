## Answer

Covered. Claude Code plugin is in Beta. Limited to agents with hook support such as Claude Code and Cursor.

Source statement: "This plugin enables you to evaluate, allow, or block high-risk activities in real-time." (https://github.com/Noma-Security/claude-marketplace)

Research detail: For Claude Code and Cursor, Noma enforces policy through the agents' native hooks before and after tool calls and shell commands. The Claude Code plugin gates shell execution, MCP tool execution, sensitive file reads such as .env files and SSH keys, and prompt submission, with allow or block decisions. The plugin is in Beta and the policy language for local actions is not published.
