## Answer

Covered. Enforcement runs through existing gateways, hooks, SDKs or APIs.

Source statement: "Restrict individual tools within approved servers and enforce those decisions when agents attempt to connect or act." (https://noma.security/solutions/mcp-security)

Research detail: Agent Access Control sets per-user and per-tool policies, keyed to IdP groups and tool sensitivity, that decide which agents may use which tools and skills in an MCP server and what data and actions they can access. Approving an MCP server does not approve all of its tools, and specific tools can be disabled for agents or users. Enforcement runs through existing gateways, hooks, SDKs and APIs rather than a Noma-owned proxy.
