## Answer

Not covered. Noma's inventory and AI Registry map agents to the human who built them, but it does not issue each agent its own identity or bind it to where it runs or to a release.

Research detail: Noma discovers agents across endpoint, SaaS and homegrown environments and records each in an inventory and AI Registry mapped to connections, permissions, blast radius and owner. For SaaS agents it maps each agent to the human who built it. Noma does not issue or anchor agent workload identities, and release or runtime linkage is not described.
