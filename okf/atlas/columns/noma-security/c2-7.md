## Answer

Not covered. No sandbox, process policy or network egress control. Runtime blocking and a killswitch are documented, but the killswitch mechanism and scope are not explained.

Research detail: Noma blocks risky agent actions and tool calls at runtime through AI gateways, MCP gateways, agent hooks, SDKs and APIs, and its pages show a delete_access_key call blocked as an unapproved tool. AI-DR lists triggering a kill switch as a response option. The Claude Code guardrails plugin can allow or block shell execution, MCP tool calls and file reads. Noma does not provide a sandbox, process policy or network egress control, and the kill switch is not explained.
