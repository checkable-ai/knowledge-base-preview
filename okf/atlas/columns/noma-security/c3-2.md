## Answer

Not covered. Noma documents per-server, per-tool and per-user-group allow and block policies. It does not document input-format or schema enforcement, rate limits or quotas, or internet egress control. It has no gateway of its own: enforcement runs through AI gateways, MCP gateways, agent hooks, SDKs and APIs.

Last checked 16 November 2026. This platform is checked on demand, so this answer has not been rechecked since.

Research detail: Noma enforces per-user, per-agent allowed MCP servers and tools, blocks out-of-scope and destructive actions before they run, and inspects tool responses for embedded prompt injection, exfiltration patterns and cross-server shadowing. Enforcement runs through MCP gateways, hooks, SDKs or APIs. Schema validation, quotas, rates and internet egress control are not documented.
