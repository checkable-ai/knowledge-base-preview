## Answer

Covered, with conditions. Vercel Agent Code Review is in Public Beta on Enterprise and Pro plans. Chat can open pull requests without plan approval, so review there depends on the repository's own branch protection.

Source statement: "Vercel Agent will read your comment and either generate a suggested fix (which you can review and apply) or reply to your question in the same thread." (https://vercel.com/docs/agent/pr-review)

Last checked 17 November 2026.

Research detail: Vercel Agent suggestions reach people through pull requests and plans. Code Review shows only validated suggestions that a developer applies, replies can be reviewed in the thread, and chat plans wait for approval. Review is by the developer or approver and no separate reviewer queue exists.

## Products

Code Review suggestions, plans, pull request review

## Gaps

Pull requests can be opened by the agent without plan approval, so human review depends on repository branch protection.
