## Answer

Covered, with conditions. Vercel Agent is in Public Beta on Enterprise and Pro plans. Reading Vercel data, including environment variables, is auto-approved. GitHub writes need no plan approval and require the Vercel GitHub App installation to grant Contents and Pull requests write access.

Source statement: "Vercel Agent is read-only by default." (https://vercel.com/docs/agent/chat/permissions)

Last checked 17 November 2026.

Research detail: Vercel Agent is read-only by default. Reads of Vercel data are auto-approved and changes to Vercel resources need plan approval that lists exact targets and scopes, limited to the selected team and project. GitHub writes need no plan approval and rely on the GitHub App's Contents and Pull requests write access.

## Products

Vercel Agent authorization levels and plans, team roles

<!-- chunk: gaps -->
## Gaps

Pull request writes bypass plan approval. Reads include environment variables.

<!-- chunk: options -->
## Options

Narrow the GitHub App installation and use team roles to limit who can enable Vercel Agent.
