## Answer

Covered, with conditions. Python support and NestJS support are in beta. Vercel Workflows is the managed service on Vercel; the Workflow SDK can also run on other infrastructure through a World adapter. Each run is pinned to one Vercel Function region. multi-region needs workflow 5.0.0-beta.33 or later.

Source statement: "Vercel Workflows runs multi-step logic as durable code that can retry failed steps, wait for external events, and resume across crashes and deployments." (https://vercel.com/docs/workflows)

Last checked 17 November 2026.

Research detail: Vercel Agent Investigations start automatically on Medium and High anomaly alerts, and a user can run one again with fresh data. Multi-step chat requests show a plan that waits for approval and can be cancelled. Retry and recovery semantics for failed agent runs are not documented.
