## Answer

Covered, with conditions. Workflow run payloads are readable for 1 day on Hobby, 7 days on Pro and 30 days on Enterprise after the run finishes, and are deleted within 66, 96 and 126 days respectively. Vercel pins each run to a single region when it starts, and runs created by the 4.x release line live in iad1. Decrypted run data is readable only by team owners or holders of the Workflow Run Data Viewer permission. Auto-delete (experimental_retention) is experimental.

Source statement: "Vercel Workflows stores the inputs, outputs, event log, and streams of every workflow run so that the run can pause, resume, and replay." (https://vercel.com/docs/workflows/retention)

Research detail: Dashboard chat sessions are private to the user, keep history, and only the session owner can approve plans. Messages and attachments become part of the conversation. Retention and deletion for sessions are pointed to privacy guidance that was not opened.
