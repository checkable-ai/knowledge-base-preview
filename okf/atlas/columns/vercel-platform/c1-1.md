## Answer

Covered. Applies to agents running in Vercel Sandbox. Per-agent Linux users are available in the JS and Python SDKs, groups in the JS SDK only, and the sandbox image must include /bin/bash.

Source statement: "Run several AI agents in one sandbox, each as its own Linux user with a private home directory and separate file permissions." (https://vercel.com/docs/sandbox/concepts/multi-agent)

Last checked 17 November 2026.

Research detail: Vercel Agent's local sandbox work (reading, editing and running commands in the session workspace) is authorised according to the approved plan. The agent runs in Vercel sandboxes and not on the user's host, so host level file or process scopes are not offered.
