## Answer

Partly covered. No lifecycle workflow is documented for changing an agent's permissions or configuration over time. Directory Sync and Access Groups manage people, not agents.

Source statement: "Only a team Owner or Billing member can change this setting." (https://vercel.com/docs/agent/chat/dashboard)

Last checked 17 November 2026.

Research detail: Directory Sync (SCIM) adds and removes team members and maps directory groups to team roles, and Access Groups assign project roles. Owners or billing members enable Vercel Agent chat, and Code Review and Investigations are enabled separately by team settings. Agent identities as objects are not provisioned.

<!-- chunk: products -->
## Products

Directory Sync, Access Groups, Vercel Agent team settings

<!-- chunk: gaps -->
## Gaps

Directory Sync and Access Groups are Enterprise only. No lifecycle workflow for agent configurations is described.

<!-- chunk: options -->
## Options

Map directory groups to roles and limit Agent settings to owners and billing.
