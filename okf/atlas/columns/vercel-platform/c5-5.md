## Answer

Not covered. No standing, per-agent view of the downstream systems an agent can reach and what it can do there. Vercel Agent shows the targets, operations and scopes only inside each plan before approval, and the permissions page is a general reference table. The Firewall dashboard shows inbound traffic, not agent reach.

Last checked 17 November 2026.

Research detail: Each Vercel Agent plan lists the targets, operations and scopes it needs, so approvers see what the agent will reach. The Firewall dashboard shows inbound traffic. A standing view of the agent's reach into downstream systems is not documented.
