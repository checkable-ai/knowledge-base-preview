## Answer

Partly covered. No egress or internet access filtering, input format validation or injection screening of agent tool calls is documented. The Vercel Firewall governs inbound traffic to deployments.

Source statement: "If a request needs more access than the active plan allows, Vercel Agent stops and asks for a new plan." (https://vercel.com/docs/agent/chat/permissions)

Last checked 17 November 2026.

Research detail: Vercel Agent tool use is scoped by plans, the selected team and project, and GitHub App permissions. The Firewall, WAF custom rules and Attack Mode control inbound traffic to deployments, with rate limiting actions. Egress filtering and schema validation of agent tool calls are not documented.
