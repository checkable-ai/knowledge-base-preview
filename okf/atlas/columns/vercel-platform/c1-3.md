## Answer

Covered, with conditions. Vercel Agent is in Public Beta on Enterprise and Pro plans. Only the session owner can approve a plan in the dashboard. Creating or updating GitHub pull requests needs no plan approval.

Source statement: "Approval applies only to the listed targets, operations, scopes, and risk." (https://vercel.com/docs/agent/chat/permissions)

Research detail: When a task needs a change to Vercel resources, Vercel Agent shows a plan and waits for approval. Approval covers only the listed targets, operations and scopes, a new plan needs new approval, and rejecting or cancelling stops the writes. Only the session owner can approve in the dashboard.

Vercel Agent plans and approvals

## Gaps
