## Answer

Covered, with conditions. Runs in Vercel Sandbox, Vercel's own service. Network access is allow-all by default and is restricted through the sandbox firewall.

Source statement: "Each sandbox runs in a secure Firecracker microVM with its own filesystem and network." (https://vercel.com/docs/sandbox)

Last checked 17 November 2026.

Research detail: Code Review and Investigations use secure sandboxes to reproduce issues, run builds, tests and linters, and validate patches before showing them. Secure Compute (Enterprise, paid) puts deployments in a dedicated private network with static IPs. Sandbox egress and filesystem settings were not documented in the pages read.
