## Answer

Covered, with conditions. Vercel Connect is available on all plans and is subject to the Vercel Connect terms. The user must authorize once, and the token is limited to what that user approved. Vercel Agent is in Public Beta on Pro and Enterprise plans.

Source statement: "Ask a user to authorize once, then get a refreshable user token that your agent uses to make calls as that user." (https://vercel.com/docs/connect)

Research detail: Vercel Agent uses the requesting user's existing Vercel permissions and the selected team scope, so Vercel actions carry that user's authority. For GitHub it uses the GitHub App installation's access, not the user's own repository role. OIDC tokens carry project and environment claims to cloud backends.

<!-- chunk: products -->
## Products

Vercel Agent permission model, OIDC federation

<!-- chunk: gaps -->
## Gaps

GitHub operations do not carry the user's own authority. Delegation to downstream services other than GitHub is not described for the agent.

<!-- chunk: options -->
## Options

Limit the GitHub App installation to the repositories the agent should reach and review its permissions.
