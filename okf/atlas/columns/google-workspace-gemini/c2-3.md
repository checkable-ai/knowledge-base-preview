## Answer

Out of scope. Gemini in Workspace and Studio flows are a fully managed SaaS service. Google runs the machines, containers, code interpreter and network egress. The customer does not provision or choose where agent code runs, so the control does not apply to this kind of product. Admin controls such as turning off Studio web search are feature settings, not a runtime.

Research detail: Gemini in Workspace is processed inside Google's infrastructure and the Privacy Hub says it does not open a direct connection to the public internet. Real-time information comes from search grounding against Google's index.

## Products

Google-hosted Gemini service

## Gaps

Managed service. There is no customer-configurable sandbox, code interpreter or egress setting. Studio web search can be turned off by source.

<!-- chunk: options -->
## Options

Restrict Studio data sources to Workspace content only where web search is not allowed.
