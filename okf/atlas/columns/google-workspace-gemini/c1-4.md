## Answer

Partly covered. Controls are per setting or per flow. No documented lifecycle process for creating, approving and retiring agent identities.

Source statement: "Blocks the flow's access to Google data and stops any in-progress or future runs." (https://knowledge.workspace.google.com/admin/studio/manage-ws-flows-access-to-data)

Last checked 17 November 2026.

Research detail: Admins control Studio access and feature steps by organisational unit and group, set the default data access for flows, and review, change or pause each flow in Agent access management. Gemini features are enabled and disabled through the same console.

## Products

Admin console Gemini and Studio settings, Agent access management

## Gaps

Controls are per setting or per flow, not a lifecycle for agent identity creation and retirement. Group settings override organisational units, which needs care.
