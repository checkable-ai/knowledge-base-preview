## Answer

Partly covered. Redaction of sensitive data in the telemetry, session correlation and a named owner for the response are not documented.

Source statement: "You can set up alerts based on log event data using reporting rules." (https://knowledge.workspace.google.com/admin/reports/gemini-for-workspace-log-events)

Last checked 17 November 2026.

Research detail: Gemini log events are available through the Reports API and the security investigation tool, with actor, IP, device and agent attributes. Admins can create alert rules and jump from an audit event to Agent access management for a flow.
