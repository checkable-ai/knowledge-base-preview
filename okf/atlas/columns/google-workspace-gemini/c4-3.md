## Answer

Covered. The flow default applies to newly created Studio flows. Admins can change the default data access for flows. Studio Agent access management only lists newly created flows.

Source statement: "By default, newly created flows run with the same data access privileges as the user that created them." (https://knowledge.workspace.google.com/admin/studio/manage-ws-flows-access-to-data)

Last checked 17 November 2026.

Research detail: Gemini retrieves only content the initiating user can access in Workspace. Studio flows by default run with the data access privileges of the user who created them, and audit logs record under which user's authority an action ran.
