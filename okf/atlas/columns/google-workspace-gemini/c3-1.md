## Answer

Not covered. No customer-controlled point for routing, per-agent or per-user quotas or cost limits. Edition-based usage limits are fixed by Google, and Gemini's built-in threat checks before actions are not an admin-configurable gateway.

Last checked 17 November 2026.

Research detail: Gemini checks for malicious content and prompt injection before it performs an action, and usage limits apply by edition. Admins set feature access by user group or organisational unit.

## Products

Gemini threat checks, AI usage limits, feature access

## Gaps

Customers do not set per-user quotas, routing or injection screening policy. No model routing control is documented.

## Options
