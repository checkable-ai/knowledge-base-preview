## Answer

Not covered. Approval is SHOULD-level UI guidance, not bound to the exact action, with no defined refusal or replay handling.

Research detail: The specification says hosts must obtain explicit user consent before invoking any tool, and the Tools page says there SHOULD always be a human able to deny tool invocations, with confirmation prompts. Elicitation gives the user decline and cancel options. Approval is not bound to the exact action and replay handling is not defined.
