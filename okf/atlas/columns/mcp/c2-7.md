## Answer

Not covered. Containment is guidance only, there is no kill switch for a running agent, and cancellation is cooperative. Enterprise-Managed Authorization revocation is opt-in and covers server access only.

Research detail: The Local Server Security guide recommends containers, seccomp or AppArmor, no network where none is needed and egress proxies with domain allowlists. Requests can be cancelled, and the enterprise extension revokes server access centrally at the identity provider. There is no defined kill switch for a running agent.
