## Answer

Not covered. Client registration and the Enterprise-Managed Authorization extension handle server access for employees but define no process to create, change or retire agents or their configurations.

Research detail: Clients register through Client ID Metadata Documents, with Dynamic Client Registration deprecated. The Enterprise-Managed Authorization extension moves onboarding and revocation of server access to the enterprise identity provider. Neither covers the full lifecycle of agent configurations.
