## Answer

Not covered. Isolation of where code runs is guidance in the Local Server Security guide, not a protocol feature. Nothing governs a code interpreter or agent runtime.

Research detail: The stdio transport runs a local server as a client subprocess. The Local Server Security guide recommends containers with no extra mounts, lightweight VMs or OS sandboxing, and the security best practices say clients SHOULD run local server commands in a sandbox with minimal privileges.
