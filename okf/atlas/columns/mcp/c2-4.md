## Answer

Not covered. The protocol has no sessions. No retention, readership or resumption rules; server-minted handles are left to each server.

Research detail: Revision 2026-07-28 removed protocol sessions. Servers that need state mint explicit handles, MUST NOT treat a handle as authentication and SHOULD bind handles to the authenticated user and expire them. Retention and resumption are left to servers.
