## Answer

Not covered. clientInfo and serverInfo are self-reported and the spec says they are not verified and should not be relied on for security decisions. Client ID Metadata Documents identify an OAuth client but do not bind an agent to an owner, a runtime or a release.

Research detail: Clients SHOULD identify themselves on each request with clientInfo and servers SHOULD return serverInfo, and server/discover MUST advertise server identity. OAuth clients register through Client ID Metadata Documents, and the OAuth Client Credentials extension lets an unattended client authenticate with its own credentials. None of this binds an agent to an owner, runtime or release.
