## Answer

Not covered. No enforced local permission model. Roots is deprecated and the Local Server Security guide gives cooperative guidance only; enforcement depends on the host's isolation layer.

Research detail: The Roots feature, now deprecated, let clients declare filesystem boundaries to servers. The Local Server Security guide recommends granting the narrowest directory, read-only where possible, and warns that configuration allowlists are cooperative and need an isolation layer to be enforced.
