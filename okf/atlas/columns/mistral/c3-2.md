## Answer

Not covered. Connector Permissions allow or block tools per workspace and confirmation can be required, but there is no documented input schema validation, per-tool rate limits, output screening or internet egress control.

Research detail: Connector permissions per workspace allow all, selected or no tools, and API keys are scoped to shared or private connectors. Confirmation can be required per tool, and tool calls appear in audit logs as connectors_gateway.tool_called.
