## Answer

Covered, with conditions. Sandbox egress blocking runs on Mistral Cloud. The default region nl-north-1 is described as the only region that can block traffic. Managed Agents and the Agents SDK are in public preview.

Source statement: "Block a tool call your policy forbids, before any hook or tool runs." (https://docs.mistral.ai/studio/agents/learn/agent/guardrails)

Last checked 16 November 2026.

Research detail: Connector permissions per workspace allow all, selected or no tools, and API keys are scoped to shared or private connectors. Confirmation can be required per tool, and tool calls appear in audit logs as connectors_gateway.tool_called.

## Products

Connectors permissions, requires_confirmation, audit logs

## Gaps
