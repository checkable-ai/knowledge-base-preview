## Answer

Covered. store=False disables storage; no retention period stated; ZDR excludes conversations.

Source statement: "You can also opt out from the automatic storing with store=False" (https://docs.mistral.ai/studio/agents/agents-api)

Research detail: Conversations store interaction history and are resumed by conversation_id. Storage can be turned off with store=False. The public Conversations API only reads and modifies conversations owned by the creator of the calling API key.

## Products

Conversations API

<!-- chunk: gaps -->
## Gaps

No retention period for stored conversations is stated, and ZDR does not cover conversations.

<!-- chunk: options -->
## Options

Use store=False for sensitive sessions and confirm retention terms contractually.
