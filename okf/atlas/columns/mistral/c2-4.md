## Answer

Covered. Conversations are stored by default and can be opted out with store=False. The page's code uses the client.beta.conversations namespace. Zero data retention excludes conversations.

Source statement: "this will make the new history not being stored on our cloud." (https://docs.mistral.ai/studio/agents/agents-api)

Last checked 16 November 2026. This platform is checked on demand, so this answer has not been rechecked since.

Research detail: Conversations store interaction history and are resumed by conversation_id. Storage can be turned off with store=False. The public Conversations API only reads and modifies conversations owned by the creator of the calling API key.

## Gaps

## Options
