## Answer

Not covered. Mistral's audit logs (Enterprise) are ordinary chronological activity records of organisation actions in Studio and Vibe. No documented write-once or integrity-validated storage, no tamper-evidence, no per-agent tool-call/data-access record, and the docs state log export is not supported, so there is no export to immutable storage.

Research detail: Enterprise audit logs record actor, event, target and metadata for sign-ins, API keys, members, agents, libraries, connector tool calls and conversation creation and deletion. Logs are on by default and can be retrieved through the Admin API with filters.
