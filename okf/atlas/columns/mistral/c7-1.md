## Answer

Not covered. Traces (30-day retention) and Enterprise audit logs record activity. The documentation describes no tamper-evidence, write-once storage, integrity validation or log export, and does not describe reasoning as recorded.

Last checked 16 November 2026.

Research detail: Enterprise audit logs record actor, event, target and metadata for sign-ins, API keys, members, agents, libraries, connector tool calls and conversation creation and deletion. Logs are on by default and can be retrieved through the Admin API with filters.

## Products

Audit logs, Admin API

<!-- chunk: gaps -->
## Gaps

Inference inputs, outputs and reasoning are not listed as logged. Tamper protection and retention are not documented. The overview says export is not supported, which conflicts with the Admin API retrieval endpoint.

<!-- chunk: options -->
## Options

Pull logs regularly through the Admin API into immutable storage and pair them with trace data.
