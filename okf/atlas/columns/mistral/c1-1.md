## Answer

Covered. Applies to the Vibe Code CLI only; admin config is a distribution mechanism that users can bypass.

Source statement: "Per-tool permissions let you tighten or loosen access for specific tools." (https://docs.mistral.ai/vibe/code/safety-approvals-permissions)

Research detail: The Vibe Code CLI sets tool permissions per tool (always or ask, or disabled_tools), bash allow and deny lists, and asks before any read, write or command outside the working directory. Agent modes include plan (read-only) and auto-approve. The core Agents API runs tools server-side and has no local host scope.

## Gaps

No sandbox is described for the CLI. Admin config is documented as a distribution mechanism, not a security control, so users can bypass it. Vibe Code sits beside the core research scope.
