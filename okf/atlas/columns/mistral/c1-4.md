## Answer

Covered. No approval step before creation; SCIM not GA.

Source statement: "Records when an agent is created." (https://docs.mistral.ai/admin/monitor-comply/audit-logs/reference)

Research detail: Agents are created, updated (each update creates a version) and deleted through the Agents API. The Admin API manages users, groups, workspaces, roles and API keys, and service accounts start with no roles until an admin grants them and are deleted to remove their credentials. Audit logs record agent.create, agent.update and agent.delete.

<!-- chunk: products -->
## Products

Agents API, Admin API, service accounts, RBAC, audit logs

<!-- chunk: gaps -->
## Gaps

SCIM is not generally available. No approval step before agent creation and no documented effect on agents or keys when a user is removed.

<!-- chunk: options -->
## Options

Drive agent and service account changes through Admin API automation with your own approval step. Check for orphaned agents and keys after offboarding.
