## Answer

Not covered. Code Interpreter is an isolated container but network and filesystem limits are not documented. No customer egress allowlist. Vibe Code Web has no manual stop or cancel yet; Vibe Work stop is best effort. API key revocation is not documented as an immediate agent kill switch.

Research detail: Code Interpreter runs code in an isolated container, and each Vibe Code Web session runs in a single-tenant cloud sandbox with no inbound access and outbound internet managed by Mistral. Vibe Work stops for approval before external actions, offers a stop button with no guarantee, and lets admins disable connectors and features per workspace. API keys can be revoked or deleted. Vibe Code Web states that cancellation, interrupt and manual stop are not available yet, and customer egress allowlists are not offered.

<!-- chunk: products -->
## Products

Code Interpreter, Vibe Code Web sandbox, Vibe Work approvals and stop, workspace admin feature controls, API key revocation

<!-- chunk: gaps -->
## Gaps

No user-configurable egress allowlist. No manual stop for Vibe Code Web sessions. Vibe Work stop is best effort. Whether key revocation takes effect immediately is not stated. Code Interpreter network and filesystem limits are not documented.

<!-- chunk: options -->
## Options

Revoke the API key or disable the connector as the stop path, test revocation latency, and run self-built agents under Mistral Workflows on customer workers where egress can be controlled.
