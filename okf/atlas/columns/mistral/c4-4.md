## Answer

Not covered. Handoffs work inside one organisation with no agent authentication, per-handoff credential or A2A support.

Research detail: Handoffs let one agent pass a task to another, and an agent can only hand off to agents listed in its handoffs field. Handoffs run on Mistral servers by default or can be returned to the client to execute. This works inside one Mistral organisation only.

## Gaps

No cross-organisation or cross-platform agent authentication, no A2A protocol support documented, no per-handoff credential.

<!-- chunk: options -->
## Options

Treat handoffs as intra-tenant only. Use client-side handoff execution where an external trust boundary must be enforced by your own code.
