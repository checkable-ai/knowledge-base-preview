## Answer

Not covered. The model lifecycle (Labs, Public Preview, General Availability, Deprecated, Retired) covers Serverless API models only. There is no governance lifecycle for agents or use cases from proposal through testing to change and retirement. Agent deploy, redeploy and shutdown are technical runtime steps.

Last checked 16 November 2026.

Research detail: Mistral's own models move through Labs, Public Preview, GA, Deprecated and Retired stages with stated notice. Agents are versioned with switchable active versions.
