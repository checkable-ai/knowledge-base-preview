## Answer

Covered. The AI Registry is part of Mistral AI Studio, offered through a private beta signup. Rollback relies on agent versions and model pinning.

Source statement: "The Registry enforces access controls, moderation policies, and promotion gates before deployment." (https://mistral.ai/news/ai-studio/)

Research detail: Each agent update creates a new version, the active version can be switched back, and aliases can point to versions. Models can be pinned to fixed identifiers. Audit logs capture agent and API key changes.
