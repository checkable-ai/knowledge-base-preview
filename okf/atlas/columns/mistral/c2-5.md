## Answer

Covered, with conditions. Code Interpreter works only through the Conversations API with an Agent created with the tool, and is not supported in Chat Completions. Built-in tools run in Mistral's isolated container. The Agents API v1 is flagged as about to be deprecated in favour of the Agents SDK. Managed Agents and the Agents SDK are in public preview. The harness runs in the customer's process or through a self-hosted or Mistral-managed Studio deployment.

Source statement: "safely execute code in an isolated container" (https://docs.mistral.ai/studio/agents/agent-tools/code_interpreter)

Last checked 16 November 2026.

Research detail: The Agents API executes built-in tools, MCP connectors and function calls server-side, with local functions run by the client SDK. The Vibe Code CLI is a local harness for tools with its own permission model. Durable agents run the loop inside Workflows.
