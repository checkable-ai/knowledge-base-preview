## Answer

Not covered. Only org/workspace spend limits and per-model rate limits; no per-agent, per-user or per-key quotas or routing; guardrails are input only.

Last checked 16 November 2026.

Research detail: Organisation and workspace monthly spend limits cap API and Vibe use. Rate limits are set per model. Guardrails screen input for categories including jailbreaking and block with a 403 at request, conversation or agent level.

## Products

Usage limits, guardrails (moderation_llm_v2)

## Gaps

No per-user, per-agent or per-key quotas or routing. Guardrails are input only. allowed_models in Vibe Code limits client offers, not API access.

<!-- chunk: options -->
## Options

Use workspaces as the quota and policy boundary, or place a third-party gateway in front of the API for per-agent controls.
