## Answer

Covered, with conditions. Mistral Workflows is in Public Preview. The page says durable agents are about to be deprecated. Needs mistralai>=2.8.0. Running the Studio environment in a private cloud or on-premises is available to enterprise customers.

Source statement: "agent state is preserved across worker crashes and restarts" (https://docs.mistral.ai/studio/workflows/building-workflows/durable_agents)

Last checked 16 November 2026.

Research detail: Mistral Workflows, built on Temporal, records each step in an event history so work resumes after crashes, with per-activity retry backoff and pauses for human signals. Durable agents run the agent loop inside a workflow so state survives restarts. Handoffs chain agents within conversations.
