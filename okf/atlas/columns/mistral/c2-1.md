## Answer

Covered. Mistral Workflows is Public Preview.

Source statement: "Wrap tool side-effects in activities so they get retry isolation and appear in the execution history." (https://docs.mistral.ai/studio/workflows/building-workflows/durable_agents)

Research detail: Mistral Workflows, built on Temporal, records each step in an event history so work resumes after crashes, with per-activity retry backoff and pauses for human signals. Durable agents run the agent loop inside a workflow so state survives restarts. Handoffs chain agents within conversations.
