## Answer

Covered, with conditions. Applies to tools listed in requires_confirmation, covering connector tools, built-in tools and local functions. The Python SDK flow needs mistralai 2.4 or later with the agents extra. Local functions are available in the Python SDK only. Used through the Agents and Conversations API, whose SDK namespaces are client.beta.agents and client.beta.conversations.

Source statement: "The tool doesn't run, and the model answers without its result." (https://docs.mistral.ai/studio/connectors/confirmation)

Last checked 16 November 2026.

Research detail: Tools listed under requires_confirmation pause before execution. Each pending call carries a tool_call_id, name and arguments, the client returns allow or deny per call, and denial is passed back to the model. Vibe Work stops before create, modify, send, post or delete actions and offers Continue, Always allow or Decline.

<!-- chunk: products -->
## Products

Agents and Conversations confirmation (requires_confirmation), Vibe Work approvals

<!-- chunk: gaps -->
## Gaps

Docs do not describe binding approval to the exact arguments, replay protection, expiry of pending calls or approver identity checks. Always allow is per user and can pre-authorise functions.

<!-- chunk: options -->
## Options

Record approver identity in your client. Test whether an approval can be replayed or reused after arguments change.
