## Answer

Covered. Applies to tools registered with requires_confirmation in the Agents and Conversations API.

Source statement: "Send `"allow"` to run the tool and get the model response." (https://docs.mistral.ai/studio/connectors/confirmation)

Research detail: Tools listed under requires_confirmation pause before execution. Each pending call carries a tool_call_id, name and arguments, the client returns allow or deny per call, and denial is passed back to the model. Vibe Work stops before create, modify, send, post or delete actions and offers Continue, Always allow or Decline.

<!-- chunk: products -->
## Products

Agents and Conversations confirmation (requires_confirmation), Vibe Work approvals

<!-- chunk: gaps -->
## Gaps

Docs do not describe binding approval to the exact arguments, replay protection, expiry of pending calls or approver identity checks. Always allow is per user and can pre-authorise functions.

## Options
