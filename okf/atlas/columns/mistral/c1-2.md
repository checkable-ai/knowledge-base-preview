## Answer

Covered. Connectors are Public Preview; control is at workspace level (allowed, restricted, blocked).

Source statement: "Only selected tools are available for users in this Workspace." (https://docs.mistral.ai/admin/identity-access/connectors)

Research detail: Workspace admins set each connector to Allowed, Restricted (selected tools only) or Blocked. Connector visibility is private, shared_workspace or shared_org, and API keys default to shared connectors only. Agents only see the tools configured on them.

<!-- chunk: products -->
## Products

Connectors permissions tab, connector visibility, API key connector access scope

<!-- chunk: gaps -->
## Gaps

Granularity is workspace and API key, not per agent or per user. Connectors are in Public Preview. No argument-level constraints documented.

<!-- chunk: options -->
## Options

Separate workspaces per agent class and restrict connectors to the tools each needs. Test that Restricted tools cannot be called through the API.
