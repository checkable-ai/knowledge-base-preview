## Answer

Covered. Copilot Studio agents with Entra Agent IDs. Connector permissions attach when a maker publishes the agent. Shows Entra-visible permissions and connectors only, not non-Entra access such as API keys. There is no graph view.

Source statement: "This lets Microsoft Entra ID and Microsoft 365 admins see which connectors an agent can call without leaving the Microsoft Entra admin center." (https://learn.microsoft.com/en-us/microsoft-copilot-studio/admin-use-entra-agent-identities)

Research detail: Admins can see API permissions, roles and group memberships held by each agent identity in the Entra admin center. Copilot Studio attaches each configured connector as an API permission on the agent identity so admins can see what an agent can call.
