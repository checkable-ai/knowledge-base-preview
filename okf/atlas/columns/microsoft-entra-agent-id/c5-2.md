## Answer

Partly covered. Detections cover only autonomous agent activity; in OBO flows risk goes to the user rather than the agent. No task training or continuous validation of task behaviour, and detection uses identity and access signals only, offline, not in real time.

Source statement: "Unless noted otherwise, risk detections in this table apply only to autonomous agent activity." (https://learn.microsoft.com/en-us/entra/id-protection/concept-risky-agents)

Research detail: ID Protection detects anomalous agent identity behaviour such as sign-in spikes, unfamiliar resource access, failed access attempts, directory reconnaissance and early-life malicious activity. Learning Mode suppresses behavioural alerts for agents with little history.

## Gaps

Detections are offline and based on identity and access signals, not task output. In OBO flows risk is attributed to the user, not the agent. Licensing is moving to Agent 365.
