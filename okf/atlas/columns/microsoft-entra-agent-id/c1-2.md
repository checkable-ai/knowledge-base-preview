## Answer

Covered. Only applies where the downstream system accepts Entra tokens (API keys bypass Conditional Access). Conditional Access for agents needs Agent 365 with Entra P1 or M365 E3, or Microsoft 365 E7.

Source statement: "Agents can only do what a regular user could consent to, or what an administrator explicitly grants in a controlled, scoped manner." (https://learn.microsoft.com/en-us/entra/agent-id/authorization-agent-id)

Research detail: Agent identities receive scoped access through Microsoft Graph delegated and application permissions, Azure RBAC, Entra roles, app roles, groups and access packages. Entra blocks high-privilege roles such as Global Administrator and permissions such as Application.ReadWrite.All for agents. Conditional Access controls token issuance per agent, blueprint or attribute, and Copilot Studio connector permissions appear as API permissions on the agent identity.

## Products

Microsoft Entra Agent identity platform, Conditional Access for agents, Copilot Studio Entra Agent ID integration

<!-- chunk: gaps -->
## Gaps

Applies only where the downstream system accepts Entra tokens. API keys bypass Conditional Access. Copilot Studio connector scopes are honoured only by the Power Platform connector runtime. Agent Conditional Access needs an Agent 365 licence.

<!-- chunk: options -->
## Options

Front non-Entra systems with an Entra-protected API and grant least privilege through access packages.
