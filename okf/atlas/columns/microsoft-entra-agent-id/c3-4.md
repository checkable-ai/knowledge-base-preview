## Answer

Not covered. No control point on the agent-to-agent message path and no enforcement of approved message formats. Nearby: Conditional Access for agents, scoped by agent identity, blueprint or attribute, decides which agents get tokens for a callee agent that is an Entra-protected resource, and risk policies can block risky agents from reaching other agents. That enforcement happens only at token issuance.

Research detail: Because a callee agent can be an Entra-protected resource, Conditional Access policies scoped by agent identity, blueprint or custom security attribute decide which agents get tokens for it. Risk policies can block risky agents from reaching other agents.
