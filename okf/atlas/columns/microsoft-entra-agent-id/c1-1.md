## Answer

Not covered. No model for local file, command or tool permissions on the agent's host. Conditional Access device compliance for agents' user accounts gates access, not local actions.

Last checked 12 November 2026.

Research detail: Agent ID governs access to Entra-protected resources through tokens. It does not control what an agent may do on its local host. Conditional Access can require a compliant device for agents' user accounts on Windows 365 Cloud PCs, which gates access rather than local actions.
