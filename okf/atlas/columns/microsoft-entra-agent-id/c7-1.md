## Answer

Not covered. Entra audit and sign-in logs record identity operations and token acquisitions for agent identities, not the agent's tool calls, data access or changes. Microsoft does not document write-once or integrity-validated storage for these logs, or a documented export of an agent action record to such storage. Diagnostic-settings export to a storage account is a nearby feature that falls short, because immutability is a separate Azure Storage setting and the exported record lacks agent action detail.

Research detail: Entra audit logs record agent identity creation, updates and deletion with agentType and blueprintId on initiator, performer and target. Sign-in logs record each agent token acquisition and can be filtered by agent type.

## Gaps
