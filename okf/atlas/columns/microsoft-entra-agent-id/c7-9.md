## Answer

Covered. Network-based: traffic must pass through Global Secure Access (internet and Microsoft 365 traffic). Detects known generative AI apps, SaaS MCP servers and model provider APIs matched against the Defender for Cloud Apps catalog. Agent-specific discovery needs the endpoint client or the Copilot Studio integration, and Agent 365 licensing applies to agent features.

Source statement: "Shadow AI discovery lets administrators see which generative AI apps or tools employees are using without IT approval." (https://learn.microsoft.com/en-us/entra/global-secure-access/concept-shadow-ai-discovery)

Research detail: Entra lists every agent that has an Entra Agent ID, and agent sign-ins are flagged in logs. Microsoft says the full inventory, including agents without an Entra identity, now lives in the Agent 365 registry in the Microsoft 365 admin center.

<!-- chunk: products -->
## Products

Microsoft Entra Agent identity platform

<!-- chunk: gaps -->
## Gaps

Entra alone does not discover agents built as plain app registrations or with no Entra identity. Shadow AI discovery depends on Agent 365, which is outside this subject.

<!-- chunk: options -->
## Options

Use the Agent 365 All agents view and audit app registrations used by agents.
