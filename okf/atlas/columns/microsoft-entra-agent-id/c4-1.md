## Answer

Covered. Sponsor required on every agent identity and blueprint. Copilot Studio agents created before May 2026 may still use app registrations until migrated. Foundry project agents share a project identity until published. Runtime and release linkage is not part of the documented identity schema, so the customer must track those separately.

Source statement: "A sponsor is required when creating an agent identity or agent blueprint." (https://learn.microsoft.com/en-us/entra/agent-id/agent-owners-sponsors-managers)

Research detail: Each agent gets an agent identity in Entra ID, created from an agent identity blueprint that holds shared description, credentials, permissions and verified publisher. A sponsor is required on every agent identity and blueprint, so each identity is linked to an accountable human. Copilot Studio creates an agent identity automatically for each new agent since May 2026, and Foundry, App Service and Teams also provision them.
