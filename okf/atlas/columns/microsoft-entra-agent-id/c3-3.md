## Answer

Not covered. No gateway that filters what data each agent and user can retrieve, and no content-aware DLP in Agent ID. Conditional Access for agents withholds tokens for a resource at issuance, and Global Secure Access network file filtering acts on file type in transit for Copilot Studio agent traffic. Both fall short of retrieval-level filtering with DLP, and the vendor page does not describe them as meeting part of this outcome.

Research detail: Conditional Access can block an agent identity from obtaining tokens for a data resource such as SharePoint, and Global Secure Access network file filtering can restrict file uploads and downloads in Copilot Studio agent traffic. There is no content-level DLP in Agent ID.
