## Answer

Covered. Entra-protected resources only. Child agent identities cannot get interactive consent, so admin consent or inheritable permissions on the blueprint are needed. Inheritance is within one tenant.

Source statement: "The agent accesses downstream resources with the user's identity and delegated permissions." (https://learn.microsoft.com/en-us/entra/identity/conditional-access/agent-id)

Research detail: Agent identities support the OAuth 2.0 on-behalf-of flow, exchanging a user token audienced to the blueprint for a resource token carrying the user's identity and delegated permissions. Conditional Access evaluates the user's policies on each OBO exchange, and refresh tokens support background work in user context. Delegated permissions are preauthorised through inheritable permissions on the blueprint.

## Products

Microsoft Entra Agent identity platform, Conditional Access for agents

<!-- chunk: gaps -->
## Gaps

Child agent identities cannot obtain interactive user consent, so admin consent on the blueprint is required. Inheritance works only within one tenant. Delegation applies only to Entra-protected resources.

<!-- chunk: options -->
## Options

Use the sidecar /Validate and /AuthorizationHeader endpoints for OBO and apply the on-behalf-of Conditional Access template.
