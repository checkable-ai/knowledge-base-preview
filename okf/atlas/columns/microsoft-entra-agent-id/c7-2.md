## Answer

Partly covered. No documented linkage of telemetry to sessions, and no redaction of sensitive data. Detections are offline only and cover autonomous activity only (OBO risk is attributed to the user). Sponsors are displayed but no response owner workflow is defined.

Source statement: "Unless noted otherwise, risk detections in this table apply only to autonomous agent activity." (https://learn.microsoft.com/en-us/entra/id-protection/concept-risky-agents)

Research detail: ID Protection produces agent risk detections, a Risky Agents report and Graph collections riskyAgents and agentRiskDetections, exportable to Log Analytics, event hubs or a SIEM. Responders can confirm compromise, which triggers risk-based blocking, or disable the agent. Sponsors are shown on risky agent details.
