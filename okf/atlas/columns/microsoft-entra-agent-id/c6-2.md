## Answer

Not covered. Entra Agent ID documents no process to submit, register and approve a new agent identity, model or tool. The nearest feature is the Copilot Studio and Microsoft 365 admin center flow, where an admin approves an already-published agent before it is shown org-wide, which creates a 'Published by your org' entry in the Agent 365 registry. That flow is a distribution gate for existing Copilot Studio agents, run in the Microsoft 365 admin center and Agent 365 rather than in Entra Agent ID. It does not cover models or tools. Entra ID Governance access packages approve access requests only, not new agents.

Last checked 12 November 2026.

Research detail: Blueprints declare required resource access that admins review at consent, and permissions require admin or user consent. Access packages route agent access requests through configured approvers.
