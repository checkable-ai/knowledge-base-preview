## Answer

Not covered. No sandboxing of agent files, processes or general network access. The nearby features are the Agent ID disable and Conditional Access block templates (token cutoff) and Global Secure Access filtering of Copilot Studio traffic only. They do not limit files or processes. The docs do not state how fast a disable affects tokens already issued.

Research detail: An Agent ID Administrator can disable a single agent identity or blueprint in the Entra admin center, which stops it receiving tokens and authenticating. Three Conditional Access templates block token issuance tenant wide for all agent identities, for agents' user accounts, or for users signing into agents, which Microsoft describes as a reversible hold for incident response. Global Secure Access can forward Copilot Studio agent traffic (HTTP nodes, custom connectors, MCP connector) to its proxy for web content, threat intelligence and file filtering. Entra does not sandbox agent code or processes.

## Products

Agent identity and blueprint Disable, Conditional Access agent block policies (Entra ID P1), Global Secure Access for agents (Agent 365 licence).

## Gaps

The pages do not state how fast a disable or block takes effect on tokens already issued. Network filtering covers Copilot Studio agent traffic only. Execution sandboxing, filesystem and process policy are outside Entra's scope.

## Options

Test the disable and Conditional Access block in report-only then enforced mode and measure when an agent's existing token stops working. Pair with the agent platform's own sandbox for execution containment.
