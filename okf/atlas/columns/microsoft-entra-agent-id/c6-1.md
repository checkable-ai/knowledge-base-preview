## Answer

Partly covered. Agents without an Entra agent identity appear only in Agent 365, a separate product. Models, tools and agent components are not inventoried.

Source statement: "The comprehensive agent inventory, including agents without a Microsoft Entra agent identity, is available in Agent 365." (https://learn.microsoft.com/en-us/entra/agent-id/agent-registry-convergence)

Research detail: Entra and Microsoft Graph hold an inventory of blueprints, agent identities and agents' user accounts with descriptions, publisher and sponsors. The Entra Agent Registry experience has converged into Agent 365, and blueprints must be registered there to appear in the unified registry.
