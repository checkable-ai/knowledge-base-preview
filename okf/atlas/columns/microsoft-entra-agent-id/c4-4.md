## Answer

Covered. Receiving agents or APIs must accept Entra-issued tokens and enforce the documented token checks and configured permissions (audiences, app roles). Conditional Access for agents, if used, needs Microsoft Agent 365 licensing. Cross-tenant use relies on multitenant blueprints.

Source statement: "Those requests can be secured using access tokens issued by Microsoft Entra ID, allowing the agent to reliably identify the caller and make authorization decisions." (https://learn.microsoft.com/en-us/entra/agent-id/what-are-agent-identities)

Research detail: Agents can accept requests from other agents secured with Entra-issued tokens, and Microsoft documents four checks for inbound agent tokens including the xms_par_app_azp agent marker that names the calling blueprint. Conditional Access can block risky agents from reaching resources or other agents. Foundry supports agent identity authentication for A2A tools.
