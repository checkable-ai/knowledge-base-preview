## Answer

Covered. Governance features need Agent 365 with Entra P1 or E3, or Microsoft 365 E7. Cascade cleanup after blueprint deletion can lag hours or days. Direct grants outside access packages have no expiry.

Source statement: "A sponsor is required when creating an agent identity or agent blueprint." (https://learn.microsoft.com/en-us/entra/agent-id/agent-owners-sponsors-managers)

Research detail: Agent identities are created only from blueprints through supported creation channels, with a required sponsor. Access is granted through access packages with up to three approval stages and expiry. Owners and sponsors can disable agents, disabling a blueprint blocks all its agents, and deleting a blueprint cascades a soft delete to child identities with 30-day restore.
