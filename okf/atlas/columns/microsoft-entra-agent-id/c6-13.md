## Answer

Covered. Platform-level attestations (SOC 2 Type 2, IRAP, ISO 42001 for AI services). Reports sit in the Service Trust Portal, and scope for Entra Agent ID must be confirmed there. No Agent ID specific attestation, privacy impact or penetration test material is public.

Source statement: "Microsoft Azure, Dynamics 365, and other Microsoft cloud services undergo rigorous independent third-party SOC 2 Type 2 audits conducted by a reputable certified public accountant (CPA) firm." (https://learn.microsoft.com/en-us/azure/compliance/offerings/offering-soc-2)

Research detail: Microsoft states that Azure in-scope services were IRAP assessed up to PROTECTED across its four Australian regions, and that Office 365 commercial services are also IRAP assessed. Azure, Dynamics 365 and Microsoft 365 services are covered by SOC 2 Type 2 reports issued semi-annually. Microsoft states ISO/IEC 42001 certification for its AI services, including Copilot Studio, Foundry and Security Copilot, but Entra is not in that list. The service lists for IRAP and SOC 2 sit in reports on the Service Trust Portal, so the public pages do not confirm that Microsoft Entra ID and Agent ID is in scope.

<!-- chunk: products -->
## Products

Microsoft IRAP assessments (Azure, Office 365), Azure SOC 2 Type 2 report, Microsoft ISO/IEC 42001 certification. Agent ID itself has no separate attestation on these pages.

<!-- chunk: gaps -->
## Gaps

The public IRAP pages list assessment milestones only to December 2020, which is older than 24 months, and name no service list. Whether Microsoft Entra ID and Agent ID and its agent features are in the current IRAP and SOC 2 scope needs the Service Trust Portal reports. No product-specific privacy impact or red-team material was found on these pages.

<!-- chunk: options -->
## Options

Download the current Azure and Office 365 IRAP reports and SOC 2 bridge letter from the Service Trust Portal and check the in-scope service list for Microsoft Entra ID and Agent ID. Use the reports in the agency's own IRAP assessment and authority to operate.
