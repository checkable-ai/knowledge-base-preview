## Answer

Not covered. No documented tool gateway: no allowed-tool lists, input format or schema validation, per-tool limits or blocks on specific dangerous actions. Nearby: Global Secure Access for agents forwards Copilot Studio agent traffic (HTTP nodes, custom connectors, MCP server connector) and applies web content, threat intelligence and network file filtering, but only through the tenant-wide baseline profile and only for Copilot Studio agents (Agent 365 licence). Conditional Access gates token issuance to tool endpoints, not the calls themselves.

Research detail: Global Secure Access can proxy Copilot Studio agent traffic from HTTP nodes, custom connectors and MCP server connectors and apply web content filtering, threat intelligence filtering and network file filtering. Conditional Access controls token issuance to MCP servers and APIs per agent identity or blueprint. Microsoft also describes prompt injection detection at the network layer.

## Gaps

Network forwarding is documented only for Copilot Studio agents and applies tenant-wide through the baseline profile, not per agent. No tool schema validation or per-tool rate limits. Requires Agent 365 licensing.

<!-- chunk: options -->
## Options

Enable traffic forwarding per Power Platform environment and test filtering against a known blocked category. Use an MCP gateway for schema and rate controls.
