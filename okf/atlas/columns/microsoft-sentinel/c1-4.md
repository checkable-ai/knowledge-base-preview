## Answer

Not covered. No documented controlled process for approving, changing permissions of, versioning or retiring agents in Sentinel. Agent creation tooling for Security Copilot agents covers creation only.

Research detail: The agent creation collection in the Sentinel MCP server lets engineers compose a Security Copilot agent definition in YAML and deploy it to user or workspace scope with deploy_agent. Sentinel does not manage change or retirement of agents, and governance of the deployed agent sits in Security Copilot.

<!-- chunk: products -->
## Products

Sentinel MCP server agent creation collection, Microsoft Security Copilot

<!-- chunk: gaps -->
## Gaps

No approval gate, versioning or retirement workflow documented on the Sentinel side. Limited to Security Copilot agents.

<!-- chunk: options -->
## Options

Keep agent YAML in source control and require review before deploy_agent is run.
