## Answer

Not covered. Custom MCP tools limit which saved queries agents can run over Sentinel data, but there is no DLP or content inspection on returned results, and no per-agent and per-user gateway across data stores.

Research detail: For security data, custom Sentinel MCP tools built from saved KQL queries give granular control over what an agent can retrieve, and table-level and resource-context RBAC restrict reads. Azure Monitor transformations can filter or obfuscate sensitive columns at ingestion. This governs agent retrieval of Sentinel data only, and there is no DLP on agent retrieval from other stores.

<!-- chunk: products -->
## Products

Custom Sentinel MCP tools, Sentinel RBAC, Azure Monitor transformations

<!-- chunk: gaps -->
## Gaps

Limited to Sentinel and Defender data. Custom tools are prerelease. No content inspection on returned results.

<!-- chunk: options -->
## Options

Give agents only custom tools with narrow queries and protect sensitive tables with protected tables or table RBAC.
