## Answer

Not covered. Retention and residency settings apply to telemetry in Sentinel, not rules for agent inputs, outputs and memory; some processing occurs in a US region.

Research detail: Customers set retention and can delete data, with the data lake holding security data for up to 12 years and purge available for accidental collection. Data is stored in the workspace region, which includes Australia East for the data lake, but for workspaces outside Europe and Israel, Sentinel processes customer data in a US region. This covers agent telemetry held in Sentinel, not agent memory or outputs in the agent platform.

## Gaps

US processing for Australian workspaces may matter for residency. Auxiliary plan tables cannot be purged. Agent memory is out of scope.

## Options
