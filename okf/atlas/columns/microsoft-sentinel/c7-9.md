## Answer

Covered. MCP Servers Dashboard workbook is in preview. Needs Microsoft Entra Global Secure Access with generative AI and MCP logging enabled, the NetworkAccessGenerativeAIInsights table (preview) streamed to Sentinel via Entra diagnostic settings, and the Global Secure Access solution installed from the Sentinel content hub. Coverage is limited to traffic that passes through Global Secure Access.

Source statement: "Use this workbook to improve visibility into AI-driven traffic and identify unmanaged or noncompliant MCP services." (https://learn.microsoft.com/en-us/entra/global-secure-access/how-to-sentinel-integration)

Research detail: Sentinel has no shadow AI discovery feature of its own. It can hunt over Copilot activity and cloud app events from Defender for Cloud Apps, but discovery and agent inventory are features of Defender and Purview.
