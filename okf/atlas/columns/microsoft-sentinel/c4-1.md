## Answer

Not covered. Sentinel does not issue or register agent identities or bind them to owner, host or release. It only consumes identities from Entra and Agent 365.

Research detail: Sentinel does not issue or register agent identities. It consumes identities from other sources, such as Entra ID profiles in the UEBA IdentityInfo table and agent telemetry from the Agent 365 connector. Agent identity is provided by Entra and Agent 365, which are outside this subject.
