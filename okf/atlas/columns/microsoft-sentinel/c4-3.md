## Answer

Covered. Sentinel MCP server triage tool collection; requires Security reader role and Sentinel data lake onboarding. Applies to calls into Sentinel MCP tools only.

Source statement: "The triage tool collection lets you use any tool your existing permissions grant you." (https://learn.microsoft.com/en-us/azure/sentinel/datalake/sentinel-mcp-get-started)

Research detail: The Sentinel MCP server authenticates callers with Microsoft Entra, and the triage collection runs tools under the caller's existing permissions, so an agent client acting for a user sees only that user's data. This applies only to calls into Sentinel's own MCP tools, not to delegation across other downstream services.
