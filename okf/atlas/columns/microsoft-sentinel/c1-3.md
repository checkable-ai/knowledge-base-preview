## Answer

Not covered. Playbooks (Azure Logic Apps) can wait for an admin response for SOC response actions, but there is no approval of an AI agent's exact proposed action, and denial and replay handling are not documented.

Research detail: Playbooks built on Azure Logic Apps can pause and wait for a human decision, for example emailing admins with Block and Ignore buttons before blocking an IP and disabling a user. This approves SOC response actions, not actions proposed by AI agents, and binding to the exact action and replay handling are left to the playbook design.
