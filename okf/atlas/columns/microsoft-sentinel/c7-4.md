## Answer

Not covered. Sentinel ingests telemetry about hosts and containers but does not harden or scan the hosts, containers or agent software that run models and tools. Hardening and scanning belong to Defender for Cloud and similar products.

Research detail: Sentinel does not harden or assess inference or tool execution containers and hosts. It can ingest telemetry from Defender for Endpoint and cloud workload sources about those hosts.
