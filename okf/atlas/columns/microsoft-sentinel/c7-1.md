## Answer

Not covered. Sentinel MCP tool runs are audited (SentinelAIToolCreated, SentinelAIToolRunStarted, SentinelAIToolRunCompleted in CloudAppEvents), but Microsoft does not document these records as write-once or integrity-validated. Nor does it document capture of agent inputs, outputs and reasoning, or export to immutable storage. Log Analytics data export is a general feature and falls short.

Research detail: Sentinel stores ingested agent and Copilot audit records in Log Analytics, which is append-only but allows deletion for compliance. Microsoft recommends a resource lock, which can be removed, or export to immutable blob storage for a fully tamper-proof record. Data lake and graph activity, including creating and running MCP tools, is audited in Purview. Reasoning content is only present if the source logs it.
