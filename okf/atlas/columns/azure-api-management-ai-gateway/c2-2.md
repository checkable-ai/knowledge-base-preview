## Answer

Covered, with conditions. Applies to all API Management tiers, but capability availability varies by tier. The Anthropic Messages API is supported in API Management v2 tiers only. The unified model API for multiple providers is in preview. Models can be hosted in Microsoft Foundry, Amazon Bedrock or other providers, and the gateway routes to them.

Source statement: "Configure a token limit policy on your LLM APIs to manage and enforce limits per API consumer based on the usage of AI service tokens." (https://learn.microsoft.com/en-us/azure/api-management/genai-gateway-capabilities)

Research detail: The gateway routes calls to models hosted elsewhere and gives them stable alias names. It does not run model inference.
