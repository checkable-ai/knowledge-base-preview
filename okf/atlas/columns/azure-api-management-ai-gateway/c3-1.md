## Answer

Covered, with conditions. The llm-content-safety policy needs a separate Azure AI Content Safety resource. The llm-content-safety policy applies to Developer, Basic, Basic v2, Standard, Standard v2 and Premium tiers (and v2 Premium). The Anthropic Messages API is supported in API Management v2 tiers only. AI Gateway tier features such as aliases and estimated spend controls are in public preview in East US 2 and Sweden Central only.

Source statement: "This policy provides flexibility to assign token-based limits on any counter key, such as subscription key, originating IP address, or an arbitrary key defined through a policy expression." (https://learn.microsoft.com/en-au/azure/api-management/genai-gateway-capabilities)

Last checked 17 November 2026.

Research detail: The gateway routes LLM calls to Foundry, Bedrock, Vertex AI and other backends with load balancing and fallback. It limits tokens per minute and by quota against any key such as a subscription or caller, and screens prompts with Azure AI Content Safety including a prompt shield. The AI Gateway tier adds model aliases, estimated spend controls and policy cards.

<!-- chunk: products -->
## Products

llm-token-limit policy, llm-content-safety policy, backend load balancer, semantic cache, AI Gateway tier policy cards

<!-- chunk: gaps -->
## Gaps

Per-agent limits depend on choosing a good counter key. The AI Gateway tier is a preview in US and Swedish regions only. Content Safety is a separate Azure resource. Semantic caching can return stale or unsafe answers.

<!-- chunk: options -->
## Options

Key limits on an agent or workload identifier. Enable the content safety prompt shield on all model APIs.
