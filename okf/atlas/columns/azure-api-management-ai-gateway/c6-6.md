## Answer

Covered, with conditions. The owner fields are in Azure API Center, a separate Azure service used as the registry alongside API Management. Custom metadata can be set as required or optional per entity type. Local and remote MCP servers and A2A agents can be included in the API Center inventory.

Source statement: "For example, you can define and assign Department metadata to APIs, so that when an API is registered or a new API version is added, the department responsible for the API is specified." (https://learn.microsoft.com/en-us/azure/api-center/metadata)

Last checked 17 November 2026.

Research detail: The pages read describe no owner assignment for agents, models or tools. API Center custom metadata could hold an owner field but the pages do not present it for that purpose.
