## Answer

Out of scope. The control is about what an agent may do on its own machine (files, commands, local tools). This is a cloud gateway for remote model, MCP and A2A traffic. Microsoft documents only remote MCP server mode, not local stdio servers, and the gateway has no presence on the agent host, so the control cannot apply to this kind of product. Changed from not-covered after the objection.

Research detail: The gateway sits between agents and remote services. It has no control over what an agent may do on its local host.
