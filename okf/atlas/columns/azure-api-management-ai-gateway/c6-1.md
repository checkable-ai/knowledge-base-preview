## Answer

Covered, with conditions. The catalogue is held in Azure API Center, which the page presents as a related Azure service. The Agent 365 MCP server inventory is in preview and needs a Microsoft Agent 365 tenant and a supported API Management instance. API Management v1 tiers are not supported by the Agent 365 integration. Azure API Center is available only in listed Azure regions, including Australia East.

Source statement: "Easy registration of APIs, MCP servers, skills, and other assets in an organizational catalog in Azure API Center" (https://learn.microsoft.com/en-au/azure/api-management/genai-gateway-capabilities)

Last checked 17 November 2026.

Research detail: Azure API Center keeps an inventory of APIs and registers remote or local MCP servers, and Agent 365 keeps a central MCP server inventory. APIs, MCP servers, skills and other assets register in an organisational catalogue. Registered A2A agent APIs and models are managed in the gateway.

<!-- chunk: products -->
## Products

Azure API Center, Agent 365 Tools inventory, AI Gateway model registrations

## Gaps

## Options
