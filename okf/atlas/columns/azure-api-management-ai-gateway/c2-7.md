## Answer

Partly covered. No sandboxing of an agent's files or processes. The block applies only to traffic through the gateway, and Agent 365 does not route agents through a gateway on its own, so agents that bypass the gateway are not stopped.

Source statement: "Block or unblock MCP servers." (https://learn.microsoft.com/en-au/azure/api-management/agent-365)

Last checked 17 November 2026.

Research detail: An administrator can block an MCP server, which returns HTTP 403, or block single tools, and unblocking removes the managed policy. Network paths can be restricted with virtual networks and private endpoints. Backend circuit breakers stop traffic to unresponsive AI backends.

<!-- chunk: products -->
## Products

Agent 365 block or unblock, AI Gateway tier tool blocks, virtual network options, backend circuit breaker

<!-- chunk: gaps -->
## Gaps

The block stops traffic through the gateway only. Agents that bypass the gateway are not stopped. Agent 365 does not route agents through a gateway. There is no sandboxing of agent code.

<!-- chunk: options -->
## Options

Make the gateway the only permitted caller of MCP servers through private networking.
