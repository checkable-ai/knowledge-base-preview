## Answer

Covered, with conditions. Credential manager is available on all API Management tiers. Credential manager is not supported in the self-hosted gateway. Credential manager is not supported in sovereign clouds or in the regions australiacentral, australiacentral2 and indiacentral. Credential manager is not available in workspaces. AI Gateway (preview) runtime API keys grant gateway-wide access, and AI Gateway is in public preview in East US 2 and Sweden Central only. Available in all API Management service tiers.

Source statement: "Using API Management's credential manager, you can easily configure OAuth 2.0, consent, acquire tokens, cache tokens in a credential store, and refresh tokens without writing a single line of code." (https://learn.microsoft.com/en-au/azure/api-management/credentials-overview)

Research detail: API Management credential manager stores, caches and refreshes OAuth 2.0 tokens for backend services and injects them at the gateway, so agents and models never hold them. Managed identities remove secrets that need rotating. The AI Gateway tier keeps gateway runtime credentials apart from provider credentials.

<!-- chunk: products -->
## Products

Credential manager, managed identities, get-authorization-context policy, AI Gateway backend connections

<!-- chunk: gaps -->
## Gaps

Runtime API keys in the AI Gateway tier preview are gateway-wide, with no per-asset scoping. Revocation and expiry of caller keys are not described on the pages read. Credential manager is not supported in the self-hosted gateway.

<!-- chunk: options -->
## Options

Prefer Microsoft Entra runtime access and managed identity over shared runtime keys. Test key rotation and revocation in a trial gateway.
