## Answer

Not covered. No write-once or integrity-validated storage, and no documented tamper-evidence for the record. Azure Monitor resource logs (gateway and generative AI categories, optional prompt and completion bodies) can be sent to Log Analytics, a storage account or an event hub, but the page does not describe them as immutable or tamper-evident. Entries are not tied to a named agent identity by default.

Last checked 17 November 2026.

Research detail: Azure Monitor resource logs capture gateway requests, including headers, timings, errors and optionally request and response bodies. The generative AI log category can include prompts and completions. The Azure activity log records control-plane changes.

<!-- chunk: products -->
## Products

Diagnostic settings, Log Analytics, generative AI gateway logs, Azure activity log

<!-- chunk: gaps -->
## Gaps

Logs are stored in customer-chosen sinks and are not described as tamper-proof. Reasoning traces are not captured. Body logging is optional and has size limits.

<!-- chunk: options -->
## Options

Send logs to an immutable storage account and enable body logging for AI APIs.
