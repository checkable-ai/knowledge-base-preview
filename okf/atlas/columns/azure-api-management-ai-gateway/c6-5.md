## Answer

Partly covered. No proposal or approval stage, no use-case lifecycle, and no managed workflow for testing, change and retirement of models, agents or use cases. Lifecycle stages are labels on registered assets and versions.

Source statement: "An API version can be at any lifecycle stage from design, to preview, production, or deprecated." (https://learn.microsoft.com/en-us/azure/api-center/key-concepts)

Last checked 17 November 2026.

Research detail: The gateway does not manage how models, agents or use cases move from proposal to retirement. API Center has version lifecycle stages for registered assets only.
