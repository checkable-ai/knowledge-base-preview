## Answer

Covered, with conditions. A2A agent API import applies to Developer, Basic, Basic v2, Standard, Standard v2, Premium and Premium v2 tiers. Only JSON-RPC based A2A agent APIs are supported. Subscription key authentication is optional and must be enabled on the API.

Source statement: "Rewrites security requirements to include the API Management subscription key requirement." (https://learn.microsoft.com/en-au/azure/api-management/agent-to-agent-api)

Last checked 17 November 2026.

Research detail: An imported A2A agent API is fronted by the gateway, which can require a subscription key and apply policies such as JWT validation to calls between agents. The agent card is rewritten to point at the gateway and to require the subscription key. Content safety checks can run on A2A requests and responses.

<!-- chunk: products -->
## Products

A2A agent API import, subscription keys, validate-jwt policy, llm-content-safety policy

<!-- chunk: gaps -->
## Gaps

Only JSON-RPC A2A agent APIs are supported. The pages do not describe agent-to-agent trust boundaries beyond key and token checks at the gateway.

<!-- chunk: options -->
## Options

Require Entra tokens through validate-jwt on A2A APIs in addition to the subscription key.
