## Answer

Partly covered. No documented submission and reviewer approval workflow. Registration is a form entry in API Center and approval is limited to an administrator blocking or allowing a server or tool.

Source statement: "Block or unblock MCP servers." (https://learn.microsoft.com/en-au/azure/api-management/agent-365)

Last checked 17 November 2026.

Research detail: API Center registers MCP servers with versions and a lifecycle stage, and administrators can block or unblock MCP servers from Agent 365. Platform teams publish approved models and tools for application teams.

<!-- chunk: products -->
## Products

API Center registration, Agent 365 block or unblock, AI Gateway publish model

<!-- chunk: gaps -->
## Gaps

No approval workflow with reviewers is documented. Registration is a form entry, and blocking is an administrator switch.

<!-- chunk: options -->
## Options

Add an approval process around API Center registration using pipelines or tickets.
