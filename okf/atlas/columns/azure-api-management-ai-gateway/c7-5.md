## Answer

Partly covered. No SBOMs, code scanning or review of MCP servers, command-line tools, skills or extensions, and no review of external services or network egress. A post-invocation denial cannot undo actions the tool already took.

Source statement: "The policy uses Microsoft Defender and Microsoft Purview capabilities to evaluate tool requests and results for risks such as malicious content, prompt injection, and exposure of sensitive information." (https://learn.microsoft.com/en-au/azure/ai-gateway/policy-tool-threat)

Last checked 17 November 2026.

Research detail: Agent 365 tool threat protection evaluates tool requests and results at runtime for malicious content and prompt injection, before and after tool invocation. This is a runtime defence for MCP servers published through the gateway.
