## Answer

Partly covered. Provider billing remains the source of actual cost. Staff time, savings and return delivered are not covered. Custom metric limits silently drop data once reached.

Source statement: "Track token metrics per consumer in Application Insights." (https://learn.microsoft.com/en-au/azure/api-management/genai-gateway-capabilities)

Last checked 17 November 2026.

Research detail: The gateway emits token metrics by consumer, with custom dimensions, to Application Insights or OTLP destinations, and the analytics dashboard breaks usage down by language model. Token quotas cap consumption. The AI Gateway tier adds estimated model spend controls.

<!-- chunk: products -->
## Products

llm-emit-token-metric policy, API analytics, AI Gateway estimated spend controls

## Gaps

Provider billing stays the source of actual cost. Labour cost, savings and yield are not covered. Custom metric limits drop data silently once reached.

## Options
