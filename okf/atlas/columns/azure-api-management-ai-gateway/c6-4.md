## Answer

Not covered. No documented ownership, versioned publication or review cycle for AI policies. API Management policies and Azure Policy enforce settings but do not manage who writes, owns and reviews AI policy.

Research detail: AI Gateway tier policies are shown as cards and stored as JSON properties, so they can be managed as code and enforced across many gateways with Azure Policy. Classic tiers define policies in XML at global, product, API or operation scope.
