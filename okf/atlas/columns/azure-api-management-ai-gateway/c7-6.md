## Answer

Not covered. No scanning of public registry tools, plugins or skills for look-alike names, poisoned descriptions or compromised packages. API Center registers MCP servers, including partner and package entries, but does not scan them. Tool threat protection does not evaluate tools/list, so tool descriptions are not screened.

Last checked 17 November 2026.

Research detail: The gateway governs third-party MCP servers but the pages describe no scanning of registries for squatting, tool metadata poisoning or package compromise. Tool discovery calls are explicitly not evaluated.
