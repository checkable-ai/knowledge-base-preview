## Answer

Partly covered. No per-agent or per-user retrieval filtering and no named data loss prevention rule set is described. Retrieval is not governed as a separate data path.

Source statement: "The policy uses Microsoft Defender and Microsoft Purview capabilities to evaluate tool requests and results for risks such as malicious content, prompt injection, and exposure of sensitive information." (https://learn.microsoft.com/en-au/azure/ai-gateway/policy-tool-threat)

Research detail: Agent 365 tool threat protection in the AI Gateway tier uses Microsoft Defender and Purview to evaluate tool requests and results for malicious content, prompt injection and exposure of sensitive information. Content Safety filters prompts and completions for harm categories. Retrieval is not governed as a separate data path.
