## Answer

Partly covered. No documented redaction of sensitive data in telemetry, no built-in linking of telemetry to sessions and people (custom dimensions and correlation IDs are customer-configured), no detections specific to agents or MCP servers, and no named response owner.

Source statement: "Integrate with SIEM systems and Defender Cloud Security Posture Management" (https://learn.microsoft.com/en-au/azure/api-management/protect-with-defender-for-apis)

Last checked 17 November 2026.

Research detail: Gateway logs and metrics can go to Log Analytics, storage or event hubs. The AI Gateway tier emits OpenTelemetry data to Application Insights, Datadog, Splunk or Grafana. Defender for APIs integrates with SIEM systems and carries alerts.

<!-- chunk: products -->
## Products

Diagnostic settings, OpenTelemetry export, Defender for APIs, Agent 365 runtime signals

<!-- chunk: gaps -->
## Gaps

Session and actor correlation relies on correlation IDs and custom dimensions that the customer sets up. Redaction is not described. Detections cover REST APIs only.

<!-- chunk: options -->
## Options

Add correlation IDs in policy and write detections in the SIEM.
