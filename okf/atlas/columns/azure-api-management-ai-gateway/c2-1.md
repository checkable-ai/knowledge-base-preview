## Answer

Out of scope. The gateway mediates individual model, tool and agent API requests. It does not run agent tasks or sequence, hand off, cancel or recover their steps. Backend load balancing and circuit breakers work per request, not per task step, so this control concerns agent runtimes and cannot apply to a gateway. Changed from not-covered after the objection.
