## Answer

Not covered. No per-agent view of which downstream systems each agent can reach or what it can do there. Agent 365 lists MCP servers and tools registered with a connected gateway, with endpoints, access scopes and service identities, but that is a server and tool inventory, not an agent-to-system reach map. API Center is a catalogue of registered assets. Calls made outside the gateway are not covered.

Last checked 17 November 2026.

Research detail: Agent 365 discovers API Management and AI Gateway resources in a tenant and lists their MCP servers and tools with metadata such as endpoints, access scopes and service identities. API Center gives a catalogue of registered MCP servers and APIs.

<!-- chunk: products -->
## Products

Agent 365 Tools inventory, Azure API Center portal

<!-- chunk: gaps -->
## Gaps

This shows what is registered with a gateway. It does not map the reach of agents or their downstream action scopes. Agent 365 does not cover calls made outside the gateway.

<!-- chunk: options -->
## Options

Use the Agent 365 Tools page with API Center, and add network flow logs for traffic that bypasses the gateway.
