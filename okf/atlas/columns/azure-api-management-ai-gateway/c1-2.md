## Answer

Covered, with conditions. Tool-level blocking is only available for MCP servers registered in the AI Gateway tier, which is in public preview in East US 2 and Sweden Central only. It needs a Microsoft Agent 365 tenant and tenant-level administrator consent. The MCP server needs a static list of allowed tools. API Management v2 tiers support only server-level block or unblock. API Management v1 tiers are not supported by the Agent 365 integration.

Source statement: "Tool-level control lets an organization block selected tools without disabling the entire server." (https://learn.microsoft.com/en-au/azure/api-management/agent-365)

Last checked 17 November 2026.

Research detail: Gateway policies control which callers reach an MCP server and its tools, and a REST API can be exposed with only selected operations as tools. In the AI Gateway tier preview, Agent 365 can block individual tools on an MCP server. On other tiers, policies apply to the whole server.

<!-- chunk: products -->
## Products

MCP server policies, selected-operation MCP export, Agent 365 tool-level blocking (AI Gateway tier)

<!-- chunk: gaps -->
## Gaps

Tool-level blocking is a preview and needs the AI Gateway tier and a static tool list. Classic and v2 tiers apply policies to all tools in a server. The pages do not describe scopes inside a backend system.

<!-- chunk: options -->
## Options

Publish MCP servers with only the operations an agent needs and use the AI Gateway tier for per-tool blocks.
