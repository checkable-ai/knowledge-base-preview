## Answer

Not covered. No documented rules for keeping, deleting or locating agent inputs, outputs and memory. Prompt and completion logging is optional and goes to customer-chosen Azure Monitor destinations, where retention is set outside the gateway. The AI Gateway tier preview is only offered in East US 2 and Sweden Central.

Research detail: The AI Gateway runs in the customer's subscription and sends telemetry to destinations the customer controls. Prompt and completion logging is optional, so the customer decides what is retained.

## Products

Diagnostic settings, optional prompt and completion logging, AI Gateway customer-controlled telemetry
