## Answer

Covered, with conditions. A2A agent API import applies to Developer, Basic, Basic v2, Standard, Standard v2, Premium and Premium v2 tiers. Only JSON-RPC based A2A agent APIs are supported. Deserialization of outgoing response bodies is not supported. Subscription key authentication is optional and must be enabled on the API.

Source statement: "Mediates JSON-RPC runtime operations to the A2A backend." (https://learn.microsoft.com/en-au/azure/api-management/agent-to-agent-api)

Last checked 17 November 2026.

Research detail: Imported A2A agent APIs are mediated by the gateway, which applies policies, subscription keys, content safety checks and OpenTelemetry attributes to JSON-RPC traffic. The agent card is rewritten so clients call the gateway.

<!-- chunk: products -->
## Products

A2A agent API import, API Management policies, llm-content-safety on A2A APIs

<!-- chunk: gaps -->
## Gaps

No allowed-pair control between named agents and no schema enforcement on A2A messages is described. JSON-RPC only. Response body deserialisation is not supported.

<!-- chunk: options -->
## Options

Write policies keyed on caller identity to limit which agents reach which A2A APIs.
