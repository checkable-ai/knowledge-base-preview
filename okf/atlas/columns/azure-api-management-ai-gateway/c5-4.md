## Answer

Covered, with conditions. The Azure Monitor based analytics dashboard needs a Log Analytics workspace. API analytics is not available in workspaces. Legacy built-in analytics in the classic tiers retires in March 2027. Detailed telemetry is captured through Azure Application Insights or Azure Monitor.

Source statement: "Azure Monitor collects and aggregates metrics and logs from your system to monitor availability, performance, and resilience, and notify you of issues affecting your system." (https://learn.microsoft.com/en-au/azure/api-management/monitor-api-management)

Last checked 17 November 2026.

Research detail: Azure Monitor collects gateway metrics and resource logs, and the Azure Monitor based analytics dashboard shows usage and performance by API, operation and language model. Backends have load balancers and circuit breakers, and the gateway scales by units or regions.

<!-- chunk: products -->
## Products

Azure Monitor metrics, API analytics, diagnostic settings, backend circuit breaker

<!-- chunk: gaps -->
## Gaps

Legacy built-in analytics in classic tiers retire in March 2027. Log Analytics request logs are not available on the Consumption tier.

## Options

Alert on gateway and backend metrics through Azure Monitor.
