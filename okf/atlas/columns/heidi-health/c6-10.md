## Answer

Covered, with conditions. Admins and users set auto-deletion for sessions, patients, chats and transcripts. Australian customer data is hosted in Australia. Memory is not a named retention category.

Source statement: "Data can be deleted manually, or you can set auto-deletion of data within defined retention policies." (https://support.heidihealth.com/en/articles/17240261-data-management)

Last checked 19 October 2026.

Research detail: Users and organisation admins set auto-deletion periods for sessions, patients, chats including Heidi Home, and transcripts, and deletion is permanent. Heidi states data for Australian customers is hosted in Australia and is not used for model training.
