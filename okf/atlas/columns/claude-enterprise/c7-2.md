## Answer

Covered. Cowork OpenTelemetry on Team and Enterprise; Compliance API on Enterprise. Detection content and response ownership are the customer's to set up. User email and folder paths are always included in OTel events.

Source statement: "OpenTelemetry monitoring for Claude Cowork is available on Team and Enterprise plans." (https://support.claude.com/en/articles/14477985-monitor-claude-cowork-activity-with-opentelemetry)

Research detail: The Compliance API feeds security platforms and SIEMs, with actor, IP and user agent on events. Cowork OpenTelemetry (Team and Enterprise) streams tool calls, file access and approval decisions to any OTel collector, with a prompt.id linking all events from one prompt and content capture off by default. Inference hooks record each denial.

<!-- chunk: products -->
## Products

Compliance API, Cowork OpenTelemetry, Inference hooks

<!-- chunk: gaps -->
## Gaps

Detection content and response ownership are left to the customer. User email and folder paths are always included in OTel events.

<!-- chunk: options -->
## Options

Route both feeds to the SIEM and write detections for denials and unusual tool use.
