## Answer

Not covered. Skill and plugin scanning and the desktop extension allowlist fall short: no SBOM, MCP servers and hooks are not scanned, and the allowlist does not guard against local tampering.

Research detail: Skill and plugin scanning (Enterprise) checks uploaded skills and plugins for malicious content and blocks failures, on by default from 2 October 2026. Owners can allowlist desktop extensions (Team and Enterprise), which force-removes unlisted ones. Organisation marketplaces sync only from private or internal repositories.

<!-- chunk: products -->
## Products

Skill and plugin scanning, desktop extension allowlist, private plugin marketplaces

<!-- chunk: gaps -->
## Gaps

MCP servers and hooks are not scanned, and scanning is unavailable with CMEK, ZDR or HIPAA. No SBOM is produced. The allowlist does not guard against local file tampering.

<!-- chunk: options -->
## Options

Scan MCP servers separately and require private marketplaces for plugins.
