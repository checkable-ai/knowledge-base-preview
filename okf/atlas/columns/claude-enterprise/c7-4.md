## Answer

Not covered. No documented hardening baseline or scanning of the containers, agent software or hosts that run models and tools. The nearby feature, the Claude Code Bash sandbox (OS-level filesystem and network isolation), isolates shell commands only. File tools, MCP servers and hooks run outside it. Customers cannot inspect or verify the hardening of Anthropic-hosted sessions.

Research detail: Anthropic documents isolation for Cowork: per-session cloud sandboxes destroyed at session end with no cross-tenant state, separation from research and training environments, and a hypervisor-isolated VM for local code. A detailed security architecture document is on the Trust Center.
