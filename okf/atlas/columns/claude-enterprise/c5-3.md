## Answer

Not covered. The Claude Code usage analytics Value tab estimates cost and return for Claude Code only. It does not cover other agents, infrastructure cost or staff time, and the return figures are estimates built from adjustable assumptions. Spend analytics and smart reports show spend and usage but give no return figure.

Research detail: Usage analytics show activity, adoption, skill and connector use and spend for Team and Enterprise owners. Claude Code analytics show accepted lines, sessions and a Value tab. The Enterprise Analytics API exports engagement and cost data, and smart reports (Enterprise beta) attach spend to workstreams and outputs.
