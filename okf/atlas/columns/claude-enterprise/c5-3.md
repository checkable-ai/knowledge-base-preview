## Answer

Not covered. No documented view that sets agent cost (model use, infrastructure, staff time) against delivered value. Smart reports (Claude Enterprise) show model spend at list price per workstream and output type, with time saved only as a ranking factor and no figures. They leave out infrastructure and staff-time cost. The Claude Code usage analytics Value tab gives an assumption-based estimate for Claude Code only.

Research detail: Usage analytics show activity, adoption, skill and connector use and spend for Team and Enterprise owners. Claude Code analytics show accepted lines, sessions and a Value tab. The Enterprise Analytics API exports engagement and cost data, and smart reports (Enterprise beta) attach spend to workstreams and outputs.

## Products

Usage analytics, Claude Code analytics, Enterprise Analytics API, smart reports
