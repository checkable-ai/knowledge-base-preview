## Answer

Covered. Inference hooks are Enterprise only and Owner configured; allow or deny only; some Anthropic-run calls not governed; not on Bedrock or Google Cloud. Spend limits per user and group.

Source statement: "Inference hooks let a Claude Enterprise organization route every governed prompt through an AI security server, an HTTPS service that the organization or its security vendor operates, before inference runs." (https://platform.claude.com/docs/en/manage-claude/inference-hooks)

Research detail: Inference hooks (Enterprise only, Owner configured) send every governed prompt across claude.ai, Cowork, Claude Code, Claude in Chrome and Microsoft 365 add-ins to the customer's security server for an allow or deny verdict before inference, and support model allowlist policies. Model access and effort caps apply per role. Spend limits apply per user, group and organisation with pooled group budgets in beta.

<!-- chunk: products -->
## Products

Inference hooks, model access, spend limits, Admin API spend limit endpoints

<!-- chunk: gaps -->
## Gaps

Hooks cannot redact or rewrite, and some Anthropic-run calls (Claude Security scans, Code Review, smart reports) are not governed. Not available on Bedrock or Google Cloud.

<!-- chunk: options -->
## Options

Run hooks in shadow mode first and set failure handling to block for high-risk groups.
