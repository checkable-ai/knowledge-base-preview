## Answer

Covered. Claude Enterprise only. Security center is in beta. Only Owners and the Primary Owner can open it. PDF report download. Compliance API adds programmatic access and status-change events.

Source statement: "Security center shows who attested and when." (https://support.claude.com/en/articles/18246629-review-your-organization-s-security-posture-with-the-security-center)

Research detail: No built-in posture view of control coverage or breaches. The Compliance API exposes each organisation's effective settings, which partner tools use for posture checks. Checked Compliance API and analytics pages.
