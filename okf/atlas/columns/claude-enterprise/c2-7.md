## Answer

Covered. Sandbox egress settings apply on Team and Enterprise; no documented admin action to terminate a specific running session; changes apply to new Cowork sessions only.

Source statement: "Claude operates with pre-installed packages only, with no internet access." (https://support.claude.com/en/articles/12111783-create-and-edit-files-with-claude)

Research detail: Code runs in isolated sandboxes or a VM with owner-set egress, and Cowork cloud egress passes a proxy the sandbox cannot bypass. Users can stop tasks at any time. Owners can turn off Cowork, cloud sessions, Chrome or code execution organisation-wide, shorten session length (Enterprise), and SCIM deprovisioning removes access and connector tokens.

<!-- chunk: products -->
## Products

Sandboxes and egress controls, organisation feature toggles, session length, SCIM deprovisioning

<!-- chunk: gaps -->
## Gaps

No documented admin action that terminates a specific running session. Network setting changes apply only to new Cowork sessions.

## Options
