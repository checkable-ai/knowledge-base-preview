## Answer

Not covered. The Compliance API Activity Feed gives per-user records, but tamper evidence is not documented for claude.ai Enterprise activity.

Research detail: The Compliance API (Enterprise) Activity Feed records authentication, chat, file, project and admin activity, retained 6 years from enablement. Content endpoints return chats and files, and session endpoints return Cowork, Claude Code, Microsoft 365 add-in and Chrome transcripts with prompts, responses and tool calls. Audit log CSV export covers 180 days.

## Products

Compliance API, audit log export

## Gaps

Tamper evidence is documented only for Anthropic staff access events on the API and Claude Code, not for claude.ai Enterprise activity. Recording is not retroactive. Local transcripts show what was sent to the API, not on-device actions.
