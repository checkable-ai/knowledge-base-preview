## Answer

Covered. Owners provision, change access to and remove skills and plugins. Group-limited distribution via plugins needs Enterprise. Configured per skill or plugin, not per agent identity.

Source statement: "Only owners can add or remove organization-wide skills." (https://support.claude.com/en/articles/13119606-provision-and-manage-skills-for-your-organization)

Research detail: SSO is on Team and Enterprise, SCIM on Enterprise only. Owners distribute skills and plugins (which bundle skills, connectors and sub-agents) through organisation marketplaces as Required, Installed by default, Available or Not available, with group overrides on Enterprise. User submissions can require owner review, and SCIM with custom roles controls who gets each capability. Provisioned skills and plugins also sync to Claude Code.

<!-- chunk: products -->
## Products

Plugin marketplaces, organisation skill provisioning, publishing review, custom roles and groups, SCIM

<!-- chunk: gaps -->
## Gaps

Configuration is per plugin or skill, not per agent identity. Server-managed Claude Code settings apply to everyone with no per-group targeting.

<!-- chunk: options -->
## Options

Use a GitHub-synced private marketplace so plugin changes go through code review.
