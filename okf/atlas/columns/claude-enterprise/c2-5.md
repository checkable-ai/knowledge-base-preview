## Answer

Covered. Org toggles on Team and Enterprise; groups and custom roles on Enterprise. Egress settings do not apply to web fetch, web search or MCPs.

Source statement: "Cowork respects your organization's current network egress permissions." (https://support.claude.com/en/articles/13455879-use-claude-cowork-on-team-and-enterprise-plans)

Research detail: Anthropic supplies the harness for chat, Cowork, Claude Code and Claude in Chrome. Owners can turn each on or off by organisation toggle and, on Enterprise, by role. MDM keys can turn off Cowork, Claude Code, local MCP servers and extensions in Claude Desktop, and Claude Code server-managed settings can enforce permissions and hooks.

<!-- chunk: products -->
## Products

Cowork, Claude Code, Claude in Chrome, Claude Desktop policy keys, server-managed settings

<!-- chunk: gaps -->
## Gaps

Per-group harness configuration for Claude Code is not supported in the console.

<!-- chunk: options -->
## Options

Combine organisation toggles with MDM for managed devices.
