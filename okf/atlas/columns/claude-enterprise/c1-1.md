## Answer

Covered. Team and Enterprise; Claude Desktop MDM policy keys; Claude Code server-managed settings apply to all users and are client-side.

Source statement: "Filepath or filepaths the user can mount to Cowork" (https://support.claude.com/en/articles/12622667-enterprise-configuration-for-claude-desktop)

Research detail: Local Cowork sessions are limited to folders the member connects, and the allowedWorkspaceFolders MDM key restricts which paths can be mounted. MDM keys can disable local MCP servers, desktop extensions, Cowork and Claude Code in Claude Desktop (Team and Enterprise). Claude Code server-managed settings let owners enforce permission deny rules. Computer use is not offered on Team or Enterprise.

<!-- chunk: products -->
## Products

Claude Desktop enterprise policy keys, Cowork connected folders, Claude Code server-managed settings

<!-- chunk: gaps -->
## Gaps

Server-managed settings are a client-side control that users on unmanaged devices can bypass, and apply to all users with no per-group targeting.

<!-- chunk: options -->
## Options

Deploy Desktop and Claude Code policy through MDM on managed devices.
