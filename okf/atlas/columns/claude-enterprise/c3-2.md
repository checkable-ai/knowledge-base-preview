## Answer

Not covered. The documented controls cover allow and block per tool only. They do not enforce input formats or limits, so the outcome is not met.

Research detail: Owners allow connectors, restrict actions organisation-wide and, on Enterprise, set per-tool grants per role. With Validate tool calls on, Inference hooks send tool calls to the security server before they run. Code execution egress is set by owners and Claude in Chrome and the Cowork browser follow an organisation site allowlist and blocklist.

<!-- chunk: products -->
## Products

Connector tool policy, custom role connector grants, Inference hooks tool_call event, egress settings, Chrome site lists

<!-- chunk: gaps -->
## Gaps

Egress settings do not cover MCP traffic. Some claude.ai built-in tools are left out of tool_call events. Rate limits per tool are not documented.

<!-- chunk: options -->
## Options

Turn on Validate tool calls and block write tools by default.
