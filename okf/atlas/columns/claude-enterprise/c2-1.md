## Answer

Covered. Cowork cloud availability is on by default for Team and off by default for Enterprise. Retry and recovery semantics not documented.

Source statement: "Scheduled tasks run remotely, so they run on their cadence even when your computer is asleep or the Claude Desktop app is closed." (https://support.claude.com/en/articles/13854387-schedule-recurring-tasks-in-claude-cowork)

Research detail: Cowork runs multi-step tasks as sessions and scheduled tasks run on a cadence in the cloud even when the device is off. Cloud sessions continue across desktop, web and mobile, and users can stop or pause tasks. Owners control Cowork, cloud sessions and Claude Code dynamic workflows by organisation toggle and role.

<!-- chunk: products -->
## Products

Cowork tasks and scheduled tasks, Cowork in the cloud, Claude Code dynamic workflows

<!-- chunk: gaps -->
## Gaps

Retry and recovery semantics for failed tasks are not documented. Admins cannot see or cancel another member's running task from the console.

<!-- chunk: options -->
## Options

Restrict cloud sessions and dynamic workflows by role during pilot.
