## Answer

Covered. Team and Enterprise; network access off by default; owners choose egress level. Egress settings do not cover MCP connectors, web search or Claude in Chrome.

Source statement: "When Claude executes code or creates files, it operates within an isolated, sandboxed container." (https://support.claude.com/en/articles/12111783-create-and-edit-files-with-claude)

Research detail: Code execution runs in an isolated sandbox and owners on Team and Enterprise choose network egress: off, package managers only, package managers plus listed domains, or all domains. Enterprise starts with egress off. Cowork cloud sessions use a per-session sandbox with egress through a mandatory proxy, and local Cowork code runs in a hypervisor-isolated VM.

<!-- chunk: products -->
## Products

Code execution and file creation sandbox, network egress settings, Cowork cloud sandbox and local VM

<!-- chunk: gaps -->
## Gaps

Egress settings do not cover MCP connectors, web search, web fetch or Claude in Chrome. EDR tools cannot inspect the Cowork VM or cloud sessions.

<!-- chunk: options -->
## Options

Keep egress off or domain-allowlisted and govern MCP connectors separately.
