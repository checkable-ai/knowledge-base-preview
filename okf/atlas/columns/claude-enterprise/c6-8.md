## Answer

Not covered. Skill and plugin update review and versioning exist, but rollback is not documented and prompt and model changes have no release gate.

Research detail: Plugin and skill updates go through the same review as the first version, with a diff shown. Claude Code server-managed settings changes are written to audit events with previous and new values. Role and permission changes are made in the console and take up to 15 minutes.

Publishing review, version history, server-managed settings audit events
