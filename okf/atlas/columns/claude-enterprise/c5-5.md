## Answer

Not covered. There is no readable map, per agent or across the organisation, of which downstream systems each agent can reach and what it can do there. The /mcp panel and claude mcp list show one user's servers, their status, tool counts and tool settings for the current session or project only. Servers blocked by managed MCP configuration are hidden rather than listed. View effective role is per member and only covers members with custom roles.

Last checked 16 November 2026.

Research detail: On Enterprise, View effective role shows each member's capabilities, admin permissions and connectors with the level granted and the granting role. Usage analytics count connector users and read and write actions. The plugin and skill Inventory lists capabilities and audience.
