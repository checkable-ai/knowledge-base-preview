## Answer

Partly covered. Central retention and deletion for agent sessions. Custom retention does not cover Cowork cloud sessions a member starts directly, scheduled tasks and their runs, Cowork history on members' computers, memory of former members, or transcripts and memory kept by Claude Code, including Claude Code on the web. Standalone Claude Design, Claude Tag and Claude Managed Agents are also excluded. Admins cannot centrally manage or delete local Cowork data, and deletion endpoints for local sessions are not available. There is no customer choice of storage location and no Australian residency, because data is stored in the US.

Source statement: "Cowork cloud sessions a member starts directly, including in a project." (https://support.claude.com/en/articles/17444462-set-up-and-manage-the-new-unified-claude-experience-for-your-enterprise-organization)

Research detail: Enterprise owners set chat and project retention (30 day minimum, default indefinite), the Compliance API can delete chats, files and projects, and incognito chats follow organisation retention. US-only inference is available on usage-based Enterprise. Data is stored in the US, and CMEK is available to eligible Enterprise organisations.

<!-- chunk: products -->
## Products

Custom data retention, Compliance API delete, US-only inference, CMEK

<!-- chunk: gaps -->
## Gaps

No Australian residency. Retention excludes Claude Code cloud features and Claude Design, and local Cowork history cannot be centrally deleted. Flagged chats are kept up to 2 years.

<!-- chunk: options -->
## Options

Set retention, enable deletion workflows through the Compliance API and record US storage in the privacy impact assessment.
