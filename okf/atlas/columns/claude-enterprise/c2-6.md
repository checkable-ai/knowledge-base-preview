## Answer

Covered. Team and Enterprise. Owners enable memory for the organisation, and each member turns it on for themselves. Entries are not removed when the source chat expires.

Source statement: "When an owner turns memory off for the organization, all existing memory entries for all users are deleted immediately." (https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context)

Research detail: Memory and past-chat search let Claude use earlier conversations. On Team and Enterprise owners decide whether memory is available, it is off for each member until they turn it on, and turning it off for the organisation deletes all memory entries. Memory follows chat retention, and members can view, edit and delete entries.

<!-- chunk: products -->
## Products

Memory, chat search

<!-- chunk: gaps -->
## Gaps

Memory entries created from a chat are not removed when that chat expires or is deleted. Memory can be granted per role on Enterprise.

<!-- chunk: options -->
## Options

Decide memory policy before enabling and include memory in retention reviews.
