## Answer

Covered. Owners or Primary Owners approve; connector requests are off by default on Enterprise; publishing review applies to skills and plugins.

Source statement: "Decline it and block the connector, so no one else can request it until an owner adds it" (https://support.claude.com/en/articles/11176164-use-connectors-to-extend-claude-s-capabilities)

Research detail: Publishing can require owner review, with each request showing the scan result, files, changes and possible duplicates, and owners approve or request changes. Members can request connectors, which owners approve, decline or decline and block. Enterprise publishing defaults to Requires review from 2 October 2026 if unset.

<!-- chunk: products -->
## Products

Publishing review, connector requests

<!-- chunk: gaps -->
## Gaps

No workflow for registering models or agents. Connector requests are off by default on Enterprise.

<!-- chunk: options -->
## Options

Turn on Requires review and connector requests with a named reviewer group.
