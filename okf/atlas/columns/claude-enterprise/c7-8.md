## Answer

Covered. Compliance API, custom retention and CMEK are Enterprise features.

Source statement: "The Compliance API exposes hard-delete endpoints for chats, files, project documents, and entire projects." (https://platform.claude.com/docs/en/manage-claude/compliance-content-data)

Research detail: Project knowledge files are the main data store. Owners control project sharing, Enterprise retention deletes projects and their contents, the Compliance API can retrieve and delete projects and attachments, and CMEK can encrypt chats, projects and files.

<!-- chunk: products -->
## Products

Projects, project sharing controls, retention, Compliance API delete endpoints, CMEK

## Gaps
