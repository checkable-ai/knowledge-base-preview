## Answer

Not covered. No documented per-agent identity tied to an owner, runtime location and release. Agents act as the signed-in member, and the Compliance API and audit logs attribute activity to users, which is per-user attribution and falls short of an agent identity.

Research detail: Claude agents (Cowork, Claude Code, Claude in Chrome) act as the signed-in member, and records are attributed to that user and session. The Compliance API ties each session to a user. There is no separate agent or workload identity with an owner, runtime and release.
