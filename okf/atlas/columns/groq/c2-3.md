## Answer

Covered, with conditions. Code Execution tool only, Python only, not available on regional or sovereign endpoints. Groq does not host the customer's own agent software.

Source statement: "Code execution runs in a secure sandboxed environment with no access to external networks or sensitive data" (https://console.groq.com/docs/tool-use/built-in-tools/code-execution)

Last checked 19 October 2026.

Research detail: The built-in code execution tool runs Python in an isolated, ephemeral sandbox powered by E2B, with no external network access, timeouts and a fresh environment per request.
