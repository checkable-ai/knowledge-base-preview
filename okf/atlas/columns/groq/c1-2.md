## Answer

Covered. Remote MCP, currently in beta. Limits apply at the tool level through allowed_tools.

Source statement: "Allows you to filter the tools that the model can use." (https://console.groq.com/docs/tool-use/remote-mcp)

Research detail: Remote MCP accepts an allowed_tools filter that limits which tools of a server the model may call. Model permissions limit which models a project can use.

<!-- chunk: products -->
## Products

allowed_tools, Model Permissions

<!-- chunk: gaps -->
## Gaps

Scopes apply to tool names and models, not to actions or data in a connected system.

<!-- chunk: options -->
## Options

Enforce action scopes in the MCP server or a gateway.
