## Answer

Covered. Remote MCP only, currently in beta. require_approval must be set to always, since the default is no approval. The caller returns an mcp_approval_response with approve true or false.

Source statement: "Whether human approval is required for the tool call" (https://console.groq.com/docs/tool-use/remote-mcp)

Research detail: Remote MCP supports require_approval set to always. Groq then pauses and returns an mcp_approval_request, and the caller returns an mcp_approval_response with the request ID and an approve flag.

## Products

require_approval on Remote MCP

## Gaps

The approval is keyed to a request ID, and denial and replay handling are not described. The default value was not established clearly from the page. The feature is in beta and covers MCP only.

<!-- chunk: options -->
## Options

Set require_approval to always explicitly and test denial paths.
