## Answer

Not covered. The Code Execution sandbox limits network and data access for that tool only. There is no file, process or egress policy for customer agents and no stop control for a running agent. Key revocation and the spend cap are the only cut-off steps.

Research detail: Code execution is isolated and ephemeral with no outside network and timeouts. Revoking a key is the documented incident step, and reaching the organisation spend cap blocks all keys with a 400 error.
