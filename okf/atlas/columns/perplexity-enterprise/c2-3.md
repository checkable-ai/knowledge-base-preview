## Answer

Covered. Firewall changes apply to new tasks only.

Source statement: "Each task session runs in its own isolated compute container with a dedicated filesystem and browser instance" (https://www.perplexity.ai/help-center/en/articles/13901210-computer-for-enterprise)

Research detail: Each Computer task runs in its own isolated compute container with a dedicated filesystem and browser, separated from the organisation network and other members' sessions. Admins can apply a network firewall policy with an internet toggle, allowed domains and denied CIDRs. Personal and Portable Computer run on the user's device and ask before sending work to the cloud.
