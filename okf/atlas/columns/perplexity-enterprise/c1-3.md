## Answer

Covered. Approval is by the member running the task. Tools set to Always ask.

Source statement: "Perplexity asks for your confirmation before every call." (https://www.perplexity.ai/help-center/en/articles/12569435-microsoft-365-connector-sharepoint-and-onedrive)

Research detail: Connector tools set to Always ask pause for the user to approve that single action, allow it for the rest of the thread, or deny it, and recurring runs inherit thread-level grants. Comet Agent checks with the user before important or sensitive actions, and admins can remove the Always allow option. Computer drafts a plan and waits for approval before long or credit-heavy tasks, and asks before using saved credentials.

<!-- chunk: products -->
## Products

Connector approvals, Comet Assistant permissions, Computer plan approval, credential approval

<!-- chunk: gaps -->
## Gaps

Inherited thread grants mean later recurring runs proceed without a fresh decision. Approvals are by the member running the task, not a separate approver.

<!-- chunk: options -->
## Options

Set write tools to Always ask, disable Always allow for Comet, and review audit events for approved actions.
