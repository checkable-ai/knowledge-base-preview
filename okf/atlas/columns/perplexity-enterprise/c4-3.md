## Answer

Covered. Connectors using per-user authentication. Admin-set organisation-scoped connectors use a shared identity instead.

Source statement: "Standard Search reads the connected service at query time, so it always sees your current files" (https://www.perplexity.ai/help-center/en/articles/10673197-perplexity-connectors-for-enterprise-frequently-asked-questions)

Research detail: Connectors authenticate with each member's own account, and Standard Search reads the source at query time so answers reflect source permissions. Shared answers only show cited files to people who already have access in the source system. Data Map queries run with each user's connected warehouse account or a shared service account.

<!-- chunk: products -->
## Products

File and app connectors, custom remote connectors, Snowflake and Databricks connectors

<!-- chunk: gaps -->
## Gaps

Admins can authenticate an organisation-scoped OAuth connector once for everyone, which replaces per-user delegation with a shared identity. Token exchange or user context passed to custom MCP servers is not documented.

<!-- chunk: options -->
## Options

Require per-member authentication on organisation connectors and confirm in source system logs that actions carry the member identity.
