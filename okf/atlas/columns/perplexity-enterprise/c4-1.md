## Answer

Not covered. No separate agent identity tied to owner, runtime and release. Audit events carry user email, IP and session ID, which identify the member, not the agent.

Research detail: Computer, Comet Assistant and Comet Agent act inside a member's own session. Audit events are attributed to the user email, IP address and session ID, and Comet Telemetry records device and browser profile IDs. No separate agent or workload identity tied to an owner, runtime and release is documented.
