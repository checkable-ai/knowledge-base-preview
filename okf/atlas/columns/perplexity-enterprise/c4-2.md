## Answer

Not covered. Custom API credentials for Computer are scoped, revocable and injected through a proxy, but no rotation or expiry is documented, so they are not short-lived. Only proxied API requests are supported, and Always allow removes per-use approval.

Research detail: Custom API credentials for Computer are entered in a secure form, encrypted and injected into outgoing API requests through a secure proxy, so the raw value never reaches the agent trajectory or the sandbox. Credentials can be scoped to one task, a personal vault or a project, can be revoked, and saved ones need user approval before each use unless Always allow is set. Custom connector secrets and Cloudflare Access headers are stored encrypted and redacted.

## Products

Credential vault, custom API credentials, custom remote connectors

<!-- chunk: gaps -->
## Gaps

No rotation or expiry for vault credentials is documented. Only API requests routed through the proxy are supported, not SSH keys or other secret types. Always allow removes the per-use check.

<!-- chunk: options -->
## Options

Prefer session or project credentials with short-lived upstream tokens, and test that a revoked vault credential fails in a running task.
