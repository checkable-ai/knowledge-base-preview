## Answer

Covered. Enterprise plans. Per-tool Allow, Always ask or Disable with locks is documented for the Microsoft 365 connector. Custom connectors are off by default.

Source statement: "set organization-wide defaults for these groups and lock individual tools so members cannot override them." (https://www.perplexity.ai/help-center/en/articles/12569435-microsoft-365-connector-sharepoint-and-onedrive)

Research detail: Admins enable or disable each connector for the organisation and choose whether new connectors start enabled. Microsoft 365 connector tools can be set to Allow, Always ask or Disable per group or per tool, and admins can set organisation defaults and lock tools. Member-added custom connectors are off by default, and a network firewall policy restricts which domains and CIDRs the Computer sandbox can reach.

## Products

Connector availability, Manage connector defaults permission, per-tool connector permissions, Network Firewall Policy

<!-- chunk: gaps -->
## Gaps

Per-tool locking is documented for the Microsoft 365 connector. Other connectors may only have on or off at organisation level.

<!-- chunk: options -->
## Options

Inventory each enabled connector and set write tools to Always ask or Disable.
