## Answer

Covered. Comet Assistant permissions are organisation admin settings. Desktop folder access is granted per user.

Source statement: "these settings override the global assistant permissions." (https://www.perplexity.ai/help-center/en/articles/13531023-managing-comet-assistant-permissions)

Research detail: Admins set Comet Assistant permissions for the organisation: whether it can control the browser, whether Always allow is offered, and per-domain Browser Control, Read Only or No Access that overrides the global setting. Comet is managed through 500+ Chromium policies by MDM. On the desktop app, Perplexity can only work inside folders the user adds, and organisations can set rules for local inference and what may leave the device.

<!-- chunk: products -->
## Products

Comet Assistant permissions, Comet browser policies, Personal Computer folder access

<!-- chunk: gaps -->
## Gaps

Desktop folder access is granted per user. Admins decide whether local inference is allowed on Windows and Linux, but rules for what must stay on device are only described for Mac.

<!-- chunk: options -->
## Options

Deploy Comet with MDM, block sensitive domains with No Access, and disable Always allow.
