## Answer

Not covered. Audit Logs (Enterprise orgs with 50+ seats or an Enterprise Max user) record queries, agent steps, answers and admin changes with user, IP and session, and stream to a customer webhook. Perplexity does not document write-once or integrity-validated storage, signing or hash chaining, or an export to such storage. A webhook push alone does not make entries tamper-evident.

Research detail: Audit Logs stream every query, generated answer, agent step, Comet and Computer agent action, file, connector, sharing, role and settings change in real time to an HTTPS webhook. Events carry user email, IP, user agent, timestamp and session ID, settings changes include old and new values, and answer events include the model used.
