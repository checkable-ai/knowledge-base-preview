## Answer

Covered. The tenant setting Show desktop flow actions in DLP policies must be turned on, and once enabled it cannot be changed. Design-time enforcement needs Power Automate for desktop version 2.14.173.21294 or later. Only modules explicitly classified in a policy group are enforced, and basic modules such as Variables cannot be managed. Enforcement can take up to 24 hours.

Source statement: "Power Automate allows you to create and enforce DLP policies that classify desktop flow modules and individual module actions as Business, Non-business, or Blocked." (https://learn.microsoft.com/en-us/power-automate/prevent-data-loss)

Last checked 17 November 2026.

Research detail: Managed environments list data policies for desktop flows, so connector and module use on the local host can be governed from the admin center. Other local scopes such as file system or process limits are not described in the pages read.
