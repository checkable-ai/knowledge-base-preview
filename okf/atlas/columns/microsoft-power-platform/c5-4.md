## Answer

Covered. Tenant-level analytics must be turned on for Monitor data to be available. Monitor recommendations require a managed environment. Metrics are aggregated daily, not real time, and are kept for up to 28 days, with event logs available for up to seven days. Work queue and Dataverse monitoring are not yet available.

Source statement: "Your organization can use the Monitor area of the Power Platform admin center to measure and improve operational health metrics of resources that are built or deployed." (https://learn.microsoft.com/en-us/power-platform/admin/monitoring/monitoring-overview)

Last checked 17 November 2026.

Research detail: Power Automate analytics and Application Insights export cover flow runs, failures and performance. The flow limits page sets throttling and run limits, and consistently throttled flows are turned off. Load testing and anomaly detection are not described as built-in features.

<!-- chunk: products -->
## Products

Power Automate analytics, Application Insights export, flow limits

<!-- chunk: gaps -->
## Gaps

Run level detail sits outside Purview. Infrastructure anomaly detection is not documented.

<!-- chunk: options -->
## Options

Export to Application Insights and alert on failure and throttling rates.
