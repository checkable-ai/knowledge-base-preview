## Answer

Covered, with conditions. Needs the Power Automate Hosted Process licence (previously the hosted RPA add-on). Hosted machine groups run unattended only and need an Azure subscription for a custom virtual network or Azure Compute Gallery image. Machines are provisioned in the Azure region mapped to the environment's geography. Singapore is for allowlisted tenants only. Hosted machine groups are not available in China. In GCC, GCC High and DoD, work or school accounts are not supported, and custom VM images are not supported in GCC and DoD. Microsoft Entra hybrid join with custom virtual networks is in preview.

Source statement: "You can connect to your own virtual network with your hosted machine groups to securely communicate with each other, the Internet, and on-premises networks." (https://learn.microsoft.com/en-us/power-automate/desktop-flows/hosted-machine-groups)

Research detail: Each environment is a boundary bound to a tenant and a geography, and apps can connect only to data sources in the same environment. Managed environments add IP firewall, virtual network support and conditional access on individual apps. Hosts and runtimes are Microsoft operated, so customers do not configure the execution host itself.
