## Answer

Covered, with conditions. The connection must be set to Provided by run-only user; embedded connections otherwise run as the connection owner. Run-only sharing is described for instant flows. Sharing a cloud flow needs a Power Automate licence other than the free licence, or a seeded licence such as Office 365 or Dynamics 365 plans.

Source statement: "When the flow connects to a service via a connector, the Provided by run-only user connections allow the flow to act as the run-only user and access the data that the user has access to." (https://learn.microsoft.com/en-us/power-automate/create-team-flows)

Last checked 17 November 2026.

Research detail: A connection set to Provided by run-only user makes the flow act as the person who runs it and reach only the data that person can access. Copilot in Power Platform answers only from data the user can reach. By default, embedded connections run as the connection owner, so propagation depends on how each flow is configured.

<!-- chunk: products -->
## Products

Provided by run-only user connections, Copilot permission inheritance

<!-- chunk: gaps -->
## Gaps

Not enforced by default and not documented for apps calling other services in the maker's name. No token exchange or scoped delegation chain is described.

<!-- chunk: options -->
## Options

Require run-only user connections for flows that touch user data and review embedded connections in production flows.
