## Answer

Not covered. No customer-configurable gateway for model calls with routing, quotas, cost or rate limits per agent, user or workload, and no admin-defined prompt screening rules. Nearest features are the Copilot hub on/off settings, the data movement setting and a preview user allow list for model-driven apps. Prompt injection protection is a Microsoft-side requirement.

Last checked 17 November 2026.

Research detail: Admins switch generative AI features on or off per environment or environment group, control data movement across regions and, in preview, limit which users in model-driven apps can use Copilot. Prompt injection protection is described as a requirement on Microsoft services. There is no customer configurable model gateway with routing, quotas or screening rules.

## Products

Copilot hub settings, generative AI settings rule, data movement setting

## Gaps

No per user quota or cost routing. Copilot user allow lists are preview and only for managed environments.

<!-- chunk: options -->
## Options

Use environment group rules to stage AI features and keep a record of which groups have them on.
