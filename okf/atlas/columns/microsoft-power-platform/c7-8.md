## Answer

Partly covered. No cleaning or sanitisation of data used by agents, and no feature store or training data governance. Dataverse is an application data store.

Source statement: "Microsoft Dataverse uses a role-based security model to control access to a database and its resources in an environment." (https://learn.microsoft.com/en-us/power-platform/admin/database-security)

Last checked 17 November 2026.

Research detail: Dataverse underpins apps and flows with role-based security, environment boundaries, masking rules and encryption at rest with an optional customer-managed key. Retention, residency and access are governable, but feature store and training data sanitisation are not in scope.

<!-- chunk: products -->
## Products

Dataverse security roles, masking rules, customer-managed key

<!-- chunk: gaps -->
## Gaps

Application data store, not a model or feature store. Sanitisation tooling for AI data is not described.

<!-- chunk: options -->
## Options

Apply column security and masking to sensitive tables before enabling Copilot features that read them.
