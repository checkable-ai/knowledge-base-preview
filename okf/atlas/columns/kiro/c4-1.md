## Answer

Not covered. No distinct agent identity bound to owner, runtime and release. Agent profiles are local named config files and the GitHub app installation is shared across the organisation.

Research detail: Kiro has no separate agent or workload identity. Custom agents are named profiles in .kiro/agents files. Kiro Web acts through the Kiro Agent GitHub app and lists both the user and the agent as co-authors on every commit. Telemetry ties activity to an IAM Identity Center user ID and a Kiro profile ARN.
