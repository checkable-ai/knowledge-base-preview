## Answer

Not covered. No Kiro feature is documented that records each agent action (tool calls, data access, changes) with agent, user/session, action and time in write-once or integrity-validated storage. CloudTrail logging of Kiro API activity falls short because it covers API calls, not agent tool actions. Crew's HMAC-signed audit trail is not documented to capture user and session context. Prompt logging to S3 has no tamper protection.

Research detail: Prompt logging writes IDE and CLI chat prompts, responses and inline suggestions with user ID, timestamps and conversation IDs to a customer S3 bucket. CloudTrail records Kiro API calls with caller, source IP and time. Kiro Crew records every tool call, approval and denial in an HMAC-signed trail with an integrity check command.

<!-- chunk: products -->
## Products

Prompt logging, AWS CloudTrail, Kiro Crew audit trail

<!-- chunk: gaps -->
## Gaps

Prompt logs do not document tool call records or Kiro Web coverage. Tamper resistance of S3 logs depends on bucket configuration.

<!-- chunk: options -->
## Options

Enable S3 Object Lock and versioning on the prompt log bucket and correlate with CloudTrail.
