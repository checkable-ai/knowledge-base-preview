## Answer

Covered. Local CLI sessions are stored on the user's machine and do not sync; cloud sessions are separate. Deletion is manual.

Source statement: "Kiro CLI automatically saves all chat sessions on every conversation turn." (https://kiro.dev/docs/cli/chat/session-management/)

Research detail: Kiro CLI saves every turn to a local SQLite store with owner-only file access, scoped per directory, and supports resume, export and deletion. Cloud sessions are stored in the account's cloud session store and can be resumed from any machine. Untrusted workspaces cannot write to the session store.
