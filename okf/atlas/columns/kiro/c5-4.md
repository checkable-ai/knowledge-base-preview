## Answer

Not covered. Crew's System dashboard and resource_status tool show current task state, resource use, Gateway capacity and memory-pressure deferral on the Crew host. They are a live view only. No anomaly detection, alerting or historical performance monitoring is documented, and there are no host metrics for Kiro Web sandboxes. The vendor page does not describe this as covering part of a monitoring outcome.

Research detail: Kiro publishes metrics to CloudWatch, for example invocation counts and daily active users, which support alarms and dashboards. Kiro is a managed service so load performance of inference is AWS's responsibility.
