## Answer

Covered. Kiro CLI V3 and IDE 1.0 agent configuration; legacy 2.x profiles must be converted.

Source statement: "The `tools` field lists all tools that the agent can potentially use." (https://kiro.dev/docs/custom-agents/configuration-reference/)

Research detail: The Kiro IDE and CLI are the harness that executes tools, with agent profiles setting visible tools, permissions, MCP servers, model and hooks. Pre Tool Use hooks can validate and block tool calls. Kiro Crew enforces a fixed sequence of gates on every tool call.
