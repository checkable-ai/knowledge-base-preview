## Answer

Covered, with conditions. Documented for Kiro Crew subagents. Each subagent can run up to three hours and make up to 1000 tool calls. Workflows are opt-in. Web execution needs a cloud-session subscription (Pro, Pro+, Pro Max or Power).

Source statement: "a row that stops producing activity is marked stalled so you can inspect or stop it." (https://kiro.dev/docs/crew/features/subagents/)

Last checked 15 November 2026.

Research detail: Kiro Web autonomous mode plans work, delegates steps to sub-agents and opens pull requests, entering a needs attention state when blocked. Kiro Crew subagents run in parallel from a durable queue with stop, retry, stalled detection and run limits of three hours and 1,000 tool calls. Spec task lists sequence implementation work.
