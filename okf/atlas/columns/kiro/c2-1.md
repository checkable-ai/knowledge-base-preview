## Answer

Covered. Documented for Kiro Crew subagents, not for Kiro Web tasks.

Source statement: "Crew does not treat silence alone as proof that useful work ended." (https://kiro.dev/docs/crew/features/subagents/)

Research detail: Kiro Web autonomous mode plans work, delegates steps to sub-agents and opens pull requests, entering a needs attention state when blocked. Kiro Crew subagents run in parallel from a durable queue with stop, retry, stalled detection and run limits of three hours and 1,000 tool calls. Spec task lists sequence implementation work.
