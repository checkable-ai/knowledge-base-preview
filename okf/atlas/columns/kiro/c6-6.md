## Answer

Not covered. No accountable owner records for agents, models or tools. Activity attribution to users falls short.

Last checked 15 November 2026.

Research detail: Kiro Web commits name the user and the agent as co-authors, and pull requests can be created as the user. Prompt logs and activity reports attribute activity to a user ID.
