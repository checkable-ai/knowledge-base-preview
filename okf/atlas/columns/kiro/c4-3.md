## Answer

Covered. Kiro Web with the GitHub app only. Users connect their own GitHub account and need write access. Delegated identity to MCP servers or other downstream systems is not documented.

Source statement: "The agent acts on your behalf and includes both you and itself as co-authors in every commit, ensuring proper attribution." (https://kiro.dev/docs/web/github/)

Research detail: In Kiro Web each user connects their own GitHub account, sees only repositories that both the app and the user can access, and can assign tasks only where they have write permission. An option creates pull requests as the user's GitHub identity. Outside GitHub, MCP servers use whatever credentials the user configures.

<!-- chunk: products -->
## Products

Kiro Agent GitHub app, Create pull requests as your GitHub user option

<!-- chunk: gaps -->
## Gaps

User authority is propagated to GitHub only. No token exchange or delegated identity to MCP servers or other downstream services is documented.

<!-- chunk: options -->
## Options

Use MCP servers that support per-user OAuth, or front downstream services with a gateway that performs token exchange.
