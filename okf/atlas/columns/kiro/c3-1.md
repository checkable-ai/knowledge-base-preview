## Answer

Not covered. No control point that every model call passes through. Per-user credit usage limits in the Kiro Enterprise credit pool cap spend, but there is no per-agent or per-workload routing, no rate limits and no prompt screening. The approved model list only restricts model selection.

Last checked 15 November 2026. This platform is checked on demand, so this answer has not been rechecked since.

Research detail: Admins restrict models to an approved list with a default model, and overage beyond plan credits is off by default with a profile-wide cap set through Service Quotas. The Auto router chooses models per task. All inference goes through Kiro's service rather than a customer gateway.
