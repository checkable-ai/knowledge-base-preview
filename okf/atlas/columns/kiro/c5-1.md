## Answer

Covered. Kiro Web autonomous mode; the agent does not always open a pull request, and review relies on repository rules.

Source statement: "The agent automatically addresses your comments and pushes updates." (https://kiro.dev/docs/web/autonomous-mode/)

Research detail: Kiro Web delivers work as pull or merge requests for human review, and reviewers direct fixes with /kiro all or /kiro fix comments. Specs give reviewable requirements, design and task documents before code is written.
