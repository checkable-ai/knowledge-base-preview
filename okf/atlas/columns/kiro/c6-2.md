## Answer

Not covered. No submission, registration and approval workflow for models, agents or tools. The MCP registry is an admin-maintained allow-list, and the page describes no submission or approval process. It is also enforced client-side.

Last checked 15 November 2026. This platform is checked on demand, so this answer has not been rechecked since.

Research detail: Once model access management is on, new models stay unavailable until an admin adds them, with a console notification on release. MCP servers must be added to the admin registry file to be usable.
