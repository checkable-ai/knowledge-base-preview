## Answer

Not covered. No scanning for look-alike names, poisoned descriptions or compromised packages. The registry allow-list only restricts choice, and the vendor says it does not vet third-party MCP servers.

Last checked 15 November 2026.

Research detail: The powers registry offers curated partner powers, and the admin MCP registry limits users to named packages at fixed versions, removing servers no longer listed. Community powers install from any GitHub URL with no documented review.
