## Answer

Not covered. No SBOM, scanning or verification of MCP servers, skills or extensions. MCP sandboxing limits runtime impact only, and the vendor states Kiro does not vet third-party MCP servers.

Last checked 15 November 2026. This platform is checked on demand, so this answer has not been rechecked since.

Research detail: Admins can pin Kiro client versions with a self-hosted update server and phased rollouts, and pin MCP server package versions in the registry file. The MCP security page states Kiro does not vet, sandbox or restrict third-party servers and recommends manual source review.
