## Answer

Not covered. Only saved Crew workflows in the library are versioned, with revision history and rollback. No approval step is documented. No versioning or rollback is documented for models, prompts, steering, hooks, tools, permissions or knowledge.

Research detail: Managed updates let admins pin Kiro IDE and CLI versions and run phased rollouts through a self-hosted update server. Model and MCP versions change only when admins edit the allow-list or registry.
