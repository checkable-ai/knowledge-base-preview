## Answer

Not covered. OpenTelemetry export is aggregate metrics, with no session events, detections, redaction or response ownership.

Research detail: Kiro exports daily aggregate usage metrics by user over OpenTelemetry to collectors such as Datadog, Elastic and CloudWatch. CloudTrail and S3 prompt logs can be ingested into a SIEM.

<!-- chunk: products -->
## Products

OpenTelemetry export, CloudTrail, prompt logging

<!-- chunk: gaps -->
## Gaps

Telemetry is daily aggregates with no session or tool call events. No built-in detections, redaction or response ownership.

<!-- chunk: options -->
## Options

Ingest prompt logs and CloudTrail into a SIEM and write detections there.
