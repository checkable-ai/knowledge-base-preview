## Answer

Covered. Kiro IDE and CLI; Memory setting defaults to Off; stored locally per user account; no retention period documented.

Source statement: "To delete a memory, right-click its row and choose Delete, or select Delete in its tab." (https://kiro.dev/docs/memory/)

Research detail: Kiro Web learns from the task creator's pull request feedback and applies it across that user's repositories, with memories reviewable and deletable in settings. Kiro Crew keeps preferences, lessons, project context and history summaries across sessions.
