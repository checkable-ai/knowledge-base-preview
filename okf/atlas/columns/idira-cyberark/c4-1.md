## Answer

Not covered. Managed AI agents registration gives an agent ID, owners and an origin ID linking to the runtime agent, but no documented binding of the identity to a specific release or version.

Research detail: Registering an agent in Managed AI agents creates an agent identity with an auto-generated Agent ID, a fixed agent type, owners and an optional platform-native origin ID (for example an AWS ARN) that links it to the discovered runtime agent. Secure Workload Access also issues SPIFFE identities to AI agents on Google Gemini Enterprise Agent Platform. Release linkage is limited to version fields shown in discovery metadata for AWS agents.
