## Answer

Covered. Policies match user or role, registered agent and tools on MCP servers; whole server allowed until tools are discovered.

Source statement: "Our Agent Identity Broker enforces dynamic access policies" (https://www.paloaltonetworks.com/idira/agentic.md)

Research detail: AI agent access policies grant access only when the user or role, the registered agent and the specific tools on specific MCP servers all match, with deny by default and newly discovered tools denied when specific tools are selected. Until tools are discovered a policy allows the whole MCP server. Database access is limited to the default database through SIA.

## Products

AI agent access policies, Identity Broker

<!-- chunk: gaps -->
## Gaps

No argument-level or resource-level conditions within a tool. Whole-server access applies before tool discovery.

<!-- chunk: options -->
## Options

Connect an agent first to discover tools, then restrict policies per tool and test denial of an unlisted tool.
