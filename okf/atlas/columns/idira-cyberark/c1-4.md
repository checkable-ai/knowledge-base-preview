## Answer

Covered. Register, edit, suspend, resume, delete in Managed AI agents under RBAC and audit; credentials cannot be rotated in place.

Source statement: "improve lifecycle management with automated ownership workflows" (https://www.paloaltonetworks.com/idira/agentic.md)

Research detail: Agents are registered, edited, suspended, resumed and deleted in the Managed AI agents inventory, with all actions under RBAC and audited. Secure AI Agents builders can register MCP servers but these stay disabled until a Secure AI Agents admin enables them. Agent credentials cannot be rotated and deletion requires suspended or pending status.

<!-- chunk: products -->
## Products

Managed AI agents inventory, Secure AI Agents admin and builder roles

<!-- chunk: gaps -->
## Gaps

No credential rotation in place, and no documented API for policy-as-code provisioning beyond agent registration (POST /api/agents).

## Options

Test the builder to admin enablement path and the suspend then delete retirement path.
