## Answer

Not covered. Identity Broker enforces per user, agent and tool access policies on MCP servers, but no documented rate limits, input schema validation, dangerous-action filtering or internet egress control.

Research detail: The Identity Broker is the single endpoint for each registered MCP server, hides the real server URL, authenticates agents and enforces per user, agent and tool access policies. Disabling a server or suspending an agent cuts access immediately. No quota, rate limiting, schema validation, dangerous action filtering, injection screening or general egress control is documented.

## Gaps
