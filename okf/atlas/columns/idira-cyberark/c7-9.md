## Answer

Covered. Native scanners cover AWS and Azure; other sources need the external API.

Source statement: "Idira Secure AI Agents discovers agents across SaaS, cloud and developer environments" (https://www.paloaltonetworks.com/idira/agentic.md)

Research detail: The AI agents inventory discovers agents through scanners deployed in AWS Bedrock, AWS AgentCore and Azure (Copilot Studio) environments or through an external API, and raises an unmanaged AI agent risk for discovered agents not registered in Secure AI Agents. Up to 50,000 agents are supported.
