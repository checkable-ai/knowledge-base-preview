## Answer

Not covered. No sandboxing of files, processes or network for agent execution. The Agent Identity Broker kill switch cuts access only, and is described on a product page without mechanism or timing.

Research detail: The Idira product page states the Agent Identity Broker can act as a kill switch and deny access when an agent goes rogue, revokes access in real time on anomalous behaviour, and removes task permissions when a job is done. No sandbox, filesystem, process or network egress control for agent execution is offered, and the Agent Guard README covers secrets retrieval and MCP traceability only.
