## Answer

Not covered. No agent task training or validation and no behavioural baselining of outputs. Data Activity Monitoring covers data access oversight only.

Last checked 19 October 2026.

Research detail: Data Activity Monitoring tracks how AI agents, copilots and machine identities interact with sensitive data and detects unusual access patterns, suspicious downloads and privilege misuse. The agent governance page tracks agent changes such as new permissions or tools. This covers data access behaviour only, not task validation.
