## Answer

Not covered. No propagation of user identity for customer agents to other downstream systems.

Research detail: For BigID's own AgentIQ agents and MCP server, the AgentIQ page states that agents inherit the requesting user's permissions, enforced at the API and MCP layer rather than in a system prompt. This applies only to agents acting on the BigID platform. BigID does not propagate user identity for customer agents to other downstream services.
