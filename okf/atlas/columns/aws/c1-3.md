## Answer

Covered. Amazon Bedrock Agents only. The agent developer must turn on user confirmation for each action in the action group (console, CLI or SDK), and the customer's application must show CONFIRM or DENY to the end user and send the answer back in confirmationState. The customer's application and identity layer decide who counts as an authorised approver. Each new invocation of a confirmation-enabled action asks for confirmation again, but AWS does not document a limit or special handling for repeat attempts after a denial.

Source statement: "If the user response is DENY, the function or the API in the response is not implemented." (https://docs.aws.amazon.com/bedrock/latest/userguide/agents-userconfirmation.html)

Research detail: Source statement: Bedrock action groups support user confirmation and returning control to the application.
