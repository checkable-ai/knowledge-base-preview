## Answer

Covered. Two compute types: microVMs (per-session isolation) or Instances on EC2 in your account, where shared-instance isolation is weaker. VPC mode is optional.

Source statement: "In AgentCore Runtime, each user session runs in a dedicated microVM with isolated CPU, memory, and filesystem resources." (https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/agents-tools-runtime.html)

Research detail: Source statement: Runtime provides hosted sessions and compute choices.

Assessment: The documented isolation differs between microVMs and shared Instances.
