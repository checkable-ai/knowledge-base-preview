## Answer

Covered. Applies to tools served through AgentCore Gateway with a policy engine attached. Direct access that bypasses the gateway is not covered.

Source statement: "Policy in AgentCore intercepts all agent traffic through Amazon Bedrock AgentCore Gateways and evaluates each request against defined policies in the policy engine before allowing tool access." (https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/policy.html)

Research detail: Source statement: Gateway Policy evaluates tool requests outside agent code. Resource policies restrict invocation.

Assessment: Direct tool credentials or runtime endpoints can bypass an incompletely designed gateway boundary.
