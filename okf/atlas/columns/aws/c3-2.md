## Answer

Covered. Tools must be served through AgentCore Gateway with a policy engine attached. Guardrails can be added as a policy signal.

Source statement: "Policy in AgentCore intercepts all agent traffic through Amazon Bedrock AgentCore Gateways and evaluates each request against defined policies in the policy engine before allowing tool access." (https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/policy.html)

Research detail: Source statement: Gateway exposes APIs and MCP tools with authentication. Policy checks tool calls.

Assessment: Unknown tools and alternate egress paths need denial tests.
