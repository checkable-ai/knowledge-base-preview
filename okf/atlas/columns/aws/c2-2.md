## Answer

Covered, with conditions. Retention mode is set per AWS Region, at account level, or at project level; projects exist only on the bedrock-mantle endpoint. Zero data retention for models that require retention needs approval per account and per model through the AWS account team. For Claude models that require retention, zero data retention is limited to customers eligible for the Enterprise Frontier Safeguards program. There is no console UI for data retention at launch; use the API or SDK. With cross-Region inference, retained data is stored in the destination Regions.

Source statement: "Amazon Bedrock gives you explicit control over whether the prompts and outputs from your inference requests are retained." (https://docs.aws.amazon.com/bedrock/latest/userguide/data-retention.html)
