## Answer

Covered. Needs Image Builder image recipes using the Amazon-managed STIG hardening components on supported operating systems, with Amazon Inspector scanning enabled for the resulting images and hosts. The hardened images must then be deployed. Hardening applies to images built through Image Builder, not to already-running hosts.

Source statement: "These STIG components scan for misconfigurations and run a remediation script." (https://docs.aws.amazon.com/imagebuilder/latest/userguide/ib-stig.html)

Research detail: Source statement: Runtime documents isolation. Security guidance assigns customer responsibilities.

Assessment: Managed isolation and host monitoring have different coverage.
