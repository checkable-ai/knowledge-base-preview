## Answer

Covered, with conditions. Needs EC2 Image Builder image recipes using the Amazon managed STIG hardening components, on supported operating systems. Hardening applies to images built through Image Builder, not already-running hosts. Scanning containers and hosts needs Amazon Inspector, a separate AWS service.

Source statement: "Image Builder provides STIG hardening components to help you more efficiently build compliant images for baseline STIG standards." (https://docs.aws.amazon.com/imagebuilder/latest/userguide/ib-stig.html)

Last checked 17 November 2026.
