## Answer

Covered. You have to set up AWS Lake Formation (central access control with database, table, column, row and cell-level policies, plus S3 encryption) and AWS Glue data preparation (cleaning and normalising) for the data stores agents read. This works best for data-lake and structured sources registered in the Glue Data Catalog, which Bedrock Knowledge Bases can query through Redshift. Lake Formation permissions apply only in the Region where they were granted, and requests must pass both the Lake Formation and the IAM checks. No dedicated poisoning defence or approval workflow for knowledge sources is documented for agent data, but the control does not ask for either.

Source statement: "Use row and cell-level security to protect sensitive data like Personal Identifiable Information (PII)." (https://aws.amazon.com/documentation-overview/lake-formation/)

Research detail: Source statement: AWS provides retrieval, memory and encryption controls.
