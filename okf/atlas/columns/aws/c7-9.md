## Answer

Covered, with conditions. Needs AWS Organizations with all features enabled, trusted access for auto-detection and a registered delegated administrator. Auto-detection runs per Region, so a registry with it enabled is needed in each Region. It discovers only AgentCore Runtimes and Gateways in member accounts. Records need curator approval unless the registry uses auto-approval. Self-hosted discovery requires Amazon Inspector with Security Hub essentials. Self-hosted discovery supports Amazon EC2 and Amazon ECR images only.

Source statement: "Auto-detection discovers both resources that already exist when you enable the feature and resources that are created afterward." (https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/registry-organizations.html)
