## Answer

Covered. Auto-detection is enabled per Region and needs AWS Organizations with all features, trusted access and a registered delegated administrator. It discovers only AgentCore Runtimes and Gateways in member accounts, not external SaaS AI tools. Records still need curator approval.

Source statement: "Auto-detection discovers both resources that already exist when you enable the feature and resources that are created afterward." (https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/registry-organizations.html)

Research detail: Source statement: Registry covers submitted resources. Security Hub checks specified configured resources.
