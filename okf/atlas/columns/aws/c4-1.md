## Answer

Covered, with conditions. Workload identities are created automatically for agents deployed on AgentCore Runtime or Gateway. Identities for self-hosted agents must be created manually. Owner, runtime location and release binding rely on configuration and Runtime versioned endpoints.

Source statement: "Agent identities are implemented as workload identities with specialized attributes that enable agent-specific capabilities while helping to maintain compatibility with industry-standard workload identity patterns." (https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/identity.html)

Last checked 17 November 2026.

Research detail: Source statement: Identity implements agent workload identities.

Assessment: A workload identity needs an accountable owner and bounded permissions.
