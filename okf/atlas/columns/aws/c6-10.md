## Answer

Covered. Long-term record TTL defaults to no expiry, minimum 31 days. Expired record deletion can take a few days, so use explicit delete for immediate removal. Cross-Region inference may process prompts outside the storage Region, so Australian-only processing needs suitable model or inference profile selection.

Source statement: "You can optionally set a time-to-live (TTL) so that records are automatically deleted after a retention period that you choose." (https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/long-term-record-ttl.html)

Research detail: AgentCore stores customer data in DynamoDB and S3 encrypted with a service key or customer-managed KMS key, and Memory keeps short-term events and long-term extracted insights. For residency, Bedrock AU geographic cross-Region inference keeps Claude inference within Sydney and Melbourne for Australian source Regions. AgentCore Memory cross-region inference from Sydney can process in Tokyo, Seoul, Mumbai or Singapore, although data stays stored in the primary Region. The Top Secret cloud for Australia is a separate sovereign environment for the National Intelligence Community and Defence.

<!-- chunk: products -->
## Products

AgentCore Memory, KMS, Bedrock AU cross-Region inference profiles, AWS Top Secret cloud for Australia

<!-- chunk: gaps -->
## Gaps

AgentCore Memory inference from Sydney leaves Australia unless the model is overridden. CloudWatch and CloudTrail do not record the inference Region. Retention and deletion across every data copy still need tracing.

<!-- chunk: options -->
## Options

Use au. inference profiles, set a built-in with overrides strategy for Memory, and check every destination Region with GetInferenceProfile.
