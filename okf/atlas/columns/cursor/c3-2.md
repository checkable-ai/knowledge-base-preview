## Answer

Not covered. MCP allowlists, hooks and egress policies exist, but no native per-tool quotas, rate limits or input schema validation; injection screening relies on partners.

Research detail: MCP allowlists approve servers and set which tools auto-run, with per-server network modes. Hooks on beforeMCPExecution, beforeShellExecution and preToolUse can deny calls. Sandbox and Cloud Agent egress policies limit internet access, and partner hooks add injection and dangerous-call detection.
