## Answer

Not covered. Cursor's Enterprise audit logs record admin and security events only, not agent tool calls, data access or changes. Streaming and export to SIEM or S3 exists, but the docs describe no write-once storage, integrity validation or tamper detection for it. OpenTelemetry export (tool call metrics) and hooks are separate, customer-built pipelines with no documented tamper-evident storage.

Research detail: Enterprise audit logs record admin and security events with timestamp, actor, IP and surface, exportable as CSV or via the Admin API. Agent prompts, responses and automation runs are not logged, and Cursor points to hooks for development activity.
