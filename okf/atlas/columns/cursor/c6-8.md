## Answer

Not covered. Project rules are version-controlled, but dashboard settings, model access, MCP allowlists and hooks have no approval, versioning or rollback.

Research detail: Project rules are version-controlled files in the repository. Admins control client updates with the UpdateMode policy and defer extension updates with an install cooldown. Agent code changes go through draft pull requests.
