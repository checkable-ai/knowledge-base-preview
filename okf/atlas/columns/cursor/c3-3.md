## Answer

Not covered. .cursorignore, repository blocklist and read hooks filter some reads, but there is no DLP and terminal and MCP tools ignore .cursorignore.

Last checked 8 November 2026.

Research detail: .cursorignore blocks agent reads of listed paths, a team read policy limits reads outside the workspace, and the repository blocklist stops Cursor indexing or working with listed repositories. beforeReadFile hooks can deny reads.
