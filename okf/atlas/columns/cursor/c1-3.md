## Answer

Covered. Local agents; depends on run mode. Auto-run modes skip prompts, and Cloud Agents auto-run commands then require draft PR review.

Source statement: "Cursor will indicate when a command runs outside the sandbox and ask for your approval." (https://cursor.com/docs/agent/security/run-modes)

Research detail: Terminal and MCP calls require approval by default, and the user can expand the prompt to inspect arguments. Hooks can return ask for shell and MCP calls. Cloud Agents never ask but open draft pull requests that need human review before merge.

<!-- chunk: products -->
## Products

Tool approval prompts, Hooks ask decision, Draft pull requests

<!-- chunk: gaps -->
## Gaps

No documented binding of approval to a signed action, denial record or replay handling. Auto-review and Run Everything skip prompts, and Cloud Agents auto-run commands.

<!-- chunk: options -->
## Options

Restrict run modes by policy and log approvals through hooks to an external store.
