## Answer

Not covered. Service accounts can be created, rotated, suspended and archived, but there is no versioned agent configuration or approval step for changing an agent's permissions or configuration.

Research detail: Admins create, rotate, suspend and archive service accounts for automations and cloud agents. SCIM 2.0 provisions and deprovisions users and directory groups. Only admins can set an automation to run as a service account.
