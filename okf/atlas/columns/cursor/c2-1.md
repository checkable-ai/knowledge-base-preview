## Answer

Not covered. Cloud Agents API supports create, follow-up and cancel, but retry and recovery behaviour is not documented and cancellation is terminal.

Research detail: The Cloud Agents API creates agents, sends follow-up runs, cancels runs, and archives and deletes agents. Automations start agents from schedules, source control, Slack, webhooks and incident tools. Agents can run in parallel, and Projects use a coordinator agent that delegates to others.
