## Answer

Not covered. Marketplace plugins are manually reviewed, but there is no documented scanning for look-alike names, poisoned descriptions or compromised packages.

Research detail: Marketplace plugins are manually reviewed and delisted when found risky. A blocked MCP server inside a plugin cannot make calls. Extension install cooldown and signature checks reduce exposure to compromised updates.
