## Answer

Covered. Cloud Agents; Enterprise teams can cap conversation retention with policies.

Source statement: "Each is stored in a different place and follows its own retention rule." (https://cursor.com/docs/cloud-agent/security)

Research detail: Local agents keep checkpoints of file changes and a local transcript search index. Cloud Agent runs can be listed, retrieved, streamed, archived and deleted through the API, and shared agents give teammates read-only access unless follow-ups are enabled.
