## Answer

Covered. Cloud Agents, through the triggering user's connected Git account and the Cursor GitHub or GitLab App. Applies to repository access.

Source statement: "A Cloud Agent can only reach repositories the triggering user could already reach." (https://cursor.com/docs/cloud-agent/security)

Research detail: Cloud Agents act through the Cursor GitHub or GitLab App and the triggering user's connected Git account, and can only reach repositories that user can already access. OIDC tokens carry owner claims that downstream verifiers can check. Automations run as the creator or a service account.
