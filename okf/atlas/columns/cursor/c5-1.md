## Answer

Covered. Merge gating relies on the pull request flow and the repository's own branch protection settings.

Source statement: "Agents open pull requests for review. Nothing merges until a person reviews the change." (https://cursor.com/docs/cloud-agent/security)

Research detail: Cloud Agents push branches and open draft pull requests for human review. Agent Review runs quick or deep reviews of local changes, and Bugbot and the Security Reviewer review pull requests before merge.

<!-- chunk: products -->
## Products

Draft pull requests, Agent Review, Bugbot, Security Agents

## Gaps

Merge review depends on repository branch protection. Agent Review triggers are described inconsistently. An independent sample found 77.8% of merged Cursor PRs had a human reviewer.

<!-- chunk: options -->
## Options

Require reviewed pull requests through source control branch protection.
