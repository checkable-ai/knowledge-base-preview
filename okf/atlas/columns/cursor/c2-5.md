## Answer

Covered. Enterprise, Team, Project and User hook layers; hooks fail open unless failClosed is set; hooks do not run before a cloud agent has a writable environment.

Source statement: "Hooks let you observe, control, and extend the agent loop using custom scripts." (https://cursor.com/docs/hooks)

Research detail: The Cursor Agent harness runs tools for file search, reads, edits, shell, web, browser and MCP, with lifecycle hooks at session, tool, shell, MCP, file and subagent points. Enterprise, team, project and user hook layers all run, with deny taking precedence.
