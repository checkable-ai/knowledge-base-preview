## Answer

Covered. Enterprise MCP allowlist controls; per-server tool lists and network policies set by admins.

Source statement: "For each approved server, restrict which tools can run by listing them in that server's Tools field." (https://cursor.com/docs/enterprise/model-and-integration-management)

Research detail: Admins allowlist MCP servers by command or URL with per-server tool allowlists and network controls. A repository blocklist and Protected Git Scopes restrict which repositories Cursor works with, and Cloud Agent egress can be locked org-wide to an allowlist.

<!-- chunk: products -->
## Products

MCP allowlist, Repository blocklist, Protected Git Scopes, Cloud Agent network policy

<!-- chunk: gaps -->
## Gaps

Tool allowlists set which tools auto-run rather than fine-grained action scopes. Allowlisting does not push servers to users. The egress lock does not cover self-hosted machines.

<!-- chunk: options -->
## Options

Pair MCP allowlists with beforeMCPExecution hooks and scope downstream API keys.
