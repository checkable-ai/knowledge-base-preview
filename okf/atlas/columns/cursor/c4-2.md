<!-- chunk: answer -->
## Answer

Covered. Cloud Agents. OIDC tokens last 5 minutes. Service account keys can be rotated, suspended and revoked. Local agents use the user's own environment.

Source statement: "Mark sensitive values as Runtime Secrets to keep them out of the transcript, tool output, and commits." (https://cursor.com/docs/cloud-agent/security)

Research detail: Cloud Agent secrets are KMS encrypted and injected as environment variables, and Runtime Secrets are scrubbed from transcripts, tool output and commits so they never reach the model. OIDC tokens last 5 minutes for federation into AWS, GCP or Azure. Service account API keys can be rotated, suspended or revoked.

<!-- chunk: products -->
## Products

Runtime Secrets, Cloud Agent OIDC federation, Service account key rotation

<!-- chunk: gaps -->
## Gaps

Local agents run with the user's own permissions and environment, with no boundary between agent and account. MCP credentials sit in environment variables the agent can reach.

<!-- chunk: options -->
## Options

Use Runtime Secrets and OIDC federation for cloud runs. Keep secrets out of local workspaces and block reads with hooks and .cursorignore.
