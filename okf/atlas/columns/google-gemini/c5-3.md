## Answer

Not covered. Usage and billing tools report model use only. Nothing links agent cost to delivered value.

Research detail: AI Studio shows usage, and Gemini API costs appear in Cloud Billing reports by SKU, with tier and project spend caps. Gemini Enterprise has a Value tab, in preview, that estimates hours and money saved from successful searches and answers. Gemini CLI exports token usage metrics.

<!-- chunk: products -->
## Products

AI Studio usage dashboard, Cloud Billing reports, Gemini Enterprise Value tab, Gemini CLI metrics

<!-- chunk: gaps -->
## Gaps

No per-request cost reporting. The Value tab uses a fixed per-query time estimate from Google internal research.
