## Answer

Covered, with conditions. Applies to Gemini CLI run on the user's own machine (self-hosted). Not available for managed agents or Gemini Enterprise connector actions.

Source statement: "The user is prompted to approve or deny the tool call." (https://geminicli.com/docs/reference/policy-engine/)

Last checked 18 November 2026.

Research detail: In Gemini CLI, write tools and agent delegation default to ask_user, so the user approves or denies the specific tool call, and ask_user becomes deny in non-interactive mode. Jules shows a plan for approval before it changes code. Users can grant standing approval for future sessions, which weakens binding to the exact action.

## Products

Gemini CLI policy engine, Jules plan approval

<!-- chunk: gaps -->
## Gaps

Replay handling is not documented. Gemini Enterprise connector actions and managed agents have no documented per-action approval step.

## Options
