## Answer

Covered. Gemini CLI policy engine ask_user rules. Not available for managed agents or Gemini Enterprise connector actions.

Source statement: "In non-interactive mode, this is treated as `deny`." (https://geminicli.com/docs/reference/policy-engine/)

Research detail: In Gemini CLI, write tools and agent delegation default to ask_user, so the user approves or denies the specific tool call, and ask_user becomes deny in non-interactive mode. Jules shows a plan for approval before it changes code. Users can grant standing approval for future sessions, which weakens binding to the exact action.
