## Answer

Covered. Gemini Enterprise only. Covers calls from Gemini Enterprise to registered A2A agents. The Google-signed OIDC token applies to agents on Cloud Run default run.app URLs. The OAuth 2.0 user token is optional and sent after user consent. Registration needs the Gemini Enterprise Admin role. Agent card securitySchemes and apiKey are not supported.

Source statement: "Gemini Enterprise automatically generates a Google-signed OIDC ID token for the Discovery Engine service agent" (https://docs.cloud.google.com/gemini/enterprise/docs/register-and-manage-an-a2a-agent)

Research detail: Gemini Enterprise acts as an A2A client for admin-registered agents, authenticating with a Google-signed ID token or a user OAuth token. Registration needs the Gemini Enterprise Admin role. The agent card securitySchemes are ignored and API key or static header authentication is not supported.
