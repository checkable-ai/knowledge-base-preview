<!-- chunk: answer -->
## Answer

Covered. Managed agents are in Public Preview. Outbound access is unrestricted by default, so the allowlist must be configured.

Source statement: "Use a `network` allowlist to restrict outbound traffic to specific domains or wildcard patterns." (https://aistudio.google.com/docs/agents)

Research detail: Gemini Enterprise limits connected-system access through source ACLs, resource-level IAM on apps and data stores, an org policy that restricts allowed data sources, and per-connector action selection. Gemini CLI policy rules target MCP servers and individual MCP tools, and mcp.allowed lists approved servers. Gemini API managed agents can restrict outbound traffic with a domain allowlist.

<!-- chunk: products -->
## Products

Gemini Enterprise IAM and connectors, allowedDataSources org policy, Gemini CLI policy engine, managed agents network allowlist

<!-- chunk: gaps -->
## Gaps

Managed agent egress is unrestricted by default. Write actions in Workflow Builder are enabled per connector, with no documented per-user action scoping.

<!-- chunk: options -->
## Options

Set the allowedDataSources constraint, apply resource-level IAM, and set network allowlists on every managed agent.
