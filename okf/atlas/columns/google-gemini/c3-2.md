<!-- chunk: answer -->
## Answer

Covered. Gemini CLI policy engine, with admin (Tier 4) policies overriding user settings. Managed agents add a network egress allowlist (Public Preview, open by default).

Source statement: "The tool call is blocked and is not executed." (https://geminicli.com/docs/reference/policy-engine/)

Research detail: Gemini CLI enforces allowed tools, per-MCP-server and per-tool rules and argument patterns, with admin-tier policies and an approved MCP server list. Managed agents restrict egress with a domain allowlist, and Gemini Enterprise limits connector egress with firewall rules to named FQDNs.

<!-- chunk: products -->
## Products

Gemini CLI policy engine, managed agents network allowlist, Gemini Enterprise connector egress rules

<!-- chunk: gaps -->
## Gaps

No tool-call injection screening or per-user quotas on tools. CLI blocklists can be bypassed, per the enterprise page.

<!-- chunk: options -->
## Options

Route CLI and MCP traffic through a corporate proxy and add an external MCP gateway for screening.
