## Answer

Covered, with conditions. Gemini CLI only, which is self-hosted. OpenTelemetry telemetry must be enabled and exported. The pre-configured dashboard is in Google Cloud Monitoring, which needs the Cloud Monitoring API enabled.

Source statement: "Gemini CLI provides a pre-configured Google Cloud Monitoring dashboard to visualize your telemetry." (https://geminicli.com/docs/cli/telemetry/)

Research detail: Gemini CLI emits OpenTelemetry metrics for API and tool latency, sessions and resource use, with a prebuilt Cloud Monitoring dashboard. AI Studio shows usage against quota.
