## Answer

Covered. Gemini CLI only. OpenTelemetry telemetry must be enabled and exported, for example to Google Cloud Monitoring.

Source statement: "Find this dashboard under Google Cloud Monitoring Dashboard Templates as "Gemini CLI Monitoring"." (https://geminicli.com/docs/cli/telemetry/)

Research detail: Gemini CLI emits OpenTelemetry metrics for API and tool latency, sessions and resource use, with a prebuilt Cloud Monitoring dashboard. AI Studio shows usage against quota.
