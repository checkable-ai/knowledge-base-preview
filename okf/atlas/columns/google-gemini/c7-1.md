## Answer

Not covered. Cloud Audit Logs and Gemini Enterprise usage logs are not documented as a per-action agent record tied to user and session. No write-once or integrity-validated storage is documented for that record. Managed agents, Gemini CLI and Jules have no equivalent.

Research detail: Gemini Enterprise writes Cloud Audit Logs for agent, engine and data store changes, and Admin Activity logs cannot be disabled. Usage audit logs record queries, assistant responses, session IDs and agent IDs when prompt logging is on. AI Studio stores full API prompts and responses for up to 55 days on paid projects.

<!-- chunk: products -->
## Products

Gemini Enterprise Cloud Audit Logs and usage audit logs, AI Studio logs

<!-- chunk: gaps -->
## Gaps

Tamper-proofing depends on Cloud Logging bucket settings. Reasoning is not logged, and the model field misses specialised agent models. Managed agents are excluded from AI Studio logs.

<!-- chunk: options -->
## Options

Route logs with sinks to a locked bucket in a separate project.
