## Answer

Not covered. Admin registration of A2A agents exists, but nothing restricts which agent pairs may talk or enforces message formats.

Research detail: Gemini Enterprise registers A2A agents by admin action, but the registration page states that traffic to these agents does not pass through Agent Gateway, so its policies do not apply. No allowed-pair or schema enforcement between agents is documented in the first-party Gemini products.
