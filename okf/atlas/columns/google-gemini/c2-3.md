## Answer

Covered. Managed agents are in Public Preview. Outbound network access is open by default unless an allowlist is set. Gemini CLI sandboxing is opt-in.

Source statement: "Every agent runs in a sandboxed environment that is isolated at the OS level." (https://aistudio.google.com/docs/agents)

Research detail: Gemini API managed agents run in an OS-isolated Ubuntu sandbox with an optional network allowlist. API code execution runs Python only with a 30 second limit and no package installs. Gemini CLI offers opt-in sandboxing with Seatbelt, Docker, Podman, gVisor and others, and Jules works in a VM.

<!-- chunk: products -->
## Products

Managed agents sandbox, code execution tool, Gemini CLI sandbox, Jules VM

<!-- chunk: gaps -->
## Gaps

CLI sandboxing is off by default and the default Seatbelt profile allows network. Code execution network access is not stated.

<!-- chunk: options -->
## Options

Enforce tools.sandbox through system settings and use proxied profiles. Set managed agent network allowlists.
