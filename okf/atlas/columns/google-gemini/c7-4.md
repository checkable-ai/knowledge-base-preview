## Answer

Not covered. No product documentation of hardening and scanning of the containers, agent software and hosts that run models and tools. Managed agent and CLI sandboxing are isolation only. Google's general infrastructure security page is not a Gemini product feature a customer sets up.

Last checked 18 November 2026.

Research detail: Managed agents run in OS-isolated sandboxes, code execution runs in a restricted Python environment, and Gemini CLI can run tools in containers built from a hardened image. Gemini Enterprise inherits Google Cloud certifications.

## Products

Managed agents sandbox, code execution, Gemini CLI sandbox

## Gaps

No customer-visible assurance of host or container hardening for the hosted sandboxes.

## Options

Rely on Google Cloud compliance reports and test sandbox escape and egress behaviour.
