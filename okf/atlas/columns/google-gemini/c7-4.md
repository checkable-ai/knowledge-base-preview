## Answer

Not covered. No customer-visible documentation of hardening or scanning of the containers, agent software and hosts that run models and tools. Sandbox isolation is not hardening and scanning.

Research detail: Managed agents run in OS-isolated sandboxes, code execution runs in a restricted Python environment, and Gemini CLI can run tools in containers built from a hardened image. Gemini Enterprise inherits Google Cloud certifications.
