## Answer

Covered. Managed agents on the Gemini API are in Public Preview.

Source statement: "Managed agents on the Gemini API give you a configurable agent harness." (https://aistudio.google.com/docs/agents)

Research detail: Gemini API managed agents are described as a configurable agent harness that reasons, runs code, manages files and browses inside a sandbox. Gemini CLI is a local harness that runs built-in and MCP tools under its policy engine.
