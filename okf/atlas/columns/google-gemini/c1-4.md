## Answer

Covered. Gemini Enterprise, performed by admins.

Source statement: "Gemini Enterprise admins can register custom agents built by your organization." (https://docs.cloud.google.com/gemini/enterprise/docs/agents-overview)

Research detail: Gemini Enterprise admins create, update and delete agents through the console or REST API, set states (private, enabled, suspended, disabled) and control which users can build and share agents with feature toggles. Agent create, update and delete calls are recorded as Admin Activity audit logs.
