## Answer

Covered. Gemini Enterprise. Memory is on by default and admins can turn it off.

Source statement: "By default, Memory is turned on to provide a helpful experience from the start." (https://docs.cloud.google.com/gemini/enterprise/docs/configure-personalization)

Research detail: Gemini Enterprise builds a per-user Memory from interactions and connected apps, which users can view and delete and admins can turn off for everyone. Gemini CLI writes durable memory to GEMINI.md files at project and global scope that load in future sessions.
