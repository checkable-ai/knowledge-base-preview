## Answer

Covered, with conditions. Gemini Enterprise. Memory is on by default and admins can turn it off.

Source statement: "If you are an administrator, you can turn off memory and personalization profiles for all users within your organization." (https://docs.cloud.google.com/gemini/enterprise/docs/configure-personalization)

Last checked 18 November 2026.

Research detail: Gemini Enterprise builds a per-user Memory from interactions and connected apps, which users can view and delete and admins can turn off for everyone. Gemini CLI writes durable memory to GEMINI.md files at project and global scope that load in future sessions.
