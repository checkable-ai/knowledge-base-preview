## Answer

Covered. Managed agents are in Public Preview. Background runs require store=true.

Source statement: "You can cancel a running background interaction using the `cancel` method." (https://aistudio.google.com/docs/antigravity-agent)

Research detail: Gemini Enterprise Workflow Builder builds single and multi-step agents with connector action steps. The Interactions API runs long tasks in the background and chains turns. Code execution retries failed code up to five times.

<!-- chunk: products -->
## Products

Gemini Enterprise Workflow Builder, Interactions API background execution
