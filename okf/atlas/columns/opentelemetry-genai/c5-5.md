## Answer

Not covered. Observed tools in traces only; no view of reachable systems or action scopes.

Last checked 12 November 2026.

Research detail: gen_ai.tool.definitions records the tools offered to a model, execute tool spans record tool name and type, skill spans record gen_ai.skill.source.uri, and MCP spans record server address, method and resource URI. A conforming tool can draw an agent's observed reach from these.
