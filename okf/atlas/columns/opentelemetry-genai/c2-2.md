## Answer

Not covered. Inference span attributes (gen_ai.request.model, gen_ai.response.model, server.address, gen_ai.request.max_tokens) record the model and endpoint per call, but the spec does not represent prompt data handling terms (retention, training use, residency) and does not set or enforce limits. It only flags sensitive content attributes and suggests optional filtering.

Research detail: Inference spans carry gen_ai.request.model, gen_ai.response.model, gen_ai.provider.name, server.address and request limits such as gen_ai.request.max_tokens, so a conforming tool can record the exact model version and endpoint for each call. The spec does not execute models or enforce limits.
