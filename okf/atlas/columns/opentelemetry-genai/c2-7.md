## Answer

Not covered. No sandbox, egress control or stop mechanism; command execution span records execution only.

Research detail: The conventions describe telemetry only and define no sandbox, process policy, egress control or stop mechanism. The Command execution span (Development status) records commands an agent tool runs, with process.executable.name, process.exit.code and error.type, so a containment control elsewhere can be observed but not enforced.

## Products

None. The Command execution span gen_ai.execute_tool.command.internal records execution only.

## Gaps

No attribute records whether a command ran inside a sandbox, which sandbox profile applied, or that an agent was stopped or had access revoked.

<!-- chunk: options -->
## Options

Use a runtime or harness column for containment and emit these spans from it so stops and blocked commands are visible in traces.
