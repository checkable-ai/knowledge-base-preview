## Answer

Not covered. Memory span describes operations but provides no long-term memory, retention or access controls.

Last checked 12 November 2026.

Research detail: The memory span covers create, search, update, upsert and delete of memory records and stores, with gen_ai.memory.store.id and opt-in gen_ai.memory.records. It describes memory operations but does not provide or govern long-term memory.
