## Answer

Covered. Servers declare security schemes in the Agent Card. Authorisation logic is implementation-specific.

Source statement: "Servers MUST reject requests with invalid or missing authentication credentials." (https://a2a-protocol.org/latest/specification/)

Research detail: Production deployments MUST use TLS. Servers declare security schemes in the Agent Card (API key, HTTP auth, OAuth 2.0, OpenID Connect and mutual TLS), MUST authenticate every request and MUST run authorisation checks on every operation, scoped to the caller. The authorisation model itself is agent defined.
