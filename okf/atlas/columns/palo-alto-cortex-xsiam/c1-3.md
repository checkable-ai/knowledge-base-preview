## Answer

Covered. Sensitive flag on actions; MCP actions sensitive by default. Agentic Response is preview.

Source statement: "Actions marked as sensitive require explicit user approval before execution and are never run automatically." (https://cortex-docs.paloaltonetworks.com/cortex-xsiam/learn-about-cortex-xsiam/agentic-ai-in-cortex-xsiam/agentic-assistant-security)

Research detail: Actions marked sensitive require explicit user approval and never run automatically. System actions that affect system reality are marked sensitive, MCP tool actions are sensitive by default, and administrators choose for custom actions. In Agentic Response the agent pauses and creates a pending task that an analyst approves or denies.
