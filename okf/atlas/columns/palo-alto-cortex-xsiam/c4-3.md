## Answer

Not covered. Agent actions are limited to the invoking user's permissions inside the Cortex tenant, but the user's identity is not documented as passed to downstream MCP servers or integrations, which use instance credentials. Agentic Assistant RBAC is the nearby feature and falls short.

Research detail: Agents run within the invoking user's existing tenant permissions, so an agent cannot isolate an endpoint if the user cannot. Slack actions require the Slack email to match the Cortex user email so RBAC applies. Calls to external systems run through integration instance credentials, not the user's own identity.
