## Answer

Not covered. No per-agent identity bound to owner, runtime and release is documented. Audit records show which agent ran an action, but that is not an issued identity.

Research detail: Cortex agents are personas defined in the Agentic Assistant Hub, either system agents or custom agents. The audit dataset records which agent ran an action. No workload identity, credential or owner binding is issued to an agent, and Cortex does not issue identities to customer agents.
