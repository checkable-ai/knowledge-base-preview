## Answer

Covered. Applies to Cortex's own agents and MCP integrations; also bound to user RBAC and SBAC.

Source statement: "You can restrict access for MCP integration instance commands to one or more roles." (https://cortex-docs.paloaltonetworks.com/cortex-xsiam/configure-cortex-xsiam/configure-the-cortex-agentic-assistant-1/agents-hub/expand-agent-capabilities-with-mcp-integrations)

Research detail: Agents can only use actions assigned to them, and execution is limited to the invoking user's RBAC and SBAC permissions. Integration permissions can restrict MCP and other integration commands to named roles. Separate MCP integration instances can expose read only or read and write tool sets.

<!-- chunk: products -->
## Products

Agentic Assistant Hub, RBAC, SBAC, integration permissions, MCP integrations

<!-- chunk: gaps -->
## Gaps

Scopes apply to Cortex's own SOC agents, not to customer agents elsewhere.

<!-- chunk: options -->
## Options

Create custom agents with minimal actions and restrict integration commands by role.
