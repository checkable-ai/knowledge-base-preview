## Answer

Not covered. No documented short-lived scoped credentials, rotation or revocation for agents, and no statement that secrets stay out of model context. API keys with expiry and integration instances fall short.

Research detail: MCP and other integrations are configured as integration instances that hold the URL and authentication details, including OAuth, so agents call actions rather than handling credentials. The Cortex MCP server uses API keys with a chosen role, optional SBAC scope and an optional expiry date with expiry notifications. The July 2026 blog says Agentic Endpoint Security guardrails block agents from exposing credentials such as API keys.

## Products

Integration instances, Cortex API keys, Agentic Endpoint Security
