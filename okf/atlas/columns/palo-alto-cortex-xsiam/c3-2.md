## Answer

Not covered. The vendor does not document a control point for tool calls and internet access that enforces input formats, call or rate limits, or internet egress. The nearest feature is Cortex AgentiX MCP integrations, which let you enable or disable MCP server actions, restrict them to roles and mark them as sensitive so they need manual approval. That covers allowed tools and approval of dangerous actions. It does not validate inputs, limit calls or control internet access. Agentic Endpoint Security runtime guardrails on endpoints also fall short of a tool-call gateway.

Last checked 15 November 2026. This platform is checked on demand, so this answer has not been rechecked since.

Research detail: MCP tools are registered as actions that can be enabled, disabled and marked sensitive, and integration permissions restrict MCP commands to roles. For endpoint agents, the July 2026 blog says AES blocks destructive commands and supports custom runtime policies and supply chain protections.
