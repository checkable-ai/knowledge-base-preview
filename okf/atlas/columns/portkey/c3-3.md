## Answer

Partly covered. No retrieval authorisation or vector store access control per agent or user is documented. Guardrails check the request and response content only, and PII checks are not available for MCP tool calls.

Source statement: "The redacted request is then forwarded to the LLM, ensuring sensitive data never reaches the model." (https://portkey.ai/docs/product/guardrails/pii-redaction.md)

Last checked 17 November 2026.

Research detail: Guardrails run on LLM requests and responses and can detect and redact PII before it reaches the model, with partner DLP and content tools such as AWS Bedrock Guardrails and Palo Alto Prisma AIRS. Embedding requests are covered by input guardrails. Retrieval rights per agent or user are not enforced.
