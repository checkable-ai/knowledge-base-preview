## Answer

Research detail: There is no sandbox for agent code. Access can be cut off quickly at the gateway: keys can be rotated or revoked, MCP access revoked, hard budget and rate limits block requests when hit, and circuit breakers stop routing to unhealthy targets.

<!-- chunk: products -->
## Products

API key revocation and rotation, budget and rate limits, circuit breaker, MCP access control

<!-- chunk: gaps -->
## Gaps

No filesystem, process or network sandbox is documented, and no single stop control for a running agent. Revocation applies to traffic through the gateway only.

## Options
