## Answer

Not covered. No ownership, authorship, versioning, publication or review cycle for AI policies. Configs, guardrails and org-level guardrails are technical enforcement rules.

Last checked 17 November 2026.

Research detail: Policy is expressed as gateway configs, guardrails, org-level guardrails and usage and rate limit policies, each created through the dashboard or Admin API. Updating a config changes behaviour for every key that uses it without code changes.

<!-- chunk: products -->
## Products

Configs, guardrails, org-level guardrails, policies API

<!-- chunk: gaps -->
## Gaps

These are technical enforcement rules. Ownership, versioning of narrative AI policies, publication and review cycles are not documented. Usage and rate limit policies are Enterprise self-hosted only.

<!-- chunk: options -->
## Options

Keep the written policy in a governance system and record the config and guardrail IDs that enforce it.
