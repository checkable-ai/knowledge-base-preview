## Answer

Covered, with conditions. Tool-level claim-based authorisation and per-user agent skill access are listed as coming later.

Source statement: "Control which workspaces and users can access each server." (https://portkey.ai/docs/product/mcp-gateway.md)

Last checked 17 November 2026.

Research detail: Admins choose which workspaces can reach each MCP server and, at workspace level, which users. Individual tools, resources and prompts on a server can be switched off for the whole organisation or a workspace, and disabled capabilities return errors. Server-level rules can also require JWT claims such as group membership.

## Gaps

Tool-level claim-based authorisation and webhook authorisation are marked as coming in a future release. Agent skill access per user is also coming soon.

## Options
