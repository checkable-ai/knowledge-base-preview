## Answer

Covered, with conditions. Metrics-only logging is a Portkey Enterprise plan feature.

Source statement: "Fine-tune which models are available through each Integration" (https://portkey.ai/docs/product/model-catalog.md)

Last checked 17 November 2026.

Research detail: The Model Catalog fixes which providers and models a workspace can call and the endpoint behind each, including privately hosted models through custom hosts. Budgets, rate limits and request timeouts set operating limits, and a metrics-only logging mode stops request and response bodies being stored.
