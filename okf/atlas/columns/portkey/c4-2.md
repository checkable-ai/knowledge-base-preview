## Answer

Covered, with conditions. API key rotation is available on all accounts and plans (Free, Growth, and Enterprise) on Portkey Cloud. Self-hosted Airgapped needs Backend v1.14.0 or later and Hybrid needs Gateway Enterprise v2.5.0 or later. Secret References are available on Enterprise plans only and need Gateway 2.2.4 or later.

Source statement: "After the transition period ends, the old secret is automatically revoked." (https://portkey.ai/docs/product/enterprise-offering/org-management/api-key-rotation.md)

Research detail: The MCP Gateway injects upstream credentials so agents never hold them, and client credentials tokens are cached and refreshed by the gateway. Provider keys can be fetched at runtime from AWS Secrets Manager, Azure Key Vault or HashiCorp Vault, or replaced by short-lived tokens through Workload Identity Federation for OpenAI and Anthropic. Portkey API keys rotate with an overlap window and the old secret is revoked automatically.

<!-- chunk: products -->
## Products

MCP Gateway credential injection, Secret References, Workload Identity Federation, API key rotation

<!-- chunk: gaps -->
## Gaps

Secret References are Enterprise only. Workload Identity Federation covers OpenAI and Anthropic only. Nothing in these pages addresses keeping secrets out of model context beyond the gateway holding them.

<!-- chunk: options -->
## Options

Use Secret References or federation for provider keys and give each agent its own rotated Portkey key.
