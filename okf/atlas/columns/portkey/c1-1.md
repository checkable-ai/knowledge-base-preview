## Answer

Out of scope. Portkey is a network gateway and control plane that does not run on the agent's host, so it cannot govern local file reads, shell commands or local tools. Its coding agent guidance covers credentials, spend and logging, not local permissions.

Research detail: Portkey is a network gateway and does not govern what an agent may do on its local host. Its coding agent guidance covers credentials, spend and logging for tools such as Claude Code, not local file or command permissions.
