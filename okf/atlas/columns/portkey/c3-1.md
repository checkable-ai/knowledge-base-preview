## Answer

Covered, with conditions. Usage and rate limit policies are available on the Enterprise Self Hosting plan only and need Gateway 1.17.0 or higher. Saved-only mode is available on SaaS and self-hosted deployments, and Hybrid enterprise customers need Gateway 2.11.0 or later. Organisation owners can exempt individual workspaces from org-level guardrails through the Admin API.

Source statement: "These guardrails are enforced on all API requests made within the organization" (https://portkey.ai/docs/product/administration/enforce-orgnization-level-guardrails.md)

Last checked 17 November 2026.

Research detail: Every model call passes through the gateway, where API keys, workspaces and metadata decide routing, budgets and rate limits. Org-level input and output guardrails apply to all requests and saved-only mode blocks inline provider or config selection. Guardrails include prompt injection scanning and many partner checks, and start hooks can reject requests that lack required metadata or headers. Default configs can be locked to a key so callers cannot override routing.

<!-- chunk: products -->
## Products

AI Gateway, Model Catalog, usage and rate limit policies, org-level guardrails, saved-only mode, start hooks, default configs on API keys

<!-- chunk: gaps -->
## Gaps

Usage and rate limit policies are Enterprise self-hosted only. Guardrails see only the last message in the request body. Prompt injection scanning uses an LLM check or a partner.

<!-- chunk: options -->
## Options

Attach a default config with override disabled to every API key and enforce org-level guardrails.
