## Answer

With our team for a decision. The agent checks did not agree on this finding.

Last checked 17 November 2026.

Research detail: Admins create agents and MCP servers in registries and provision them to workspaces, and SCIM automates user provisioning and deprovisioning from Entra or Okta. API keys can be created, rotated and revoked, and a user cannot edit a key with more permission than their own role.

<!-- chunk: products -->
## Products

Agent Registry, MCP Registry provisioning, SCIM, API key management

<!-- chunk: gaps -->
## Gaps

Provisioning is per workspace and key, not per agent identity with a recorded lifecycle. SCIM is Enterprise only. No documented retirement workflow for agents.

<!-- chunk: options -->
## Options

Drive registry and key changes through the Admin API from a change-controlled pipeline.
