## Answer

Covered. MCP rate limits need Gateway v2.18.0 or later and Backend v1.24.0 or later. Org-wide MCP policies are not supported in this release. LLM-specific checks such as PII detection and content moderation are not available for MCP tool calls.

Source statement: "Run the guardrail on tool call arguments (before the tool executes)." (https://portkey.ai/docs/product/mcp-gateway/guardrails.md)

Last checked 17 November 2026.

Research detail: The MCP Gateway checks that each caller may use a server and tool, injects the server's credentials, rate limits calls by key, server or tool, and runs input and output guardrails on tool calls. Regex, contains, JSON schema and webhook checks can deny dangerous arguments, and tools can be disabled outright.

## Products

MCP Gateway, MCP guardrails, MCP rate limits, tool provisioning

<!-- chunk: gaps -->
## Gaps

Prompt injection and PII checks are not available for MCP tool calls. Internet egress control is not documented. Tool-level claim authorisation and webhook authorisation are listed as coming.

<!-- chunk: options -->
## Options

Deny risky patterns with regex or webhook guardrails and apply per-tool rate limits.
