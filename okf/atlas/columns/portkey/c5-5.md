## Answer

Partly covered. No per-agent view of which downstream systems an agent can reach. Access is shown per MCP server by workspace and user, with tool toggles, and does not cover non-MCP systems or network reach.

Source statement: "lists all tools, resources, and prompts exposed by an MCP server." (https://portkey.ai/docs/product/mcp-gateway/mcp-registry.md)

Last checked 17 November 2026.

Research detail: The MCP Registry shows each server with connection status, health metrics and which teams can reach it. MCP analytics break requests down by server, team and user.
