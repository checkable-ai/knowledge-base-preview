## Answer

Covered. Requires MCP server portals with Access. Gateway routing must be enabled for the portal for HTTP and DLP policies to apply. Is MCP selector is beta. DLP AI prompt profiles do not apply to portal traffic.

Source statement: "Turned-off tools will not appear in the portal's tool list. Users will not be able to call them." (https://developers.cloudflare.com/cloudflare-one/access-controls/ai-controls/mcp-portals/)

Research detail: MCP server portals give one endpoint for many MCP servers, with Access authentication, per-portal tool allowlists and centrally held upstream auth. Routing portal traffic through Cloudflare Gateway adds HTTP logs and DLP policies that block tool calls carrying sensitive data in either direction. Gateway HTTP policies can block MCP traffic that does not arrive through a portal, which controls egress to unsanctioned servers.

<!-- chunk: products -->
## Products

MCP server portals, Cloudflare Gateway HTTP policies, Is MCP selector (beta)

<!-- chunk: gaps -->
## Gaps

No per-tool quota or rate limit, schema validation or injection screening of tool results is documented. DLP AI prompt profiles do not apply to portal traffic. Gateway DLP scans only the first 1,024 bytes of POST bodies.

<!-- chunk: options -->
## Options

Pair with an injection scanner on tool results. Test DLP block behaviour on large tool payloads.
