## Answer

Not covered. No agent identity object tied to an owner, runtime or release. Access service tokens give a machine credential, but service-token requests carry no cf.user_id.

Research detail: Access service tokens give an autonomous agent or bot a named machine credential to connect to an MCP server portal, and Service Auth policies decide which portals and servers it reaches. AI Gateway requests authenticated by Access carry the verified user ID as cf.user_id, but service token requests do not. There is no agent identity object linked to an owner, runtime or release.

## Products

## Gaps

No agent registry, owner binding or release linkage. Service token requests lose per-user attribution in AI Gateway.

## Options
