## Answer

Covered. MCP server portals (Access); AI Gateway BYOK with Secrets Store. Bearer tokens are static values, and rotation of manual OAuth client secrets is done by saving a new value.

Source statement: "Authentication credentials and environment variables remain outside the model context." (https://developers.cloudflare.com/cloudflare-one/access-controls/ai-controls/mcp-portals/)

Research detail: MCP server portals hold upstream credentials (DCR or manual OAuth client secrets, per-user OAuth grants, bearer tokens or custom headers) and inject them on calls to upstream servers, so the client and model never see them. Manual OAuth client secrets are encrypted, write-only and rotated by saving a new value, with an optional revocation endpoint. AI Gateway BYOK stores provider API keys in Secrets Store and strips Cloudflare credentials before forwarding upstream.

<!-- chunk: products -->
## Products

MCP server portals, AI Gateway BYOK with Secrets Store

<!-- chunk: gaps -->
## Gaps

Expiry and revocation of per-user upstream OAuth grants held by the portal are not described in detail. Bearer tokens are static values.

<!-- chunk: options -->
## Options

Prefer OAuth upstream servers over static bearer tokens. Test rotation and revocation of a stored upstream grant.
