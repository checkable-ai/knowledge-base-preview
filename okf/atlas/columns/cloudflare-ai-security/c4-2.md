## Answer

Covered, with conditions. Requires Cloudflare One (Access) with MCP server portals. Secrets stay outside the model context only when portal Code Mode is used. The admin sets the service token lifetime when creating the token; the page's API examples use one year (8760h), so short lifetimes have to be configured on purpose. Rotation is manual: rotate the secret, with a grace period, or save a new upstream secret. To revoke, delete or turn off the token. Agents are scoped through portal and per-server Service Auth policies, but service token sessions use the shared admin credential for upstream MCP calls, not per-user OAuth.

Source statement: "Service tokens expire according to the token duration you selected when you created the token." (https://developers.cloudflare.com/cloudflare-one/access-controls/service-credentials/service-tokens/)

Last checked 12 November 2026.

Research detail: MCP server portals hold upstream credentials (DCR or manual OAuth client secrets, per-user OAuth grants, bearer tokens or custom headers) and inject them on calls to upstream servers, so the client and model never see them. Manual OAuth client secrets are encrypted, write-only and rotated by saving a new value, with an optional revocation endpoint. AI Gateway BYOK stores provider API keys in Secrets Store and strips Cloudflare credentials before forwarding upstream.

<!-- chunk: products -->
## Products

MCP server portals, AI Gateway BYOK with Secrets Store

<!-- chunk: gaps -->
## Gaps

Expiry and revocation of per-user upstream OAuth grants held by the portal are not described in detail. Bearer tokens are static values.

<!-- chunk: options -->
## Options

Prefer OAuth upstream servers over static bearer tokens. Test rotation and revocation of a stored upstream grant.
