## Answer

Not covered. No scanning of registry tools for look-alike names, poisoned descriptions or compromised packages. The Is MCP selector only allows, blocks or isolates MCP traffic.

Research detail: Gateway detects MCP traffic and can block MCP use that does not go through an approved portal, so only admin-added third-party servers are reachable. Admins can rename tools and edit descriptions at the portal. No scanning for tool metadata poisoning, squatting or package compromise is documented.
