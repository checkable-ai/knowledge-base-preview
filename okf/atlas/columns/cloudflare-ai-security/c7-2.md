## Answer

Not covered. No documented session correlation across model and tool calls, no named response owner or case management. Logpush export and Gateway HTTP logs with user attribution are nearby features but fall short of the full outcome.

Research detail: AI Gateway Logpush exports request logs to external storage with request and response bodies encrypted under a customer RSA key, and Gateway HTTP logs carry user attribution, DLP matches and MCP detection. Portal logs export via Logpush on Enterprise plans. Detections come from DLP, Guardrails and AI Security for Apps fields.
