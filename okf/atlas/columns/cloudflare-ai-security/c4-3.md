<!-- chunk: answer -->
## Answer

Covered. Requires per-user authentication (Require user auth / manual credentials) on the MCP portal; AI Gateway behind Access. Service token sessions do not support per-user OAuth.

Source statement: "Manual credentials require per-user authentication." (https://developers.cloudflare.com/cloudflare-one/access-controls/ai-controls/mcp-portals/)

Research detail: With Require user auth on, each user authenticates to each upstream MCP server with their own account through the portal, so tool calls run with that user's upstream permissions. Access linked apps let an MCP server forward the user's Access JWT to downstream self-hosted applications. AI Gateway behind Access attaches the verified user ID to each request for logs, routing and spend controls.

<!-- chunk: products -->
## Products

MCP server portals (Require user auth), Access for SaaS and Linked App Token policies, AI Gateway Access integration

<!-- chunk: gaps -->
## Gaps

Service token sessions cannot use per-user OAuth, so autonomous agents fall back to the admin credential. Token scope narrowing is not described for linked apps.

<!-- chunk: options -->
## Options

Keep Require user auth on for servers holding user data. Avoid admin credentials for servers reachable by service tokens.
