## Answer

Not covered. No limits on agent files or processes, and no documented kill switch for an agent. Turning off portal tools and Gateway egress policies only affect traffic through Cloudflare.

Research detail: MCP portal Code Mode runs model-written code in an isolated Dynamic Worker that keeps credentials out of model context. Admins can turn off tools or disable a server, which removes its tools from the active session, and sign-out revokes portal OAuth grants. With Gateway routing, portal calls respect Gateway egress policies, and HTTP policies can block outbound traffic by destination or application.

<!-- chunk: products -->
## Products

MCP server portals with Code Mode, Gateway HTTP policies, Access.

<!-- chunk: gaps -->
## Gaps

Containment covers traffic through the portal and Gateway only, not code running on the agent's host. Admin-forced revocation of another user's portal session is not described on the portal page.

<!-- chunk: options -->
## Options

Route all agent MCP and web traffic through Gateway, and test that disabling a server ends tool access mid-session.
