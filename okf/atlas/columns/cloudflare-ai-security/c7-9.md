## Answer

Covered. Requires traffic proxied through Gateway HTTP filtering; MCP detection is beta; endpoint discovery on all plans.

Source statement: "Shadow IT SaaS analytics provides visibility into the SaaS applications your users are visiting." (https://developers.cloudflare.com/cloudflare-one/insights/analytics/shadow-it-discovery/)

Research detail: Shadow IT analytics show which SaaS apps, including AI apps, users reach with users, data volumes and approval status. Gateway detects MCP traffic and the AI security report shows unique MCP servers and users, and AI Security for Apps discovers LLM endpoints in an organisation's own web properties on all plans.
