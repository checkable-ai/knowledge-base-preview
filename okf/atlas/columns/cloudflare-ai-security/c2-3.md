## Answer

Not covered. No control of the agent's own host, container, interpreter or network. Portal Code Mode runs only portal tool code in a Dynamic Worker.

Research detail: Portal Code Mode replaces upstream tool definitions with search and execute tools and runs model-written JavaScript in an isolated Dynamic Worker. This is a hosted sandbox for portal tool calls only, not a general agent host.

## Products

MCP server portals Code Mode

## Gaps

No control over the agent's own host, networking or interpreter outside Code Mode. Upstream servers running their own Code Mode are not supported.

<!-- chunk: options -->
## Options

Test Code Mode sandbox isolation before relying on it. Use a separate sandbox product for agent hosts.
