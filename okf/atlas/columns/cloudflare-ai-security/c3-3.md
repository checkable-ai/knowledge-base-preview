## Answer

Covered. AI Gateway DLP is configured per gateway. Gateway HTTP DLP is needed for portal traffic. Only two predefined profiles without a Zero Trust subscription.

Source statement: "DLP policies are configured at the gateway level and apply uniformly to all requests passing through that gateway." (https://developers.cloudflare.com/ai-gateway/features/dlp/)

Research detail: AI Gateway DLP scans prompts and responses against Cloudflare One DLP profiles (financial, PII, government IDs, healthcare, custom) and flags or blocks matches. Gateway HTTP DLP policies apply to MCP portal traffic and to AI apps such as ChatGPT, Gemini, Perplexity and Claude, where AI prompt profiles classify prompt content and intent.

<!-- chunk: products -->
## Products

AI Gateway DLP, Cloudflare Gateway DLP, AI prompt protection

<!-- chunk: gaps -->
## Gaps

Retrieval scoping per agent or user is not addressed. Without a Zero Trust subscription only two predefined profiles are available in AI Gateway. Response scanning buffers streamed output.

<!-- chunk: options -->
## Options

Buy the Zero Trust DLP tier for full profiles. Enforce retrieval permissions in the data source.
