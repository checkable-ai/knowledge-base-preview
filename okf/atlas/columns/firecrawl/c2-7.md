## Answer

Partly covered. No configurable file or process limits. Agent cancellation is cooperative, not immediate, and Threat Protection does not intercept navigations inside an agent's remote browser.

Source statement: "Firecrawl only fetches public web addresses on your behalf." (https://docs.firecrawl.dev/security.md)

Last checked 17 November 2026.

Research detail: Fetch and browser egress is forced outside Firecrawl's network and blocks private addresses on every redirect. Interact sessions and agent jobs can be stopped and keys can be revoked, with changes taking effect within about a minute. Threat Protection can block risky destinations.

<!-- chunk: products -->
## Products

Network protections, Interact stop, Agent cancel, key revocation, Threat Protection

<!-- chunk: gaps -->
## Gaps

No filesystem or process policy is configurable. Agent cancellation is cooperative and not immediate. Navigations inside an agent's remote browser are not intercepted by Threat Protection.

<!-- chunk: options -->
## Options

Revoke the key to cut access and set Threat Protection to fail closed.
