## Answer

Escalated for a person to settle. The agent checks did not agree on this finding.

Research detail: SIEM Audit Logging delivers events to Microsoft Sentinel through the Logs Ingestion API, normalised to the ASIM web session schema so existing analytics rules and hunting queries work. Events carry key attribution, a job request ID, correlation IDs and Threat Protection decision context.

<!-- chunk: products -->
## Products

SIEM Audit Logging, Threat Protection decision events

<!-- chunk: gaps -->
## Gaps

Enterprise only. Sentinel is the only destination documented. Only normalized fields are exported, so redaction is by omission. Detections and response ownership are the customer's.
