## Answer

Escalated for a person to settle. The agent checks did not agree on this finding.

Last checked 17 November 2026.

Research detail: PII redaction removes personal data from scrape and parse output before it reaches agents, with chosen entity types and replace styles. Zero data retention stops Firecrawl keeping content. These act on retrieved web content, not on enterprise data stores.

<!-- chunk: products -->
## Products

redactPII, zero data retention, Threat Protection

<!-- chunk: gaps -->
## Gaps

Redaction is per request and charged at 5 credits per page. LinkedIn URLs served by third-party data providers cannot be redacted. It is not a per-agent retrieval policy.

<!-- chunk: options -->
## Options

Make redactPII the default in the calling code and test the entity coverage against sample pages.
