## Answer

Out of scope. Firecrawl is a hosted web data API and tool server whose fetching and browsers run on its own servers. It does not run the agent or govern the agent host's file, command or local tool permissions. The local MCP server is only a client to the Firecrawl API, and host permissions are the operator's to set.

Last checked 17 November 2026.

Research detail: Firecrawl runs its fetching and browsers on its own servers. The open source MCP server can run locally over stdio and a self-hosted API can read a local file path, but no scoping of local actions is documented.
