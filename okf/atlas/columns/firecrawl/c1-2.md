## Answer

Covered, with conditions. Key Restrictions are an enterprise feature and are gated per organization, enabled through your Firecrawl account team. IP Restrictions and Threat Protection are also Enterprise features. Scopes cover Firecrawl endpoints, output formats and fetched URLs, not actions in other connected systems.

Source statement: "Key Restrictions let you lock a single API key down to a defined set of output formats and endpoints." (https://docs.firecrawl.dev/features/key-restrictions.md)

Last checked 17 November 2026.

Research detail: Key Restrictions lock one API key to listed endpoint groups (such as scrape or crawl) and output formats, enforced server side with no request override. IP Restrictions limit where keys can be used from. Threat Protection and its blacklist set which sites can be fetched. Spend limits cap each key.

<!-- chunk: products -->
## Products

Key Restrictions, IP Restrictions, Threat Protection, per-key spend limits

<!-- chunk: gaps -->
## Gaps

Key Restrictions, IP Restrictions and Threat Protection are Enterprise only. The scopes cover Firecrawl calls and target URLs, not actions in other connected systems.

<!-- chunk: options -->
## Options

Hand each agent a key limited to the endpoints and formats it needs and enforce Threat Protection.
