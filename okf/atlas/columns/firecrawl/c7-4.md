## Answer

Not covered. No documented hardening or scanning of the containers, browsers or hosts that run the tools. The documented network protections (blocking private, loopback, link-local and metadata addresses) and SOC 2 Type II are egress and assurance measures, not host or container hardening.

Last checked 17 November 2026.

Research detail: Network protections run server side for every plan and the Security overview documents the fetcher, redirect and egress design. A self-hosted DNS rebinding fix was published with a CVE and fixed version. SOC 2 Type II and a penetration test on request add assurance.
