## Answer

Not covered. No per-agent identity tied to an owner, runtime and release. The nearest feature is the named API key, which SIEM audit events record by key ID and display name, but it is a credential rather than an agent identity.

Research detail: Firecrawl is a web data API and MCP server, not an agent platform. Each API key has a name and an owner, and SIEM events attribute every fetch to a key ID and display name. There is no agent identity linked to an owner, runtime and release.
