## Answer

With our team for a decision. The agent checks did not agree on this finding.

Last checked 17 November 2026.

Research detail: For agents that fetch the web through Firecrawl, it acts as a controlled egress point. Key Restrictions limit endpoints and formats per key, Threat Protection screens every URL, rate and spend limits apply, and private addresses are always refused. It does not mediate an agent's other tools.

<!-- chunk: products -->
## Products

Key Restrictions, Threat Protection, Network protections, rate limits

<!-- chunk: gaps -->
## Gaps

Enterprise only for Key Restrictions and Threat Protection. No schema validation of tool calls or prompt injection screening of page content is documented. Applies only to traffic sent through Firecrawl.

## Options

Route all agent web access through Firecrawl and use Enterprise controls with Threat Protection set to fail closed.
