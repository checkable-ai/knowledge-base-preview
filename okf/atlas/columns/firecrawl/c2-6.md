How [Firecrawl](profile.md) addresses the [Agent Persistent Memory](../../controls/c2-6.md) control. Researcher verdict: escalated. Verification state: contested. Agents must not retrieve this page: escalated by the confirm agents, so a person settles it.

<!-- chunk: answer -->
## Answer

Escalated for a person to settle. The agent checks did not agree on this finding.

Last checked 17 November 2026.

Research detail: Interact persistent profiles save browser state such as logins to a named profile and load it on later scrapes. Change tracking snapshots persist and do not expire. Agent history stays in the activity logs after results leave the API. This is cache and browser state, not conversational memory.

<!-- chunk: products -->
## Products

Persistent profiles, change tracking snapshots, scrape cache, Activity Logs

<!-- chunk: gaps -->
## Gaps

The dashboard has no complete inventory of API-created profiles. Retention periods for profiles are not stated. Profiles and recordings are not available with ZDR.

<!-- chunk: options -->
## Options

Prefer read-only profiles, record each profile in an inventory and set storeInCache to false where needed.
