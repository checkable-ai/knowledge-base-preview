## Answer

Not covered. No on-behalf-of or token exchange flow. Firecrawl OAuth connects a user to a team's Firecrawl access, and permissions are team-level (an API key grants its owning team full access by default), not per initiating user. Nothing documents passing the user's identity or permissions to downstream systems.

Last checked 17 November 2026.

Research detail: Firecrawl OAuth lets each user connect their own Firecrawl account to an app or MCP client, and the connection is listed and revocable by that user. This propagates the user to Firecrawl only. Nothing documents passing the initiating user identity on to other downstream services.

## Gaps

Delegation stops at Firecrawl. No token exchange or on-behalf-of flow to third-party systems is described.

<!-- chunk: options -->
## Options

Use OAuth connections so usage is attributable to a person, and handle downstream delegation in the identity layer.
