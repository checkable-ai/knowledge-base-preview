## Answer

Not covered. SIEM Audit Logging records one event per URL fetched and exports it to Microsoft Sentinel, but the page documents no write-once or integrity-validated storage and no tamper detection. It does not record agent tool calls or data changes, and events are dropped if the destination stays down past the retry budget.

Research detail: SIEM Audit Logging streams one event per URL fetched, with the target URL, status, outcome, the API key and workflow that triggered it, a shared request identifier and the caller's correlation IDs. Content is never included. Activity Logs hold request history in the dashboard.

## Products

SIEM Audit Logging, Activity Logs

<!-- chunk: gaps -->
## Gaps

Enterprise only. Page content, prompts and reasoning are not logged and tamper-proofing is not documented. Events are dropped if the destination stays down past the retry budget.

<!-- chunk: options -->
## Options

Send events to an immutable store in the SIEM and log agent prompts and outputs in the calling platform.
