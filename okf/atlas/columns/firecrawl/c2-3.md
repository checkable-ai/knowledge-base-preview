## Answer

Partly covered. Sandbox isolation is not detailed. The self-hosted quickstart disables API authentication and is not a production architecture.

Source statement: "Firecrawl only fetches public web addresses on your behalf." (https://docs.firecrawl.dev/security.md)

Research detail: Interact runs page actions and Playwright or bash code in a Firecrawl-hosted browser sandbox. Fetches refuse private and metadata addresses and connect out from outside Firecrawl's internal network. Customers can self-host a pinned release with Docker Compose.
