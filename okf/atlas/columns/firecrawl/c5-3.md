## Answer

Partly covered. Only Firecrawl credit cost is shown. Model use elsewhere, infrastructure, staff time and what agents deliver are not covered.

Source statement: "The Usage page shows your credit consumption over time and current billing-cycle totals." (https://docs.firecrawl.dev/dashboard.md)

Research detail: Activity Logs show each request's status, duration and credits, and the Usage page shows consumption over time. Spend limits apply per API key and per team, Agent runs report creditsUsed and a pay-as-you-go limit caps monthly spend.
