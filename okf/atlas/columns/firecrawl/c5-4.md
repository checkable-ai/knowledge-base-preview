## Answer

Not covered. No monitoring of load, performance or anomalies in the systems agents run on. The Queue Status endpoint and concurrency limits show only Firecrawl's own queue availability for a team's work, and no latency, alerting or anomaly dashboard is documented.

Last checked 17 November 2026.
