## Answer

Partly covered. Cancellation is cooperative and credits can still accrue. No generic retry policy is documented for Agent runs, and the controls cover Firecrawl's own jobs, not a customer's workflow engine.

Source statement: "Agent jobs run asynchronously. When you submit a job, you'll receive a Job ID that you can use to check status:" (https://docs.firecrawl.dev/features/agent.md)

Last checked 17 November 2026.

Research detail: Agent jobs run asynchronously with status polling, a cooperative cancel endpoint, a maxCredits budget, follow-up turns that continue a thread, and lifecycle webhooks. Crawls and batch scrapes report failed pages. This covers Firecrawl's own jobs, not a customer's workflow engine.

## Products

Agent, Crawl and batch scrape jobs, webhooks

## Gaps

Cancellation is cooperative and credits can still accrue. Follow-up turns are not available with zero data retention. No generic retry policy is documented for Agent runs.

## Options

Set maxCredits on every agent call and subscribe to lifecycle webhooks.
