## Answer

Escalated for a person to settle. The agent checks did not agree on this finding.

Research detail: Firecrawl supplies the managed harness for its Agent and Interact endpoints, and an open source MCP server and CLI that execute its tools. Team policy, key restrictions and keyless or key-based access shape which tools are available. Operators cannot change the harness internals.

<!-- chunk: products -->
## Products

Agent, Interact, Firecrawl MCP server, CLI

<!-- chunk: gaps -->
## Gaps

Some Cloud-only surfaces (Agent, Browser, Interact) are not in the open source stack.

<!-- chunk: options -->
## Options
