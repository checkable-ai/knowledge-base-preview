## Answer

Escalated for a person to settle. The agent checks did not agree on this finding.

Last checked 17 November 2026.

Research detail: Team Admins invite, remove and re-role members, and Enterprise adds SAML or OIDC SSO with SCIM sync. API keys are created, restricted and revoked in the dashboard and changes propagate within about a minute. There is no agent identity lifecycle.

<!-- chunk: products -->
## Products

Team roles, SSO and SCIM, API key management, Key Restrictions

<!-- chunk: gaps -->
## Gaps

Only two roles (Admin and Member). SSO and SCIM are Enterprise and their dedicated page was refused by the reader, so detail comes from the Security overview and Enterprise pages.

<!-- chunk: options -->
## Options

Provision per-agent keys through a controlled process and use SCIM to retire people with access.
