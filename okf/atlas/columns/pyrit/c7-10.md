## Answer

Covered, with conditions. PyRIT is open source and runs locally; the Foundry AI Red Teaming Agent offers local and cloud runs. Agentic risk categories (prohibited actions, sensitive data leakage, task adherence) are cloud red teaming only. Cloud red teaming is available in East US 2, France Central, Sweden Central, Switzerland West and US North Central. Cloud agent testing supports only Foundry hosted prompt and container agents with Azure tool calls. Only text-based scenarios are supported. Agentic categories are single-turn, English-only, and use synthetic data and mock tools. ASR scoring uses generative models and can be non-deterministic. The Microsoft Foundry AI Red Teaming Agent route requires a Foundry project and is documented as preview.

Source statement: "AI Red Teaming Agent can be used to run automated scans and simulate adversarial probing to help accelerate the identification and evaluation of known risks at scale." (https://learn.microsoft.com/en-us/azure/foundry/concepts/ai-red-teaming-agent)

Last checked 16 November 2026.

Research detail: PyRIT is an open-source framework for automated and human-led red teaming of generative AI systems. It combines datasets, attack executors (including multi-turn attacks such as Crescendo), stackable prompt converters, scorers and memory, and ships scenario families (Foundry, Garak, AIRT, Adaptive, Benchmark) runnable through pyrit_scan. Foundry's AI Red Teaming Agent uses PyRIT attack strategies, adds agentic categories (prohibited actions, sensitive data leakage, task adherence, indirect prompt injection) and reports Attack Success Rate.

## Gaps

Authorisation of testing is left to the user.
