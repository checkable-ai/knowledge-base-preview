## Answer

Covered. PyRIT is open source and runs locally. Foundry agentic risk categories are cloud only, text only, single-turn, English-only, use synthetic data and mock tools, and support only Foundry prompt and container agents with Azure tool calls. ASR scoring is model-based and non-deterministic.

Source statement: "AI Red Teaming Agent can be used to run automated scans and simulate adversarial probing to help accelerate the identification and evaluation of known risks at scale." (https://learn.microsoft.com/en-us/azure/foundry/concepts/ai-red-teaming-agent)

Research detail: PyRIT is an open-source framework for automated and human-led red teaming of generative AI systems. It combines datasets, attack executors (including multi-turn attacks such as Crescendo), stackable prompt converters, scorers and memory, and ships scenario families (Foundry, Garak, AIRT, Adaptive, Benchmark) runnable through pyrit_scan. Foundry's AI Red Teaming Agent uses PyRIT attack strategies, adds agentic categories (prohibited actions, sensitive data leakage, task adherence, indirect prompt injection) and reports Attack Success Rate.
