## Answer

Not covered. No training of agents on their tasks and no anomaly detection on live agent behaviour. The nearest feature is the Foundry AI Red Teaming Agent's scheduled continuous red teaming runs, which repeat adversarial tests on synthetic data. They do not observe production behaviour. The vendor states: "Red teaming runs only represent adversarial population and don't include any observational population." Task adherence red teaming is also a test on synthetic scenarios, not continuous validation of real agent behaviour. The customer must address agent behaviour monitoring and anomaly detection separately.

Last checked 16 November 2026.

Research detail: Foundry documents post-deployment continuous red teaming runs scheduled at set intervals, built on PyRIT attack strategies and scored by Attack Success Rate. PyRIT scenarios can be rerun and resume where they stopped. This gives repeated adversarial validation but no anomaly detection on live traffic.

## Gaps
