## Answer

Not covered. No anomaly detection on live agent behaviour and no agent training. Scheduled continuous red teaming runs on synthetic adversarial data fall short of monitoring. The page states red teaming runs do not include any observational population.

Research detail: Foundry documents post-deployment continuous red teaming runs scheduled at set intervals, built on PyRIT attack strategies and scored by Attack Success Rate. PyRIT scenarios can be rerun and resume where they stopped. This gives repeated adversarial validation but no anomaly detection on live traffic.
