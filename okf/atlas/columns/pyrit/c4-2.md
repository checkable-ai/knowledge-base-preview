## Answer

Out of scope. Kept. Issuing, rotating and revoking agent credentials is a runtime identity function. PyRIT only holds credentials for its own test targets (Entra authentication, managed identity, environment secrets), which is not agent credential handling. The objection also concludes it is not documented, and does not show a feature that meets the outcome.

Last checked 16 November 2026.

Research detail: PyRIT reads target endpoints and keys from local configuration such as ~/.pyrit/.env. It does not broker, rotate or revoke credentials for agents. Checked the PyRIT 1.1.0 framework, scanner, memory, targets and GUI docs and the Foundry AI Red Teaming Agent pages.
