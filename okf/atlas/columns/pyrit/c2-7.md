## Answer

Not covered. No sandbox, egress policy or kill switch for agents under test. Foundry agentic tests run in a minimally sandboxed environment, and Microsoft notes the lack of completely locked-down sandboxing.

Research detail: PyRIT is a red teaming library and does not contain or stop production agents. Its prompt target docs describe rate limits and probe timeouts but no sandboxing, network restriction or way to stop a running scan. The Foundry cloud red teaming page says agentic risk scenarios run in a minimally sandboxed environment for the test run only, and a run can end in a canceled state, which is test control rather than agent containment.
