## Answer

Covered. AI Agent Gateway; named SaaS apps such as Salesforce, Microsoft 365 and Jira; product page only; staged rollout after the 22 July 2026 launch.

Source statement: "Short-lived credential tokens with instant revocation when agent behavior changes" (https://www.forcepoint.com/use-case/agentic-ai-security)

Research detail: The AI Agent Gateway is described as sitting between agents and SaaS applications so that no agent holds a direct application credential, using short-lived credential tokens with instant revocation when agent behaviour changes.
