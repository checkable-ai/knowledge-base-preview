## Answer

Not covered. Forcepoint logs and attributes agent actions but does not give each agent its own identity tied to an owner, runtime or release. Nearby feature: identity attribution on every agent action.

Research detail: The agentic AI page says every agent action is logged with attribution to the agent and to the user who triggered it, and the platform claims full identity attribution for sanctioned and shadow agents. Forcepoint observes agent identity rather than issuing one.
