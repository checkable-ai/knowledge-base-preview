## Answer

Covered. PingGateway MCP support has evolving interface stability; Agent Privilege is a separate product.

Source statement: "Tools a user isn't entitled to are removed from listings in flight" (https://docs.pingidentity.com/privilege/agent-privilege/what-is-agent-privilege.md)

Research detail: PingGateway acts as an MCP security gateway that validates MCP JSON-RPC payloads, enforces OAuth 2.1 resource server checks, throttles, audits and can call PingOne Authorize for fine-grained policy. Agent Privilege's MCP Gateway authorises individual tools, injects credentials and runs AI Guard for injection, unsafe tool use and exfiltration.

## Products

PingGateway McpValidationFilter, McpProtectionFilter, McpAuditFilter, Agent Privilege MCP Gateway, AI Guard
