## Answer

Covered. No cross-organisation federation model described.

Source statement: "With each new agent authentication, a new `act` claim is appended, creating a nested audit trail of collaboration between agents and servers." (https://developer.pingidentity.com/identity-for-ai/identity/idai-token-exchange.html)

Research detail: Token exchange supports agent-to-agent flows where each hop gets a token for a new audience with nested act claims. Agent Privilege registers external agents as Remote Agent apps, can discover A2A agent cards, and can forward the calling agent's verified token so the remote agent can check it.
