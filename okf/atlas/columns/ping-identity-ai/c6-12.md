## Answer

Not covered. Agent Privilege LLM Control restricts keys to approved models, and Remote Agent policies set start and end dates for access. Neither is a supplier governance process: there is no scheduled reassessment, vendor assessment workflow or retirement workflow for external models, tools and services. The customer must run that governance themselves.

Research detail: LLM Control limits keys to approved models, and Remote Agent policies set start and end dates for access to external agents. Periodic reassessment and retirement of external services are not described.
