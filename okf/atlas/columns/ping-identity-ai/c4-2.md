## Answer

Covered. Credential injection, LLM Control and agent keys are part of PingOne Privilege Agent Privilege, a separate product from Agent IAM Core.

Source statement: "Short-lived keys reduce blast radius; you can revoke keys instantly at any time." (https://docs.pingidentity.com/privilege/agent-privilege/configuration/agent-registry.md)

Research detail: Agent Privilege injects backend credentials at the gateway at request time so agents never hold them, accepts short-lived platform tokens (Kubernetes, CI, SPIFFE, OIDC) through Secretless Access, and fronts external vaults through Secrets Bridge. Agent keys have an expiry and can be revoked instantly. Agent IAM Core issues short-lived, audience-restricted delegation tokens.

## Products

Agent Privilege AI gateway, Secretless Access, Secrets Bridge, User-Level Attribution, Agent IAM Core token exchange
