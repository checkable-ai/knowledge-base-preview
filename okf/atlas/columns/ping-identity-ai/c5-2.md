## Answer

Not covered. PingOne Protect detects agentic traffic and Agent Privilege scores configuration risk, but no baseline or anomaly detection of an agent's own task behaviour, nor task training or validation.

Research detail: PingOne Protect's Bot Detection predictor uses fingerprinting, behavioural telemetry, device attributes and HTTP message signatures to separate agentic activity from human traffic and can name some agent types. Agent Privilege scores workload agents for configuration risk. Anomaly detection on an agent's own task behaviour is not described.
