## Answer

Not covered. No sandbox for agent files, processes or network egress. Agent Privilege session manager and kill switch cut access to tools and models only.

Research detail: Agent Privilege lists Session Manager, which lets an administrator manage or terminate an agent's access immediately with session management and kill switch capabilities, and per-user LLM Control virtual keys described as revocable instantly. The PingGateway MCP gateway allows only valid MCP requests, throttles request rates and applies OAuth 2.1 and fine-grained policy. PingOne can disable or delete an AI agent identity, and delegation tokens are short-lived.

<!-- chunk: products -->
## Products

PingOne Privilege Agent Privilege (Session Manager, LLM Control, MCP Gateway), PingGateway MCP security gateway, PingOne AI Agents lifecycle

<!-- chunk: gaps -->
## Gaps

This is a control on access to tools and models, not code sandboxing. No page read describes a sandbox, filesystem or process policy for agent code, or general network egress control. The PingOne pages do not say whether disabling or deleting an agent invalidates tokens it already holds. The kill switch claim comes from the Agent Privilege overview, and the page read gives no detail on propagation time.

<!-- chunk: options -->
## Options

Test how quickly Session Manager termination and virtual key revocation stop an active MCP session, and whether disabling a PingOne agent invalidates issued tokens.
