## Answer

Covered. Requires CIBA configured in PingOne; the binding message shown to the approver is supplied by the agent.

Source statement: "the agent's request is paused while the human user receives a push notification" (https://docs.pingidentity.com/pingone/ai_agents/p1_ai_agents.html)

Research detail: PingOne can require human approval for high-risk agent actions through CIBA. The agent request pauses, the user sees an optional binding message and approves or denies, denial returns access_denied and requests expire. Binding to the exact action depends on the agent supplying an accurate binding message.
