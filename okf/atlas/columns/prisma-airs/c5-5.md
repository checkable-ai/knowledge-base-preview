## Answer

Covered, with conditions. Requires Prisma AIRS AI Runtime Security. Covers AWS Bedrock Agents (optimised models only) and Azure AI Foundry Agents and OpenAI Assistants (static configurations only; Hub-Based Projects not supported). Release supports configuration discovery only; Azure has no runtime invocation information. Requires Prisma AIRS AI Runtime Security licensing and cloud-account onboarding. Enterprise Agent Discovery is documented for United States Americas, Singapore, India, United Kingdom and Canada.

Source statement: "Knowledge Bases and Tools/Action Groups" (https://docs.paloaltonetworks.com/prisma-airs/ai-inventory/agent-discovery)

Research detail: Agent Discovery shows each agent's foundation model, knowledge bases, tools and action groups and collaborator agents, split into protected and unprotected. AI traffic visibility maps flows between users, applications, models and internet destinations. Cortex AISPM discovery shows dependency relationships for blast radius.

## Products

AI Agent Discovery, AI Traffic and Application Visibility, AI Discovery with Cortex AISPM

## Gaps

Agent coverage is AWS Bedrock and Azure Foundry and OpenAI Assistants. Action scopes against downstream systems are not shown. AISPM discovery is Americas only and needs Cortex Cloud.
