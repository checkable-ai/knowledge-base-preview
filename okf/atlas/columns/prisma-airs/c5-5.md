## Answer

Covered. Needs AI Runtime with onboarded cloud accounts. Covers AWS Bedrock Agents, Azure AI Foundry Agents and OpenAI Assistants. Azure shows static configuration only. Enterprise Agent Discovery regions listed: US (Americas), Singapore, India, UK, Canada; Australia not listed. Cortex AISPM graph needs Cortex Cloud with the Cloud Posture Management bundle and a separate AI-SPM licence. Action visibility is at tool or action group level.

Source statement: "API results show all agents, models, knowledge bases, and tools divided into Protected and Unprotected lists." (https://docs.paloaltonetworks.com/prisma-airs/ai-inventory/agent-discovery)

Research detail: Agent Discovery shows each agent's foundation model, knowledge bases, tools and action groups and collaborator agents, split into protected and unprotected. AI traffic visibility maps flows between users, applications, models and internet destinations. Cortex AISPM discovery shows dependency relationships for blast radius.
