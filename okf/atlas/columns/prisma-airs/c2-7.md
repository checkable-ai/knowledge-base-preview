## Answer

Not covered. No sandbox, filesystem or process policy, and no agent kill switch. Network intercept firewalls are the nearest feature.

Research detail: AI Runtime network intercept is an inline firewall in front of AI workloads in AWS, Azure or GCP, and on NVIDIA BlueField-3 DPUs selected traffic is steered to a containerised firewall that can inspect, allow or block it, which gives network egress control. Through the Cortex AES integration, Prisma AIRS verdicts on prompts, MCP tool calls and WebFetch or WebSearch calls are enforced on coding agents such as Claude Code and Cursor on developer endpoints. Prisma AIRS does not sandbox agent code execution or set filesystem or process policy, and no page read describes stopping a running agent or revoking its access.

Prisma AIRS AI Runtime network intercept, BlueField-3 DPU firewall, Cortex AES integration

## Gaps

No sandbox, no filesystem or process policy and no agent kill switch. On the DPU, traffic bypasses the firewall unless steering rules select it. SaaS agent security pages do not name disable or revoke actions.

<!-- chunk: options -->
## Options

Use the network intercept firewall for egress allowlisting around agent hosts, and pair it with an agent runtime or identity platform that can stop agents and revoke credentials.
