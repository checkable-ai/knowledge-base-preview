## Answer

Not covered. Agent audit logs reach a SIEM, but redaction of sensitive data, detections and a named response owner are not documented as part of the outcome.

Last checked 14 November 2026.

Research detail: API scan logs can be forwarded to a SIEM with metadata and verdict plus a session_URL linking to the full conversation in Strata Cloud Manager, so raw prompts are not sent. AI Sessions group calls by transaction ID. Cortex AES attributes verdicts to device, agent, session and policy.
