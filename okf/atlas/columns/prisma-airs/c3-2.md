## Answer

Not covered. The AI Gateway enforces MCP tool access policies per user and agent at runtime, but no input schema enforcement, tool-call rate limits or general internet access control is documented. Only MCP tool calls routed through the gateway are controlled.

Research detail: Scan APIs inspect MCP tool definitions, inputs and outputs for context poisoning, credential leakage, injection and malicious code, and block per profile. The MCP server returns allow or block verdicts but depends on the agent being instructed to call it. Network intercept and URL filtering cover egress. An MCP Gateway is listed in the architecture without detail.
