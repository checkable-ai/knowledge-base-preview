## Answer

Not covered. Per-agent OAuth 2.1 client credentials issue short-lived access tokens, but the docs describe no rotation or revocation. A lost client secret means deleting and re-registering the agent. Downstream tool credentials are not brokered, and keeping secrets from the model is not documented.

Research detail: AI Gateway holds provider integrations behind workspace virtual keys, so applications send a gateway API key and virtual key rather than provider secrets. Gateway keys have three scopes and are shown once at creation. Runtime scanning also detects credential leakage in MCP tool configs and outputs.

## Gaps

Rotation, expiry and revocation of gateway keys are not described. No brokerage of downstream tool credentials.

## Options
