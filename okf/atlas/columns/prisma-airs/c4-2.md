## Answer

Not covered. No single feature gives agents short-lived, scoped, rotated and revocable credentials with secrets kept from the model. AI Gateway keys are persistent; agent client secrets have no documented rotation or revocation.

Last checked 14 November 2026.

Research detail: AI Gateway holds provider integrations behind workspace virtual keys, so applications send a gateway API key and virtual key rather than provider secrets. Gateway keys have three scopes and are shown once at creation. Runtime scanning also detects credential leakage in MCP tool configs and outputs.

<!-- chunk: products -->
## Products

AI Gateway virtual keys and gateway API keys, AI Runtime credential leakage detection

<!-- chunk: gaps -->
## Gaps

Rotation, expiry and revocation of gateway keys are not described. No brokerage of downstream tool credentials.

<!-- chunk: options -->
## Options

Test key revocation in a tenant. Use a secrets manager or identity broker for tool credentials.
