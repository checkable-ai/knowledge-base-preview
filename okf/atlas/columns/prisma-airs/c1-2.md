## Answer

Not covered. Database Security Detection allows or blocks database query types in scanned content. It is not a per-agent permission model for connected systems.

Research detail: Security profiles include Database Security Detection with allow or block per create, read, update and delete query, and AI Agent Protection that detects direct tool invocation and function schema leakage. Malicious URL detection covers outbound links. These are detections on content, not a per-system permission grant.
