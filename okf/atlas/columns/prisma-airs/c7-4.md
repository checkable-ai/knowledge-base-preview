## Answer

Not covered. No hardening or scanning of the containers or hosts that run models and tools. Skill Security and Model Security scan skill packages and model artefacts only, and the network firewalls inspect traffic.

Research detail: AI Runtime network intercept places firewalls inline with AI workloads in cloud networks, and can run on NVIDIA BlueField-3 DPUs or via a Windows microperimeter agent. This protects traffic around inference and tool hosts rather than assuring the hosts themselves.
