## Answer

Not covered. Agent Identity Security gives each registered agent a unique Agent ID and an optional IdP-mapped owner. It documents no binding to where the agent runs or to its release or version. The callback URL is only a registration field.

Research detail: The docs navigation has an AI Agent Identity section, but the pages opened cover SaaS agent onboarding and the MCP server, not identity issuance. Agent Discovery records agent name, versions, aliases and foundation model for Bedrock and Foundry agents, which is inventory rather than a stable workload identity tied to an owner.
