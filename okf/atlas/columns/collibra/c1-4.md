## Answer

Not covered. Collibra registers agents and moves them through lifecycle and retirement statuses (Register AI Agent permission, AI Producer role), but does not set up agents or change their permissions or configuration on external platforms. It only records them. Maestro Studio is preview and covers only Collibra's own agents.

Research detail: AI agents and agent versions are registered through AI Command Center under the Register AI Agent permission, moved through lifecycle stages and set to retirement statuses. Maestro Studio lets builders set persona, permissions and tool access for no-code governance agents built inside Collibra.

## Gaps

Provisioning of identities and permissions for agents on external platforms is not performed by Collibra, only recorded. Maestro Studio is Public Preview and limited to Collibra's own agents.
