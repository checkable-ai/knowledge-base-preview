## Answer

Covered. Copilot Memory is in public preview. On Business and Enterprise, user-level preferences are disabled until an owner enables the policy. Default expiry is 90 days, configurable 7 to 180 days for repository facts.

Source statement: "The expiry period starts when a memory is created and resets when Copilot upvotes it." (https://docs.github.com/en/copilot/concepts/prompting-and-context/copilot-memory)

Research detail: Source statement: Copilot Memory stores repository facts and user preferences with citations and validation.

Assessment: Memory is public preview. Citation validation does not establish accountable business approval.

Source qualification: Copilot Memory remains public preview. Unused entries are deleted after 28 days and successful validation and use may reset that timer. Managed plans require administrator policy enablement before user use.
