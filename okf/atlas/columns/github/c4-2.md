## Answer

Not covered. GitHub documents one-hour installation tokens for the Copilot SDK server-to-server route, but the page does not document revocation, automatic rotation, or keeping secrets from the model. The cloud agent uses static environment secrets. The CLI sandbox placeholder injection only hides secrets from sandboxed processes and has no credential lifecycle.

Last checked 17 November 2026.

Research detail: Source statement: Cloud Agents secrets supply selected credentials. CLI sandbox settings govern git and gh credential injection.

Assessment: Cloud and local credential paths have different exposure boundaries.
