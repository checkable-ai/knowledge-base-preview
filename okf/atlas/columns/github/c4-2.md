## Answer

Not covered. No documented short-lived, rotated or revocable credentials for agents. The Copilot CLI local sandbox swaps in placeholder values and a local proxy injects real credentials only for approved hosts, which keeps secrets from sandboxed processes but does not provide credential lifecycle (expiry, rotation, revocation). The cloud agent uses static Copilot environment secrets. Server-to-server authentication for the Copilot SDK is public preview and not documented as meeting the lifecycle outcome.

Research detail: Source statement: Cloud Agents secrets supply selected credentials. CLI sandbox settings govern git and gh credential injection.

Assessment: Cloud and local credential paths have different exposure boundaries.
