## Answer

Covered. Local sandboxing is off by default unless enterprise managed settings require it. App sandbox settings apply only to local sessions, not to cloud sandbox or remote-host sessions. On Linux it needs Bubblewrap 0.5.0 or later and slirp4netns on the PATH. On Windows it needs Windows 11 version 25H2 with a specific update, or Windows 11 26H1.

Source statement: "Local sandboxing is turned off by default unless enterprise managed settings require it." (https://docs.github.com/en/copilot/how-tos/cloud-and-local-sandboxes/configuring-local-sandbox-settings)

Research detail: Source statement: Cloud agent runs on Actions runners. CLI offers local sandbox settings.

Assessment: Self-hosted runners and local preview sandboxes require separate hardening.
