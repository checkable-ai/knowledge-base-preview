## Answer

Covered. Requires GitHub Enterprise Cloud with data residency, the model enforcement policy enabled (off by default, adds AI credit consumption), compatible clients and supported regions (US, EU). Copilot Memory is in public preview.

Source statement: "Your code, prompts, and Copilot responses never leave your region during inference processing." (https://docs.github.com/en/enterprise-cloud@latest/admin/data-residency/github-copilot-with-data-residency)

Research detail: Source statement: Memory has documented deletion and inactivity retention. Telemetry content and history syncing are configurable.

Assessment: These sources do not establish one retention period for all Copilot data.

Source qualification: Copilot Memory remains public preview. Unused entries are deleted after 28 days and successful validation and use may reset that timer. Managed plans require administrator policy enablement before user use.
