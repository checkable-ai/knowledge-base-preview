## Answer

Covered. Covers enterprise-level custom agents only. Agent profiles are defined in a .github-private repository in the enterprise, and changes are governed by pull requests, rulesets and codeowners. The setting can be limited to enterprise owners or delegated AI managers. Settings apply only to users on the enterprise's Copilot plan who use a supported client. VS Code local agents are not managed through GitHub. Enterprise policies switch the cloud agent and third-party agents on or off, and organisations cannot override them.

Source statement: "Enterprise members with bypass access to the ruleset can then merge those pull requests as they see fit." (https://docs.github.com/en/copilot/how-tos/administer-copilot/manage-for-enterprise/manage-agents/prepare-for-custom-agents)
