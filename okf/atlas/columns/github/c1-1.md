## Answer

Covered. Copilot CLI local sandbox. Windows needs Windows 11 25H2 or 26H1 with specific updates and BaseContainer support. Linux needs Bubblewrap 0.5.0 or later and slirp4netns. Commands the host cannot sandbox fail rather than run unprotected.

Source statement: "Local sandboxing limits access to files, network resources, and credentials on your machine." (https://docs.github.com/en/copilot/how-tos/cloud-and-local-sandboxes/configuring-local-sandbox-settings)

Research detail: Source statement: CLI sandbox settings and tool permissions constrain local actions.

Assessment: Local sandboxing is public preview and Windows needs an Insiders build. Bypass must be governed.
