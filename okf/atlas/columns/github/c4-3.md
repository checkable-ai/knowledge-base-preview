## Answer

Not covered. GitHub documents identifying the user's account in agent apps (public preview) but not that called systems apply only that user's permissions. Cloud agent's default GitHub MCP server uses a scoped token, and remote MCP servers with OAuth are not supported.

Research detail: Source statement: Cloud agent's default GitHub MCP token is read-only and repository-scoped. Remote OAuth MCP is not currently supported there.

Assessment: Broader tokens do not prove end-user delegation across external services.
