## Answer

Covered, with conditions. Applies to Copilot cloud agent sessions. Steering is not available for third-party coding agents. Steering messages consume AI credits. Dynamic workflows are in public preview. They exclude Copilot Pro and Copilot Pro+ subscribers on existing annual plans who remain on legacy premium request-based billing.

Source statement: "Stopping a session ends the GitHub Actions run and preserves any commits already pushed." (https://docs.github.com/en/copilot/how-tos/copilot-on-github/use-copilot-agents/manage-and-track-agents)
