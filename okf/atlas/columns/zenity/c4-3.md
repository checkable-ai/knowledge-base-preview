## Answer

Not covered. Zenity does not propagate the user's token to called systems. It enforces rules on the human via Okta attributes at the MCP Gateway, but delegation is left to the platform and IdP.

Research detail: For calls through the MCP Gateway, Zenity decodes the live token to show the identity the agent assumed, and Boundaries rules can reference the human the agent acts for using Okta attributes. It can block a deactivated Okta user from acting through an agent. It inspects and enforces on delegation context but does not propagate it.
