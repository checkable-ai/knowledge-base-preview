## Answer

Covered. MCP traffic routed through the gateway; non-MCP paths rely on platform integration. Quotas and schema validation not documented.

Source statement: "Allow or block individual tools per agent, user, or team." (https://zenity.io/platform/mcp-security)

Research detail: MCP Security routes agent MCP traffic through a gateway URL and allows, modifies or blocks tool calls per agent, user or team using live context. Boundaries can block tool calls to specific third-party domains and AIDR flags tool misuse and injection in tool results. Quotas, rates and schema validation are not documented.
