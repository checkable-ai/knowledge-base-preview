## Answer

Not covered. No sandbox or file, process or network limits. The kill switch and quarantine in Runtime Boundaries cover only the emergency stop, and egress control applies to tool calls, not network traffic.

Research detail: Runtime Boundaries can allow, block or escalate each agent action. Prevent mode hard-stops an action with a deny decision, one rule can block tool calls to named external domains for every agent, and a kill switch immediately disables an agent's ability to call tools or access data during an incident. Severe cases can quarantine an agent. Zenity does not provide a sandbox or filesystem and process policy, and egress control applies to tool calls rather than network traffic.
