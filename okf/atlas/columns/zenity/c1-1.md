## Answer

Not covered. No documented local scoping of files, commands or processes on the host. Runtime Boundaries rules apply to coding agents but do not define local machine limits.

Research detail: Zenity covers personal and coding agents on endpoints, including in developer IDEs, with what the platform page calls lightweight monitoring, detection and response. Boundaries rules are stated to apply to coding agents. Local scope definitions for file system or shell actions are not described.
