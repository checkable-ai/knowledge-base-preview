## Answer

Covered. Enforcement sits beside each host platform's own permissions; depth varies by integrated platform.

Source statement: "It can reference the agent, the human it's acting for, the action, the resource, live identity" (https://zenity.io/platform/runtime-boundaries)

Research detail: Runtime Boundaries evaluates each agent action against rules that reference the agent, the human, the action and the resource, and MCP Security allows or blocks individual tools per agent, user or team. AISPM flags permissions that exceed least-privilege policy before go-live. Enforcement sits beside the host platform's own connector permissions.
