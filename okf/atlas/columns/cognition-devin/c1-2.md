## Answer

Covered. Security profiles; enterprise mandatory profiles; running sessions pick up changes on reboot or wake.

Source statement: "sessions governed by the profile can only use the listed servers." (https://docs.devin.ai/product-guides/security-profiles)

Research detail: Security profiles bundle a network allowlist, an MCP server allowlist, a git access level (read-only or full), removal of the GitHub CLI token and a read-only mode for Devin's own management MCP. Mandatory profiles bound at enterprise level can only be narrowed below. The GitHub integration limits Devin to selected repositories.

<!-- chunk: products -->
## Products

Security profiles, GitHub integration repository selection, MCP allowlist

<!-- chunk: gaps -->
## Gaps

Running sessions keep their profile until they reboot or wake. On Outposts the network policy is only published to the customer's orchestrator, not enforced by Devin.

<!-- chunk: options -->
## Options

Bind a mandatory enterprise profile, use read-only git for analysis automations, and enforce network policy on Outpost infrastructure.
