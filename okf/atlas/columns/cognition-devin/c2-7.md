## Answer

Covered. CLI sandbox OS enforcement not supported on Windows; network filtering marked unstable.

Source statement: "A network policy is an allowlist of destinations the session's machine is permitted to reach." (https://docs.devin.ai/product-guides/security-profiles)

Research detail: Each Devin cloud session runs on its own isolated machine (the Devbox). Security profiles apply an outbound network allowlist to all session traffic, an MCP server allowlist, read-only Devin MCP, a git access level and removal of the GitHub CLI token, and enterprise admins can enforce them as a mandatory floor. The Devin CLI sandbox enforces writable and hidden paths at OS level and fails closed if the sandbox cannot start. A session can be terminated through the API, after which it cannot be resumed.

<!-- chunk: products -->
## Products

Devin Devbox, security profiles, Devin CLI sandbox, Terminate Session API

<!-- chunk: gaps -->
## Gaps

CLI sandbox network filtering is marked unstable, and OS sandboxing is not supported on Windows. Commands excluded from the sandbox run unconfined.

<!-- chunk: options -->
## Options

Bind a mandatory enterprise security profile with a network allowlist. Test session termination and token revocation during a live session.
