## Answer

Covered. MCP allowlist and extension policy are Desktop admin settings. Security profiles, permission rules and hooks apply to sessions. No per-tool quotas.

Source statement: "Explicit list of MCP servers members may use." (https://docs.devin.ai/desktop/controls)

Research detail: Security profiles allowlist MCP servers and network egress per session, and Desktop enforces an MCP allowlist and MCP registry. Permission rules gate MCP tools and commands, and pre-tool hooks can block dangerous commands or rewrite tool input. Devin Local prompts before any MCP call by default.

<!-- chunk: products -->
## Products

Security profiles, MCP allowlist and registry, CLI permissions, Hooks

<!-- chunk: gaps -->
## Gaps

No per-tool quotas or rates. No documented injection screening of tool outputs.

<!-- chunk: options -->
## Options

Use mandatory profiles with narrow egress, deploy blocking pre-tool hooks centrally, and test injection through tool results.
