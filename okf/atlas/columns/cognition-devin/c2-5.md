## Answer

Covered. Cascade and Devin Local use different control sets during migration.

Source statement: "A semver constraint (for example `>=1.2.0 <2.0.0`) restricting which Devin CLI versions members can use." (https://docs.devin.ai/desktop/controls)

Research detail: Devin CLI is the tool-executing harness, shared by Devin Local in Desktop, with permission rules, sandbox, hooks, plugins, skills and subagents. Admins can set a semver version constraint on the CLI and enforce settings through team settings, MDM device policies and system-level files.

## Products

Devin CLI, Devin Local, Cascade, Devin CLI version constraint

<!-- chunk: gaps -->
## Gaps

Cascade and Devin Local use different control sets during migration. Some legacy Cascade controls do not apply to Devin Local.

<!-- chunk: options -->
## Options

Disable legacy Cascade once CLI permission policies are in place and pin the CLI version range.
