## Answer

Partly covered. Staff time spent supervising, reviewing and correcting agents, and a measure of delivered value against cost. The customer must measure business value and ROI themselves.

Source statement: "It does not replace measuring ROI, which requires deeper context on the business value of each task." (https://cognition.com/blog/ai-guarantee)

Research detail: Usage is metered in ACUs from agent actions plus VM time, and consumption is reported by user, session, service user and organisation through the v3 API. Usage policies cap and monitor per-member spend. Desktop analytics report credit consumption and the share of code written by Devin Desktop.
