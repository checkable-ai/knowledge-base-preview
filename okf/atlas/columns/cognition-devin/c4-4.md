## Answer

Not covered. No documented authenticated agent-to-agent protocol across trust boundaries or per-pair authorisation. Child sessions inheriting the parent's security profile is delegation within one platform.

Research detail: A coordinator Devin can launch, message, sleep and terminate managed child sessions, and child sessions are governed by the same security profile chain as their parent so restrictions cannot be escaped by delegation. Devin Desktop delegates to the cloud agent and to ACP agents, gated by admin toggles. All of this stays inside Cognition's platform.
