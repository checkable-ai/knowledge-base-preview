## Answer

Not covered. Model allowlists and defaults exist for Desktop and CLI, but short names resolve to the latest version, and cloud Devin does not disclose which models or endpoints serve a session.

Research detail: Desktop and CLI admins allowlist models by model or provider, set default and subagent models, and choose whether to unlock Anthropic or OpenAI models that need 30-day provider retention. Paid plans can opt out of training, which also enables zero data retention with model providers. The cloud agent is a compound system with no customer model choice and no third-party API keys.

## Products

Allowlisted models, Default model, Data retention toggles, Data Controls opt-out
