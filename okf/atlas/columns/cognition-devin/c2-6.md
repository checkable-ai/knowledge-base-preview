## Answer

Covered. Devin Memory in cloud; Devin Local keeps no memories; turning memory off keeps existing notes.

Source statement: "Devin Memory saves your preferences, corrections, and project lessons as notes that carry across sessions" (https://docs.devin.ai/product-guides/memory)

Research detail: Devin Memory stores per-user notes in a Git-backed memory drive with source links to the session that taught each item, and a daily Dreaming session consolidates them. Admins can set memory to default on, always on or always off at enterprise level, or switch it per organisation. Cascade memories are stored locally per workspace, and Devin Local does not keep memories.

<!-- chunk: products -->
## Products

Devin Memory, Dreaming, Cascade memories, Knowledge

<!-- chunk: gaps -->
## Gaps

Turning memory off keeps existing notes. Memory files are read-only in the app and changed only by asking Devin.

<!-- chunk: options -->
## Options

Set the enterprise memory policy explicitly and review memory drives during offboarding.
