## Answer

Not covered. No central gateway for model calls. Model allowlists, ACU limits and guardrails on user messages are nearby but give no routing, rate limits or screening of all model inputs.

Research detail: Model allowlists restrict which models members can use. Per-user and per-organisation ACU limits block new work once reached, with tiers mapped from IdP groups. AI Guardrails screen user messages and PR comments for prompt injection, exfiltration and policy violations, with log, warn or block actions.

<!-- chunk: products -->
## Products

Allowlisted models, Usage policies, organisation ACU limits, AI Guardrails

<!-- chunk: gaps -->
## Gaps

Controls apply only inside Cognition's products. Guardrails screen user messages, not model inputs from tools or files. Per-user limits are beta.

<!-- chunk: options -->
## Options

Combine usage policies with guardrails in block mode and review guardrail violation data.
