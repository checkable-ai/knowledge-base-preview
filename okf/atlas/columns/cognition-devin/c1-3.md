## Answer

Covered. Applies to Devin Local, Devin Desktop and Devin CLI where allow/ask/deny permission rules are configured; enterprise admins can set fine-grained permissions. Cloud Devin sessions run autonomously unless configured.

Source statement: "Allow, ask, and deny rules, approval requests, and MCP tool permissions." (https://docs.devin.ai/desktop/devin-local)

Research detail: Local agents prompt for approval on ask-rule or unmatched actions, show the exact command, allow editing it before approval, and support reject or session-wide grants. In the cloud, every hosted deploy needs an approve or deny prompt, blocked network destinations raise an access request, and admins can require approval before child sessions launch. Most cloud work runs autonomously and relies on PR review.

<!-- chunk: products -->
## Products

Permission prompts, PermissionRequest hook, deploy approval, child session approval

<!-- chunk: gaps -->
## Gaps

No documented replay protection or signed binding of approvals. Session-wide grants extend to later requests and subagents.

<!-- chunk: options -->
## Options

Use ask rules for sensitive commands, turn off auto-approve child sessions, and require branch protection on merges.
