## Answer

Not covered. Allowlists and managed plugin distribution exist, but no SBOM, vulnerability scanning or signing of plugins, MCP servers or extensions.

Research detail: Organisations can host their own plugins in one repo with a validator in CI, then distribute them through required, optional and forbidden lists where higher levels always win. Desktop admins set an extension allowlist and internal marketplace URL, and MCP allowlist entries can pin config with regex templates.
