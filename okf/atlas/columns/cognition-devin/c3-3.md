## Answer

Not covered. Read deny rules and repository selection limit access, but there is no DLP on outputs, PRs or tool calls and no per-user retrieval policy over knowledge.

Research detail: Read deny rules hide paths such as key files from the agent and sandboxed commands. Repository selection limits what code Devin can reach, and guardrails flag messages that ask Devin to send data to unauthorised destinations. Network allowlists limit where data can go.
