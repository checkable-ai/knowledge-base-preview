## Answer

Not covered. No data loss prevention inspection of retrieved content, outputs, PRs or tool calls, and no per-user retrieval policy. Security profiles limit network destinations, MCP allowlists and repository access but fall short.

Last checked 14 November 2026.

Research detail: Read deny rules hide paths such as key files from the agent and sandboxed commands. Repository selection limits what code Devin can reach, and guardrails flag messages that ask Devin to send data to unauthorised destinations. Network allowlists limit where data can go.

## Products

Read deny rules, repository selection, AI Guardrails, network policy

<!-- chunk: gaps -->
## Gaps

No DLP on agent outputs, PRs or tool calls, and no per-user retrieval policy over knowledge.

<!-- chunk: options -->
## Options

Pair narrow network allowlists with an external DLP or egress proxy, for example the GWLB inspection option on dedicated deployments.
