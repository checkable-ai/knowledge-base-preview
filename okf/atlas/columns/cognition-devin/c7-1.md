## Answer

Not covered. Devin documents enterprise audit logs retrievable through the v2 and v3 audit-logs API, covering admin and account events such as MCP server updates and secret link/unlink. No documentation describes write-once or integrity-validated storage, tamper detection, or an export to such storage. The logs are not documented as a per-action record of agent tool calls and data access.

Research detail: Enterprise and organisation audit logs record several hundred action types, including session creation and messages, secret, MCP, security profile and service user changes, permission responses, PR merges and denials, and guardrail violations, attributed to user or service user. Desktop hooks can write full Cascade transcripts for audit.
