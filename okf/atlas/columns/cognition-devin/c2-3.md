## Answer

Covered. Agent reasoning runs in Cognition's cloud; Outposts shift hardening to the customer.

Source statement: "Each Devin session runs on its own isolated machine, keeping customer data segregated by default." (https://docs.devin.ai/enterprise/deployment/overview)

Research detail: Each cloud session runs on its own isolated VM with a shell, browser and editor. Dedicated deployments run the devbox in a single-tenant VPC reached over PrivateLink or IPSec, and Outposts run sessions on customer machines. Network allowlists are enforced at machine level on Devin-managed VMs, and local agents use an OS sandbox.

<!-- chunk: products -->
## Products

Devbox, Customer Dedicated Deployment, Devin Outposts, Devin Sandbox

<!-- chunk: gaps -->
## Gaps

The agent brain always runs in Cognition's cloud. Outposts move isolation and hardening to the customer.

<!-- chunk: options -->
## Options

Use dedicated deployment for private networks, and recycle Outpost machines per session without passwordless sudo.
