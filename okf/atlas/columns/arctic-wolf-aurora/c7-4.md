## Answer

Not covered. No hardening or scanning of containers, agent software or hosts that run models and tools. Aurora Endpoint Security and the Arctic Wolf Agent give general host protection only.

Research detail: Aurora Endpoint Security and the Arctic Wolf Agent protect and monitor hosts, and MDR monitors endpoints and cloud for threats, which can include hosts that run AI workloads. This is general host protection and not specific to inference or tool containers.
