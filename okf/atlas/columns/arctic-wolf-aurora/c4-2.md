## Answer

Not covered. No short-lived scoped credentials brokered to agents and no documentation that secrets are kept out of model context. Personal API keys expire and can be revoked, but they are user keys for Arctic Wolf APIs, not agent credentials.

Research detail: Personal API keys are tied to the creating user's account and expire after a number of days set at creation, and they can be revoked. Arctic Wolf MFA recovery codes are not visible to Arctic Wolf. These cover credentials for Arctic Wolf APIs only, not credentials that agents use to reach other systems.

## Products

Personal API keys, Arctic Wolf authentication MFA

## Gaps

No documented brokering of scoped credentials to agents or keeping secrets out of model context. Credentials for Active Response integrations are described only at the integration page level.

## Options
