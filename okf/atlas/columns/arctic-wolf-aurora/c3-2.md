## Answer

Not covered. No gateway enforcing allowed tools, input formats, limits or blocks on dangerous actions for agent tool calls. Choosing which Active Response integrations to enable falls short of a tool call control point.

Last checked 17 November 2026.

Research detail: Customers decide which Active Response integrations and response actions are enabled, which limits what the vendor's agents can do to customer systems. The Assistant answers questions and does not itself run actions in other systems.
