## Answer

Not covered. No checks for look-alike names, poisoned descriptions or compromised packages. Changed MCP server tool definitions are retrieved at run time, and the vendor says configured tools are not updated automatically when a server changes.

Last checked 12 November 2026.

Research detail: No checks for tool squatting, metadata poisoning or compromised packages on third-party MCP servers are documented. Schema changes on a server are picked up automatically at run time.
