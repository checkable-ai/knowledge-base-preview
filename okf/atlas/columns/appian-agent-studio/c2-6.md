## Answer

Covered. Chat agent conversation history persists across sessions and users can pick up previous conversations. Process agents keep durable state in records via tools. The agent does not recall other sessions, users cannot delete history, and no retention period is stated.

Source statement: "Conversations are retained for audit purposes." (https://docs.appian.com/suite/help/26.9/conversation-persistence-chat-agents.html)

Last checked 12 November 2026.

Research detail: Conversation persistence keeps chat history across sessions so users can return to earlier conversations, and history is kept for audit. Process agents can also read and write record data as durable state through tools.
