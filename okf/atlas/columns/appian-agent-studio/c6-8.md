## Answer

Covered. Every save creates a version that can be viewed and reverted. Deployments move the latest version, with an optional review step for higher environments. Auto model selection can change the model without a new version. Tool and MCP server changes are versioned separately or not at all.

Source statement: "This allows you to review a full history of changes and revert to a previous configuration if needed." (https://docs.appian.com/suite/help/26.9/ai-agent-reference.html)

Last checked 12 November 2026.

Research detail: Every save creates an agent version that can be viewed and restored, and evaluations compare versions. Deployments move the latest version through packages and releases, with optional review for higher environments.
