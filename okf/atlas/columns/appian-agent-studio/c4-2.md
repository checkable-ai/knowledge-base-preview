## Answer

Not covered. Provider keys are masked and MCP connected systems hold API key or OAuth client credentials, but no short-lived scoped credentials, rotation, revocation or vault are documented, and the vendor does not state secrets are kept from the model.

Last checked 12 November 2026.

Research detail: Credentials for MCP servers are held in MCP connected systems using API key or OAuth 2.0 client credentials, and the agent calls tools through them without the secret entering the prompt. Admin Console provider keys are stored securely, masked after saving and never written to server logs.

<!-- chunk: products -->
## Products

MCP connected systems, AI Services provider credentials

<!-- chunk: gaps -->
## Gaps

No documented rotation, expiry or external vault for connected system credentials used by agents. Tool credentials are shared, not per user.

<!-- chunk: options -->
## Options

Use short-lived OAuth client credentials where the MCP server supports them and rotate API keys on a schedule.
