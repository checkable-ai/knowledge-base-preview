## Answer

Not covered. Sub-agents are invoked by the initiator with no distinct agent identities, mutual authentication, A2A support or trust boundary controls.

Last checked 12 November 2026.

Research detail: Agents can call other agents through the AI agent tool, and the sub-agent runs as the initiator and must respect its own access controls. External agents can call Appian agents enabled for Appian MCP Server, authenticated by user OAuth or a service account API key.

## Products

AI agent tool, Appian MCP Server

## Gaps

No A2A protocol support is documented. Multi-agent collaboration is advised to stay within two levels.

## Options
