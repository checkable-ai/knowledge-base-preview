## Answer

Not covered. AI agents run only on Appian Cloud, but no execution host, container, code interpreter or network configuration is documented or configurable.

Research detail: Appian manages the infrastructure for agents, including model hosting, tool execution and orchestration, on Appian Cloud. The AI service is multi-tenant with site-level controls and per-site signing keys.
