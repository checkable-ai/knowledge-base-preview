## Answer

Covered. Process agents run through the Execute AI Agent smart service. Retry and recovery after failure are handled in the process model by the customer. Agents cannot pause for input.

Source statement: "Appian automatically stops an AI agent run when it reaches the maximum number of 30 tool calls." (https://docs.appian.com/suite/help/26.9/ai-agent-reference.html)

Last checked 12 November 2026.

Research detail: Process agents run inside process models through the Execute AI Agent smart service, which returns success status, errors and AI actions for handling. Agents can call sub-agents, run up to five tool calls in parallel, and can be stopped by users or automatically cancelled after 30 tool calls.

<!-- chunk: products -->
## Products

Execute AI Agent smart service, AI agent tool, parallel tool execution

<!-- chunk: gaps -->
## Gaps

Agents cannot pause for input. Recovery after a failed run is left to the process model.

<!-- chunk: options -->
## Options

Use process model error paths and timers to retry or escalate failed agent runs.
