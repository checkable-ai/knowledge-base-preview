<!-- chunk: answer -->
## Answer

Covered. Chat agent conversations are persisted per user and agent and can be resumed. No retention setting is documented and users cannot clear history.

Source statement: "Other users cannot view, access, or share another user's conversation sessions." (https://docs.appian.com/suite/help/26.9/conversation-persistence-chat-agents.html)

Research detail: Chat agent conversations are stored as sessions tied to one user and one agent, and the agent keeps context across turns. Users can switch between and resume sessions, and other users cannot view them.

## Products

Agent chat component conversation persistence

<!-- chunk: gaps -->
## Gaps

Users cannot clear history and no retention setting is documented. Sessions do not move with deployments.

## Options

Confirm retention needs with Appian before storing sensitive chat content.
