## Answer

Covered. Agents are created in Appian Designer by developers with object permissions, once an admin enables a supported model. Changes create versions, deployments move the latest version between environments, and object security controls edit and delete rights. Retirement is deletion subject to impact analysis. No lifecycle states.

Source statement: "Each time you save, you create a new AI agent version." (https://docs.appian.com/suite/help/26.9/deploy-ai-agents.html)

Last checked 12 November 2026.

Research detail: AI agents are design objects created in Appian Designer by developers with the right object permissions, once an administrator enables a supported model. Changes create new versions, deployments move agents between environments, and object security controls who can edit or delete them.

<!-- chunk: products -->
## Products

AI agent design object, object security, deployments

<!-- chunk: gaps -->
## Gaps

Agent permissions are inherited from the initiator, so provisioning controls what the agent can call but not a separate agent principal.

<!-- chunk: options -->
## Options

Restrict agent Administrator rights to a small group and require deployment review for production.
