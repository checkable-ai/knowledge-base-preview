## Answer

Not covered. Agent pairs are wired per agent through the AI agent tool, with no central policy of approved pairs or schema enforcement.

Research detail: Which agents may call which is set by adding an AI agent tool to the parent agent, and the initiator needs access to the sub-agent. External agents reach Appian agents only if MCP Server access is enabled on the agent and the caller has permission.
