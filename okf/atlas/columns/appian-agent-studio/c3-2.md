## Answer

Not covered. Per-agent tool allow-listing and a 30 tool call cap exist, but no rate limits, screening of dangerous actions, input format enforcement or egress control for MCP servers.

Last checked 12 November 2026.

Research detail: Tool access is enforced per agent through the Tools tab, object security and connected system permissions, with a 30 tool call cap. Guardrails can block malicious code in model content.

## Products

## Gaps

Appian does not rate limit MCP tool calls, does not screen tool calls for dangerous actions and has no documented egress control for MCP servers.

<!-- chunk: options -->
## Options

Allow only vetted MCP connected systems and limit MCP tools to named tools per agent.
