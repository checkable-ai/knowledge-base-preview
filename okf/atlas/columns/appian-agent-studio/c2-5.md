## Answer

Covered. Appian runs the agent loop for system, custom, AI agent and MCP tools. Parallel tool calls, a 30 tool call cap, a 30 minute process model tool timeout, and a 60 minute AI agent tool timeout are documented. The harness is closed and cannot be replaced.

Source statement: "Each reasoning step supports a maximum of five parallel tool calls." (https://docs.appian.com/suite/help/26.9/ai-agent-reference.html)

Last checked 12 November 2026.

Research detail: Appian runs the agent loop, sends tool definitions to the model, executes system, custom, AI agent and MCP tools, and returns results. It applies parallel calls, timeouts, the 30 tool call limit and automatic prompt caching.
