## Answer

Covered. Query Records and data fabric queries are filtered for the initiator. Query Records reaches only assigned record types. AI guardrails can block or mask PII when enabled. Guardrails are disabled by default, capped at 10 per environment, and do not cover Enterprise Copilot.

Source statement: "Every query is filtered by record-level and field-level security." (https://docs.appian.com/suite/help/26.9/ai-agent-reference.html)

Last checked 12 November 2026.

Research detail: Every data fabric query by an agent is filtered by record-level and field-level security for the initiator, and Query Records only reaches record types assigned to the agent. Once an administrator enables them, AI guardrails can mask or block PII such as SSNs, card numbers and emails in inputs and outputs.

<!-- chunk: products -->
## Products

Data fabric security, Query Records, AI guardrails

<!-- chunk: gaps -->
## Gaps

Record types with security expressions are excluded from Query Records. Guardrails must be enabled and do not cover Enterprise Copilot.

<!-- chunk: options -->
## Options

Replace security expressions with security rules and enable PII guardrails.
