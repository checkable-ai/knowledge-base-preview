## Answer

Not covered. No approval step that pauses an agent run for a human to approve an exact proposed action. Agents run autonomously and cannot pause mid-execution for human input. Chat agents wait for user input only between responses. Process designs can escalate or route output to review, but the vendor describes this as built in the process model rather than a native approval. No denial or replay handling. The Composer approval in 26.7 applies to Composer, not to agents.

Research detail: Process agents cannot pause mid-run for human input. Approval is built around the agent, for example by routing the agent's output to a user task in the process model before a write, or by stopping the agent and escalating to a human queue.

## Gaps

No native approval bound to an exact proposed tool call, and no denial or replay handling inside a run. Release notes from 25.4 to 26.9 add none.

<!-- chunk: options -->
## Options

Keep write actions out of agent tools and apply them in a later process step after a user task approves the agent's proposal.
