## Answer

Covered, with conditions. The capabilities described on the page are included in Appian's advanced and premium capability tiers. Usage limits may apply. Process model tools can do whatever the underlying process does, so the scope of actions depends on process design.

Source statement: "Start small by enabling only the tools the AI agent truly needs." (https://docs.appian.com/suite/help/26.9/create-and-configure-ai-agent.html)

Last checked 12 November 2026.

Research detail: Tools must be added to each agent, and since 26.8 new agents start with no tools enabled. The initiator needs at least viewer permission on every tool, Query Records is read-only and limited to assigned record types, and MCP tools are chosen individually per agent.

## Gaps
