## Answer

Not covered. Agents are versioned design objects, but have no separate identity or principal and run as the initiator. Owners are groups in object security role maps, not an accountable person.

Last checked 12 November 2026.

Research detail: Each AI agent is a design object with its own identifier and a new version on every save, and each run in the Monitor tab records the agent name, version and initiator. Write Records nodes can tag record events with the AI Agent automation type. Object security role maps name the groups that administer the agent.

## Products

AI agent design object, versions, Monitor tab

## Gaps

Agents run as the initiating user and have no separate workload identity. Owners are groups in a role map rather than an accountable person.

<!-- chunk: options -->
## Options

Name an owner group per agent and check that Monitor and audit entries tie each run to the agent version.
