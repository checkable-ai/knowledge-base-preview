## Answer

Covered, with conditions. Provider and model are chosen per agent, with Auto or a specific model. Admins enable models and processing regions. Data stays in region unless cross-region processing is selected. Auto picks the latest enabled model at run time, so the exact model version can change without a new agent version. Cross-provider fallback is not documented.

Source statement: "Appian does not use your data to train or improve underlying AI models." (https://docs.appian.com/suite/help/26.9/security-compliance.html)

Research detail: Developers choose a provider and either Auto or a specific model per agent. Administrators enable models and processing regions in the Admin Console, and can connect their own AWS, Azure, Google Cloud or custom gateway providers. Appian states data stays in region unless cross-region processing is chosen and is not used for training.
