## Answer

Not covered. The hosted API offers only account API keys, with no documented scoped, short-lived or automatically expiring credentials for agents. DeepSeek Harness resolves credentials per request from environment-variable references and can remove a local grant, but the docs give no token lifetime or rotation schedule. They also never state that this feature meets part of the outcome or that secrets are kept out of model context. Harness is a developer preview with no security audit.

Research detail: DeepSeek Harness keeps secrets out of configuration: settings carry environment-variable references and providers resolve the value once per operation, so a rotated key reaches the next request. The describe call reports source and writability without returning the value. The MCP stdio bridge strips credential-like and DSH_* variables before launching a child. The hosted API offers only account API keys that the terms say the customer must keep secure.

## Products

DeepSeek Harness credentials seam, MCP stdio bridge

## Gaps

No scoped, expiring or revocable API keys documented for the API. Harness rotation relies on the operator changing the variable. Developer preview without a security audit.

<!-- chunk: options -->
## Options

Broker DeepSeek API keys through a secrets manager or gateway with short-lived credentials, and keep keys out of agent workspaces.
