## Answer

Partly covered. Network and process visibility are outside the sandbox modes. No security audit or isolation guarantee.

Source statement: "SandboxMode governs filesystem effects only." (https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/subsystems/sandbox.md)

Research detail: DeepSeek Harness sandbox modes read-only, workspace-write and danger-full-access govern file effects of shell processes using bwrap or Landlock on Linux, Seatbelt on macOS and a restricted-token ACL backend on Windows. The default mode is read-only and the backend reports whether enforcement is full or partial. Permission presets pair a sandbox mode with an approval policy.
