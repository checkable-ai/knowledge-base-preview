## Answer

Not covered. No network egress restriction in the Harness sandbox and no hosted code execution. Sandbox confines files only.

Research detail: DeepSeek Harness runs on the user's own host and confines shell processes with OS sandbox backends. Outbound model calls, web search, page fetches and HTTP MCP servers follow the standard proxy environment variables, and the harness refuses to start if a repository .env tries to set them. The API offers no hosted code execution and marks code_execution_tool_result as not supported.
