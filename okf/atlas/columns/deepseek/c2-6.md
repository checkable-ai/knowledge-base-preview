## Answer

Not covered. No first-party long-term memory with access control or retention. Session logs and third-party memory MCP configurations that DeepSeek does not support fall short.

Research detail: DeepSeek Harness persists every session log so sessions can be listed and reopened, and optional session query tools search past sessions. Long-term memory is only available through default-off reference configurations for third-party memory MCP servers, which DeepSeek says it does not endorse or support.
