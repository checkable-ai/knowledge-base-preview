## Answer

Not covered. No per-agent tool allowlist, rate limits, injection screening or egress filtering. Harness hooks and guards and API strict mode fall short of a gateway.

Research detail: DeepSeek Harness runs every tool call through pre-execute hooks, permission checks, sandbox, guards and an approval prompt, with around-dispatch timeouts and post-execute hooks that can block or replace results. Strict mode on the API validates function JSON Schemas. When used through the Anthropic endpoint, web search is executed by DeepSeek's API.
