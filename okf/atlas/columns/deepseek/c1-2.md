## Answer

Not covered. No per-server or per-system scope model, allowlist of remote actions or downstream authorisation. Generic permission and guard checks in Harness fall short.

Research detail: In DeepSeek Harness, MCP server tools run as ordinary harness tools with permission checks, and every tool call passes through a pre-execute waterfall of hooks, permission and registered guards that can deny it. Approval policy can be set to ask or never per session.
