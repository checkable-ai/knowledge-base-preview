## Answer

Covered. DeepSeek Harness only, developer preview with no security audit. Hosted API has no approval feature.

Source statement: "allowed-once grants only the asked-about action; callers deny on rejected, cancelled, and unavailable." (https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/subsystems/approval.md)

Research detail: DeepSeek Harness approval issues a fresh request ID per ask, attaches the prompt to the exact streamed tool call by callId, and returns closed outcomes where only allowed-once grants the single asked action. Rejected, cancelled and unavailable outcomes fail closed, a never policy rejects before any answerer runs, and approval/asked and approval/decided events are appended to the session log.
