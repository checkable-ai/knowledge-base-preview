## Answer

Not covered. Agent Teams mailbox and subagent seam work within one harness host and document no authentication or authorisation between agents.

Research detail: DeepSeek Harness has an experimental Agent Teams domain where teammates exchange messages through a durable mailbox that records sender and target session IDs, and a subagent seam that can delegate to in-process, ACP, Codex or Claude Code providers. This works inside one harness host.
