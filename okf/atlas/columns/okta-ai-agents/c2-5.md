Covered. MCP tool calls only; remote MCP servers must be publicly reachable and accept OAuth 2.0 bearer tokens; cloud-only, no self-hosting.

Research detail: No tool execution harness is provided. Agent Gateway proxies MCP tool calls but does not run tools.
