## Answer

Not covered. No central data gateway and no data loss prevention, content inspection or redaction. Auth0 FGA for RAG filters retrieved documents inside the customer's own retriever, which is a building block only.

Last checked 15 November 2026.

Research detail: Auth0 for AI Agents documents Auth0 FGA for RAG, applying document-level and relationship-based access checks so retrieval returns only data the user may see.
