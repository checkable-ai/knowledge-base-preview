## Answer

Not covered. Agent registration gives each agent a record, owners, credentials and a linked OIDC app, but no documented binding of identity to where it runs or to a specific release or version.

Research detail: Registering an agent creates a workload principal record in Universal Directory alongside human identities, with owners, credentials and an optional linked OIDC app. Custom agents are registered manually and builder platform agents are imported. The Agent Gateway attributes tool calls to the agent's workload principal regardless of credential rotation.
