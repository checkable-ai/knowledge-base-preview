<!-- chunk: answer -->
## Answer

Covered. Agent Gateway only, with OAuth 2.0 bearer upstreams. Revoked agent tokens stay valid at the gateway until they expire, so revocation is not immediate.

Source statement: "As a result, the AI agent never holds or sees the credentials for the tools that it uses." (https://developer.okta.com/docs/concepts/agent-gateway/)

Research detail: Agent Gateway obtains downstream OAuth tokens by STS token exchange and injects them, so the agent never holds tool credentials. Resource connections can hand out secrets and service accounts vaulted in Okta Privileged Access by resource indicator. Auth0 Token Vault stores connected account tokens and refreshes and exchanges them without user action.

<!-- chunk: products -->
## Products

Agent Gateway, resource connections with Okta Privileged Access, Auth0 Token Vault

<!-- chunk: gaps -->
## Gaps

Revoked agent tokens stay valid at the gateway until expiry. Rotation of vaulted secrets and Token Vault encryption are not described on the pages read. The gateway only supports upstreams that accept OAuth bearer tokens.

<!-- chunk: options -->
## Options

Set short token lifetimes, test revocation latency end to end, and use Okta Privileged Access rotation for static secrets.
