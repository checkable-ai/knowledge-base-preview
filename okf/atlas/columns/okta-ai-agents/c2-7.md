## Answer

Not covered. No limits on agent files, processes or network access. The Okta kill switch and Permiso's identity-layer kill switch revoke access, but tokens already issued can stay valid until expiry, so access is not cut at once.

Research detail: Okta documents a manual kill switch: disable the AI agent record, its linked application and its authorisation server, after which the agent cannot obtain new tokens. Existing tokens stay valid until expiry unless an administrator revokes them separately, and there are no automatic behavioural triggers yet. Agent Gateway enforces identity and policy on every MCP tool call. Okta does not sandbox agent execution or control network egress.
