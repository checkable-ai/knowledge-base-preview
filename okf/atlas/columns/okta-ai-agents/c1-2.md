## Answer

Covered. Applies to resources configured as resource connections (authorization servers, apps, other agents).

Source statement: "The resource appears on the Resource connections tab." (https://help.okta.com/oie/en-us/content/topics/ai-agents/ai-agent-connected-resource.htm)

Research detail: Resource connections bind an agent to authorisation servers, apps, MCP servers, secrets, service accounts or other agents, with scopes set to allow all, only allow or disallow. Deactivating a connection denies all further access requests to that resource. Agent Gateway exposes only admin-selected tools per virtual MCP server.
