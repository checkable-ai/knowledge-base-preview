## Answer

Covered. Shows resources connected through Okta; access via credentials outside Okta is visible only if discovered by ISPM.

Source statement: "The resource appears on the Resource connections tab." (https://help.okta.com/oie/en-us/content/topics/ai-agents/ai-agent-connected-resource.htm)

Research detail: Each agent's resource connections tab lists the gateways, apps, MCP servers, secrets and agents it can reach with their scopes. The ISPM dashboard shows agent counts, agent risk and a graph linking owners to connected tools, and Okta for AI Agents maps the resources an agent can reach.
