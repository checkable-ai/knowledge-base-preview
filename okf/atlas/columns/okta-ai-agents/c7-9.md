## Answer

Covered, with conditions. Okta for AI Agents - Core SKU excludes Identity Security Posture Management, so a SKU that includes ISPM is needed. Browser shadow AI discovery uses the Secure Access Monitor (SAM) plugin. Locally running agents and MCP servers are surfaced through CrowdStrike Falcon, a separate product. Browser discovery uses the Secure Access Monitor (SAM) plugin and is listed as Early Access. Endpoint discovery requires CrowdStrike Falcon and is listed as Early Access.

Source statement: "ISPM finds shadow AI agents, and lets you assess the risk each one poses." (https://help.okta.com/oie/en-us/content/topics/ai-agents/ai-agent-discover.htm)

Last checked 15 November 2026.

Research detail: ISPM discovers shadow agents through the Secure Access Monitor browser plugin, CrowdStrike Falcon on endpoints, and builder platforms including Agentforce, Copilot Studio and Bedrock AgentCore. It also detects OAuth grants and MCP servers, and discovered agents can be registered or imported into Universal Directory.
