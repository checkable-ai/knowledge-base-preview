## Answer

Not covered. Access Requests and Access Reviews approve access grants and review decisions, not the exact agent action before it runs. No binding to a proposed action or replay handling is documented.

Last checked 17 November 2026.

Research detail: Access Requests route requests to approvers who approve, reject or ask for more information, with multi-step approvals set by policy. Veza's own Access Agents expose any state-changing step as an action button so nothing changes until the user selects it.
