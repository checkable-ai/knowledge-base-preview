## Answer

Covered. Work supports one-off, scheduled, event-triggered and monitor tasks. Event triggers are off by default in Enterprise and Edu. Retry policy is not configurable.

Source statement: "Work Cloud uses the Codex task-execution harness." (https://learn.chatgpt.com/docs/enterprise/chatgpt-work-cloud-security)

Research detail: ChatGPT Work runs multi-step tasks once, on a schedule, on an event trigger or as a monitor, and users can change direction mid-task. Workspace agents run on schedules, from Slack or through an API trigger. Synced Work tasks fall back to a cloud container when the connected computer is offline. Event-triggered tasks are off by default in Enterprise and Edu.

<!-- chunk: products -->
## Products

ChatGPT Work, Scheduled Tasks, workspace agents

<!-- chunk: gaps -->
## Gaps

Retry policy and workflow definitions are not customer configurable. A running turn does not move between local and cloud.

<!-- chunk: options -->
## Options

Pilot scheduled and event-triggered tasks with a limited role before wider rollout.
