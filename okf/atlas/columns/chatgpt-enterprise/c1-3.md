## Answer

Covered. Approval policies are admin-constrained. Agent builders can set some write actions to Never ask.

Source statement: "Codex asks for approval to edit files outside the workspace or to run commands that require network access." (https://learn.chatgpt.com/docs/agent-approvals-security)

Research detail: App permissions set when ChatGPT asks before reading or changing data, and workspace agent write actions default to Always ask. Codex browser approvals last one turn or one thread and cannot override admin restrictions. Cloud browser asks for confirmation in chat before consequential actions such as payments or bookings.

<!-- chunk: products -->
## Products

App permissions, workspace agent write approvals, Codex approval policies and browser approvals, cloud browser confirmations

<!-- chunk: gaps -->
## Gaps

Binding of an approval to the exact action and replay handling are not documented. Agent builders can set some write actions to Never ask. Spoken approval is not supported.

<!-- chunk: options -->
## Options

Enforce allowed approval policies in Agent Security and restrict Never ask through review of published agents.
