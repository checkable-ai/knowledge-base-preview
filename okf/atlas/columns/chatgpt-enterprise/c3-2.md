## Answer

Covered. Admins control apps, MCP servers, plugins, command rules and hooks via Agent Security. Per-tool rate limits not documented.

Source statement: "Requirements set limits that users cannot override." (https://learn.chatgpt.com/docs/enterprise/agent-security)

Research detail: Admins choose which apps, plugins and MCP servers each role can use and which actions they can take. Agent Security requirements govern apps, MCP servers, plugins, command rules and managed hooks for Work and Codex. Browser Use site rules can default to Block with Allow exceptions, and Computer Use app rules work the same way. Approved custom MCP servers run against a frozen tool snapshot.

<!-- chunk: products -->
## Products

Plugins and app controls, Agent Security requirements, Browser Use site rules, custom MCP frozen snapshot

<!-- chunk: gaps -->
## Gaps

Hook errors or timeouts can fail without blocking the tool. Per-tool quota and rate limits are not documented. Tool-call injection screening is not customer configurable.

<!-- chunk: options -->
## Options

Set browser default to Block, allowlist MCP servers in requirements and test hook failure behaviour.
