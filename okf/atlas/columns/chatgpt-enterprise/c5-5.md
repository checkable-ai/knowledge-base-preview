## Answer

Not covered. Plugin role access, installation policy and the Admin Console agent area show pieces of reach, but the vendor documents no readable view that joins each agent with its downstream systems and permitted actions. Locally configured MCP servers are not listed.

Research detail: Admin Console lists each workspace agent with its connected apps, memory files and schedules. The Plugins page shows each app's role access, actions and permissions. External access shows which members are connected to each external application. Enterprise only for the updated Admin Console.
