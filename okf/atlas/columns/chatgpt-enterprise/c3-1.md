## Answer

Covered. Role model access and usage limits on Enterprise and Edu. Prisma AIRS prompt screening covers Codex only and needs enablement and a Palo Alto licence. No routing to other endpoints.

Source statement: "Codex sends newly submitted prompt text to the configured Prisma AIRS endpoint for inspection." (https://learn.chatgpt.com/docs/enterprise/prisma-airs)

Research detail: Model access is enforced per role, and usage limits apply per user through workspace, group and individual settings with budgets and alerts. Enterprise admins can connect Prisma AIRS as an external guardrail that scans Codex prompts for DLP and prompt injection before they reach the model.
