## Answer

Covered. Personal app connections use the user's permissions. Agent-owned or shared connections act with the owner's permissions.

Source statement: "A personal connection uses the connected employee's permissions in the source system." (https://learn.chatgpt.com/docs/enterprise/chatgpt-work-cloud-security)

Research detail: Apps run with each end user's own authenticated account, and ChatGPT respects the source system's permissions. Workspace agent builders choose per app between end-user account and agent-owned account authentication. Available on Business and Enterprise.

<!-- chunk: products -->
## Products

Apps and plugins, workspace agents end-user authentication

<!-- chunk: gaps -->
## Gaps

Agent-owned or shared connections act with the connection owner's permissions, not the caller's. Agents deployed to Slack must use shared connections. Propagation of user identity to custom MCP servers depends on the server's OAuth set-up.

<!-- chunk: options -->
## Options

Restrict agent publishing with agent-owned connections by RBAC and require service accounts for shared connections.
