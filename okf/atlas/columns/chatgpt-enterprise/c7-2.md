## Answer

Not covered. The Compliance API page documents streaming events to a SIEM but does not say which user or conversation identifiers are included or how sensitive content is redacted. Codex OTel redacts prompts by default and carries a conversation id, but the docs list no user identifier.

Research detail: Compliance Platform logs feed SIEM and DLP tools, with named partners including CrowdStrike, Microsoft Purview, Netskope and Palo Alto Networks. Local Work execution emits OpenTelemetry events to a customer collector. Admin keys can be scoped to audit, authentication or app log categories, and Compliance API traffic is always IP allowlisted.

<!-- chunk: products -->
## Products

Compliance Platform, OTel events, Admin keys, IP allowlisting

<!-- chunk: gaps -->
## Gaps

No native detections or response workflow. Redaction is left to the receiving tool.

<!-- chunk: options -->
## Options

Create a least-privilege Admin key for the SIEM and configure an OTel collector for desktop Work.
