## Answer

Covered. Scoped tokens must expire and can be rotated and revoked. Codex Cloud network secrets and cloud browser secure sign-in keep secrets from the model. Codex environment variables are passed directly.

Source statement: "Scoped personal access tokens must expire." (https://learn.chatgpt.com/docs/enterprise/access-tokens)

Research detail: Codex Cloud network secrets give programs a placeholder while the proxy substitutes the real credential for allowed HTTPS destinations. Cloud browser sign-in uses a secure form whose credentials are not visible to the model. Service account and Admin key tokens have expiries, rotation guidance and revocation. App connections use OAuth handled by ChatGPT.

<!-- chunk: products -->
## Products

Codex Cloud network secrets, cloud browser secure sign-in, service account tokens, Admin keys

<!-- chunk: gaps -->
## Gaps

Codex environment variables are passed to programs directly. Agent-owned app connections hold a shared credential. Admin keys can be created with no expiry.

<!-- chunk: options -->
## Options

Use network secrets rather than environment variables and set finite token lifetimes as policy.
