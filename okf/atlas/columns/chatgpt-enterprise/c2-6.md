## Answer

Covered. Memory is controlled through account and workspace memory settings, managed per role in Enterprise. Local Codex memories are off by default and stored on the user's machine. Deleting a conversation does not necessarily delete a saved memory.

Source statement: "Memories let ChatGPT and Codex carry useful context from earlier work into future work." (https://learn.chatgpt.com/docs/customization/memories)

Research detail: Memory is managed per role through Use shared memory and Use improved memory. Memory is stored in-region under data residency. Admins can review workspace agent memory files in Admin Console.

<!-- chunk: products -->
## Products

Memory, Permissions & roles, workspace agent memory files

<!-- chunk: gaps -->
## Gaps

Deleting a chat does not delete a saved memory. Improved memory is unavailable with UAE inference residency and off by default in regulated workspaces.

<!-- chunk: options -->
## Options

Decide memory settings per role and tell members how to delete saved memories.
