## Answer

Not covered. The managed configuration MCP allow list restricts which MCP servers run, but no SBOMs, scanning or review of CLIs, skills, extensions, external services or egress is documented. Custom apps are not verified by OpenAI.

Research detail: OpenAI reviews apps in its approved registry and red-teams write actions. Admins test custom MCP servers privately and publish them, after which tool definitions are frozen and later changes are shown as a diff with new actions disabled. Desktop app builds can be pinned through MDM, and browser extensions are controlled with Chromium policies.

<!-- chunk: products -->
## Products

Approved app registry, custom MCP publish and refresh, MDM app updates, desktop browser extension policies

<!-- chunk: gaps -->
## Gaps

No SBOM for apps, plugins, CLIs or extensions is documented. Custom apps are not verified by OpenAI. Admins are not notified when a server changes.

<!-- chunk: options -->
## Options

Vet custom MCP servers before publishing and pin desktop app builds through MDM.
