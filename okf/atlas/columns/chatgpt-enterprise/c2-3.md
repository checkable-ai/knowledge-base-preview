## Answer

Covered, with conditions. Capabilities and controls depend on the workspace plan, rollout, configuration, and connected integration. Data residency and inference residency cover only eligible content and supported workloads, regions, and configurations. Work is not supported with UAE inference residency. Work Cloud runs only on OpenAI-managed infrastructure; customers cannot host it.

Source statement: "Work Cloud runs on shared, OpenAI-managed infrastructure." (https://learn.chatgpt.com/docs/enterprise/chatgpt-work-cloud-security)

Last checked 13 November 2026.

Research detail: Work Cloud runs tasks in VM-backed sandboxes on OpenAI-managed shared infrastructure, and Codex Cloud runs in published environments with their own internet settings. Local Work and Codex run under the client sandbox on the user's computer. Customers do not host the cloud containers.

<!-- chunk: products -->
## Products

Work Cloud, Codex Cloud environments, local sandbox

<!-- chunk: gaps -->
## Gaps

No dedicated host per customer. Codex Web is not eligible for data residency.

<!-- chunk: options -->
## Options

Decide per role whether Work Cloud, Work Local, Codex Local and Codex Cloud are enabled.
