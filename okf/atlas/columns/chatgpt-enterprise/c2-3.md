## Answer

Covered. Cloud tasks run on OpenAI-managed shared infrastructure. Local work runs in the client sandbox. No customer-hosted option.

Source statement: "Public internet access for code or shell execution follows its own network policy." (https://learn.chatgpt.com/docs/enterprise/chatgpt-work-cloud-security)

Research detail: Work Cloud runs tasks in VM-backed sandboxes on OpenAI-managed shared infrastructure, and Codex Cloud runs in published environments with their own internet settings. Local Work and Codex run under the client sandbox on the user's computer. Customers do not host the cloud containers.

<!-- chunk: products -->
## Products

Work Cloud, Codex Cloud environments, local sandbox

<!-- chunk: gaps -->
## Gaps

No dedicated host per customer. Codex Web is not eligible for data residency.

<!-- chunk: options -->
## Options

Decide per role whether Work Cloud, Work Local, Codex Local and Codex Cloud are enabled.
