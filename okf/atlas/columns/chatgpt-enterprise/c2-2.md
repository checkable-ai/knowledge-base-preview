<!-- chunk: answer -->
## Answer

Covered, with conditions. GPT-6 Sol and GPT-6 Luna are off by default in Enterprise workspaces and need admin enablement. Astra is off by default in eligible Enterprise and Edu workspaces. Data and inference residency apply only to eligible content and supported regions; Work is not supported with UAE inference residency. Codex cloud does not support changing its default model.

Source statement: "Workspace owners and admins can configure separate starting defaults for Chat and for Work and Codex." (https://learn.chatgpt.com/docs/enterprise/workspace-model-availability)

Last checked 13 November 2026.

Research detail: Owners control which models each role can use, and Model Test shows a member's effective model access. Business data is not used for training by default. Enterprise and Edu workspaces can add inference residency in Europe, the United States or the UAE.

<!-- chunk: products -->
## Products

Models page and Model Test, RBAC model access, inference residency

<!-- chunk: gaps -->
## Gaps

Australia is a data residency region but not an inference residency region. Explicit model version pinning is not documented beyond the picker and legacy model access.

<!-- chunk: options -->
## Options

Record the approved models per role and check them with Model Test after each model launch.
