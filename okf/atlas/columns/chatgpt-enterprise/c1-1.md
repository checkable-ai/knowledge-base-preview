## Answer

Covered. Local computer access is a separate opt-in for Work and Codex. Only approval policies and web search modes have dedicated UI controls; other fields are configured through TOML in requirements.toml.

Source statement: "Local: adjust supported execution settings for work that runs on a connected computer." (https://learn.chatgpt.com/docs/enterprise/agent-security)

Research detail: Agent Security policies set requirements and defaults for local execution by ChatGPT Work and Codex: sandbox modes, filesystem permission profiles, command rules and managed networking. Computer Use can be disabled or limited to named applications, and Browser Use features can be turned off. Requirements cannot be overridden by members.
