## Answer

Covered. Agent Security policies for ChatGPT Work and Codex local execution. Browser and computer use controls documented for Enterprise.

Source statement: "Requirements set limits that users cannot override." (https://learn.chatgpt.com/docs/enterprise/agent-security)

Research detail: Agent Security policies set requirements and defaults for local execution by ChatGPT Work and Codex: sandbox modes, filesystem permission profiles, command rules and managed networking. Computer Use can be disabled or limited to named applications, and Browser Use features can be turned off. Requirements cannot be overridden by members.
