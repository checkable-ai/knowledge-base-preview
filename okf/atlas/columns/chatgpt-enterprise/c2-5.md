## Answer

Covered. Cloud harness is OpenAI managed. Many Agent Security fields are TOML only.

Source statement: "Work Cloud uses the Codex task-execution harness." (https://learn.chatgpt.com/docs/enterprise/chatgpt-work-cloud-security)

Research detail: Work Cloud uses the Codex task-execution harness, and Codex runs in the desktop app, CLI and cloud. Admins configure the harness through Agent Security: orchestrator controls such as approvals, web search, apps, MCP servers, plugins, command rules and managed hooks sit in Global, with execution overrides per environment.
