## Answer

Covered. Managed network allow and deny rules plus sandbox modes. Disabling a service account revokes all tokens. No workspace-wide stop for a single running task. Settings changes can take minutes.

Source statement: "An Allow does not bypass a different matching Deny, such as an inherited wildcard." (https://learn.chatgpt.com/docs/enterprise/agent-security)

Research detail: Agent Security enforces sandbox modes and a managed network allowlist with deny rules, and a deny-only policy blocks the rest of the internet. Work Cloud code and shell networking has its own public internet switch. Admins can turn off features, and turning off local work sync interrupts running turns. Disabling or deleting a service account revokes all its tokens.

<!-- chunk: products -->
## Products

Agent Security networking, Codex Cloud internet settings, Work Cloud network access, service account disable

<!-- chunk: gaps -->
## Gaps

Approved full sandbox escalation can bypass the command proxy. RBAC changes take up to 5 minutes. No admin control documented to stop a single running task across the workspace. Network setting changes apply after the current command finishes.

<!-- chunk: options -->
## Options

Block full sandbox escalation in requirements and test an allowed and a blocked request.
