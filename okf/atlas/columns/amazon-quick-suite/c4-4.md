## Answer

Last checked 17 November 2026.

Research detail: Quick supports agent-to-agent connectors, with Snowflake Cortex Agent, Adobe Marketing Agent and Visier Agent listed among the supported external connectors, and authentication is chosen per connector. The AWS Agent Registry integration does not support A2A descriptors, and no cross-agent trust model beyond connector authentication is described.
