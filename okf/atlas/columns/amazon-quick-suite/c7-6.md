## Answer

Not covered. No scanning for look-alike names, poisoned tool descriptions or compromised packages. The AWS Agent Registry integration surfaces a single registry of remote MCP servers (same account and Region, IAM authorization) but does not scan them.

Last checked 17 November 2026.

Research detail: The Agent Registry integration lets an administrator link one registry of remote MCP servers so Quick users get governed access to a single source of truth, and records are read live from the registry. Tools reach the assistant only through integrations an administrator creates.

<!-- chunk: products -->
## Products

AWS Agent Registry integration, administrator-created integrations

<!-- chunk: gaps -->
## Gaps

No scanning for squatting, tool metadata poisoning or package compromise is documented. Only same account, same Region registries with IAM authorisation are supported.

<!-- chunk: options -->
## Options

Curate the registry and review each MCP server before linking.
