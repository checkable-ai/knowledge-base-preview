## Answer

Out of scope. The containers, hosts and agent runtime that run Quick's models and tools are operated by AWS under the shared responsibility model and are not exposed for customers to harden or scan. The documented code-execution sandboxes are built-in isolation properties, not a customer hardening and scanning capability.

Research detail: Documented runtime controls are sandboxed code execution on each surface, a sandboxed iframe for apps, encryption in transit with TLS 1.2 required and FIPS endpoints. Quick runs in AWS-managed infrastructure.
