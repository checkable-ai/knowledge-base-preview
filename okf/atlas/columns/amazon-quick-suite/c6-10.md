## Answer

Covered, with conditions. Stored data stays in the account's primary Region. AI inference runs in Regions within a defined geography (United States, Europe, Australia, Japan or Singapore) and cross-Region inference cannot be disabled. Chat memory is not supported for accounts configured with AWS KMS customer managed keys. Agentic features vary by Region.

Source statement: "Documents uploaded through the chat interface are deleted with the associated conversation after 90 days of inactivity." (https://docs.aws.amazon.com/quick/latest/userguide/using-quick-chat.html)

Last checked 17 November 2026.

Research detail: Stored data stays in the primary Region, AI inference stays within a chosen geography, chat uploads are deleted after 90 days of inactivity, users can delete memories and unsubscribing permanently deletes all data. Customer data is not used to train models, and user removal paths define what happens to assets.

<!-- chunk: products -->
## Products

Regional storage, cross-Region inference geography, user lifecycle paths, memory deletion

<!-- chunk: gaps -->
## Gaps

Retention periods are fixed and not configurable. Conversation history for removed users depends on the removal path.

<!-- chunk: options -->
## Options

Select the primary Region and geography and set an offboarding procedure.
