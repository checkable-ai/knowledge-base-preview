## Answer

Covered, with conditions. MCP integration requires an Enterprise subscription. Only remote MCP servers are supported, and private servers need a Quick VPC connection.

Source statement: "After discovery completes, each tool is listed as an action that you can review and turn on." (https://docs.aws.amazon.com/quick/latest/userguide/mcp-integration.html)

Last checked 17 November 2026.

Research detail: MCP tools are discovered and then listed as actions that an administrator reviews and turns on. Per-connector Create, Share and Use permissions and custom permissions apply per user and role, and authentication is configured per connector. Only remote MCP servers are supported and private ones need a VPC connection.

<!-- chunk: products -->
## Products

MCP tool enablement, connector permissions, VPC connection

<!-- chunk: gaps -->
## Gaps

No quotas or rate limits per tool, no schema enforcement and no dangerous action filtering are documented. Quick does not judge the trustworthiness of MCP servers or their tools.

<!-- chunk: options -->
## Options

Enable only needed tools and place an external gateway in front of high-risk servers.
