## Answer

Not covered. No agent behaviour baseline, continuous validation of agent behaviour or anomaly detection is documented. Chat and feedback logs, analytics, CloudWatch alarms and built-in prompt-attack screening fall short: the vendor describes logging as after-the-fact visibility and states the service has no real-time alerting of its own.

Last checked 17 November 2026.

Research detail: Quick provides analytics on usage, adoption, feedback and selected security-related insights, user feedback on chat responses can be delivered to logs, and CloudWatch alarms can be set on metrics. Built-in screening checks requests for prompt attacks.
