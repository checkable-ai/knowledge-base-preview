## Answer

Covered, with conditions. Tool access levels apply to Quick on desktop. Restricting capabilities through custom permissions requires an Enterprise subscription.

Source statement: "Changes take effect immediately, in existing and new conversations and agent runs." (https://docs.aws.amazon.com/quick/latest/userguide/system-tools-desktop.html)

Last checked 17 November 2026.

Research detail: Code runs in sandboxes, web chat and Quick Apps have no direct internet access, tools can be set to Always deny, and IP and VPC rules block other traffic. Revoking access to the customer managed KMS key locks down the data, and removing a user from the directory group ends sign-in.

<!-- chunk: products -->
## Products

Sandboxes, Always deny access level, KMS key revocation, directory deactivation

<!-- chunk: gaps -->
## Gaps

No deterministic stop for a running agent or automation is documented. Egress control for connectors rests on connector configuration.

<!-- chunk: options -->
## Options

Document a runbook for disabling connectors, deactivating users and revoking keys.
