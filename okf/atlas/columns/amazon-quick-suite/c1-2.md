## Answer

Covered, with conditions. MCP integrations require an Enterprise subscription. Restricting individual connectors through custom permissions requires an Enterprise subscription.

Source statement: "A user can invoke only the connectors that an administrator shares with that user." (https://docs.aws.amazon.com/quick/latest/userguide/outbound-connections.html)

Last checked 17 November 2026.

Research detail: Administrators create each connector and choose its authentication method and scopes, and a user can use only connectors shared with them. Custom permissions add Create and Update, Share and Use controls per connector. Discovered MCP tools are listed as actions that must be reviewed and turned on.

<!-- chunk: products -->
## Products

Connector scopes and sharing, custom permissions per connector, MCP tool enablement

<!-- chunk: gaps -->
## Gaps

Reach is set by the credential and scopes granted. Per-user MCP scopes depend on the server's OAuth design.

<!-- chunk: options -->
## Options

Grant minimal scopes, share connectors narrowly and enable only needed MCP tools.
