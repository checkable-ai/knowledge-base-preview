## Answer

Covered. Chat memory is not supported for accounts configured with AWS KMS customer managed keys. Viewing, editing and deleting individual memories is a Quick on desktop feature.

Source statement: "Memories are specific to you and are not shared with other users." (https://docs.aws.amazon.com/quick/latest/userguide/using-quick-chat.html)

Research detail: Chat memory personalises responses from past interactions, is specific to each user, and users can view and delete individual or all memories. Desktop adds a Memory tab and a knowledge graph with privacy controls. Custom permissions can restrict knowledge memory and engrams, and conversations are not used to train models.
