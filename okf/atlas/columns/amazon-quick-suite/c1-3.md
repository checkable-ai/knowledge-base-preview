How [Amazon Quick Suite (Amazon Quick)](profile.md) addresses the [Human Approval](../../controls/c1-3.md) control. Researcher verdict: escalated. Verification state: contested. Agents must not retrieve this page: escalated by the confirm agents, so a person settles it.

<!-- chunk: answer -->
## Answer

Escalated for a person to settle. The agent checks did not agree on this finding.

Research detail: The human-in-the-loop task center pauses an automation and collects approval before it continues, desktop tools can be set to Ask each time, the Apps agent asks the author to approve each integration it adds, and flow sharing can need approval. Approval is optional and per workflow.

<!-- chunk: products -->
## Products

Human-in-the-loop task center, Ask each time access level, Apps integration consent, flow share approval

<!-- chunk: gaps -->
## Gaps

On-demand web actions run immediately and unattended workflows have no prompt. Binding an approval to the exact action, and replay handling, are not documented.

<!-- chunk: options -->
## Options

Add task center steps to any automation that writes to outside systems and set desktop tools to Ask each time.
