## Answer

Covered. The details view is documented for custom chat agents that the user created or that are shared with the user.

Source statement: "You can view the details of chat agents that are either created by you or shared with you, including all spaces and actions attached to each chat agent." (https://docs.aws.amazon.com/quick/latest/userguide/custom-agents.html)

Last checked 17 November 2026.

Research detail: The outbound connections page lists every path data can leave through, what triggers it and who controls it, and the Check permissions feature shows which custom profile applies to a user. The admin console lists connectors, but no single view of an agent's reachable systems is documented.
