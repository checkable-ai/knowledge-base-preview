## Answer

Covered, with conditions. Quick Automate is available only for accounts provisioned through the AWS Management Console, not Free or Plus accounts.

Source statement: "AWS Quick Automate provides the easiest way for businesses to build, deploy, and continuously maintain workflow automations with the set of capabilities needed to support complex use cases that span multiple applications, data sources, and departments." (https://docs.aws.amazon.com/quick/latest/userguide/using-amazon-quick-automate.html)

Research detail: Quick Automate builds end-to-end processes with control flow logic, case management, error handling, custom code and agent actions, and projects move through build, test, version, deploy and monitor. Quick Flows covers personal tasks, and schedule and event triggers start automations.
