## Answer

Not covered. No gateway enforcing model routing, quotas, cost or rate limits per agent, user or workload. Quick manages routing itself and customers cannot configure it. Nearby features fall short: built-in safety screening for prompt attacks and up to 50 exact-match blocked words apply only to web chat agents and flows.

Research detail: Built-in safety screening checks user requests for harmful content and prompt attacks, and administrators can add up to 50 blocked words applied to requests and responses in chat agents and flows. Model routing is managed by Quick.

## Products

## Gaps
