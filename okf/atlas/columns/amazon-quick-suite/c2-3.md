## Answer

Covered, with conditions. Desktop code runs on the user's machine in an OS-level sandbox. Restricting account access by IP and VPC endpoint requires Enterprise Edition. Private MCP servers are reached through a Quick VPC connection.

Source statement: "Each surface runs code in a sandboxed environment designed to contain the code's effects." (https://docs.aws.amazon.com/quick/latest/userguide/sec-agentic-security.html)

Last checked 17 November 2026.

Research detail: Code runs in isolated sandboxes on each surface. Web chat code has no internet access, Quick Apps run in a sandboxed iframe that blocks direct network access, desktop code uses an OS sandbox and automation code runs in a restricted Python environment. Private MCP servers can be reached through VPC connections, and account access can be limited by IP and VPC endpoint rules.

<!-- chunk: products -->
## Products

Code execution sandboxes, Quick Apps sandbox, VPC connections, IP and VPC restrictions

<!-- chunk: gaps -->
## Gaps

Desktop sandbox always has access to system temporary directories. Sandboxing does not judge what code does with content already in context.

<!-- chunk: options -->
## Options

Use VPC connections for private servers and enable IP restrictions.
