## Answer

Covered, with conditions. Applies to Quick on desktop. Restricting these capabilities for users through custom permissions requires an Enterprise subscription.

Source statement: "Quick stores your permission choices and applies them whenever an agent acts on your behalf, including scheduled agents." (https://docs.aws.amazon.com/quick/latest/userguide/system-tools-desktop.html)

Last checked 17 November 2026.

Research detail: On Quick Desktop each system tool can be switched on or off and each operation set to Always allow, Ask each time or Always deny. File access follows configured folder permissions and code runs in an OS-level sandbox. Custom permissions can remove local code execution, browser automation and agent management for chosen users.

<!-- chunk: products -->
## Products

System tools permissions, desktop code sandbox, custom permissions for Quick desktop

<!-- chunk: gaps -->
## Gaps

Applies to Quick Desktop only. The sandbox always reaches system temporary directories.

<!-- chunk: options -->
## Options

Set sensitive tools to Ask each time and restrict Execute code locally for high-risk roles.
