## Answer

Covered, with conditions. MCP integrations require an Enterprise subscription. Custom permissions require Enterprise Edition.

Source statement: "Tools reach the AI assistant only through integrations that an administrator creates." (https://docs.aws.amazon.com/quick/latest/userguide/sec-agentic-security.html)

Last checked 17 November 2026.

Research detail: Quick runs its own agent runtime for chat, flows, automations and desktop. Administrators control it through custom permissions that can switch off whole capabilities, individual desktop tools, browser and Office extensions, coding agents (ACP) and web search, and the system chat agent can be assigned owners.
