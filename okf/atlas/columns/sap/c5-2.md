## Answer

Not covered. SAP's agent behaviour mining page is forward-looking reference architecture for agents on Joule Studio 2.0, which is not yet generally available. It describes conformance checks for deviations from approved paths, but not training agents on their tasks and not anomaly detection. SAP AI Core Evaluations measure output quality, which falls short of continuous behaviour monitoring.

Last checked 12 November 2026.

Research detail: SAP AI Core Evaluations benchmark prompts and models with predefined and custom metrics. SAP describes SAP Cloud ALM agent dashboards with evaluation rates, error causes and anomaly detection, and SAP Signavio agent behaviour mining for conformance.
