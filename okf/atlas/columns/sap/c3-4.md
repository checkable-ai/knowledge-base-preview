## Answer

Not covered. Agent Gateway checks described in architecture guidance, not generally available; no schema enforcement.

Research detail: The SAP Agent Gateway checks at entry whether the calling user or agent may call the target agent, and checks again before agent-to-agent hand-off. Integration Suite can sit in front for authentication, authorisation, rate limits and quotas on A2A traffic. SAP says parts of this are not yet generally available.
