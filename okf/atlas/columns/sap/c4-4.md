## Answer

Not covered. A2A trust via IAS App2App exists for Joule BYOA, but Agent Gateway is not confirmed generally available and bidirectional third-party communication is unsupported.

Research detail: Joule calls external agents over A2A 0.3.0 and requires an IAS App2App trust relationship between Joule and the agent server for inbound updates. The SAP Agent Gateway exposes Joule Agents to external clients over A2A with IAS authentication and policy checks. SAP's architecture page states bidirectional communication with third-party agents through the Agent Gateway is not yet supported.

## Products

Joule bring-your-own-agent (A2A), SAP Agent Gateway, SAP Integration Suite A2A connectivity

<!-- chunk: gaps -->
## Gaps

Only the text message type is supported for BYOA. Joule does not validate the agent response object. General availability of the gateway is not confirmed.

## Options
