## Answer

Not covered. No vendor statement for this control could be checked by code after four rounds of agent checks, so coverage is not claimed.

Research detail: Joule Memory stores preferences, system preferences and summaries of past tasks across conversations. It is off by default, users can view, export and delete memories, and a built-in mechanism excludes some personal data types. Disabling memory stops learning but keeps stored memories.
