## Answer

Not covered. SAP documents an identity record per agent in SAP Cloud Identity Services, but not a binding of that identity to the runtime or release version. Parts of the governance stack are not yet generally available.

Research detail: SAP's reference architecture describes agent identities stored in SAP Cloud Identity Services alongside human identities, each with a Global User ID, and says registering an agent in SAP AI Agent Hub creates the identity record. Content-based Joule agents are created in the agent runtime when an assistant is deployed and removed when it is deleted. The identity model is documented as architecture guidance, not as a product configuration guide.
