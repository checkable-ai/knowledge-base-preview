## Answer

Research detail: The Joule agent runtime runs agents defined in YAML with planning, tool calls from declared toolkits, pre and post processing, and output schema. Dialog functions used as tools do not see conversational context. SAP states that testing and debugging features to check agent execution traces are not available.
