## Answer

Not covered. No central per-agent permission model for remote actions; relies on back-end authorisation, gateway enforcement planned.

Research detail: Content-based agents can call only the toolkits declared in their configuration (document grounding, calculator, Joule functions). Scenarios can carry visibility conditions on IAS groups, user IDs, licences or navigation targets, and back-end calls go through destinations mapped in Joule Admin Center. SAP states that agent access to tools is checked by back-end application authorisation, with a gateway enforcement point for tools planned for H2 2026.

<!-- chunk: products -->
## Products

Joule agent toolkits, role-based scenario access, Joule Admin Center destinations, SAP Agent Gateway

<!-- chunk: gaps -->
## Gaps

No central per-agent permission model for remote actions is documented as available today.

<!-- chunk: options -->
## Options

Restrict destinations to technical users with narrow back-end roles and use IAS group visibility conditions on scenarios.
