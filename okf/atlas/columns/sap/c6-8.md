## Answer

Not covered. Prompt template and orchestration config version history exists, but no approval step or rollback for agent releases, permissions or knowledge is documented.

Last checked 12 November 2026.

Research detail: Prompt templates and orchestration configs keep version history, and the declarative API syncs them from git for CI/CD. Model versions can be pinned. Joule Admin Center destination changes apply only to new conversations and can be reset to default.
