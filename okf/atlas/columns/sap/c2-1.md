## Answer

Not covered. Cancellation and recovery of in-flight agent runs not documented; orchestration fallbacks cover only model errors.

Research detail: The Joule orchestrator routes conversations to agents, content-based agents run up to a configured iteration limit, and remote A2A agents support asynchronous push notifications and context or task IDs. SAP AI Core orchestration supports fallback configurations that switch on 408, 429 or 5xx errors.

## Products
