## Answer

Not covered. Principal propagation from agent tool calls to back ends is architecture guidance only; the enforcement point is planned.

Research detail: Joule authenticates users through XSUAA with an OAuth authorisation code flow and SAP Identity Authentication. The Agent Gateway accepts IAS App2App tokens with named user context, and the identity architecture says each agent interaction is governed by the user's identity intersected with the agent's scope. SAP's MCP guidance tells builders to use token exchange that keeps the original user context rather than forwarding user tokens.
