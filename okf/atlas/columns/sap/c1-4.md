## Answer

Not covered. Admin consent and deployment lifecycle exist but no controlled permission-change workflow documented.

Research detail: Agents in a Joule capability are created on assistant deployment and removed when the assistant is deleted. Custom agent deployment is blocked until a customer administrator gives consent in Joule Admin Center. SAP AI Agent Hub is described as driving the agent identity lifecycle through Cloud Identity Services provisioning.

<!-- chunk: products -->
## Products

Joule deployment, Joule Admin Center, SAP AI Agent Hub, SAP Cloud Identity Services

## Gaps
