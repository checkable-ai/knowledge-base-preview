## Answer

Not covered. No sanitisation or classification controls for grounding stores.

Last checked 12 November 2026. This platform is checked on demand, so this answer has not been rechecked since.

Research detail: SAP AI Core grounding uses pipelines and vector collections, and training data sits in a customer-registered object store. SAP AI Core does not delete object store files, and inference observability payloads are not sanitised, which SAP flags as a customer responsibility.
