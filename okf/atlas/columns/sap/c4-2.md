## Answer

Not covered. No documented short-lived scoped agent credentials with rotation and revocation; AI Core generic secrets and BTP destinations fall short.

Research detail: SAP AI Core stores credentials as generic secrets scoped to a resource group, and offers mTLS certificate secrets where SAP AI Core generates the certificate and key through the SAP BTP Certificate Service. Joule reaches back-end systems through BTP destinations mapped to system aliases, so credentials sit in the destination, not in agent content. The Agent Gateway use case states the external agent does not receive back-end credentials.

<!-- chunk: products -->
## Products

SAP AI Core generic secrets and mTLS certificate secrets, BTP destinations via Joule Admin Center, SAP Agent Gateway

<!-- chunk: gaps -->
## Gaps

Rotation and expiry policies for generic secrets are not documented in the pages read. No statement on whether secrets can reach model context for custom tools.

<!-- chunk: options -->
## Options

Use mTLS certificate secrets or SAP Credential Store with rotation, and test whether a Joule Studio tool can echo destination credentials into a response.
