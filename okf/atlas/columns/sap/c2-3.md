## Answer

Not covered. AI Core pod security settings are enforced, but no code interpreter, network egress controls or runtime isolation are documented for Joule agents.

Research detail: SAP AI Core workloads run in a sandbox per tenant and resource group namespace, allow only TCP, and must meet enforced pod settings such as non-root user, dropped capabilities and no privilege escalation. Joule agents run on an SAP-managed runtime that SAP describes only at the level of scaling and monitoring.
