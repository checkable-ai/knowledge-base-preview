## Answer

Not covered. Gateway enforcement for tools planned H2 2026; MCP Gateway is a separate product; no dangerous-action blocking.

Research detail: SAP points to the MCP Gateway in SAP Integration Suite for OIDC authentication, rate limiting and payload protection on tools, and to the Agent Gateway for policy checks. The gateway enforcement point between agents and tools is stated as planned for H2 2026. Joule web search egress is an administrator toggle in Joule Admin Center.
