## Answer

Not covered. human_approval_required prompts exist but no binding to exact parameters, denial handling or approval audit record could be verified.

Research detail: A Joule function tool can set human_approval_required with a human_approval_prompt, so the agent asks the user to confirm before the step. Agent responses tagged permissionRequest or missingInput are handled in dialog functions. The approval message is composed by an LLM call, so the binding between the displayed summary and the exact tool parameters is not documented.
