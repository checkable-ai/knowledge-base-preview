## Answer

Covered. Inventory is in preview. Excludes Classic (V1) agents. Covers agents built in Copilot Studio and Agent Builder only.

Source statement: "The Copilot Studio agent inventory provides IT and security admins with a centralized view of all agents created using Copilot Studio or Agent Builder in the tenant." (https://learn.microsoft.com/en-us/microsoft-copilot-studio/admin-agent-inventory)

Research detail: The agent inventory gives admins a tenant view of all Copilot Studio and Agent Builder agents, including drafts, with creator, owner, channels, authentication and connectors. This surfaces maker-built agents that IT did not commission.

<!-- chunk: products -->
## Products

Copilot Studio agent inventory

<!-- chunk: gaps -->
## Gaps

Covers only agents built in Copilot Studio and Agent Builder, not other AI tools. Classic V1 agents are excluded. The inventory is preview.
