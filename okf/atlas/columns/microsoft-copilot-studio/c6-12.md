## Answer

Not covered. No scheduled reassessment or retirement workflow for external models, tools or services. Admin approval of external model providers and connector data policies cover the approval step only.

Research detail: Admins must turn on external models per environment and allow each provider, such as Anthropic, Mistral or xAI, in the Microsoft 365 admin center. Microsoft states makers are responsible for external A2A agents and MCP servers, and connectors can be blocked by data policy.
