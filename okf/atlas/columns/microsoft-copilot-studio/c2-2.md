## Answer

Covered. Standard harness. Preview and experimental models require admin settings for preview models and cross-region data movement. External models (Anthropic, xAI, Mistral) need admin enablement. Cross-geo models may process data outside the region. Availability varies by region.

Source statement: "Choose a model based on how much your agent needs in response speed, output quality, reasoning, and cost." (https://learn.microsoft.com/en-us/microsoft-copilot-studio/authoring-select-agent-model)

Research detail: Makers pick a named primary model per agent, such as GPT-5.5 Chat or Claude Opus 4.7, with tags for GA, preview, experimental, retired and cross-geo, and a regional availability table. Admins can block preview, experimental and external models and must allow cross-region data movement for experimental models. Prompts can use Azure AI Foundry models.

<!-- chunk: products -->
## Products

Primary model selection, external models from Anthropic, xAI and Mistral, admin model settings

<!-- chunk: gaps -->
## Gaps

The default model is upgraded periodically and is the fallback when a selected model is unavailable, so the running version can change. Endpoints are Microsoft-managed and not exposed. Cross-geo models can process data outside the region.

<!-- chunk: options -->
## Options

Pin a GA model, block experimental and external models where residency matters, and use the inventory model field to track drift.
