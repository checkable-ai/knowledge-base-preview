## Answer

Covered. Opt-in per agent for the standard harness and requires a customer Azure Application Insights resource. The dashboard workbook is preview.

Source statement: "These views bring key metrics, such as total conversations, latency, exceptions, tool usage, and topic analytics, into a single view." (https://learn.microsoft.com/en-us/microsoft-copilot-studio/advanced-bot-framework-composer-capture-telemetry)

Research detail: Agents can send telemetry to Azure Application Insights, and a Copilot Studio dashboard workbook (preview) shows conversations, latency, exceptions and tool usage. Environment-level telemetry is also available in preview.

<!-- chunk: products -->
## Products

Application Insights telemetry, Copilot Studio dashboard workbook

<!-- chunk: gaps -->
## Gaps

Telemetry is opt-in per agent and needs a customer Azure resource. Anomaly detection is not built in.

<!-- chunk: options -->
## Options

Connect Application Insights and add Azure Monitor alerts on latency and exceptions.
