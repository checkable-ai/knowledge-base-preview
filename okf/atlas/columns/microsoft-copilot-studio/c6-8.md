## Answer

Covered. Changes take effect on publish, with solutions, pipelines and Git for versioning. Rollback means redeploying an earlier solution. Default model upgrades are not release-gated.

Source statement: "The default model is periodically upgraded as new, more capable models become generally available." (https://learn.microsoft.com/en-us/microsoft-copilot-studio/authoring-select-agent-model)

Research detail: Changes take effect only when an agent is published, and publish, update and component changes are audited. Agents move between environments as managed solutions through pipelines or Git with deployment history, and version control supports rollback.

<!-- chunk: products -->
## Products

Publish model, solutions, Power Platform pipelines, Git integration, Purview audit

<!-- chunk: gaps -->
## Gaps

Rollback relies on redeploying an earlier solution version. Model changes through the default upgrade are not release-gated.

## Options
