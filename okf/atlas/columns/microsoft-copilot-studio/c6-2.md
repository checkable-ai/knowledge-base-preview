## Answer

Covered. Applies to agents submitted for organisational distribution through the Microsoft 365 admin center (Teams, Copilot and Office surfaces), documented under Agent 365. Covers agents, not models or tools.

Source statement: "When you submit an agent for admin approval, the Microsoft 365 admin center provides all metadata about the agent's definition." (https://learn.microsoft.com/en-us/microsoft-agent-365/admin/agent-requests?view=o365-worldwide)

Research detail: Admins control who can author agents, which features makers may use through data policies, and whether agents using generative AI can be published. Microsoft 365 admins govern which agents appear in Microsoft Copilot, and org-wide sharing can require admin approval.

<!-- chunk: products -->
## Products

Copilot Author setting, data policies, publishing controls, Microsoft 365 admin center agent controls

<!-- chunk: gaps -->
## Gaps

No built-in submission and approval workflow for new agents or tools is documented in Copilot Studio.

<!-- chunk: options -->
## Options

Use Power Platform pipelines and solution deployment as the approval gate into production environments.
