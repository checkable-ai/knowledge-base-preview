## Answer

Covered. Production-ready preview on the GitHub Copilot harness only (a separate memory capability exists for the Customer Conversation harness). Enabled per agent by the maker. Disabled in group chats and Teams channels.

Source statement: "If a user doesn't interact with the agent for 28 days, the system deletes their memories from that agent." (https://learn.microsoft.com/en-us/microsoft-copilot-studio/agents-experience/memory-overview)

Research detail: Memory, a production-ready preview on the GitHub Copilot harness, keeps a separate store per user per agent in Microsoft-managed storage. Makers turn it on per agent but cannot see user memories. Users can view, change or delete memories in chat or a memory portal, and memories are deleted after 28 days of inactivity.

## Products

Copilot Studio Memory (preview)

<!-- chunk: gaps -->
## Gaps

Preview only and not available on the standard harness. Turning memory off does not delete stored memories. No admin retention or eDiscovery controls are described.

<!-- chunk: options -->
## Options

Leave memory off for regulated agents until admin retention controls are documented.
