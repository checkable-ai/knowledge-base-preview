## Answer

Covered. Applies only to the computer use tool on a Windows machine. Access control is off by default and the allow list does not stop the model opening unlisted sites or apps. Machine hardening (Intune, App Control) is customer-managed.

Source statement: "Access control only prevents the model from taking actions on websites or applications that aren't in the allow list." (https://learn.microsoft.com/en-us/microsoft-copilot-studio/computer-use)

Research detail: Copilot Studio agents run in the Microsoft cloud, so local host actions arise only through computer use on a Windows machine. Computer use has an access control allow list for websites and desktop apps and an Enforce HTTPS setting. Microsoft recommends dedicated, least-privilege machines with Intune and app control.

<!-- chunk: products -->
## Products

Computer use tool, Power Automate machines

<!-- chunk: gaps -->
## Gaps

The allow list blocks actions but does not stop the model opening other sites. Access is unrestricted by default. Machine hardening is the customer's job.

<!-- chunk: options -->
## Options

Turn on access control and Enforce HTTPS, and apply Edge and App Control policies to computer use machines.
