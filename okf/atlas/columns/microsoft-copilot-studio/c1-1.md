## Answer

Covered, with conditions. Applies to the computer use tool on a Windows machine, for agents on the standard harness with generative orchestration. Access control is off by default. The allow list does not stop the model opening unlisted sites or apps. The target machine is one the customer sets up and hardens (for example with Intune and App Control). premium models consume 15 credits per step. Claude Sonnet 4.6 and Claude Opus 4.6 computer-use models are experimental.

Source statement: "If you want to restrict this access, enable access control to define the specific URLs and desktop applications that computer use should be limited to." (https://learn.microsoft.com/en-us/microsoft-copilot-studio/computer-use)

Research detail: Copilot Studio agents run in the Microsoft cloud, so local host actions arise only through computer use on a Windows machine. Computer use has an access control allow list for websites and desktop apps and an Enforce HTTPS setting. Microsoft recommends dedicated, least-privilege machines with Intune and app control.

<!-- chunk: products -->
## Products

Computer use tool, Power Automate machines

<!-- chunk: gaps -->
## Gaps

The allow list blocks actions but does not stop the model opening other sites. Access is unrestricted by default. Machine hardening is the customer's job.

<!-- chunk: options -->
## Options

Turn on access control and Enforce HTTPS, and apply Edge and App Control policies to computer use machines.
