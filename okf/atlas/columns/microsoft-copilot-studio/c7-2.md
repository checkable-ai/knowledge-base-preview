## Answer

Covered, with conditions. Defender detection for AI agents is in public preview. Defender detection for AI agents covers agents managed through Microsoft Agent 365. Defender detection for AI agents needs Microsoft Defender, a separate product. Defender detection for AI agents needs onboarding to Microsoft Agent 365. Defender detection for AI agents needs the Microsoft 365 connector turned on.

Source statement: "This feature is currently in public preview." (https://learn.microsoft.com/en-us/defender-xdr/security-for-ai/ai-agent-detection-protection)

Last checked 13 November 2026.

Research detail: Admins can monitor and alert on agent activities through Microsoft Sentinel. Microsoft Defender correlates agent alerts into incidents and exposes Advanced Hunting tables for agent inventory, activity and real-time protection behaviours, with redacted prompt evidence.
