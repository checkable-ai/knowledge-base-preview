## Answer

Covered. Defender detection is in public preview and is a separate product, covering agents managed through Microsoft Agent 365. Copilot Studio block events are not yet recorded as behaviours. Sentinel needs separate setup.

Source statement: "Microsoft Defender continuously monitors AI agent activity and detects suspicious and malicious behavior for all Agent 365-managed agents." (https://learn.microsoft.com/en-us/defender-xdr/security-for-ai/ai-agent-detection-protection)

Research detail: Admins can monitor and alert on agent activities through Microsoft Sentinel. Microsoft Defender correlates agent alerts into incidents and exposes Advanced Hunting tables for agent inventory, activity and real-time protection behaviours, with redacted prompt evidence.
