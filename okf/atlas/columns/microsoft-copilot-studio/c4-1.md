<!-- chunk: answer -->
## Answer

Covered. New agents (from May 2026) get an Entra Agent ID with the owner as sponsor. Older agents keep app registrations until migrated. Agent Builder agents get no identity.

Source statement: "Copilot Studio automatically provisions Entra Agent IDs for new agents." (https://learn.microsoft.com/en-us/microsoft-copilot-studio/govern-agents-identities-overview)

Research detail: Since May 2026 Copilot Studio automatically creates a Microsoft Entra Agent ID for every new agent, as a child of a Microsoft-owned blueprint. The agent owner is added as a sponsor, the GUID is shown in agent metadata, and deleting the agent deletes the identity. Agents created before May 2026 still use app registrations until Microsoft migrates them.

<!-- chunk: products -->
## Products

Microsoft Entra Agent ID, Copilot Studio agent identity blueprint

<!-- chunk: gaps -->
## Gaps

Legacy agents keep app registrations until migration. Opt-out is no longer possible. Agent Builder agents get no identity. Link to a specific release or published version is not documented.

<!-- chunk: options -->
## Options

Use the inventory entraAgentId field to find agents still on app registrations and migrate them through the Power Platform admin center or API.
