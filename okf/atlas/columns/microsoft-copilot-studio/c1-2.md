## Answer

Covered. Connector scopes are added only to Entra Agent IDs and apply to first-party and certified connectors. Conditional Access enforcement on the agent identity applies only in Teams. Custom connectors, MCP servers and REST API tools add no scopes. Data policies are set by admins per environment or tenant.

Source statement: "Only the operations the agent actually uses are permitted." (https://learn.microsoft.com/en-us/microsoft-copilot-studio/govern-agents-identities-overview)

Research detail: Data policies classify connectors as business, non-business or blocked and can block knowledge sources, HTTP, skills, channels and triggers, with endpoint filtering for HTTP, SharePoint and public websites. Published connector use appears as API permissions on the agent's Entra Agent ID, and the connector runtime revalidates them against data policies on every call. Makers can limit an agent to specific connector operations.

## Gaps
