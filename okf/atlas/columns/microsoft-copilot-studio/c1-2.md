## Answer

Covered. Connector scopes are added only to Entra Agent IDs, not legacy app registrations. They apply to first-party and certified Power Platform connectors; custom connectors, MCP servers and REST API tools add no scopes. Conditional Access enforcement on the agent identity currently applies only when the agent runs in Microsoft Teams. Scopes are applied at publish.

Source statement: "Individual operation scopes are granted when the maker added specific connector actions instead of the whole connector." (https://learn.microsoft.com/en-us/microsoft-copilot-studio/govern-agents-identities-overview)

Last checked 13 November 2026.

Research detail: Data policies classify connectors as business, non-business or blocked and can block knowledge sources, HTTP, skills, channels and triggers, with endpoint filtering for HTTP, SharePoint and public websites. Published connector use appears as API permissions on the agent's Entra Agent ID, and the connector runtime revalidates them against data policies on every call. Makers can limit an agent to specific connector operations.

## Products

Power Platform data policies, endpoint filtering, advanced connector policies, Entra Agent ID scopes

## Gaps

Conditional Access on agent scopes is enforced only in Teams. Custom connectors, MCP servers and REST API tools add no Entra scopes.

## Options
