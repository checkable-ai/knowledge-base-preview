## Answer

Covered. Entra Agent ID is created with the agent (first publish on the GitHub Copilot harness). Connector scopes update on publish. Quarantine does not support classic chatbots.

Source statement: "When you delete an agent from Copilot Studio, the process removes the associated Agent ID (or app registration) from Microsoft Entra ID." (https://learn.microsoft.com/en-us/microsoft-copilot-studio/govern-agents-identities-overview)

Research detail: Copilot Studio creates the Entra Agent ID when an agent is created, updates its connector scopes on each publish, and deletes it when the agent is deleted. Admins control who can author through the Copilot Author security group, route makers to set environments, and can quarantine agents through the Power Platform API. Create, update, publish, share and delete events are audited.

## Products

Entra Agent ID lifecycle, environment routing, quarantine API, Purview audit

## Gaps
