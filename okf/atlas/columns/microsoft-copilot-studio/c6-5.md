## Answer

Covered. Authentication, channels and sharing are not solution-aware and need post-deployment steps in the target environment.

Source statement: "Application Lifecycle Management (ALM) is a set of processes, people, and tools that govern an agent's lifecycle." (https://learn.microsoft.com/en-us/microsoft-copilot-studio/guidance/alm)

Research detail: Microsoft's ALM guidance uses development, test and production environments, solutions, environment variables, Git integration and pipelines, Azure DevOps or GitHub Actions to move agents. Agents can be quarantined and deleted, and retired models remain usable for one month.
