## Answer

Covered. Three harnesses (GitHub Copilot, Customer Conversation, standard) with differing feature coverage.

Source statement: "The harness is a runtime that exists between the two: it determines when to call the model, what components to send it, interprets what comes back, and calls the right tools." (https://learn.microsoft.com/en-us/microsoft-copilot-studio/harnesses-overview)

Research detail: Copilot Studio documents three harnesses that decide when to call the model and which tools to run: the GitHub Copilot harness for multistep work with files, skills and memory, the standard harness for rule-based agents and agent flows, and the Copilot chat harness for extending Microsoft Copilot Chat. The harness type is recorded per agent in the inventory.

## Products

GitHub Copilot harness, standard harness, Copilot chat harness
