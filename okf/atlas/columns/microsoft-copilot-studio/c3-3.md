## Answer

Covered. Admins configure data policies in the Power Platform admin center per environment or tenant. Tools use end-user credentials by default so retrieval follows user permissions.

Source statement: "Data policies let you govern how agents connect and interact with data and services, both within and outside your organization." (https://learn.microsoft.com/en-us/microsoft-copilot-studio/admin-data-loss-prevention)

Research detail: Data policies can block document uploads, SharePoint and OneDrive, and public website knowledge sources, with endpoint filtering for specific SharePoint sites and websites. Tools default to end-user credentials so retrieval follows user permissions. Agents show the highest sensitivity label of SharePoint sources used in a response.

<!-- chunk: products -->
## Products

Data policies, endpoint filtering, end-user credentials, sensitivity labels for SharePoint knowledge

<!-- chunk: gaps -->
## Gaps

Data policies act at connector level, not on content. Content inspection DLP on prompts and responses is not described in Copilot Studio docs.

<!-- chunk: options -->
## Options

Combine knowledge endpoint filtering with Purview DSPM for AI and test label handling on sensitive SharePoint content.
