## Answer

Covered. End user credentials are the default for tools. Maker-provided credentials are an alternative that lets users act with the author's access.

Source statement: "This method ensures users only access data they're authorized to see." (https://learn.microsoft.com/en-us/microsoft-copilot-studio/add-tools-custom-agent)

Research detail: Tools default to End user credentials, so the agent calls services as the signed-in user and users only see data they are authorised for. Maker-provided credentials are an option and trigger a pre-publish security warning. Authentication with Microsoft or manual Entra ID and OAuth 2 providers carries the user identity, with SSO support.

<!-- chunk: products -->
## Products

Copilot Studio tool authentication, user authentication settings

<!-- chunk: gaps -->
## Gaps

Maker-provided credentials let any user act with the author's access. End-to-end Entra Agent ID token use is only in Teams today.

<!-- chunk: options -->
## Options

Block maker-credential use through review of inventory connectionProvider values and require authentication through a data policy.
