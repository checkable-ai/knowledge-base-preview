## Answer

Covered. Ownership is recorded per agent. For Entra Agent IDs the agent owner is the sponsor; for legacy app registrations the owner is the app registration owner. The agent inventory shows the current owner (ownerId). Some preexisting agents might not have sponsors yet. Tools (connectors, actions) and model choice are set up inside each agent and fall under that agent's owner. They do not get separate owner records.

Source statement: "The agent owner is added as a sponsor with limited permissions compared to full owners, which reduces security concerns around permission modifications." (https://learn.microsoft.com/en-us/microsoft-copilot-studio/govern-agents-identities-overview)

Research detail: Copilot Studio adds the agent owner as a sponsor on the Entra Agent ID for traceability and accountability. The inventory records createdBy and the current ownerId, and the creator of each connector operation.

<!-- chunk: products -->
## Products

Entra Agent ID sponsors, agent inventory

<!-- chunk: gaps -->
## Gaps

Some preexisting agents have no sponsor. Reassignment when an owner leaves is not described in Copilot Studio docs.

<!-- chunk: options -->
## Options

Use Entra ID Governance to review sponsors and reassign orphaned agents.
