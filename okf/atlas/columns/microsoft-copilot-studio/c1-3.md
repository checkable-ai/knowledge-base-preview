## Answer

Covered. The 'Ask the end user before running' setting is No by default and must be enabled per tool. Standard harness. Multistage approvals in agent flows are preview.

Source statement: "In the end user chat experience, ask the agent for confirmation before running the tool." (https://learn.microsoft.com/en-us/microsoft-copilot-studio/add-tools-custom-agent)

Research detail: Each tool has an Ask the end user before running setting that asks for confirmation in chat. Agent flows can run multistage approvals with human stages that pause until assignees respond in Teams, Outlook or Power Automate. Computer use can email a named supervisor when it detects potentially harmful instructions, and the run stops when the request expires.

<!-- chunk: products -->
## Products

Tool confirmation, Human review connector multistage approvals, computer use human supervision

<!-- chunk: gaps -->
## Gaps

Tool confirmation is off by default. Multistage approvals are preview and lack ALM support. Binding of the approval to exact parameters, denial handling detail and replay protection are not documented.

<!-- chunk: options -->
## Options

Route high-impact actions through an agent flow with a manual approval stage and test denial and timeout paths.
