## Answer

Covered, with conditions. Evaluations apply to the standard harness. Evaluations are triggered through the Power Platform REST API against test sets, so recurring runs must be set up by the customer. Anomaly detection comes from Microsoft Defender detection for agents, which is in public preview. Defender detection for agents is a separate Microsoft Defender product. Defender detection covers agents managed through Microsoft Agent 365.

Source statement: "This article describes features used in agents or agent flows powered by the standard harness." (https://learn.microsoft.com/en-us/microsoft-copilot-studio/analytics-agent-evaluation-rest-api)

Last checked 13 November 2026.

Research detail: Agent evaluation runs test sets with graders for general quality, content safety, compare meaning, tool use, keyword, text similarity, exact match and custom criteria. Security analytics show trends of blocked messages, and Defender raises near-real-time alerts on jailbreak, XPIA and other agent behaviour.

## Products
