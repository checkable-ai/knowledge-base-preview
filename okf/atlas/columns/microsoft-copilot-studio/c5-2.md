## Answer

Covered. Evaluations are triggered through the REST API or Power Automate against test sets, so recurring runs must be set up. Standard harness. Defender detection for agents is preview and separately licensed.

Source statement: "Copilot Studio provides makers with tools to continuously evaluate agent performance by running automated tests against predefined test sets using the Power Platform REST API." (https://learn.microsoft.com/en-us/microsoft-copilot-studio/analytics-agent-evaluation-rest-api)

Research detail: Agent evaluation runs test sets with graders for general quality, content safety, compare meaning, tool use, keyword, text similarity, exact match and custom criteria. Security analytics show trends of blocked messages, and Defender raises near-real-time alerts on jailbreak, XPIA and other agent behaviour.

## Products

Agent evaluation, security analytics, Microsoft Defender detections

## Gaps

Evaluation is run on demand, and continuous scheduled validation is not described. Behavioural anomaly detection depends on Defender, which is preview for agents.
