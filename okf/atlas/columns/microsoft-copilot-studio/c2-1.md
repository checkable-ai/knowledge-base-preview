## Answer

Covered. Retry and alternative paths apply to the GitHub Copilot harness. The standard harness follows paths the maker built, with agent flows for retry and error handling. User-facing cancellation of a running task is not documented.

Source statement: "Instead of following only a fixed script, it can take a goal, break it into steps, call the right tools across connectors, knowledge, MCP, and connected agents, and adjust when a step fails or a request changes." (https://learn.microsoft.com/en-us/microsoft-copilot-studio/harnesses-overview)

Research detail: Generative orchestration selects topics, tools, knowledge and child or connected agents, with redirect nodes for explicit sequencing. The GitHub Copilot harness breaks goals into steps, retries and finds alternative paths. Agent flows in Power Automate support retry policies, Run after error paths, try-catch scopes and Terminate.

<!-- chunk: products -->
## Products

Generative orchestration, GitHub Copilot harness, agent flows, Power Automate

<!-- chunk: gaps -->
## Gaps

User-facing cancellation of a running agent task is not documented. The orchestrator supports up to 128 tools per agent and degrades beyond 30 to 40 choices.

<!-- chunk: options -->
## Options

Split large agents into connected agents and put fragile steps in agent flows with retry policies.
