## Answer

Covered. Data policies are generally available. External threat detection (including Defender real-time protection) is preview, applies only to generative orchestration agents, is set per environment, and defaults to allow if no decision arrives within one second.

Source statement: "At runtime, every time the orchestrator considers invoking a tool, it sends relevant data about the proposed tool use to the threat detection endpoint for evaluation." (https://learn.microsoft.com/en-us/microsoft-copilot-studio/external-security-provider)

Research detail: Data policies block or allow connectors, MCP tools, skills and HTTP per environment, with endpoint filtering for HTTP egress, and the connector runtime revalidates every call. An external threat detection endpoint, including Microsoft Defender, is called before each tool invocation and returns allow or block. Defender real-time protection rules can block tool invocations by detection type per agent.

<!-- chunk: products -->
## Products

Power Platform data policies, endpoint filtering, external threat detection webhook, Microsoft Defender real-time protection

<!-- chunk: gaps -->
## Gaps

External threat detection and Defender protection for Copilot Studio are preview, skip classic agents, are set per environment, and default to allow after a one-second timeout. No per-tool quotas or schema enforcement are documented.

<!-- chunk: options -->
## Options

Enable threat detection in every environment with Block the query as error behaviour, and add Defender custom block rules.
