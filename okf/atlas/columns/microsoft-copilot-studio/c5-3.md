## Answer

Covered, with conditions. The user consumption report covers agents on the standard harness only. Credits must be bought as prepaid capacity or pay-as-you-go through the Power Platform admin center. Admins can set monthly consumption limits per agent. The savings calculator is for standard harness agents. The savings calculator uses savings estimates entered by makers. Admins can turn off cost savings for an environment.

Source statement: "For agents powered by the standard harness, the user report also shows consumption by user." (https://learn.microsoft.com/en-us/power-platform/admin/manage-copilot-studio-copilot-credits-capacity)

Research detail: The Power Platform admin center shows Copilot Credit consumption by environment, agent and user with downloadable reports that include channel, model and tool. Admins set monthly per-agent limits. The Copilot Studio Monitor page has a savings calculator for time and cost saved per run or per tool.

<!-- chunk: products -->
## Products

Copilot Studio capacity management, consumption reports, savings calculator

## Gaps

Savings figures come from maker estimates, not measured baselines. Admins can turn off cost savings.

## Options
