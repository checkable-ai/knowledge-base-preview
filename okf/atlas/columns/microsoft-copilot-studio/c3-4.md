## Answer

Not covered. Makers can enable or disconnect child and connected agents, but no admin allow-list of agent pairs or message formats is documented.

Research detail: Makers can enable, disable or disconnect child and connected agents per main agent. A2A connections run on the custom connector infrastructure, which data policies govern, and skills can be blocked with a data policy.

## Products

Connected agents settings, A2A connections, data policies

## Gaps

No admin policy for allowed agent pairs or A2A message schemas is documented. Connected agent use inside an environment has no separate admin control.

<!-- chunk: options -->
## Options
