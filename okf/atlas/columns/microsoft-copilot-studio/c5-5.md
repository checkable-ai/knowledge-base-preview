## Answer

Partly covered. Custom connectors, MCP servers and REST API tools add no API permissions to the Entra Agent ID, so the reach view does not show them. Legacy app registrations have no scopes.

Source statement: "Today, this behavior applies to first-party and certified Power Platform connectors; custom connectors, MCP servers, and REST API tools added to agents don't add API permissions to the Entra Agent ID." (https://learn.microsoft.com/en-us/microsoft-copilot-studio/govern-agents-identities-overview)

Research detail: Entra admins can see the connectors an agent may call as API permissions on its Agent ID without opening the Power Platform admin center. The inventory lists each connector operation, whether it is a tool or knowledge, when it can be used, and whether the connection is the user's or the maker's.

## Products

Entra Agent ID API permissions, Copilot Studio agent inventory

## Gaps

Custom connectors, MCP servers and REST API tools add no Entra scopes. Inventory capability fields are preview and capped at 200 resources per type.
