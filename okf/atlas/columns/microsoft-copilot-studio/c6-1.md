## Answer

Partly covered. The vendor states in words that component detail is limited.

Source statement: "Currently, it only displays detailed data on connectors used by the agent and a knowledge configuration as detailed in the following sections." (https://learn.microsoft.com/en-us/microsoft-copilot-studio/admin-agent-inventory)

Research detail: The agent inventory records each agent's harness, IDs, creator, owner, environment, publish date, Entra identity, model, authentication, channels, sharing and connector operations. Data is available in the Power Platform admin center, the Power Platform API and Azure Resource Graph and refreshes within about 20 minutes.
