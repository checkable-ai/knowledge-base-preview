## Answer

Covered. Code interpreter must be enabled by a tenant admin (off by default) and is unavailable in sovereign clouds. GitHub Copilot harness tasks run in a sandbox. Hosted browser and Cloud PC options for computer use are preview.

Source statement: "Code execution is sandboxed and isolated, with strict constraints to prevent unsafe operations such as network access, system-level commands, or unauthorized file operations." (https://learn.microsoft.com/en-us/microsoft-copilot-studio/faq-code-interpreter)

Research detail: The GitHub Copilot harness runs each task in a secure sandbox governed by Copilot Studio. Computer use runs on a Microsoft-managed hosted browser, an Entra joined and Intune enrolled Cloud PC pool, or the customer's own machines registered in Power Automate. A2A connections can reach on-premises or virtual network agents through the custom connector infrastructure.

<!-- chunk: products -->
## Products

GitHub Copilot harness sandbox, Windows 365 for Agents hosted browser and Cloud PC pool, Power Automate machines

<!-- chunk: gaps -->
## Gaps

Sandbox isolation, networking and code execution limits are not described. Hosted browser and Cloud PC pool are preview, and the hosted browser is not tenant managed.

<!-- chunk: options -->
## Options

Use Cloud PC pools or dedicated managed machines for computer use and request sandbox architecture details from Microsoft.
