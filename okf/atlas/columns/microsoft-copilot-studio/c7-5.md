## Answer

Not covered. MCP server certification tests only servers that are submitted for it. No SBOMs, scanning or review of connectors, skills, command-line tools or all agent tools, and no network egress checks are documented. The pre-publish security scan covers configuration only.

Research detail: An automatic security scan warns makers before publishing when an agent has no authentication, uses maker-provided credentials or is shared organisation-wide. Real-time risk assessment flags exfiltration risks while configuring knowledge, tools and actions. MCP connectors can go through connector certification to be used across tenants.

## Products

Automatic security scan, real-time risk assessment, connector certification

## Gaps

No SBOM, code scanning or review of MCP servers, connectors or skills is documented. Scan findings are warnings.

## Options
