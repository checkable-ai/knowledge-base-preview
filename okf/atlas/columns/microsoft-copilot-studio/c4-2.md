## Answer

Not covered. The documented features fall short of the lifecycle and model-isolation outcome. The vendor does not state that they cover part of it.

Research detail: Agent identity tokens use Federated Identity Credentials held by a Microsoft-owned blueprint, so no tenant user can mint tokens or see a secret. Tool connections use Power Platform connections with end-user or maker credentials. Computer use stores site and app passwords in Power Platform internal storage or a customer Azure Key Vault and fills them at sign-in prompts.

<!-- chunk: products -->
## Products

Entra Agent ID blueprint, Power Platform connections, computer use stored credentials, Azure Key Vault

<!-- chunk: gaps -->
## Gaps

Rotation, expiry and revocation of connection credentials are not described in the Copilot Studio pages. Legacy app registrations can have secrets created by tenant admins. Manual authentication can use client secrets.

<!-- chunk: options -->
## Options

Prefer Entra ID with federated credentials or certificates for manual auth, keep computer use credentials in Key Vault and test revocation behaviour on connections.
