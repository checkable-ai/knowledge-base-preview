## Answer

Covered. Sandbox off by default in CLI and admin default; Windows sandbox in preview.

Source statement: "Sandboxed commands run without network access by default." (https://antigravity.google/docs/sandbox/)

Research detail: The terminal sandbox uses Linux namespaces or macOS Seatbelt profiles, mounts only the project and granted paths, blocks ~/.ssh and .env, and has no network except read_url-allowed domains. Admins can require sandbox mode, and projects can use isolated Git worktrees.

<!-- chunk: products -->
## Products

Antigravity terminal sandbox, Gemini Enterprise sandbox mode

<!-- chunk: gaps -->
## Gaps

Windows sandbox is in preview. The CLI default has the sandbox off and admin sandbox mode defaults to disabled. The agent can request unsandboxed runs with host privileges.

<!-- chunk: options -->
## Options

Turn on admin sandbox mode and deny unsandboxed(*) by rule, then test escape requests.
