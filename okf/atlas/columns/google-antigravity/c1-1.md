## Answer

Covered. Windows still uses the earlier permission system; admin defaults for terminal and sandbox are permissive.

Source statement: "Conflicting rules are strictly evaluated in priority order: Deny > Ask > Allow." (https://antigravity.google/docs/permissions/)

Research detail: A unified permission engine applies allow, deny and ask rules on read_file, write_file, command, read_url, execute_url and mcp actions, with deny taking precedence. Presets (Default, Request Review, Turbo) set the baseline, and Gemini Enterprise admins set the outside-of-file-access policy, terminal auto-execution mode and sandbox mode centrally.

## Products

Antigravity permissions, Gemini Enterprise security policies

<!-- chunk: gaps -->
## Gaps

Windows still uses the earlier permission system. Admin defaults are Always proceed for terminal and sandbox off. Users can choose Turbo unless admin settings override it, and the docs do not say which user settings admins lock.

<!-- chunk: options -->
## Options

Set terminal mode to Require review or Proceed in sandbox and file access to Deny in admin settings, then test Turbo on a managed machine.
