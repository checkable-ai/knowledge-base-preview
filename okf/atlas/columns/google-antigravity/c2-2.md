## Answer

Covered. Preview models run only in global region; background lightweight models not selectable.

Source statement: "Developers can use a third-party model only after an administrator enables it." (https://docs.cloud.google.com/gemini/enterprise/docs/ai-developer-tools-settings)

Research detail: Admins choose authorised models by named version (Gemini 3.8, 3.7, 3.6 Flash, 3.1 Pro Preview, Claude Opus 5.5 and Sonnet 5.5), and enterprise sessions run on the organisation's Google Cloud project with global, us or eu endpoints. Quotas are pooled per edition on a rolling seven-day cycle.
