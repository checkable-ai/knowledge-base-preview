## Answer

Covered. Headless runs soft-deny actions needing approval; users can widen grants.

Source statement: "When the agent encounters an operation requiring approval (Ask mode), an interactive card appears in your editor." (https://antigravity.google/docs/permissions/)

Research detail: Ask rules raise an approval card showing the specific file, URL, MCP tool or command. PreToolUse hooks can return force_ask or deny, and the SDK ask_user handler receives the concrete tool call with arguments. Headless runs soft-deny anything needing approval.

<!-- chunk: products -->
## Products

Antigravity permissions approval cards, hooks, SDK ask_user policy

<!-- chunk: gaps -->
## Gaps

Users can widen a file, URL or MCP grant for the rest of the turn, and Always allow caches grants. Replay protection and approver identity are not documented.

<!-- chunk: options -->
## Options

Use force_ask hooks for high-risk tools and log decisions from a PostToolUse hook.
