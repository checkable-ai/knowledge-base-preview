## Answer

Covered. Requires local Application Default Credentials or a per-user OAuth flow on the MCP server.

Source statement: "Set `authProviderType` to `"google_credentials"` to use Google Application Default Credentials (ADC):" (https://antigravity.google/docs/mcp/)

Research detail: MCP servers can use the user's Google ADC credentials or a per-user OAuth flow, so downstream calls carry the initiating user's authority. Inference logs record the authenticated principal. Delegated scope narrowing for the agent beyond the user's own grant is not documented.

<!-- chunk: products -->
## Products

Antigravity MCP google_credentials and OAuth, Gemini Enterprise inference logs

<!-- chunk: gaps -->
## Gaps

The agent inherits the user's full token scope. No token exchange or audience-restricted delegation.

<!-- chunk: options -->
## Options

Register OAuth clients with narrow scopes per MCP server and test what a downstream API sees.
