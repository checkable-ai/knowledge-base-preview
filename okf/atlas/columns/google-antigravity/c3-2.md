## Answer

Not covered. No central tool-call gateway. MCP allowlists and browser URL limits are per workstation, with no input schema validation, rate limits or injection screening. Hooks are user-configured and not admin-enforced.

Research detail: Admins can switch MCP off or allow only listed local and remote servers, with admin command and args overriding local config, and can limit the browser agent to allowed URLs. Google's server-side denylist blocks known bad hosts, and sandbox egress is limited to read_url-allowed domains.

<!-- chunk: products -->
## Products

Gemini Enterprise MCP allowlist and external web access, browser denylist, sandbox network allowlist, hooks

<!-- chunk: gaps -->
## Gaps

Enforcement runs on each workstation, not a central gateway. No schema validation, rate limits or injection screening for tools. Unsandboxed commands have open egress.

<!-- chunk: options -->
## Options

Pair the admin allowlist with a network egress proxy and test a non-listed MCP server.
