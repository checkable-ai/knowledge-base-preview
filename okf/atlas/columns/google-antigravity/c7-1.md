## Answer

Not covered. No tamper-evident record of each action with inputs, outputs and reasoning by user, agent and session. Optional inference logging falls short.

Last checked 12 November 2026.

Research detail: Admins can turn on prompts and responses logging and metadata logging, stored in the organisation's Cloud project, and each inference call writes an inference_response entry with user and trajectory IDs. Both settings default to disabled.

<!-- chunk: products -->
## Products

Gemini Enterprise compliance settings, Cloud Logging

<!-- chunk: gaps -->
## Gaps

Tool call inputs and outputs and reasoning text are not documented as logged. Tamper resistance depends on Cloud Logging bucket configuration. Default bucket retention is 30 days.

<!-- chunk: options -->
## Options

Enable both logs, route them with a sink to a locked bucket, and add PostToolUse hooks for tool logging.
