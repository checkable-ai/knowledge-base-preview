## Answer

Covered. Hooks are configured per workspace (.agents/hooks.json) or globally (~/.gemini/config/hooks.json). Admin-enforced locking of hooks is not documented.

Source statement: "Fires before a tool is executed." (https://antigravity.google/docs/hooks/)

Research detail: Antigravity provides one harness across 2.0, CLI, IDE extensions and the SDK that executes file, terminal, browser and MCP tools. PreToolUse, PostToolUse, invocation and Stop hooks let operators run commands around every tool call and block calls.
