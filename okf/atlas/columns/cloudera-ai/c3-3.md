## Answer

Not covered. No gateway that filters what data each agent or user can retrieve by identity or permission. Guardrails only block or mask content (such as PII) in requests and in data returned from tools and MCP servers.

Last checked 15 November 2026. This platform is checked on demand, so this answer has not been rechecked since.

Research detail: Guardrails mask PII and filter sensitive keywords before data reaches the model, including data returned by tools and MCP servers. The Agent Studio 3.0 blog says SDX policies enforce role-based access to data, but the product docs read do not describe per-agent retrieval enforcement.
