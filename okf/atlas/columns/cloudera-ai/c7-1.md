## Answer

Not covered. No documented tamper-evident or write-once record of agent actions. Cloudera AI audit logs and Phoenix traces in Agent Studio record activity, but the vendor does not document immutability, integrity validation, or export to write-once storage.

Research detail: Resource management audit logs record create, update and delete of workflows, agents, tools and MCP servers with user, operation, resource type and resource ID. Every workflow run is traced in Phoenix to sub-step level and linked to the initiating user. The Agent Studio 3.0 blog describes the logs as append-only and including prompt inputs and tool outputs.

## Products

Agent Studio resource audit logs, Phoenix workflow traces

<!-- chunk: gaps -->
## Gaps

Product docs do not state immutability, retention or export for audit logs. The append-only claim appears only in a blog.

<!-- chunk: options -->
## Options

Forward Application Logs and Phoenix traces to a write-once store and test that entries cannot be altered.
