## Answer

Covered. User-authored tools and stdio MCP servers run in the sandbox. Only local stdio MCP servers are supported.

Source statement: "within a Linux namespace (bubblewrap)" (https://docs.cloudera.com/machine-learning/1.5.5/use-ai-studios/topics/ml-shared-responsibility-model.html)

Research detail: Agent Studio is the harness that executes tools for agents. Since 3.0.0 all agents use native function calling, built-in system tools run in-process, and user-authored tools and stdio MCP servers run in a bubblewrap sandbox. A tools playground tests tools before use in a workflow.
