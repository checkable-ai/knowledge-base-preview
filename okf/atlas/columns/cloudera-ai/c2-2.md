## Answer

Covered. Cloudera AI Inference service with Cloudera AI Registry. External providers configured in Agent Studio sit outside these controls. Canary only for MLflow models.

Source statement: "Each Cloudera AI Registry has its own model catalog, versioning, access controls, and lifecycle management" (https://docs.cloudera.com/machine-learning/1.5.5/ai-inference/topics/ml-caii-key-features.html)

Research detail: Cloudera AI Inference service serves predictive and generative models, including NVIDIA NIM, on KServe with OpenAI and Open Inference Protocol APIs. Endpoints draw versioned models from Cloudera AI Registry, autoscale on requests per second or concurrency, and can run multiple versions with traffic splitting. Input and output logging can be turned on or off per service. Agent Studio can also use OpenAI-compatible external providers.

## Products

## Gaps
