## Answer

Not covered. No gateway that enforces tool allowlists, input schemas, rate limits or internet egress filtering. The Tool Call Judge in Agent Studio is an LLM-based scorer of tool requests, and MCP servers registered by contributors have no product-level endpoint allowlist, so both fall short of a control point.

Last checked 15 November 2026. This platform is checked on demand, so this answer has not been rechecked since.

Research detail: Guardrails can run when the model requests a tool call, before the tool runs, and on tool results before the model processes them, including MCP server outputs. There is no product-level allowlist of MCP servers or tool endpoints and no egress control.
