## Answer

Not covered. Retry and recovery of failed steps are not documented. Sequential tasks, Manager Agent hand-off and stop workflow exist but fall short of the full outcome.

Research detail: Agent Studio workflows run tasks sequentially, passing context forward, or through a Manager Agent that executes a plan from the Planning feature and delegates to worker agents. A running workflow can be stopped, which terminates active agents and releases compute. Deployed workflows run asynchronously and return a trace ID for status polling.
