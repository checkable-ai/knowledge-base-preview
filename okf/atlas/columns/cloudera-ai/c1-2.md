## Answer

Not covered. No product-level allowlist of MCP servers or tool endpoints and no per-tool action scopes. Service accounts only limit the whole workflow.

Research detail: Tools and MCP servers are attached to agents when a workflow is built, and a deployed workflow can run under a service account to limit what it can reach. The shared responsibility model states there is no product-level allowlist for MCP servers or tool endpoints, so any registered MCP server can make outbound connections.

## Gaps

No per-tool action scopes and no egress allowlist in the product.

<!-- chunk: options -->
## Options

Route MCP and tool subprocess traffic through a network proxy with an egress allowlist, as Cloudera recommends, and scope service account permissions in target systems.
