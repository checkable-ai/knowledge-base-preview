## Answer

Not covered. No on-behalf-of identity propagation. Shared instances use the application creator's or a service account's credentials.

Research detail: The security recommendations state that a shared instance without a service account connects to Cloudera Data Warehouse or Datalake with the credentials of the application creator, not the calling user. The documented pattern is a service account, not propagation of the initiating user's identity. Run traces record the initiating user, but that is attribution only.
