## Answer

Not covered. No gateway enforcing routing, quotas, cost or rate limits. Per-workflow guardrails screen prompts only.

Research detail: Agent Studio guardrails run before a prompt goes to the model and after the response, with prompt injection detection, PII masking and topic policies, and can block or mask. The shared responsibility model states there are no in-product per-user token limits and recommends provider limits or LiteLLM for quotas.
