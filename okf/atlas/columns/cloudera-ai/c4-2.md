## Answer

Not covered. No secret store, scoped short-lived credentials, rotation or revocation. API keys sit in project environment variables readable by Contributors.

Research detail: LLM API keys and integration credentials are stored as Workbench project environment variables, which every Contributor on the project can read. The shared responsibility model leaves unique keys, rotation and revocation to the customer. Inference service JWTs expire after one hour by default, but that applies to calling endpoints, not to brokering tool credentials for agents.

## Options
