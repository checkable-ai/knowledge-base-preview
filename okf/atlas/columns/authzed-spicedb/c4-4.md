## Answer

Partly covered. No authentication mechanism between agents is described, and there is no protocol for agents outside the cluster.

Source statement: "Delegation doesn't hand a child the parent's authority." (https://openap.org/docs/subagents-delegation)

Last checked 17 November 2026.

Research detail: No authenticated agent to agent protocol or trust boundary is documented. SpiceDB can hold relationships between agents and tasks, but AuthZed says it does not authenticate identities. The MCP pages cover documentation and development servers, not agent to agent traffic.
