## Answer

Covered. SpiceBox covers Claude Code and Claude Agent SDK agents. The kernel-level sandbox layer is macOS only. SpiceBox is open source and released as a tool for coding agents.

Source statement: "An out-of-process server checks every tool call against SpiceDB before execution." (https://authzed.com/blog/spicedb-dev-and-spicebox-add-permissions-for-ai-coding-agents)

Last checked 17 November 2026.

Research detail: SpiceBox wraps Claude Code and Claude Agent SDK agents and checks every tool call against SpiceDB through an out-of-process hook server. A macOS kernel sandbox and a network filtering proxy back it. File tools resolve to the same SpiceDB permissions.

## Products

## Gaps

Announced April 2026 as a coding agent tool. The OS layer is macOS only, it covers Claude Code and Agent SDK agents, and filesystem scope cannot be escalated mid-session. Not a general control for other agent runtimes.

## Options

Use SpiceBox for developer machines that run Claude Code and test it against the agent builds actually in use.
