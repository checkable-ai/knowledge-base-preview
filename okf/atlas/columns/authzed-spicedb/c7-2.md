## Answer

Not covered. Audit Logging can ship events to AWS Kinesis, Kinesis Firehose or GCP Pub/Sub, and SpiceDB emits JSON logs, Prometheus metrics and OpenTelemetry traces. None of this is documented as agent security monitoring: no detections, redaction, session or person linkage for agents, or response ownership.

Research detail: Audit events can be shipped to AWS Kinesis, Kinesis Firehose or GCP Pub/Sub, and plan pages list a Kafka compatible audit stream. SpiceDB also emits JSON logs, Prometheus metrics and OpenTelemetry traces.

## Gaps
