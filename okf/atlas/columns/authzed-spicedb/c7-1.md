How [AuthZed (SpiceDB)](profile.md) addresses the [Administrative Audit](../../controls/c7-1.md) control. Researcher verdict: escalated. Verification state: contested. Agents must not retrieve this page: escalated by the confirm agents, so a person settles it.

<!-- chunk: answer -->
## Answer

Escalated for a person to settle. The agent checks did not agree on this finding.

Research detail: Audit Logging publishes SpiceDB API requests and responses, with token hash, caller IP and errors, to a log sink. It is not in open source SpiceDB. The Watch API streams relationship changes. OAP says each session transcript is a signed, append-only log.

<!-- chunk: products -->
## Products

Audit Logging (Cloud, Dedicated, Enterprise), Watch API, OAP session transcripts

<!-- chunk: gaps -->
## Gaps

No tamper-proof ledger is documented for the audit log. Audit events cover SpiceDB API calls and not agent reasoning or model inputs. Watch history is kept about 24 hours by default.

<!-- chunk: options -->
## Options

Send the audit log to write-once storage and keep agent transcripts in the same store.
