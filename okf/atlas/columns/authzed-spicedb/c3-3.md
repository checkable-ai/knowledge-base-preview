## Answer

Covered, with conditions. Retrieval filtering uses SpiceDB checks that the application or the langchain-spicedb library must call. Egress gating is provided by OAP, which runs inside a cluster you operate. Provided by Open Agent Primitives (OAP), which runs self-hosted in your own Kubernetes cluster.

Source statement: "A tool call carries data out exactly like a reply does, so both are checked at the same egress line." (https://openap.org/docs/information-leakage)

Last checked 17 November 2026.

Research detail: AuthZed documents permissions-aware RAG. Documents are retrieved by similarity and each result is checked in SpiceDB before it reaches the model. A LangChain and LangGraph library wraps retrievers with this filter, and LookupResources or bulk checks support filtering at scale.

<!-- chunk: products -->
## Products

SpiceDB CheckPermission, langchain-spicedb, LookupResources, CheckBulkPermissions

<!-- chunk: gaps -->
## Gaps

Enforcement sits in the application or library, not a gateway. No DLP or content inspection is documented.

<!-- chunk: options -->
## Options

Add a DLP scanner on retrieved content and make the SpiceDB post-filter mandatory in the retrieval path.
