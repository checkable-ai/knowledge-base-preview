## Answer

Covered, with conditions. Provided by OAP, which runs inside a cluster you operate. Whether a call needs approval depends on each tool's declared stateImpact (readonly, readwrite or external). Provided by Open Agent Primitives (OAP), which runs self-hosted in your own Kubernetes cluster.

Source statement: "External/high-impact actions require explicit confirmation" (https://openap.org/docs/owasp-top10)

Last checked 17 November 2026.

Research detail: AuthZed's AI page lists human approval before high-impact actions as part of agent guardrails. SpiceBox supports mid-session permission escalation where the request is HMAC-signed, shown for approval and written to SpiceDB. OAP lets an owner approve a colleague joining an agent session.
