## Answer

Covered, with conditions. Provided by OAP, which runs inside a cluster you operate. Provided by Open Agent Primitives (OAP), which runs self-hosted in your own Kubernetes cluster.

Source statement: "a reviewable template you version and approve" (https://openap.org/docs/agent-definition)

Last checked 17 November 2026.

Research detail: Permissions for an agent can be created, changed and retired by writing and deleting relationships, including relationships that expire on their own. Restricted API Access roles and policies control who may change SpiceDB data, and a control plane API and Terraform provider provision permission systems.

<!-- chunk: products -->
## Products

WriteRelationships, expiring relationships, Restricted API Access, control plane API and Terraform provider

<!-- chunk: gaps -->
## Gaps

This provisions permissions and permission systems, not agent identities or agent configurations. There is no agent lifecycle workflow.

<!-- chunk: options -->
## Options

Drive agent grants from the agent provisioning pipeline and keep relationship writes behind a restricted service account.
