## Answer

Covered, with conditions. Provided by OAP and documented only for delegation within one cluster, which runs inside a cluster you operate. Provided by Open Agent Primitives (OAP), which runs self-hosted in your own Kubernetes cluster.

Source statement: "It can't summon an arbitrary agent by name; it can hand work only to a member of that reviewed list." (https://openap.org/docs/subagents-delegation)

Research detail: No gateway for agent to agent traffic is documented. Allowed agent pairs could be expressed as relationships, but nothing enforces schemas or pairs on the wire.
