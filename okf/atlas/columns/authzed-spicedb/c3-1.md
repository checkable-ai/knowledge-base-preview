## Answer

Partly covered. OAP does not describe a gateway that every model call passes through, nor model routing, rate limits per call or prompt injection screening of model prompts.

Source statement: "can't raise its token budget past the cluster cap" (https://openap.org/docs/settings-config)

Research detail: SpiceDB is not a model gateway. Its rate limiting applies to calls to the SpiceDB API and not to model requests, and nothing about prompt injection screening or model routing is documented.
