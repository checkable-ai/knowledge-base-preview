## Answer

Covered, with conditions. Provided by OAP, which runs inside a cluster you operate. The content guard inspects tool input and output, not the agent's own replies. Per-tool rate limits are opt-in, and the data-volume budget is per call. Provided by Open Agent Primitives (OAP), which runs self-hosted in your own Kubernetes cluster.

Source statement: "What isn't described can't be called." (https://openap.org/docs/toolspec-validation)

Last checked 17 November 2026.

Research detail: SpiceBox's hook server checks every Claude Code tool call against SpiceDB before it runs and a proxy limits outbound domains. OAP refuses reads and writes outside approved repositories before they reach GitHub, outside the model.

<!-- chunk: products -->
## Products

SpiceBox hook server and proxy, OAP authorisation

<!-- chunk: gaps -->
## Gaps

Covers Claude Code agents through SpiceBox and OAP's own tools. There is no general tool gateway with schema checks, quotas or injection screening. Rate limiting covers the SpiceDB API only.

<!-- chunk: options -->
## Options

Place a tool gateway in front of tools and have it call SpiceDB on each request.
