## Answer

Covered, with conditions. Provided by OAP on a Kubernetes cluster you operate. Micro-VM isolation needs a kata-fc runtime class that the cluster must support. Hostname allowlists need a DNS-aware CNI plugin such as Cilium or Calico. Provided by Open Agent Primitives (OAP), which runs self-hosted in your own Kubernetes cluster.

Source statement: "Each session gets its own NetworkPolicy (on by default)." (https://openap.org/docs/sandboxed-execution)

Last checked 17 November 2026.

Research detail: No agent execution host, code interpreter or network setup is documented for SpiceDB. OAP is deployed on a Kubernetes cluster that the customer provides.
