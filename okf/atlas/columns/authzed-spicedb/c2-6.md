## Answer

Covered, with conditions. Provided by OAP, which runs inside a cluster you operate. Channel-wide history is off by default and works only on Slack. Provided by Open Agent Primitives (OAP), which runs self-hosted in your own Kubernetes cluster.

Source statement: "When one session should see another's memory, you don't copy data between them - you grant it." (https://openap.org/docs/memory-authorization)

Research detail: OAP names a memory and knowledge primitive. The post describes immutable design revisions and signed session transcripts, and says the memory system can be swapped. It does not describe cross-session agent memory or its controls.
