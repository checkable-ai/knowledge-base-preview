## Answer

Partly covered. Only permission filtering of retrieved documents. No cleaning, sanitisation, data quality or governance of the data stores themselves.

Source statement: "Never fall back to unfiltered results when authorization fails." (https://authzed.com/docs/spicedb/integrations/langchain-spicedb)

Last checked 17 November 2026.

Research detail: AuthZed documents permission filtering for vector stores and retrieval data. Its RAG demo says a vector database has no ACLs and uses SpiceDB checks on returned document IDs. A LangChain library supports any vector store.

## Products

## Gaps

This is access control on retrieved data only. No sanitisation, data quality or store governance is documented.

<!-- chunk: options -->
## Options

Use SpiceDB for retrieval permissions and a separate tool for data sanitisation.
