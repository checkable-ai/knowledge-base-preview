## Answer

Covered, with conditions. Provided by OAP, which runs inside a cluster you operate. Federated credentials are minted on demand only for passthrough agents. Credentials are injected per tool call for sandbox tools and at session start for MCP servers and sidecars. Provided by Open Agent Primitives (OAP), which runs self-hosted in your own Kubernetes cluster.

Source statement: "The model never sees a credential's bytes" (https://openap.org/docs/giving-credentials)

Research detail: SpiceDB is not a secrets or credential broker. Restricted API Access issues long-lived tokens for service accounts that call SpiceDB, with advice to deploy a new token before removing the old one. These authenticate callers to SpiceDB and are not scoped credentials delivered to agents for downstream systems.

## Gaps

Outside the product's category. OAP mentions a read-only GitHub token supplied at install, with no description of brokerage, rotation or hiding secrets from model context.

<!-- chunk: options -->
## Options

Pair SpiceDB with a secrets broker or workload identity service and use SpiceDB only for the permission decision.
