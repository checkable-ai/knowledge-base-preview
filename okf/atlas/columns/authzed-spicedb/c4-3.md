## Answer

Covered, with conditions. Provided by OAP userPassthrough identity mode, which runs inside a cluster you operate. The initiating user must have linked the accounts a tool needs; the session pauses until they do. Provided by Open Agent Primitives (OAP), which runs self-hosted in your own Kubernetes cluster.

Source statement: "tools use the credentials of the person who started the session." (https://openap.org/docs/identity-modes)

Last checked 17 November 2026.

Research detail: AuthZed describes delegation as relationship data in SpiceDB. A parent agent connects to a task, a child agent is assigned a narrower part, and the child reaches only what its own relationships allow. Expiry and caveats can end or condition the delegation.

<!-- chunk: products -->
## Products

SpiceDB relationships, expiring relationships, caveats

<!-- chunk: gaps -->
## Gaps

The page says delegation policy is not automatic and the application must create the relationships. SpiceDB does not carry the initiating user's identity to downstream services itself.

<!-- chunk: options -->
## Options

Model user to agent to task relationships in the schema and have the calling service pass the user and agent subjects on every check.
