## Answer

Covered, with conditions. Provided by OAP, which runs inside a cluster you operate. Micro-VM isolation needs cluster support for the kata-fc runtime class. Provided by Open Agent Primitives (OAP), which runs self-hosted in your own Kubernetes cluster.

Source statement: "halt a run outright, or place it on a hold so it's frozen for inspection rather than torn down" (https://openap.org/docs/revocation)

Last checked 17 November 2026.

Research detail: SpiceBox adds a macOS kernel sandbox and a localhost proxy that allows only listed domains. In SpiceDB a deleted or expired relationship stops granting access, and ZedTokens let a check require data at least as fresh as a given write. AuthZed says revocations are reflected immediately.

<!-- chunk: products -->
## Products

SpiceBox, relationship deletion and expiry, ZedTokens

<!-- chunk: gaps -->
## Gaps

No deterministic stop for a running agent is documented. The sandbox layer is macOS only. Revocation takes effect only for checks that the application actually makes.

<!-- chunk: options -->
## Options

Combine SpiceDB revocation with a runtime sandbox and a way to terminate the agent process.
