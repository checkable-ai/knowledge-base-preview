## Answer

Not covered. Entity map shows observed agent and tool calls only, not the permissions or downstream systems an agent can reach but has not called.

Research detail: The entity map shows agents, the tools they invoke and in what order, and delegation between agents as directed edges, linked to services and models. The Agents Service Map draws a link whenever one agent calls another. This shows observed calls only, not the potential action scopes an agent holds.
