## Answer

Not covered. No documented way to sandbox, block or stop an agent. Drop filters only remove data before storage and alerts only notify.

Research detail: AI Monitoring captures prompts, completions, token use and traces from instrumented applications and supports alerts and dashboards. The docs describe no way to block, stop or sandbox an application or agent. The only control is drop filters, which remove sensitive data before it reaches storage and do not change application behaviour.

## Gaps

Execution containment and a kill switch sit outside an observability product. Alerts can notify, but no documented action stops an agent.

## Options
