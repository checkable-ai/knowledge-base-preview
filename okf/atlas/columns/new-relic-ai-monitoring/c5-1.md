## Answer

Not covered. No reviewer queue, labelling, annotation or sign-off workflow. The AI responses view and feedback API only display responses and collect end-user ratings that the customer builds into the application.

Research detail: The AI responses table lists each prompt and response with tokens and model, and a trace view shows detail for review. A feedback API lets applications forward end-user positive or negative ratings, which can filter the graphs. There is no reviewer queue or annotation workflow.

## Gaps
