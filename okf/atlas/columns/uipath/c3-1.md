## Answer

Not covered. No configurable quotas, cost limits or rate limits per agent, user or workload. The AI Trust Layer LLM gateway provides routing, allow lists and guardrails, but only fixed caps (custom-model token cap, Delegate monthly usage limits) are documented.

Research detail: The AI Trust Layer LLM gateway applies policies at tenant, group or user level before requests reach models. It enforces product and model allow lists, region routing, a prompt injection guardrail, harmful content and IP protection checks, and third-party guardrail vendors. Conversational agents have a per-user monthly usage limit.

<!-- chunk: products -->
## Products

AI Trust Layer, centralized guardrails

<!-- chunk: gaps -->
## Gaps

No per-agent policy level, quota or rate limit is documented. Context Grounding honours only tenant-level policies.

<!-- chunk: options -->
## Options

Use groups to approximate per-workload policies. Test the prompt injection guardrail with known payloads.
