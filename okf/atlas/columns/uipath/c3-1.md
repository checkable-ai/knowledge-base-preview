## Answer

Not covered. The AI Trust Layer LLM gateway applies routing, model allow lists and prompt guardrails, but UiPath documents no configurable quota, cost or rate limit per agent, user or workload. The only cap is the fixed per-user monthly limit for conversational agents. There is no per-agent policy level, and Context Grounding honours tenant-level policies only.

Research detail: The AI Trust Layer LLM gateway applies policies at tenant, group or user level before requests reach models. It enforces product and model allow lists, region routing, a prompt injection guardrail, harmful content and IP protection checks, and third-party guardrail vendors. Conversational agents have a per-user monthly usage limit.
