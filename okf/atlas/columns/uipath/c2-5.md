## Answer

Covered. Runs on Serverless robots via Unified Runtime.

Source statement: "The action can happen before and/or after tool execution." (https://docs.uipath.com/agents/automation-cloud/latest/user-guide/tool-guardrails)

Research detail: Unified Runtime is the shared engine that runs low-code and coded agents and their tool calls on Serverless robots. Studio Web policy caps iterations per execution between 1 and 100. Tool guardrails run in order before or after each tool call.
