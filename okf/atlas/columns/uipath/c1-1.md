## Answer

Covered. Applies to the Delegate desktop agent. Tool permissions (Allow, Ask, Block), protected files and blocked commands are configurable. The shell sandbox is labelled BETA. Low-code agents on Serverless robots have no equivalent local controls.

Source statement: "Configure when Delegate needs your approval." (https://docs.uipath.com/delegate/standalone/latest/user-guide/security-settings)

Research detail: Delegate is a desktop agent that acts with the user's access on their machine. Admins can set and lock approval mode, execution mode, screen context, blocked apps and sites, and tool permissions through Automation Ops. Guarded mode limits the agent to a project's allowed files and folders. Robot policies in Automation Ops apply Runtime Analyzer rules that restrict applications and web pages.

## Products

UiPath Delegate, Automation Ops Robot policy

## Gaps

Guarded mode is experimental and Delegate documentation is preview status. Low-code agents run on Serverless robots with no documented local scope controls.
