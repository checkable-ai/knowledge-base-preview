## Answer

Covered. Requires Automation Ops Studio Web policy. Policy enforced at publish time.

Source statement: "Set the maximum number of iterations an agent can run during a single execution." (https://docs.uipath.com/automation-ops/automation-cloud/latest/user-guide/settings-for-studio-web-policies)

Research detail: Agents are published to a feed, deployed as solutions into folders, and moved between versions with Change version. Studio Web design policies block publishing of agents that fail minimum score, temperature, token, iteration or HITL limits. The AI Trust Layer Enable Agents toggle turns agents on or off per tenant. Instance management covers terminating agents and agent jobs.
