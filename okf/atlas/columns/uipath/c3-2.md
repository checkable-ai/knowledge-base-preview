## Answer

Not covered. Tool guardrails are configured per agent and check tool inputs and outputs. There is no documented central control point for tool calls, no internet or egress control, and no per-tool limits or quotas. Workflow Analyzer rules are design-time only.

Research detail: Tool guardrails apply log, filter, block or escalate actions to tool inputs and outputs using string, number and boolean rules. Centralized guardrails can apply at tool level. MCP server management is governed by Orchestrator roles, and the MCP OAuth flow fails closed unless dynamic client registration is enabled, with a callback domain allow list. Workflow Analyzer rules restrict allowed packages and activities.

## Products

Tool guardrails, AI Trust Layer policy, Orchestrator MCP roles, Studio Web policy

## Gaps
