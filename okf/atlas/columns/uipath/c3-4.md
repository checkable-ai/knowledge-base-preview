## Answer

Not covered. Access to registered agents is governed by folder permissions on callers. No allow-list of approved agent pairs is documented. A2A messages pass through unparsed, so approved formats are not enforced beyond the protocol version.

Last checked 12 November 2026.

Research detail: Agent Gateway (preview) is the central place where external A2A agents are registered before Maestro flows and agents can use them. Outbound calls need an Agent 2 Agent connection to each remote agent.
