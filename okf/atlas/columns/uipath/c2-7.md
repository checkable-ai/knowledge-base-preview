## Answer

Not covered. Egress control left to customer. Stop and Kill not documented for agent jobs. Delegate restrictions off by default and preview.

Research detail: UiPath runs Coded and Command MCP servers in isolated, ephemeral containers without elevated privileges, with timeouts and resource limits. Orchestrator jobs can be stopped at a safe point (Stop) or killed (Kill), which moves them to Terminating and then Stopped. Delegate offers a shell command sandbox with allowed paths and blocked commands, restricted folder access and the Escape key to interrupt it.

<!-- chunk: products -->
## Products

Serverless containers, Orchestrator Stop and Kill, Delegate shell command sandbox and restricted access.

<!-- chunk: gaps -->
## Gaps

Egress control for serverless containers is left to the customer. The job states page does not say Stop and Kill apply to agent jobs, and the agent management page names terminating agents without a procedure. Delegate restricted access is off by default.

<!-- chunk: options -->
## Options

Test Kill on a running agent job and on a Delegate task, and enforce network controls outside UiPath for serverless robots.
