## Answer

Covered. Prompt-triggered escalations depend on the agent deciding to escalate. Tool guardrail escalations are deterministic.

Source statement: "Select Continue if the agent should resume its process using the inputs provided by the escalation assignee." (https://docs.uipath.com/agents/automation-cloud/latest/user-guide/agent-escalations-and-agent-memory)

Research detail: Escalations send a task to a named recipient through Action Center apps, and each outcome maps to Continue or End. Tool guardrails can escalate a specific tool call before execution based on its inputs, which binds the decision to the proposed call. A Studio Web policy can require at least one human-in-the-loop escalation before publishing. Delegate asks for confirmation on data-changing actions.

<!-- chunk: products -->
## Products

Action Center escalations, tool guardrails, Studio Web design policy, Delegate approvals

<!-- chunk: gaps -->
## Gaps

Prompt-triggered escalations are non-deterministic. Replay handling and timeouts are not documented. Escalation memory (preview) can reuse a past human resolution without raising a new escalation.

<!-- chunk: options -->
## Options

Use tool guardrail escalation rather than prompt-based escalation for consequential actions. Disable escalation memory where each approval must be fresh.
