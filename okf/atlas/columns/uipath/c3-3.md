## Answer

Not covered. No documented filtering of what data each agent and user can retrieve. PII in-flight masking (off by default, selected entities only) and tool guardrail field filtering are nearby features but do not authorise retrieval per agent or user.

Research detail: In-flight PII masking replaces detected entities with placeholders in agent prompts and runtime files before the LLM call and restores them in the response. Tool guardrail filter actions remove fields from tool inputs or outputs. Restrict Insights Trace data limits what reaches Insights.
