## Answer

Covered. Agent memory is in preview. A memory space must be configured. Items can be inspected and deleted, not edited. No retention policy is documented.

Source statement: "Multiple agents can share one memory space, which lets them learn from each other's cases." (https://docs.uipath.com/agents/automation-cloud/latest/user-guide/agent-memory)

Research detail: Agent memory (preview) offers episodic memory of past cases and feedback, and escalation memory of human resolutions. Memory spaces can be shared across agents, and items can be inspected and deleted in Agents instance management. Customer managed key encryption is set when a space is created.

<!-- chunk: products -->
## Products

Agent memory, memory spaces

<!-- chunk: gaps -->
## Gaps

Preview feature. The memory page does not describe access control or a retention policy. Memory items cannot be edited, only deleted and re-added.

<!-- chunk: options -->
## Options

Restrict who can manage memory spaces and review stored items before production.
