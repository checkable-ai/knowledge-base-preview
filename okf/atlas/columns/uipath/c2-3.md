## Answer

Not covered. No documented network isolation or egress filtering for the agent runtime. The advanced agent code interpreter is documented as having no network or filesystem access, but that covers only the interpreter, not the machine or container running the agent or its network access. The vendor does not state that this meets part of the outcome.

Last checked 12 November 2026.

Research detail: Agent jobs run on Serverless robots through Unified Runtime on UiPath-managed infrastructure. For Coded and Command MCP servers UiPath describes isolated ephemeral containers without elevated privileges, with timeouts and resource limits. Delegate runs on the user's own Windows machine.
