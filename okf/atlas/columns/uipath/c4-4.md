## Answer

Not covered. Agent Gateway is preview and docs do not describe A2A authentication or inbound authorisation across trust boundaries.

Research detail: Agent Gateway (preview) registers external A2A agents and MCP servers as platform resources, and UiPath conversational agents expose an A2A agent card inbound. Maestro calls a remote A2A agent through the Invoke an Agent activity, which needs an Agent 2 Agent Integration Service connection and selects skills from the remote Agent Card.
