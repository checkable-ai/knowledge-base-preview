## Answer

Not covered. No native approval of changes. Prompt, permission and knowledge changes not versioned separately.

Research detail: Agent versions increment on each publish, and Change version upgrades or rolls back a solution deployment. Design policies apply to each new version before republishing. Model versions can be locked by turning off auto allow new models.
