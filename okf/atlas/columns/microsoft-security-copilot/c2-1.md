## Answer

Partly covered. No documented cancellation, retry or recovery behaviour for agent runs. The node map is only a high-level summary of steps.

Source statement: "Promptbooks are sequences of prompts that run in order to accomplish specific security tasks." (https://learn.microsoft.com/en-us/copilot/security/security-copilot-application-card-agents)

Last checked 17 November 2026.

Research detail: Agents run on a schedule, on an alert trigger or on demand, promptbooks run prompts in sequence, and Logic Apps and Copilot Studio connectors call the platform from workflows. Agents show step by step node maps. Cancellation, retry and recovery behaviour for agent runs is not documented.
