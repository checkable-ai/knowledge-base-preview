## Answer

Covered, with conditions. The Conditional Access Optimization Agent needs at least a Microsoft Entra ID P1 license and available security compute units. Only the Conditional Access Administrator and Security Administrator roles can act on suggestions, while Security Reader and Global Reader can only view them. The ServiceNow integration and least-privileged access suggestions for agent identities are in preview. Partner-built agents that access Microsoft product data also need Global Administrator approval before setup.

Source statement: "As the administrator, you need to review the suggestions and decide what to do." (https://learn.microsoft.com/en-us/entra/security-copilot/conditional-access-agent-optimization-review-suggestions)

Last checked 17 November 2026.

Research detail: Agents that take scoped actions need user or administrator approval. A partner-built agent that touches Microsoft product data needs a Global Administrator to approve the permissions before setup can finish. Triage agents decide and classify on their own, and analysts review verdicts afterwards.

## Products

Agent setup approval, Global Administrator consent

<!-- chunk: gaps -->
## Gaps

Approval is of agent permissions at setup, not of each proposed action. Replay and denial handling are not documented.

<!-- chunk: options -->
## Options

Limit agents to read and classify permissions and add approval steps in the response workflow.
