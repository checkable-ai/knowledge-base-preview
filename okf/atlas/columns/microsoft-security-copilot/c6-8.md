## Answer

Not covered. No approval workflow, versioning or rollback of changes to prompts, tools, permissions or knowledge. Agent changes appear in the audit log and release notes are published, which fall short.

Last checked 17 November 2026.

Research detail: Capabilities pass through private and public preview and Microsoft publishes release notes. Custom plugins should be vetted at user scope before tenant release, and agent changes are audited. There is no staged release or rollback of agent or permission changes.
