## Answer

Not covered. The Purview Unified Audit Log records admin events and user activity metadata, and prompt/response pairs go to DSPM for AI, but the documentation does not describe write-once or integrity-validated storage. It does not document per-action records of agent tool calls and data access either: agent execution is shown only as a summarised node map. The Sentinel export route is not described as tamper-evident.

Last checked 17 November 2026.

Research detail: Security Copilot writes admin events and activity metadata to the Microsoft Purview Unified Audit Log and prompt and response pairs to Purview DSPM for AI. Agent create, update and delete actions are audited. Default retention is 180 days. The documentation does not claim tamper-proofing, and agent reasoning is only shown as a node map.
