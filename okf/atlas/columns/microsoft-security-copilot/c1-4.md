## Answer

Covered, with conditions. Only Security Copilot owners and contributors can set up and edit agents. Partner-built agents that access Microsoft product data need Global Administrator approval. Some agents are in public preview. Audit of agent changes goes through Microsoft Purview audit logging, which an administrator must turn on. The Phishing Triage Agent requires Microsoft Defender for Office 365 Plan 2 and provisioned Security Copilot SCUs.

Source statement: "Owners and Contributors can edit an agent to modify its configuration settings." (https://learn.microsoft.com/en-us/copilot/security/agents-manage)

Last checked 17 November 2026.

Research detail: Owners and contributors set up agents from a library or the Security Store, choose identity, trigger and parameters, edit settings later, and pause or run them. Partner agents need Global Administrator approval and agent create, update and delete actions are logged in the Unified Audit Log. RBAC controls who can do this.

<!-- chunk: products -->
## Products

Agent library, Security Store, agent setup and edit, Purview audit of agent changes

<!-- chunk: gaps -->
## Gaps

Retirement is by pause or delete and there is no separate review step. Some agents are in preview.

<!-- chunk: options -->
## Options

Restrict who holds the contributor and owner roles and audit agent changes.
