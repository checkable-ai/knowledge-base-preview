## Answer

Covered, with conditions. Prompt evaluation location can be set to Australia (ANZ), Europe (EU), United Kingdom (UK) or United States (US), or opted in to anywhere in the world. Data storage location is chosen at workspace creation and cannot be changed afterwards. When data sharing is opted in, prompts and responses may be stored outside the workspace geo. Default settings differ for Microsoft 365 E5 and E7 customers. Government and Microsoft Sovereign Public/Private Cloud are not supported. Usage is bound by provisioned and overage SCU capacity. GCC customers on the Security Copilot Commercial SKU have data stored in the US Geo of the Azure Public Cloud.

Source statement: "Prompts are evaluated using GPU resources in Azure datacenters protected with Azure security and privacy controls." (https://learn.microsoft.com/en-us/copilot/security/privacy-data-security)

Research detail: Security Copilot uses Azure OpenAI models and prompts are evaluated on GPU resources in Azure datacenters. Customers choose where prompts are evaluated (Australia, EU, UK or US) or opt in to anywhere, and customer data is not used to train the models. Capacity limits bound use and new model versions are announced in the release notes.

<!-- chunk: products -->
## Products

Azure OpenAI models, prompt evaluation location setting, SCU capacity

<!-- chunk: gaps -->
## Gaps

Model version pinning is not offered. Opting in to anywhere evaluation or data sharing can move data outside the chosen geo.

<!-- chunk: options -->
## Options

Choose the Australia evaluation location and keep data sharing off unless approved.
