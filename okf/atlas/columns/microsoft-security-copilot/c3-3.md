## Answer

Partly covered. No retrieval filter per agent beyond each service's RBAC, and no data loss prevention inside Security Copilot itself.

Source statement: "Security Copilot runs queries as the user, so it never has elevated privileges beyond what the user has." (https://learn.microsoft.com/en-us/copilot/security/privacy-data-security)

Last checked 17 November 2026.

Research detail: Owners can switch off Security Copilot's access to Microsoft 365 data and decide who may upload files. Prompt and response content can be governed with Purview DSPM for AI policies. There is no retrieval filter per user beyond each service's RBAC.

<!-- chunk: products -->
## Products

Microsoft 365 data access setting, file upload setting, Purview DSPM for AI

<!-- chunk: gaps -->
## Gaps

DLP over prompts depends on Purview DSPM for AI being configured separately.

<!-- chunk: options -->
## Options

Configure DSPM for AI policies and restrict uploads.
