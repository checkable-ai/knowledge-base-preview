## Answer

Partly covered. No documented short-lived credentials, rotation, expiry or revocation controls for agent credentials, and no statement that secrets are kept out of model context.

Source statement: "Using Agent IDs keeps access scoped, secure, and easier to manage." (https://learn.microsoft.com/en-us/copilot/security/agents-overview)

Research detail: Each agent runs under either a managed identity or a user account, and Entra agent permissions are granted to the identity by the platform. Plugins authenticate according to their provider, with per-user setup for some. How tokens are rotated, expired or kept out of model context is not documented.

<!-- chunk: products -->
## Products

Entra Agent ID, managed identity, plugin authentication

<!-- chunk: gaps -->
## Gaps

No documented rotation, expiry or revocation controls for agent credentials. Website plugins use anonymous authentication.

<!-- chunk: options -->
## Options

Use Entra Agent ID and review plugin authentication per provider.
