## Answer

Covered, with conditions. The Security Alert Triage Agent is in preview and some agents are in public preview. For autonomous triage agents, review happens after the verdicts. The node map is a summary, not a full trace. The Phishing Triage Agent requires Microsoft Defender for Office 365 Plan 2 and provisioned Security Copilot SCUs.

Source statement: "Agents surface their reasoning transparently so that analysts can review, validate, or override conclusions before acting on them." (https://learn.microsoft.com/en-us/copilot/security/security-copilot-application-card-agents)

Last checked 17 November 2026.

Research detail: Agents show their reasoning in plain language and visual node maps so analysts can review, validate or override verdicts. Analysts can give feedback that teaches the agent. Triage agents can resolve alerts they judge to be false positives without a person first reviewing them.
