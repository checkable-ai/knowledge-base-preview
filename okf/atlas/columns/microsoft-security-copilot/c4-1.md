## Answer

Partly covered. Partner and custom agents get no dedicated identity (they inherit a user's access). No documented tie between an agent identity and the release or runtime location of the agent.

Source statement: "This option creates a dedicated identity for the agent using the Microsoft Entra Agent ID capability." (https://learn.microsoft.com/en-us/copilot/security/agents-overview)

Last checked 17 November 2026.

Research detail: During agent setup an owner or contributor picks the agent's identity. For Microsoft-built agents this can be a dedicated Microsoft Entra Agent ID, and otherwise the agent runs as an existing user account. Entra agents get a unique identity when switched on. No release or runtime linkage is documented.

<!-- chunk: products -->
## Products

Microsoft Entra Agent ID, agent setup identity choice

<!-- chunk: gaps -->
## Gaps

The dedicated agent identity is limited to Microsoft-built agents. Partner and custom agents use a user account that inherits that user's access.

<!-- chunk: options -->
## Options

Prefer Entra Agent ID where offered and use a dedicated service account for other agents.
