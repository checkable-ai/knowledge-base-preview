Not covered. Owner settings configure data sharing, audit logging, file upload and plugins, but there is no authoring, ownership, versioning, publication or review of AI policies.

Last checked 17 November 2026.

Research detail: Owner settings act as tenant policy for data sharing, Microsoft 365 data access, audit logging, file upload and custom plugin use. Owners are the accountable role. There is no versioning, publication or review cycle for these settings.
