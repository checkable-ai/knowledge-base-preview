## Answer

Covered, with conditions. On-behalf-of authentication applies to Microsoft plugins; the plugin provider determines authentication for other plugins. Users need the Security Copilot role plus each service's own role. Shared session links are read-only and do not re-check the viewer's plugin access. Each Microsoft plugin needs its own service roles and licences for the user.

Source statement: "Copilot uses on-behalf-of authentication to access security-related data through active Microsoft plugins." (https://learn.microsoft.com/en-us/copilot/security/authentication)

Last checked 17 November 2026.

Research detail: Security Copilot uses on-behalf-of authentication to reach security data through Microsoft plugins, so a user's Entra and Azure RBAC decides which plugins and data are available in a prompt. It does not go beyond the access the user has. Shared session links are read-only and bypass plugin access checks for the viewer.

<!-- chunk: products -->
## Products

On-behalf-of authentication, Entra and Azure RBAC

<!-- chunk: gaps -->
## Gaps

Non-Microsoft plugins set their own authentication. A shared session shows prior results to a recipient who may lack access to the underlying service.

<!-- chunk: options -->
## Options

Review plugin roles per user and restrict session sharing for sensitive investigations.
