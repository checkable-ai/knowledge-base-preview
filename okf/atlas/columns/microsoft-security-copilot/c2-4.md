## Answer

Covered, with conditions. Shared sessions can only go to users in the same tenant who have Copilot access. Session sharing by email is not supported in the SouthAfricaNorth and UAENorth regions. Session data is deleted after 180 days of inactivity. Uploaded files are available only to the uploading user.

Source statement: "Only the user that creates a session controls which Copilot users can access that session." (https://learn.microsoft.com/en-us/copilot/security/authentication)

Last checked 17 November 2026.

Research detail: Each session holds its prompts and responses and only the creator controls who can open a shared session, which is read-only and limited to the same tenant. Uploaded files are visible only to the uploader. Session data is deleted after 180 days of inactivity.

<!-- chunk: products -->
## Products

Sessions, shared sessions, file upload controls

<!-- chunk: gaps -->
## Gaps

Shared sessions bypass the viewer's plugin access check. Some regions do not support session sharing by email.

<!-- chunk: options -->
## Options

Limit sharing and set the upload permission to owners where content is sensitive.
