## Answer

Covered, with conditions. Only Copilot owners can view the usage monitoring dashboard, which holds up to 90 days of data and can be exported to Excel. Billing can be viewed in Azure. The Phishing Triage Agent needs Security Copilot with provisioned SCU capacity and Microsoft Defender for Office 365 Plan 2. Its expanded Security Alert Triage capabilities are in preview. Agent card metrics run from the first recorded incident or the last 30 days, whichever is more recent.

Source statement: "This data helps demonstrate the agent's impact and can be used to inform broader strategic conversations, highlight return on investment, or support decisions around scaling automation across your organization." (https://learn.microsoft.com/en-us/defender-xdr/phishing-triage-agent)

Research detail: The usage monitoring dashboard shows SCUs consumed, provisioned and overage units, session initiator, category, type, experience and plugin, with 90 days of data and export to Excel. Billing is visible in Azure and a cost estimator helps size capacity.

## Products

## Gaps
