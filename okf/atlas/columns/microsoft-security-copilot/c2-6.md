## Answer

Covered. Visibility into stored agent feedback varies by agent experience and user role. Session data is kept while the subscription is active and deleted after 180 days of inactivity.

Source statement: "You can control what information the agent retains and uses, ensuring that it considers relevant data when forming outputs." (https://learn.microsoft.com/en-us/copilot/security/agents-manage)

Research detail: Session history is kept while the subscription is active and for up to 180 days of inactivity per session. Agents keep memory in the form of analyst feedback that owners and contributors can review and reject. Customers can request deletion and data is deleted when capacity is removed.
