## Answer

Partly covered. No documented redaction of sensitive data, no ready-made detections for agent activity, and no named owner for response. Session-level correlation is only partly documented.

Source statement: "Blog that provides insight on how to leverage sending Security Copilot audit logs to your cloud native SIEM to gain deeper insights into usage and take proactive measures to mitigate risks." (https://learn.microsoft.com/en-us/copilot/security/audit-log)

Last checked 17 November 2026.

Research detail: Audit events flow to Purview and Microsoft publishes guidance for sending Security Copilot audit logs to Microsoft Sentinel. Events carry user and activity details. Detections and response ownership are the customer's to build.
