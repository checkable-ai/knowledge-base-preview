## Answer

Covered, with conditions. Some agents are in public preview. Permissions are set per agent at setup. Access to plugin data still follows each service's RBAC. Entra agent permissions cannot be changed or removed.

Source statement: "In the context of agents, permissions are the level of authorization an AI agent is given by an administrator during configuration that enables it to access specific information or carry out its tasks." (https://learn.microsoft.com/en-us/copilot/security/agents-overview)

Last checked 17 November 2026.

Research detail: Administrators set each agent's permissions at setup, such as read or write on alerts, and an agent can only act within them. Plugin availability can be limited to owners, and users can review an agent's triggers, data access, identity and action permissions. Access to plugin data still follows each service's RBAC.

<!-- chunk: products -->
## Products

Agent permissions, plugin availability settings, Entra and Azure RBAC

<!-- chunk: gaps -->
## Gaps

Scopes are set per agent and product and are not a general policy language. Some agent permissions on Entra agents cannot be changed or removed.

<!-- chunk: options -->
## Options

Grant agents only the roles in the least privilege list and review permissions at each agent change.
