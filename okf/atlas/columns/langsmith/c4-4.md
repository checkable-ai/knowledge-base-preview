## Answer

Not covered. No agent-to-agent authentication or trust boundaries documented.

Research detail: Agent Server exposes an A2A v1.0 JSON-RPC endpoint per assistant at /a2a/{assistant_id} with an Agent Card at /.well-known/agent-card.json. Agent Server requires a LangSmith API key by default on Cloud and accepts custom auth handlers.

<!-- chunk: products -->
## Products

Agent Server A2A endpoint, custom auth

<!-- chunk: gaps -->
## Gaps

The A2A page does not describe A2A-specific authentication or trust boundaries, and authenticated extended cards are not accepted. Self-hosted Agent Server has no default authentication.

## Options
