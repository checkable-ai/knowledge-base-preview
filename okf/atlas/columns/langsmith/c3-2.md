## Answer

Not covered. No tool-call gateway with allowlists, input schemas, quotas or dangerous-action blocks; Fleet tool approval and sandbox egress fall short.

Research detail: Sandbox egress rules allow or deny destinations per sandbox and inject credentials for matched hosts. Fleet sets which tools an agent can use and a per-tool approval mode, and pulls tools from MCP servers configured in workspace settings.

<!-- chunk: products -->
## Products

Sandbox auth proxy, Fleet connections

<!-- chunk: gaps -->
## Gaps

No gateway enforces per-agent tool allowlists, schemas, quotas or dangerous action filtering for MCP or API tool calls outside Fleet and sandboxes. No injection screening on tool output.

<!-- chunk: options -->
## Options

Place an MCP or API gateway in front of tools and use sandbox allow lists for egress.
