## Answer

Not covered. No security telemetry feed to a SOC, detections linked to sessions and people, or named response owner. Engine notifications are general issue alerts.

Research detail: Audit log events are returned in OCSF v1.7.0 API Activity format through an API, and the docs describe a scheduled pull to forward them to a SIEM. Bulk export writes trace data to S3 in Parquet. Gateway spans record matched, passed and violated policies.
