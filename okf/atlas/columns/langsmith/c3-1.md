## Answer

Covered. LLM Gateway is in beta; only calls routed through it are controlled; no prompt injection screening documented.

Source statement: "The gateway routes each request to the provider named in its model ID" (https://docs.langchain.com/langsmith/llm-gateway)

Research detail: The LLM Gateway (beta) enforces spend caps, request and token rate limits, and model access allowlists scoped to organisation, workspace, user or API key, and can split limits per end customer with X-Gateway headers. Blocked requests return 402, 429 or 403 and are traced with the policy violation.

<!-- chunk: products -->
## Products

LLM Gateway spend, rate limit and model access policies

<!-- chunk: gaps -->
## Gaps

Beta. No prompt injection screening is documented. Header-based per-customer limits trust headers set by the caller.

<!-- chunk: options -->
## Options

Route all model traffic through the gateway and block direct provider egress.
