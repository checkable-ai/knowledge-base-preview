## Answer

Covered. Fleet agents using user credentials mode; each user authenticates individually.

Source statement: "With user credentials, each user authenticates individually the first time they interact with the agent." (https://docs.langchain.com/langsmith/fleet/agent-identity)

Research detail: Custom authentication on Agent Server adds the authenticated user, and any user tokens the handler returns, to the run context as langgraph_auth_user so agents can act on the user's behalf. Fleet agents can run with user credentials, where each user authenticates and the agent uses that user's tokens. Agent Auth can scope OAuth tokens to a user or agent.

## Products

Agent Server custom auth, Fleet user credentials, Agent Auth

## Gaps
