## Answer

Covered. Fleet tools set to Ask pause for approval. On Agent Server, approval needs interrupts implemented in graph code.

Source statement: "The agent pauses and waits for your approval before the tool runs." (https://docs.langchain.com/langsmith/fleet/essentials)

Last checked 14 November 2026.

Research detail: Agent Server supports LangGraph dynamic and static interrupts to review, edit and approve tool calls before they run. Fleet sets an approval mode per tool, and Ask pauses the agent until a user responds. Fleet also asks for approval before memory updates by default.
