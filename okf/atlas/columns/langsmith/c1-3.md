## Answer

Covered. Fleet tools set to Ask; Agent Server requires interrupts implemented in graph code.

Source statement: "To require approval for a tool, set it to Ask. When the agent reaches that tool, it pauses until you respond." (https://docs.langchain.com/langsmith/fleet/essentials)

Research detail: Agent Server supports LangGraph dynamic and static interrupts to review, edit and approve tool calls before they run. Fleet sets an approval mode per tool, and Ask pauses the agent until a user responds. Fleet also asks for approval before memory updates by default.
