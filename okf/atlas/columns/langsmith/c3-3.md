## Answer

Not covered. No filtering of data retrieval per agent or user; gateway data policies cover model requests only.

Research detail: LLM Gateway data policies scan outbound model requests for secrets and PII and replace them with placeholders before they reach the provider, then restore values in the response. Policies are scoped to organisation, workspace, user or API key. SDK masking can hide or redact trace inputs and outputs.

<!-- chunk: products -->
## Products

LLM Gateway data policy, SDK masking

<!-- chunk: gaps -->
## Gaps

PII redaction is off by default and enabled for selected organisations. Redaction covers model requests, not retrieval. Scans that time out are allowed by default.

<!-- chunk: options -->
## Options

Request the PII entitlement, set On timeout to Block request, and enforce retrieval access in the data layer.
