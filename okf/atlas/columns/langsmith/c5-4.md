## Answer

Covered, with conditions. Needs a self-hosted LangSmith deployment with an existing Datadog or Grafana/Prometheus monitoring installation. Grafana 13 or later is needed. Self-hosted hosting with a control plane requires Enterprise with Agent Server hosting enabled.

Source statement: "Use them to monitor the components running in your infrastructure from one dashboard per monitoring platform." (https://docs.langchain.com/langsmith/self-host-observability-dashboards)

Last checked 14 November 2026.

Research detail: Prebuilt dashboards show trace count, error rates, latency and token usage per project or agent environment, and alerts trigger on latency and error thresholds.

## Products

## Gaps
