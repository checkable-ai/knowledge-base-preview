## Answer

Not covered. No per-command or per-file action policy on the agent's own machine. Sandboxes isolate execution rather than govern what the agent may do.

Last checked 14 November 2026.

Research detail: LangSmith Sandboxes run agent code and filesystem operations in isolated environments. By default only the sandbox creator can execute commands, read or write files, open tunnels or reach service URLs, and others need the sandboxes:exec permission. Egress is controlled per sandbox.

## Gaps

No per-command or per-file policy inside the sandbox is documented. Agents that run outside LangSmith sandboxes are not covered.

## Options
