## Answer

Not covered. No per-command or per-file action policy on the agent's own machine; sandbox isolation limits access, not actions.

Research detail: LangSmith Sandboxes run agent code and filesystem operations in isolated environments. By default only the sandbox creator can execute commands, read or write files, open tunnels or reach service URLs, and others need the sandboxes:exec permission. Egress is controlled per sandbox.

## Gaps
