## Answer

Covered. LLM Gateway is in beta; only calls routed through it are controlled; execution location stays with the upstream provider.

Source statement: "The gateway routes each request to the provider named in its model ID" (https://docs.langchain.com/langsmith/llm-gateway)

Research detail: The LLM Gateway (beta) routes calls to an explicit provider-prefixed model ID, translates between Chat Completions, Messages and Responses formats, and applies rate limits and data policies. Model execution happens at the upstream provider or with Gateway Credits models billed by LangChain.
