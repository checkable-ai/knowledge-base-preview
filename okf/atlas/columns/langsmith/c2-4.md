## Answer

Covered, with conditions. Threads do not expire unless a TTL is configured. Global TTL applies to new threads only. Access control needs custom auth handlers. Self-hosted hosting with a control plane requires Enterprise with Agent Server hosting enabled.

Source statement: "If omitted, threads do not expire by default." (https://docs.langchain.com/langsmith/configure-ttl)

Last checked 14 November 2026.

Research detail: Agent Server persists threads and checkpoints in PostgreSQL by default, so runs can resume from a checkpoint. Checkpoint TTL policies delete or prune expired thread state, with per-thread overrides. Authorization handlers control access to the threads resource.

## Products

Agent Server threads and checkpointer

## Gaps

TTL is off unless configured. Access control on threads needs custom auth handlers.

## Options
