## Answer

Covered. TTL must be configured; access control needs custom auth handlers.

Source statement: "Setting a TTL automatically deletes or prunes expired data." (https://docs.langchain.com/langsmith/configure-ttl)

Research detail: Agent Server persists threads and checkpoints in PostgreSQL by default, so runs can resume from a checkpoint. Checkpoint TTL policies delete or prune expired thread state, with per-thread overrides. Authorization handlers control access to the threads resource.

## Products

## Gaps
