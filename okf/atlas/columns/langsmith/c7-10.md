## Answer

Covered. Private beta; LangSmith Cloud only, for organisations where it has been enabled. Tests agents on LangSmith Cloud deployments only. Each run bounded: up to 50 hypotheses, 2 probes each, 100 requests.

Source statement: "Red Teaming tests a deployed agent by sending it new, synthetic requests and judging how it responds." (https://docs.langchain.com/langsmith/engine-red-teaming)

Research detail: Engine Red Teaming sends synthetic probes to a deployed agent and judges responses across ten issue classes, including indirect injection, data exposure, auth isolation and tool safety, producing a report of hypotheses and verdicts.
