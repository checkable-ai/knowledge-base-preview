## Answer

Not covered. No short-lived scoped agent credentials with rotation and revocation; API key expiry and sandbox auth proxy fall short.

Research detail: The sandbox auth proxy injects credentials from workspace secrets into matching outbound requests from outside the sandbox, signs AWS requests with SigV4 using renewable temporary credentials from an assumed IAM role, and keeps GCP service account JSON outside the sandbox. Agent Auth stores and refreshes OAuth tokens for agents. The LLM Gateway holds provider keys as workspace provider secrets.

<!-- chunk: products -->
## Products

Sandbox auth proxy, Agent Auth, LLM Gateway provider secrets

<!-- chunk: gaps -->
## Gaps

Agent Auth returns the token to agent code, so it can reach model context. Rotation of stored workspace secrets is not described as automatic. Proxy injection applies only to LangSmith sandboxes.

<!-- chunk: options -->
## Options

Route tool calls that need secrets through sandboxes with proxy rules, and test that tokens do not appear in traces.
