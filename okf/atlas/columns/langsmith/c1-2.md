## Answer

Covered. Fleet agents only; per-tool approval mode set in the Connections drawer.

Source statement: "Each tool has an approval mode you can set in the Connections drawer of the agent sidebar." (https://docs.langchain.com/langsmith/fleet/essentials)

Research detail: Fleet agents have a Connections drawer that sets which integrations and tools an agent can use and whether each runs automatically or asks for approval. Sandbox access_control allow and deny lists restrict outbound destinations, and AWS role authentication limits AWS actions to the customer role. Agent Server authorization handlers restrict access to threads, assistants and runs.

<!-- chunk: products -->
## Products

Fleet connections, sandbox access_control, Agent Server authorization handlers

<!-- chunk: gaps -->
## Gaps

No central per-agent scope policy for connected systems outside Fleet. Scopes on downstream APIs depend on the credentials connected.

<!-- chunk: options -->
## Options

Use least-privilege OAuth scopes and IAM roles for agent credentials and review Fleet connections per agent.
