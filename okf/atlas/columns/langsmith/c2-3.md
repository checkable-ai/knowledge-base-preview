## Answer

Covered. Sandboxes; restricted egress is default for non-Enterprise organisations; policy changes may not reach existing sandboxes.

Source statement: "Sandboxes are isolated environments that allow agents to safely execute potentially risky operations" (https://docs.langchain.com/langsmith/sandboxes)

Research detail: LangSmith Sandboxes are isolated environments for running code and filesystem operations. An egress proxy controls every outbound TCP connection with allow or deny lists, refuses private, loopback and cloud-metadata addresses, and drops UDP and ICMP. Non-Enterprise organisations get restricted egress to a managed allowlist by default.

<!-- chunk: products -->
## Products

LangSmith Sandboxes, sandbox auth proxy

<!-- chunk: gaps -->
## Gaps

Default egress for organisations without restricted egress allows every hostname on every TCP port. Policy changes do not update existing sandboxes.

<!-- chunk: options -->
## Options

Set an allow_list on every sandbox and confirm restricted egress is enabled for the organisation.
