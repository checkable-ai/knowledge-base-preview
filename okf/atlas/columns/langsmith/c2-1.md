## Answer

Covered. Agent Server; checkpoint durability mode controls recovery granularity.

Source statement: "When a client creates a run, the API server enqueues it and a queue worker picks it up for execution." (https://docs.langchain.com/langsmith/agent-server)

Research detail: Agent Server enqueues runs on a task queue where workers execute them and can be signalled to cancel. Runs can be cancelled by interrupt, which keeps checkpoints for resumption, or rollback, which removes them. Double texting options (enqueue, reject, interrupt) handle input that arrives during a run.
