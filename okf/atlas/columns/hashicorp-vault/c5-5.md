## Answer

Not covered. Ceiling policies and the Agent Registry UI show Vault paths and policies only, with no map of downstream systems an agent can reach or what it can do there.

Research detail: The Agent Registry UI in Vault Enterprise 2.1 shows agent identities, authentication activity, policies and namespaces. Ceiling policies state the maximum Vault paths an agent can reach. It does not show reach into downstream systems.
