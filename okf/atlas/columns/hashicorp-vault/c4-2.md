## Answer

Covered. Dynamic secrets and Vault Agent are available in all editions. Agentic IAM is Vault Enterprise 2.1 or HCP Vault Dedicated. The beta MCP server returns secret values to the client and model.

Source statement: "When a lease is revoked, it invalidates that secret immediately and prevents any further renewals." (https://developer.hashicorp.com/vault/docs/concepts/lease)

Research detail: Vault issues dynamic secrets with leases and TTLs, supports renewal, and revokes leases individually, by token or by prefix, which deletes the backing credential (for example AWS keys). Vault Agent authenticates, renews and renders secrets into files or child process environment variables, so applications do not handle Vault tokens. Agentic IAM issues a Vault token that lasts only for one request.

<!-- chunk: products -->
## Products

Secrets engines with leases, Vault Agent templating and process supervisor mode, Vault Enterprise agentic IAM

<!-- chunk: gaps -->
## Gaps

The beta Vault MCP server returns secret values to the MCP client and its LLM, so keeping secrets out of model context depends on how the agent calls Vault.

<!-- chunk: options -->
## Options

Use Vault Agent or a tool-side broker that injects credentials outside the prompt, and avoid secret-reading tools in model-facing MCP servers. Test by inspecting agent transcripts for secret values.
