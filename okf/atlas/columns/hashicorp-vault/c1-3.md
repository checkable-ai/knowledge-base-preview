## Answer

Not covered. Control groups hold a Vault request until named group members authorise it, but the page documents no denial or repeat-attempt handling and does not cover approval of an agent's proposed downstream action.

Research detail: Vault Enterprise control groups hold a request until a set number of members of named identity groups approve it. The requester gets a time-limited response wrapping token, and only approvals for that request count. The page does not describe an explicit denial workflow, and approval covers a Vault request, not an agent's proposed downstream action.
