## Answer

Not covered. The Agent Registry (Vault Enterprise 2.1+) records a display name, description, owner and ceiling policies per agent, but has no runtime, version or release attributes, so identity is not tied to where the agent runs or which release it is.

Research detail: The Vault Agent Registry (Vault Enterprise 2.1 or HCP Vault Dedicated) records each AI agent against a Vault Identity entity, with a unique display name, description, owner and ceiling policies. Vault rejects OAuth credentials from entities with no registration record. Records do not link the identity to a runtime or release.
