## Answer

Not covered. The Agent Registry (Vault Enterprise 2.1 or later) gives each agent one Vault identity entity and an optional owner field. Its record has no runtime, deployment location, version or release fields, so identity is not tied to where the agent runs or which release it is. The vendor page does not state that it covers part of the outcome.

Last checked 16 November 2026.

Research detail: The Vault Agent Registry (Vault Enterprise 2.1 or HCP Vault Dedicated) records each AI agent against a Vault Identity entity, with a unique display name, description, owner and ceiling policies. Vault rejects OAuth credentials from entities with no registration record. Records do not link the identity to a runtime or release.

## Gaps

No runtime, version or release attributes on the registration record. Enterprise or HCP Vault Dedicated only.

## Options
