## Answer

Covered. Vault Enterprise 2.1 Agent Registry. Covers the agent's Vault registration and access configuration.

Source statement: "Create or update an Agent Registry record." (https://developer.hashicorp.com/vault/api-docs/secret/agent-registry)

Research detail: The Agent Registry API creates, reads, updates, lists and deletes agent registrations, and the Terraform Vault provider adds a vault_agent_registration resource. Policies, entities and namespaces are managed through the API. There is no approval step built into registration.

<!-- chunk: products -->
## Products

Vault Enterprise Agent Registry API and UI, Terraform Vault provider

<!-- chunk: gaps -->
## Gaps

No approval workflow for registration or permission change. Enterprise only.

<!-- chunk: options -->
## Options

Manage registrations through Terraform with pull request review as the approval gate.
