## Answer

Not covered. Audit devices log Vault API requests and responses with identity, but the page describes no tamper evidence and no capture of agent inputs, outputs or reasoning.

Research detail: Audit devices log every API request and response, hash most string values with HMAC-SHA256, and Vault refuses a request if no audit device can record it. Agentic IAM audit entries include identity and authorisation metadata and record both user and agent on delegated requests. Logs cover Vault operations only, with no agent input, output or reasoning, and the page does not describe tamper evidence.
