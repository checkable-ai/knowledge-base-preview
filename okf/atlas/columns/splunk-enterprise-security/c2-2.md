## Answer

Not covered. Named model and version per agent, region, and a stated prompt retention period. The documentation only says frontier models are supported and that a Splunk-hosted option exists.

Research detail: The Security AI Assistant uses Model Runtime by default from ES 8.6, routing each prompt to a Splunk-hosted LLM or a third-party LLM in Azure OpenAI. Prompts sent externally leave the Splunk data boundary, admins can limit the assistant to Splunk-hosted models, responses are tagged internal or external in audit logs, and region standards are listed.
