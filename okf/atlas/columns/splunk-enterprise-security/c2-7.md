## Answer

Not covered. No sandbox or emergency stop for agents. The Triage agent on/off switch and MCP per-tool role mapping fall short of cutting off arbitrary agents.

Research detail: ES is a SIEM and does not sandbox or contain agent execution. Its own Triage agent can be turned on or off globally or per detection, and the Splunk MCP Server limits tool use through the mcp_tool_execute capability and per-tool role mapping. Containment of other agents depends on SOAR playbooks calling third-party endpoint or network tools.

<!-- chunk: products -->
## Products

None native. Triage agent on and off setting, MCP Server tool role mapping.

<!-- chunk: gaps -->
## Gaps

No in-flight stop, sandbox or egress control is documented. Token expiry and revocation for MCP clients are not described on the setup page.

## Options

Pair ES with an endpoint or runtime containment product, use SOAR playbooks to trigger isolation, then test the response time.
