## Answer

Covered. Attestations are for Splunk Cloud Platform (IRAP PROTECTED in AWS Sydney, SOC 2 Type 2, ISO 27001). No ISO 42001 found. Customers should confirm ES scope.

Source statement: "SOC 2 Type II: Splunk Cloud Platform has an annual SOC 2 Type 2 audit report issued." (https://help.splunk.com/en/splunk-cloud-platform/get-started/service-terms-and-policies/10.5.2605/information-about-the-service/splunk-cloud-platform-service-details)

Research detail: Splunk states Splunk Cloud Platform is attested at the IRAP PROTECTED level in the AWS Sydney region, has an annual SOC 2 Type 2 report and is ISO/IEC 27001:2013 certified, with FedRAMP Moderate and High in AWS GovCloud. The compliance page lists Enterprise Security and Security AI Assistant rows in its IRAP, SOC 2 and ISO 27001 matrices as of February 2026, and says IRAP reports are valid for two years. Cloud SOAR reached IRAP PROTECTED in January 2025.
