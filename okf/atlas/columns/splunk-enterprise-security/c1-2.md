## Answer

Covered. Splunk MCP Server app in ES: role mapping per tool, per-tool rate limits and on/off switches. ES tools are read-only. Scope is Splunk and ES.

Source statement: "(optional) Customize the rate limit or select the roles that can run the tool." (https://help.splunk.com/en/splunk-enterprise-security-8/user-guide/8.7/introduction/use-the-splunk-mcp-server-app-to-access-tools-in-splunk-enterprise-security)

Research detail: Agents reaching ES through the Splunk MCP Server need the mcp_tool_execute capability and API access. Admins can map roles to specific tools, turn individual tools on or off and set per-tool rate limits, and the ES tools are documented as read-only.

<!-- chunk: products -->
## Products

Splunk MCP Server app, ES role-based access control

<!-- chunk: gaps -->
## Gaps

Scopes cover Splunk and ES only. ES does not limit what agents can do against other connected systems.

<!-- chunk: options -->
## Options

Create a dedicated minimal role for agent tokens and map it only to the tools the agent needs.
