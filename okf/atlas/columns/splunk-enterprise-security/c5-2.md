## Answer

Not covered. No documented training of agents on their tasks and no documented behavioural anomaly detection for agents. The nearby AI Agent Monitoring evaluations (bias, hallucination, relevance, sentiment, toxicity, run on sampled spans, with a quality flag below 80% pass and a detector that can be created) only measure response quality. They do not train agents or detect behavioural anomalies.

Last checked 16 November 2026.

Research detail: ES UEBA baselines normal activity for users and assets and scores deviations into entity risk. AI Agent Monitoring scores agent spans for bias, hallucination, relevance, sentiment and toxicity and flags an agent when fewer than 80 percent of evaluations pass.

## Products

ES UEBA, Splunk AI Agent Monitoring

## Gaps

UEBA documentation does not mention AI agents. AI Agent Monitoring is scheduled for deprecation, and agent quality scores live in Observability Cloud, not ES.

<!-- chunk: options -->
## Options

Map agent service accounts as ES identities so UEBA baselines them, and move agent evaluation to Splunk Agent Observability.
