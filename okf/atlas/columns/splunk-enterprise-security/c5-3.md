## Answer

Not covered. Splunk AI Token and Cost Monitoring shows token usage and estimated cost by agent, provider and model, and provider token cost on the AI infrastructure dashboard. It has no staff-time cost and no measure of return or value delivered to set against cost. Token costs are estimates from editable token rates, not actual billing.

Last checked 16 November 2026.

Research detail: The AI agents page in Splunk APM ranks agents by token usage and shows an estimated cost from published provider prices multiplied by token counts.
