## Answer

Covered. Applies to Splunk SOAR playbook actions. The Prompt block must have Required checked and a Required response time set. External prompts may need extra authentication.

Source statement: "send a message to a user or group that they must acknowledge, to continue running a playbook" (https://help.splunk.com/en/splunk-soar/soar-cloud/develop-apps/build-playbooks/use-the-playbook-editor-to-create-and-view-playbooks-to-automate-analyst-workflows/require-user-input-using-the-prompt-block-in-your-splunk-soar-cloud-playbook)

Research detail: SOAR Prompt blocks pause a playbook until a chosen user or role answers within a required response time, after which the prompt is no longer actionable. External prompts can require SAML authentication. The ES 8.7 AI SOC Analyst runs permitted actions and asks for analyst approval on some next steps.

<!-- chunk: products -->
## Products

Splunk SOAR Prompt block, AI SOC Analyst (Premier)

<!-- chunk: gaps -->
## Gaps

Approvals cover SOC automation, not customer agents' actions in other systems. The AI SOC Analyst approval model and which actions are permitted without approval are not documented beyond the release note. Splunk warns against unauthenticated external prompts for sensitive actions.

<!-- chunk: options -->
## Options

Gate destructive SOAR actions behind internal Prompt blocks with short response windows and test the timeout branch.
