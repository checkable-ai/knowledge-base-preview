## Answer

Not covered. Nearby feature: field filters redact sensitive fields in indexed data by role. They are Splunk data protection, not a gateway filtering what each agent retrieves across sources, and there is no DLP on agent outputs.

Research detail: ES has no inline retrieval or DLP gateway for agents. Splunk RBAC limits which indexes a user or token can search, which is access control on the SIEM itself.
