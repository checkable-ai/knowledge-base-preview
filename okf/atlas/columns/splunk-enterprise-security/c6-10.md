## Answer

Not covered. Index retention and Model Runtime settings exist, but no rules for retaining, deleting or locating agent inputs, outputs or memory are documented.

Research detail: Splunk Cloud Platform sets searchable retention per index, with optional archive or self-storage for expired data, and admins can delete an index and its data. For the Security AI Assistant, admins can keep prompts within the Splunk boundary by limiting it to Splunk-hosted models, and region standards are documented.

<!-- chunk: products -->
## Products

Splunk Cloud Platform index retention, Model Runtime settings

<!-- chunk: gaps -->
## Gaps

Retention is per index, not per agent input, output or memory. Deletion removes whole buckets or indexes. Internal index retention cannot be changed. Retention of prompts sent to Azure OpenAI is governed by the third party.

<!-- chunk: options -->
## Options

Store agent conversation data in dedicated indexes with retention matched to policy.
