## Answer

Not covered. Nearby feature: encrypted MCP tokens for the Splunk MCP Server (audience fixed to mcp, 30/60/90/120-day or custom expiry, deactivate, delete). Expiry is in months, not short-lived. Rotation is manual only (create a new token and update the client). Nothing documented keeps secrets out of model context. Tokens cover Splunk MCP access only, not credentials for agents generally.

Last checked 16 November 2026.

Research detail: ES does not broker credentials for agents. The Splunk MCP Server uses encrypted tokens that let an MCP client reach Splunk itself, and token authentication must be enabled on the deployment.

## Gaps

MCP tokens are credentials for Splunk access only. No delivery, rotation or revocation of credentials for downstream systems.

<!-- chunk: options -->
## Options

Use a secrets manager or credential broker outside Splunk and send its audit logs to ES.
