## Answer

Not covered. No brokered short-lived credentials, automatic rotation, or mechanism keeping secrets out of model context. Project API key expiry and revocation fall short.

Research detail: API keys are scoped to one project, can carry an expiration date and can be revoked. Legacy keys can only be regenerated, not revoked. The platform does not broker credentials to downstream tools or keep secrets out of model context.

<!-- chunk: products -->
## Products

Project-scoped API keys

<!-- chunk: gaps -->
## Gaps

No automatic rotation, no model or endpoint restriction per key and no secret injection for sandboxes beyond the TOGETHER_API_KEY variable.

<!-- chunk: options -->
## Options

Use an external secrets manager or credential broker for tool credentials and set expiry on every Together key.
