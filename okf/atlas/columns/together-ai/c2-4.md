## Answer

Not covered. No documented access rules for who can read session state, no stated retention period for snapshots or sandbox data after expiry, and no resume policy beyond creating a new sandbox from a snapshot. Chat inference keeps no memory, so callers resend history.

Last checked 16 November 2026.

Research detail: Code interpreter sessions keep state across calls, belong to the caller and carry an expiry timestamp. Sandboxes keep state until terminated and can be snapshotted. Chat inference is stateless, with history held by the client.

## Products

Code Interpreter sessions, Code Sandbox snapshots

## Gaps

Session lifetime rules and retention after expiry are not documented. No conversation state service.

## Options
