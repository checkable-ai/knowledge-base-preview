## Answer

Not covered. No agent identity object tied to an owner, runtime and release. Project-scoped API keys segment usage by workload but are not agent identities.

Last checked 16 November 2026. This platform is checked on demand, so this answer has not been rechecked since.

Research detail: Project-scoped API keys can be created per workload, for example production, CI/CD or inference, and usage is attributed by api_key_id in cost analytics. There is no agent or workload identity object linked to an owner, runtime or release.
