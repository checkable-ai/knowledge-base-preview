## Answer

Not covered. Isolated environments, IP allowlisting and quotas exist, but no agent sandbox or documented emergency stop or key revocation.

Research detail: GovAI Hosting gives each agency an isolated Azure subscription or AWS account with network restrictions and no unrestricted internet access. Model Brokerage access uses an API key per subscription with IP allowlisting and quotas, which GovAI provisions and can withhold. The agency builds and contains its own agents inside these limits.

<!-- chunk: products -->
## Products

GovAI Hosting isolated environments, Model Brokerage API keys and IP allowlisting

## Gaps

No agent code sandbox, process policy or documented immediate stop or key revocation procedure is published. Detailed controls are in the Hosting and Brokerage guides, which are released on request.
