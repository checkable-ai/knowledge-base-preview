## Answer

Not covered. Brokerage issues a key per application with IP registration, but rotation, expiry and revocation are not documented and tool or data credentials are not covered. Could not fetch the page to verify a quote.

Research detail: The Model Brokerage provisions an API subscription with a key per application and registers its IP addresses. The Brokerage authenticates the request and holds the route to each model provider, so agencies do not hold provider credentials. No rotation, expiry or revocation process is published.
