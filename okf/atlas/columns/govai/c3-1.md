## Answer

Not covered. Verdict could not be confirmed: pages timed out when fetched, so no exact quote could be verified. Research notes indicate the Brokerage is a single gateway with API key, IP allowlist, routing, quotas and budget alerts per application, without prompt screening.

Research detail: The Model Brokerage is a single government-managed endpoint that authenticates each application by API key and IP allowlist, checks permissions and routes to the requested model. It provides usage dashboards by project, application or team with budget alerts and quotas. Content filtering and guardrails stay with the agency.
