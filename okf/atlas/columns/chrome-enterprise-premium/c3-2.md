## Answer

Not covered. No gateway for agent tool calls: no per-tool allow lists, input format or schema checks, or rate limits. Nearby features (auto browse URL allow and block lists, URL filtering) only control browser web access.

Research detail: Premium URL filtering and real-time URL checks control browser egress by category, and auto browse can be limited to allowed sites. From Chrome 152 text typed by the agent goes through DLP content analysis, and rules can use Gemini in Chrome as the source context to audit or block it.
