## Answer

Covered. Covers Google's own auto browse agent only. Off by default for managed users and needs an eligible Workspace edition.

Source statement: "GeminiActOnWebAllowedForURLs, and GeminiActOnWebBlockedForURLs policies to control auto browse" (https://support.google.com/chrome/a/answer/16291696)

Research detail: Chrome is the harness for Google's browser agent: auto browse navigates, views, clicks and types on pages, and Gemini Spark uses it for web actuation. Admins control it through GeminiActOnWebSettings and URL allow and block lists, and from Chrome 150 WebMCP tools on pages can be inspected and called, governed by developer tools policies.

## Products

Gemini in Chrome auto browse, WebMCP tooling
