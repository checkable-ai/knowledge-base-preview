## Answer

Not covered. Auto browse uses the user's session implicitly. No documented delegation or token exchange to downstream systems.

Research detail: Auto browse acts inside the signed-in user's Chrome session, so downstream sites see the user's own session and context-aware access applies to the agent as it does to the user. Google states that if an employee lacks authorisation to access or export data, their agents will not have it either.

## Products

Gemini in Chrome auto browse, context-aware access

## Gaps

Delegation is implicit through the user's browser session. No token exchange, scoped delegation or record of delegated authority to downstream services is documented, and the context-aware access claim is from an announcement rather than admin docs.
