## Answer

Not covered. GeminiActOnWebAllowedForURLs and GeminiActOnWebBlockedForURLs scope auto browse by site only. The page does not describe limits by action type such as read, write or submit, so what the agent may do inside an allowed site is not admin-controlled.

Research detail: Admins can allow or block auto browse per OU or group with GeminiActOnWebSettings, and limit where it can act with GeminiActOnWebAllowedForURLs and GeminiActOnWebBlockedForURLs. URL filtering and DLP rules also apply to the agent's typing from Chrome 152.

## Products

GeminiActOnWebSettings, GeminiActOnWebAllowedForURLs, GeminiActOnWebBlockedForURLs, DLP rules

<!-- chunk: gaps -->
## Gaps

Scopes are per site, not per action type such as read, write or submit. Action limits inside an allowed site rest on built-in confirmations.

## Options

Start with an allow list of low-risk sites and audit agent activity before widening it.
