## Answer

Not covered. No documented control over the machine or container running agent software, code interpreter or network access. The agent runs in Chrome on the user's device.

Last checked 12 November 2026.

Research detail: The agent runs inside Chrome on the user's desktop. Google describes site isolation extended to limit the agent to task-relevant origins, auto browse is not available in Incognito, and Chrome 145 and later report local policy tampering on managed profiles.
