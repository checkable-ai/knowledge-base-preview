## Answer

Not covered. No admin control over an agent's local files, processes or commands beyond browser policies such as file upload settings.

Research detail: Auto browse is confined to the browser. Google describes limiting the agent to origins relevant to the task, admins can control file upload into Gemini in Chrome with GeminiChromeFileUploadSettings from Chrome 152, and on-device model download is controlled with GenAILocalFoundationalModelSettings. WebMCP tooling for agents is governed by RemoteDebuggingAllowed and DeveloperToolsAvailability.

<!-- chunk: products -->
## Products

GeminiChromeFileUploadSettings, GenAILocalFoundationalModelSettings, DeveloperToolsAvailability, Chrome auto browse origin restriction

<!-- chunk: gaps -->
## Gaps

No admin control over the local file system, processes or network for an agent beyond browser policies. The origin restriction is a built-in design, not an admin setting.

<!-- chunk: options -->
## Options

Set file upload and developer tools policies by OU and test that auto browse cannot reach local files.
