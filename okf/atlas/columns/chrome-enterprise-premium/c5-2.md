## Answer

Not covered. Chrome's built-in User Alignment Critic and prompt-injection classifier check agent actions, but Google does not document admin-facing agent behaviour monitoring, tuning, task-specific training or customer-visible anomaly detection. The vendor does not state that these features cover part of this outcome.

Last checked 12 November 2026.

Research detail: The User Alignment Critic checks proposed auto browse actions against the user's goal. Premium security insights flag high-risk users and domains, and Premium extension telemetry watches for code injection, process invocation and unauthorised data access by extensions.

## Products

User Alignment Critic, Chrome high risk users report, extension telemetry

## Gaps

No customer-tunable anomaly detection or validation for agent behaviour. The Critic is a built-in Google control with no admin output.

## Options
