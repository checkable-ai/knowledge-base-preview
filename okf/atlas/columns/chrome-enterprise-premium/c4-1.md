## Answer

Not covered. Logs flag agent actions, but there is no per-agent identity tied to owner, runtime and release.

Research detail: Chrome log events and Gemini for Workspace log events carry a By an agent flag and an Agent info field with agent ID, name and product, so actions taken by a Google agent can be told apart from the user's. Chrome History tags pages navigated by auto browse and Gemini Spark as agent actions from Chrome 153.

<!-- chunk: products -->
## Products

Chrome log events, Gemini for Workspace log events, Chrome History agent activity logging

<!-- chunk: gaps -->
## Gaps

This is attribution in logs, not an identity linked to an owner, runtime and release. Agent product is documented only for the Google Workspace Studio flow. No identity for third-party agents or extensions acting in the browser.

<!-- chunk: options -->
## Options

Use the user identity plus the By an agent flag as the attribution key, and test whether auto browse actions populate Agent info in Chrome log events.
