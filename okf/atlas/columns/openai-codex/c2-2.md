## Answer

Covered, with conditions. The provider definition must be placed in requirements.toml. The gateway is customer-supplied, so prompt retention depends on it. ChatGPT sign-in applies ChatGPT workspace retention and residency settings. Available models vary by plan, client, workspace settings and rollout.

Source statement: "An enforced provider definition replaces the matching provider table from ordinary configuration." (https://learn.chatgpt.com/docs/enterprise/roll-out-a-gateway)

Last checked 16 November 2026.

Research detail: Models are named in configuration and managed defaults can pin one. Model access follows the workspace plan, role and authentication boundary, and retirement dates are published. Organisations can route Codex through their own gateway to chosen upstream models.

## Products

Workspace model availability, managed defaults, organisation gateway

## Gaps

Codex cloud does not support changing its default model. Data handling varies by surface, and local computer access with Work Cloud has no strict zero data retention.

## Options
