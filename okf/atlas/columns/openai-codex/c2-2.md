## Answer

Covered. Needs requirements.toml with the full provider definition. The gateway is customer-supplied, so prompt retention depends on it. Codex cloud cannot change its default model.

Source statement: "An enforced provider definition replaces the matching provider table from ordinary configuration" (https://learn.chatgpt.com/docs/enterprise/roll-out-a-gateway)

Research detail: Models are named in configuration and managed defaults can pin one. Model access follows the workspace plan, role and authentication boundary, and retirement dates are published. Organisations can route Codex through their own gateway to chosen upstream models.
