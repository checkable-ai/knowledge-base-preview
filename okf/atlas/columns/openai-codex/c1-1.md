## Answer

Covered, with conditions. Needs ChatGPT Enterprise managed configuration (requirements.toml). Permission profile allowlists need Codex 0.138.0 or later.

Source statement: "Admins can deny reads for exact paths or glob patterns with `&#91;permissions.filesystem&#93;`." (https://learn.chatgpt.com/docs/enterprise/managed-configuration)

Research detail: Sandbox modes (read-only, workspace-write, danger-full-access), permission profiles, filesystem deny_read and command prefix rules set what Codex can do on the host. Admins enforce allowed sandbox modes, approval policies and permission profiles through requirements.toml, MDM or Agent Security.

<!-- chunk: products -->
## Products

Codex sandbox, permission profiles, requirements.toml, Agent Security

<!-- chunk: gaps -->
## Gaps

Permission profile allowlists need Codex 0.138.0 or later. deny_read does not cover shell subprocess reads on native Windows. Approved full sandbox escalation can bypass the command proxy.

<!-- chunk: options -->
## Options

Deploy requirements through MDM, forbid danger-full-access and test allowed and blocked actions on the deployed client version.
