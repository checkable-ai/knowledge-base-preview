## Answer

Covered. Needs ChatGPT Enterprise managed configuration. Permission profile allowlists need Codex 0.138.0 or later. deny_read does not cover shell subprocess reads on native Windows.

Source statement: "Users can't weaken these requirements with local configuration." (https://learn.chatgpt.com/docs/enterprise/managed-configuration)

Research detail: Sandbox modes (read-only, workspace-write, danger-full-access), permission profiles, filesystem deny_read and command prefix rules set what Codex can do on the host. Admins enforce allowed sandbox modes, approval policies and permission profiles through requirements.toml, MDM or Agent Security.
