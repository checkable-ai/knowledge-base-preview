## Answer

Covered, with conditions. Data residency and inference residency cover only eligible content and supported workloads, regions and configurations. Enterprise Key Management covers supported stored content in eligible workspaces. Work is not supported with UAE inference residency. Local computer access with Work Cloud does not provide strict zero data retention. Features still in beta or alpha are excluded from residency.

Source statement: "Data residency and inference residency cover only eligible content and supported workloads, regions, and configurations." (https://learn.chatgpt.com/docs/enterprise/admin-setup)

Last checked 16 November 2026.

Research detail: Docs cover data residency for eligible content, Enterprise Key Management, an enforce_residency safeguard, local history caps and seven-day cloud task state.

## Gaps
