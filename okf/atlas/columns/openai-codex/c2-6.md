## Answer

Covered. Local clients only (ChatGPT desktop app and Codex TUI). Off by default, enabled in Settings > Personalization.

Source statement: "Memories let ChatGPT and Codex carry useful context from earlier work into future work." (https://learn.chatgpt.com/docs/customization/memories)

Last checked 16 November 2026.

Research detail: Local Codex clients keep a separate memory store with per-chat use and contribution controls, a machine-level on or off switch and a delete option. ChatGPT web uses ChatGPT memory.
