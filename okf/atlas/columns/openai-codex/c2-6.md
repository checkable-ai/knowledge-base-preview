## Answer

Covered. Local clients only (ChatGPT desktop app and Codex TUI); off by default, enabled in Settings > Personalization. No admin control documented.

Source statement: "Codex stores memories under your Codex home directory." (https://learn.chatgpt.com/docs/customization/memories)

Research detail: Local Codex clients keep a separate memory store with per-chat use and contribution controls, a machine-level on or off switch and a delete option. ChatGPT web uses ChatGPT memory.
