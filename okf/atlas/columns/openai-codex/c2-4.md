## Answer

Covered, with conditions. Applies to Codex cloud tasks. Saved VM state is recoverable for up to seven days by default. Local history retention is configured separately. ChatGPT Enterprise retention settings apply when authenticated through the Enterprise workspace.

Source statement: "Each cloud task runs in its own workspace." (https://learn.chatgpt.com/docs/environments/cloud-environments)

Last checked 16 November 2026.

Research detail: Local session transcripts are saved and can be capped or disabled. Cloud task VM state is recoverable for up to seven days after the last turn.

<!-- chunk: products -->
## Products

Local history, Codex cloud task state

<!-- chunk: gaps -->
## Gaps

Access control on session state beyond the workspace account is not documented. Local history is a file under CODEX_HOME.

<!-- chunk: options -->
## Options

Set history.persistence or history.max_bytes in managed defaults and protect CODEX_HOME.
