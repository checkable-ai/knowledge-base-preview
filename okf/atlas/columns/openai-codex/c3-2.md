## Answer

Partly covered. Complete enforcement. Hosted tools such as WebSearch bypass the hook path, a PreToolUse error or timeout can let the tool run, input validation needs customer-written handlers, and no per-tool quotas or rate limits are documented.

Source statement: "Treat tool hooks as a useful guardrail, not a complete enforcement boundary." (https://learn.chatgpt.com/docs/hooks)

Last checked 16 November 2026.

Research detail: Admins set an approved MCP server list, app action controls, command rules, managed PreToolUse hooks and managed network allowlists. Auto-review blocks exfiltration and destructive actions that need approval.

<!-- chunk: products -->
## Products

requirements.toml mcp_servers and rules, managed hooks, managed networking, Auto-review

<!-- chunk: gaps -->
## Gaps

No per-tool quotas, rate limits or schema enforcement documented. Tool results are not screened for injection.

<!-- chunk: options -->
## Options

Combine the MCP allowlist with a managed network allowlist and an external MCP gateway for quotas and injection screening.
