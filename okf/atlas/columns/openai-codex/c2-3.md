## Answer

Covered. Windows network support is limited and DNS rebinding protection is best effort. Cloud agent-phase internet is off by default unless enabled per environment.

Source statement: "Locally, Codex uses an OS-enforced sandbox that limits what it can touch." (https://learn.chatgpt.com/docs/agent-approvals-security)

Research detail: Local runs use OS sandboxes (Seatbelt on macOS, bwrap with seccomp on Linux, MXC on Windows) with network off by default in workspace-write and a managed proxy for domain rules. Cloud tasks run in isolated VMs with internet off by default.

## Products

Codex sandbox, network proxy, Codex cloud VMs

## Gaps

DNS rebinding protection is best effort. Windows network support is limited. Cloud environments do not inherit local device policy.

<!-- chunk: options -->
## Options

Keep network off by default and use permission profiles with the proxy feature so domain rules are enforced.
