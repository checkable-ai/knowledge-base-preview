## Answer

Not covered. No documented detections, redaction of sensitive output or named response owner. Telemetry export lets a customer build monitoring but detection and response stay with the customer.

Research detail: OTel log export carries conversation id, model, sandbox and approval settings, tool decisions and results, with user prompts redacted by default. Compliance API events can be streamed to a SIEM.
