## Answer

Covered. Network rules need the managed proxy enabled and the network section is experimental; access stays within scopes the connected service grants.

Source statement: "the client enables an MCP server only when both its name and identity match an approved entry" (https://learn.chatgpt.com/docs/enterprise/managed-configuration)

Research detail: Admins approve MCP servers by identity, set read-only or custom action sets per app connection, assign plugins by role and restrict command networking to allowed domains. Cloud environments can limit internet access to listed domains and to GET, HEAD and OPTIONS.

<!-- chunk: products -->
## Products

MCP server allowlist, Action control, Agent Security managed networking, cloud internet access settings

<!-- chunk: gaps -->
## Gaps

Access stays within scopes the connected service grants. Network controls do not by themselves disable hosted web search, apps or MCP. The network section is experimental.

<!-- chunk: options -->
## Options

Start with read actions, turn on Only allow domains added by admins and test an allowed and a blocked request.
