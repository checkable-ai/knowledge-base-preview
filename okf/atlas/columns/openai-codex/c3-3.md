## Answer

Not covered. No native data loss prevention on tool results, files or model output. The deny_read setting only blocks paths, which falls short of a data access gateway.

Research detail: Filesystem deny_read rules block reads of set paths, and Prisma AIRS can apply DLP to prompts. Connector access stays within the connected service's scopes.

## Products

## Gaps
