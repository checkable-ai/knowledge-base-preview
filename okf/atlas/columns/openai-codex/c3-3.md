## Answer

Not covered. Data loss prevention and per-agent, per-user filtering of retrieved data. The deny_read setting only blocks paths. Prisma AIRS, a separate product, scans only newly submitted prompts and not tool results or files.

Last checked 18 November 2026.

Research detail: Filesystem deny_read rules block reads of set paths, and Prisma AIRS can apply DLP to prompts. Connector access stays within the connected service's scopes.

<!-- chunk: products -->
## Products

deny_read, Prisma AIRS integration

<!-- chunk: gaps -->
## Gaps

No native DLP on tool results, files or model output. AIRS is a third-party add-on enabled by request.

<!-- chunk: options -->
## Options

Use an external DLP or data gateway on connected services.
