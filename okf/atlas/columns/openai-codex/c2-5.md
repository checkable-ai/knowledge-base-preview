## Answer

Covered. Hooks are a guardrail, not a complete enforcement boundary. Managed hooks on Work Cloud support only MCP tool handlers.

Source statement: "`PreToolUse` can intercept Bash, file edits performed through `apply_patch`, MCP tool calls, and other local function tools." (https://learn.chatgpt.com/docs/hooks)

Research detail: The Codex CLI, IDE extension and desktop app run tools through one harness with sandboxing, approvals, command rules, hooks at tool and session events, and MCP support. Admin-managed hooks are trusted by policy and user hooks need hash-based trust.
