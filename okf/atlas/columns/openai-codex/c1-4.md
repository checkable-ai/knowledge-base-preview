## Answer

Covered, with conditions. Service accounts are available only on pay-as-you-go plans. Only workspace owners and admins can create service accounts.

Source statement: "Only workspace owners and admins can create service accounts." (https://learn.chatgpt.com/docs/enterprise/service-accounts)

Last checked 16 November 2026.

Research detail: Workspace owners control access through seats, built-in and custom roles, groups and SCIM. Service accounts are created, enabled, disabled and deleted in the console or Admin API, and deletion revokes tokens. Runtime configuration is set centrally through managed requirements and Agent Security policies.

<!-- chunk: products -->
## Products

RBAC, SCIM, service accounts, Admin API, Agent Security

<!-- chunk: gaps -->
## Gaps

Disabling local Codex permission suspends but does not revoke tokens. A changed cloud policy does not replace requirements already loaded in a running process.

<!-- chunk: options -->
## Options

Manage service accounts through SCIM and revoke tokens explicitly at offboarding.
