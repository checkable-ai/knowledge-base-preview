## Answer

Covered. Disabling local Codex permission suspends but does not revoke tokens.

Source statement: "Only workspace owners and admins can create service accounts." (https://learn.chatgpt.com/docs/enterprise/service-accounts)

Research detail: Workspace owners control access through seats, built-in and custom roles, groups and SCIM. Service accounts are created, enabled, disabled and deleted in the console or Admin API, and deletion revokes tokens. Runtime configuration is set centrally through managed requirements and Agent Security policies.
