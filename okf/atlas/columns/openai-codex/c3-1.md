## Answer

Not covered. OpenAI provides no gateway of its own for Codex; routing, quotas, cost and rate limits depend on a customer-supplied gateway. Managed provider pinning only directs traffic to it.

Research detail: Codex can send all model requests to an organisation-run gateway that holds upstream credentials and sets approved models, rate limits and budgets per credential. Prisma AIRS can screen prompts for injection and DLP before they reach the model.

<!-- chunk: products -->
## Products

Organisation gateway support, Prisma AIRS integration, usage limits

<!-- chunk: gaps -->
## Gaps

Routing, quotas and screening come from the customer gateway or Prisma AIRS, not Codex itself. AIRS scans only newly submitted prompt text and allows prompts on failure by default.

<!-- chunk: options -->
## Options

Deploy a gateway and set Prisma AIRS On AIRS failure to Block prompts.
