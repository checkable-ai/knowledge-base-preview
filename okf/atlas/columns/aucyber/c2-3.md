## Answer

Not covered. No managed agent runtime, code interpreter or sandbox. Generic VMs and Kubernetes are customer-built.

Research detail: AUCyber provides the hosts an agent harness could run on: VMware Cloud Director VMs, Kubernetes clusters and OpenStack, with isolated VDC networks that allow traffic only between VMs in the same virtual data centre. The VMware platform is IRAP-assessed to PROTECTED. The customer builds and secures the execution environment itself.
