## Answer

Not covered. No agent sandbox, process or filesystem limits, or kill switch. Isolated VDC networks and edge firewall are customer-configured network primitives.

Research detail: AUCyber supplies network primitives a customer can use to contain agent hosts. Isolated VDC networks allow traffic only between VMs in the same virtual data centre, and the Edge Services Gateway firewall takes allow, drop or reject rules, with SNAT needed before internal networks reach the internet. The customer configures these in VMware Cloud Director. No agent sandbox or agent kill switch is offered.

<!-- chunk: products -->
## Products

Isolated VDC networks, NSX-T Edge Services Gateway firewall and NAT

## Gaps

The pages do not state a default-deny egress policy, process or filesystem policy, or a documented way to stop an AI workload. The Managed AI Services page does not describe isolation or revocation.

## Options

Place agent hosts on isolated VDC networks, allow egress only through explicit ESG rules, and agree a stop and revoke procedure in the managed service contract.
