## Answer

Not covered. No secrets broker, rotation or agent credential delivery. VCD API tokens and S3 keys are tenant infrastructure credentials.

Research detail: Infrastructure credentials exist: revocable per-client VCD API tokens and S3 access keys that can carry an expiry date and be bound to one bucket by policy. These are tenant infrastructure credentials, with no broker that keeps secrets out of model context.
