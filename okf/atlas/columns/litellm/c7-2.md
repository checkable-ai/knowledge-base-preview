## Answer

Not covered. No security detections or named response ownership in LiteLLM. The Azure Sentinel logging callback only exports logs, and the page attributes threat detection to Sentinel, not LiteLLM. No redaction is documented on that page.

Last checked 16 November 2026.

Research detail: Logging callbacks send a standard payload with call ID, key, user and team to OpenTelemetry, Datadog, S3 and others. Message logging can be turned off or redacted per request, and key details can be redacted. Guardrail results and MCP tool drift alerts are emitted.

## Products

Logging callbacks, Alerting, Guardrail metrics

## Gaps

No security detections or response ownership. Per-team logging needs an Enterprise licence.

<!-- chunk: options -->
## Options
