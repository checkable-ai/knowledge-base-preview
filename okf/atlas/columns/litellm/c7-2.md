## Answer

Not covered. No security detections or named response ownership. Logging callbacks (OpenTelemetry, Datadog) export telemetry only.

Research detail: Logging callbacks send a standard payload with call ID, key, user and team to OpenTelemetry, Datadog, S3 and others. Message logging can be turned off or redacted per request, and key details can be redacted. Guardrail results and MCP tool drift alerts are emitted.
