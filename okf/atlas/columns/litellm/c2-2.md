## Answer

Covered, with conditions. Region filtering needs enable_pre_call_checks set in router_settings. Self-hosted proxy configuration. Provider-side prompt data handling follows each provider's terms.

Source statement: "LiteLLM can automatically infer region_name for Vertex AI, Bedrock, and IBM WatsonxAI." (https://docs.litellm.ai/docs/proxy/reliability)

Last checked 16 November 2026.

Research detail: Each model name maps to explicit provider deployments with API base, credentials and per-deployment rpm limits, managed in config.yaml or the model API. Timeouts, context window pre-call checks and region_name filtering for routing are configurable. LiteLLM routes to providers and does not host model weights.

## Gaps
