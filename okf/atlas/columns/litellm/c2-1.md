## Answer

Not covered. No workflow ordering, hand-off, task cancellation or agent state recovery. Router retries and fallbacks apply per model call only; iteration budgets and the kill switch are nearby but do not sequence or recover tasks.

Research detail: LiteLLM does not sequence agent workflows. It retries model calls, falls back across model groups and cools down unhealthy deployments. For agents it caps iterations and spend per session and offers an admin-fired kill switch webhook to stop an agent runtime.
