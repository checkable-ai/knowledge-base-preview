## Answer

Covered. Covers only tools the proxy has seen in traffic and assets registered in the gateway. Tool Policies is only available to proxy admins.

Source statement: "a registry of every tool the proxy has seen in traffic" (https://docs.litellm.ai/docs/proxy/tool_policies)

Research detail: The gateway keeps registries of models, A2A agents, MCP servers and observed tools, with model_info metadata and agent card fields. AI Hub publishes selected models, agents and MCP servers to a discovery page and API.
