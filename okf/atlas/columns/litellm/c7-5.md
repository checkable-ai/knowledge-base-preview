## Answer

Not covered. No SBOM, no code or vulnerability scanning of MCP servers, CLIs or skills, and no review of external services or network egress. Nearby features, MCP tool description/schema scanning by guardrails and pinning of approved tool lists, check content only.

Last checked 16 November 2026.

Research detail: MCP server submissions are held in pending_review until an admin approves them. Tool pinning freezes a server's tool names, descriptions and schemas and alerts on drift. pre_mcp_call guardrails scan tool descriptions during discovery and hide blocked tools.
