## Answer

Not covered. No look-alike name or package compromise checks for public registries. Tool pinning detects only changed tool metadata.

Research detail: Tool pinning detects upstream changes to tool names, descriptions and schemas, which covers some tool metadata poisoning. Description scanning on discovery can block suspect tools. New server names must follow SEP-986.
