## Answer

Covered. SOC 2 Type II covers the vendor, not a customer's self-hosted deployment; report via Trust Center.

Source statement: "LiteLLM is SOC 2 Type II audited." (https://docs.litellm.ai/docs/enterprise/compliance)

Research detail: LiteLLM states it is SOC 2 Type II audited, with the report available through the LiteLLM Trust Center. The compliance page adds signed Docker images (cosign from v1.83.0), grype image scans and a vulnerability disclosure policy. The self-hosted gateway keeps prompts, responses and keys in the customer's environment.

## Products

SOC 2 Type II, LiteLLM Trust Center, cosign-signed images

## Gaps

No IRAP, ISO/IEC 27001 or ISO/IEC 42001 statement and no published pen test attestation found. The SOC 2 report covers the vendor, not a self-hosted deployment, which the agency must assess itself.

## Options

Request the SOC 2 report and treat a self-hosted proxy as part of the agency's own system for IRAP and authority-to-operate purposes.
