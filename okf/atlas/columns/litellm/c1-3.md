## Answer

Not covered. require_approval only decides whether the proxy executes tool calls or returns them to the client; no gateway-side approval of the exact action, approver record, refusal or replay handling.

Research detail: On the MCP gateway, require_approval controls whether the proxy runs tool calls itself. Unless it is set to never, tool calls are returned to the client for review. The approval decision, its binding to the exact call and replay handling sit with the client application.
