## Answer

Not covered. Aura log forwarding (Business Critical, VDC, AuraDS Enterprise) delivers logs to customer logging, but Neo4j provides no agent detections or response ownership.

Last checked 12 November 2026.

Research detail: Aura forwards security and query logs to Google Cloud Logging, CloudWatch or Azure Log Analytics, with filters for query log entries. Logs carry user fields, and literal obfuscation and parameter logging controls support redaction.

## Gaps
