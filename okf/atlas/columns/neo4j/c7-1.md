## Answer

Not covered. Query and security logs record user, query text and parameters, but no tamper protection is described and there is no agent session or reasoning capture.

Last checked 12 November 2026.

Research detail: The security log records logins, administration commands and authorisation failures, and the query log records query text, parameters and transaction metadata with executing and authenticated user. Both support JSON layout, and Aura can forward them to the customer's cloud logging.
