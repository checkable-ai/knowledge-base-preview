## Answer

Not covered. No approval workflow or versioning for agent changes.

Research detail: Only Aura project admins can create, edit and delete Aura agents, while members and viewers can list and use them. In the database, user and role creation, change and removal are controlled by DBMS privileges.

## Products

Aura Agent project roles, DBMS user and role management

## Gaps

No approval workflow or configuration versioning for agents. Regenerating an agent overwrites its configuration.

<!-- chunk: options -->
## Options

Manage agent users and roles as code and review changes outside Neo4j.
