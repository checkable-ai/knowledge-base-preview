## Answer

Not covered. Neo4j consumes per-request credentials but does not issue short-lived credentials or rotate and revoke them for agents.

Last checked 12 November 2026.

Research detail: The Neo4j MCP server in HTTP mode reads credentials per request from a header (bearer token or basic auth) and the docs say not to set a static username and password in that mode. Aura tool authentication lets Query and Bloom connect with the Aura user instead of a database password.

<!-- chunk: products -->
## Products

Neo4j MCP server HTTP mode, Aura tool authentication

<!-- chunk: gaps -->
## Gaps

Neo4j consumes credentials but does not broker, rotate or revoke them for agents. Aura Agent token endpoint is limited to 15 requests per hour per client ID.

<!-- chunk: options -->
## Options

Pair with a secrets broker or identity provider that issues short-lived OIDC tokens to the MCP server.
