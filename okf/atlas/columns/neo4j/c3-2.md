## Answer

Not covered. No general gateway for tool calls or internet access. The MCP server read-only setting and tool listing only affect Neo4j tools. There is no per-agent tool allowlist, rate limiting, input format enforcement or egress control.

Last checked 12 November 2026.

Research detail: The MCP server read-only setting disables write tools, read-cypher checks queries with EXPLAIN and query-type classification, and HTTP mode can require credentials for tools/list. Aura Agent restricts tools to read-only queries.

<!-- chunk: products -->
## Products

Neo4j MCP server, Aura Agent

<!-- chunk: gaps -->
## Gaps

Controls apply only to Neo4j tools. No per-agent tool allowlist, quota, rate limits or injection screening. Text2Cypher output can contain errors.

<!-- chunk: options -->
## Options

Front the MCP server with a tool gateway and keep write tools on a separate deliberately enabled connection.
