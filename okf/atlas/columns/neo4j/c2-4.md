## Answer

Not covered. Aura Agent does not store conversation history. Labs Agent Memory has no documented access control or retention and is unsupported.

Last checked 12 November 2026.

Research detail: The Agent Memory library stores short-term memory as conversation messages linked to conversation IDs. Aura Agent does not currently store conversation history.

## Products

Neo4j Agent Memory

<!-- chunk: gaps -->
## Gaps

Conversation IDs do not enforce access control, and no session expiry or retention is documented. The project is a Labs project without official support.

<!-- chunk: options -->
## Options

Enforce session access in the application and apply database roles to the memory store.
