## Answer

Not covered. Agent Memory and NAMS are experimental Labs projects with no retention or isolation guarantees.

Research detail: Agent Memory provides long-term memory as a knowledge graph of entities, preferences and facts, plus reasoning memory of tool calls. NAMS hosts this per workspace on Aura with REST, MCP and SDK access.

## Products

Neo4j Agent Memory, NAMS

## Gaps

Both are Neo4j Labs, experimental and community supported. No retention policy or per-user isolation guarantee is documented.
