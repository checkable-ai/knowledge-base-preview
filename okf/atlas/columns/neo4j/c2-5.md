## Answer

Covered. Limited to Neo4j graph tools. Neo4j MCP server also runs its tools for MCP clients.

Source statement: "Aura provides the orchestration layer as well as the integration with GenAI models/LLMs" (https://neo4j.com/docs/aura/aura-agent/)

Last checked 12 November 2026.

Research detail: Aura Agent executes its configured graph tools for the agent, and the Neo4j MCP server executes get-schema, read-cypher, write-cypher and GDS listing tools for MCP clients.
