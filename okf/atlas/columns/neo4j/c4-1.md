## Answer

Not covered. No per-agent identity tied to an owner, runtime and release. Aura OAuth client credentials and generic database users fall short.

Research detail: Aura Agent agents are objects in an Aura project, addressed by project ID and agent ID, and external callers authenticate with Aura OAuth client credentials. In the database, an agent can be given its own native, LDAP or OIDC user with assigned roles.

## Products

Aura Agent, Neo4j users and roles

## Gaps

No workload identity that links an agent to an owner, runtime and release. Database users are generic accounts.

<!-- chunk: options -->
## Options

Issue one database user or OIDC client per agent and record the owner and release in an external registry.
