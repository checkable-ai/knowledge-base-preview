## Answer

Not covered. Metrics and query logs cover database instances, with no agent infrastructure monitoring or anomaly detection.

Last checked 12 November 2026.

Research detail: Customer Metrics Integration exposes Aura instance metrics such as CPU usage and node counts to Prometheus and other APM tools. The query log records query duration and can log only queries above a threshold.

## Products

## Gaps
