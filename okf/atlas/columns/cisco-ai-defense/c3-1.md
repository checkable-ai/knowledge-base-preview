## Answer

Not covered. No routing, quotas, cost or rate limits per agent, user or workload. The gateway only screens prompts and content, which is the optional part.

Research detail: The AI Defense Gateway proxies LLM traffic per application connection and applies a policy that blocks prompt injection, unsafe content and sensitive data. The same policies apply through the Inspection API, LiteLLM guardrail, Multicloud Defense and Google agent gateway, with fail-open or fail-closed options. The API path only reports and leaves blocking to the app.
