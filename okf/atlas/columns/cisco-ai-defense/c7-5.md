## Answer

Not covered. MCP scanning (Streamable HTTP remote servers) and GitHub skill scanning exist, but command-line tools, extensions, external services and network egress are not scanned or defended.

Research detail: MCP scanning checks remote MCP servers by URL and their GitHub code for mismatch between stated and actual tool intent, on registration and on a schedule. Discovered skill files in GitHub are scanned for prompt injection and exfiltration. Rescans detect changed tools.

<!-- chunk: products -->
## Products

MCP Scanning, GitHub skill threat scanning, AI BOM

## Gaps

Only Streamable HTTP remote servers. CLIs, extensions and external services beyond MCP are not scanned.

<!-- chunk: options -->
## Options

Register all in-house MCP servers with both URL and repo and enable periodic scans.
