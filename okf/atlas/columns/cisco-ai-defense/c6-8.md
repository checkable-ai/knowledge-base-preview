## Answer

Not covered. No approval, versioning or rollback for changes to models, prompts, permissions or knowledge. MCP tool pinning blocks tools that change after a scan, and Policy Studio versions guardrail policies, but neither is change and release control for the AI system.

Research detail: MCP Security Profiles pin server and tool definitions and can block tools changed after a scan. Policy Studio versions its policies.
