## Answer

Not covered. Cisco AI Defense documents event and audit logs only for traffic that triggers policy, and API calls evaluated by rules alone write no event. It documents no per-agent record of tool calls, data access and changes by agent and user or session. It also documents no write-once or integrity-validated storage, and no export of such a record to tamper-evident storage. Runtime Protection event logs and the admin audit log are the nearest features, and both fall short of a complete, tamper-evident record of agent actions.

Research detail: The event log records time, action, message type, application, model and rule for policy triggers, and audit logs of user actions are kept for the subscription life. Events are kept one year.
