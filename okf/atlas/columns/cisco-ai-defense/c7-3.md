## Answer

Not covered. Model scanning and AI BOM cover inspection and bill of materials, but model provenance, lineage and compliance evidence are not documented.

Research detail: Model file scanning inspects pickle, PyTorch, Keras, ONNX, GGUF, SafeTensors and other formats for code execution, system and network access, template injection and obfuscation, from uploads or Hugging Face repos. The cisco-aibom CLI produces an AI BOM from source folders or container images. The CLI supports CI gating.
