## Answer

Not covered. MCP runtime guardrails and security profiles monitor or block individual tools and flag tool exploitation, but there are no tool quotas or rate limits, no input format or schema enforcement and no general internet egress control.

Research detail: MCP runtime guardrails inspect agent requests and MCP server responses and can block tool calls that breach policy, including PII. MCP Security Profiles block risky or changed tools, and a Tool Exploitation rule and Talos URL reputation rule screen tool misuse and malicious URLs. The Google agent gateway integration inspects every MCP method and tool call.
