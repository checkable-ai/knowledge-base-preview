## Answer

Covered. Discovering employee AI apps needs the Cisco Secure Access integration. Native cloud discovery covers AWS only and is in beta.

Source statement: "AI Access inspects web traffic to identify uses of shadow AI across your organization" (https://www.cisco.com/site/us/en/products/security/secure-access/ai-access/index.html)

Research detail: AI Inventory discovers agents, models, endpoints, agent runtimes and knowledge bases in AWS Bedrock, SageMaker and AgentCore, and Multicloud Defense Visibility covers AWS, Azure and GCP. GitHub integration finds agents and skills in code. Secure Access integration discovers third-party generative AI apps in use.
