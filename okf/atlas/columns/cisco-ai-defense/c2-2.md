## Answer

Not covered. Does not select or pin model versions per agent or set model operating limits. Its gateway only proxies calls to provider endpoints.

Last checked 15 November 2026.

Research detail: AI Defense does not run customer models. Its gateway proxies calls to provider endpoints such as Bedrock, OpenAI, Anthropic and Vertex, and its own detection models run in Cisco cloud or the hybrid data plane.
