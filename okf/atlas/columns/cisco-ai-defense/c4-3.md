## Answer

Not covered. Vendor documentation does not describe passing the user's identity or a delegated token to downstream systems. Duo-based MCP tool policies are announced in release notes only, with no documented propagation.

Research detail: Release 2026.8.2 announces identity-aware MCP tool-access policies with Duo authentication in AI Runtime, checked at tool discovery and invocation. The note does not say whether the user identity or a delegated token is passed to downstream services. The FAQ says user-level reporting depends on the app passing user IDs in requests.
