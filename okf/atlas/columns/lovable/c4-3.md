## Answer

Covered, with conditions. The Lovable MCP server is available on all plans, but the project and workspace scopes require a Business or Enterprise workspace. Third-party MCP client access is disabled by default on Enterprise workspaces. Chat connectors are enabled by default on all plans.

Source statement: "Tool calls run with your Lovable account's permissions and operate on your real projects." (https://docs.lovable.dev/integrations/lovable-mcp-server)

Last checked 17 November 2026.

Research detail: Enterprise-managed authentication lets Claude call the Lovable MCP server on behalf of each member with their existing Lovable permissions, and MCP clients are authorised per user. Chat connections are personal and app user connectors let each app user sign in with their own account. App and chat connectors instead use the credentials of the account that created the connection.

<!-- chunk: products -->
## Products

Enterprise-managed authentication, Lovable MCP server OAuth, chat connectors, app user connectors

<!-- chunk: gaps -->
## Gaps

Delegation is per user for chat and app user connectors only. Shared connections run as the creating account. Okta is the only identity provider named for managed authentication.

<!-- chunk: options -->
## Options

Use chat or app user connectors where each person's own access must apply, and limit shared app and chat connections.
