## Answer

Covered. Chat connectors, including custom MCP servers, are enabled by default on all plans. Admins can switch remote MCP connectors on or off in Privacy and security settings.

Source statement: "Lovable reads real context from tools like Notion, Linear, Jira, or Miro while you build, so results match your actual work." (https://docs.lovable.dev/integrations/chat-connectors)

Research detail: The harness is Lovable's own agent with Chat, Plan and Build modes. Admins shape it through workspace instructions and skills, switch remote MCP connectors on or off, gate third-party MCP clients and set the auto-fix scope for security findings.

## Products

Workspace instructions, workspace skills, MCP privacy settings, auto-fix setting

## Gaps
