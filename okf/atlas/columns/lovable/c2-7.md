## Answer

Partly covered. No sandbox or egress policy for agent code execution is documented, and no admin kill switch for a running agent task. The stop button is per user and per request.

Source statement: "Click the stop button while Lovable is working to halt the current task immediately." (https://docs.lovable.dev/features/agent-mode.md)

Last checked 17 November 2026.

Research detail: Admins can stop activity at several points. Usage limits can block building, API keys can be revoked, remote MCP connectors and third-party MCP clients can be switched off, and public apps can be unpublished from the Action center. SCIM deactivation removes users.

<!-- chunk: products -->
## Products

Usage limit blocks, API key revocation, MCP switches, Action center unpublish, SCIM deactivation

<!-- chunk: gaps -->
## Gaps

No kill switch for a running agent task and no documented sandbox or egress policy for agent code execution.

<!-- chunk: options -->
## Options

Pair usage limit blocks with a runbook for revoking keys and disabling MCP.
