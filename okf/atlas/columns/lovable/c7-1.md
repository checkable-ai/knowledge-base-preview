## Answer

Not covered. Audit logs record workspace admin events (membership, SSO, secrets, project lifecycle, prompt events) with actor and time, and can be exported as JSONL or sent to storage. Lovable does not document the logs as write-once or integrity-validated, or the export destinations as such. Logs of agent tool calls and data access are not described.

Last checked 17 November 2026.

Research detail: Enterprise audit logs record membership, role, SSO, SCIM, integration, project lifecycle, secret and prompt events with actor, IP address, user agent and structured JSON. Publish events carry the commit SHA. Logs are kept 13 weeks and can be exported.

## Gaps

Tamper-proofing is not described. Prompt events carry message IDs, and full input, output and reasoning are not documented as logged.
