## Answer

Covered. The local desktop MCP servers setting is available on all plans and is disabled by default on Enterprise workspaces. It applies to the desktop app.

Source statement: "Before Lovable uses a tool from a local MCP server, it asks for your approval on a card." (https://docs.lovable.dev/integrations/desktop-app)

Last checked 17 November 2026.

Research detail: Lovable builds in its own cloud, so there is little local host scope to govern. Admins can block local desktop MCP servers in the desktop app (off by default on Enterprise) and restrict source code downloads to admins and owners.

<!-- chunk: products -->
## Products

Local desktop MCP servers setting, Code downloads setting

<!-- chunk: gaps -->
## Gaps

No file system or process scope for the agent on a user's machine is documented. The controls cover only the desktop app's local MCP servers and code download.

<!-- chunk: options -->
## Options

Keep local desktop MCP servers off and restrict code downloads for sensitive workspaces.
