## Answer

Covered, with conditions. The admin settings area is available on Business and Enterprise plans. On Free and Pro, any workspace member with the editor role or higher can create connections and clients.

Source statement: "When you disable a chat connector, Lovable removes the connections members made with it." (https://docs.lovable.dev/integrations/admin-controls)

Research detail: On Business and Enterprise, admins set per connector whether no one, admins, or editors and admins can create connections, and can switch off remote MCP connectors, custom MCP and third-party MCP clients. Connector access mirrors the connected account, and API keys and OAuth clients are scoped.

<!-- chunk: products -->
## Products

Connector admin settings, MCP privacy settings, API key and OAuth scopes

<!-- chunk: gaps -->
## Gaps

No per-tool allow or deny rules for connector actions are documented. Scope is set per connector type and by what the connected account can see.

<!-- chunk: options -->
## Options

Create connectors with least-privilege provider accounts and set unused connectors to No one.
