## Answer

Covered, with conditions. Memory is on by default on all plans. Background tidying of project memory (dreaming) is limited to paid plans. Turning memory off does not delete what was saved.

Source statement: "Memory is enabled by default on all plans, and you can change or disable what Lovable remembers at any time." (https://docs.lovable.dev/features/memory.md)

Last checked 17 November 2026.

Research detail: Memory is on by default on all plans. Lovable keeps project memory shared by editors and a separate personal memory per workspace, and users can view and change memory in Account settings. Personal memory is hidden from other members and secret-like values are removed before saving.

<!-- chunk: products -->
## Products

Project memory, personal memory

<!-- chunk: gaps -->
## Gaps

Turning memory off does not delete what was saved. No admin-wide memory switch or retention setting is documented.

<!-- chunk: options -->
## Options

Review memory settings per workspace and include memory in data reviews.
