## Answer

Not covered. How the build agent's code execution, code interpreter and network egress are sandboxed is not documented. Nearby features, workspace and project isolation and regional Cloud data hosting, describe Lovable Cloud apps, not the agent's runtime.

Research detail: Lovable hosts project code and the built-in backend in its own infrastructure. Its security page describes logical isolation between workspaces and projects, network isolation and a web application firewall, and Cloud data can be placed in the Americas, Europe or Asia Pacific. Enterprise can keep code in GitHub Enterprise Cloud with data residency.
