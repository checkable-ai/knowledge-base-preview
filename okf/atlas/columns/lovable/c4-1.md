## Answer

Not covered. No separate agent or workload identity tied to an owner, runtime and release. The nearest features are API key attribution (api_key_id in audit log entries) and per-member audit events, which identify a key and a person, not an agent release.

Research detail: Lovable's agent acts inside a member's workspace session. API calls are attributed to the key and the person who created it, and audit entries carry an api_key_id. No separate agent or workload identity with an owner, runtime and release is documented.
