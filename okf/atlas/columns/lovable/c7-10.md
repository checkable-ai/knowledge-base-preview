## Answer

Partly covered. Tests the running app generated on Lovable. It does not test models, retrieval or agent tool boundaries for AI-specific attacks such as prompt injection.

Source statement: "AI pentesting is automated penetration testing performed by AI agents that simulate real attackers." (https://docs.lovable.dev/integrations/aikido.md)

Last checked 17 November 2026.

Research detail: Lovable integrates Aikido for AI penetration tests that send real payloads and attempt exploits against a running project, with findings synced into the Security view. Aikido also produces SOC 2 and ISO 27001 ready reports.

## Gaps

Needs a separate Aikido connection. It tests the generated app and does not test Lovable's own model or agent boundaries.
