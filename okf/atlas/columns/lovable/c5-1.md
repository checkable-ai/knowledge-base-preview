## Answer

Covered, with conditions. Admin approval of publishing is an Enterprise workspace policy. The Review security findings dialog appears for projects using the built-in backend with unresolved critical findings.

Source statement: "Everyone sees the same list of drafts, and a draft's edits reach the project only when someone accepts it." (https://docs.lovable.dev/features/collaboration.md)

Last checked 17 November 2026.

Research detail: Build, Plan and Chat modes let a person review the agent's work, and drafts only reach the project when accepted. Publishing can be gated by admin approval, and a Review security findings dialog appears before publishing with critical findings.
