## Answer

Partly covered. Exported audit events are workspace activity, not agent security telemetry. Redaction, detections and a named response owner are not provided by Lovable.

Source statement: "Each export sends every audit log event in the workspace." (https://docs.lovable.dev/features/data-exports.md)

Last checked 17 November 2026.

Research detail: Enterprise data exports send audit logs on an hourly or three-hourly schedule to Splunk, Azure Log Analytics, Amazon S3, Google Cloud Storage or Azure Blob Storage, so they can sit beside other security events.
