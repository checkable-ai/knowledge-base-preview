## Answer

Covered.

Source statement: "Click the stop button while Lovable is working to halt the current task immediately." (https://docs.lovable.dev/features/agent-mode.md)

Last checked 17 November 2026.

Research detail: Lovable runs a project chat with Chat, Plan and Build modes. Build mode carries a task end to end and the agent can start temporary read-only subagents to investigate in parallel. Users can work in separate drafts that reach the project only when accepted.
