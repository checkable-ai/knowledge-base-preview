## Answer

Not covered. No per-agent tool allow lists, input format checks, rate limits or blocks on dangerous tool actions. The DLP web search block for Copilot and Cowork and endpoint or network DLP for AI sites fall short of a tool call gateway.

Research detail: DLP can block Copilot and Cowork from using external web search as a grounding source when a prompt contains chosen sensitive information types. Endpoint DLP and network data security can warn or block sensitive data sent to third-party AI sites and apps.
