## Answer

Not covered. Purview itself has no control point for tool calls or internet access. It has no per-agent tool allow lists, input format checks, invocation limits or blocks on dangerous tool actions. The nearest feature is the Agent 365 tool threat protection policy (preview). It runs in the Azure API Management AI Gateway tier and needs a delegated Entra user token. Purview is only one of the engines that evaluates tool requests and results there. The gateway, and allowing or blocking MCP servers and tools, belong to Agent 365 and Azure API Management, not Purview. DLP for web search grounding and endpoint or network DLP for AI sites only control sensitive data going out, not tool calls.

Last checked 14 November 2026.

Research detail: DLP can block Copilot and Cowork from using external web search as a grounding source when a prompt contains chosen sensitive information types. Endpoint DLP and network data security can warn or block sensitive data sent to third-party AI sites and apps.

## Gaps

Covers web search and AI site egress only. No per-agent tool allow lists, schema checks, auth configuration or rate limits for tools.
