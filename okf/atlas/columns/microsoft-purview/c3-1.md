## Answer

Not covered. No gateway for model calls: no model routing, quotas, cost or rate limits per agent, user or workload. Nearest features are DLP for Microsoft 365 Copilot (sensitive-info prompt blocking, in preview, typed text only, not uploaded files, up to four hours for policy changes) and the external-email exclusion (preview), which screen content but are not a control point every model call passes through.

Research detail: DLP can stop Microsoft 365 Copilot, Copilot Chat and Cowork responding to prompts that contain chosen sensitive information types, and can exclude external email from grounding to reduce prompt injection risk. Custom apps can call the processContent and protection scopes APIs to apply the same policies per user.

## Products

DLP for Microsoft 365 Copilot location, Purview APIs in Microsoft Graph, Agent Framework Purview middleware

<!-- chunk: gaps -->
## Gaps

No model routing, quota, cost or rate limits. Prompt blocking is in preview, does not scan uploaded files, and policy changes take up to four hours. Foundry support is limited to a PowerShell-scoped SIT block honoured by apps that integrate the API.

<!-- chunk: options -->
## Options

Use Foundry or an API gateway for routing and quotas, and integrate processContent in custom apps.
