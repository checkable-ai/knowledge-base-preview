## Answer

Not covered. No permission model for which actions or APIs an agent may perform in connected systems. DLP and label policies that include agents restrict data handling only.

Last checked 14 November 2026.

Research detail: Purview restricts what data agents can use in connected Microsoft 365 systems. DLP can stop Copilot and Cowork processing labelled files and emails, and Agent 365 instances need files explicitly shared and labels that grant them VIEW and EXTRACT rights. DLP and Insider Risk policies can target agent instances as users.

<!-- chunk: products -->
## Products

DLP for Microsoft 365 Copilot location, sensitivity labels, DLP for Agent 365 instances

<!-- chunk: gaps -->
## Gaps

Controls data access, not which actions or APIs an agent may call. DLP blocks for Agent 365 cover Teams, OneDrive, SharePoint and email only, and the agent is unaware of the block.

<!-- chunk: options -->
## Options

Pair with Entra permissions and Copilot Studio or Foundry tool settings for action scopes.
