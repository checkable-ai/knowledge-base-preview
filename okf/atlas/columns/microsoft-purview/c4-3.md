## Answer

Not covered. Purview does not propagate delegated user authority to downstream systems. It relies on Entra user-context tokens and the AI platform. Nearby: Copilot prompts run in the initiating user's context, which is Copilot behaviour, not a Purview feature.

Research detail: Purview does not propagate delegated authority. It depends on it: Foundry data security policies apply only to API calls that use an Entra user-context token or explicitly include user context, and Microsoft 365 Copilot prompts run in the initiating user's security context.

## Gaps
