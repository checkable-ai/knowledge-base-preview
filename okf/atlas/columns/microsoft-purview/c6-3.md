## Answer

Covered. Needs Compliance Administrator or equivalent permissions. Allow a day or so after first setup before data appears. Reports cover data security posture, policy coverage and risky behaviour of users and AI agents, not agent runtime control coverage.

Source statement: "These insights provide a single view for monitoring data risks, policy coverage, and posture trends." (https://learn.microsoft.com/en-us/purview/data-security-posture-management-learn-about)

Research detail: DSPM's Posture page shows key metrics, objectives and a 30-day posture trend, with reports on sensitive data use, policy usage and risky behaviour of users and agents. Compliance Manager shows assessment progress, control status by family and a compliance score.
