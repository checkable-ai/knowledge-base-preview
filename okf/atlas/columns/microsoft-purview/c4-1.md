## Answer

Out of scope. Agent identity issuance sits with Microsoft Entra Agent ID. Purview only consumes agent identities in audit and observability.

Research detail: Purview does not issue or manage agent identities. It consumes them: audit records carry AgentId, AgentName and AgentVersion, and the DSPM AI observability page shows each Agent 365 instance's Entra-enabled status, owner and agent user ID. Identity itself comes from Microsoft Entra.
