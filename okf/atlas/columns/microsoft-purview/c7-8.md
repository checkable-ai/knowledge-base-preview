## Answer

Covered, with conditions. Needs an account in the Entra Compliance Administrator role or the Microsoft Purview Compliance Administrator role group. Allow a day or so after first use before data appears. Non-Microsoft data sources need integration with partner solutions, and setting up Microsoft Sentinel data lake for them is in preview. Asset explorer Microsoft locations currently include Microsoft 365 only. Unified Catalog requires the enterprise version of Microsoft Purview data governance. Data quality requires the Purview account and data source to be in the same supported Azure region, including Australia East. On-premises data quality support is in preview.

Source statement: "Microsoft Purview Data Security Posture Management (DSPM) helps organizations discover, protect, and investigate sensitive data risks across their digital estate." (https://learn.microsoft.com/en-us/purview/data-security-posture-management-learn-about)

Last checked 14 November 2026.

Research detail: Unified Catalog governs data assets with governance domains, data products, access policies and data quality rules. DSPM data risk assessments scan Fabric workspaces and SharePoint sites for overshared sensitive data and recommend labelling and DLP remediation.

<!-- chunk: products -->
## Products

Unified Catalog, DSPM data risk assessments

<!-- chunk: gaps -->
## Gaps

No feature store specific controls or sanitisation of training or retrieval data. Fabric assessments need a one-time Entra app setup.

<!-- chunk: options -->
## Options

Register retrieval sources in Unified Catalog and run a custom data risk assessment before connecting them to agents.
