## Answer

Covered. Claude Code sandbox runs on macOS, Linux and WSL2 and covers shell commands. Managed Agents is beta; API-created environments default to unrestricted networking unless limited networking is set. After an interrupt, a running tool call can complete first; credential removal has a documented delay.

Source statement: "The operating system enforces the sandbox boundary on the running process, so it holds regardless of what the model chose to run and even if an allowed command does more than its name suggests." (https://code.claude.com/docs/en/sandboxing)

Research detail: Claude Code's Bash sandbox is enforced by the operating system and limits which files and network domains shell commands and their child processes can reach, and admins can enforce it through managed settings. Managed Agents cloud sandboxes are isolated Linux containers, and limited networking restricts access to allowed_hosts, which also applies to web search and web fetch. A user.interrupt event stops a running session, and archiving prevents further events.

<!-- chunk: products -->
## Products

Claude Code sandbox, managed settings, Managed Agents cloud sandboxes, limited networking, user.interrupt, session archive

<!-- chunk: gaps -->
## Gaps

API-created environments default to unrestricted networking unless networking is set. Claude Code has an unsandboxed retry path that admins should turn off. Managed Agents is beta.

<!-- chunk: options -->
## Options

Set limited networking explicitly, enforce the Claude Code sandbox and disable the escape hatch in managed settings, and time how quickly an interrupt halts a tool call.
