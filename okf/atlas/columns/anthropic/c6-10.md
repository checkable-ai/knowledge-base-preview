## Answer

Covered, with conditions. Inference geo supports only "us" and "global", on Claude 4.6 and later models. US-only inference is priced at 1.1x the standard rate on the Claude API, Claude Platform on AWS and Claude Models on Google Cloud (Anthropic managed). Workspace geo is currently "us" only and cannot be changed after workspace creation; it is not configurable on Claude Platform on AWS or Claude Models on Google Cloud (Anthropic managed). On Amazon Bedrock and Claude Models on Google Cloud (Google managed), inference_geo is not applicable and the region follows the endpoint or inference profile. With self-hosted sandboxes, memory store contents stay stored by Anthropic. Managed Agents is in beta, needs the managed-agents-2026-04-01 header, and is not eligible for Zero Data Retention (except self-hosted) or HIPAA.

Source statement: "Data residency controls let you manage where your data is processed and stored." (https://platform.claude.com/docs/en/manage-claude/data-residency)

Last checked 18 November 2026.

Research detail: Source statement: Retention differs by endpoint. Managed Agents is not ZDR eligible and memory has explicit lifecycle operations.

Assessment: Self-hosted execution still sends model inputs and tool results to Anthropic.
