## Answer

Covered. Inference geo is US or global only, on Claude 4.6 and later models; US-only inference is priced at 1.1x. Workspace geo is US only and fixed at creation. With self-hosted sandboxes, memory store contents stay with Anthropic and are copied to the customer sandbox. Managed Agents is not ZDR eligible; customers can delete sessions.

Source statement: "Workspace geo is set when you create a workspace and can't be changed afterward." (https://platform.claude.com/docs/en/manage-claude/data-residency)

Research detail: Source statement: Retention differs by endpoint. Managed Agents is not ZDR eligible and memory has explicit lifecycle operations.

Assessment: Self-hosted execution still sends model inputs and tool results to Anthropic.
