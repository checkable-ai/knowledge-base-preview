## Answer

Covered, with conditions. Vaults are in beta and need the managed-agents-2026-04-01 beta header. Not eligible for Zero Data Retention (except self-hosted Managed Agents) or HIPAA. Offered on the Claude API, Claude Platform on AWS and Claude Models on Google Cloud (Anthropic managed). Environment variable credentials are not yet supported with self-hosted sandboxes. Vaults and credentials are workspace-scoped.

Source statement: "This ensures that credential rotation, archival, or deletion takes effect in running sessions without a restart." (https://platform.claude.com/docs/en/managed-agents/vaults)

Last checked 18 November 2026.

Research detail: Source statement: Vaults attach credentials to sessions and can use opaque environment placeholders.

Assessment: Workspace API keys can reference workspace vaults. Separate users and minimise attachments.
