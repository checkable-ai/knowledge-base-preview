## Answer

Covered. Managed Agents vaults, beta (header managed-agents-2026-04-01); not eligible for ZDR or HIPAA. Vaults are workspace-scoped. Host (allowed_hosts) and injection_location scoping must be set per credential. Environment-variable secrets are substituted at egress only for clients that send the secret verbatim; MCP OAuth tokens are refreshed automatically.

Source statement: "This ensures that credential rotation, archival, or deletion takes effect in running sessions without a restart." (https://platform.claude.com/docs/en/managed-agents/vaults)

Research detail: Source statement: Vaults attach credentials to sessions and can use opaque environment placeholders.

Assessment: Workspace API keys can reference workspace vaults. Separate users and minimise attachments.
