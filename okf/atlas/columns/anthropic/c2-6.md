## Answer

Covered. Memory stores are beta (agent-memory-2026-07-22 header); not eligible for ZDR. Attach mode defaults to read_write. On self-hosted sandboxes the local copy of a read-only store can be altered by the bash tool.

Source statement: "Memory stores let the agent carry information across sessions: user preferences, project conventions, prior mistakes, and domain context." (https://platform.claude.com/docs/en/managed-agents/memory)

Research detail: Source statement: Memory stores hold versioned documents with read-only or read-write attachment modes.

Assessment: Self-hosted shell tools can mutate local copies despite read-only API attachment.
