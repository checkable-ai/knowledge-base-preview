## Answer

Covered, with conditions. Managed Agents is in beta and needs the managed-agents-2026-04-01 beta header. Managed Agents is offered on the Claude API, Claude Platform on AWS and Claude Models on Google Cloud (Anthropic managed), each in beta. Managed Agents is not eligible for Zero Data Retention, except self-hosted Managed Agents. Managed Agents is not eligible for HIPAA. Policies apply to server-executed tools only, as custom tools run in your application and are outside them. The agent toolset defaults to always_allow (MCP toolsets default to always_ask), so restrictive policies must be set explicitly.

Source statement: "All Managed Agents endpoints require the managed-agents-2026-04-01 beta header." (https://platform.claude.com/docs/en/managed-agents/overview)

Last checked 18 November 2026.

Research detail: Source statement: Managed tool policies can require confirmation, but wrapped self-hosted custom tools require their own checks.

Assessment: Remote API privileges still depend on the attached credential and downstream service.

Source qualification: The agent toolset defaults to always_allow, MCP toolsets to always_ask, and custom tools require application controls. Running sessions retain their original toolset configuration after an agent update.
