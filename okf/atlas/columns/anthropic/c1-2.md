## Answer

Covered. Managed Agents, beta (managed-agents-2026-04-01). The agent toolset defaults to always_allow and MCP toolsets to always_ask, so restrictive policies must be set explicitly. Custom tools run in the customer's application and are not governed by permission policies.

Source statement: "Permission policies control whether server-executed tools (the pre-built agent toolset and MCP toolset) run automatically, wait for your approval, or have each call evaluated by the server." (https://platform.claude.com/docs/en/managed-agents/permission-policies)

Research detail: Source statement: Managed tool policies can require confirmation, but wrapped self-hosted custom tools require their own checks.

Assessment: Remote API privileges still depend on the attached credential and downstream service.

Source qualification: The agent toolset defaults to always_allow, MCP toolsets to always_ask, and custom tools require application controls. Running sessions retain their original toolset configuration after an agent update.
