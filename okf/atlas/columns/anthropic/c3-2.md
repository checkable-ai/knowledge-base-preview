## Answer

Partly covered. Custom tools run in the customer's application and sit outside permission policies, so there is no single control point for all tool calls. No input-format enforcement. Network control is per host, not per operation.

Source statement: "Permission policies control whether server-executed tools (the pre-built agent toolset and MCP toolset) run automatically, wait for your approval, or have each call evaluated by the server." (https://platform.claude.com/docs/en/managed-agents/permission-policies)

Research detail: Source statement: Managed Agents and Claude Code connect to MCP servers.

Assessment: A connection is not a complete security review of the server or its tool outputs.
