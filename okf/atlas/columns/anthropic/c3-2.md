## Answer

Covered, with conditions. Permission policies are in beta and need the managed-agents-2026-04-01 beta header. They are offered in beta on the Claude API, Claude Platform on AWS and Claude Models on Google Cloud (Anthropic managed). They apply to server-executed tools only (the prebuilt agent toolset and MCP toolsets); custom tools run in the customer's application, where permission policies do not apply. Managed Agents is not eligible for Zero Data Retention (except self-hosted) or HIPAA.

Source statement: "Permission policies apply to server-executed tools: the prebuilt agent toolset and MCP toolsets." (https://platform.claude.com/docs/en/managed-agents/permission-policies)

Last checked 18 November 2026.
