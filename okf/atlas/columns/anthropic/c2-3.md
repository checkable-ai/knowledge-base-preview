## Answer

Covered, with conditions. Cloud environments are in beta and need the managed-agents-2026-04-01 beta header. They are offered on the Claude API, Claude Platform on AWS and Claude Models on Google Cloud (Anthropic managed). Not eligible for Zero Data Retention (except self-hosted Managed Agents) or HIPAA. API create requests that omit networking get unrestricted access. Self-hosted sandboxes can run on your own infrastructure.

Source statement: "Environments define the sandbox configuration where your agent runs." (https://platform.claude.com/docs/en/managed-agents/environments)

Research detail: Source statement: Managed environments can be cloud-hosted or self-hosted.

Assessment: Cloud API environments default to unrestricted networking. Self-hosting retains customer isolation responsibility.
