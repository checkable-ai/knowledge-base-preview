## Answer

Covered. The sandbox runs on macOS, Linux and WSL2 only. Native Windows runs commands unsandboxed and WSL1 is not supported. Linux and WSL2 need bubblewrap and socat installed. The sandbox covers shell commands only; file tools, MCP servers and hooks run outside it and are governed by permission rules and managed settings. By default Claude Code runs commands unsandboxed if the sandbox is unavailable, unless sandbox.failIfUnavailable is set to true.

Source statement: "You set which files and network domains those commands can reach, and the limits apply to Bash, PowerShell, and Monitor commands and the processes they start." (https://code.claude.com/docs/en/sandboxing)

Research detail: Source statement: Claude Code separates tool permission rules from filesystem and network sandboxing.

Assessment: Host support and selected modes determine enforcement. Permission bypass modes require separate governance.
