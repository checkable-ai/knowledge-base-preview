## Answer

Covered. Claude Code sandbox runs on macOS, Linux and WSL2 only; native Windows runs unsandboxed. It covers shell commands only. File tools, MCP servers and hooks run outside it and are governed by permission rules and managed settings.

Source statement: "The Bash sandbox is a boundary that the operating system enforces around the shell commands Claude runs on your machine." (https://code.claude.com/docs/en/sandboxing)

Research detail: Source statement: Claude Code separates tool permission rules from filesystem and network sandboxing.

Assessment: Host support and selected modes determine enforcement. Permission bypass modes require separate governance.
