## Answer

Covered, with conditions. Pinned model IDs apply to Anthropic-operated platforms; Amazon Bedrock and Claude Models on Google Cloud (Google managed) set their own lifecycle dates. Inference geography supports only "us" and "global", and needs Claude 4.6 or later models. US-only inference costs 1.1x the standard token rates on the Claude API, Claude Platform on AWS and Claude Models on Google Cloud (Anthropic managed). Managed Agents is in beta and not eligible for Zero Data Retention (except self-hosted) or HIPAA.

Source statement: "Each Claude model ID identifies a pinned version of the model." (https://platform.claude.com/docs/en/about-claude/models/model-ids-and-versions)
