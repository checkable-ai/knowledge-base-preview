## Answer

Covered. Managed Agents, beta. The customer creates a per-end-user vault and attaches it at session creation via vault_ids. The downstream service must honour that user's token and permissions.

Source statement: "This means you don't need to run your own secret store, transmit tokens on every call, or lose track of which end user an agent acted on behalf of." (https://platform.claude.com/docs/en/managed-agents/vaults)

Research detail: Source statement: MCP connections can use OAuth credentials attached through vaults.

Assessment: Credential attachment does not establish universal on-behalf-of semantics for every downstream API.
