## Answer

Covered. Managed Agents, beta. The always_ask policy must be set (default for MCP toolsets, not for the agent toolset). The auto policy is a server evaluation, not human approval. Custom tools need application-side controls.

Source statement: "The session pauses and waits for your approval before executing." (https://platform.claude.com/docs/en/managed-agents/permission-policies)

Research detail: Source statement: always_ask produces tool confirmation requests. auto makes an automated permission decision.

Assessment: auto is not a human approval checkpoint.

Source qualification: The agent toolset defaults to always_allow, MCP toolsets to always_ask, and custom tools require application controls. Running sessions retain their original toolset configuration after an agent update.
