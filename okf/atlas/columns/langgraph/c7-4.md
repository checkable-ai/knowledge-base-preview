## Answer

Not covered. No documented hardening or scanning of the containers, agent software and hosts that run the customer's own models and tools. The shared responsibility page covers LangChain's own LangSmith application code, API endpoints, database clusters and managed infrastructure, and leaves the customer's SDK environment to the customer.

Last checked 15 November 2026.

Research detail: LangSmith Sandboxes isolate agent code in microVMs. Agent Server supports application-level encryption at rest with AES or custom KMS handlers. The shared responsibility model says LangChain manages firewalls, DDoS protection and container security for its cloud.
