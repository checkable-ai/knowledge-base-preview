## Answer

Covered. Nodes rerun on retry or resume, so idempotency is the developer's job.

Source statement: "Workers can also be signaled to cancel a run in progress." (https://docs.langchain.com/langsmith/agent-server)

Research detail: LangGraph sequences work as a graph with Command routing, Send fan-out and subgraphs for multi-agent handoffs, plus a recursion limit. Checkpoints let interrupted runs resume, and Agent Server queue workers can cancel runs. Retry middleware handles model and tool failures with backoff.
