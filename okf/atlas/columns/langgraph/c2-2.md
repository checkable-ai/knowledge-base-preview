## Answer

Covered. LangSmith LLM Gateway is in public beta, Plus and Enterprise plans only. Trace redaction is Enterprise only. Calls must be routed through the gateway.

Source statement: "Define fallback rules across models and hosts, then enforce them for all applications." (https://www.langchain.com/blog/langsmith-llm-gateway-runtime-controls-for-production-agents)

Research detail: LangGraph does not run models itself. The developer picks the model in code. Middleware adds model fallback, retry and call limits. LangSmith LLM Gateway (public beta) adds spend caps, rate limits, fallbacks and PII redaction for OpenAI, Anthropic, Fireworks and compatible endpoints.

<!-- chunk: products -->
## Products

ModelFallbackMiddleware, ModelCallLimitMiddleware, LangSmith LLM Gateway (beta)

<!-- chunk: gaps -->
## Gaps

Model version pinning and provider data handling depend on the chosen provider. The gateway is beta and only on Plus and Enterprise.

<!-- chunk: options -->
## Options

Pin model versions in configuration and route calls through the gateway or another model gateway.
