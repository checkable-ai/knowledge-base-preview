## Answer

Last checked 15 November 2026.

Research detail: The control plane lists deployments, Agent Server lists assistants with versions, and the prompt hub keeps prompts with commit history. The MCP endpoint exposes each agent's name, description and input schema. There is no single inventory of models, agents and tools with component records.
