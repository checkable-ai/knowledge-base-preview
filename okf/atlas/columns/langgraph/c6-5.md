## Answer

Not covered. No governed lifecycle from proposal through testing, production, change and retirement for models, agents and use cases. The Agent Development Lifecycle page is a product-stage overview, and prompt versioning and deployment revisions are nearby features that fall short of a lifecycle state register.

Last checked 15 November 2026.

Research detail: Deployments move through revisions, assistants keep versions with one active, prompts move between staging and production environments, and offline evaluation tests versions before release. There is no lifecycle state model from proposal to retirement.
