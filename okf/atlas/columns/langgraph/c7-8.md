## Answer

Not covered. Encryption and TTL exist but no data governance, cleaning or poisoning controls.

Research detail: Agent Server encrypts checkpoints and selected JSON fields at rest with a deployment key, or with custom handlers for per-tenant keys and external KMS. Store and checkpointer data have TTLs and per-user namespace auth. There is no sanitisation of stored memory content.

<!-- chunk: products -->
## Products

Agent Server encryption, store and checkpointer TTL, store auth

<!-- chunk: gaps -->
## Gaps

Checkpoint deserialisation advisories show the store must be treated as trusted. No memory poisoning controls.

<!-- chunk: options -->
## Options

Restrict write access to checkpoint databases and keep checkpointer packages patched.
