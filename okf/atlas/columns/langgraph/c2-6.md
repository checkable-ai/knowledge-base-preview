## Answer

Covered. Per-user isolation on Agent Server needs store auth handlers.

Source statement: "Use long-term memory to store user-specific or application-specific data across conversations." (https://docs.langchain.com/oss/python/langgraph/add-memory)

Research detail: The LangGraph store holds cross-thread memory in namespaces such as per-user tuples, with Postgres, Redis or Oracle backends and optional semantic search. On Agent Server, store auth handlers rewrite the namespace per user, and store TTL controls expiry.
