## Answer

Not covered. No data access gateway. PIIMiddleware and store auth are in-process and do not filter retrieval sources.

Research detail: PIIMiddleware detects and blocks, redacts, masks or hashes PII in inputs, outputs and tool results. Store auth handlers scope memory retrieval to each user's namespace. There is no gateway over external retrieval sources.

<!-- chunk: products -->
## Products

PIIMiddleware, Agent Server store auth

<!-- chunk: gaps -->
## Gaps

Built-in PII types are limited (email, card, IP, MAC, URL). No policy enforcement for vector stores or enterprise data sources.

<!-- chunk: options -->
## Options

Add custom detectors and enforce retrieval permissions in the data source itself.
