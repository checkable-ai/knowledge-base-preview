## Answer

Covered. LLM Gateway is in public beta, Plus and Enterprise plans only. Model calls must be routed through it. Limits at organisation, workspace, user and API key levels. No prompt injection screening. PII redaction as documented for plans.

Source statement: "Apply rate limits at the organization, workspace, user, and API key levels to prevent accidental abuse" (https://www.langchain.com/blog/langsmith-llm-gateway-runtime-controls-for-production-agents)

Research detail: LangSmith LLM Gateway (public beta, July 2026) applies spend caps and rate limits at organisation, workspace, user and API key levels, with a custom header for per-customer limits. It offers fallback routing and redacts PII and secrets before requests reach providers. Injection screening is not offered and is listed as a future direction.
