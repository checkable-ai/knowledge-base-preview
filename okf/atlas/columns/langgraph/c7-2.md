## Answer

Not covered. No documented security detections, redaction-aware export to a SOC, or named response owner. LangSmith Engine notifications forward events to incident and paging tools, but they are operational monitoring and do not describe security telemetry reaching a security operations team.

Research detail: The audit log API returns events in OCSF API Activity format, and the docs give a scheduled pull job for SIEM forwarding. Alerts can go to PagerDuty, Dynatrace or webhooks. Traces can be redacted with anonymisers before sending. There are no built-in security detections.

## Gaps
