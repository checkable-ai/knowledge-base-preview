## Answer

Not covered. No built-in security detections or push export of agent security telemetry to a SOC with a named response owner.

Research detail: The audit log API returns events in OCSF API Activity format, and the docs give a scheduled pull job for SIEM forwarding. Alerts can go to PagerDuty, Dynatrace or webhooks. Traces can be redacted with anonymisers before sending. There are no built-in security detections.
