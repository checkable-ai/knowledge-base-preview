## Answer

Not covered. Agent Auth (beta) documents no revocation, expiry policy or guarantee that secrets stay out of model context.

Research detail: Agent Auth (beta) runs OAuth flows, stores and refreshes tokens, and scopes them by assistant and user ID. LangSmith Sandboxes inject credentials at the network layer through an auth proxy so secrets do not reach the sandbox runtime. Deployment secrets are set per revision. Agent Auth returns the token to application code, and the docs do not say how it is kept out of model context or revoked.

<!-- chunk: products -->
## Products

LangSmith Agent Auth (beta), LangSmith Sandboxes auth proxy, deployment secrets

<!-- chunk: gaps -->
## Gaps

Agent Auth is beta. No documented revocation, expiry policy or guarantee that tokens stay out of model context. Secret changes need a new revision.

<!-- chunk: options -->
## Options

Keep token handling inside tool code, never in tool outputs. Test revocation with the provider. Route sandboxed calls through the auth proxy.
