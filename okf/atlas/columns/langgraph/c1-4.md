## Answer

Covered. Access governed by LangSmith RBAC; custom roles need Enterprise. Changes made as new revisions.

Source statement: "The API is used to create, update, and delete deployments." (https://docs.langchain.com/langsmith/control-plane)

Research detail: Assistants can be created, versioned and deleted through the Agent Server API, and @auth.on.assistants handlers can restrict creation to users with a given permission. Deployments are created, updated and deleted in the control plane, with LangSmith RBAC governing workspace roles. There is no provisioning workflow covering identities, permissions and configuration together.
