## Answer

Not covered. No per-agent identity record tied to owner, runtime and release. Assistant IDs and deployment revisions fall short.

Research detail: Agent Server gives each configured agent an assistant ID with a version history, and each deployment has revisions. Agent Auth scopes OAuth tokens to the calling agent by assistant ID. There is no documented workload identity that links an agent to an accountable owner, runtime attestation and release in one record.

<!-- chunk: products -->
## Products

LangSmith Deployment assistants and revisions, LangSmith Agent Auth

<!-- chunk: gaps -->
## Gaps

No agent identity issued as a credential (for example SPIFFE or an IdP principal). Owner linkage is not a native field. Open-source LangGraph has no identity concept.

<!-- chunk: options -->
## Options

Map assistant IDs and deployment revisions to an external identity provider or registry, and stamp owner metadata on assistants through custom auth handlers.
