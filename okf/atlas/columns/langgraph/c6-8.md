## Answer

Not covered. Versioning exists but no approval gate or documented deployment rollback.

Research detail: Assistants version on every edit and roll back by setting an earlier version active. Prompts have commits, diffs, environment promotion with rollback history and commit webhooks for CI. Deployment code and secrets change through revisions, and audit logs record changes. No rollback is documented for deployment revisions and there is no built-in approval gate.

<!-- chunk: products -->
## Products

Assistant versions, LangSmith prompt environments, deployment revisions, audit logs

<!-- chunk: gaps -->
## Gaps

No change approval step. Deployment revision rollback not documented. Tool and permission changes ride on code revisions.

<!-- chunk: options -->
## Options

Gate revisions through CI review using prompt webhooks and the control plane API, and redeploy a previous commit for rollback.
