## Answer

Not covered. No central tool gateway; middleware is in-process only.

Research detail: There is no separate tool gateway. In-process middleware gives per-tool approval, tool call limits, PII handling on tool results and model-based tool selection. Sandboxes filter egress by domain through the auth proxy.

<!-- chunk: products -->
## Products

HumanInTheLoopMiddleware, ToolCallLimitMiddleware, PIIMiddleware, LangSmith Sandboxes auth proxy

<!-- chunk: gaps -->
## Gaps

No central enforcement point across agents, no schema validation policy or injection screening for tool outputs, and egress control only applies inside Sandboxes.

<!-- chunk: options -->
## Options

Place an MCP or API gateway in front of tools, or enforce a shared middleware stack in every agent.
