## Answer

Covered. Opt-in LangChain middleware. Must set DockerExecutionPolicy or CodexSandboxExecutionPolicy (default host policy gives full host access) and configure root_path for file search.

Source statement: "Reuses the Codex CLI sandbox for additional syscall/filesystem restrictions." (https://docs.langchain.com/oss/python/langchain/middleware/built-in)

Research detail: LangChain's ShellToolMiddleware offers execution policies for host, Docker per run, and a Codex sandbox policy with syscall and filesystem restrictions. FilesystemFileSearchMiddleware limits file tools to a root path. These are opt-in middleware, and core LangGraph has no local permission model.

<!-- chunk: products -->
## Products

ShellToolMiddleware execution policies, FilesystemFileSearchMiddleware

<!-- chunk: gaps -->
## Gaps

Host policy gives full host access and redaction does not stop exfiltration. Persistent shell sessions do not work with interrupts.

<!-- chunk: options -->
## Options

Use the Docker or Codex sandbox policies or LangSmith Sandboxes for any shell access, and test escape and file access boundaries.
