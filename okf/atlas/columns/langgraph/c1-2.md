## Answer

Not covered. No declarative per-agent policy over downstream actions. Fixed tool lists, call limits and @auth.on handlers govern only Agent Server resources.

Research detail: The tools an agent can call are fixed in code, and ToolCallLimitMiddleware caps calls per tool, run or thread. Agent Server @auth.on handlers scope access to threads, assistants, runs and store by user and permission. Permissions against downstream systems rely on the credentials and OAuth scopes the developer configures.
