## Answer

Covered. A checkpointer must be configured so state survives the pause, and a thread ID is needed to resume. Conditional approval needs langchain 1.3.3 or later.

Source statement: "It does this by checking each tool call against a configurable policy." (https://docs.langchain.com/oss/python/langchain/human-in-the-loop)

Last checked 15 November 2026.

Research detail: The tools an agent can call are fixed in code, and ToolCallLimitMiddleware caps calls per tool, run or thread. Agent Server @auth.on handlers scope access to threads, assistants, runs and store by user and permission. Permissions against downstream systems rely on the credentials and OAuth scopes the developer configures.

<!-- chunk: products -->
## Products

ToolCallLimitMiddleware, Agent Server @auth.on handlers, Agent Auth

<!-- chunk: gaps -->
## Gaps

No declarative per-agent policy over downstream actions. @auth.on governs Agent Server resources, not external systems.

<!-- chunk: options -->
## Options

Use narrow OAuth scopes in Agent Auth and per-tool approval. Enforce downstream scopes in the target systems.
