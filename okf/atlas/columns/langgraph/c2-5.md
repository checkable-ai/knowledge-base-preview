## Answer

Covered, with conditions. The open-source LangGraph library provides it; any hardening of tool calls is added by the developer through middleware.

Source statement: "Performs the tool call" (https://docs.langchain.com/oss/python/langgraph/workflows-agents)

Last checked 15 November 2026.

Research detail: LangGraph is a harness that executes nodes and tools under a graph runtime, and LangChain agents run tools through it with middleware hooks before and after model and tool calls. Agent Server runs the harness behind a queue with checkpointing.
