## Answer

Covered. Open-source library; hardening of tool calls depends on middleware the developer adds.

Source statement: "ToolNode is a prebuilt node that executes tools in LangGraph workflows." (https://docs.langchain.com/oss/python/langgraph/workflows-agents)

Research detail: LangGraph is a harness that executes nodes and tools under a graph runtime, and LangChain agents run tools through it with middleware hooks before and after model and tool calls. Agent Server runs the harness behind a queue with checkpointing.
