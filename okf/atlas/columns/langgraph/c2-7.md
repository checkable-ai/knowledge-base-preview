## Answer

Not covered. No documented limits on agent files, processes or network access, and no emergency stop or access cut-off. Run cancellation falls short.

Research detail: LangSmith Sandboxes run agent code in hardware-virtualised microVMs, each with its own filesystem and network boundary. Outbound requests pass through a proxy that injects credentials and applies domain allow and deny lists, and non-Enterprise organisations get restricted egress to a managed allowlist by default. Agent Server queue workers can be signalled to cancel a run in progress, and the interrupt and rollback strategies halt a running run.

<!-- chunk: products -->
## Products

LangSmith Sandboxes, LangSmith Deployment (Agent Server)

<!-- chunk: gaps -->
## Gaps

Containment applies to code sent to a sandbox, not to the Agent Server process that runs the graph. Filesystem and process policy inside the sandbox are not described. Cancellation semantics for in-flight tool calls are not documented, and the docs warn a cut-off step may leave partial work.

<!-- chunk: options -->
## Options

Route all code and shell tools through Sandboxes with restricted egress. Test run cancellation mid tool call and revoke credentials held by the auth proxy.
