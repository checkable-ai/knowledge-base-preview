## Answer

Covered. Choice of Cloud, BYOC, Hybrid or self-hosted topology. Code-execution sandboxes are separate.

Source statement: "to pick a topology (Cloud managed, BYOC, Hybrid, self-hosted with control plane, or standalone)" (https://docs.langchain.com/langsmith/platform-setup)

Research detail: Agent Server runs agents in LangChain cloud, BYOC or self-hosted infrastructure. LangSmith Sandboxes, generally available from 13 May 2026, run agent code in hardware-virtualised microVMs with their own network boundary and an auth proxy that can allow or deny egress domains.

## Products

## Gaps

Sandbox resource limits are not specified in the announcement. Open-source LangGraph has no execution environment of its own.

## Options

Run code execution in Sandboxes with an egress allowlist, and choose BYOC or self-hosting where data must stay in the customer network.
