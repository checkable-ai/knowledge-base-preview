## Answer

Not covered. Vaults keep secret values out of the sandbox and model and bind MCP credentials to a server URL, with OAuth refresh and secret replacement. They do not issue short-lived scoped credentials or rotate them automatically. Deleting stored credentials does not revoke the original tokens with their providers or stop a running session, so provider-side revocation is left to the application. Sandbox injection works only in openai_hosted environments.

Research detail: Source statement: Vaults keep credentials outside instructions and can inject secrets through an approved-host proxy.

Assessment: Self-hosted credential brokerage needs customer infrastructure.

Source qualification: OpenAI API federation maps to an existing project service account. Codex federation maps to a managed ChatGPT workspace principal, is beta and requires workspace enablement.
