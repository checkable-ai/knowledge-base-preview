## Answer

Covered, with conditions. Zero Data Retention and Modified Abuse Monitoring need prior OpenAI approval and acceptance of additional requirements. Data residency is for eligible organisations, set per project, and covers only supported regions, endpoints and models. The Agents API supports US residency only and is not Zero Data Retention eligible. Agents API is in public beta. Agents API does not support Zero Data Retention, including with a self-hosted sandbox.

Source statement: "By default, abuse monitoring logs are generated for all API feature usage and retained for up to 30 days." (https://developers.openai.com/api/docs/guides/your-data)

Last checked 16 November 2026.

Research detail: Source statement: Retention and ZDR eligibility vary by endpoint. Session deletion has asynchronous physical cleanup.

Assessment: Agents state and third-party MCP copies need separate lifecycle controls.

Source qualification: The data-controls table lists /v1/agents and /v1/conversations application state until deleted, with neither endpoint eligible for Zero Data Retention. Other endpoints and third-party transfers have separate rules.
