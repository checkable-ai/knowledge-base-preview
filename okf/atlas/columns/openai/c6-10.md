## Answer

Covered. Zero Data Retention needs approval and is endpoint-specific. Some endpoints are not ZDR-eligible and keep application state until deleted. Data residency applies per project to supported regions, endpoints and models, and does not apply to system data.

Source statement: "Files can be manually deleted via the API or the dashboard." (https://developers.openai.com/api/docs/guides/your-data)

Research detail: Source statement: Retention and ZDR eligibility vary by endpoint. Session deletion has asynchronous physical cleanup.

Assessment: Agents state and third-party MCP copies need separate lifecycle controls.

Source qualification: The data-controls table lists /v1/agents and /v1/conversations application state until deleted, with neither endpoint eligible for Zero Data Retention. Other endpoints and third-party transfers have separate rules.
