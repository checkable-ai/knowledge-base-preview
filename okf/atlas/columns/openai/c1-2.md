## Answer

Covered, with conditions. Applies to remote MCP servers and connectors in the Responses API. Remote servers must support the Streamable HTTP or HTTP/SSE transport. The connector_id parameter is deprecated for models released after September 1, 2026, so use server_url instead. Local or private MCP servers connect through Secure MCP Tunnel using tunnel_id. Downstream authorisation still depends on the target system.

Source statement: "This guide shows how to use MCP tools with the Responses API." (https://developers.openai.com/api/docs/guides/tools-connectors-mcp)
