## Answer

Covered. This applies to Agents API sessions and sandbox memory, not to Responses conversations. Persistence needs the customer to preserve memory directories, session state, a snapshot or mounted storage such as S3.

Source statement: "To reuse memory in a later run, preserve the configured memory directories" (https://developers.openai.com/api/docs/guides/agents/sandboxes)
