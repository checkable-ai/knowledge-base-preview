## Answer

Covered. Application must run the OAuth flow and supply the user's token on every request, as it is not stored. Available tools depend on token scopes.

Source statement: "This value will also not be visible in the Response object created." (https://developers.openai.com/api/docs/guides/tools-connectors-mcp)

Research detail: Source statement: Workload federation exchanges identity tokens. Connectors accept configured OAuth credentials.

Assessment: Workload authentication does not establish end-user delegation to every tool.

Source qualification: OpenAI API federation maps to an existing project service account. Codex federation maps to a managed ChatGPT workspace principal, is beta and requires workspace enablement.
