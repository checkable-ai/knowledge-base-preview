## Answer

Not covered. No per-agent identity bound to owner, runtime and release. Federation maps workloads to project service accounts and session IDs are not identities.

Research detail: Source statement: Federation maps workloads to existing service accounts or managed workspace principals.

Assessment: Session IDs and named SDK agents are not independent security principals.

Source qualification: OpenAI API federation maps to an existing project service account. Codex federation maps to a managed ChatGPT workspace principal, is beta and requires workspace enablement.
