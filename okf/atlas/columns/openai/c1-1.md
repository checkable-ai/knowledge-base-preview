## Answer

Covered, with conditions. The Agents API is in beta. Applies to OpenAI-hosted sandboxes only, since self-hosted environments are the customer's responsibility. Outbound network access is enabled by default, so set it to restricted or disabled. Automatic review needs an eligible session in a project with automatic review enabled. OpenAI-hosted sandboxes use standard container rates. Agents API data residency supports only the United States.

Source statement: "Use a version of your OpenAI SDK that includes the beta Agents API." (https://developers.openai.com/api/docs/guides/agents-api/environments/openai-hosted)
