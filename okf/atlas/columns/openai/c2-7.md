## Answer

Covered. Agents API beta. Hosted sandbox network enabled by default. Deleting a session does not stop self-hosted compute.

Source statement: "Block outbound access." (https://developers.openai.com/api/docs/guides/agents-api/environments/openai-hosted)

Research detail: OpenAI-hosted Agents API sandboxes take a network access setting of enabled, disabled or restricted to up to 100 listed hosts, and templates cannot be broadened by overrides. Vault secrets reach approved hosts through a proxy so sandbox code sees a placeholder. Codex local sandboxing uses Seatbelt or bubblewrap with read-only and workspace-write modes, and Codex cloud blocks agent-phase internet by default. Background responses can be cancelled, and sessions can be deleted to request sandbox cleanup.

<!-- chunk: products -->
## Products

Agents API OpenAI-hosted sandboxes, vault secrets, Codex sandbox, Codex cloud internet access, Responses cancel

<!-- chunk: gaps -->
## Gaps

API-created sandboxes default to enabled outbound access. Closing an event stream does not cancel a task, deleting a session can return 409 while work finishes, and deleting a session does not stop self-hosted compute. The Agents API is beta.

<!-- chunk: options -->
## Options

Set network to disabled or restricted in a template, and test how long cancel plus delete takes to stop a running tool call.
