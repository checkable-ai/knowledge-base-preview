## Answer

Covered, with conditions. This applies to Agents API sessions, which are used with the OpenAI-Beta: agents=v1 header. The application must store the session ID. Managed session state is kept until deleted and is not Zero Data Retention eligible. Agents API data residency is US only.

Source statement: "Delete a session when your application no longer needs it." (https://developers.openai.com/api/docs/guides/agents-api/sessions/manage)

Last checked 16 November 2026.
