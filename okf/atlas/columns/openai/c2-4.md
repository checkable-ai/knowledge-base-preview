## Answer

Covered. Agents API is beta. The application must store the session ID and delete sessions itself; physical cleanup may be asynchronous.

Source statement: "After a restart or stream disconnect, retrieve the session to find pending actions." (https://developers.openai.com/api/docs/guides/agents-api/sessions/manage)

Research detail: Source statement: Responses conversation state and Agents API sessions maintain interaction history.

Assessment: Retained state can include untrusted content and differs by API.
