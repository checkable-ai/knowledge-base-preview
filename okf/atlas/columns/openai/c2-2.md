## Answer

Covered, with conditions. Data residency is for eligible organisations and is set per project at creation. The region cannot be changed afterwards. Models released on or after March 5, 2026 carry a 10% uplift on data residency endpoints. In Australia, gpt-6-luna supports regional processing. Zero Data Retention and Modified Abuse Monitoring need prior OpenAI approval. Agents API uses an OpenAI-managed harness and is in public beta.

Source statement: "Eligible organizations can enable data residency when creating a project in the API Platform." (https://developers.openai.com/api/docs/guides/data-residency)
