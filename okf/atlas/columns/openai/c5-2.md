## Answer

Covered. Misalignment monitoring covers Responses API requests only, not Chat Completions. Automatic stopping applies only to Responses requests that use persisted reasoning, WebSockets or compaction; other Responses requests are monitored but not stopped. Alerts arrive through safety.alert.created webhooks. Review is asynchronous, so an action may complete before a concern is flagged, and a stop does not undo earlier actions. It can miss issues or flag legitimate activity. Training agents on their tasks is not part of this feature.

Source statement: "It reviews model reasoning and actions asynchronously and can stop a conversation when it identifies a potential issue." (https://developers.openai.com/api/docs/guides/safety-checks/misalignment-monitoring)

Research detail: Source statement: Trace grading scores model/tool calls and handoffs for regressions.
