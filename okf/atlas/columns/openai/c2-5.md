## Answer

Covered, with conditions. The Agents API is in beta. With the Agents API, OpenAI runs the harness. With function tools, the customer's own code runs the function and returns the result. Self-hosted environments need a connected executor. Agents API data residency supports only the United States.

Source statement: "The harness calls the model, uses the configured tools, and returns results." (https://developers.openai.com/api/docs/guides/agents-api/architecture)
