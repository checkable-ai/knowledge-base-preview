## Answer

Covered. Requires separately licensed MuleSoft Agent Fabric with an ingress authentication policy (such as Client ID enforcement) configured on the broker. Agentforce-native orchestration is same-org only.

Source statement: "Configure the broker with an ingress authentication policy that yields this identity." (https://docs.mulesoft.com/agent-network/latest/af-a2a-agent-network)

Research detail: Multi-Agent Orchestration connects Agentforce agents in the same org as orchestrator and connected subagents, with documented identity handling per agent type combination. MuleSoft Agent Fabric release notes list A2A protocol 1.0 support in agent networks, A2A policies and Trusted Agent Identity. Agentforce-native orchestration is limited to agents in one org.

<!-- chunk: products -->
## Products

Agentforce Multi-Agent Orchestration, MuleSoft Agent Fabric (Agent Broker, Trusted Agent Identity)

<!-- chunk: gaps -->
## Gaps

Cross-org and cross-vendor A2A authentication is documented only in MuleSoft release notes, not in the primary feature pages reviewed.

## Options
