## Answer

Covered. Up to 50 memories per user per agent; employee agents in Lightning Experience need user opt-in.

Source statement: "This graph endures across sessions and distinct communication channels." (https://engineering.salesforce.com/how-agentic-memory-enables-durable-reliable-ai-agents-across-millions-of-enterprise-users/)

Research detail: Agent Memory stores memories per user per agent and uses them in later conversations. Memories are not shared between agents, are capped at 50 per user, and users can view, edit, import, export and delete them. Employee agents in Lightning Experience require user opt-in, Service agent channels do not.

## Products

Agent Memory

<!-- chunk: gaps -->
## Gaps

Disabling memory keeps stored memories. No opt-in or disclaimer step on Service agent channels.

## Options

Add the User Memory Management subagent and publish a notice to customers before enabling.
