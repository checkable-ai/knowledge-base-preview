## Answer

Covered, with conditions. Agentforce external MCP connections using OAuth per-user named/external credentials and a Per-User Principal; each user needs external consent and an account. Plan and region unspecified.

Source statement: "With a per-user type configured (a named credential paired with an external credential using a Per-User Principal), each individual Salesforce user goes through a one-time OAuth consent flow the first time they trigger the connection, authorizing against the external system" (https://www.salesforce.com/blog/connect-agentforce-external-mcp-servers/)

Last checked 12 November 2026.
