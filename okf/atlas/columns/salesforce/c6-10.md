## Answer

Not covered. Zero data retention with third-party LLM providers is documented, but no configurable rules for retention, deletion and residency of agent inputs, outputs and memory were verified. Provider terms cover only the model-side part.

Research detail: External LLM providers operate under zero data retention. Geo-aware routing and an in-region only setting control model request residency. Audit and feedback data can be deleted, enhanced event logs keep data for seven days, and Agent Memory keeps up to 50 memories per user with user deletion.

<!-- chunk: products -->
## Products

Zero data retention, geo-aware routing, Data 360 audit data, Agent Memory

<!-- chunk: gaps -->
## Gaps

Default behaviour reroutes failed requests to other regions. Retention settings for session tracing data were not reviewed.

<!-- chunk: options -->
## Options

Enable In-Region Model Requests Only and define Data 360 retention for trace data.
