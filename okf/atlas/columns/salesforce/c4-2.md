## Answer

Not covered. Named and external credentials with OAuth exist, but no documented short-lived scoped credentials, rotation and revocation, or statement that secrets stay out of model context.

Research detail: Registering an MCP server creates a named credential, external credential and permission set so Salesforce authenticates to the server. OAuth 2.0 client credentials and per-user authentication are supported, users are re-prompted when OAuth credentials expire and can revoke per-user authorisation. The docs do not state rotation policy or explicitly confirm that secrets never reach model context.
