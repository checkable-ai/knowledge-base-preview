## Answer

Covered. Requires MuleSoft Agent Fabric / Omni Gateway licensing, Managed or Connected Mode (not Local Mode). Governs only calls routed through the Model Proxy, not Agentforce-native Trust Layer calls.

Source statement: "enforces rate limiting on Model Proxy requests based on the number of tokens consumed." (https://docs.mulesoft.com/gateway/latest/policies-included-llm-token-rate-limit)

Research detail: Model calls pass through the LLM Gateway in the Einstein Trust Layer, which applies prompt defence, toxicity scoring and, in beta, prompt injection detection, with scores logged to the audit trail. Admins can allow or block model providers org-wide. No per-agent or per-user model routing, quota or rate controls are documented.

<!-- chunk: products -->
## Products

Einstein Trust Layer (LLM Gateway, Prompt Defense, Prompt Injection Detection beta, Toxicity Detection)

<!-- chunk: gaps -->
## Gaps

Prompt injection detection is beta. No per-workload quota or routing policy for model calls.
