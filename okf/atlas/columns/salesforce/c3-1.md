## Answer

Covered, with conditions. Requires MuleSoft Agent Fabric with Omni Gateway. Model Proxy is supported on Managed Omni Gateway and Self-Managed Omni Gateway running in Connected Mode. The token rate limit policy is not supported in Local Mode. The policy is first available in Omni Gateway v1.11.0. It governs only calls routed through the Model Proxy, not Agentforce-native Trust Layer calls.

Source statement: "Rate limits Model Proxy usage based on token consumption." (https://docs.mulesoft.com/gateway/latest/policies-included-llm-token-rate-limit)

Research detail: Model calls pass through the LLM Gateway in the Einstein Trust Layer, which applies prompt defence, toxicity scoring and, in beta, prompt injection detection, with scores logged to the audit trail. Admins can allow or block model providers org-wide. No per-agent or per-user model routing, quota or rate controls are documented.

<!-- chunk: products -->
## Products

Einstein Trust Layer (LLM Gateway, Prompt Defense, Prompt Injection Detection beta, Toxicity Detection)

## Gaps

Prompt injection detection is beta. No per-workload quota or routing policy for model calls.
