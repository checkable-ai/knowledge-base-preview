## Answer

Covered. Requires separately licensed MuleSoft Omni Gateway / Agent Fabric. Policies are inbound and cover MCP traffic, not general internet egress.

Source statement: "Restricts which MCP tools are exposed by defining Allow and Block rules." (https://docs.mulesoft.com/gateway/1.12/flex-agent-policies)

Research detail: Agentforce Gateway applies policies to MCP server and API connections: quota per agent and per tool or operation, restrictive access by HTTP path and method, and MCP attribute-based access control by tool name. Policies can be applied by matching criteria. Tool response injection screening and general internet egress control are not covered by the gateway.

<!-- chunk: products -->
## Products

Agentforce Gateway (Policy Builder), Agentforce Registry

<!-- chunk: gaps -->
## Gaps

Policies are not enforced for draft agents. No documented schema validation or screening of tool outputs.

<!-- chunk: options -->
## Options

Apply rule-based policies to all MCP connections and pair with MCP risk scoring at registration.
