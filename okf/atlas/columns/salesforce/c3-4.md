## Answer

Covered. Requires separately licensed MuleSoft Omni Gateway 1.9.3 or later (not Local Mode), A2A v0.3.0, with authentication and schema validation policies configured.

Source statement: "The A2A Schema Validation policy validates that every request to the A2A server complies with the A2A schema." (https://docs.mulesoft.com/gateway/1.9/policies-included-a2a-schema-validation)

Research detail: Within Agentforce, orchestrator and connected subagent pairs are configured by admins with fixed identity rules per agent type. MuleSoft Agent Fabric lists A2A, MCP and LLM policies enforced by Omni Gateway. Agentforce Gateway itself covers MCP and API connections only.
