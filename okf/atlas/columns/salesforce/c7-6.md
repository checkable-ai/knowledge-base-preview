## Answer

Not covered. The MCP schema validation policy detects tool poisoning and near-twin shadow tool names in tools/list responses, with each detection type off by default, but does not scan tools, plugins or skills from public registries or check packages for compromise.

Last checked 12 November 2026.

Research detail: Third-party MCP servers are scanned at registration for tool poisoning attacks: exfiltration, privilege escalation, steering and instruction overriding, scored low, medium or high per tool. Pre-packaged servers can be installed from AgentExchange. Detection of name squatting or package compromise after registration is not documented.

## Gaps

Scoring happens at registration. Ongoing monitoring of tool description changes is not described beyond out-of-sync handling.

## Options

Re-review tools when servers go out of sync and keep high-risk tools off the allowlist.
