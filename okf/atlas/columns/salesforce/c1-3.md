## Answer

Not covered. Require user confirmation is confirmed by the conversing user; no separate approver, parameter binding, or denial and replay handling. Manual Approval queue covers only Engagement agent emails.

Research detail: When an action changes a record, admins can enable Require user confirmation so the agent asks the user to confirm before running it. The confirming person is the conversing user, not a separate approver. Denial handling and replay protection are not described.
