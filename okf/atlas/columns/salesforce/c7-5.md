## Answer

Not covered. MCP risk scores at registration are advisory; no SBOM, code or vulnerability scanning of tools, Apex or flows, or egress defence.

Research detail: When an MCP server is registered, Salesforce scans its tools and assigns risk scores for tool poisoning categories, and the registration flow warns on hidden or bidirectional Unicode in tool descriptions. Gateway policies then limit tools and call volumes. No SBOM, code scanning or review of Salesforce-hosted MCP servers, Apex or flow actions is documented.
