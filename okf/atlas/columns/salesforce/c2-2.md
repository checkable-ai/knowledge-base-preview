## Answer

Covered, with conditions. Data handling is via the Einstein Trust Layer. Available in Enterprise, Performance, Unlimited, and Developer Editions. Required add-on licences vary by agent type. The AWS-Hosted option uses Anthropic Claude Haiku 4.5 on Salesforce-managed Amazon Bedrock. Google Gemini uses Gemini 3.5 Flash on Vertex AI and supports only agents built in the new Agentforce Builder.

Source statement: "Zero data retention is a strict policy where the prompts and generated responses are never stored" (https://www.salesforce.com/artificial-intelligence/trusted-ai/?bc=DB)

Last checked 12 November 2026.

Research detail: Salesforce publishes supported models with provider, version string, usage type and regions. Admins can turn model providers on or off, requests use geo-aware routing with an in-region only option, and external providers are under zero data retention agreements. Deprecated models may be rerouted to a newer model in the same family.
