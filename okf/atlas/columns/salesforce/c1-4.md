## Answer

Not covered. Permission-gated setup, activation and deletion exist, but no documented controlled approval process for creating, changing or retiring agents.

Research detail: Agent users are created during agent setup with minimal access and only admins can view or edit them. Managing agents requires Manage AI Agents or Customize Application, and the Manage Agentforce Service Agents permission set delegates agent management. Agents can be activated, deactivated and deleted. There is no documented approval workflow for creating or retiring agent identities.

<!-- chunk: products -->
## Products

Agent user, Manage AI Agents permission, Manage Agentforce Service Agents permission set

<!-- chunk: gaps -->
## Gaps

Manage AI Agents grants org-wide management of all agents. No retirement workflow for agent users.

<!-- chunk: options -->
## Options

Restrict Manage AI Agents assignment and use change sets or DevOps pipelines for agent metadata changes.
