## Answer

Not covered. Agent Visualizer maps agents, MCP servers, LLMs, call direction and policy coverage, but does not describe which downstream systems each agent can reach or what it is permitted to do there.

Research detail: Agentforce Registry lists registered MCP servers and their allowlisted tools, which appear as actions in the asset library. MuleSoft Agent Visualizer adds search and MCP server and tool insights across agent networks. No single Agentforce view of each agent's reach and action scope against downstream systems is documented.
