## Answer

Not covered. The A2A PII Detector only logs or blocks four PII types in requests to the agent; no per-agent and per-user retrieval filtering or response inspection.

Research detail: Secure data retrieval grounds prompts using the permissions, field-level security and sharing of the executing user. Data masking replaces sensitive data before it reaches external LLMs, but pattern-based and field-based masking is disabled for agents. Data sent outside the trust boundary is covered by zero data retention.

## Products

Einstein Trust Layer (Dynamic Grounding with Secure Data Retrieval, Data Masking)

<!-- chunk: gaps -->
## Gaps

No DLP masking for agent prompts. Service agents retrieve with the agent user's access.

<!-- chunk: options -->
## Options

Restrict agent user access and use Salesforce-hosted models where data must stay in the trust boundary.
