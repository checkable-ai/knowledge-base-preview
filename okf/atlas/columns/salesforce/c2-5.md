## Answer

Covered. Salesforce-managed reasoning engine, not customer-hosted.

Source statement: "It thinks through a step, uses an action, checks the outcome, and loops until it completes the user's goal." (https://trailhead.salesforce.com/content/learn/modules/reasoning-in-artificial-intelligence/discover-the-atlas-reasoning-engine)

Research detail: The Atlas reasoning engine is the harness that builds prompts and runs agent actions, which can be Apex, flows, prompt templates, API calls or MCP tools. Agent Script combines deterministic expressions with natural language instructions. The harness is Salesforce-managed and not customer-hosted.
