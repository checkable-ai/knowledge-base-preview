## Answer

Covered, with conditions. Testing consumes credits and can modify CRM data, so run tests in a sandbox. Testing Center is available in Enterprise, Performance, Unlimited, and Developer Editions, with add-on licences varying by agent type. Agent Optimizer in Observability is beta. That Optimizer requires Enterprise, Performance, or Unlimited Edition with an Einstein for Sales, Einstein for Platform, Einstein for Service, Einstein 1 Service, or Einstein GPT Service add-on.

Source statement: "You can use the tests over and over, adding to them as needed to ensure the agent continues to be trustworthy." (https://trailhead.salesforce.com/content/learn/modules/agentforce-agent-testing/trust-your-agents)

Last checked 12 November 2026.

Research detail: Agentforce Testing Center runs batch tests from generated or uploaded cases and scores response accuracy, subagent and action selection, completeness, latency and instruction adherence. Guardrail monitoring evaluates instruction adherence and task resolution in production, and Agent Health Monitoring alerts on error and latency anomalies.
