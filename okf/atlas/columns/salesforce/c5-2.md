## Answer

Covered. Testing consumes credits and can modify CRM data, so run tests in a sandbox.

Source statement: "Automated testing saves time that would have been lost on manually testing many different variations of a conversation." (https://trailhead.salesforce.com/content/learn/modules/agentforce-agent-testing/trust-your-agents)

Research detail: Agentforce Testing Center runs batch tests from generated or uploaded cases and scores response accuracy, subagent and action selection, completeness, latency and instruction adherence. Guardrail monitoring evaluates instruction adherence and task resolution in production, and Agent Health Monitoring alerts on error and latency anomalies.
