## Answer

Covered. Subagent and action scoping, agent user permissions and gateway policies. Gateway policies are not enforced on draft agents; flows running in system context without sharing bypass user access.

Source statement: "Subagents define what actions are valid and which policies apply." (https://trailhead.salesforce.com/content/learn/modules/reasoning-in-artificial-intelligence/discover-the-atlas-reasoning-engine)

Research detail: Agent data access is set by the agent user's or end user's profile, permission sets, field-level security and sharing rules, created with minimal access by default. Filters restrict subagents and actions to conditions such as verified identity. Agentforce Gateway policies restrict MCP tools by name and API paths and methods, and MCP tools must be allowlisted at registration.
