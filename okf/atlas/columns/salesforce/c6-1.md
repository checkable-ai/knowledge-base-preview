## Answer

Covered. Requires MuleSoft Agent Fabric / Anypoint Exchange licence and suitable Exchange permissions to register assets. Component detail depends on asset metadata.

Source statement: "The registry is a single inventory of agents, MCP servers, APIs, and related services, regardless of which platform built them." (https://docs.mulesoft.com/general/af-get-started)

Research detail: Agentforce Registry records registered MCP servers and allowlisted tools, and the asset library lists subagents and actions. MuleSoft Agent Registry catalogues agent, MCP and LLM assets. Agent and model inventory inside Agentforce is split across Setup pages.

## Products

Agentforce Registry, Agentforce Assets, MuleSoft Agent Registry

## Gaps

## Options
