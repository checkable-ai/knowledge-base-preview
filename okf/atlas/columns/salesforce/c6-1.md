<!-- chunk: answer -->
## Answer

Covered, with conditions. Registering assets needs one of the Exchange roles: Exchange Contributor, Exchange Administrator or Exchange Creator. Agent Fabric must be enabled for the Anypoint Platform organisation. Observability-based dashboards apply only when the tenant includes Observability. The Akamai API Security scanner is available only when an administrator turns it on. Runs on MuleSoft Agent Fabric, a separate product from Salesforce Agentforce.

Source statement: "The registry is a single inventory of agents, MCP servers, APIs, and related services" (https://docs.mulesoft.com/general/af-get-started)

Research detail: Agentforce Registry records registered MCP servers and allowlisted tools, and the asset library lists subagents and actions. MuleSoft Agent Registry catalogues agent, MCP and LLM assets. Agent and model inventory inside Agentforce is split across Setup pages.

<!-- chunk: products -->
## Products

Agentforce Registry, Agentforce Assets, MuleSoft Agent Registry

## Gaps

No single inventory of agents, models and tools with software component records in Agentforce.

## Options

Use MuleSoft Agent Registry as the cross-platform inventory.
